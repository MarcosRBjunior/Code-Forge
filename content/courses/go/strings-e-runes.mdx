Em Python, uma string é uma sequência de caracteres. Em JavaScript, uma sequência de unidades UTF-16. Em Go, uma string é uma sequência imutável de bytes, normalmente codificados em UTF-8. Essa diferença explica por que `len("olá")` não é 3 e por que você precisa de `rune` quando o texto sai do ASCII.

## Bytes, runes e tamanhos

O tipo `string` guarda bytes. Indexar com `s[i]` devolve um `byte` (um `uint8`), não um caractere. Um `rune` é um ponto de código Unicode (alias de `int32`). Letras ASCII ocupam 1 byte; letras acentuadas como `á` ocupam 2.

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	s := "olá"
	fmt.Println(len(s), utf8.RuneCountInString(s))
	fmt.Println(s[0])

	for i, r := range s {
		fmt.Println(i, string(r))
	}

	rs := []rune(s)
	fmt.Println(len(rs), string(rs[2]))
}
```

```text
Saída:
4 3
111
0 o
1 l
2 á
3 á
```

Observe as saídas. `len(s)` conta bytes (4), e `utf8.RuneCountInString` conta caracteres (3). O `s[0]` vale 111, o código de `o`. Já o `range` sobre uma string decodifica UTF-8: o índice é a posição em bytes e o valor é um `rune`, por isso o último caractere começa no índice 2 e não no 3. Se precisar de acesso por posição de caractere, converta com `[]rune(s)`.

<Callout type="note" title="Strings são imutáveis">
`s[0] = 'x'` não compila. Para modificar, converta para `[]byte` ou `[]rune`, altere e converta de volta com `string(...)`. Cada conversão copia, custando O(n).
</Callout>

## Montando e inspecionando strings

Concatenar com `+` em um laço cria uma string nova a cada passo, o que leva a O(n ao quadrado) no total. Use `strings.Builder`, que acumula bytes em um buffer. O pacote `strings` também traz as operações do dia a dia.

```go
package main

import (
	"fmt"
	"strings"
)

func inverte(s string) string {
	rs := []rune(s)
	for i, j := 0, len(rs)-1; i < j; i, j = i+1, j-1 {
		rs[i], rs[j] = rs[j], rs[i]
	}
	return string(rs)
}

func anagrama(a, b string) bool {
	if len(a) != len(b) {
		return false
	}
	var cont [26]int
	for i := 0; i < len(a); i++ {
		cont[a[i]-'a']++
		cont[b[i]-'a']--
	}
	for _, c := range cont {
		if c != 0 {
			return false
		}
	}
	return true
}

func main() {
	fmt.Println(inverte("olá"))

	var sb strings.Builder
	for i := 0; i < 3; i++ {
		sb.WriteString("ab")
	}
	sb.WriteByte('!')
	fmt.Println(sb.String())

	fmt.Println(strings.Fields("  a  b c "), len(strings.Fields("  a  b c ")))
	fmt.Println(strings.Split("x,y,z", ","))
	fmt.Println(strings.Contains("entrevista", "vis"), strings.Repeat("-", 5))
	fmt.Println(anagrama("listen", "silent"), anagrama("abc", "abd"))
}
```

```text
Saída:
álo
ababab!
[a b c] 3
[x y z]
true -----
true false
```

O truque `cont[a[i]-'a']++` é o idioma mais comum em problemas de string: subtrair `'a'` de um byte dá o índice de 0 a 25, e a tabela `[26]int` custa menos que um mapa. Ele só vale para letras minúsculas ASCII; para texto geral use `map[rune]int`.

## O que mais existe

| Função | Uso |
|---|---|
| `strings.Fields` | divide por espaços em branco, ignorando repetidos |
| `strings.Split` | divide por um separador |
| `strings.TrimSpace`, `Trim` | remove bordas |
| `strings.HasPrefix`, `HasSuffix` | testa início e fim |
| `strings.Index` | posição de uma substring, ou menos 1 |
| `strings.Join` | une um slice de strings |
| `strconv.Itoa`, `Atoi` | número e texto |

Comparar com `==` e ordenar com `<` funcionam direto, byte a byte.

## Na entrevista

Pergunte logo se a entrada é ASCII. Se for, trabalhe com bytes e `[26]int`; se houver Unicode, converta para `[]rune`. Para acumular resultado, use `strings.Builder` ou um `[]byte` que você converte no final. Para verificar palíndromos, dois ponteiros sobre o `[]rune` resolvem.

Follow-ups comuns: "qual o custo de concatenar em um laço?" (quadrático, por isso o Builder) e "por que `len` de uma string com acento é maior que o número de letras?" (conta bytes UTF-8).
