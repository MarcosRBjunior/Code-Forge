Python tem `heapq` e JavaScript, nas entrevistas, costuma exigir que você escreva o heap à mão. Go fica no meio do caminho: a biblioteca padrão traz `container/heap`, mas ela não é uma estrutura pronta. É um conjunto de algoritmos (`Init`, `Push`, `Pop`, `Fix`) que operam sobre qualquer tipo que implemente uma interface. Você escreve cinco métodos uma vez, e o resto é a biblioteca. Isso é verboso, então vale ter o molde na ponta dos dedos.

## A interface

Seu tipo precisa implementar `heap.Interface`, que combina `sort.Interface` (`Len`, `Less`, `Swap`) com dois métodos `Push(x any)` e `Pop() any`. Os três primeiros usam receptor por valor; `Push` e `Pop` precisam alterar o tamanho do slice, então usam receptor ponteiro. O sentido do `Less` define o heap: com `<` você tem um min-heap, com `>` um max-heap.

```go
package main

import (
	"container/heap"
	"fmt"
)

type IntHeap []int

func (h IntHeap) Len() int           { return len(h) }
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *IntHeap) Push(x any) { *h = append(*h, x.(int)) }

func (h *IntHeap) Pop() any {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[:n-1]
	return x
}

func topK(nums []int, k int) []int {
	h := &IntHeap{}
	for _, v := range nums {
		heap.Push(h, v)
		if h.Len() > k {
			heap.Pop(h)
		}
	}
	res := make([]int, 0, k)
	for h.Len() > 0 {
		res = append(res, heap.Pop(h).(int))
	}
	return res
}

func main() {
	h := &IntHeap{5, 2, 8}
	heap.Init(h)
	heap.Push(h, 1)
	fmt.Println((*h)[0], h.Len())

	var ordem []int
	for h.Len() > 0 {
		ordem = append(ordem, heap.Pop(h).(int))
	}
	fmt.Println(ordem)

	fmt.Println(topK([]int{3, 1, 5, 12, 2, 11}, 3))
}
```

```text
Saída:
1 4
[1 2 5 8]
[5 11 12]
```

Há uma armadilha clássica aqui: você chama `heap.Push(h, v)` e `heap.Pop(h)`, não `h.Push` e `h.Pop`. Os métodos do seu tipo só mexem no slice cru; as funções do pacote `heap` são as que reorganizam o heap depois (`up` e `down`). Chamar os métodos diretamente quebra a invariante sem avisar. O elemento mínimo fica sempre em `(*h)[0]`, e `Pop` devolve `any`, então você faz a asserção de tipo `.(int)`.

O `topK` mostra o padrão mais cobrado: para os k maiores, mantenha um **min-heap de tamanho k**. Ao inserir um elemento além de k, remova o menor; no fim sobram os k maiores. O custo é O(n log k), melhor que ordenar tudo (O(n log n)) quando k é pequeno.

## Heap com structs e prioridade

Em problemas reais, o item carrega um dado e uma prioridade. Basta trocar o tipo do elemento e o `Less`.

```go
package main

import (
	"container/heap"
	"fmt"
)

type Tarefa struct {
	nome string
	prio int
}

type Fila []Tarefa

func (f Fila) Len() int           { return len(f) }
func (f Fila) Less(i, j int) bool { return f[i].prio > f[j].prio }
func (f Fila) Swap(i, j int)      { f[i], f[j] = f[j], f[i] }
func (f *Fila) Push(x any)        { *f = append(*f, x.(Tarefa)) }
func (f *Fila) Pop() any {
	old := *f
	n := len(old)
	t := old[n-1]
	*f = old[:n-1]
	return t
}

func main() {
	f := &Fila{}
	heap.Push(f, Tarefa{"lavar", 2})
	heap.Push(f, Tarefa{"estudar", 9})
	heap.Push(f, Tarefa{"dormir", 5})

	(*f)[0].prio = 1
	heap.Fix(f, 0)

	for f.Len() > 0 {
		t := heap.Pop(f).(Tarefa)
		fmt.Println(t.nome, t.prio)
	}
}
```

```text
Saída:
dormir 5
lavar 2
estudar 1
```

Como `Less` usa `>`, é um max-heap por prioridade: `estudar` (9) começa no topo. O programa rebaixa a prioridade dele para 1 e chama `heap.Fix(f, 0)`, que reposiciona o elemento no índice informado em O(log n). Depois disso a ordem de saída é `dormir`, `lavar`, `estudar`. Para Dijkstra, é comum guardar `{no, dist}` e preferir inserir uma entrada nova em vez de atualizar, ignorando as obsoletas na hora de remover.

## Custos

| Operação | Custo |
|---|---|
| `heap.Init` | O(n) |
| `heap.Push` / `heap.Pop` | O(log n) |
| Ver o topo | O(1) |
| `heap.Fix` / `heap.Remove` | O(log n) |

<Callout type="note" title="Sem heap de bolso">
Não existe `PriorityQueue` pronta. Se a entrevista for em Go, decore o molde acima: cinco métodos, o `Less` define min ou max, e sempre use `heap.Push` e `heap.Pop`.
</Callout>

## Na entrevista

Comece dizendo que vai usar `container/heap` e escreva o tipo e os cinco métodos de uma vez, trocando só o tipo do elemento e o `Less`. Para max-heap de inteiros, inverta o `Less` ou insira o negativo. Follow-ups comuns: "quais os k elementos mais frequentes?" (mapa de contagem mais min-heap de tamanho k), "mediana de um fluxo" (dois heaps) e "por que `Pop` do tipo é diferente de `heap.Pop`?" (o primeiro só remove o último do slice, o segundo troca o topo com o fim e reorganiza).
