Python tem `set`, `deque` e listas que servem de pilha. JavaScript tem `Set` e arrays com `push`, `pop` e `shift`. Go não traz nenhum desses como tipo embutido, mas os três saem de duas ferramentas que você já conhece: o mapa e o slice. Montá-los em segundos é uma habilidade de entrevista.

## Conjunto com mapa

O idioma é `map[T]struct{}`. A struct vazia ocupa zero bytes, então só a chave importa. Quando preferir legibilidade, `map[T]bool` também é aceito e costuma ser o que as pessoas escrevem em entrevista.

```go
package main

import "fmt"

func valido(s string) bool {
	pares := map[rune]rune{')': '(', ']': '[', '}': '{'}
	var pilha []rune
	for _, c := range s {
		switch c {
		case '(', '[', '{':
			pilha = append(pilha, c)
		case ')', ']', '}':
			if len(pilha) == 0 || pilha[len(pilha)-1] != pares[c] {
				return false
			}
			pilha = pilha[:len(pilha)-1]
		}
	}
	return len(pilha) == 0
}

func main() {
	visto := map[int]struct{}{}
	for _, v := range []int{3, 1, 3, 2, 1} {
		visto[v] = struct{}{}
	}
	_, tem := visto[2]
	fmt.Println(len(visto), tem)

	pilha := []int{}
	pilha = append(pilha, 1, 2, 3)
	topo := pilha[len(pilha)-1]
	pilha = pilha[:len(pilha)-1]
	fmt.Println(topo, pilha)

	fmt.Println(valido("([]{})"), valido("(]"), valido("(("))
}
```

```text
Saída:
3 true
3 [1 2]
true false false
```

O conjunto `visto` guarda os valores distintos 3, 1 e 2, então `len` dá 3. Inserir um elemento repetido não muda nada, e a checagem de pertencimento é `_, ok := visto[x]`. Para operações de conjunto (união, interseção, diferença) não há função pronta: escreva um laço sobre um dos conjuntos e consulte o outro.

## Pilha com slice

Uma pilha é um slice em que você só mexe no fim. Empilhar é `s = append(s, x)`, ler o topo é `s[len(s)-1]`, e desempilhar é `s = s[:len(s)-1]`. Tudo O(1). Verifique `len(s) > 0` antes de ler o topo, ou o programa entra em pânico por índice fora do intervalo. O exemplo de parênteses balanceados acima é o problema que mais aparece com pilha, junto com "próximo maior elemento" e "avaliação de expressão".

## Fila com slice e BFS

Para uma fila, enfileire com `append` e desenfileire com `q = q[1:]`. Isso é O(1), porque só avança o início do slice. O custo é que a memória dos elementos já removidos continua alocada até o slice ser coletado; em entrevista isso não costuma importar.

```go
package main

import "fmt"

func bfs(grafo [][]int, inicio int) []int {
	visitado := make([]bool, len(grafo))
	fila := []int{inicio}
	visitado[inicio] = true
	var ordem []int
	for len(fila) > 0 {
		no := fila[0]
		fila = fila[1:]
		ordem = append(ordem, no)
		for _, viz := range grafo[no] {
			if !visitado[viz] {
				visitado[viz] = true
				fila = append(fila, viz)
			}
		}
	}
	return ordem
}

func main() {
	grafo := [][]int{{1, 2}, {3}, {3}, {}}
	fmt.Println(bfs(grafo, 0))
}
```

```text
Saída:
[0 1 2 3]
```

Marcar o nó como visitado ao enfileirá-lo (e não ao desenfileirar) evita que o mesmo nó entre duas vezes na fila. O resultado `[0 1 2 3]` sai por níveis: primeiro o início, depois seus vizinhos, depois os vizinhos dos vizinhos.

## Quando o slice não basta

Se você precisa inserir ou remover nas duas pontas com frequência, o pacote `container/list` oferece uma lista duplamente ligada com `PushFront`, `PushBack` e `Remove`. Ela é mais lenta na prática por causa dos ponteiros e do `any` nos elementos, então use só quando necessário. Para uma deque simples, uma fila em slice mais um índice de início costuma bastar. Já uma fila de prioridade exige `container/heap`, tema do próximo capítulo.

| Estrutura | Representação | Operação principal |
|---|---|---|
| Conjunto | `map[T]struct{}` | pertencimento O(1) |
| Pilha | `[]T` | `append` e fatiar o fim, O(1) |
| Fila | `[]T` | `append` e `q[1:]`, O(1) |
| Deque | `container/list` | pontas O(1) |

<Callout type="tip" title="Dica de digitação">
Se o tipo for pequeno, `map[int]bool` é mais rápido de escrever e ler que `map[int]struct{}`. Combine com o idioma `if !visto[x] { visto[x] = true }`.
</Callout>

## Na entrevista

Diga que vai usar um slice como pilha ou fila e que isso dá O(1) nas operações. Cite que o conjunto é um mapa e que a ordem de iteração dele é aleatória. Em BFS, marque visitados ao enfileirar.
