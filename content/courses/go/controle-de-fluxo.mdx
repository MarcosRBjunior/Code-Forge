Go tem poucas estruturas de controle: `if`, `switch` e um único laço, o `for`, que faz o papel de `for`, `while` e `foreach`. Menos palavras-chave significam menos escolhas, e isso ajuda na entrevista, porque você digita o mesmo padrão o tempo todo.

## O laço for em todas as formas

O `for` clássico tem inicialização, condição e passo. Sem inicialização nem passo, ele vira um `while`. Sem nada, é um laço infinito que você interrompe com `break` ou `return`. Com `range`, percorre slices, strings, mapas, canais e, desde Go 1.22, também inteiros.

```go
package main

import "fmt"

func main() {
	soma := 0
	for i := 1; i <= 5; i++ {
		soma += i
	}
	fmt.Println(soma)

	n, passos := 10, 0
	for n > 1 {
		if n%2 == 0 {
			n /= 2
		} else {
			n = 3*n + 1
		}
		passos++
	}
	fmt.Println(passos)

	for i, v := range []string{"a", "b"} {
		fmt.Println(i, v)
	}
	for i := range 3 {
		fmt.Println(i)
	}
}
```

```text
Saída:
15
6
0 a
1 b
0
1
2
```

Não há parênteses em volta da condição, e as chaves são obrigatórias, mesmo para uma única instrução. Em `range` sobre um slice você recebe o índice e uma cópia do valor; se só quer o índice, escreva `for i := range s`, e se só quer o valor, use `_` no lugar do índice. Desde Go 1.22 cada iteração tem sua própria variável de laço, o que removeu um velho problema de closures capturando a mesma variável.

## if com inicialização

O `if` aceita uma instrução curta antes da condição, e a variável criada vale apenas dentro do `if` e dos seus `else`. É o idioma padrão para o "comma ok" de mapas e para tratar erros:

```go
package main

import "fmt"

func classifica(n int) string {
	switch {
	case n < 0:
		return "negativo"
	case n == 0:
		return "zero"
	default:
		return "positivo"
	}
}

func main() {
	m := map[string]int{"a": 1}
	if v, ok := m["a"]; ok {
		fmt.Println("achou", v)
	}

	fmt.Println(classifica(-5), classifica(0), classifica(7))

	dia := "sab"
	switch dia {
	case "sab", "dom":
		fmt.Println("fim de semana")
	default:
		fmt.Println("dia útil")
	}

	nums := []int{1, 2, 3, 4}
outer:
	for i := 0; i < len(nums); i++ {
		for j := i + 1; j < len(nums); j++ {
			if nums[i]+nums[j] == 7 {
				fmt.Println("par:", i, j)
				break outer
			}
		}
	}
}
```

```text
Saída:
achou 1
negativo zero positivo
fim de semana
par: 2 3
```

## switch sem pegadinha

O `switch` de Go não cai para o caso seguinte: cada `case` termina sozinho, sem precisar de `break`. Se quiser o comportamento de cair, escreva `fallthrough` explicitamente, o que é raríssimo. Um `case` aceita vários valores separados por vírgula. O `switch` sem expressão, como em `classifica`, é uma cadeia de `if/else` mais legível, e as expressões dos casos podem ser qualquer condição booleana.

Há também o `switch` de tipos, `switch v := x.(type)`, que você verá no capítulo de interfaces.

## break, continue e rótulos

`break` e `continue` valem para o laço mais interno. Para sair de laços aninhados de uma vez, ponha um rótulo na linha do laço externo e use `break outer` ou `continue outer`, como no programa acima. É bem mais limpo que uma variável de controle. Dentro de um `switch` dentro de um `for`, um `break` simples só sai do `switch`, e não do laço, uma armadilha clássica; o rótulo resolve.

<Callout type="warning" title="break dentro de switch">
Em um `for` com `switch` dentro, `break` sai apenas do `switch`. Para encerrar o laço use um rótulo (`break loop`) ou `return`.
</Callout>

## Na entrevista

Prefira `for` com `range` quando percorrer coleções e o `for` clássico quando precisar do índice para dois ponteiros ou janelas. Busque o idioma `if v, ok := m[k]; ok` para mapas. Para varrer pares, use o laço duplo com `j := i + 1`.

Follow-ups comuns: "como sair de dois laços ao mesmo tempo?" (rótulo) e "o `switch` de Go precisa de `break`?" (não; cada caso termina sozinho). Se perguntarem sobre `while`, a resposta é que não existe: é o `for` com apenas a condição.
