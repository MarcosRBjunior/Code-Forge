Em Go, um programa executável é um conjunto de arquivos que declaram o pacote `main` e uma função `main`. Não existe classe obrigatória, não existe `public static void`, e o compilador é bem rígido com o que sobra: import não usado e variável declarada e não usada são erros de compilação, não avisos. Entender esse esqueleto evita perder minutos de entrevista com mensagens de erro bobas.

## O menor programa

Todo arquivo começa com a cláusula `package`. Um programa que roda sozinho precisa do pacote `main`, e a execução começa na função `main`, que não recebe argumentos nem devolve valor.

```go
package main

import "fmt"

func main() {
	fmt.Println("Olá, entrevista!")
	soma := 2 + 3
	fmt.Println("soma =", soma)
	fmt.Printf("pi com 2 casas: %.2f\n", 3.14159)
}
```

```text
Saída:
Olá, entrevista!
soma = 5
pi com 2 casas: 3.14
```

`fmt` é o pacote de formatação da biblioteca padrão. `Println` separa os argumentos por espaço e termina a linha; `Printf` usa verbos de formatação e não adiciona quebra de linha sozinho, então você escreve `\n` no fim. Quem vem de Python pode pensar em `print` e em f-strings; quem vem de JavaScript, em `console.log` e template strings.

## Imports e nomes exportados

Os imports ficam logo depois do `package`. Para vários pacotes, agrupe em parênteses. Se você importar algo e não usar, o programa não compila, o que costuma surpreender quem está acostumado a linguagens mais permissivas.

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	nomes := []string{"ana", "bia"}
	fmt.Println(strings.ToUpper(strings.Join(nomes, ",")))
	fmt.Printf("%d %s %v %q\n", 42, "go", []int{1, 2}, "oi")
	fmt.Printf("%T %T\n", 1, "x")
}
```

```text
Saída:
ANA,BIA
42 go [1 2] "oi"
int string
```

Repare que `strings.ToUpper` começa com maiúscula. Em Go, a visibilidade é decidida pela primeira letra do nome: maiúscula é exportado (visível para outros pacotes), minúscula é privado ao pacote. Não há `public` nem `private`. Em entrevista você quase sempre fica dentro de um único pacote, então isso importa mais para ler a biblioteca padrão do que para escrever.

## Os verbos que você vai usar

Quatro verbos resolvem quase tudo: `%d` para inteiros, `%s` para strings, `%v` para qualquer valor no formato padrão e `%q` para string entre aspas. Dois são ótimos para depurar: `%+v` mostra os nomes dos campos de uma struct e `%T` mostra o tipo. Para decimais, `%.2f` fixa as casas. Quando só quer ver um valor rapidamente, `fmt.Println(x)` imprime slices, mapas e structs de forma legível sem nenhum esforço.

## Compilar e executar

Duas formas de rodar um arquivo `main.go`:

```bash
go run main.go     # compila em memória e executa
go build main.go   # gera o binário ./main
```

O compilador é rápido, e o resultado é um binário estático, sem máquina virtual nem interpretador. Isso diferencia Go de Python e JavaScript: um erro de tipo aparece antes de qualquer saída, porque o programa nem chega a executar.

## Formatação e estilo

Go tem um formatador oficial, o `gofmt`, que decide indentação (com tabs) e posição das chaves. A chave de abertura fica na mesma linha da declaração; colocá-la na linha seguinte é erro de sintaxe, por causa da inserção automática de ponto e vírgula. Você não escreve ponto e vírgula no fim das linhas. Comentários usam `//` para uma linha e `/* ... */` para blocos.

<Callout type="note" title="Declarou, usou">
Variável local não usada e import não usado quebram a compilação. Em entrevista, se você declarou algo para depurar e esqueceu, o erro aponta a linha exata. Para silenciar de propósito, atribua ao identificador em branco: `_ = x`.
</Callout>

## Na entrevista

Em plataformas como o LeetCode, você recebe apenas a função a preencher (o pacote e o `main` já estão prontos). Em um editor em branco ou numa entrevista ao vivo, comece sempre por `package main`, o `import` do que for usar e `func main()`. Digitar esse esqueleto de memória sem hesitar passa uma boa impressão logo no começo.

Perguntas de follow-up comuns: "como o Go decide o que é público?" (primeira letra maiúscula) e "o que acontece se eu importar um pacote e não usar?" (erro de compilação). Outra pergunta frequente é a diferença entre `Println` e `Printf`: o primeiro formata com regras padrão e quebra a linha; o segundo exige a string de formato e não quebra a linha por conta própria.
