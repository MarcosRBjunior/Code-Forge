title: O problema leitores-escritores
kind: lesson
---

Um recurso compartilhado, como uma tabela de configuração, um índice em memória ou um cache, é lido o tempo todo e alterado de vez em quando. Um mutex comum resolve a corretude, mas serializa também as leituras, que poderiam rodar juntas sem risco. O **problema leitores-escritores** pergunta: como permitir muitos leitores simultâneos, garantir que um escritor trabalhe sozinho e, ao mesmo tempo, decidir **quem tem prioridade** quando os dois lados disputam o recurso?

As regras de segurança são fixas:

- Vários leitores podem estar dentro ao mesmo tempo.
- Um escritor exige exclusividade: nenhum outro escritor e nenhum leitor.

O que muda entre as variantes clássicas é a política de justiça, e é aí que mora a pergunta de entrevista.

## As três variantes

```text
tempo ->
R1 [=========lendo=========]
W        chega e espera....
R2            chega
                ├─ prioridade a leitores:   R2 entra já; W espera R1 e R2 (e quem mais vier)
                ├─ prioridade a escritores: R2 espera; W entra assim que R1 sai
                └─ justa (ordem de chegada): W, depois R2
```

**Prioridade a leitores.** Um leitor só espera se houver um escritor *ativo*. É a mais simples e maximiza a vazão de leituras, mas com fluxo contínuo de leitores o escritor pode nunca entrar: **starvation de escritores**.

**Prioridade a escritores.** Um leitor novo espera se houver escritor ativo *ou aguardando*. O dado atualizado aparece rápido, mas uma rajada de escritas pode deixar leitores famintos.

**Justa.** Leitores e escritores passam por uma "catraca" em ordem de chegada. Ninguém passa fome, ao custo de um pouco menos de paralelismo entre leituras.

O programa abaixo implementa as duas primeiras com uma `Condition` e reproduz o cenário do diagrama de forma determinística: o fluxo principal só avança quando o escritor e o segundo leitor já estão na posição esperada.

```python
import threading
import time

class RWLock:
    def __init__(self, prioridade):
        self.prioridade = prioridade
        self.cond = threading.Condition()
        self.leitores = 0
        self.escrevendo = False
        self.escritores_esperando = 0
        self.leitores_esperando = 0

    def adquirir_leitura(self):
        with self.cond:
            self.leitores_esperando += 1
            while self.escrevendo or (self.prioridade == "escritores" and self.escritores_esperando > 0):
                self.cond.wait()
            self.leitores_esperando -= 1
            self.leitores += 1

    def liberar_leitura(self):
        with self.cond:
            self.leitores -= 1
            if self.leitores == 0:
                self.cond.notify_all()

    def adquirir_escrita(self):
        with self.cond:
            self.escritores_esperando += 1
            while self.escrevendo or self.leitores > 0:
                self.cond.wait()
            self.escritores_esperando -= 1
            self.escrevendo = True

    def liberar_escrita(self):
        with self.cond:
            self.escrevendo = False
            self.cond.notify_all()

def esperar_ate(condicao):
    while not condicao():
        time.sleep(0.001)

def cenario(prioridade):
    rw = RWLock(prioridade)
    log = []
    r1_dentro, solta_r1 = threading.Event(), threading.Event()

    def r1():
        rw.adquirir_leitura()
        log.append("R1 le")
        r1_dentro.set()
        solta_r1.wait()
        log.append("R1 sai")
        rw.liberar_leitura()

    def w():
        rw.adquirir_escrita()
        log.append("W escreve")
        rw.liberar_escrita()

    def r2():
        rw.adquirir_leitura()
        log.append("R2 le")
        rw.liberar_leitura()

    ts = [threading.Thread(target=f) for f in (r1, w, r2)]
    ts[0].start(); r1_dentro.wait()
    ts[1].start(); esperar_ate(lambda: rw.escritores_esperando == 1)
    ts[2].start(); esperar_ate(lambda: "R2 le" in log or rw.leitores_esperando == 1)
    solta_r1.set()
    for t in ts:
        t.join()
    print(f"prioridade a {prioridade}: " + " -> ".join(log))
```

```java
import java.util.*;
import java.util.concurrent.CountDownLatch;
import java.util.function.BooleanSupplier;

static class RWLock {
    final String prioridade;
    int leitores = 0;
    boolean escrevendo = false;
    // volatile: o fluxo principal lê estes dois contadores sem pegar o monitor
    volatile int escritoresEsperando = 0;
    volatile int leitoresEsperando = 0;

    RWLock(String prioridade) {
        this.prioridade = prioridade;
    }

    synchronized void adquirirLeitura() throws InterruptedException {
        leitoresEsperando += 1;
        while (escrevendo || (prioridade.equals("escritores") && escritoresEsperando > 0)) {
            wait();
        }
        leitoresEsperando -= 1;
        leitores += 1;
    }

    synchronized void liberarLeitura() {
        leitores -= 1;
        if (leitores == 0) {
            notifyAll();
        }
    }

    synchronized void adquirirEscrita() throws InterruptedException {
        escritoresEsperando += 1;
        while (escrevendo || leitores > 0) {
            wait();
        }
        escritoresEsperando -= 1;
        escrevendo = true;
    }

    synchronized void liberarEscrita() {
        escrevendo = false;
        notifyAll();
    }
}

static void esperarAte(BooleanSupplier condicao) throws InterruptedException {
    while (!condicao.getAsBoolean()) {
        Thread.sleep(1);
    }
}

static void cenario(String prioridade) throws InterruptedException {
    RWLock rw = new RWLock(prioridade);
    List<String> log = Collections.synchronizedList(new ArrayList<>());
    CountDownLatch r1Dentro = new CountDownLatch(1), soltaR1 = new CountDownLatch(1);

    Runnable r1 = () -> {
        try {
            rw.adquirirLeitura();
            log.add("R1 le");
            r1Dentro.countDown();
            soltaR1.await();
            log.add("R1 sai");
            rw.liberarLeitura();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    };

    Runnable w = () -> {
        try {
            rw.adquirirEscrita();
            log.add("W escreve");
            rw.liberarEscrita();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    };

    Runnable r2 = () -> {
        try {
            rw.adquirirLeitura();
            log.add("R2 le");
            rw.liberarLeitura();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    };

    List<Thread> ts = List.of(new Thread(r1), new Thread(w), new Thread(r2));
    ts.get(0).start();
    r1Dentro.await();
    ts.get(1).start();
    esperarAte(() -> rw.escritoresEsperando == 1);
    ts.get(2).start();
    esperarAte(() -> log.contains("R2 le") || rw.leitoresEsperando == 1);
    soltaR1.countDown();
    for (Thread t : ts) t.join();
    System.out.println("prioridade a " + prioridade + ": " + String.join(" -> ", log));
}

public static void main(String[] args) throws InterruptedException {
    cenario("leitores");
    cenario("escritores");
}
```

```cpp
        rw.adquirirEscrita();

        anotar("R2 le");

    soltaR1.count_down();
    for (auto& t : ts) t.join();

    }
```

```csharp
    {
        lock (cond)
        {
            leitoresEsperando += 1;
            while (escrevendo || (prioridade == "escritores" && escritoresEsperando > 0))
                Monitor.Wait(cond);
            leitoresEsperando -= 1;
            leitores += 1;

        {
            leitores -= 1;

        {

            escrevendo = true;
```

## A solução justa com catraca

Na versão justa, todo mundo passa por um mutex de entrada. O leitor atravessa e solta na hora; o escritor **segura a catraca** enquanto espera os leitores ativos saírem, então quem chega depois fica atrás dele.

<CodeTabs>

```python
import threading

class RWJusto:
    def __init__(self):
        self.catraca = threading.Lock()
        self.cond = threading.Condition()
        self.leitores = 0

    def adquirir_leitura(self):
        with self.catraca:          # passa pela catraca e solta
            with self.cond:
                self.leitores += 1

    def liberar_leitura(self):
        with self.cond:
            self.leitores -= 1
            if self.leitores == 0:
                self.cond.notify_all()

    def adquirir_escrita(self):
        self.catraca.acquire()      # bloqueia novos leitores e escritores
        with self.cond:
            while self.leitores > 0:
                self.cond.wait()

    def liberar_escrita(self):
        self.catraca.release()

rw = RWJusto()
dados = {"a": 0, "b": 0}
inconsistentes = [0]
leituras = [0]
contador_lock = threading.Lock()

def escritor():
    for _ in range(200):
        rw.adquirir_escrita()
        dados["a"] += 1
        dados["b"] += 1          # leitor nunca deve ver a != b
        rw.liberar_escrita()

def leitor():
    for _ in range(300):
        rw.adquirir_leitura()
        ok = dados["a"] == dados["b"]
        rw.liberar_leitura()
        with contador_lock:
            leituras[0] += 1
            if not ok:
                inconsistentes[0] += 1

ts = [threading.Thread(target=escritor) for _ in range(3)]
ts += [threading.Thread(target=leitor) for _ in range(5)]
for t in ts:
    t.start()
for t in ts:
    t.join()

print("a =", dados["a"], "b =", dados["b"])
print("leituras:", leituras[0], "inconsistentes:", inconsistentes[0])
```

```java
import java.util.*;
import java.util.concurrent.locks.ReentrantLock;

static class RWJusto {
    // ReentrantLock e não synchronized: o escritor pega a catraca num método e solta em outro
    final ReentrantLock catraca = new ReentrantLock();
    final Object cond = new Object();
    int leitores = 0;

    void adquirirLeitura() {
        catraca.lock();             // passa pela catraca e solta
        try {
            synchronized (cond) {
                leitores += 1;
            }
        } finally {
            catraca.unlock();
        }
    }

    void liberarLeitura() {
        synchronized (cond) {
            leitores -= 1;
            if (leitores == 0) {
                cond.notifyAll();
            }
        }
    }

    void adquirirEscrita() throws InterruptedException {
        catraca.lock();             // bloqueia novos leitores e escritores
        synchronized (cond) {
            while (leitores > 0) {
                cond.wait();
            }
        }
    }

    void liberarEscrita() {
        catraca.unlock();
    }
}

static final RWJusto rw = new RWJusto();
static final Map<String, Integer> dados = new HashMap<>(Map.of("a", 0, "b", 0));
static int inconsistentes = 0;
static int leituras = 0;
static final Object contadorLock = new Object();

static void escritor() {
    try {
        for (int i = 0; i < 200; i++) {
            rw.adquirirEscrita();
            dados.put("a", dados.get("a") + 1);
            dados.put("b", dados.get("b") + 1);   // leitor nunca deve ver a != b
            rw.liberarEscrita();
        }
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    }
}

static void leitor() {
    for (int i = 0; i < 300; i++) {
        rw.adquirirLeitura();
        boolean ok = dados.get("a").equals(dados.get("b"));
        rw.liberarLeitura();
        synchronized (contadorLock) {
            leituras += 1;
            if (!ok) {
                inconsistentes += 1;
            }
        }
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> ts = new ArrayList<>();
    for (int i = 0; i < 3; i++) ts.add(new Thread(() -> escritor()));
    for (int i = 0; i < 5; i++) ts.add(new Thread(() -> leitor()));
    for (Thread t : ts) t.start();
    for (Thread t : ts) t.join();

    System.out.println("a = " + dados.get("a") + " b = " + dados.get("b"));
    System.out.println("leituras: " + leituras + " inconsistentes: " + inconsistentes);
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Threading;

class RWJusto
{
    // Monitor.Enter e Exit, e não lock: o escritor pega a catraca num método e solta em outro
    private readonly object catraca = new object();
    private readonly object cond = new object();
    private int leitores = 0;

    public void AdquirirLeitura()
    {
        lock (catraca)              // passa pela catraca e solta
        {
            lock (cond)
            {
                leitores += 1;
            }
        }
    }

    public void LiberarLeitura()
    {
        lock (cond)
        {
            leitores -= 1;
            if (leitores == 0)
                Monitor.PulseAll(cond);
        }
    }

    public void AdquirirEscrita()
    {
        Monitor.Enter(catraca);     // bloqueia novos leitores e escritores
        lock (cond)
        {
            while (leitores > 0)
                Monitor.Wait(cond);
        }
    }

    public void LiberarEscrita()
    {
        Monitor.Exit(catraca);
    }
}
```

```go
import (
	"fmt"
	"sync"
)

type RWJusto struct {
	catraca  sync.Mutex
	mu       sync.Mutex
	cond     *sync.Cond
	leitores int
}

func NovoRWJusto() *RWJusto {
	rw := &RWJusto{}
	rw.cond = sync.NewCond(&rw.mu)
	return rw
}

func (rw *RWJusto) adquirirLeitura() {
	rw.catraca.Lock() // passa pela catraca e solta
	rw.mu.Lock()
	rw.leitores += 1
	rw.mu.Unlock()
	rw.catraca.Unlock()
}

func (rw *RWJusto) liberarLeitura() {
	rw.mu.Lock()
	rw.leitores -= 1
	if rw.leitores == 0 {
		rw.cond.Broadcast()
	}
	rw.mu.Unlock()
}

func (rw *RWJusto) adquirirEscrita() {
	rw.catraca.Lock() // bloqueia novos leitores e escritores
	rw.mu.Lock()
	for rw.leitores > 0 {
		rw.cond.Wait()
	}
	rw.mu.Unlock()
}

func (rw *RWJusto) liberarEscrita() {
	rw.catraca.Unlock()
}

var rw = NovoRWJusto()
var dados = map[string]int{"a": 0, "b": 0}
var inconsistentes = 0
var leituras = 0
var contadorLock sync.Mutex

func escritor(wg *sync.WaitGroup) {
	defer wg.Done()
	for i := 0; i < 200; i++ {
		rw.adquirirEscrita()
		dados["a"] += 1
		dados["b"] += 1 // leitor nunca deve ver a != b
		rw.liberarEscrita()
	}
}

func leitor(wg *sync.WaitGroup) {
	defer wg.Done()
	for i := 0; i < 300; i++ {
		rw.adquirirLeitura()
		ok := dados["a"] == dados["b"]
		rw.liberarLeitura()
		contadorLock.Lock()
		leituras += 1
		if !ok {
			inconsistentes += 1
		}
		contadorLock.Unlock()
	}
}

func main() {
	var wg sync.WaitGroup
	for i := 0; i < 3; i++ {
		wg.Add(1)
		go escritor(&wg)
	}
	for i := 0; i < 5; i++ {
		wg.Add(1)
		go leitor(&wg)
	}
	wg.Wait()

	fmt.Println("a =", dados["a"], "b =", dados["b"])
	fmt.Println("leituras:", leituras, "inconsistentes:", inconsistentes)
}
```

## Trade-offs

| Variante | Vantagem | Risco |
| --- | --- | --- |
| Prioridade a leitores | Máximo paralelismo de leitura | Escritor pode nunca entrar |
| Prioridade a escritores | Dados novos visíveis rápido | Leitores famintos sob muitas escritas |
| Justa (catraca/FIFO) | Sem starvation | Leituras concorrentes interrompidas por cada escritor |

Na vida real, `ReentrantReadWriteLock` em Java tem modo justo opcional, `sync.RWMutex` em Go bloqueia novos leitores quando há escritor esperando (evita fome de escritores) e `std::shared_mutex` em C++ deixa a política para a implementação. Se as seções críticas são curtas, um mutex simples costuma ganhar, porque o RW lock tem mais contabilidade interna.

<Callout type="warning" title="Upgrade de leitura para escrita">
Um leitor que tenta virar escritor sem soltar a leitura espera que os leitores saiam, inclusive ele mesmo: deadlock. Se dois fazem isso juntos, nenhum sai. Solte a leitura, adquira a escrita e revalide o estado.
</Callout>
