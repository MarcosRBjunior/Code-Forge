"Projete um agendador que executa tarefas depois de um atraso" aparece em entrevistas de backend com nomes variados: timer service, `ScheduledExecutorService`, fila de jobs com retry. O enunciado parece simples (guarde a tarefa e rode depois), mas a solução boa exige três ideias juntas: uma estrutura ordenada por prazo, uma thread que **dorme exatamente até o próximo prazo** e uma forma de acordá-la quando chega uma tarefa mais urgente.

## A estrutura: heap por prazo

Guarde cada tarefa como `(prazo, sequência, função)` num min-heap. O topo é sempre a próxima a vencer, a inserção custa O(log n) e consultar o próximo prazo custa O(1). A `sequência` serve de desempate: duas tarefas com o mesmo prazo saem na ordem em que chegaram, e o Python nunca precisa comparar funções.

```text
agendar(B, +300ms)  agendar(A, +100ms)  agendar(C, +200ms)

heap:        (100, A)
            /        \
      (300, B)     (200, C)

o trabalhador dorme até 100ms, roda A, depois dorme até 200ms...
```

Antes de pensar em threads, vale separar a lógica do relógio. Com um relógio falso, você testa a ordem de execução sem esperar nada de verdade:

```python
import heapq
import itertools

class AgendadorSimulado:
    def __init__(self):
        self.agora = 0
        self.heap = []
        self.seq = itertools.count()

    def agendar(self, atraso, nome):
        heapq.heappush(self.heap, (self.agora + atraso, next(self.seq), nome))

    def avancar_ate(self, instante):
        executadas = []
        while self.heap and self.heap[0][0] <= instante:
            prazo, _, nome = heapq.heappop(self.heap)
            self.agora = prazo
            executadas.append(f"t={prazo} {nome}")
        self.agora = instante
        return executadas

ag.agendar(300, "enviar relatorio")
ag.agendar(100, "limpar sessoes")
ag.agendar(200, "renovar token")
ag.agendar(100, "aquecer cache")
for linha in ag.avancar_ate(250):
    print(linha)
```

```javascript
function vemAntes(a, b) {
  return a[0] !== b[0] ? a[0] < b[0] : a[1] < b[1];
}

function heappush(heap, item) {
  heap.push(item);
  let i = heap.length - 1;
  while (i > 0) {
    const pai = (i - 1) >> 1;
    if (!vemAntes(heap[i], heap[pai])) break;
    [heap[i], heap[pai]] = [heap[pai], heap[i]];
    i = pai;
  }
}

function heappop(heap) {
  const topo = heap[0];
  const ultimo = heap.pop();
  if (heap.length > 0) {
    heap[0] = ultimo;
    let i = 0;
    while (true) {
      const esq = 2 * i + 1;
      const dir = 2 * i + 2;
      let menor = i;
      if (esq < heap.length && vemAntes(heap[esq], heap[menor])) menor = esq;
      if (dir < heap.length && vemAntes(heap[dir], heap[menor])) menor = dir;
      if (menor === i) break;
      [heap[i], heap[menor]] = [heap[menor], heap[i]];
      i = menor;
    }
  }
  return topo;
}
```

```csharp
using System;
using System.Collections.Generic;

class Item
{
    public int Prazo;
    public int Seq;
    public string Nome;
}

class AgendadorSimulado
{
    public int Agora = 0;
    // o Mono não tem PriorityQueue: min-heap binário à mão, ordenado por (prazo, seq)
    public readonly List<Item> Heap = new List<Item>();
    int seq = 0;

    static bool VemAntes(Item a, Item b)
    {
        return a.Prazo != b.Prazo ? a.Prazo < b.Prazo : a.Seq < b.Seq;
    }

    void Empilhar(Item item)
    {
        Heap.Add(item);
        int i = Heap.Count - 1;
        while (i > 0)
        {
            int pai = (i - 1) / 2;
            if (!VemAntes(Heap[i], Heap[pai])) break;
            Item troca = Heap[i];
            Heap[i] = Heap[pai];
            Heap[pai] = troca;
            i = pai;
        }
    }

    Item Retirar()
    {
        Item topo = Heap[0];
        Heap[0] = Heap[Heap.Count - 1];
        Heap.RemoveAt(Heap.Count - 1);
        int i = 0;
        while (true)
        {
            int esq = 2 * i + 1, dir = 2 * i + 2, menor = i;
            if (esq < Heap.Count && VemAntes(Heap[esq], Heap[menor])) menor = esq;
            if (dir < Heap.Count && VemAntes(Heap[dir], Heap[menor])) menor = dir;
            if (menor == i) break;
            Item troca = Heap[i];
            Heap[i] = Heap[menor];
            Heap[menor] = troca;
            i = menor;
        }
        return topo;
    }

    public void Agendar(int atraso, string nome)
    {
        Empilhar(new Item { Prazo = Agora + atraso, Seq = seq++, Nome = nome });
    }

    public List<string> AvancarAte(int instante)
    {
        var executadas = new List<string>();
        while (Heap.Count > 0 && Heap[0].Prazo <= instante)
        {
            Item item = Retirar();
            Agora = item.Prazo;
            executadas.Add("t=" + item.Prazo + " " + item.Nome);
        }
        Agora = instante;
        return executadas;
    }
}

static void Main()
{
    AgendadorSimulado ag = new AgendadorSimulado();
    ag.Agendar(300, "enviar relatorio");
    ag.Agendar(100, "limpar sessoes");
    ag.Agendar(200, "renovar token");
    ag.Agendar(100, "aquecer cache");
    foreach (string linha in ag.AvancarAte(250))
    {
        Console.WriteLine(linha);
    }
    Console.WriteLine("pendentes: " + ag.Heap.Count);
}
```

```go
type Item struct {

// container/heap pede estes cinco métodos para ordenar por (prazo, seq)
type Heap []Item

func (h Heap) Len() int { return len(h) }
func (h Heap) Less(i, j int) bool {
	if h[i].prazo != h[j].prazo {
		return h[i].prazo < h[j].prazo
	}
	return h[i].seq < h[j].seq
}
func (h Heap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *Heap) Push(x interface{}) { *h = append(*h, x.(Item)) }
func (h *Heap) Pop() interface{} {
	antigo := *h
	item := antigo[len(antigo)-1]
	*h = antigo[:len(antigo)-1]
	return item
}
```

## O trabalhador: esperar com timeout numa condição

A versão real tem uma thread trabalhadora. O erro mais comum é fazê-la acordar a cada 10 ms para conferir o heap (espera ativa disfarçada): gasta CPU e ainda erra o horário por até 10 ms. O certo é usar uma **variável de condição** e esperar com timeout igual ao tempo que falta para o topo:

- heap vazio: `wait()` sem limite;
- topo no futuro: `wait(prazo - agora)`;
- topo vencido: retira e executa **fora do lock**.

Quando `agendar` insere uma tarefa, ele chama `notify()`. Se a nova tarefa for mais urgente que o topo antigo, o trabalhador acorda, recalcula e dorme menos. O laço sempre reavalia o estado após acordar, então despertares espúrios ou timeouts não causam erro.

```python
import heapq
import itertools
import threading
import time

class Agendador:
    def __init__(self):
        self.heap = []
        self.seq = itertools.count()
        self.cond = threading.Condition()
        self.cancelados = set()
        self.ativo = True
        self.trabalhador = threading.Thread(target=self._laco)
        self.trabalhador.start()

    def agendar(self, atraso, func):
        with self.cond:
            ident = next(self.seq)
            heapq.heappush(self.heap, (time.monotonic() + atraso, ident, func))
            self.cond.notify()
            return ident

    def cancelar(self, ident):
        with self.cond:
            self.cancelados.add(ident)

    def _laco(self):
        while True:
            with self.cond:
                while self.ativo and (not self.heap or self.heap[0][0] > time.monotonic()):
                    falta = self.heap[0][0] - time.monotonic() if self.heap else None
                    self.cond.wait(falta)
                if not self.ativo:
                    return
                _, ident, func = heapq.heappop(self.heap)
                if ident in self.cancelados:
                    continue
            func()  # fora do lock: tarefa lenta não bloqueia novos agendamentos

    def encerrar(self):
        with self.cond:
            self.ativo = False
            self.cond.notify()
        self.trabalhador.join()

log = []
ag = Agendador()
ag.agendar(0.30, lambda: log.append("C"))

ag.agendar(0.20, lambda: log.append("B"))
```

```java
import java.util.*;
import java.util.concurrent.locks.*;

class Tarefa {
    final long prazo;
    final long ident;
    final Runnable func;

    Tarefa(long prazo, long ident, Runnable func) {
        this.prazo = prazo;
        this.ident = ident;
        this.func = func;
    }
}

class Agendador {
    private final PriorityQueue<Tarefa> heap = new PriorityQueue<>(
        Comparator.<Tarefa>comparingLong(t -> t.prazo).thenComparingLong(t -> t.ident));
    private long seq = 0;
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition cond = lock.newCondition();
    private final Set<Long> cancelados = new HashSet<>();
    private boolean ativo = true;
    private final Thread trabalhador = new Thread(this::laco);

    Agendador() {
        trabalhador.start();
    }

    // System.nanoTime é monotônico: o equivalente de time.monotonic
    long agendar(long atrasoMs, Runnable func) {
        lock.lock();
        try {
            long ident = seq++;
            heap.add(new Tarefa(System.nanoTime() + atrasoMs * 1_000_000L, ident, func));
            cond.signal();
            return ident;
        } finally {
            lock.unlock();
        }
    }

    void cancelar(long ident) {
        lock.lock();
        try {
            cancelados.add(ident);
        } finally {
            lock.unlock();
        }
    }

    // devolve a próxima tarefa vencida ou null quando o agendador foi encerrado
    private Tarefa proxima() throws InterruptedException {
        lock.lock();
        try {
            while (true) {
                while (ativo && (heap.isEmpty() || heap.peek().prazo > System.nanoTime())) {
                    if (heap.isEmpty()) {
                        cond.await();
                    } else {
                        cond.awaitNanos(heap.peek().prazo - System.nanoTime());
                    }
                }
                if (!ativo) return null;
                Tarefa t = heap.poll();
                if (!cancelados.contains(t.ident)) return t;
            }
        } finally {
            lock.unlock();
        }
    }

    private void laco() {
        try {
            for (Tarefa t = proxima(); t != null; t = proxima()) {
                t.func.run();  // fora do lock: tarefa lenta não bloqueia novos agendamentos
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }

    void encerrar() throws InterruptedException {
        lock.lock();
        try {
            ativo = false;
            cond.signal();
        } finally {
            lock.unlock();
        }
        trabalhador.join();
    }
}

public static void main(String[] args) throws InterruptedException {
    List<String> log = new ArrayList<>();
    Agendador ag = new Agendador();
    ag.agendar(300, () -> log.add("C"));
    ag.agendar(100, () -> log.add("A"));
    long idX = ag.agendar(150, () -> log.add("X"));
    ag.agendar(200, () -> log.add("B"));
    ag.cancelar(idX);
    Thread.sleep(450);
    ag.encerrar();
    System.out.println("ordem de execucao: " + log);
}
```

```cpp
#include <chrono>
#include <condition_variable>
#include <functional>
#include <iostream>
#include <mutex>
#include <queue>
#include <string>
#include <thread>
#include <tuple>
#include <unordered_set>
#include <vector>
using namespace std;

using Relogio = chrono::steady_clock;   // monotônico: o equivalente de time.monotonic

struct Tarefa {
    Relogio::time_point prazo;
    long ident;
    function<void()> func;

    bool operator>(const Tarefa& outra) const {
        return tie(prazo, ident) > tie(outra.prazo, outra.ident);
    }
};

class Agendador {
    priority_queue<Tarefa, vector<Tarefa>, greater<Tarefa>> heap;
    long seq = 0;
    mutex trava;
    condition_variable cond;
    unordered_set<long> cancelados;
    bool ativo = true;
    thread trabalhador;

    void laco() {
        while (true) {
            function<void()> func;
            {
                unique_lock<mutex> guarda(trava);
                while (ativo && (heap.empty() || heap.top().prazo > Relogio::now())) {
                    if (heap.empty()) {
                        cond.wait(guarda);
                    } else {
                        cond.wait_until(guarda, heap.top().prazo);
                    }
                }
                if (!ativo) return;
                Tarefa t = heap.top();
                heap.pop();
                if (cancelados.count(t.ident)) continue;
                func = t.func;
            }
            func();  // fora do lock: tarefa lenta não bloqueia novos agendamentos
        }
    }

public:
    Agendador() : trabalhador([this] { laco(); }) {}

    long agendar(chrono::milliseconds atraso, function<void()> func) {
        lock_guard<mutex> guarda(trava);
        long ident = seq++;
        heap.push(Tarefa{Relogio::now() + atraso, ident, func});
        cond.notify_one();
        return ident;
    }

    void cancelar(long ident) {
        lock_guard<mutex> guarda(trava);
        cancelados.insert(ident);
    }

    void encerrar() {
        {
            lock_guard<mutex> guarda(trava);
            ativo = false;
            cond.notify_one();
        }
        trabalhador.join();
    }
};

int main() {
    vector<string> log_execucao;
    Agendador ag;
    ag.agendar(chrono::milliseconds(300), [&] { log_execucao.push_back("C"); });
    ag.agendar(chrono::milliseconds(100), [&] { log_execucao.push_back("A"); });
    long id_x = ag.agendar(chrono::milliseconds(150), [&] { log_execucao.push_back("X"); });
    ag.agendar(chrono::milliseconds(200), [&] { log_execucao.push_back("B"); });
    ag.cancelar(id_x);
    this_thread::sleep_for(chrono::milliseconds(450));
    ag.encerrar();
    cout << "ordem de execucao: [";
    for (size_t i = 0; i < log_execucao.size(); i++) cout << (i ? ", " : "") << log_execucao[i];
    cout << "]" << endl;
}
```

```csharp
    readonly Stopwatch relogio = Stopwatch.StartNew();   // monotônico: o equivalente de time.monotonic

    public Agendador()
    {
        trabalhador = new Thread(Laco);
        trabalhador.Start();
    }

    static bool VemAntes(Tarefa a, Tarefa b)
    {
        return a.Prazo != b.Prazo ? a.Prazo < b.Prazo : a.Ident < b.Ident;
    }

    void Empilhar(Tarefa t)
    {
        heap.Add(t);
        int i = heap.Count - 1;
        while (i > 0)
        {
            int pai = (i - 1) / 2;
            if (!VemAntes(heap[i], heap[pai])) break;
            Tarefa troca = heap[i];
            heap[i] = heap[pai];
            heap[pai] = troca;
            i = pai;
        }
    }

    Tarefa Retirar()
    {
        Tarefa topo = heap[0];
        heap[0] = heap[heap.Count - 1];
        heap.RemoveAt(heap.Count - 1);
        int i = 0;
        while (true)
        {
            int esq = 2 * i + 1, dir = 2 * i + 2, menor = i;
            if (esq < heap.Count && VemAntes(heap[esq], heap[menor])) menor = esq;
            if (dir < heap.Count && VemAntes(heap[dir], heap[menor])) menor = dir;
            if (menor == i) break;
            Tarefa troca = heap[i];
            heap[i] = heap[menor];
            heap[menor] = troca;
            i = menor;
        }
        return topo;
    }

    public long Agendar(double atraso, Action func)
    {
        lock (cond)
        {
            long ident = seq++;
            Empilhar(new Tarefa { Prazo = relogio.Elapsed.TotalSeconds + atraso, Ident = ident, Func = func });
            Monitor.Pulse(cond);
            return ident;
        }
    }

    public void Cancelar(long ident)
    {
        lock (cond)
        {
            cancelados.Add(ident);
        }
    }

    void Laco()
    {
        while (true)
        {
            Action func;
            lock (cond)
            {
                while (ativo && (heap.Count == 0 || heap[0].Prazo > relogio.Elapsed.TotalSeconds))
                {
                    if (heap.Count == 0)
                    {
                        Monitor.Wait(cond);
                    }
                    else
                    {
                        double falta = heap[0].Prazo - relogio.Elapsed.TotalSeconds;
                        Monitor.Wait(cond, (int)Math.Ceiling(Math.Max(falta, 0) * 1000));
                    }
                }
                if (!ativo) return;
                Tarefa t = Retirar();
                if (cancelados.Contains(t.Ident)) continue;
                func = t.Func;
            }
            func();  // fora do lock: tarefa lenta não bloqueia novos agendamentos
        }
    }

    public void Encerrar()
    {
        lock (cond)
        {
            ativo = false;
            Monitor.Pulse(cond);
        }
        trabalhador.Join();
    }
}

static void Main()
{
    var log = new List<string>();
    Agendador ag = new Agendador();
    ag.Agendar(0.30, () => log.Add("C"));
    ag.Agendar(0.10, () => log.Add("A"));
    long idX = ag.Agendar(0.15, () => log.Add("X"));
    ag.Agendar(0.20, () => log.Add("B"));
    ag.Cancelar(idX);
    Thread.Sleep(450);
    ag.Encerrar();
    Console.WriteLine("ordem de execucao: [" + string.Join(", ", log) + "]");
}
```

```go
import (
	"container/heap"
	"fmt"
	"sync"
	"time"
)

type Tarefa struct {
	prazo  time.Time // time.Now() carrega uma leitura monotônica: o equivalente de time.monotonic
	ident  int
	funcao func()
}

type Heap []Tarefa

func (h Heap) Len() int { return len(h) }
func (h Heap) Less(i, j int) bool {
	if !h[i].prazo.Equal(h[j].prazo) {
		return h[i].prazo.Before(h[j].prazo)
	}
	return h[i].ident < h[j].ident
}
func (h Heap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *Heap) Push(x interface{}) { *h = append(*h, x.(Tarefa)) }
func (h *Heap) Pop() interface{} {
	antigo := *h
	item := antigo[len(antigo)-1]
	*h = antigo[:len(antigo)-1]
	return item
}

// sync.Cond não tem wait com timeout: o idioma de Go é select entre um timer e um canal de aviso
type Agendador struct {
	fila       Heap
	seq        int
	mu         sync.Mutex
	acordar    chan struct{}
	cancelados map[int]bool
	ativo      bool
	terminou   chan struct{}
}

func novoAgendador() *Agendador {
	a := &Agendador{acordar: make(chan struct{}, 1), cancelados: map[int]bool{}, ativo: true, terminou: make(chan struct{})}
	go a.laco()
	return a
}

// faz o papel do notify: o buffer de 1 guarda o aviso se o trabalhador ainda não estiver no select
func (a *Agendador) notificar() {
	select {
	case a.acordar <- struct{}{}:
	default:
	}
}

func (a *Agendador) agendar(atraso time.Duration, funcao func()) int {
	a.mu.Lock()
	defer a.mu.Unlock()
	ident := a.seq
	a.seq += 1
	heap.Push(&a.fila, Tarefa{time.Now().Add(atraso), ident, funcao})
	a.notificar()
	return ident
}

func (a *Agendador) cancelar(ident int) {
	a.mu.Lock()
	defer a.mu.Unlock()
	a.cancelados[ident] = true
}

func (a *Agendador) laco() {
	defer close(a.terminou)
	for {
		a.mu.Lock()
		for a.ativo && (len(a.fila) == 0 || a.fila[0].prazo.After(time.Now())) {
			var espera <-chan time.Time // canal nil: sem prazo, esse caso do select nunca dispara
			if len(a.fila) > 0 {
				espera = time.After(time.Until(a.fila[0].prazo))
			}
			a.mu.Unlock()
			select {
			case <-espera:
			case <-a.acordar:
			}
			a.mu.Lock()
		}
		if !a.ativo {
			a.mu.Unlock()
			return
		}
		t := heap.Pop(&a.fila).(Tarefa)
		cancelada := a.cancelados[t.ident]
		a.mu.Unlock()
		if !cancelada {
			t.funcao() // fora do lock: tarefa lenta não bloqueia novos agendamentos
		}
	}
}

func (a *Agendador) encerrar() {
	a.mu.Lock()
	a.ativo = false
	a.notificar()
	a.mu.Unlock()
	<-a.terminou
}

func main() {
	log := []string{}
	ag := novoAgendador()
	ag.agendar(300*time.Millisecond, func() { log = append(log, "C") })
	ag.agendar(100*time.Millisecond, func() { log = append(log, "A") })
	idX := ag.agendar(150*time.Millisecond, func() { log = append(log, "X") })
	ag.agendar(200*time.Millisecond, func() { log = append(log, "B") })
	ag.cancelar(idX)
	time.Sleep(450 * time.Millisecond)
	ag.encerrar()
	fmt.Println("ordem de execucao:", log)
}
```

Três detalhes fazem diferença. O relógio é `time.monotonic()`, que não anda para trás se alguém ajustar o horário do sistema. O cancelamento é preguiçoso: marcar o id é O(1) e a tarefa é descartada quando chega ao topo. E a função roda fora do lock; se rodasse dentro, uma tarefa lenta impediria qualquer `agendar` nesse meio-tempo.

<Callout type="tip" title="Equivalentes em outras linguagens">
Java oferece `ScheduledThreadPoolExecutor`, que usa internamente uma fila de atraso com heap e `Condition.awaitNanos`. Em Go, o idioma é `time.Timer` com `select`; em C++, `std::condition_variable::wait_until` com uma `std::priority_queue`.
</Callout>

## Trade-offs e extensões

| Questão | Opção simples | Opção robusta |
| --- | --- | --- |
| Tarefa lenta atrasa as outras | Um só trabalhador | Trabalhador só despacha para um thread pool |
| Tarefas periódicas | Reagendar ao terminar | Calcular o próximo prazo a partir do prazo anterior, para não acumular atraso |
| Milhões de timers | Heap | Timing wheel: baldes por intervalo, inserção O(1) |
| Sobreviver a reinício | Memória | Persistir em banco e recuperar pendências |
| Muitas máquinas | Agendador local | Lease por tarefa para que só um nó a execute |

Uma exceção dentro de `func()` mataria a thread trabalhadora e, com ela, o agendador inteiro. Em produção, envolva a chamada em `try/except` e registre o erro.

## Na entrevista
