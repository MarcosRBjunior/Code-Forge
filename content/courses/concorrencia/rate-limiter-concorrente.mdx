"Implemente um rate limiter que permita no máximo N requisições por segundo e que funcione com várias threads chamando ao mesmo tempo" é uma pergunta que mistura algoritmo e concorrência. A parte algorítmica (token bucket, janela deslizante) você talvez já conheça de system design. Aqui o foco é o que muda quando dezenas de threads chamam `permitir()` simultaneamente: sem cuidado, duas threads leem "resta 1 token", ambas o consomem e o limite é furado.

## Escolhendo o algoritmo

| Algoritmo | Estado | Rajadas | Precisão |
| --- | --- | --- | --- |
| Janela fixa | contador + início da janela | permite 2N na virada da janela | baixa |
| Janela deslizante (log) | timestamps recentes | não | exata, memória O(N) |
| Token bucket | tokens + último reabastecimento | sim, até a capacidade | boa, memória O(1) |

O **token bucket** é a escolha mais comum: um balde com capacidade `C` se enche a uma taxa `r` tokens por segundo; cada requisição consome um token e é recusada se o balde estiver vazio. Ele permite rajadas curtas até `C` e mantém a média em `r`.

```text
 reabastece r/s ──►  ┌───────┐
                     │ ● ● ● │  capacidade C
                     └───┬───┘
 requisição ─► pega 1 token? ─ sim ─► permitida
                         └─ não ─► recusada (ou espera)
```

## A seção crítica

O reabastecimento preguiçoso (calcular quantos tokens entraram desde a última chamada) e o consumo precisam acontecer **juntos**, sob o mesmo lock. Separar as duas coisas reabre a condição de corrida:

```python
# ERRADO: ler e decrementar fora do lock
if self.tokens >= 1:        # duas threads veem 1 token
    with self.lock:
        self.tokens -= 1    # as duas decrementam: tokens = -1
```

Para os testes serem determinísticos, a implementação recebe um **relógio injetável**. Em produção você passaria `time.monotonic` (nunca `time.time`, que pode voltar no tempo com ajustes de NTP); no teste, um relógio falso que você avança à mão.

import threading

class RelogioFalso:
    def __init__(self):
        self.agora = 0.0
    def __call__(self):
        return self.agora
    def avancar(self, s):
        self.agora += s

class TokenBucket:
    def __init__(self, capacidade, taxa, relogio):
        self.capacidade = capacidade
        self.taxa = taxa                 # tokens por segundo
        self.relogio = relogio
        self.tokens = float(capacidade)
        self.ultimo = relogio()
        self.lock = threading.Lock()

    def permitir(self):
        with self.lock:                  # reabastecer e consumir juntos
            agora = self.relogio()
            self.tokens = min(self.capacidade, self.tokens + (agora - self.ultimo) * self.taxa)
            self.ultimo = agora
            if self.tokens >= 1:
                self.tokens -= 1
                return True
            return False

import java.util.*;
import java.util.function.*;

class RelogioFalso implements DoubleSupplier {
    double agora = 0.0;

    public double getAsDouble() {
        return agora;
    }

    void avancar(double s) {
        agora += s;
    }
}

class TokenBucket {
    private final int capacidade;
    private final double taxa;                 // tokens por segundo
    private final DoubleSupplier relogio;
    private double tokens;
    private double ultimo;
    private final Object lock = new Object();

    TokenBucket(int capacidade, double taxa, DoubleSupplier relogio) {
        this.capacidade = capacidade;
        this.taxa = taxa;
        this.relogio = relogio;
        this.tokens = capacidade;
        this.ultimo = relogio.getAsDouble();
    }

    boolean permitir() {
        synchronized (lock) {                  // reabastecer e consumir juntos
            double agora = relogio.getAsDouble();
            tokens = Math.min(capacidade, tokens + (agora - ultimo) * taxa);
            ultimo = agora;
            if (tokens >= 1) {
                tokens -= 1;
                return true;
            }
            return false;
        }
    }
}

static String pedir(TokenBucket balde, int n) {
    List<String> saida = new ArrayList<>();
    for (int i = 0; i < n; i++) saida.add(balde.permitir() ? "True" : "False");
    return saida.toString();
}

public static void main(String[] args) throws InterruptedException {
    RelogioFalso relogio = new RelogioFalso();
    TokenBucket balde = new TokenBucket(3, 2, relogio);

    System.out.println("rajada: " + pedir(balde, 5));
    relogio.avancar(0.5);                      // entra 1 token
    System.out.println("apos 0,5 s: " + pedir(balde, 2));
    relogio.avancar(10);                       // enche, mas limita à capacidade
    System.out.println("apos 10 s: " + pedir(balde, 4));

    // 50 threads disputando o mesmo instante: só a capacidade passa
    relogio.avancar(10);
    List<Boolean> resultados = new ArrayList<>();
    Object guarda = new Object();

    Runnable cliente = () -> {
        boolean ok = balde.permitir();
        synchronized (guarda) {
            resultados.add(ok);
        }
    };

    List<Thread> threads = new ArrayList<>();
    for (int i = 0; i < 50; i++) threads.add(new Thread(cliente));
    for (Thread t : threads) t.start();
    for (Thread t : threads) t.join();
    System.out.println("concorrentes permitidas: " + Collections.frequency(resultados, true) + " de " + resultados.size());
}

## Limite por cliente

Em geral o limite é por usuário ou por chave de API. Agora há dois níveis de concorrência: o mapa de clientes e o estado de cada cliente. Um lock global para tudo funciona, mas serializa clientes independentes. A versão abaixo usa um lock curto só para criar o limitador de cada cliente (evitando o check-then-act) e um lock por cliente para a janela deslizante.

<CodeTabs>

```python
import threading
from collections import deque

class RelogioFalso:
    def __init__(self):
        self.agora = 0.0
    def __call__(self):
        return self.agora

class JanelaDeslizante:
    def __init__(self, limite, janela, relogio):
        self.limite, self.janela, self.relogio = limite, janela, relogio
        self.eventos = deque()
        self.lock = threading.Lock()

    def permitir(self):
        with self.lock:
            agora = self.relogio()
            while self.eventos and self.eventos[0] <= agora - self.janela:
                self.eventos.popleft()           # descarta o que saiu da janela
            if len(self.eventos) < self.limite:
                self.eventos.append(agora)
                return True
            return False

class LimitadorPorCliente:
    def __init__(self, limite, janela, relogio):
        self.args = (limite, janela, relogio)
        self.clientes = {}
        self.lock_mapa = threading.Lock()

    def permitir(self, cliente):
        with self.lock_mapa:                     # só para obter/criar
            lim = self.clientes.get(cliente)
            if lim is None:
                lim = self.clientes[cliente] = JanelaDeslizante(*self.args)
        return lim.permitir()                    # fora do lock global

relogio = RelogioFalso()
limitador = LimitadorPorCliente(limite=4, janela=1.0, relogio=relogio)
contagem = {}
guarda = threading.Lock()

def rajada(cliente, n):
    aceitas = sum(limitador.permitir(cliente) for _ in range(n))
    with guarda:
        contagem[cliente] = contagem.get(cliente, 0) + aceitas

threads = [threading.Thread(target=rajada, args=(c, 5)) for c in ("ana", "bia", "caio") for _ in range(3)]
for t in threads:
    t.start()
for t in threads:
    t.join()
print("t=0,0:", sorted(contagem.items()))

relogio.agora = 1.0                              # a janela anterior expirou
print("ana em t=1,0:", [limitador.permitir("ana") for _ in range(5)])
```

import java.util.*;
import java.util.function.*;

class RelogioFalso implements DoubleSupplier {
    double agora = 0.0;

    public double getAsDouble() {
        return agora;
    }
}

class JanelaDeslizante {
    private final int limite;
    private final double janela;
    private final DoubleSupplier relogio;
    private final ArrayDeque<Double> eventos = new ArrayDeque<>();
    private final Object lock = new Object();

    JanelaDeslizante(int limite, double janela, DoubleSupplier relogio) {
        this.limite = limite;
        this.janela = janela;
        this.relogio = relogio;
    }

    boolean permitir() {
        synchronized (lock) {
            double agora = relogio.getAsDouble();
            while (!eventos.isEmpty() && eventos.peekFirst() <= agora - janela) {
                eventos.pollFirst();             // descarta o que saiu da janela
            }
            if (eventos.size() < limite) {
                eventos.addLast(agora);
                return true;
            }
            return false;
        }
    }
}

class LimitadorPorCliente {
    private final int limite;
    private final double janela;
    private final DoubleSupplier relogio;
    private final Map<String, JanelaDeslizante> clientes = new HashMap<>();
    private final Object lockMapa = new Object();

    LimitadorPorCliente(int limite, double janela, DoubleSupplier relogio) {
        this.limite = limite;
        this.janela = janela;
        this.relogio = relogio;
    }

    boolean permitir(String cliente) {
        JanelaDeslizante lim;
        synchronized (lockMapa) {                // só para obter/criar
            lim = clientes.get(cliente);
            if (lim == null) {
                lim = new JanelaDeslizante(limite, janela, relogio);
                clientes.put(cliente, lim);
            }
        }
        return lim.permitir();                   // fora do lock global
    }
}

static final RelogioFalso relogio = new RelogioFalso();
static final LimitadorPorCliente limitador = new LimitadorPorCliente(4, 1.0, relogio);
static final Map<String, Integer> contagem = new TreeMap<>();
static final Object guarda = new Object();

static void rajada(String cliente, int n) {
    int aceitas = 0;
    for (int i = 0; i < n; i++) {
        if (limitador.permitir(cliente)) aceitas += 1;
    }
    synchronized (guarda) {
        contagem.put(cliente, contagem.getOrDefault(cliente, 0) + aceitas);
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> threads = new ArrayList<>();
    for (String c : List.of("ana", "bia", "caio")) {
        for (int i = 0; i < 3; i++) threads.add(new Thread(() -> rajada(c, 5)));
    }
    for (Thread t : threads) t.start();
    for (Thread t : threads) t.join();
    System.out.println("t=0,0: " + contagem);

    relogio.agora = 1.0;                         // a janela anterior expirou
    List<String> saida = new ArrayList<>();
    for (int i = 0; i < 5; i++) saida.add(limitador.permitir("ana") ? "True" : "False");
    System.out.println("ana em t=1,0: " + saida);
}

using System;

using System.Threading;

{
    public double Agora = 0.0;
}

class JanelaDeslizante
{
    readonly int limite;
    readonly double janela;
    readonly Func<double> relogio;
    readonly Queue<double> eventos = new Queue<double>();
    readonly object trava = new object();

    public JanelaDeslizante(int limite, double janela, Func<double> relogio)
    {
        this.limite = limite;
        this.janela = janela;
        this.relogio = relogio;
    }

    public bool Permitir()
    {
        lock (trava)
        {
            double agora = relogio();
            while (eventos.Count > 0 && eventos.Peek() <= agora - janela)
            {
                eventos.Dequeue();               // descarta o que saiu da janela

                eventos.Enqueue(agora);
                return true;

            return false;

}

    public LimitadorPorCliente(int limite, double janela, Func<double> relogio)
    {
        this.limite = limite;
        this.janela = janela;
        this.relogio = relogio;
    }

    public bool Permitir(string cliente)
    {
        JanelaDeslizante lim;
        lock (lockMapa)                          // só para obter/criar
        {
            if (!clientes.TryGetValue(cliente, out lim))
            {
                lim = new JanelaDeslizante(limite, janela, relogio);
                clientes[cliente] = lim;
            }
        }
        return lim.Permitir();                   // fora do lock global
    }
}

static readonly RelogioFalso relogio = new RelogioFalso();
static readonly LimitadorPorCliente limitador = new LimitadorPorCliente(4, 1.0, () => relogio.Agora);
static readonly SortedDictionary<string, int> contagem = new SortedDictionary<string, int>(StringComparer.Ordinal);
static readonly object guarda = new object();

static void Rajada(string cliente, int n)
{
    int aceitas = 0;
    for (int i = 0; i < n; i++)
    {
        if (limitador.Permitir(cliente)) aceitas += 1;
    }
    lock (guarda)
    {
        int atual;
        contagem.TryGetValue(cliente, out atual);
        contagem[cliente] = atual + aceitas;
    }
}

static void Main()
{
    var threads = new List<Thread>();
    foreach (string c in new[] { "ana", "bia", "caio" })
    {
        for (int i = 0; i < 3; i++) threads.Add(new Thread(() => Rajada(c, 5)));
    }
    foreach (Thread t in threads) t.Start();
    foreach (Thread t in threads) t.Join();
    var pares = new List<string>();
    foreach (var par in contagem) pares.Add("(" + par.Key + ", " + par.Value + ")");
    Console.WriteLine("t=0,0: [" + string.Join(", ", pares) + "]");

    relogio.Agora = 1.0;                         // a janela anterior expirou
    var saida = new List<bool>();
    for (int i = 0; i < 5; i++) saida.Add(limitador.Permitir("ana"));
    Console.WriteLine("ana em t=1,0: [" + string.Join(", ", saida) + "]");
}

import (
	"fmt"
	"strings"
	"sync"

type RelogioFalso struct {
	agora float64
}

type JanelaDeslizante struct {
	limite  int
	janela  float64
	relogio func() float64
	eventos []float64 // fatia usada como fila: Go não tem deque na biblioteca padrão
	mu      sync.Mutex
}

func (j *JanelaDeslizante) permitir() bool {
	j.mu.Lock()
	defer j.mu.Unlock()
	agora := j.relogio()
	for len(j.eventos) > 0 && j.eventos[0] <= agora-j.janela {
		j.eventos = j.eventos[1:] // descarta o que saiu da janela
	}
	if len(j.eventos) < j.limite {
		j.eventos = append(j.eventos, agora)
		return true
	}
	return false
}

type LimitadorPorCliente struct {
	limite   int
	janela   float64
	relogio  func() float64
	clientes map[string]*JanelaDeslizante
	lockMapa sync.Mutex
}

func (l *LimitadorPorCliente) permitir(cliente string) bool {
	l.lockMapa.Lock() // só para obter/criar
	lim, existe := l.clientes[cliente]
	if !existe {
		lim = &JanelaDeslizante{limite: l.limite, janela: l.janela, relogio: l.relogio}
		l.clientes[cliente] = lim
	}
	l.lockMapa.Unlock()
	return lim.permitir() // fora do lock global
}

func main() {
	relogio := &RelogioFalso{}
	limitador := &LimitadorPorCliente{limite: 4, janela: 1.0, relogio: func() float64 { return relogio.agora }, clientes: map[string]*JanelaDeslizante{}}
	contagem := map[string]int{}
	var guarda sync.Mutex
	var wg sync.WaitGroup

	rajada := func(cliente string, n int) {
		defer wg.Done()
		aceitas := 0
		for i := 0; i < n; i++ {
			if limitador.permitir(cliente) {
				aceitas += 1
			}
		}
		guarda.Lock()
		defer guarda.Unlock()
		contagem[cliente] += aceitas
	}

	for _, c := range []string{"ana", "bia", "caio"} {
		for i := 0; i < 3; i++ {
			wg.Add(1)
			go rajada(c, 5)
		}
	}
	wg.Wait()
	fmt.Println("t=0,0:", contagem) // fmt imprime mapas com as chaves em ordem

	relogio.agora = 1.0 // a janela anterior expirou
	saida := []string{}
	for i := 0; i < 5; i++ {
		if limitador.permitir("ana") {
			saida = append(saida, "True")
		} else {
			saida = append(saida, "False")
		}
	}
	fmt.Println("ana em t=1,0: [" + strings.Join(saida, ", ") + "]")
}

## Armadilhas e trade-offs

- **Relógio de parede**: use um relógio monotônico; `time.time` pode retroceder e gerar tokens negativos ou infinitos.
- **Dormir com o lock**: uma versão bloqueante ("espere até ter token") deve calcular o tempo de espera, soltar o lock e só então dormir.
- **Memória por cliente**: o mapa cresce para sempre; remova clientes inativos (TTL) ou use um cache com limite.
- **Vários servidores**: um lock local não vale entre máquinas. Aí o estado vai para um Redis com operação atômica (script Lua) ou você aceita limites aproximados por nó.
- **Alternativa sem lock**: em Java, dá para guardar o estado num `AtomicLong` e atualizar com CAS em laço; em Go, `sync.Mutex` é o caminho idiomático, e `golang.org/x/time/rate` já implementa token bucket.

<Callout type="warning" title="Teste com relógio falso">
Testes que usam `sleep` real para verificar um rate limiter são lentos e instáveis. Injete o relógio e controle o tempo no teste: é também um ótimo ponto para citar na entrevista.
</Callout>
