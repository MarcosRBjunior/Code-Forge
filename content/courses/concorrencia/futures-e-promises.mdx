Quando você submete uma tarefa a outra thread, surge uma pergunta: como receber o resultado? Variáveis globais e listas compartilhadas funcionam, mas obrigam você a criar locks, saber quando o valor ficou pronto e decidir o que fazer se a tarefa falhar. Um **future** encapsula tudo isso num objeto: é uma promessa de valor que estará disponível depois. Quem pede trabalho recebe o future na hora e decide quando esperar por ele.

## Future e promise: dois lados da mesma caixa

Os nomes variam entre linguagens, mas a ideia é uma caixa de uso único com dois lados:

```text
   lado de quem produz                    lado de quem consome
  ┌───────────────────┐   mesma caixa   ┌────────────────────┐
  │ promise           │ ──────────────> │ future             │
  │ set_result(valor) │                 │ result()  (espera) │
  │ set_exception(e)  │                 │ done()    (consulta)│
  └───────────────────┘                 └────────────────────┘
  estados: pendente -> concluído com valor | concluído com erro | cancelado
```

- **Promise**: o lado que escreve, completado uma única vez.
- **Future**: o lado que lê, que bloqueia em `result()` ou registra callbacks.

Em Java, `Future` vem do `ExecutorService` e `CompletableFuture` reúne os dois lados (`complete`, `thenApply`, `thenCompose`, `allOf`). Em C++, `std::promise` e `std::future` são classes separadas, e `std::async` devolve um future. Em JavaScript, `Promise` é o modelo central. Em Go não há future nativo: o idiom é um canal com buffer 1 que recebe o resultado. Em Python, `concurrent.futures.Future` serve aos dois papéis.

## Usando futures de um executor

```python
from concurrent.futures import ThreadPoolExecutor, as_completed
import time

def consultar_preco(produto):
    time.sleep(0.05)
    if produto == "inexistente":
        raise KeyError(produto)
    return len(produto) * 10

produtos = ["teclado", "mouse", "inexistente", "monitor"]
with ThreadPoolExecutor(max_workers=4) as ex:
    futures = {ex.submit(consultar_preco, p): p for p in produtos}
    print("todos pendentes logo apos submit:", not all(f.done() for f in futures))

    resultados, erros = {}, []
    for f in as_completed(futures):       # entrega na ordem em que terminam
        produto = futures[f]
        try:
            resultados[produto] = f.result()   # repropaga a exceção da tarefa
        except KeyError as e:
            erros.append(str(e))

for p in sorted(resultados):
    print(p, resultados[p])
print("erros:", erros)
```

```javascript
const espera = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

async function consultarPreco(produto) {
  await espera(50);
  if (produto === "inexistente") {
    throw new Error(`'${produto}'`);
  }
  return produto.length * 10;
}

async function main() {
  const produtos = ["teclado", "mouse", "inexistente", "monitor"];
  const futures = new Map();   // aqui não há executor: chamar a função async já inicia o trabalho
  const pendentes = new Map(); // avisos que resolvem quando a Promise termina, com sucesso ou com erro
  let concluidas = 0;          // Promise não tem done(): quem quer saber conta sozinho
  for (const p of produtos) {
    const futuro = consultarPreco(p);
    const avisar = () => {
      concluidas += 1;
      return p;
    };
    futures.set(p, futuro);
    pendentes.set(p, futuro.then(avisar, avisar));
  }
```

```java
import java.util.*;
import java.util.concurrent.*;

static int consultarPreco(String produto) throws InterruptedException {
    Thread.sleep(50);
    if (produto.equals("inexistente")) {
        throw new NoSuchElementException("'" + produto + "'");
    }
    return produto.length() * 10;
}

public static void main(String[] args) throws InterruptedException {
    List<String> produtos = List.of("teclado", "mouse", "inexistente", "monitor");
    ExecutorService ex = Executors.newFixedThreadPool(4);
    // ExecutorCompletionService é o as_completed do Java: take() entrega na ordem em que terminam
    ExecutorCompletionService<Integer> concluidas = new ExecutorCompletionService<>(ex);
    Map<Future<Integer>, String> futures = new HashMap<>();
    for (String p : produtos) futures.put(concluidas.submit(() -> consultarPreco(p)), p);
    System.out.println("todos pendentes logo apos submit: " + (futures.keySet().stream().allMatch(Future::isDone) ? "False" : "True"));

    Map<String, Integer> resultados = new TreeMap<>();
    List<String> erros = new ArrayList<>();
    for (int i = 0; i < produtos.size(); i++) {
        Future<Integer> f = concluidas.take();
        String produto = futures.get(f);
        try {
            resultados.put(produto, f.get());   // repropaga a exceção da tarefa, embrulhada em ExecutionException
        } catch (ExecutionException e) {
            erros.add(e.getCause().getMessage());
        }
    }
    ex.shutdown();

    for (String p : resultados.keySet()) System.out.println(p + " " + resultados.get(p));
    System.out.println("erros: " + erros);
}
```

```cpp
#include <chrono>

#include <vector>
using namespace std;

int consultar_preco(string produto) {
    this_thread::sleep_for(chrono::milliseconds(50));
    if (produto == "inexistente") {
        throw out_of_range("'" + produto + "'");
    }
    return produto.size() * 10;
}

int main() {
    vector<string> produtos = {"teclado", "mouse", "inexistente", "monitor"};
    // launch::async garante uma thread para cada chamada; a biblioteca padrão não traz executor
    map<string, future<int>> futures;
    for (auto& p : produtos) futures[p] = async(launch::async, consultar_preco, p);

    bool todos_prontos = true;
    for (auto& [p, f] : futures) {
        if (f.wait_for(chrono::seconds(0)) != future_status::ready) todos_prontos = false;
    }
    cout << "todos pendentes logo apos submit: " << (!todos_prontos ? "True" : "False") << endl;

    map<string, int> resultados;
    vector<string> erros;
    // C++ não tem as_completed: consulta os futures pendentes até cada um ficar pronto
    while (!futures.empty()) {
        for (auto it = futures.begin(); it != futures.end();) {
            if (it->second.wait_for(chrono::milliseconds(1)) != future_status::ready) {
                ++it;
                continue;
            }
            try {
                resultados[it->first] = it->second.get();   // repropaga a exceção da tarefa
            } catch (const out_of_range& e) {
                erros.push_back(e.what());
            }
            it = futures.erase(it);
        }
    }

    for (auto& [p, valor] : resultados) cout << p << " " << valor << endl;
    cout << "erros: [";
    for (auto& e : erros) cout << "\"" << e << "\"";
    cout << "]" << endl;
}
```

```go
func consultarPreco(produto string) (int, error) {

			concluidos <- Resultado{produto, valor, err}
		}(p)

	if len(concluidos) < len(produtos) { // len de um canal conta o que já está no buffer
```

Três detalhes importam. Primeiro, `result()` bloqueia até a tarefa terminar e, se ela falhou, **relança a exceção** na thread que chamou; o erro não some, mas só aparece se você pedir o resultado. Segundo, `as_completed` entrega na ordem de conclusão, então ordene antes de imprimir se a ordem importa. Terceiro, `result(timeout=...)` evita esperar para sempre por uma tarefa travada.

## Construindo uma promise

Para entender o mecanismo, vale implementar uma versão mínima: um `Event` para sinalizar conclusão, o valor guardado e uma lista de callbacks. O método `then` encadeia transformações sem bloquear, que é o que `thenApply` faz em Java.

<CodeTabs>

```python
import threading

class Promessa:
    def __init__(self):
        self._pronto = threading.Event()
        self._lock = threading.Lock()
        self._valor = None
        self._callbacks = []

    def resolver(self, valor):
        with self._lock:
            if self._pronto.is_set():
                raise RuntimeError("promessa ja resolvida")
            self._valor = valor
            self._pronto.set()
            callbacks = list(self._callbacks)
        for cb in callbacks:
            cb(valor)

    def resultado(self, timeout=None):
        if not self._pronto.wait(timeout):
            raise TimeoutError("ainda pendente")
        return self._valor

    def then(self, func):
        proxima = Promessa()
        def ao_concluir(valor):
            proxima.resolver(func(valor))
        with self._lock:
            if not self._pronto.is_set():
                self._callbacks.append(ao_concluir)
                return proxima
        ao_concluir(self._valor)  # já estava pronta: executa agora
        return proxima

p = Promessa()
dobro_mais_um = p.then(lambda x: x * 2).then(lambda x: x + 1)

try:
    p.resultado(timeout=0.01)
except TimeoutError as e:
    print("antes:", e)

threading.Thread(target=p.resolver, args=(20,)).start()
print("valor original:", p.resultado(timeout=1))
print("depois do encadeamento:", dobro_mais_um.resultado(timeout=1))

try:
    p.resolver(99)
except RuntimeError as e:
    print("segunda resolucao:", e)
```

```javascript
class Promessa {
  constructor() {
    this.pronto = false;
    this.valor = undefined;
    this.callbacks = [];
  }

  resolver(valor) {
    if (this.pronto) {
      throw new Error("promessa ja resolvida");
    }
    this.valor = valor;
    this.pronto = true;

      cb(valor);
    }

    if (this.pronto) {
      return Promise.resolve(this.valor);

    return new Promise((resolve, reject) => {
```

```java
import java.util.*;
import java.util.concurrent.*;
import java.util.function.*;

class Promessa<T> {
    private final CountDownLatch pronto = new CountDownLatch(1);  // faz o papel do Event
    private final Object lock = new Object();
    private T valor = null;
    private final List<Consumer<T>> callbacks = new ArrayList<>();

    void resolver(T novo) {
        List<Consumer<T>> copia;
        synchronized (lock) {
            if (pronto.getCount() == 0) {
                throw new IllegalStateException("promessa ja resolvida");
            }
            valor = novo;
            pronto.countDown();
            copia = new ArrayList<>(callbacks);
        }
        for (Consumer<T> cb : copia) cb.accept(novo);
    }

    T resultado(long timeoutMs) throws InterruptedException, TimeoutException {
        if (!pronto.await(timeoutMs, TimeUnit.MILLISECONDS)) {
            throw new TimeoutException("ainda pendente");
        }
        return valor;
    }

    <R> Promessa<R> then(Function<T, R> func) {
        Promessa<R> proxima = new Promessa<>();
        Consumer<T> aoConcluir = v -> proxima.resolver(func.apply(v));
        synchronized (lock) {
            if (pronto.getCount() != 0) {
                callbacks.add(aoConcluir);
                return proxima;
            }
        }
        aoConcluir.accept(valor);  // já estava pronta: executa agora
        return proxima;
    }
}

public static void main(String[] args) throws Exception {
    Promessa<Integer> p = new Promessa<>();
    Promessa<Integer> dobroMaisUm = p.then(x -> x * 2).then(x -> x + 1);

    try {
        p.resultado(10);
    } catch (TimeoutException e) {
        System.out.println("antes: " + e.getMessage());
    }

    new Thread(() -> p.resolver(20)).start();
    System.out.println("valor original: " + p.resultado(1000));
    System.out.println("depois do encadeamento: " + dobroMaisUm.resultado(1000));

    try {
        p.resolver(99);
    } catch (IllegalStateException e) {
        System.out.println("segunda resolucao: " + e.getMessage());
    }
}
```

```cpp
#include <chrono>
#include <condition_variable>
#include <functional>
#include <iostream>
#include <memory>
#include <mutex>
#include <stdexcept>
#include <thread>
#include <vector>
using namespace std;

struct TempoEsgotado : runtime_error {
    using runtime_error::runtime_error;
};

class Promessa {
    mutex trava;
    condition_variable mudou;   // com a flag pronto, faz o papel do Event
    bool pronto = false;
    int valor = 0;
    vector<function<void(int)>> callbacks;

public:
    void resolver(int novo) {
        vector<function<void(int)>> copia;
        {
            lock_guard<mutex> guarda(trava);
            if (pronto) throw runtime_error("promessa ja resolvida");
            valor = novo;
            pronto = true;
            copia = callbacks;
        }
        mudou.notify_all();
        for (auto& cb : copia) cb(novo);
    }

    int resultado(chrono::milliseconds timeout) {
        unique_lock<mutex> guarda(trava);
        if (!mudou.wait_for(guarda, timeout, [this] { return pronto; })) {
            throw TempoEsgotado("ainda pendente");
        }
        return valor;
    }

    // shared_ptr: o callback precisa manter a próxima promessa viva até ser chamado
    shared_ptr<Promessa> then(function<int(int)> func) {
        auto proxima = make_shared<Promessa>();
        auto ao_concluir = [proxima, func](int v) { proxima->resolver(func(v)); };
        int pronto_com;
        {
            lock_guard<mutex> guarda(trava);
            if (!pronto) {
                callbacks.push_back(ao_concluir);
                return proxima;
            }
            pronto_com = valor;
        }
        ao_concluir(pronto_com);  // já estava pronta: executa agora
        return proxima;
    }
};

int main() {
    auto p = make_shared<Promessa>();
    auto dobro_mais_um = p->then([](int x) { return x * 2; })->then([](int x) { return x + 1; });

    try {
        p->resultado(chrono::milliseconds(10));
    } catch (const TempoEsgotado& e) {
        cout << "antes: " << e.what() << endl;
    }

    thread t([p] { p->resolver(20); });
    cout << "valor original: " << p->resultado(chrono::seconds(1)) << endl;
    cout << "depois do encadeamento: " << dobro_mais_um->resultado(chrono::seconds(1)) << endl;
    t.join();  // em C++, destruir uma thread sem join encerra o programa

    try {
        p->resolver(99);
    } catch (const runtime_error& e) {
        cout << "segunda resolucao: " << e.what() << endl;
    }
}
```

```csharp
class Promessa<T>
{
    readonly ManualResetEventSlim pronto = new ManualResetEventSlim(false);  // faz o papel do Event
    readonly object trava = new object();
    T valor;
    readonly List<Action<T>> callbacks = new List<Action<T>>();

    public void Resolver(T novo)
    {
        List<Action<T>> copia;
        lock (trava)
        {
            if (pronto.IsSet)
            {
                throw new InvalidOperationException("promessa ja resolvida");
            }
            valor = novo;
            pronto.Set();
            copia = new List<Action<T>>(callbacks);
        }
        foreach (Action<T> cb in copia) cb(novo);
    }

    public T Resultado(int timeoutMs)
    {
        if (!pronto.Wait(timeoutMs))
        {
            throw new TimeoutException("ainda pendente");
        }
        return valor;
    }

    public Promessa<R> Then<R>(Func<T, R> func)
    {
        Promessa<R> proxima = new Promessa<R>();
        Action<T> aoConcluir = v => proxima.Resolver(func(v));
        lock (trava)
        {
            if (!pronto.IsSet)
            {
                callbacks.Add(aoConcluir);
                return proxima;
            }
        }
        aoConcluir(valor);  // já estava pronta: executa agora
        return proxima;
    }
}

static void Main()
{
    Promessa<int> p = new Promessa<int>();
    Promessa<int> dobroMaisUm = p.Then(x => x * 2).Then(x => x + 1);

    try
    {
        p.Resultado(10);
    }
    catch (TimeoutException e)
    {
        Console.WriteLine("antes: " + e.Message);
    }

    new Thread(() => p.Resolver(20)).Start();
    Console.WriteLine("valor original: " + p.Resultado(1000));
    Console.WriteLine("depois do encadeamento: " + dobroMaisUm.Resultado(1000));

    try
    {
        p.Resolver(99);
    }
    catch (InvalidOperationException e)
    {
        Console.WriteLine("segunda resolucao: " + e.Message);
    }
}
```

```go
import (
	"errors"
	"fmt"
	"sync"
	"time"
)

type Promessa struct {
	pronto    chan struct{} // fechar o canal faz o papel do Event: acorda todos que esperam
	mu        sync.Mutex
	resolvida bool
	valor     int
	callbacks []func(int)
}

func novaPromessa() *Promessa {
	return &Promessa{pronto: make(chan struct{})}
}

func (p *Promessa) resolver(valor int) error {
	p.mu.Lock()
	if p.resolvida {
		p.mu.Unlock()
		return errors.New("promessa ja resolvida") // Go devolve o erro como valor, não lança exceção
	}
	p.valor = valor
	p.resolvida = true
	close(p.pronto)
	callbacks := append([]func(int){}, p.callbacks...)
	p.mu.Unlock()
	for _, cb := range callbacks {
		cb(valor)
	}
	return nil
}

func (p *Promessa) resultado(timeout time.Duration) (int, error) {
	select {
	case <-p.pronto:
		return p.valor, nil
	case <-time.After(timeout):
		return 0, errors.New("ainda pendente")
	}
}

func (p *Promessa) then(funcao func(int) int) *Promessa {
	proxima := novaPromessa()
	aoConcluir := func(valor int) {
		proxima.resolver(funcao(valor))
	}
	p.mu.Lock()
	if !p.resolvida {
		p.callbacks = append(p.callbacks, aoConcluir)
		p.mu.Unlock()
		return proxima
	}
	valor := p.valor
	p.mu.Unlock()
	aoConcluir(valor) // já estava pronta: executa agora
	return proxima
}

func main() {
	p := novaPromessa()
	dobroMaisUm := p.then(func(x int) int { return x * 2 }).then(func(x int) int { return x + 1 })

	if _, err := p.resultado(10 * time.Millisecond); err != nil {
		fmt.Println("antes:", err)
	}

	go p.resolver(20)
	valor, _ := p.resultado(time.Second)
	fmt.Println("valor original:", valor)
	final, _ := dobroMaisUm.resultado(time.Second)
	fmt.Println("depois do encadeamento:", final)

	if err := p.resolver(99); err != nil {
		fmt.Println("segunda resolucao:", err)
	}
}
```

O lock em `then` evita uma corrida sutil: sem ele, o callback poderia ser registrado logo depois de `resolver` copiar a lista, e ninguém o chamaria.

## Armadilhas

- **Bloquear cedo demais**: chamar `submit(...).result()` em seguida transforma código concorrente em sequencial. Submeta tudo primeiro e espere depois.
- **Exceções esquecidas**: futures que ninguém consulta escondem falhas. Sempre chame `result()` ou verifique `exception()`.
- **Callbacks pesados**: em muitas implementações o callback roda na thread que completou o future, roubando tempo do worker.
- **Cancelamento limitado**: `cancel()` só funciona se a tarefa ainda não começou; uma tarefa em execução precisa checar uma flag por conta própria.
- **Esperar dentro do mesmo pool**: um future que espera outro future do mesmo pool lotado causa deadlock.

<Callout type="tip" title="Componha, não bloqueie">
Em código com muitas etapas, prefira composição (`thenCompose`, `allOf`, `asyncio.gather`) a chamadas `get()` espalhadas. O fluxo fica declarativo e as threads ficam livres.
</Callout>

## Na entrevista

Defina future como o lado leitor e promise como o lado escritor de um resultado de uso único, cite os estados (pendente, concluído, falho, cancelado) e mostre o padrão "submeta tudo, depois colete". Se pedirem implementação, use lock mais condição ou evento, garanta que só se resolve uma vez e trate callbacks registrados antes e depois da conclusão. Follow-ups comuns: "como esperar o primeiro de vários resultados?" (`as_completed`, `anyOf`, `wait(FIRST_COMPLETED)`) e "como aplicar timeout a uma chamada lenta?" (`result(timeout)` e cancelamento cooperativo).
