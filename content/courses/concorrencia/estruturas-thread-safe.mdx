Um `HashMap` comum compartilhado entre threads pode perder escritas, ficar inconsistente durante um redimensionamento ou, em versões antigas do Java, entrar em laço infinito. A solução ingênua é colocar um lock global em volta de tudo, mas isso transforma a coleção num gargalo: só uma thread lê ou escreve por vez. As **coleções thread-safe** existem para dar segurança com o mínimo de contenção, e entender como elas fazem isso é tema frequente de entrevista.

## As três estratégias

| Estratégia | Ideia | Exemplos | Bom quando |
| --- | --- | --- | --- |
| Lock único | Toda operação adquire o mesmo lock | `Collections.synchronizedMap`, `Hashtable` | Pouca contenção, simplicidade |
| Lock striping / granular | Várias partes, cada uma com seu lock ou CAS | `ConcurrentHashMap`, `sync.Map` (parcialmente) | Muitas threads, muitas chaves |
| Copy-on-write | Escrita cria uma cópia nova; leitura não trava | `CopyOnWriteArrayList` | Muita leitura, escrita rara |

Além dessas, existem estruturas **lock-free** baseadas em CAS, como `ConcurrentLinkedQueue` e `ConcurrentSkipListMap` em Java.

```text
 lock striping com 4 listras
 chave ─hash─► listra = hash % 4
   listra 0: [lock0] k3, k7
   listra 1: [lock1] k1
   listra 2: [lock2] k2, k6, k9
   listra 3: [lock3] k4
 threads em listras diferentes não disputam o mesmo lock
```

No `ConcurrentHashMap` do Java 8+, leituras não usam lock; escritas usam CAS quando o balde está vazio e `synchronized` só no primeiro nó do balde quando não está. Em Go, o `map` nativo não é seguro para escrita concorrente (o runtime aborta com "concurrent map writes"); você usa `sync.Mutex`/`sync.RWMutex` em volta dele ou `sync.Map`, otimizado para chaves escritas uma vez e lidas muitas. Em C++, os contêineres da STL não são thread-safe para escrita; você protege com `std::mutex` ou `std::shared_mutex`.

## O problema que nenhuma coleção resolve sozinha

Mesmo com cada operação atômica, a **composição** de operações não é. O padrão clássico é o check-then-act:

```python
# Cada chamada é segura, mas o conjunto não:
if chave not in mapa:          # thread A e thread B veem "não está"
    mapa[chave] = criar()      # as duas criam e uma sobrescreve a outra

# Ler, modificar e escrever também quebra:
mapa[chave] = mapa.get(chave, 0) + 1   # incrementos podem se perder
```

Por isso coleções concorrentes oferecem **operações compostas atômicas**: `putIfAbsent`, `computeIfAbsent`, `merge` e `compute` em Java; `LoadOrStore` em Go. Em Python, o GIL torna atômicas operações individuais de `dict` e `list` no CPython (como `setdefault` e `append`), mas isso é detalhe de implementação e não vale para sequências de operações. A versão segura usa um lock em volta da operação composta:

<CodeTabs>

```python
import threading

class ContadorSeguro:
    def __init__(self):
        self._dados = {}
        self._lock = threading.Lock()

    def incrementar(self, chave, n=1):
        with self._lock:                       # ler + somar + escrever juntos
            self._dados[chave] = self._dados.get(chave, 0) + n

    def instantaneo(self):
        with self._lock:
            return dict(self._dados)           # cópia para iterar sem lock

contador = ContadorSeguro()
palavras = ["get", "put", "get", "del", "get", "put"]

def trabalhador():
    for _ in range(1000):
        for p in palavras:
            contador.incrementar(p)

threads = [threading.Thread(target=trabalhador) for _ in range(4)]
for t in threads:
    t.start()
for t in threads:
    t.join()

for chave, valor in sorted(contador.instantaneo().items()):
    print(chave, valor)
```

```java
import java.util.*;

class ContadorSeguro {
    private final Map<String, Integer> dados = new HashMap<>();
    private final Object lock = new Object();

    void incrementar(String chave) {
        incrementar(chave, 1);
    }

    void incrementar(String chave, int n) {
        synchronized (lock) {                     // ler + somar + escrever juntos
            dados.put(chave, dados.getOrDefault(chave, 0) + n);
        }
    }

    Map<String, Integer> instantaneo() {
        synchronized (lock) {
            return new HashMap<>(dados);          // cópia para iterar sem lock
        }
    }
}

static final String[] palavras = {"get", "put", "get", "del", "get", "put"};

static void trabalhador() {
    for (int i = 0; i < 1000; i++) {

        }
    }
}

    for (int i = 0; i < 4; i++) threads.add(new Thread(() -> trabalhador()));

    for (Thread t : threads) t.join();

    for (Map.Entry<String, Integer> e : new TreeMap<>(contador.instantaneo()).entrySet()) {
```

```go
func (c *ContadorSeguro) incrementar(chave string, n int) {
	c.mu.Lock() // ler + somar + escrever juntos

	c.dados[chave] += n

	c.mu.Lock()
	defer c.mu.Unlock()

	}
```

## Lock striping na prática

Para reduzir contenção, você divide o mapa em várias partes, cada uma com seu próprio lock. Duas threads só disputam o lock quando suas chaves caem na mesma listra.

<CodeTabs>

```python
import threading

class MapaListrado:
    def __init__(self, listras=8):
        self._partes = [dict() for _ in range(listras)]
        self._locks = [threading.Lock() for _ in range(listras)]

    def _indice(self, chave):
        return hash(chave) % len(self._partes)

    def compute_if_absent(self, chave, fabrica):
        i = self._indice(chave)
        with self._locks[i]:
            if chave not in self._partes[i]:
                self._partes[i][chave] = fabrica(chave)
            return self._partes[i][chave]

    def tamanho(self):
        total = 0
        for lock, parte in zip(self._locks, self._partes):
            with lock:
                total += len(parte)
        return total

mapa = MapaListrado()
criacoes = []
registro = threading.Lock()

def fabrica(chave):
    with registro:
        criacoes.append(chave)
    return chave * 2

def trabalhador(base):
    for i in range(100):
        mapa.compute_if_absent((base + i) % 50, fabrica)

threads = [threading.Thread(target=trabalhador, args=(k * 7,)) for k in range(6)]
for t in threads:
    t.start()
for t in threads:
    t.join()

print("chaves:", mapa.tamanho())
print("cada chave criada uma vez:", len(criacoes) == len(set(criacoes)) == 50)
print("valor de 21:", mapa.compute_if_absent(21, fabrica))
```

```java
import java.util.*;
import java.util.function.*;

class MapaListrado {
    private final List<Map<Integer, Integer>> partes = new ArrayList<>();
    private final Object[] locks;

    MapaListrado(int listras) {
        locks = new Object[listras];
        for (int i = 0; i < listras; i++) {
            partes.add(new HashMap<>());
            locks[i] = new Object();
        }
    }

    private int indice(int chave) {
        return Math.floorMod(Integer.hashCode(chave), partes.size());
    }

    int computeIfAbsent(int chave, Function<Integer, Integer> fabrica) {
        int i = indice(chave);
        synchronized (locks[i]) {
            Map<Integer, Integer> parte = partes.get(i);
            if (!parte.containsKey(chave)) {
                parte.put(chave, fabrica.apply(chave));
            }
            return parte.get(chave);
        }
    }

    int tamanho() {
        int total = 0;
        for (int i = 0; i < locks.length; i++) {
            synchronized (locks[i]) {
                total += partes.get(i).size();
            }
        }
        return total;
    }
}

static final MapaListrado mapa = new MapaListrado(8);
static final List<Integer> criacoes = new ArrayList<>();
static final Object registro = new Object();

static int fabrica(int chave) {
    synchronized (registro) {
        criacoes.add(chave);
    }
    return chave * 2;
}

static void trabalhador(int base) {
    for (int i = 0; i < 100; i++) {
        mapa.computeIfAbsent((base + i) % 50, k -> fabrica(k));
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> threads = new ArrayList<>();
    for (int k = 0; k < 6; k++) {
        final int base = k * 7;
        threads.add(new Thread(() -> trabalhador(base)));
    }
    for (Thread t : threads) t.start();
    for (Thread t : threads) t.join();

    System.out.println("chaves: " + mapa.tamanho());
    boolean umaVez = criacoes.size() == new HashSet<>(criacoes).size() && criacoes.size() == 50;
    System.out.println("cada chave criada uma vez: " + (umaVez ? "True" : "False"));
    System.out.println("valor de 21: " + mapa.computeIfAbsent(21, k -> fabrica(k)));
}
```

```cpp
#include <functional>
#include <iostream>
#include <mutex>
#include <set>
#include <thread>
#include <unordered_map>
#include <vector>
using namespace std;

class MapaListrado {
    vector<unordered_map<int, int>> partes;
    vector<mutex> locks;   // mutex não é copiável: o vetor nasce com o tamanho final

    size_t indice(int chave) {
        return hash<int>{}(chave) % partes.size();
    }

public:
    MapaListrado(int listras = 8) : partes(listras), locks(listras) {}

    int compute_if_absent(int chave, const function<int(int)>& fabrica) {
        size_t i = indice(chave);
        lock_guard<mutex> guarda(locks[i]);
        auto achado = partes[i].find(chave);
        if (achado != partes[i].end()) return achado->second;
        int valor = fabrica(chave);
        partes[i][chave] = valor;
        return valor;
    }

    int tamanho() {
        int total = 0;
        for (size_t i = 0; i < partes.size(); i++) {
            lock_guard<mutex> guarda(locks[i]);
            total += partes[i].size();
        }
        return total;
    }
};

MapaListrado mapa;
vector<int> criacoes;
mutex registro;

int fabrica(int chave) {
    lock_guard<mutex> guarda(registro);
    criacoes.push_back(chave);
    return chave * 2;
}

void trabalhador(int base) {
    for (int i = 0; i < 100; i++) {
        mapa.compute_if_absent((base + i) % 50, fabrica);
    }
}

int main() {
    vector<thread> threads;
    for (int k = 0; k < 6; k++) threads.emplace_back(trabalhador, k * 7);

    cout << "cada chave criada uma vez: " << (uma_vez ? "True" : "False") << endl;
    cout << "valor de 21: " << mapa.compute_if_absent(21, fabrica) << endl;
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Threading;

class MapaListrado
{
    readonly Dictionary<int, int>[] partes;
    readonly object[] locks;

    public MapaListrado(int listras = 8)
    {
        partes = new Dictionary<int, int>[listras];
        locks = new object[listras];
        for (int i = 0; i < listras; i++)
        {
            partes[i] = new Dictionary<int, int>();
            locks[i] = new object();
        }
    }

    int Indice(int chave)
    {
        return (chave.GetHashCode() & int.MaxValue) % partes.Length;
    }

    public int ComputeIfAbsent(int chave, Func<int, int> fabrica)
    {
        int i = Indice(chave);
        lock (locks[i])
        {
            if (!partes[i].ContainsKey(chave))
            {
                partes[i][chave] = fabrica(chave);
            }
            return partes[i][chave];
        }
    }

    public int Tamanho()
    {
        int total = 0;
        for (int i = 0; i < partes.Length; i++)
        {
            lock (locks[i])
            {
                total += partes[i].Count;
            }
        }
        return total;
    }
}

static readonly MapaListrado mapa = new MapaListrado();
static readonly List<int> criacoes = new List<int>();
static readonly object registro = new object();

static int Fabrica(int chave)
{
    lock (registro)
    {
        criacoes.Add(chave);
    }
    return chave * 2;
}

static void Trabalhador(int inicio)
{
    for (int i = 0; i < 100; i++)
    {
        mapa.ComputeIfAbsent((inicio + i) % 50, Fabrica);
    }
}

static void Main()
{
    var threads = new List<Thread>();
    for (int k = 0; k < 6; k++)
    {
        int deslocamento = k * 7;
        threads.Add(new Thread(() => Trabalhador(deslocamento)));
    }
    foreach (Thread t in threads) t.Start();
    foreach (Thread t in threads) t.Join();

    Console.WriteLine("chaves: " + mapa.Tamanho());
    bool umaVez = criacoes.Count == new HashSet<int>(criacoes).Count && criacoes.Count == 50;
    Console.WriteLine("cada chave criada uma vez: " + umaVez);
    Console.WriteLine("valor de 21: " + mapa.ComputeIfAbsent(21, Fabrica));
}
```

```go
import (
	"fmt"
	"sync"
)

type MapaListrado struct {
	partes []map[int]int
	locks  []sync.Mutex
}

func novoMapaListrado(listras int) *MapaListrado {
	m := &MapaListrado{partes: make([]map[int]int, listras), locks: make([]sync.Mutex, listras)}
	for i := range m.partes {
		m.partes[i] = map[int]int{}
	}
	return m
}

func (m *MapaListrado) indice(chave int) int {
	return chave % len(m.partes) // Go não expõe o hash de um int; o próprio valor serve aqui (como o hash() de int em Python)
}

func (m *MapaListrado) computeIfAbsent(chave int, fabrica func(int) int) int {
	i := m.indice(chave)
	m.locks[i].Lock()
	defer m.locks[i].Unlock()
	if _, existe := m.partes[i][chave]; !existe {
		m.partes[i][chave] = fabrica(chave)
	}
	return m.partes[i][chave]
}

func (m *MapaListrado) tamanho() int {
	total := 0
	for i := range m.partes {
		m.locks[i].Lock()
		total += len(m.partes[i])
		m.locks[i].Unlock()
	}
	return total
}

var mapa = novoMapaListrado(8)
var criacoes = []int{}
var registro sync.Mutex

func fabrica(chave int) int {
	registro.Lock()
	defer registro.Unlock()
	criacoes = append(criacoes, chave)
	return chave * 2
}

func trabalhador(base int, wg *sync.WaitGroup) {
	defer wg.Done()
	for i := 0; i < 100; i++ {
		mapa.computeIfAbsent((base+i)%50, fabrica)
	}
}

func main() {
	var wg sync.WaitGroup
	for k := 0; k < 6; k++ {
		wg.Add(1)
		go trabalhador(k*7, &wg)
	}
	wg.Wait()

	fmt.Println("chaves:", mapa.tamanho())
	unicas := map[int]bool{}
	for _, c := range criacoes {
		unicas[c] = true
	}
	if len(criacoes) == len(unicas) && len(criacoes) == 50 {
		fmt.Println("cada chave criada uma vez: True")
	} else {
		fmt.Println("cada chave criada uma vez: False")
	}
	fmt.Println("valor de 21:", mapa.computeIfAbsent(21, fabrica))
}
```

## Armadilhas e trade-offs

- **`size()` aproximado**: em mapas listrados, somar as partes sem travar todas dá um valor que pode estar desatualizado. O `ConcurrentHashMap` documenta isso.
- **Iteradores fracamente consistentes**: iterar um `ConcurrentHashMap` não lança exceção, mas pode ou não refletir escritas feitas durante a iteração.
- **Copy-on-write** cobra caro em cada escrita (cópia inteira); use só para listas pequenas e quase imutáveis, como listas de listeners.
- **Fábrica cara dentro do lock** bloqueia a listra inteira enquanto roda; em Java, `computeIfAbsent` com função lenta trava outras chaves do mesmo balde.

<Callout type="tip" title="Segurança é da operação, não da estrutura">
Diga ao entrevistador quais operações precisam ser atômicas juntas. Uma coleção thread-safe garante cada chamada isolada; invariantes que envolvem várias chamadas continuam sendo sua responsabilidade.
</Callout>

## Na entrevista

Ao ver estado compartilhado, diga qual coleção usaria e por quê: lock único se a contenção é baixa, `ConcurrentHashMap` ou listras para muitas threads, copy-on-write para leitura dominante. Aponte o check-then-act e resolva com `computeIfAbsent`, `putIfAbsent` ou um lock na operação composta. Follow-ups comuns: "como o `ConcurrentHashMap` evita travar o mapa inteiro?" (CAS e lock por balde, leituras sem lock) e "por que `Collections.synchronizedMap` não basta para um contador?" (`get` e `put` separados permitem perder incrementos).
