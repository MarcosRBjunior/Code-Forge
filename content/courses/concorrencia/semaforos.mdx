Um mutex responde à pergunta "alguém está usando isto?". Muitas vezes a pergunta real é outra: "quantos podem usar isto ao mesmo tempo?". Um pool com 10 conexões de banco, uma API externa que aceita 5 chamadas simultâneas, uma máquina que aguenta 4 conversões de vídeo em paralelo. Para limitar a concorrência a N, você usa um **semáforo**: um contador de permissões com duas operações atômicas.

## Como funciona

- **acquire** (também chamado de `P`, `wait` ou `down`): se o contador é maior que zero, decrementa e segue; se é zero, bloqueia até alguém devolver uma permissão.
- **release** (`V`, `signal` ou `up`): incrementa o contador e acorda uma thread que esteja esperando.

```text
Semáforo com 3 permissões

contador: 3   T1 acquire -> 2
contador: 2   T2 acquire -> 1
contador: 1   T3 acquire -> 0
contador: 0   T4 acquire -> bloqueia
              T1 release -> T4 acorda e entra (contador continua 0)
```

Diferente do mutex, o semáforo **não tem dono**: qualquer thread pode chamar `release`, mesmo uma que nunca chamou `acquire`. Isso é um defeito quando você queria exclusão mútua e uma qualidade quando você quer sinalizar entre threads.

Em Python: `threading.Semaphore` e `threading.BoundedSemaphore`, além de `asyncio.Semaphore`. Em Java: `java.util.concurrent.Semaphore`. Em C++20: `std::counting_semaphore` e `std::binary_semaphore`. Em Go não há tipo dedicado; o idioma é um canal com buffer (`sem := make(chan struct{}, 3)`), em que enviar é adquirir e receber é liberar, ou o pacote `golang.org/x/sync/semaphore`.

## Limitando a concorrência

<CodeTabs>

```python
import threading
import time

limite = threading.BoundedSemaphore(3)
estado = threading.Lock()
ativos = 0
maximo = 0
concluidas = []

def chamar_api(i):
    global ativos, maximo
    with limite:  # no máximo 3 threads passam daqui ao mesmo tempo
        with estado:
            ativos += 1
            maximo = max(maximo, ativos)
        time.sleep(0.02)  # simula a chamada externa
        with estado:
            ativos -= 1
            concluidas.append(i)

threads = [threading.Thread(target=chamar_api, args=(i,)) for i in range(10)]
for t in threads:
    t.start()
for t in threads:
    t.join()

print("limite respeitado:", maximo <= 3)
print("chamadas concluidas:", sorted(concluidas))
```

```java
import java.util.*;
import java.util.concurrent.Semaphore;

// Java não tem BoundedSemaphore: um release a mais aqui aumentaria o limite sem erro
static final Semaphore limite = new Semaphore(3);
static final Object estado = new Object();
static int ativos = 0;
static int maximo = 0;
static final List<Integer> concluidas = new ArrayList<>();

static void chamarApi(int i) {
    limite.acquireUninterruptibly();  // no máximo 3 threads passam daqui ao mesmo tempo
    try {
        synchronized (estado) {
            ativos += 1;
            maximo = Math.max(maximo, ativos);
        }
        try {
            Thread.sleep(20);  // simula a chamada externa
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        synchronized (estado) {
            ativos -= 1;
            concluidas.add(i);
        }
    } finally {
        limite.release();  // o finally devolve a permissão mesmo com exceção
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> threads = new ArrayList<>();
    for (int i = 0; i < 10; i++) {
        int id = i;
        threads.add(new Thread(() -> chamarApi(id)));
    }
    for (Thread t : threads) t.start();
    for (Thread t : threads) t.join();

    Collections.sort(concluidas);
    System.out.println("limite respeitado: " + (maximo <= 3 ? "True" : "False"));
    System.out.println("chamadas concluidas: " + concluidas);
}
```

```cpp
#include <algorithm>
#include <chrono>
#include <iostream>
#include <mutex>
#include <semaphore>
#include <thread>

using namespace std;

counting_semaphore<3> limite(3);
mutex estado;
int ativos = 0;

vector<int> concluidas;

struct Permissao {
    Permissao() { limite.acquire(); }
    ~Permissao() { limite.release(); }
};

void chamar_api(int i) {
    Permissao permissao;  // no máximo 3 threads passam daqui ao mesmo tempo
    {
        lock_guard<mutex> guarda(estado);
        ativos += 1;
        maximo = max(maximo, ativos);
    }
    this_thread::sleep_for(chrono::milliseconds(20));  // simula a chamada externa
    {
        lock_guard<mutex> guarda(estado);
        ativos -= 1;
        concluidas.push_back(i);
    }
}

int main() {
    vector<thread> threads;
    for (int i = 0; i < 10; i++) {
        threads.emplace_back(chamar_api, i);
    }
    for (auto& t : threads) {
        t.join();
    }

    sort(concluidas.begin(), concluidas.end());
    cout << "limite respeitado: " << (maximo <= 3 ? "True" : "False") << endl;
    cout << "chamadas concluidas: [";
    for (size_t i = 0; i < concluidas.size(); i++) {
        cout << (i ? ", " : "") << concluidas[i];
    }
    cout << "]" << endl;
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Threading;

// o segundo argumento é o máximo: um Release a mais lança SemaphoreFullException
static readonly SemaphoreSlim limite = new SemaphoreSlim(3, 3);
static readonly object estado = new object();

static int maximo = 0;

{

        {
            ativos -= 1;

    {
```

```go
import (
	"fmt"
	"sort"
	"sync"
	"time"
)

var limite = make(chan struct{}, 3) // canal com 3 lugares: enviar adquire, receber libera
var estado sync.Mutex
var ativos, maximo = 0, 0
var concluidas []int

func chamarApi(i int, wg *sync.WaitGroup) {
	defer wg.Done()
	limite <- struct{}{}       // no máximo 3 goroutines passam daqui ao mesmo tempo
	defer func() { <-limite }() // o defer devolve a permissão mesmo com panic
	estado.Lock()
	ativos += 1
	if ativos > maximo {
		maximo = ativos
	}
	estado.Unlock()
	time.Sleep(20 * time.Millisecond) // simula a chamada externa
	estado.Lock()
	ativos -= 1
	concluidas = append(concluidas, i)
	estado.Unlock()
}

func main() {
	var wg sync.WaitGroup
	for i := 0; i < 10; i++ {
		wg.Add(1)
		go chamarApi(i, &wg)
	}
	wg.Wait()

	sort.Ints(concluidas)
	if maximo <= 3 {
		fmt.Println("limite respeitado: True")
	} else {
		fmt.Println("limite respeitado: False")
	}
	fmt.Println("chamadas concluidas:", concluidas)
}
```

Dez threads foram criadas, mas nunca mais de três estiveram dentro do trecho protegido. O `with` garante que a permissão volta mesmo que a chamada lance exceção.

## Semáforo como sinal

Com contador inicial **zero**, o semáforo vira um mecanismo de aviso: quem chama `acquire` espera até outra thread chamar `release`. Isso força uma ordem entre threads sem depender de `sleep`.

<CodeTabs>

```python
import threading

pronto = threading.Semaphore(0)
log = []

def usuario():
    pronto.acquire()  # espera o aviso
    log.append("usuario: usando a conexao")

def preparador():
    log.append("preparador: conexao aberta")
    pronto.release()  # avisa

u = threading.Thread(target=usuario)
p = threading.Thread(target=preparador)
u.start()  # mesmo iniciando primeiro, o usuário espera
p.start()
u.join()
p.join()

for linha in log:
    print(linha)
```

```java
import java.util.*;
import java.util.concurrent.Semaphore;

static final Semaphore pronto = new Semaphore(0);
static final List<String> log = new ArrayList<>();

static void usuario() {
    pronto.acquireUninterruptibly();  // espera o aviso
    log.add("usuario: usando a conexao");
}

static void preparador() {
    log.add("preparador: conexao aberta");
    pronto.release();  // avisa
}

public static void main(String[] args) throws InterruptedException {
    Thread u = new Thread(() -> usuario());
    Thread p = new Thread(() -> preparador());
    u.start();  // mesmo iniciando primeiro, o usuário espera
    p.start();
    u.join();
    p.join();

    for (String linha : log) {
        System.out.println(linha);
    }
}
```

```go
import (
	"fmt"
	"sync"
)

// contador inicial zero é um canal vazio: aqui receber espera o aviso e enviar avisa,
// o inverso do canal usado como limite de concorrência
var pronto = make(chan struct{}, 1)
var log []string

func usuario(wg *sync.WaitGroup) {
	defer wg.Done()
	<-pronto // espera o aviso
	log = append(log, "usuario: usando a conexao")
}

func preparador(wg *sync.WaitGroup) {
	defer wg.Done()
	log = append(log, "preparador: conexao aberta")
	pronto <- struct{}{} // avisa
}

func main() {
	var wg sync.WaitGroup
	wg.Add(2)
	go usuario(&wg) // mesmo iniciando primeiro, o usuário espera
	go preparador(&wg)
	wg.Wait()

	for _, linha := range log {
		fmt.Println(linha)
	}
}
```

## Semaphore vs. BoundedSemaphore

Como não há dono, um `release` a mais passa despercebido e o limite cresce silenciosamente. A versão limitada detecta o erro:

```python
import threading

comum = threading.Semaphore(2)
comum.release()  # bug: release sem acquire
livres = 0
while comum.acquire(blocking=False):
    livres += 1
print("Semaphore(2) depois de um release extra:", livres, "permissoes")

limitado = threading.BoundedSemaphore(2)
try:
    limitado.release()
except ValueError:
    print("BoundedSemaphore(2): release extra gera ValueError")
```

```text
Saída:
Semaphore(2) depois de um release extra: 3 permissoes
BoundedSemaphore(2): release extra gera ValueError
```

<Callout type="warning" title="Semáforo binário não é mutex">
Um semáforo com 1 permissão parece um lock, mas qualquer thread pode liberá-lo e ele não é reentrante. Para exclusão mútua, use um mutex: ele expressa a intenção e algumas implementações detectam liberação pela thread errada.
</Callout>

## Armadilhas

- **Esquecer o release** num caminho de erro vaza permissões até o sistema travar com contador zero. Use `with`, `try/finally` ou o equivalente da linguagem.
- **Semáforo não protege dados.** Ele limita quantos entram; se três threads entram e mexem na mesma estrutura, você ainda precisa de um lock para ela.
- **Adquirir vários semáforos** em ordens diferentes causa deadlock, assim como com locks.
- **Justiça.** Por padrão, não há garantia de que quem espera há mais tempo entra primeiro. Em Java, `new Semaphore(n, true)` dá ordem de chegada, com custo de throughput.
