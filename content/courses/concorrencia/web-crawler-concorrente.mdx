O crawler concorrente é um dos problemas de concorrência mais pedidos em entrevistas (no LeetCode ele aparece como "Web Crawler Multithreaded"). O enunciado típico: dada uma URL inicial e uma função `obter_links(url)` lenta, visite todas as páginas do mesmo domínio alcançáveis a partir dela, **sem visitar nenhuma duas vezes**, usando várias threads. É uma busca em largura num grafo que você só descobre enquanto anda, e em que cada aresta custa uma chamada de rede.

## Por que concorrência ajuda aqui

Quase todo o tempo de um crawler é espera: DNS, conexão, download. Uma thread sequencial que gasta 200 ms por página processa 5 páginas por segundo; com 20 requisições em voo, 100. Como o trabalho é limitado por I/O, threads funcionam bem mesmo em Python com GIL, e `asyncio` funciona ainda melhor para milhares de conexões.

## As três partes que precisam de cuidado

```text
            +-----------------+
 semente -> |  fronteira      |  fila de URLs a visitar
            |  (Queue)        |
            +--------+--------+
                     |  N trabalhadores
                     v
            obter_links(url)    <- lento, fora de qualquer lock
                     |
                     v
       visitados (set + lock): "testar e marcar" atômico
                     |
           novas URLs voltam para a fronteira
```

1. **Conjunto de visitados.** Testar `url in visitados` e depois `visitados.add(url)` em passos separados é uma condição de corrida clássica: duas threads veem a URL como nova e as duas a baixam. O teste e a marcação precisam acontecer na mesma seção crítica.
2. **Fronteira.** Uma fila thread-safe (`queue.Queue`, `LinkedBlockingQueue` em Java, um canal em Go) distribui trabalho entre as threads.
3. **Término.** Esta é a parte que derruba candidatos. "Fila vazia" não significa fim: uma thread pode estar no meio de um download que vai gerar dez URLs novas. O critério correto é **fila vazia e nenhum trabalho em andamento**. `Queue.join()` resolve isso contando tarefas: cada `put` incrementa, cada `task_done` decrementa, e `join` só retorna quando o contador zera.

```python
import queue
import threading
import time

WEB = {
    "http://loja.com/": ["http://loja.com/a", "http://loja.com/b", "http://blog.org/"],
    "http://loja.com/a": ["http://loja.com/b", "http://loja.com/c"],
    "http://loja.com/b": ["http://loja.com/", "http://loja.com/d"],
    "http://loja.com/c": ["http://loja.com/d", "http://loja.com/a"],
    "http://loja.com/d": [],
    "http://blog.org/": ["http://blog.org/x"],
}
DOMINIO = "http://loja.com/"
downloads = []
lock_downloads = threading.Lock()

def obter_links(url):
    time.sleep(0.02)  # simula latência de rede
    with lock_downloads:
        downloads.append(url)
    return WEB.get(url, [])

def rastrear(semente, num_threads=4):
    visitados = {semente}
    lock = threading.Lock()
    fronteira = queue.Queue()
    fronteira.put(semente)

    def trabalhador():
        while True:
            url = fronteira.get()
            if url is None:
                fronteira.task_done()
                return
            for link in obter_links(url):
                if not link.startswith(DOMINIO):
                    continue
                with lock:  # testar e marcar na mesma seção crítica
                    if link in visitados:
                        continue
                    visitados.add(link)
                fronteira.put(link)
            fronteira.task_done()

    threads = [threading.Thread(target=trabalhador) for _ in range(num_threads)]
    for t in threads:
        t.start()
    fronteira.join()          # espera fila vazia E nenhuma tarefa em andamento
    for _ in threads:
        fronteira.put(None)   # uma "pílula de veneno" por thread
    for t in threads:
        t.join()
    return visitados

resultado = rastrear("http://loja.com/")
for url in sorted(resultado):
    print(url)
print("downloads:", len(downloads), "| repetidos:", len(downloads) - len(set(downloads)))
```

```java
import java.util.*;
import java.util.concurrent.LinkedBlockingQueue;

static final Map<String, List<String>> WEB = Map.of(
    "http://loja.com/", List.of("http://loja.com/a", "http://loja.com/b", "http://blog.org/"),
    "http://loja.com/a", List.of("http://loja.com/b", "http://loja.com/c"),
    "http://loja.com/b", List.of("http://loja.com/", "http://loja.com/d"),
    "http://loja.com/c", List.of("http://loja.com/d", "http://loja.com/a"),
    "http://loja.com/d", List.of(),
    "http://blog.org/", List.of("http://blog.org/x")
);
static final String DOMINIO = "http://loja.com/";
static final String PILULA = "";  // a fila de Java não aceita null: a "pílula de veneno" é uma URL vazia
static final List<String> downloads = new ArrayList<>();
static final Object lockDownloads = new Object();

// LinkedBlockingQueue não tem join: um contador de tarefas pendentes faz o papel de task_done e join
static class Fronteira {
    private final LinkedBlockingQueue<String> fila = new LinkedBlockingQueue<>();
    private int pendentes = 0;

    synchronized void put(String url) {
        pendentes += 1;
        fila.add(url);
    }

    String get() throws InterruptedException {
        return fila.take();
    }

    synchronized void taskDone() {
        pendentes -= 1;
        if (pendentes == 0) notifyAll();
    }

    synchronized void join() throws InterruptedException {
        while (pendentes > 0) wait();
    }
}

static List<String> obterLinks(String url) throws InterruptedException {
    Thread.sleep(20);  // simula latência de rede
    synchronized (lockDownloads) {
        downloads.add(url);
    }
    return WEB.getOrDefault(url, List.of());
}

static Set<String> rastrear(String semente, int numThreads) throws InterruptedException {
    Set<String> visitados = new HashSet<>(Set.of(semente));
    Object lock = new Object();
    Fronteira fronteira = new Fronteira();
    fronteira.put(semente);

    Runnable trabalhador = () -> {
        try {
            while (true) {
                String url = fronteira.get();
                if (url.equals(PILULA)) {
                    fronteira.taskDone();
                    return;
                }
                for (String link : obterLinks(url)) {
                    if (!link.startsWith(DOMINIO)) continue;
                    synchronized (lock) {  // testar e marcar na mesma seção crítica
                        if (visitados.contains(link)) continue;
                        visitados.add(link);
                    }
                    fronteira.put(link);
                }
                fronteira.taskDone();
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    };

    List<Thread> threads = new ArrayList<>();
    for (int i = 0; i < numThreads; i++) threads.add(new Thread(trabalhador));
    for (Thread t : threads) t.start();
    fronteira.join();          // espera fila vazia E nenhuma tarefa em andamento
    for (int i = 0; i < numThreads; i++) fronteira.put(PILULA);   // uma "pílula de veneno" por thread
    for (Thread t : threads) t.join();
    return visitados;
}

public static void main(String[] args) throws InterruptedException {
    Set<String> resultado = rastrear("http://loja.com/", 4);
    for (String url : new TreeSet<>(resultado)) {
        System.out.println(url);
    }
    int repetidos = downloads.size() - new HashSet<>(downloads).size();
    System.out.println("downloads: " + downloads.size() + " | repetidos: " + repetidos);
}
```

```cpp
#include <chrono>
#include <condition_variable>
#include <deque>
#include <iostream>
#include <map>
#include <mutex>
#include <set>
#include <string>
#include <thread>
#include <vector>
using namespace std;

const map<string, vector<string>> WEB = {
    {"http://loja.com/", {"http://loja.com/a", "http://loja.com/b", "http://blog.org/"}},
    {"http://loja.com/a", {"http://loja.com/b", "http://loja.com/c"}},
    {"http://loja.com/b", {"http://loja.com/", "http://loja.com/d"}},
    {"http://loja.com/c", {"http://loja.com/d", "http://loja.com/a"}},
    {"http://loja.com/d", {}},
    {"http://blog.org/", {"http://blog.org/x"}},
};
const string DOMINIO = "http://loja.com/";
const string PILULA = "";  // a "pílula de veneno" é uma URL vazia
vector<string> downloads;
mutex lockDownloads;

// a biblioteca padrão não tem fila bloqueante: esta faz o papel de put, get, task_done e join
class Fronteira {
    deque<string> fila;
    int pendentes = 0;
    mutex m;
    condition_variable cond;

public:
    void put(const string& url) {
        lock_guard<mutex> guarda(m);
        fila.push_back(url);
        pendentes += 1;
        cond.notify_all();
    }

    string get() {
        unique_lock<mutex> guarda(m);
        while (fila.empty()) cond.wait(guarda);
        string url = fila.front();
        fila.pop_front();
        return url;
    }

    void taskDone() {
        lock_guard<mutex> guarda(m);
        pendentes -= 1;
        if (pendentes == 0) cond.notify_all();
    }

    void join() {
        unique_lock<mutex> guarda(m);
        while (pendentes > 0) cond.wait(guarda);
    }
};

vector<string> obterLinks(const string& url) {
    this_thread::sleep_for(chrono::milliseconds(20));  // simula latência de rede
    {
        lock_guard<mutex> guarda(lockDownloads);
        downloads.push_back(url);
    }
    auto it = WEB.find(url);
    return it == WEB.end() ? vector<string>{} : it->second;
}

set<string> rastrear(const string& semente, int numThreads = 4) {
    set<string> visitados = {semente};
    mutex lockVisitados;
    Fronteira fronteira;
    fronteira.put(semente);

    auto trabalhador = [&]() {
        while (true) {
            string url = fronteira.get();
            if (url == PILULA) {
                fronteira.taskDone();
                return;
            }
            for (const string& link : obterLinks(url)) {
                if (!link.starts_with(DOMINIO)) continue;
                {
                    lock_guard<mutex> guarda(lockVisitados);  // testar e marcar na mesma seção crítica
                    if (visitados.count(link)) continue;
                    visitados.insert(link);
                }
                fronteira.put(link);
            }
            fronteira.taskDone();
        }
    };

    vector<thread> threads;
    for (int i = 0; i < numThreads; i++) threads.emplace_back(trabalhador);
    fronteira.join();          // espera fila vazia E nenhuma tarefa em andamento
    for (int i = 0; i < numThreads; i++) fronteira.put(PILULA);   // uma "pílula de veneno" por thread
    for (auto& t : threads) t.join();
    return visitados;
}

int main() {
    set<string> resultado = rastrear("http://loja.com/");
    for (const string& url : resultado) {  // o set já mantém as URLs ordenadas
        cout << url << endl;
    }
    set<string> unicos(downloads.begin(), downloads.end());
    cout << "downloads: " << downloads.size() << " | repetidos: " << downloads.size() - unicos.size() << endl;
}
```

```csharp
using System.Collections.Generic;
using System.Threading;

static readonly Dictionary<string, string[]> WEB = new Dictionary<string, string[]>
{

    { "http://loja.com/c", new[] { "http://loja.com/d", "http://loja.com/a" } },
    { "http://loja.com/d", new string[0] },
    { "http://blog.org/", new[] { "http://blog.org/x" } },
};
const string DOMINIO = "http://loja.com/";
static readonly List<string> downloads = new List<string>();
static readonly object lockDownloads = new object();

// C# não tem uma fila com task_done e join: esta classe faz esse papel com Monitor
class Fronteira
{
    private readonly Queue<string> fila = new Queue<string>();
    private int pendentes = 0;

    public void Put(string url)
    {
        lock (fila)
        {
            fila.Enqueue(url);
            pendentes += 1;
            Monitor.PulseAll(fila);
        }
    }

    public string Get()
    {
        lock (fila)
        {
            while (fila.Count == 0)
                Monitor.Wait(fila);
            return fila.Dequeue();
        }
    }

    public void TaskDone()
    {
        lock (fila)
        {
            pendentes -= 1;
            if (pendentes == 0)
                Monitor.PulseAll(fila);
        }
    }

    public void Join()
    {
        lock (fila)
        {
            while (pendentes > 0)
                Monitor.Wait(fila);
        }
    }
}

static string[] ObterLinks(string url)
{
    Thread.Sleep(20);  // simula latência de rede
    lock (lockDownloads)
    {
        downloads.Add(url);
    }
    string[] links;
    return WEB.TryGetValue(url, out links) ? links : new string[0];
}

static HashSet<string> Rastrear(string semente, int numThreads = 4)
{
    var visitados = new HashSet<string> { semente };
    var lockVisitados = new object();
    var fronteira = new Fronteira();
    fronteira.Put(semente);

    ThreadStart trabalhador = () =>
    {
        while (true)
        {
            string url = fronteira.Get();
            if (url == null)
            {
                fronteira.TaskDone();
                return;
            }
            foreach (string link in ObterLinks(url))
            {
                if (!link.StartsWith(DOMINIO, StringComparison.Ordinal))
                    continue;
                lock (lockVisitados)  // testar e marcar na mesma seção crítica
                {
                    if (visitados.Contains(link))
                        continue;
                    visitados.Add(link);
                }
                fronteira.Put(link);
            }
            fronteira.TaskDone();
        }
    };

    var threads = new List<Thread>();
    for (int i = 0; i < numThreads; i++) threads.Add(new Thread(trabalhador));
    foreach (var t in threads) t.Start();
    fronteira.Join();          // espera fila vazia E nenhuma tarefa em andamento
    foreach (var t in threads) fronteira.Put(null);   // uma "pílula de veneno" por thread
    foreach (var t in threads) t.Join();
    return visitados;
}

static void Main()
{
    var resultado = new List<string>(Rastrear("http://loja.com/"));
    resultado.Sort(string.CompareOrdinal);
```

```go
import (
	"fmt"
	"sort"
	"strings"
	"sync"
	"time"
)

var WEB = map[string][]string{
	"http://loja.com/":  {"http://loja.com/a", "http://loja.com/b", "http://blog.org/"},
	"http://loja.com/a": {"http://loja.com/b", "http://loja.com/c"},
	"http://loja.com/b": {"http://loja.com/", "http://loja.com/d"},
	"http://loja.com/c": {"http://loja.com/d", "http://loja.com/a"},
	"http://loja.com/d": {},
	"http://blog.org/":  {"http://blog.org/x"},
}

const DOMINIO = "http://loja.com/"

var downloads []string
var lockDownloads sync.Mutex

func obterLinks(url string) []string {
	time.Sleep(20 * time.Millisecond) // simula latência de rede
	lockDownloads.Lock()
	downloads = append(downloads, url)
	lockDownloads.Unlock()
	return WEB[url]
}

func rastrear(semente string, numThreads int) map[string]bool {
	visitados := map[string]bool{semente: true}
	var lock sync.Mutex
	// Cada URL entra uma vez só, então len(WEB) lugares bastam e um envio nunca bloqueia.
	fronteira := make(chan string, len(WEB))
	var tarefas sync.WaitGroup // Add é o put, Done é o task_done, Wait é o join
	tarefas.Add(1)
	fronteira <- semente

	trabalhador := func(wg *sync.WaitGroup) {
		defer wg.Done()
		for url := range fronteira { // o laço termina quando o canal é fechado
			for _, link := range obterLinks(url) {
				if !strings.HasPrefix(link, DOMINIO) {
					continue
				}
				lock.Lock() // testar e marcar na mesma seção crítica
				if visitados[link] {
					lock.Unlock()
					continue
				}
				visitados[link] = true
				lock.Unlock()
				tarefas.Add(1)
				fronteira <- link
			}
			tarefas.Done()
		}
	}

	var wg sync.WaitGroup
	for i := 0; i < numThreads; i++ {
		wg.Add(1)
		go trabalhador(&wg)
	}
	tarefas.Wait()   // espera fila vazia E nenhuma tarefa em andamento
	close(fronteira) // em Go, fechar o canal substitui as "pílulas de veneno"
	wg.Wait()
	return visitados
}

func main() {
	resultado := rastrear("http://loja.com/", 4)
	urls := make([]string, 0, len(resultado))
	for url := range resultado {
		urls = append(urls, url)
	}
	sort.Strings(urls)
	for _, url := range urls {
		fmt.Println(url)
	}
	unicos := map[string]bool{}
	for _, url := range downloads {
		unicos[url] = true
	}
	fmt.Println("downloads:", len(downloads), "| repetidos:", len(downloads)-len(unicos))
}
```

A ordem de visita varia a cada execução, por isso o programa ordena antes de imprimir. O que nunca varia: cada página é baixada uma única vez, e o `blog.org` é ignorado por estar fora do domínio. Repare que `obter_links` roda **fora** do lock; se rodasse dentro, as quatro threads se revezariam e o crawler voltaria a ser sequencial.

## Versão com asyncio e limite de concorrência

Com `asyncio`, não há threads disputando o conjunto de visitados: entre dois `await` nenhuma outra corrotina roda, então testar e marcar já é atômico. O que você precisa controlar é **quantas requisições ficam em voo** ao mesmo tempo, para não derrubar o site nem esgotar sockets. Um `asyncio.Semaphore` faz isso.

```python
import asyncio

WEB = {
    "/": ["/a", "/b", "/c", "/d"],
    "/a": ["/e", "/f"], "/b": ["/g", "/h"], "/c": ["/a", "/i"], "/d": ["/j"],
    "/e": [], "/f": ["/"], "/g": [], "/h": [], "/i": [], "/j": ["/k"], "/k": [],
}
em_voo = 0
pico = 0

async def obter_links(url, limite):
    global em_voo, pico
    async with limite:
        em_voo += 1
        pico = max(pico, em_voo)
        await asyncio.sleep(0.02)
        em_voo -= 1
        return WEB.get(url, [])

async def rastrear(semente, max_simultaneas):
    limite = asyncio.Semaphore(max_simultaneas)
    visitados = {semente}
    nivel = [semente]
    while nivel:
        respostas = await asyncio.gather(*(obter_links(u, limite) for u in nivel))
        proximo = []
        for links in respostas:
            for link in links:
                if link not in visitados:  # seguro: não há await entre teste e marcação
                    visitados.add(link)
                    proximo.append(link)
        nivel = proximo
    return visitados

paginas = asyncio.run(rastrear("/", max_simultaneas=3))
print("paginas:", len(paginas), sorted(paginas))
print("respeitou o limite de 3:", pico <= 3)
```

```text
respeitou o limite de 3: True
```

<Callout type="warning" title="Contar 'fila vazia' não basta para terminar">
Se o trabalhador sair quando `fronteira.empty()` for verdadeiro, ele pode encerrar enquanto outro ainda está baixando uma página que geraria mais URLs. Use `Queue.join()` com `task_done()`, ou um contador de tarefas pendentes protegido por lock.
</Callout>

## Armadilhas e extensões

- **Visitados fora do lock:** gera downloads duplicados, às vezes muitos em sites com grafo denso.
- **Normalização de URL:** `/a`, `/a/` e `/a#topo` são a mesma página; normalize antes de marcar.
- **Politeness:** limite requisições por domínio, respeite `robots.txt` e use atraso entre acessos ao mesmo host.
- **Escala distribuída:** a fronteira vira uma fila persistente particionada por domínio, e o conjunto de visitados vai para um armazenamento compartilhado ou um filtro de Bloom.

## Na entrevista

Diga logo que é um BFS e que o gargalo é I/O, então threads ou `asyncio` servem. Destaque as três decisões: testar e marcar atômico, fronteira thread-safe e critério de término com contagem de tarefas. Follow-ups comuns: "como saber que terminou?" (fila vazia e zero tarefas em andamento) e "como evitar sobrecarregar o servidor alvo?" (semáforo global, limite por domínio e backoff).
