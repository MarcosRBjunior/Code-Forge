Um lock garante que só uma thread mexe no estado por vez, mas não resolve outra necessidade comum: **esperar até que o estado fique de um jeito específico**. O consumidor precisa esperar a fila ter algum item; o produtor precisa esperar haver espaço. A solução ingênua é ficar num laço testando a condição (*busy waiting*), o que queima CPU e, se você soltar e pegar o lock a cada volta, ainda disputa o lock com quem poderia mudar o estado.

A **variável de condição** é a primitiva feita para isso: ela permite que uma thread durma até ser avisada de que algo mudou, sem gastar CPU e sem segurar o lock enquanto dorme.

## Como funciona

Uma variável de condição sempre anda junto de um lock. O protocolo tem três operações:

- `wait()`: chamada **com o lock na mão**. Ela solta o lock e coloca a thread para dormir de forma atômica; ao acordar, a thread readquire o lock antes de retornar.
- `notify()`: acorda uma das threads que estão esperando.
- `notify_all()`: acorda todas.

```text
consumidor                         produtor
----------                         --------
lock.acquire()
while fila vazia:
    wait()  -- solta o lock, dorme
                                   lock.acquire()
                                   fila.append(x)
                                   notify()
                                   lock.release()
    (acorda, readquire o lock)
item = fila.pop()
lock.release()
```

A atomicidade de "soltar e dormir" é o ponto central. Se fossem dois passos separados, o produtor poderia notificar exatamente entre eles e o aviso se perderia: o consumidor dormiria para sempre esperando algo que já aconteceu (*lost wakeup*).

Em Python a primitiva é `threading.Condition`. Em Java, cada objeto tem `wait`/`notify` ligados ao `synchronized`, e `ReentrantLock.newCondition()` dá condições nomeadas com `await`/`signal`. Em C++ existe `std::condition_variable`, usada com `std::unique_lock<std::mutex>`, e em Go há `sync.Cond`, embora em Go canais costumem ser a escolha idiomática.

## Exemplo: fila limitada

O exemplo clássico é um buffer de capacidade fixa. O produtor espera enquanto está cheio; o consumidor espera enquanto está vazio.

<CodeTabs>

```python
import threading
from collections import deque

class FilaLimitada:
    def __init__(self, capacidade):
        self.itens = deque()
        self.capacidade = capacidade
        self.cond = threading.Condition()
        self.estourou = False

    def colocar(self, item):
        with self.cond:
            while len(self.itens) >= self.capacidade:
                self.cond.wait()
            self.itens.append(item)
            if len(self.itens) > self.capacidade:
                self.estourou = True
            self.cond.notify_all()

    def retirar(self):
        with self.cond:
            while not self.itens:
                self.cond.wait()
            item = self.itens.popleft()
            self.cond.notify_all()
            return item

fila = FilaLimitada(2)
consumidos = []

def produtor():
    for i in range(1, 7):
        fila.colocar(i)
    fila.colocar(None)  # sentinela: acabou

def consumidor():
    while True:
        item = fila.retirar()
        if item is None:
            break
        consumidos.append(item)

tp = threading.Thread(target=produtor)
tc = threading.Thread(target=consumidor)
tp.start()
tc.start()
tp.join()
tc.join()
print("consumidos:", consumidos)
print("passou da capacidade:", fila.estourou)
```

```java
import java.util.*;

static class FilaLimitada {
    // LinkedList aceita null, usado aqui como sentinela (ArrayDeque não aceita)
    private final LinkedList<Integer> itens = new LinkedList<>();
    private final int capacidade;
    boolean estourou = false;

    FilaLimitada(int capacidade) {
        this.capacidade = capacidade;
    }

    synchronized void colocar(Integer item) throws InterruptedException {
        while (itens.size() >= capacidade) {
            wait();
        }
        itens.addLast(item);
        if (itens.size() > capacidade) {
            estourou = true;
        }
        notifyAll();
    }

    synchronized Integer retirar() throws InterruptedException {
        while (itens.isEmpty()) {
            wait();
        }
        Integer item = itens.removeFirst();
        notifyAll();
        return item;
    }
}

static final FilaLimitada fila = new FilaLimitada(2);
static final List<Integer> consumidos = new ArrayList<>();

static void produtor() {
    try {
        for (int i = 1; i < 7; i++) {
            fila.colocar(i);
        }
        fila.colocar(null);  // sentinela: acabou
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    }
}

static void consumidor() {
    try {
        while (true) {
            Integer item = fila.retirar();
            if (item == null) {
                break;
            }
            consumidos.add(item);
        }
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    }
}

public static void main(String[] args) throws InterruptedException {
    Thread tp = new Thread(() -> produtor());
    Thread tc = new Thread(() -> consumidor());
    tp.start();
    tc.start();
    tp.join();
    tc.join();
    System.out.println("consumidos: " + consumidos);
    System.out.println("passou da capacidade: " + (fila.estourou ? "True" : "False"));
}
```

```cpp
#include <condition_variable>
#include <deque>
#include <iostream>
#include <mutex>
#include <optional>
#include <thread>
#include <vector>
using namespace std;

class FilaLimitada {
    deque<optional<int>> itens;
    size_t capacidade;
    mutex m;
    condition_variable cond;

public:
    bool estourou = false;

    explicit FilaLimitada(size_t capacidade) : capacidade(capacidade) {}

    void colocar(optional<int> item) {
        unique_lock<mutex> trava(m);
        while (itens.size() >= capacidade) {
            cond.wait(trava);
        }
        itens.push_back(item);
        if (itens.size() > capacidade) {
            estourou = true;
        }
        cond.notify_all();
    }

    optional<int> retirar() {
        unique_lock<mutex> trava(m);
        while (itens.empty()) {
            cond.wait(trava);
        }
        optional<int> item = itens.front();
        itens.pop_front();
        cond.notify_all();
        return item;
    }
};

FilaLimitada fila(2);
vector<int> consumidos;

void produtor() {
    for (int i = 1; i < 7; i++) {
        fila.colocar(i);
    }
    fila.colocar(nullopt);  // sentinela: acabou
}

void consumidor() {
    while (true) {
        optional<int> item = fila.retirar();
        if (!item) {
            break;
        }
        consumidos.push_back(*item);
    }
}

int main() {
    thread tp(produtor);
    thread tc(consumidor);
    tp.join();
    tc.join();
    cout << "consumidos: [";
    for (size_t i = 0; i < consumidos.size(); i++) {
        cout << (i ? ", " : "") << consumidos[i];
    }
    cout << "]" << endl;
    cout << "passou da capacidade: " << (fila.estourou ? "True" : "False") << endl;
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Threading;

class FilaLimitada
{
    private readonly Queue<int?> itens = new Queue<int?>();
    private readonly int capacidade;
    private readonly object cond = new object();
    public bool Estourou = false;

    public FilaLimitada(int capacidade)
    {
        this.capacidade = capacidade;
    }

    public void Colocar(int? item)
    {
        lock (cond)
        {
            while (itens.Count >= capacidade)
                Monitor.Wait(cond);
            itens.Enqueue(item);
            if (itens.Count > capacidade)
                Estourou = true;
            Monitor.PulseAll(cond);
        }
    }

    public int? Retirar()
    {
        lock (cond)
        {
            while (itens.Count == 0)
                Monitor.Wait(cond);
            int? item = itens.Dequeue();
            Monitor.PulseAll(cond);
            return item;
        }
    }
}

static readonly FilaLimitada fila = new FilaLimitada(2);
static readonly List<int> consumidos = new List<int>();

static void Produtor()
{
    for (int i = 1; i < 7; i++)
        fila.Colocar(i);
    fila.Colocar(null);  // sentinela: acabou
}

static void Consumidor()
{
    while (true)
    {
        int? item = fila.Retirar();
        if (item == null)
            break;
        consumidos.Add(item.Value);
    }
}

static void Main()
{
    var tp = new Thread(Produtor);
    var tc = new Thread(Consumidor);
    tp.Start();
    tc.Start();
    tp.Join();
    tc.Join();
    Console.WriteLine("consumidos: [" + string.Join(", ", consumidos) + "]");
```

```go
import (
	"fmt"
	"sync"
)

type FilaLimitada struct {
	itens      []*int // nil é a sentinela (o None do Python)
	capacidade int
	mu         sync.Mutex
	cond       *sync.Cond
	estourou   bool
}

func NovaFilaLimitada(capacidade int) *FilaLimitada {
	f := &FilaLimitada{capacidade: capacidade}
	f.cond = sync.NewCond(&f.mu)
	return f
}

func (f *FilaLimitada) colocar(item *int) {
	f.mu.Lock()
	defer f.mu.Unlock()
	for len(f.itens) >= f.capacidade { // for é o "while" do Go
		f.cond.Wait()
	}
	f.itens = append(f.itens, item)
	if len(f.itens) > f.capacidade {
		f.estourou = true
	}
	f.cond.Broadcast()
}

func (f *FilaLimitada) retirar() *int {
	f.mu.Lock()
	defer f.mu.Unlock()
	for len(f.itens) == 0 {
		f.cond.Wait()
	}
	item := f.itens[0]
	f.itens = f.itens[1:]
	f.cond.Broadcast()
	return item
}

var fila = NovaFilaLimitada(2)
var consumidos []int

func produtor(wg *sync.WaitGroup) {
	defer wg.Done()
	for i := 1; i < 7; i++ {
		item := i
		fila.colocar(&item)
	}
	fila.colocar(nil) // sentinela: acabou
}

func consumidor(wg *sync.WaitGroup) {
	defer wg.Done()
	for {
		item := fila.retirar()
		if item == nil {
			break
		}
		consumidos = append(consumidos, *item)
	}
}

func main() {
	var wg sync.WaitGroup
	wg.Add(2)
	go produtor(&wg)
	go consumidor(&wg)
	wg.Wait()
	fmt.Println("consumidos:", consumidos)
	if fila.estourou {
		fmt.Println("passou da capacidade: True")
	} else {
		fmt.Println("passou da capacidade: False")
	}
}
```

## Esperar por um predicado

`Condition.wait_for(predicado, timeout)` encapsula o laço para você e devolve o valor final do predicado, o que deixa claro se você acordou porque a condição ficou verdadeira ou porque o tempo acabou.

<CodeTabs>

```python
import threading

cond = threading.Condition()
liberado = False
resultados = []

def trabalhador(n):
    with cond:
        cond.wait_for(lambda: liberado)
        resultados.append(n * n)

threads = [threading.Thread(target=trabalhador, args=(n,)) for n in range(1, 4)]
for t in threads:
    t.start()

with cond:
    liberado = True
    cond.notify_all()

for t in threads:
    t.join()
print("resultados:", sorted(resultados))

with cond:
    ok = cond.wait_for(lambda: False, timeout=0.1)
print("condicao satisfeita antes do timeout:", ok)
```

```java
import java.util.*;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;
import java.util.function.BooleanSupplier;

static final ReentrantLock trava = new ReentrantLock();
static final Condition cond = trava.newCondition();
static boolean liberado = false;
static final List<Integer> resultados = new ArrayList<>();

// Java não tem wait_for: este laço faz o mesmo e devolve o valor final do predicado
static boolean esperarPor(BooleanSupplier predicado, long timeoutMs) throws InterruptedException {
    long restante = TimeUnit.MILLISECONDS.toNanos(timeoutMs);
    while (!predicado.getAsBoolean()) {
        if (restante <= 0) {
            return false;
        }
        restante = cond.awaitNanos(restante);
    }
    return true;
}

static void trabalhador(int n) {
    trava.lock();
    try {
        while (!liberado) {
            cond.await();
        }
        resultados.add(n * n);
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    } finally {
        trava.unlock();
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> threads = new ArrayList<>();
    for (int n = 1; n < 4; n++) {
        int k = n;
        threads.add(new Thread(() -> trabalhador(k)));
    }
    for (Thread t : threads) t.start();

    trava.lock();
    try {
        liberado = true;
        cond.signalAll();
    } finally {
        trava.unlock();
    }

    for (Thread t : threads) t.join();
    Collections.sort(resultados);
    System.out.println("resultados: " + resultados);

    boolean ok;
    trava.lock();
    try {
        ok = esperarPor(() -> false, 100);
    } finally {
        trava.unlock();
    }
    System.out.println("condicao satisfeita antes do timeout: " + (ok ? "True" : "False"));
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.Threading;

static readonly object cond = new object();
static bool liberado = false;
static readonly List<int> resultados = new List<int>();

// C# não tem wait_for: este laço faz o mesmo e devolve o valor final do predicado
static bool EsperarPor(Func<bool> predicado, int timeoutMs)
{
    var relogio = Stopwatch.StartNew();
    while (!predicado())
    {
        int restante = timeoutMs - (int)relogio.ElapsedMilliseconds;
        if (restante <= 0)
            return false;
        Monitor.Wait(cond, restante);
    }
    return true;
}

static void Trabalhador(int n)
{
    lock (cond)
    {
        while (!liberado)
            Monitor.Wait(cond);
        resultados.Add(n * n);
    }
}

static void Main()
{
    var threads = new List<Thread>();
    for (int n = 1; n < 4; n++)
    {
        int k = n;
        threads.Add(new Thread(() => Trabalhador(k)));
    }
    foreach (var t in threads) t.Start();

    lock (cond)
    {
        liberado = true;
        Monitor.PulseAll(cond);
    }

    foreach (var t in threads) t.Join();
    resultados.Sort();
    Console.WriteLine("resultados: [" + string.Join(", ", resultados) + "]");

    bool ok;
    lock (cond)
    {
        ok = EsperarPor(() => false, 100);
    }
    Console.WriteLine("condicao satisfeita antes do timeout: " + (ok ? "True" : "False"));
}
```

```go
import (
	"fmt"
	"sort"
	"sync"
	"time"
)

var mu sync.Mutex
var cond = sync.NewCond(&mu)
var liberado = false
var resultados []int

func trabalhador(n int, wg *sync.WaitGroup) {
	defer wg.Done()
	mu.Lock()
	defer mu.Unlock()
	for !liberado { // sync.Cond não tem wait_for: o laço é escrito à mão
		cond.Wait()
	}
	resultados = append(resultados, n*n)
}

func main() {
	var wg sync.WaitGroup
	for n := 1; n < 4; n++ {
		wg.Add(1)
		go trabalhador(n, &wg)
	}

	mu.Lock()
	liberado = true
	cond.Broadcast()
	mu.Unlock()

	wg.Wait()
	sort.Ints(resultados)
	fmt.Println("resultados:", resultados)

	// sync.Cond não tem espera com prazo. O equivalente é trocar a condição por um canal
	// (fechado por quem torna o predicado verdadeiro; aqui ninguém fecha) e usar select.
	satisfeita := make(chan struct{})
	var ok bool
	select {
	case <-satisfeita:
		ok = true
	case <-time.After(100 * time.Millisecond):
		ok = false
	}
	if ok {
		fmt.Println("condicao satisfeita antes do timeout: True")
	} else {
		fmt.Println("condicao satisfeita antes do timeout: False")
	}
}
```

## Armadilhas

- **Testar com `if` em vez de `while`.** Uma thread pode acordar sem que ninguém tenha notificado (*spurious wakeup*, permitido por POSIX e pela JVM) ou ser acordada e perder a corrida para outra thread que consumiu o item antes. Sempre reteste a condição depois de acordar.
- **Mudar o estado sem o lock.** Se o produtor altera a fila fora do lock e notifica, o consumidor pode testar a condição, ver falso e dormir logo depois do aviso.
- **`notify` quando havia vários tipos de espera.** Com uma condição só servindo produtores e consumidores, `notify()` pode acordar outro produtor, que volta a dormir, e o consumidor certo nunca acorda. Use `notify_all()` ou duas condições separadas (`nao_cheia` e `nao_vazia`) sobre o mesmo lock.
- **Esquecer que `wait` exige o lock.** Chamar `wait()` sem segurá-lo gera erro em Python (`RuntimeError`) e em Java (`IllegalMonitorStateException`).

<Callout type="tip" title="Regra de bolso">
Lock na mão, laço `while` testando o predicado, `wait` dentro do laço, e quem muda o estado notifica ainda segurando o lock.
</Callout>
