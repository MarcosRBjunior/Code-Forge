"Implemente um cache LRU" é clássico de entrevista. A versão concorrente acrescenta a pergunta que separa candidatos: "e se várias threads usarem esse cache ao mesmo tempo?". A resposta curta (ponha um lock em volta) está certa, mas o entrevistador quer ver se você entende **por que** o LRU é difícil de paralelizar, quanto isso custa e quais saídas existem quando o lock único vira gargalo.

## Por que até o get escreve

Um LRU combina um mapa (chave para nó) com uma lista duplamente ligada em ordem de uso. O detalhe que muda tudo: **toda leitura altera a lista**, porque o item lido precisa ir para a frente. Ou seja, `get` não é uma operação só de leitura, e um lock de leitura e escrita não ajuda. Duas threads fazendo `get` ao mesmo tempo podem corromper os ponteiros da lista se não houver exclusão mútua.

```text
get(b):   [a] <-> [b] <-> [c]      mover b para a frente
          ^cabeça        ^cauda    (4 ponteiros mudam)

put(d) cheio:  remove a cauda (c) e insere d na cabeça
```

Cada operação mexe em vários ponteiros e no mapa. Se uma thread for interrompida no meio, outra vê um estado intermediário: nó no mapa mas fora da lista, ou lista com ciclo. Por isso a seção crítica precisa cobrir mapa e lista juntos.

## Versão 1: um lock para tudo

Em Python, `OrderedDict` já faz o papel de mapa mais lista: `move_to_end` promove a chave e `popitem(last=False)` remove a mais antiga. Basta proteger tudo com um `threading.Lock`.

<CodeTabs>

```python
import threading
from collections import OrderedDict

class LRUConcorrente:
    def __init__(self, capacidade):
        self.capacidade = capacidade
        self.dados = OrderedDict()
        self.lock = threading.Lock()
        self.acertos = 0
        self.falhas = 0

    def get(self, chave):
        with self.lock:
            if chave not in self.dados:
                self.falhas += 1
                return None
            self.dados.move_to_end(chave)
            self.acertos += 1
            return self.dados[chave]

    def put(self, chave, valor):
        with self.lock:
            self.dados[chave] = valor
            self.dados.move_to_end(chave)
            if len(self.dados) > self.capacidade:
                self.dados.popitem(last=False)

cache = LRUConcorrente(capacidade=100)

def trabalhador(base):
    for i in range(1000):
        chave = (base + i) % 150
        if cache.get(chave) is None:
            cache.put(chave, chave * 10)

threads = [threading.Thread(target=trabalhador, args=(k * 37,)) for k in range(8)]
for t in threads:
    t.start()
for t in threads:
    t.join()

print("itens no cache:", len(cache.dados))
print("operacoes de get:", cache.acertos + cache.falhas)
print("valores consistentes:", all(v == k * 10 for k, v in cache.dados.items()))
```

```java
import java.util.*;

class LRUConcorrente {
    final int capacidade;
    final Map<Integer, Integer> dados;
    private final Object lock = new Object();
    int acertos = 0;
    int falhas = 0;

    LRUConcorrente(int capacidade) {
        this.capacidade = capacidade;
        // accessOrder = true: todo get move a chave para o fim, como o move_to_end do Python
        this.dados = new LinkedHashMap<>(16, 0.75f, true) {
            @Override
            protected boolean removeEldestEntry(Map.Entry<Integer, Integer> maisAntiga) {
                return size() > LRUConcorrente.this.capacidade;
            }
        };
    }

    Integer get(int chave) {
        synchronized (lock) {
            if (!dados.containsKey(chave)) {
                falhas += 1;
                return null;
            }
            acertos += 1;
            return dados.get(chave);
        }
    }

    void put(int chave, int valor) {
        synchronized (lock) {
            dados.put(chave, valor);
        }
    }
}

static final LRUConcorrente cache = new LRUConcorrente(100);

static void trabalhador(int base) {
    for (int i = 0; i < 1000; i++) {
        int chave = (base + i) % 150;
        if (cache.get(chave) == null) {
            cache.put(chave, chave * 10);
        }
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> threads = new ArrayList<>();
    for (int k = 0; k < 8; k++) {
        final int base = k * 37;
        threads.add(new Thread(() -> trabalhador(base)));
    }
    for (Thread t : threads) t.start();
    for (Thread t : threads) t.join();

    System.out.println("itens no cache: " + cache.dados.size());
    System.out.println("operacoes de get: " + (cache.acertos + cache.falhas));
    boolean consistentes = cache.dados.entrySet().stream().allMatch(e -> e.getValue() == e.getKey() * 10);
    System.out.println("valores consistentes: " + (consistentes ? "True" : "False"));
}
```

```cpp
#include <iostream>
#include <list>
#include <mutex>
#include <optional>
#include <thread>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

class LRUConcorrente {
public:
    int capacidade;
    list<pair<int, int>> dados;   // lista dupla: a frente é o mais antigo, o fim é o mais recente
    unordered_map<int, list<pair<int, int>>::iterator> posicao;   // chave para nó
    mutex trava;
    int acertos = 0;
    int falhas = 0;

    LRUConcorrente(int capacidade) : capacidade(capacidade) {}

    optional<int> get(int chave) {
        lock_guard<mutex> guarda(trava);
        auto achado = posicao.find(chave);
        if (achado == posicao.end()) {
            falhas += 1;
            return nullopt;
        }
        dados.splice(dados.end(), dados, achado->second);   // move_to_end: muda só ponteiros
        acertos += 1;
        return achado->second->second;
    }

    void put(int chave, int valor) {
        lock_guard<mutex> guarda(trava);
        auto achado = posicao.find(chave);
        if (achado != posicao.end()) {
            achado->second->second = valor;
            dados.splice(dados.end(), dados, achado->second);
            return;
        }
        dados.push_back({chave, valor});
        posicao[chave] = prev(dados.end());
        if ((int)dados.size() > capacidade) {
            posicao.erase(dados.front().first);
            dados.pop_front();
        }
    }
};

LRUConcorrente cache_lru(100);

void trabalhador(int base) {
    for (int i = 0; i < 1000; i++) {
        int chave = (base + i) % 150;
        if (!cache_lru.get(chave)) {
            cache_lru.put(chave, chave * 10);
        }
    }
}

int main() {
    vector<thread> threads;
    for (int k = 0; k < 8; k++) threads.emplace_back(trabalhador, k * 37);
    for (auto& t : threads) t.join();

    cout << "itens no cache: " << cache_lru.dados.size() << endl;
    cout << "operacoes de get: " << cache_lru.acertos + cache_lru.falhas << endl;
    bool consistentes = true;
    for (auto& [k, v] : cache_lru.dados) {
        if (v != k * 10) consistentes = false;
    }
    cout << "valores consistentes: " << (consistentes ? "True" : "False") << endl;
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading;

class Item
{
    public int Chave;
    public int Valor;
}

class LRUConcorrente
{
    readonly int capacidade;
    public readonly LinkedList<Item> Dados = new LinkedList<Item>();   // a frente é o mais antigo, o fim é o mais recente
    readonly Dictionary<int, LinkedListNode<Item>> posicao = new Dictionary<int, LinkedListNode<Item>>();   // chave para nó
    readonly object trava = new object();
    public int Acertos = 0;
    public int Falhas = 0;

    public LRUConcorrente(int capacidade)
    {
        this.capacidade = capacidade;
    }

    public int? Get(int chave)
    {
        lock (trava)
        {
            LinkedListNode<Item> no;
            if (!posicao.TryGetValue(chave, out no))
            {
                Falhas += 1;
                return null;
            }
            Dados.Remove(no);
            Dados.AddLast(no);    // move_to_end: muda só ponteiros
            Acertos += 1;
            return no.Value.Valor;
        }
    }

    public void Put(int chave, int valor)
    {
        lock (trava)
        {
            LinkedListNode<Item> no;
            if (posicao.TryGetValue(chave, out no))
            {
                no.Value.Valor = valor;
                Dados.Remove(no);
                Dados.AddLast(no);
                return;
            }
            posicao[chave] = Dados.AddLast(new Item { Chave = chave, Valor = valor });
            if (Dados.Count > capacidade)
            {
                posicao.Remove(Dados.First.Value.Chave);
                Dados.RemoveFirst();
            }
        }
    }
}

static readonly LRUConcorrente cache = new LRUConcorrente(100);

static void Trabalhador(int inicio)
{
    for (int i = 0; i < 1000; i++)
    {
        int chave = (inicio + i) % 150;
        if (cache.Get(chave) == null)
        {
            cache.Put(chave, chave * 10);
        }
    }
}

static void Main()
{
    var threads = new List<Thread>();
    for (int k = 0; k < 8; k++)
    {
        int deslocamento = k * 37;
        threads.Add(new Thread(() => Trabalhador(deslocamento)));
    }
    foreach (Thread t in threads) t.Start();
    foreach (Thread t in threads) t.Join();

    Console.WriteLine("itens no cache: " + cache.Dados.Count);
    Console.WriteLine("operacoes de get: " + (cache.Acertos + cache.Falhas));
    Console.WriteLine("valores consistentes: " + cache.Dados.All(item => item.Valor == item.Chave * 10));
}
```

```go
import (
	"container/list"
	"fmt"
	"sync"
)

type Item struct {
	chave, valor int
}

type LRUConcorrente struct {
	capacidade int
	dados      map[int]*list.Element // chave para nó
	ordem      *list.List            // a frente é o mais antigo, o fim é o mais recente
	mu         sync.Mutex
	acertos    int
	falhas     int
}

func novoLRU(capacidade int) *LRUConcorrente {
	return &LRUConcorrente{capacidade: capacidade, dados: map[int]*list.Element{}, ordem: list.New()}
}

func (c *LRUConcorrente) get(chave int) (int, bool) {
	c.mu.Lock()
	defer c.mu.Unlock()
	no, existe := c.dados[chave]
	if !existe {
		c.falhas += 1
		return 0, false
	}
	c.ordem.MoveToBack(no) // move_to_end: muda só ponteiros
	c.acertos += 1
	return no.Value.(*Item).valor, true
}

func (c *LRUConcorrente) put(chave, valor int) {
	c.mu.Lock()
	defer c.mu.Unlock()
	if no, existe := c.dados[chave]; existe {
		no.Value.(*Item).valor = valor
		c.ordem.MoveToBack(no)
		return
	}
	c.dados[chave] = c.ordem.PushBack(&Item{chave, valor})
	if len(c.dados) > c.capacidade {
		maisAntigo := c.ordem.Front()
		c.ordem.Remove(maisAntigo)
		delete(c.dados, maisAntigo.Value.(*Item).chave)
	}
}

var cache = novoLRU(100)

func trabalhador(base int, wg *sync.WaitGroup) {
	defer wg.Done()
	for i := 0; i < 1000; i++ {
		chave := (base + i) % 150
		if _, achou := cache.get(chave); !achou {
			cache.put(chave, chave*10)
		}
	}
}

func main() {
	var wg sync.WaitGroup
	for k := 0; k < 8; k++ {
		wg.Add(1)
		go trabalhador(k*37, &wg)
	}
	wg.Wait()

	fmt.Println("itens no cache:", len(cache.dados))
	fmt.Println("operacoes de get:", cache.acertos+cache.falhas)
	consistentes := true
	for k, no := range cache.dados {
		if no.Value.(*Item).valor != k*10 {
			consistentes = false
		}
	}
	if consistentes {
		fmt.Println("valores consistentes: True")
	} else {
		fmt.Println("valores consistentes: False")
	}
}
```

Repare que os contadores `acertos` e `falhas` também ficam dentro do lock. Quantos acertos houve depende do escalonamento, por isso o programa imprime só a soma, que é sempre 8000. Em Java a solução equivalente é um `LinkedHashMap` com `accessOrder = true` envolvido em `synchronized`; em Go, um `map` mais `container/list` protegidos por `sync.Mutex`.

## Quando o lock único vira gargalo

Com dezenas de núcleos e milhões de leituras por segundo, todas as threads disputam o mesmo lock. As saídas mais citadas:

| Técnica | Ideia | Custo |
| --- | --- | --- |
| Striping (shards) | N caches LRU independentes, escolhidos por `hash(chave) % N` | LRU vira aproximado: cada shard expulsa só os seus |
| Buffer de leituras | `get` registra o acesso numa fila e a reordenação é aplicada em lote | A ordem fica alguns instantes atrasada |
| LRU aproximado | Bit de "usado recentemente" (CLOCK) em vez de lista | Expulsão menos precisa, leitura quase sem lock |
| Mapa concorrente + TTL | Abrir mão de LRU estrito | Política diferente da pedida |

O Caffeine (Java) combina buffers de leitura com uma política mais esperta que LRU, e o `ConcurrentHashMap` usa a ideia de dividir o lock por regiões. Em entrevista, striping é a resposta mais fácil de justificar: você troca precisão global por contenção dividida por N.

## Evitando o estouro de cache (single flight)

Outro problema real: a chave mais popular expira e 50 threads dão `miss` ao mesmo tempo. Todas vão ao banco calcular o mesmo valor. A correção é registrar, sob o lock, que alguém **já está carregando** aquela chave; as outras esperam o resultado em vez de repetir o trabalho.

<CodeTabs>

```python
import threading
from concurrent.futures import Future

class CacheComCarga:
    def __init__(self, carregar):
        self.carregar = carregar
        self.lock = threading.Lock()
        self.valores = {}
        self.em_andamento = {}
        self.chamadas = 0

    def get(self, chave):
        with self.lock:
            if chave in self.valores:
                return self.valores[chave]
            futuro = self.em_andamento.get(chave)
            dono = futuro is None
            if dono:
                futuro = Future()
                self.em_andamento[chave] = futuro
                self.chamadas += 1
        if dono:
            valor = self.carregar(chave)  # fora do lock: outras chaves seguem livres
            with self.lock:
                self.valores[chave] = valor
                del self.em_andamento[chave]
            futuro.set_result(valor)
        return futuro.result()

cache = CacheComCarga(lambda chave: chave.upper())
resultados = []
lock_resultados = threading.Lock()

def cliente():
    valor = cache.get("usuario:42")
    with lock_resultados:
        resultados.append(valor)

threads = [threading.Thread(target=cliente) for _ in range(20)]
for t in threads:
    t.start()
for t in threads:
    t.join()

print("respostas:", len(resultados), sorted(set(resultados)))
print("vezes que o banco foi consultado:", cache.chamadas)
```

```java
import java.util.*;
import java.util.concurrent.*;
import java.util.function.*;

class CacheComCarga {
    private final Function<String, String> carregar;
    private final Object lock = new Object();
    private final Map<String, String> valores = new HashMap<>();
    private final Map<String, CompletableFuture<String>> emAndamento = new HashMap<>();
    int chamadas = 0;

    CacheComCarga(Function<String, String> carregar) {
        this.carregar = carregar;
    }

    String get(String chave) {
        CompletableFuture<String> futuro;
        boolean dono;
        synchronized (lock) {
            if (valores.containsKey(chave)) {
                return valores.get(chave);
            }
            futuro = emAndamento.get(chave);
            dono = futuro == null;
            if (dono) {
                futuro = new CompletableFuture<>();
                emAndamento.put(chave, futuro);
                chamadas += 1;
            }
        }
        if (dono) {
            String valor = carregar.apply(chave);  // fora do lock: outras chaves seguem livres
            synchronized (lock) {
                valores.put(chave, valor);
                emAndamento.remove(chave);
            }
            futuro.complete(valor);
        }
        return futuro.join();
    }
}

static final CacheComCarga cache = new CacheComCarga(chave -> chave.toUpperCase());
static final List<String> resultados = new ArrayList<>();
static final Object lockResultados = new Object();

static void cliente() {
    String valor = cache.get("usuario:42");
    synchronized (lockResultados) {
        resultados.add(valor);
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> threads = new ArrayList<>();
    for (int i = 0; i < 20; i++) threads.add(new Thread(() -> cliente()));
    for (Thread t : threads) t.start();
    for (Thread t : threads) t.join();

    System.out.println("respostas: " + resultados.size() + " " + new TreeSet<>(resultados));
    System.out.println("vezes que o banco foi consultado: " + cache.chamadas);
}
```

```cpp
            promessa.set_value(valor);
        }
```

```csharp
using System;
using System.Collections.Generic;
using System.Threading;
using System.Threading.Tasks;

class CacheComCarga
{
    readonly Func<string, string> carregar;
    readonly object trava = new object();
    readonly Dictionary<string, string> valores = new Dictionary<string, string>();
    readonly Dictionary<string, TaskCompletionSource<string>> emAndamento = new Dictionary<string, TaskCompletionSource<string>>();
    public int Chamadas = 0;

    public CacheComCarga(Func<string, string> carregar)
    {
        this.carregar = carregar;
    }

    public string Get(string chave)
    {
        TaskCompletionSource<string> futuro;
        bool dono;
        lock (trava)
        {
            string pronto;
            if (valores.TryGetValue(chave, out pronto))
            {
                return pronto;
            }
            dono = !emAndamento.TryGetValue(chave, out futuro);
            if (dono)
            {
                futuro = new TaskCompletionSource<string>();
                emAndamento[chave] = futuro;
                Chamadas += 1;
            }
        }
        if (dono)
        {
            string valor = carregar(chave);  // fora do lock: outras chaves seguem livres
            lock (trava)
            {
                valores[chave] = valor;
                emAndamento.Remove(chave);
            }
            futuro.SetResult(valor);
        }
        return futuro.Task.Result;
    }
}

static readonly CacheComCarga cache = new CacheComCarga(chave => chave.ToUpperInvariant());
static readonly List<string> resultados = new List<string>();
static readonly object lockResultados = new object();

static void Cliente()
{
    string valor = cache.Get("usuario:42");
    lock (lockResultados)
    {
        resultados.Add(valor);
    }
}

static void Main()
{
    var threads = new List<Thread>();
    for (int i = 0; i < 20; i++) threads.Add(new Thread(Cliente));
    foreach (Thread t in threads) t.Start();
    foreach (Thread t in threads) t.Join();

    var unicos = new SortedSet<string>(resultados, StringComparer.Ordinal);
    Console.WriteLine("respostas: " + resultados.Count + " [" + string.Join(", ", unicos) + "]");
    Console.WriteLine("vezes que o banco foi consultado: " + cache.Chamadas);
}
```

```go
import (
	"fmt"
	"sort"
	"strings"
	"sync"
)

// Go não tem future: fechar o canal avisa todas as goroutines que esperam (como o pacote singleflight faz por dentro)
type Carga struct {
	pronto chan struct{}
	valor  string
}

type CacheComCarga struct {
	carregar    func(string) string
	mu          sync.Mutex
	valores     map[string]string
	emAndamento map[string]*Carga
	chamadas    int
}

func novoCache(carregar func(string) string) *CacheComCarga {
	return &CacheComCarga{carregar: carregar, valores: map[string]string{}, emAndamento: map[string]*Carga{}}
}

func (c *CacheComCarga) get(chave string) string {
	c.mu.Lock()
	if valor, existe := c.valores[chave]; existe {
		c.mu.Unlock()
		return valor
	}
	futuro, emCurso := c.emAndamento[chave]
	dono := !emCurso
	if dono {
		futuro = &Carga{pronto: make(chan struct{})}
		c.emAndamento[chave] = futuro
		c.chamadas += 1
	}
	c.mu.Unlock()
	if dono {
		valor := c.carregar(chave) // fora do lock: outras chaves seguem livres
		c.mu.Lock()
		c.valores[chave] = valor
		delete(c.emAndamento, chave)
		c.mu.Unlock()
		futuro.valor = valor
		close(futuro.pronto)
	}
	<-futuro.pronto
	return futuro.valor
}

var cache = novoCache(strings.ToUpper)
var resultados = []string{}
var lockResultados sync.Mutex

func cliente(wg *sync.WaitGroup) {
	defer wg.Done()
	valor := cache.get("usuario:42")
	lockResultados.Lock()
	defer lockResultados.Unlock()
	resultados = append(resultados, valor)
}

func main() {
	var wg sync.WaitGroup
	for i := 0; i < 20; i++ {
		wg.Add(1)
		go cliente(&wg)
	}
	wg.Wait()

	unicos := map[string]bool{}
	for _, r := range resultados {
		unicos[r] = true
	}
	lista := []string{}
	for r := range unicos {
		lista = append(lista, r)
	}
	sort.Strings(lista)
	fmt.Println("respostas:", len(resultados), lista)
	fmt.Println("vezes que o banco foi consultado:", cache.chamadas)
}
```

Dois detalhes importam. Primeiro, a carga lenta acontece **fora** do lock global; segurá-lo durante uma consulta ao banco travaria o cache inteiro. Segundo, quem chega depois espera num `Future`, não num laço de espera ativa. Em Go isso existe pronto no pacote `singleflight`; em Java, `ConcurrentHashMap.computeIfAbsent` dá um efeito parecido por chave.

<Callout type="warning" title="Não chame código externo segurando o lock">
Carregar do banco, chamar um callback de expulsão ou fazer log síncrono dentro da seção crítica aumenta a contenção e abre espaço para deadlock se esse código tentar usar o cache de novo.
</Callout>

## Armadilhas

- **Lock de leitura e escrita no LRU:** não funciona, porque `get` também reordena a lista.
- **Verificar e depois inserir em duas seções críticas** separadas: entre elas, outra thread insere a mesma chave.
- **Esquecer de remover a entrada de "em andamento" quando a carga falha**: as próximas threads esperam para sempre. Em produção, use `set_exception` e remova a chave num `finally`.

## Na entrevista

Comece pelo LRU sequencial (mapa mais lista dupla, tudo O(1)), mostre o lock único e explique por que leituras também precisam dele. Depois proponha melhorias guiadas por números: "se o perfil mostrar contenção, divido em 16 shards". Follow-ups comuns: "como evitar que muitas threads recalculem a mesma chave?" (single flight com futuro por chave) e "o LRU continua exato com shards?" (não, cada shard decide sozinho, o que costuma ser aceitável).
