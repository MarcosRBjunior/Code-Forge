Muitos dados compartilhados são lidos o tempo todo e alterados raramente: configuração carregada em memória, tabela de roteamento, catálogo de produtos, cache de permissões. Proteger isso com um mutex comum funciona, mas desperdiça paralelismo, porque duas leituras simultâneas nunca se atrapalham. O **lock de leitura e escrita** (read-write lock) explora essa assimetria: vários leitores podem entrar ao mesmo tempo, mas um escritor precisa de acesso exclusivo.

## As regras

```text
                    já tem leitores    já tem escritor
novo leitor         entra              espera
novo escritor       espera             espera
```

Em Java você usa `ReentrantReadWriteLock` (com `readLock()` e `writeLock()`) ou `StampedLock`, que acrescenta leitura otimista. Em Go, `sync.RWMutex` com `RLock`/`RUnlock` e `Lock`/`Unlock`. Em C++, `std::shared_mutex` com `std::shared_lock` para leitura e `std::unique_lock` para escrita. Python não traz um na biblioteca padrão, então ele é uma ótima oportunidade de mostrar que você sabe construir um a partir de uma variável de condição.

## Implementação com preferência para escritores

A versão abaixo conta leitores ativos, marca se há escritor e também conta escritores **esperando**. Novos leitores não entram enquanto houver escritor na fila, o que evita que um fluxo contínuo de leituras deixe a escrita esperando para sempre.

```python
import threading

class RWLock:
    def __init__(self):
        self._cond = threading.Condition()
        self._leitores = 0
        self._escrevendo = False
        self._escritores_esperando = 0

    def adquirir_leitura(self):
        with self._cond:
            while self._escrevendo or self._escritores_esperando > 0:
                self._cond.wait()
            self._leitores += 1

    def liberar_leitura(self):
        with self._cond:
            self._leitores -= 1
            if self._leitores == 0:
                self._cond.notify_all()

    def adquirir_escrita(self):
        with self._cond:
            self._escritores_esperando += 1
            while self._escrevendo or self._leitores > 0:
                self._cond.wait()
            self._escritores_esperando -= 1
            self._escrevendo = True

    def liberar_escrita(self):
        with self._cond:
            self._escrevendo = False
            self._cond.notify_all()

rw = RWLock()

# 1) Três leitores dentro ao mesmo tempo: a barreira só abre se os três estiverem lá
barreira = threading.Barrier(3)
passaram = []

def leitor_simultaneo(i):
    rw.adquirir_leitura()
    try:
        barreira.wait(timeout=2)
        passaram.append(i)
    finally:
        rw.liberar_leitura()

ts = [threading.Thread(target=leitor_simultaneo, args=(i,)) for i in range(3)]
for t in ts:
    t.start()
for t in ts:
    t.join()
print("leitores simultaneos:", len(passaram))

# 2) Com um escritor dentro, o leitor precisa esperar
eventos = []
rw.adquirir_escrita()
leitor = threading.Thread(target=lambda: (rw.adquirir_leitura(), eventos.append("leitor entrou"), rw.liberar_leitura()))
leitor.start()
eventos.append("escritor terminou")
rw.liberar_escrita()
leitor.join()
print(eventos)
```

```java
import java.util.*;
import java.util.concurrent.CyclicBarrier;
import java.util.concurrent.TimeUnit;

static class RWLock {
    private int leitores = 0;
    private boolean escrevendo = false;
    private int escritoresEsperando = 0;

    synchronized void adquirirLeitura() throws InterruptedException {
        while (escrevendo || escritoresEsperando > 0) {
            wait();
        }
        leitores += 1;
    }

    synchronized void liberarLeitura() {
        leitores -= 1;
        if (leitores == 0) {
            notifyAll();
        }
    }

    synchronized void adquirirEscrita() throws InterruptedException {
        escritoresEsperando += 1;
        while (escrevendo || leitores > 0) {
            wait();
        }
        escritoresEsperando -= 1;
        escrevendo = true;
    }

    synchronized void liberarEscrita() {
        escrevendo = false;
        notifyAll();
    }
}

static final RWLock rw = new RWLock();

// 1) Três leitores dentro ao mesmo tempo: a barreira só abre se os três estiverem lá
static final CyclicBarrier barreira = new CyclicBarrier(3);
// os leitores estão juntos lá dentro: a lista precisa de proteção própria
static final List<Integer> passaram = Collections.synchronizedList(new ArrayList<>());
// 2) A ordem desta lista é garantida pelo próprio lock
static final List<String> eventos = new ArrayList<>();

static void leitorSimultaneo(int i) {
    try {
        rw.adquirirLeitura();
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
        return;
    }
    try {
        barreira.await(2, TimeUnit.SECONDS);
        passaram.add(i);
    } catch (Exception e) {  // TimeoutException, BrokenBarrierException ou InterruptedException
        System.out.println("barreira estourou o prazo");
    } finally {
        rw.liberarLeitura();
    }
}

static void lerDepois() {
    try {
        rw.adquirirLeitura();
        eventos.add("leitor entrou");
        rw.liberarLeitura();
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> ts = new ArrayList<>();
    for (int i = 0; i < 3; i++) {
        int id = i;
        ts.add(new Thread(() -> leitorSimultaneo(id)));
    }
    for (Thread t : ts) t.start();
    for (Thread t : ts) t.join();
    System.out.println("leitores simultaneos: " + passaram.size());

    // 2) Com um escritor dentro, o leitor precisa esperar
    rw.adquirirEscrita();
    Thread leitor = new Thread(() -> lerDepois());
    leitor.start();
    eventos.add("escritor terminou");
    rw.liberarEscrita();
    leitor.join();
    System.out.println(eventos);
}
```

```cpp
#include <chrono>
#include <condition_variable>
#include <iostream>
#include <mutex>
#include <string>
#include <thread>
#include <vector>
using namespace std;

class RWLock {
    mutex m;
    condition_variable cond;
    int leitores = 0;
    bool escrevendo = false;
    int escritores_esperando = 0;

public:
    void adquirir_leitura() {
        unique_lock<mutex> trava(m);
        while (escrevendo || escritores_esperando > 0) {
            cond.wait(trava);
        }
        leitores += 1;
    }

    void liberar_leitura() {
        lock_guard<mutex> trava(m);
        leitores -= 1;
        if (leitores == 0) {
            cond.notify_all();
        }
    }

    void adquirir_escrita() {
        unique_lock<mutex> trava(m);
        escritores_esperando += 1;
        while (escrevendo || leitores > 0) {
            cond.wait(trava);
        }
        escritores_esperando -= 1;
        escrevendo = true;
    }

    void liberar_escrita() {
        lock_guard<mutex> trava(m);
        escrevendo = false;
        cond.notify_all();
    }
};

// std::barrier não tem prazo: esta é uma barreira mínima, de uma rodada, com wait_for
class BarreiraComPrazo {
    mutex m;
    condition_variable cond;
    int faltam;

public:
    explicit BarreiraComPrazo(int n) : faltam(n) {}

    // devolve false se o prazo acabar antes de todas chegarem
    bool esperar(chrono::seconds prazo) {
        unique_lock<mutex> trava(m);
        faltam -= 1;
        if (faltam == 0) {
            cond.notify_all();
        }
        return cond.wait_for(trava, prazo, [this] { return faltam == 0; });
    }
};

RWLock rw;

// 1) Três leitores dentro ao mesmo tempo: a barreira só abre se os três estiverem lá
BarreiraComPrazo barreira(3);
vector<int> passaram;
mutex trava_passaram;  // os leitores estão juntos lá dentro: a lista precisa de proteção própria

void leitor_simultaneo(int i) {
    rw.adquirir_leitura();
    if (barreira.esperar(chrono::seconds(2))) {
        lock_guard<mutex> guarda(trava_passaram);
        passaram.push_back(i);
    }
    rw.liberar_leitura();
}

int main() {
    vector<thread> ts;
    for (int i = 0; i < 3; i++) {
        ts.emplace_back(leitor_simultaneo, i);
    }
    for (auto& t : ts) {
        t.join();
    }
    cout << "leitores simultaneos: " << passaram.size() << endl;

    // 2) Com um escritor dentro, o leitor precisa esperar
    vector<string> eventos;
    rw.adquirir_escrita();
    thread leitor([&eventos] {
        rw.adquirir_leitura();
        eventos.push_back("leitor entrou");
        rw.liberar_leitura();
    });
    eventos.push_back("escritor terminou");
    rw.liberar_escrita();
    leitor.join();
    cout << "['" << eventos[0] << "', '" << eventos[1] << "']" << endl;
}
```

```csharp
using System.Threading;

class RWLock
{
    private readonly object _cond = new object();
    private int _leitores = 0;
    private bool _escrevendo = false;

            _escritoresEsperando -= 1;
            _escrevendo = true;
```

```go
import (
	"fmt"
	"sync"
	"time"
)

type RWLock struct {
	mu                  sync.Mutex
	cond                *sync.Cond
	leitores            int
	escrevendo          bool
	escritoresEsperando int
}

func NovoRWLock() *RWLock {
	r := &RWLock{}
	r.cond = sync.NewCond(&r.mu)
	return r
}

func (r *RWLock) adquirirLeitura() {
	r.mu.Lock()
	defer r.mu.Unlock()
	for r.escrevendo || r.escritoresEsperando > 0 {
		r.cond.Wait()
	}
	r.leitores += 1
}

func (r *RWLock) liberarLeitura() {
	r.mu.Lock()
	defer r.mu.Unlock()
	r.leitores -= 1
	if r.leitores == 0 {
		r.cond.Broadcast()
	}
}

func (r *RWLock) adquirirEscrita() {
	r.mu.Lock()
	defer r.mu.Unlock()
	r.escritoresEsperando += 1
	for r.escrevendo || r.leitores > 0 {
		r.cond.Wait()
	}
	r.escritoresEsperando -= 1
	r.escrevendo = true
}

func (r *RWLock) liberarEscrita() {
	r.mu.Lock()
	defer r.mu.Unlock()
	r.escrevendo = false
	r.cond.Broadcast()
}

// Go não tem barreira, e sync.Cond não tem prazo: esta é uma barreira mínima, de uma rodada,
// em que o canal fecha quando a última chega e o prazo vem do select com time.After
type BarreiraComPrazo struct {
	mu     sync.Mutex
	faltam int
	abriu  chan struct{}
}

func (b *BarreiraComPrazo) esperar(prazo time.Duration) bool {
	b.mu.Lock()
	b.faltam -= 1
	if b.faltam == 0 {
		close(b.abriu)
	}
	b.mu.Unlock()
	select {
	case <-b.abriu:
		return true
	case <-time.After(prazo):
		return false
	}
}

var rw = NovoRWLock()

// 1) Três leitores dentro ao mesmo tempo: a barreira só abre se os três estiverem lá
var barreira = &BarreiraComPrazo{faltam: 3, abriu: make(chan struct{})}
var passaram []int
var travaPassaram sync.Mutex // os leitores estão juntos lá dentro: a lista precisa de proteção própria

func leitorSimultaneo(i int, wg *sync.WaitGroup) {
	defer wg.Done()
	rw.adquirirLeitura()
	defer rw.liberarLeitura()
	if barreira.esperar(2 * time.Second) {
		travaPassaram.Lock()
		passaram = append(passaram, i)
		travaPassaram.Unlock()
	}
}

func main() {
	var wg sync.WaitGroup
	for i := 0; i < 3; i++ {
		wg.Add(1)
		go leitorSimultaneo(i, &wg)
	}
	wg.Wait()
	fmt.Println("leitores simultaneos:", len(passaram))

	// 2) Com um escritor dentro, o leitor precisa esperar
	var eventos []string
	rw.adquirirEscrita()
	wg.Add(1)
	go func() {
		defer wg.Done()
		rw.adquirirLeitura()
		eventos = append(eventos, "leitor entrou")
		rw.liberarLeitura()
	}()
	eventos = append(eventos, "escritor terminou")
	rw.liberarEscrita()
	wg.Wait()
	fmt.Println(eventos)
}
```

```python
import threading

class RWLock:
    def __init__(self):
        self._cond = threading.Condition()
        self._leitores = 0
        self._escrevendo = False
        self._escritores_esperando = 0

    def adquirir_leitura(self):
        with self._cond:
            while self._escrevendo or self._escritores_esperando > 0:
                self._cond.wait()
            self._leitores += 1

    def liberar_leitura(self):
        with self._cond:
            self._leitores -= 1
            if self._leitores == 0:
                self._cond.notify_all()

    def adquirir_escrita(self):
        with self._cond:
            self._escritores_esperando += 1
            while self._escrevendo or self._leitores > 0:
                self._cond.wait()
            self._escritores_esperando -= 1
            self._escrevendo = True

    def liberar_escrita(self):
        with self._cond:
            self._escrevendo = False
            self._cond.notify_all()

class Config:
    def __init__(self):
        self._rw = RWLock()
        self.versao = 0
        self.timeout = 0  # invariante: timeout == versao * 10

    def ler(self):
        self._rw.adquirir_leitura()
        try:
            return self.versao, self.timeout
        finally:
            self._rw.liberar_leitura()

    def atualizar(self):
        self._rw.adquirir_escrita()
        try:
            self.versao += 1
            self.timeout = self.versao * 10
        finally:
            self._rw.liberar_escrita()

cfg = Config()
inconsistencias = [0] * 4

def leitor(i):
    for _ in range(2000):
        v, t = cfg.ler()
        if t != v * 10:
            inconsistencias[i] += 1

def escritor():
    for _ in range(300):
        cfg.atualizar()

threads = [threading.Thread(target=leitor, args=(i,)) for i in range(4)]
threads.append(threading.Thread(target=escritor))
for t in threads:
    t.start()
for t in threads:
    t.join()

print("inconsistencias vistas:", sum(inconsistencias))
print("versao final:", cfg.ler())
```

```java
import java.util.*;
import java.util.concurrent.locks.ReentrantReadWriteLock;

// Em Java o RW lock vem pronto: não é preciso escrever a classe RWLock
static class Config {
    private final ReentrantReadWriteLock rw = new ReentrantReadWriteLock();
    private int versao = 0;
    private int timeout = 0;  // invariante: timeout == versao * 10

    int[] ler() {
        rw.readLock().lock();
        try {
            return new int[]{versao, timeout};
        } finally {
            rw.readLock().unlock();
        }
    }

    void atualizar() {
        rw.writeLock().lock();
        try {
            versao += 1;
            timeout = versao * 10;
        } finally {
            rw.writeLock().unlock();
        }
    }
}

static final Config cfg = new Config();
static final int[] inconsistencias = new int[4];

static void leitor(int i) {
    for (int k = 0; k < 2000; k++) {
        int[] lido = cfg.ler();
        if (lido[1] != lido[0] * 10) {
            inconsistencias[i] += 1;
        }
    }
}

static void escritor() {
    for (int k = 0; k < 300; k++) {
        cfg.atualizar();
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> threads = new ArrayList<>();
    for (int i = 0; i < 4; i++) {
        int id = i;
        threads.add(new Thread(() -> leitor(id)));

    threads.add(new Thread(() -> escritor()));
    for (Thread t : threads) t.start();
    for (Thread t : threads) t.join();

    int soma = 0;
    for (int x : inconsistencias) soma += x;
    System.out.println("inconsistencias vistas: " + soma);
    int[] fim = cfg.ler();
    System.out.println("versao final: (" + fim[0] + ", " + fim[1] + ")");
```

```go
	for k := 0; k < 2000; k++ {
		v, t := cfg.ler()
		if t != v*10 {
			inconsistencias[i] += 1
		}
	}
}

func escritor(wg *sync.WaitGroup) {
	defer wg.Done()
	for k := 0; k < 300; k++ {
		cfg.atualizar()
	}
}

func main() {
	var wg sync.WaitGroup
	for i := 0; i < 4; i++ {
		wg.Add(1)
		go leitor(i, &wg)
	}
	wg.Add(1)
	go escritor(&wg)
	wg.Wait()

	soma := 0
	for _, x := range inconsistencias {
		soma += x
	}
	fmt.Println("inconsistencias vistas:", soma)
	versao, timeout := cfg.ler()
	fmt.Printf("versao final: (%d, %d)\n", versao, timeout)
}
```

## Trade-offs e armadilhas

- **Não é sempre mais rápido.** Um RW lock tem mais estado para manter que um mutex. Se a seção crítica é curtíssima ou as escritas são frequentes, o mutex simples costuma ganhar. Meça.
- **Starvation.** Com preferência para leitores, um fluxo constante de leituras pode impedir a escrita para sempre. Com preferência para escritores, o inverso pode acontecer. Implementações justas (como `ReentrantReadWriteLock(true)` em Java) atendem em ordem de chegada, com algum custo.
- **Upgrade de leitura para escrita.** Segurar o lock de leitura e tentar pegar o de escrita trava se dois leitores fizerem isso ao mesmo tempo: cada um espera o outro sair. Libere a leitura, pegue a escrita e **verifique de novo** a condição.
- **Escrever com o lock de leitura** é um bug silencioso: o código compila e a corrupção aparece sob carga.

<Callout type="tip" title="Alternativa sem lock para leitura">
Se as escritas são raras, considere copy-on-write: o escritor monta um objeto novo e troca a referência de uma vez. Leitores apenas leem a referência atual, sem lock. É o que `CopyOnWriteArrayList` faz em Java.
</Callout>
