A Quitanda tem vitrine e checkout, mas ainda não sabe fazer conta. Quanto custam 1,5 kg de tomate e três pés de alface? O frete é grátis acima de R$ 100? Quantos itens há no carrinho? HTML descreve e CSS apresenta; quem decide e calcula é o **JavaScript**, a única linguagem de programação que os navegadores executam nativamente e a mesma que você vai escrever no React, no Next.js e no Node.

Este capítulo ensina a programar com JavaScript resolvendo um problema só: o cálculo do carrinho. Você começa guardando valores em variáveis, decide com condicionais, repete com laços, organiza com funções e termina com os métodos de array que aparecem em todo componente React (`map`, `filter`, `reduce`). Ainda não há interação com a página; isso vem no próximo capítulo, com o DOM.

**Você vai aprender:**

- Onde executar JavaScript e como ler o console
- Declarar variáveis com `const` e `let` e reconhecer os tipos da linguagem
- Tomar decisões com `if`, `switch`, ternário, `??` e `?.`
- Repetir tarefas com `for`, `for...of` e `while`
- Escrever funções pequenas, com parâmetros, retorno e valores padrão
- Modelar produtos e carrinho com arrays e objetos e calcular totais com `map`, `filter` e `reduce`

## Onde o JavaScript roda

Há dois lugares para começar:

- **Console das DevTools** (aba Console): digite uma expressão e veja o resultado. Ótimo para experimentar.
- **Um arquivo `.js` ligado à página**, que é onde o código da Quitanda vai morar:

```html
<!-- index.html (head) -->
<script src="js/carrinho.js" defer></script>
```

```js
// js/carrinho.js
console.log("Carrinho carregado");
```

Recarregue a página com o console aberto e a mensagem aparece. `console.log` é a ferramenta de depuração mais usada do mundo; `console.table(lista)` mostra arrays de objetos como tabela.

## Variáveis e tipos

Uma variável é um nome para um valor:

```js
// js/carrinho.js
const nomeDaLoja = "Quitanda";
let quantidadeDeItens = 0;

quantidadeDeItens = quantidadeDeItens + 1; // ok
// nomeDaLoja = "Sacolão"; // TypeError: Assignment to constant variable.
```

| Declaração | Pode reatribuir? | Escopo | Use quando |
|---|---|---|---|
| `const` | Não | Bloco (`{ }`) | Padrão; a maioria dos valores não muda de referência |
| `let` | Sim | Bloco | O valor muda: contadores, acumuladores |
| `var` | Sim | Função, com içamento | Não use; aparece só em código legado |

`const` impede reatribuir o nome, mas não congela o conteúdo: um array declarado com `const` aceita `push`. Comece sempre com `const` e troque para `let` quando precisar.

### Os tipos

JavaScript tem tipagem dinâmica: a variável não tem tipo, o valor tem.

| Tipo | Exemplo | `typeof` |
|---|---|---|
| string | `"Banana prata"`, `` `R$ ${preco}` `` | `"string"` |
| number | `899`, `1.5`, `NaN` | `"number"` |
| boolean | `true`, `false` | `"boolean"` |
| undefined | Variável sem valor | `"undefined"` |
| null | "Sem valor", de propósito | `"object"` (erro histórico da linguagem) |
| bigint | `9007199254740993n` | `"bigint"` |
| symbol | `Symbol("id")` | `"symbol"` |
| object | `{ nome: "Alface" }`, `[1, 2]`, funções | `"object"` (`"function"` para funções) |

**Template literals**, com crase, montam textos sem concatenar com `+`:

```js
// js/carrinho.js
const produto = "Tomate";
const quilos = 1.5;
console.log(`${quilos} kg de ${produto}`); // "1.5 kg de Tomate"
```

### Por que preço em centavos

```js
// console do navegador
console.log(0.1 + 0.2); // 0.30000000000000004
```

Números em JavaScript seguem o padrão IEEE 754 de ponto flutuante, que não representa exatamente a maioria das frações decimais. Somar preços em reais com casas decimais acumula erros de centavo. Por isso o catálogo da Quitanda guarda `precoEmCentavos: 899` em vez de `8.99`: inteiros são exatos até `Number.MAX_SAFE_INTEGER`, e a conversão para reais acontece só na hora de exibir.

<Callout type="warning" title="Dinheiro nunca em ponto flutuante">
Guarde e some valores monetários como inteiros (centavos). Arredonde com `Math.round` quando multiplicar por quantidades fracionadas, como 0,5 kg, e formate para reais apenas na exibição.
</Callout>

## Operadores e comparações

Aritméticos (`+ - * / % **`), de atribuição (`+=`, `-=`, `++`), lógicos (`&&`, `||`, `!`) e de comparação. A comparação que mais causa bugs:

```js
// console do navegador
console.log(1 == "1");  // true: converte os tipos antes de comparar
console.log(1 === "1"); // false: compara tipo e valor
console.log(0 == "");   // true, surpresa
```

Use sempre `===` e `!==`. A comparação frouxa (`==`) aplica regras de conversão que quase ninguém lembra.

Todo valor é **truthy** ou **falsy** quando usado como condição. Os falsy são poucos: `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined` e `NaN`. Todo o resto é truthy, inclusive `"0"`, `[]` e `{}`.

## Decisões

```js
// js/carrinho.js
const FRETE_EM_CENTAVOS = 990;
const FRETE_GRATIS_A_PARTIR_DE = 10000; // R$ 100,00

function calcularFrete(subtotal, tipoEntrega) {
  if (tipoEntrega === "retirada") {
    return 0;
  } else if (subtotal >= FRETE_GRATIS_A_PARTIR_DE) {
    return 0;
  } else {
    return FRETE_EM_CENTAVOS;
  }
}
```

O **ternário** resolve escolhas simples numa expressão, e você vai usá-lo muito dentro do JSX:

```js
// console do navegador
const rotulo = estoque > 0 ? "Adicionar" : "Esgotado";
```

`switch` compara um valor com vários casos fixos. O status do pedido é o exemplo clássico:

```js
// js/pedidos.js
function descreverStatus(status) {
  switch (status) {
    case "recebido":
      return "Recebemos seu pedido";
    case "separando":
      return "Estamos separando seus produtos";
    case "saiu_para_entrega":
      return "Seu pedido saiu para entrega";
    case "entregue":
      return "Pedido entregue";
    default:
      return "Status desconhecido";
  }
}
```

Sem o `return` (ou um `break`), a execução "cai" para o próximo caso.

Dois operadores modernos evitam erros com valores ausentes:

```js
// console do navegador
const cliente = { nome: "Cida", endereco: null };

// ?. (encadeamento opcional): não quebra se o caminho for null ou undefined
console.log(cliente.endereco?.cep); // undefined, sem TypeError

// ?? (coalescência nula): valor padrão só para null ou undefined
const observacao = cliente.observacao ?? "Sem observações";
const quantidade = 0 ?? 1; // 0, porque 0 não é null nem undefined
const quantidadeErrada = 0 || 1; // 1: o || trata 0 como falsy
```

Use `??` para valores padrão quando `0` e `""` são válidos. Quantidade zero e desconto zero são.

## Laços de repetição

```js
// for clássico: quando você precisa do índice
for (let i = 0; i < 3; i++) {
  console.log(`Item ${i + 1}`);
}

// for...of: percorre os valores de um array (o mais legível)
const categorias = ["frutas", "legumes", "verduras"];
for (const categoria of categorias) {
  console.log(categoria.toUpperCase());
}

// while: repete enquanto a condição for verdadeira
let estoque = 3;
while (estoque > 0) {
  console.log(`Restam ${estoque}`);
  estoque--;
}
```

`break` sai do laço; `continue` pula para a próxima volta. Cuidado com laços infinitos: um `while` cuja condição nunca fica falsa trava a aba do navegador.

## Funções

Função é um bloco de código com nome, que recebe dados (parâmetros) e devolve um resultado (`return`). Funções pequenas, com um único propósito, são a base do código legível.

```js
// js/carrinho.js
// declaração de função
function formatarPreco(centavos) {
  return (centavos / 100).toLocaleString("pt-BR", {
    style: "currency",
    currency: "BRL",
  });
}

// arrow function, com parâmetro padrão
const calcularTotalDoItem = (precoEmCentavos, quantidade = 1) =>
  Math.round(precoEmCentavos * quantidade);

console.log(formatarPreco(899));                 // "R$ 8,99"
console.log(calcularTotalDoItem(899, 1.5));      // 1349 (1348,5 arredondado)
console.log(formatarPreco(calcularTotalDoItem(899, 1.5))); // "R$ 13,49"
```

| Forma | Sintaxe | Observação |
|---|---|---|
| Declaração | `function nome() {}` | Pode ser chamada antes de aparecer no arquivo (içamento) |
| Expressão | `const nome = function () {}` | Só existe depois da linha |
| Arrow | `const nome = () => {}` | Sem `this` próprio; corpo de uma expressão dispensa `return` |

Uma função sem `return` devolve `undefined`. Uma variável criada dentro da função só existe ali dentro (**escopo**). Uma função que "lembra" das variáveis de onde foi criada é uma **closure**, conceito que volta forte nos hooks do React.

**Funções puras** recebem dados e devolvem um resultado sem alterar nada fora delas. `formatarPreco` e `calcularTotalDoItem` são puras: mesmo argumento, mesmo resultado, sem efeitos colaterais. São fáceis de testar e são o modelo dos componentes React.

## Arrays e objetos: modelando a Quitanda

Um **objeto** agrupa propriedades de uma coisa; um **array** é uma lista ordenada.

```js
// js/dados.js
const produtos = [
  { id: "1", nome: "Tomate italiano", precoEmCentavos: 899, unidade: "kg", categoria: "legumes", estoque: 40, foto: "img/tomate.jpg" },
  { id: "2", nome: "Banana prata", precoEmCentavos: 649, unidade: "kg", categoria: "frutas", estoque: 25, foto: "img/banana.jpg" },
  { id: "3", nome: "Alface crespa", precoEmCentavos: 350, unidade: "un", categoria: "verduras", estoque: 0, foto: "img/alface.jpg" },
  { id: "4", nome: "Manga palmer", precoEmCentavos: 1190, unidade: "kg", categoria: "frutas", estoque: 12, foto: "img/manga.jpg" },
];

const carrinho = [
  { produtoId: "1", nome: "Tomate italiano", precoEmCentavos: 899, unidade: "kg", quantidade: 1.5 },
  { produtoId: "2", nome: "Banana prata", precoEmCentavos: 649, unidade: "kg", quantidade: 2 },
];
```

Esse formato (preço em centavos, `unidade` como `"kg"` ou `"un"`, `id` como texto) é o mesmo que a API vai devolver no capítulo de CRUD.

Operações básicas:

```js
// console do navegador
console.log(produtos.length);        // 4
console.log(produtos[0].nome);       // "Tomate italiano"
console.log(produtos.at(-1).nome);   // "Manga palmer"

const banana = produtos[1];
banana.estoque = 24;                  // altera a propriedade
const { nome, precoEmCentavos } = banana; // desestruturação

const bananaComDesconto = { ...banana, precoEmCentavos: 549 }; // cópia com alteração
const novoCarrinho = [...carrinho, { produtoId: "4", nome: "Manga palmer", precoEmCentavos: 1190, unidade: "kg", quantidade: 1 }];
```

O **spread** (`...`) cria cópias novas em vez de alterar o original. No React, atualizar estado é sempre assim: nunca `carrinho.push(...)`, sempre um array novo.

<Callout type="tip" title="Objetos são passados por referência">
`const copia = carrinho` não copia nada: as duas variáveis apontam para o mesmo array, e alterar uma altera a outra. Para copiar, use spread (`[...carrinho]`) ou `structuredClone(carrinho)` quando houver objetos aninhados.
</Callout>

## Métodos de array

Em vez de escrever um `for` para cada operação, use os métodos que expressam a intenção:

| Método | Devolve | Exemplo na Quitanda |
|---|---|---|
| `map` | Novo array, mesmo tamanho, cada item transformado | Nomes dos produtos; no React, a lista de cards |
| `filter` | Novo array com os itens que passam no teste | Produtos com estoque, produtos de uma categoria |
| `find` | O primeiro item que passa no teste, ou `undefined` | Produto pelo `id` |
| `findIndex` | O índice do primeiro item, ou `-1` | Posição do item no carrinho |
| `some` / `every` | `true` ou `false` | Algum item esgotado? Todos de uma categoria? |
| `reduce` | Um valor acumulado | Subtotal do carrinho |
| `includes` | `true` ou `false` | Categoria existe na lista? |
| `toSorted` | Novo array ordenado (sem alterar o original) | Produtos por preço |
| `forEach` | `undefined`; só executa | Imprimir no console |

```js
// js/carrinho.js
const disponiveis = produtos.filter((produto) => produto.estoque > 0);
const nomes = disponiveis.map((produto) => produto.nome);
const manga = produtos.find((produto) => produto.id === "4");
const temEsgotado = produtos.some((produto) => produto.estoque === 0);
const maisBaratos = produtos.toSorted((a, b) => a.precoEmCentavos - b.precoEmCentavos);

console.log(nomes); // ["Tomate italiano", "Banana prata", "Manga palmer"]
```

`sort` altera o array original; `toSorted`, `toReversed` e `with` são as versões que devolvem cópia, e combinam com o estilo imutável.

### O cálculo do carrinho

Juntando tudo:

```js
// js/carrinho.js
function calcularSubtotal(itens) {
  return itens.reduce(
    (soma, item) => soma + calcularTotalDoItem(item.precoEmCentavos, item.quantidade),
    0,
  );
}

function contarItens(itens) {
  return itens.length;
}

function resumirCarrinho(itens, tipoEntrega = "entrega") {
  const subtotal = calcularSubtotal(itens);
  const frete = itens.length === 0 ? 0 : calcularFrete(subtotal, tipoEntrega);
  return {
    quantidadeDeItens: contarItens(itens),
    subtotal,
    frete,
    total: subtotal + frete,
  };
}

const resumo = resumirCarrinho(carrinho);
console.log(resumo);
// { quantidadeDeItens: 2, subtotal: 2647, frete: 990, total: 3637 }
console.log(`Total: ${formatarPreco(resumo.total)}`); // "Total: R$ 36,37"
```

O `reduce` começa com `0` (o segundo argumento) e, a cada item, soma o total daquele item ao acumulador. Sem o valor inicial, ele usaria o primeiro item (um objeto) como acumulador e o resultado viraria texto sem sentido.

Repare na separação: `calcularSubtotal`, `calcularFrete` e `formatarPreco` não sabem nada de HTML. No próximo capítulo, o DOM só vai chamar essas funções e mostrar o resultado.

## Na entrevista

**Qual a diferença entre `let`, `const` e `var`?** `const` não permite reatribuição e `let` permite; os dois têm escopo de bloco. `var` tem escopo de função e é içada com valor `undefined`, o que causa bugs; não se usa em código novo.

**Qual a diferença entre `==` e `===`?** `===` compara tipo e valor sem conversão. `==` converte os tipos antes, com regras pouco intuitivas, como `0 == ""` ser verdadeiro.

**Qual a diferença entre `map`, `filter` e `reduce`?** `map` transforma cada item e devolve um array do mesmo tamanho; `filter` devolve só os itens que passam no teste; `reduce` combina todos os itens num único valor, como uma soma.

**Por que `0.1 + 0.2` não dá `0.3`?** Porque os números são ponto flutuante binário, que não representa essas frações exatamente. Para dinheiro, trabalha-se com inteiros em centavos.

**Diferença entre `??` e `||`?** `||` devolve o lado direito para qualquer valor falsy, inclusive `0` e `""`. `??` só para `null` e `undefined`.

## Pratique

1. Crie `js/carrinho.js` com os produtos e o carrinho do capítulo e imprima a lista com `console.table`.
2. Escreva `formatarPreco`, `calcularTotalDoItem`, `calcularSubtotal` e `calcularFrete` e confira os números do exemplo.
3. Adicione um cupom: `aplicarCupom(subtotal, codigo)` que dá 10% de desconto com `FEIRA10` e não faz nada com código inválido; arredonde o desconto para centavos inteiros.
4. Escreva `produtosPorCategoria(produtos, categoria)` e `buscarProdutos(produtos, termo)`, que ignora maiúsculas e acentos (dica: `normalize("NFD")` e uma expressão regular para remover os acentos).
5. Implemente `adicionarAoCarrinho(itens, produto, quantidade)` que devolve um **novo** array: soma a quantidade se o produto já estiver no carrinho e acrescenta o item se não estiver, sem alterar o array original.
6. Impeça que a quantidade ultrapasse o estoque e que itens `"un"` tenham quantidade fracionada (use `Number.isInteger`).
