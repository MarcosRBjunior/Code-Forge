React é a biblioteca de interface mais usada no mercado: está em startups, bancos, e-commerces e em boa parte das vagas de front-end. Só que a vaga não pede apenas React. Ela pede HTML semântico e acessível, CSS que se adapta a qualquer tela, JavaScript de verdade, TypeScript, testes, um framework como Next.js e, nos níveis mais altos, decisões de arquitetura, performance, observabilidade e segurança. Esta carreira põe esse conjunto em ordem, do primeiro arquivo HTML até a liderança técnica de um front-end em produção.

O alvo é a vaga de **desenvolvedor front-end React**: alguém que constrói interfaces rápidas e acessíveis, organiza o código para o time conseguir mudá-lo, escreve testes que dão confiança e sabe o que acontece com a aplicação depois do deploy.

## Como a carreira está organizada

| Módulo | Você sai sabendo | Cursos |
|---|---|---|
| Nível base: os fundamentos do Front-End | Como a web funciona, HTML, CSS, responsividade, acessibilidade, JavaScript, DOM, localStorage, HTTP e o ambiente com Node.js | 9 |
| Nível 1: React e JSX | Componentes, JSX, hooks, estilização, React Router, consumo de APIs, GraphQL, Redux e Context, formulários, primeiros testes e código legado | 10 |
| Nível 2: TypeScript, arquitetura e testes avançados | TypeScript, custom hooks, otimização, Next.js, Remix, autenticação segura, debugging e release, arquitetura, testes avançados e CI/CD | 12 |
| Nível 3: performance, escalabilidade e liderança técnica | Decisões estratégicas, SOLID, arquitetura limpa, BFF, eventos em tempo real, estado avançado, performance, New Relic, design systems, OWASP, micro frontends e débito técnico | 19 |

A Base é o que nenhum framework substitui: quem entende o navegador, o DOM e o HTTP aprende React mais rápido e depura melhor. O Nível 1 leva você do primeiro componente a uma aplicação completa, com rotas, dados de API e testes. O Nível 2 é o que as vagas pleno pedem: TypeScript, Next.js, arquitetura e qualidade. O Nível 3 é o território do sênior: performance medida, sistemas de design, monitoramento em produção e decisões que o time inteiro segue.

## O projeto que atravessa a carreira

Os capítulos constroem a mesma aplicação, a **Quitanda**: uma loja online de hortifrúti com catálogo de produtos, carrinho, checkout, acompanhamento de pedidos em tempo real e um painel para o lojista. Ela começa como um site estático em HTML e CSS, ganha interatividade com JavaScript puro, é reescrita em React no Nível 1, migra para TypeScript e Next.js no Nível 2 e, no Nível 3, ganha um design system próprio, um BFF, monitoramento e uma arquitetura que aguenta vários times.

## Como usar

- **Siga a ordem dentro de cada nível.** Os capítulos partem do que o anterior construiu na Quitanda.
- **Feche cada nível com o checkpoint.** O último capítulo de cada nível reúne a revisão do nível, uma autoavaliação, um desafio prático na Quitanda e quizzes. Faça-o antes de passar ao próximo nível: ele mostra o que ainda precisa de revisão.
- **Marque cada capítulo como concluído** quando terminar. O progresso do módulo mostra quanto falta para fechar o nível.
- **Use as notas do CodeForge como diário de bordo.** Anote os bugs que custaram uma tarde, as renderizações que surpreenderam e as decisões de arquitetura. Isso vira material para o README e para a entrevista.
- **Publique o que construir.** A Quitanda pode virar um repositório público com README, testes, pipeline e deploy. Veja [Projetos para portfólio](/learn/projetos-portfolio) para transformá-la num projeto que conta no currículo.

<Callout type="tip" title="React moderno desde o começo">

Aqui os exemplos usam React 19 com componentes de função e hooks, Vite, React Router 7, TanStack Query, Redux Toolkit, Tailwind CSS 4, TypeScript e Next.js com App Router. ## Por onde começar

Se você nunca programou, comece pelo capítulo sobre fundamentos da web e siga a Base inteira. Se já escreve JavaScript, passe rápido pela Base, faça os exercícios dos capítulos de DOM e HTTP para conferir, e vá para o Nível 1.
