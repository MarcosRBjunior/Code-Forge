Uma carreira é uma sequência de cursos com começo, meio e fim. Ela responde à pergunta que trava muita gente: "já sei um pouco de JavaScript, e agora?". Aqui a resposta está escrita na ordem: primeiro a base da linguagem, depois uma API de verdade, depois a qualidade e a operação dessa API e, por fim, como colocá-la para rodar em escala na nuvem.

O alvo é a vaga de **desenvolvedor back-end com Node.js**: alguém que constrói APIs, cuida do banco de dados, escreve testes, entende o que acontece no servidor e sabe fazer o deploy sem pedir ajuda.

## Como a carreira está organizada

| Módulo | Você sai sabendo | Cursos |
|---|---|---|
| Base: lógica de programação e JavaScript | Variáveis, condicionais, laços, funções, arrays e objetos | 6 |
| Nível 1: primeira API com Node.js | Express, MongoDB, ORM, testes, Docker, autenticação, TypeScript e Nest.js | 31 |
| Nível 2: arquitetura, qualidade e operabilidade | Linux e Bash, algoritmos e estruturas de dados, SQL, PostgreSQL e MongoDB | 14 |
| Nível 3: escala, cloud e automação | AWS, containers, Kubernetes, GraphQL, RPC, infraestrutura como código e CI/CD | 20 |

Os níveis se apoiam um no outro. O Nível 1 é o mais longo de propósito: ao final dele você já tem o que a maioria das vagas júnior pede. Os Níveis 2 e 3 são o que separa o júnior do pleno: saber por que o banco ficou lento, automatizar o que é repetitivo e entregar com segurança.

## Como usar

- **Siga a ordem dentro de cada nível.** Vários cursos continuam o projeto do anterior (o projeto full stack com React e Node.js, por exemplo, atravessa três cursos seguidos).
- **Marque cada capítulo como concluído** quando terminar o curso correspondente. O progresso do módulo mostra quanto falta para fechar o nível.
- **Use as notas do CodeForge como diário de bordo.** Anote os comandos que você mais usou, os erros que custaram uma tarde e as decisões de cada projeto. Isso vira material para o README e para a entrevista.
- **Publique o que construir.** Cada API desta carreira pode virar repositório público com README e deploy. Veja [Projetos para portfólio](/learn/projetos-portfolio) para transformar os exercícios em projetos que contam no currículo.

<Callout type="tip" title="Não pule a base">
Se condicionais, laços e funções ainda exigem esforço, fique no primeiro módulo até ficarem automáticos. Tudo o que vem depois (Express, ORM, testes) é JavaScript; travar na linguagem deixa cada curso duas vezes mais lento.
</Callout>

## Onde o resto do CodeForge ajuda

A carreira cobre o que você precisa para trabalhar. Para as entrevistas, os outros cursos daqui completam o caminho:

- [TypeScript para entrevistas](/learn/typescript): o sistema de tipos e a programação assíncrona a fundo, junto com o Nível 1.
- [Estruturas de Dados e Algoritmos](/learn/dsa): aprofunda os cursos de algoritmos e estruturas de dados do Nível 2.
- [SQL para entrevistas](/learn/sql): consultas no formato cobrado em entrevista, junto com os cursos de SQL e PostgreSQL.
- [Sistemas operacionais](/learn/sistemas-operacionais) e [Redes de computadores](/learn/redes): o que está por baixo do Linux, dos containers e da VPC.
- [System Design: Fundamentos](/learn/system-design): a teoria de escala por trás do Nível 3.

## Por onde começar

Se você já programa em JavaScript com tranquilidade, vá direto para o Nível 1. Se não, comece pelo primeiro capítulo da base e siga a ordem.
