Programar é escrever instruções tão precisas que uma máquina consegue segui-las sem perguntar nada. Toda API, script de automação ou rotina de banco de dados que você vai escrever nesta carreira é feita das mesmas peças: guardar valores, fazer contas, comparar e mostrar resultados. Este capítulo monta essas peças em JavaScript, rodando no Node.js, que é exatamente onde o seu código de back-end vai viver.

**Você vai aprender:**

- O que é um programa e como rodar JavaScript no terminal com Node.js
- Variáveis com `let` e `const` e os tipos básicos de valor
- Operadores aritméticos, de comparação e de texto
- Como ler a entrada do usuário e mostrar a saída
- Como ler uma mensagem de erro sem entrar em pânico

## O que é um programa

Um programa é uma lista de instruções executadas de cima para baixo, uma de cada vez. O computador não interpreta intenção: se você escrever a ordem errada, ele executa a ordem errada com toda a confiança.

Pense numa receita de bolo. "Misture os ingredientes" é vago para uma máquina. "Coloque 2 xícaras de farinha na tigela" é uma instrução. Programar é transformar o vago em passos concretos. Antes de escrever código, descreva o problema em português, em passos numerados. Esse texto se chama **algoritmo**, e ele é metade do trabalho.

Exemplo: calcular a média de duas notas.

1. Ler a primeira nota.
2. Ler a segunda nota.
3. Somar as duas e dividir por 2.
4. Mostrar o resultado.

Cada passo vai virar uma ou duas linhas de JavaScript.

## Rodando JavaScript com Node.js

JavaScript nasceu para rodar no navegador. O Node.js é um programa que roda JavaScript fora do navegador, direto no seu computador ou num servidor. Instale a versão LTS (22 ou mais nova) pelo site oficial e confirme no terminal:

```bash
node --version
# v22.x.x
```

Crie uma pasta, um arquivo `ola.js` e escreva:

```javascript
// ola.js
console.log("Olá, mundo!");
console.log("Meu primeiro programa em Node.js");
```

Rode com:

```bash
node ola.js
```

```text
Saída:
Olá, mundo!
Meu primeiro programa em Node.js
```

`console.log` escreve no terminal o que estiver entre parênteses. Você vai usá-lo o tempo todo, não só para mostrar resultados mas para entender o que o programa está fazendo. As linhas que começam com `//` são **comentários**: o Node ignora, e servem para você explicar o código.

Também dá para experimentar sem criar arquivo: digite `node` sozinho e você entra no REPL, um modo interativo em que cada linha é executada na hora. Saia com `.exit` ou Ctrl+C duas vezes.

## Variáveis: dando nome aos valores

Uma variável é um nome que aponta para um valor. Em JavaScript moderno você declara variáveis com duas palavras:

- `const` para valores que não vão ser reatribuídos.
- `let` para valores que vão mudar.

```javascript
const nome = "Ana";
let idade = 27;

console.log(nome, "tem", idade, "anos");

idade = idade + 1; // aniversário
console.log("Agora tem", idade);

// nome = "Bia"; // TypeError: Assignment to constant variable.
```

```text
Saída:
Ana tem 27 anos
Agora tem 28
```

A regra prática: comece sempre com `const`. Só troque para `let` quando precisar mudar o valor. Isso deixa claro para quem lê o código quais valores ficam fixos. Você ainda vai encontrar `var` em código antigo; evite, porque ele tem regras de escopo confusas que `let` e `const` corrigiram.

Nomes de variáveis em JavaScript seguem o estilo **camelCase**: `precoTotal`, `quantidadeDeItens`, `usuarioLogado`. Use nomes que digam o que o valor significa. `x` e `dado` não dizem nada; `totalEmReais` diz.

## Tipos de valor

Todo valor tem um tipo. Os que você mais vai usar agora:

| Tipo | Exemplos | Para que serve |
|---|---|---|
| `number` | `10`, `3.14`, `-2` | Contas, quantidades, preços |
| `string` | `"Ana"`, `'oi'`, `` `texto` `` | Texto |
| `boolean` | `true`, `false` | Sim ou não, ligado ou desligado |
| `undefined` | `undefined` | Variável que ainda não recebeu valor |
| `null` | `null` | "Sem valor", colocado de propósito |

O operador `typeof` diz o tipo de um valor:

```javascript
console.log(typeof 42);        // number
console.log(typeof "42");      // string
console.log(typeof true);      // boolean
let semValor;
console.log(typeof semValor);  // undefined
```

Repare que `42` e `"42"` são coisas diferentes. Um é número, o outro é texto que por acaso tem dígitos. Essa diferença vai causar bugs se você não prestar atenção, principalmente quando o valor vem de fora do programa (o terminal, um formulário, uma requisição HTTP), porque o que vem de fora quase sempre chega como texto.

## Operadores

### Aritméticos

```javascript
console.log(7 + 2);  // 9
console.log(7 - 2);  // 5
console.log(7 * 2);  // 14
console.log(7 / 2);  // 3.5
console.log(7 % 2);  // 1  (resto da divisão)
console.log(2 ** 3); // 8  (potência)
```

O `%` (resto) parece estranho no começo, mas aparece muito: um número é par quando `n % 2` dá zero.

A precedência é a da matemática: multiplicação e divisão antes de soma e subtração. Na dúvida, use parênteses. `(8 + 6) / 2` dá 7; `8 + 6 / 2` dá 11.

### Juntando textos

O `+` com strings junta (concatena) os textos. Mais legível ainda é a **template string**, escrita com crases, que aceita expressões dentro de `${}`:

```javascript
const produto = "Teclado";
const preco = 150;
const quantidade = 2;

console.log("Produto: " + produto);
console.log(`Total: R$ ${preco * quantidade}`);
```

```text
Saída:
Produto: Teclado
Total: R$ 300
```

### Comparação

Comparações devolvem `true` ou `false`:

```javascript
console.log(10 > 5);      // true
console.log(10 <= 5);     // false
console.log(5 === 5);     // true
console.log(5 === "5");   // false (tipos diferentes)
console.log(5 !== 3);     // true
```

Use sempre `===` (igualdade estrita) e `!==`. Existe também o `==`, que converte os tipos antes de comparar e por isso considera `5 == "5"` verdadeiro. Isso esconde bugs. No código desta carreira, `==` não aparece.

### Lógicos

`&&` (e), `||` (ou) e `!` (não) combinam condições:

```javascript
const temIngresso = true;
const maiorDeIdade = false;

console.log(temIngresso && maiorDeIdade); // false: precisa das duas
console.log(temIngresso || maiorDeIdade); // true: basta uma
console.log(!maiorDeIdade);               // true: inverte
```

## Convertendo texto em número

Quando um valor chega como texto e você precisa fazer conta, converta com `Number`:

```javascript
const digitado = "8.5";
console.log(digitado + 1);          // "8.51" (juntou textos!)
console.log(Number(digitado) + 1);  // 9.5

console.log(Number("abc"));         // NaN
console.log(Number.isNaN(Number("abc"))); // true
```

`NaN` significa "Not a Number": é o que você recebe ao converter algo que não é número. Ele é do tipo `number` (sim, é estranho) e contamina qualquer conta: `NaN + 1` continua `NaN`. Por isso, sempre que converter entrada de usuário, verifique com `Number.isNaN`.

<Callout type="warning" title="O + que junta em vez de somar">
O erro mais comum de quem começa é somar dois valores lidos do terminal e obter `"78"` em vez de `15`. Tudo o que vem de fora do programa chega como string, e `"7" + "8"` concatena. Converta com `Number()` assim que ler o valor, não depois.
</Callout>

## Lendo a entrada do usuário

Um programa útil recebe dados. No Node, o módulo `readline/promises` faz perguntas no terminal. Ele é assíncrono (você vai entender isso a fundo mais adiante); por enquanto, basta saber que `await` espera a resposta chegar.

Salve como `media.mjs` (a extensão `.mjs` diz ao Node para usar a sintaxe moderna de módulos, com `import`):

```javascript
// media.mjs
import * as readline from "node:readline/promises";
import { stdin as input, stdout as output } from "node:process";

const rl = readline.createInterface({ input, output });

const nota1 = Number(await rl.question("Primeira nota: "));
const nota2 = Number(await rl.question("Segunda nota: "));
rl.close();

const media = (nota1 + nota2) / 2;
console.log(`Sua média é ${media.toFixed(1)}`);
```

```bash
node media.mjs
```

```text
Saída:
Primeira nota: 7
Segunda nota: 8.5
Sua média é 7.8
```

Os quatro passos do algoritmo viraram código. `toFixed(1)` formata o número com uma casa decimal (e devolve uma string, o que é o que você quer para mostrar).

Outra forma de receber dados é por argumentos na linha de comando, com `process.argv`. Os dois primeiros itens são o caminho do Node e do arquivo; os seus argumentos vêm a partir do terceiro:

```javascript
// dobro.mjs
const valor = Number(process.argv[2]);
console.log(`O dobro de ${valor} é ${valor * 2}`);
```

```bash
node dobro.mjs 21
# O dobro de 21 é 42
```

## Lendo mensagens de erro

Errar faz parte. O que separa quem avança de quem trava é ler a mensagem de erro em vez de fechá-la. Veja:

```javascript
const total = 100;
console.log(totl);
```

```text
ReferenceError: totl is not defined
    at file:///home/ana/exemplo.mjs:2:13
```

A mensagem diz três coisas: o **tipo** do erro (`ReferenceError`, você usou um nome que não existe), a **descrição** (`totl is not defined`) e o **lugar** (arquivo, linha 2, coluna 13). Os erros que você mais vai ver no começo:

| Erro | O que significa |
|---|---|
| `ReferenceError: x is not defined` | Nome digitado errado ou variável não declarada |
| `TypeError: Assignment to constant variable` | Tentou mudar uma `const` |
| `SyntaxError: Unexpected token` | Faltou ou sobrou parêntese, chave ou aspas |
| `TypeError: x is not a function` | Chamou com parênteses algo que não é função |

Quando aparecer um erro, vá até a linha indicada, leia de novo e, se não entender, coloque um `console.log` antes da linha para ver o valor das variáveis naquele momento.

## Um programa completo: conversor de temperatura

Juntando tudo: ler um valor, converter, calcular e mostrar.

```javascript
// temperatura.mjs
import * as readline from "node:readline/promises";
import { stdin as input, stdout as output } from "node:process";

const rl = readline.createInterface({ input, output });
const celsius = Number(await rl.question("Temperatura em Celsius: "));
rl.close();

const fahrenheit = celsius * 9 / 5 + 32;
const kelvin = celsius + 273.15;

console.log(`${celsius} °C = ${fahrenheit} °F`);
console.log(`${celsius} °C = ${kelvin.toFixed(2)} K`);
```

```text
Saída:
Temperatura em Celsius: 25
25 °C = 77 °F
25 °C = 298.15 K
```

Repare na ordem: primeiro a entrada, depois o processamento, depois a saída. Quase todo programa, inclusive uma rota de API (requisição chega, regra de negócio roda, resposta sai), segue esse formato.

## Na entrevista

- **Qual a diferença entre `let`, `const` e `var`?** `const` não permite reatribuir, `let` permite; os dois têm escopo de bloco. `var` tem escopo de função e é "içado" (hoisting), o que causa bugs; não se usa mais em código novo.
- **Qual a diferença entre `==` e `===`?** `===` compara valor e tipo sem conversão. `==` converte os tipos antes, então `0 == ""` é `true`. Use `===`.
- **O que é `NaN` e como testar?** É o resultado de uma conta numérica inválida. Não é igual a nada, nem a si mesmo, então teste com `Number.isNaN(valor)`.
- **Qual a diferença entre `null` e `undefined`?** `undefined` é a ausência automática de valor (variável sem atribuição); `null` é a ausência colocada de propósito pelo programador.

## Pratique

Escreva um programa `troco.mjs` que pergunta o valor de uma compra e o valor pago, e mostra:

1. O troco, com duas casas decimais.
2. A frase `Pagamento insuficiente` em vez do troco, se faltar dinheiro (dica: você ainda não viu `if`, então use o operador ternário `condicao ? valorSeSim : valorSeNao` ou volte a este exercício depois do próximo capítulo).
3. Quantas notas de R$ 10 cabem no troco (use `Math.floor(troco / 10)`).

Entregue o arquivo e três execuções de teste coladas como comentário no final: troco normal, troco zero e pagamento insuficiente.
