"Projete a busca de um marketplace (ou de uma central de ajuda) que entenda o que o usuário quis dizer, e não só as palavras que ele digitou." Busca por palavra-chave falha quando a consulta e o documento usam termos diferentes para a mesma coisa: "tênis para correr" contra "calçado de corrida". Busca semântica resolve isso com embeddings, mas traz novos problemas de custo, avaliação e latência.

## Esclarecer o objetivo e a métrica

Pergunte o domínio e o que o usuário faz depois de buscar:

- **Marketplace**: sucesso é clique seguido de compra; métrica online é conversão por busca.
- **Central de ajuda**: sucesso é o usuário não abrir um chamado; métrica é a taxa de resolução sem contato.
- **Métrica de guarda**: taxa de buscas sem resultado clicado ("buscas abandonadas") e latência.

Escala hipotética para o exemplo: catálogo de 50 milhões de produtos, milhares de consultas por segundo no pico, p99 abaixo de 300 ms.

## Dados e rótulos

- **Logs de busca**: consulta, resultados exibidos, posições, cliques, compras. Pares consulta-produto com compra são positivos fortes; clique sem compra é positivo fraco.
- **Julgamentos humanos**: um conjunto pequeno de consultas rotuladas por avaliadores com notas de relevância (0 a 3). Caro, mas é o que permite avaliação offline confiável, inclusive em consultas raras.
- **Negativos**: os aleatórios são fáceis demais. Use **negativos difíceis**: itens que o modelo atual põe no topo mas que ninguém clica.

## Features e representações

- **Embeddings densos**: um codificador de texto (bi-encoder) gera um vetor para a consulta e outro para cada produto (título, descrição, categoria). Similaridade = cosseno.
- **Sinais lexicais**: BM25, correspondência exata de marca ou modelo ("iphone 13" não pode virar "iphone 12").
- **Sinais de qualidade**: popularidade, avaliação, estoque, preço relativo.
- **Personalização**: localização, histórico de categorias.

## Modelo de base e evolução

1. **Base**: índice invertido com BM25. Forte em consultas com nomes exatos e códigos.
2. **Recuperação densa**: bi-encoder pré-treinado, depois ajustado com pares consulta-clique e negativos difíceis. Os vetores dos produtos ficam num índice ANN.
3. **Híbrida**: une as listas lexical e densa. Um jeito simples e robusto é o **Reciprocal Rank Fusion** (RRF): cada documento ganha `1 / (k + posição)` em cada lista, e as somas definem a ordem.
4. **Re-ranqueamento**: um cross-encoder (consulta e produto entram juntos no modelo) ou um modelo de learning to rank com features de qualidade, aplicado só aos 100 primeiros.

O programa simula o efeito: a busca lexical só casa palavras, a "densa" usa um mapeamento de conceitos que imita um embedding treinado, e a híbrida funde as duas com RRF. A métrica é o MRR (média do inverso da posição do primeiro resultado relevante).

    ("tenis x200", "d6"),
    ("fone para treino", "d5"),
    ("case de notebook impermeavel", "d4"),
]

def termos(texto):
    return set(texto.split()) - PARADAS

def lexical(q, d):
    return len(termos(q) & termos(d))

def densa(q, d):
    cq = {CONCEITO[w] for w in termos(q) if w in CONCEITO}
    cd = {CONCEITO[w] for w in termos(d) if w in CONCEITO}
    return len(cq & cd) / ((len(cq) * len(cd)) ** 0.5 or 1)

def ranking(q, f):  # só devolve documentos com pontuação positiva
    achados = [k for k in docs if f(q, docs[k]) > 0]
    return sorted(achados, key=lambda k: (-f(q, docs[k]), k))

def rrf(listas, k=60):
    s = {}
    for lista in listas:
        for pos, d in enumerate(lista, start=1):
            s[d] = s.get(d, 0) + 1 / (k + pos)
    return sorted(s, key=lambda d: (-s[d], d))

def mrr(fn):
    total = 0
    for q, alvo in consultas:
        lista = fn(q)
        total += 1 / (lista.index(alvo) + 1) if alvo in lista else 0
    return total / len(consultas)

lex = lambda q: ranking(q, lexical)
den = lambda q: ranking(q, densa)
hib = lambda q: rrf([lex(q), den(q)])
for nome, fn in [("lexical", lex), ("densa", den), ("hibrida", hib)]:
    print(f"{nome:8s} MRR = {mrr(fn):.3f}")
for q, _ in consultas[:2]:
    print(f"'{q}': lexical {lex(q)[:2]}, densa {den(q)[:2]}, hibrida {hib(q)[:2]}")

static List<String> ranking(String q, BiFunction<String, String, Double> f) {  // só devolve documentos com pontuação positiva
    List<String> achados = new ArrayList<>();
    for (String k : docs.keySet()) {
        if (f.apply(q, docs.get(k)) > 0) achados.add(k);
    }
    achados.sort((a, b) -> {
        int c = Double.compare(f.apply(q, docs.get(b)), f.apply(q, docs.get(a)));
        return c != 0 ? c : a.compareTo(b);
    });
    return achados;
}

static List<String> rrf(List<List<String>> listas, int k) {
    Map<String, Double> s = new HashMap<>();
    for (List<String> lista : listas) {
        for (int i = 0; i < lista.size(); i++) {
            s.merge(lista.get(i), 1.0 / (k + i + 1), Double::sum);
        }
    }
    List<String> ordem = new ArrayList<>(s.keySet());
    ordem.sort((a, b) -> {
        int c = Double.compare(s.get(b), s.get(a));
        return c != 0 ? c : a.compareTo(b);
    });
    return ordem;
}

set<string> termos(const string& texto) {
    set<string> s;
    istringstream entrada(texto);
    string w;
    while (entrada >> w) {
        if (!PARADAS.count(w)) s.insert(w);
    }
    return s;
}

set<string> conceitos(const string& texto) {
    set<string> s;
    for (auto& w : termos(texto)) {
        auto it = CONCEITO.find(w);
        if (it != CONCEITO.end()) s.insert(it->second);
    }
    return s;
}

int emComum(const set<string>& a, const set<string>& b) {
    int n = 0;
    for (auto& x : a) n += b.count(x);
    return n;
}

}

    set<string> cd = conceitos(d);

    return emComum(cq, cd) / (raiz != 0 ? raiz : 1);

vector<string> ranking(const string& q, const Pontuador& f) {  // só devolve documentos com pontuação positiva
    vector<string> achados;
    for (auto& [k, texto] : docs) {
        if (f(q, texto) > 0) achados.push_back(k);
    }
    sort(achados.begin(), achados.end(), [&](const string& a, const string& b) {
        double fa = f(q, docs[a]), fb = f(q, docs[b]);
        return fa != fb ? fa > fb : a < b;
    });
    return achados;
}

vector<string> rrf(const vector<vector<string>>& listas, int k = 60) {
    map<string, double> s;
    for (auto& lista : listas) {
        for (size_t i = 0; i < lista.size(); i++) {
            s[lista[i]] += 1.0 / (k + i + 1);
        }
    }
    vector<string> ordem;
    for (auto& [d, _] : s) ordem.push_back(d);
    sort(ordem.begin(), ordem.end(), [&](const string& a, const string& b) {
        return s[a] != s[b] ? s[a] > s[b] : a < b;
    });
    return ordem;
}

double mrr(const Busca& fn) {
    double total = 0;
    for (auto& [q, alvo] : consultas) {
        vector<string> lista = fn(q);
        auto it = find(lista.begin(), lista.end(), alvo);
        if (it != lista.end()) total += 1.0 / (it - lista.begin() + 1);

    return total / consultas.size();
}

using System.Globalization;
using System.Linq;

static Dictionary<string, string> docs = new Dictionary<string, string> {
    { "d1", "calcado de corrida leve com amortecimento" },
    { "d2", "calcado esportivo para maratona" },
    { "d3", "mochila impermeavel para notebook" },
    { "d4", "bolsa para laptop resistente a agua" },
    { "d5", "fone bluetooth para academia" },
    { "d6", "tenis casual de couro x200" },
};
// imita um embedding treinado: palavras diferentes caem no mesmo conceito
static Dictionary<string, string> CONCEITO = new Dictionary<string, string> {
    { "tenis", "calcado" }, { "calcado", "calcado" }, { "sapato", "calcado" }, { "corrida", "corrida" },
    { "correr", "corrida" }, { "maratona", "corrida" }, { "mochila", "bolsa" }, { "bolsa", "bolsa" },
    { "notebook", "laptop" }, { "laptop", "laptop" }, { "impermeavel", "agua" }, { "agua", "agua" },
    { "fone", "audio" }, { "bluetooth", "audio" }, { "academia", "treino" }, { "treino", "treino" },
    { "esportivo", "treino" }, { "casual", "moda" }, { "couro", "moda" },
};
static HashSet<string> PARADAS = new HashSet<string> { "de", "para", "a", "com" };
static string[][] consultas = {  // { consulta, documento relevante }
    new[] { "sapato para correr", "d1" },
    new[] { "tenis x200", "d6" },
    new[] { "fone para treino", "d5" },
    new[] { "case de notebook impermeavel", "d4" },
};

static HashSet<string> Termos(string texto) {
    return new HashSet<string>(texto.Split(' ').Where(w => !PARADAS.Contains(w)));
}

static HashSet<string> Conceitos(string texto) {
    return new HashSet<string>(Termos(texto).Where(w => CONCEITO.ContainsKey(w)).Select(w => CONCEITO[w]));
}

static int EmComum(HashSet<string> a, HashSet<string> b) {
    return a.Count(x => b.Contains(x));
}

static double Lexical(string q, string d) {
    return EmComum(Termos(q), Termos(d));
}

static double Densa(string q, string d) {
    HashSet<string> cq = Conceitos(q);
    HashSet<string> cd = Conceitos(d);
    double raiz = Math.Sqrt(cq.Count * cd.Count);
    return EmComum(cq, cd) / (raiz != 0 ? raiz : 1);
}

static List<string> Ranking(string q, Func<string, string, double> f) {  // só devolve documentos com pontuação positiva
    return docs.Keys.Where(k => f(q, docs[k]) > 0)
        .OrderByDescending(k => f(q, docs[k]))
        .ThenBy(k => k, StringComparer.Ordinal)
        .ToList();
}

static List<string> Rrf(List<List<string>> listas, int k = 60) {
    var s = new Dictionary<string, double>();
    foreach (List<string> lista in listas) {
        for (int i = 0; i < lista.Count; i++) {
            double atual;
            s.TryGetValue(lista[i], out atual);
            s[lista[i]] = atual + 1.0 / (k + i + 1);
        }
    }
    return s.Keys.OrderByDescending(d => s[d]).ThenBy(d => d, StringComparer.Ordinal).ToList();
}

static double Mrr(Func<string, List<string>> fn) {
    double total = 0;
    foreach (string[] c in consultas) {
        List<string> lista = fn(c[0]);
        total += lista.Contains(c[1]) ? 1.0 / (lista.IndexOf(c[1]) + 1) : 0;
    }
    return total / consultas.Length;
}

// mostra a lista como o Python: ['d1', 'd2']
static string Mostra(List<string> lista) {
    return "[" + string.Join(", ", lista.Take(2).Select(d => "'" + d + "'")) + "]";
}

static void Main() {
    var cultura = CultureInfo.InvariantCulture;
    Func<string, List<string>> lex = q => Ranking(q, Lexical);
    Func<string, List<string>> den = q => Ranking(q, Densa);
    Func<string, List<string>> hib = q => Rrf(new List<List<string>> { lex(q), den(q) });
    string[] nomes = { "lexical", "densa", "hibrida" };
    var buscas = new List<Func<string, List<string>>> { lex, den, hib };
    for (int i = 0; i < nomes.Length; i++) {
        Console.WriteLine(string.Format(cultura, "{0,-8} MRR = {1:F3}", nomes[i], Mrr(buscas[i])));
    }
    for (int i = 0; i < 2; i++) {
        string consulta = consultas[i][0];
        Console.WriteLine("'" + consulta + "': lexical " + Mostra(lex(consulta)) + ", densa " + Mostra(den(consulta)) + ", hibrida " + Mostra(hib(consulta)));
    }
}

import (
	"fmt"
	"math"
	"sort"
	"strings"
)

var docs = map[string]string{
	"d1": "calcado de corrida leve com amortecimento",
	"d2": "calcado esportivo para maratona",
	"d3": "mochila impermeavel para notebook",
	"d4": "bolsa para laptop resistente a agua",
	"d5": "fone bluetooth para academia",
	"d6": "tenis casual de couro x200",
}

// imita um embedding treinado: palavras diferentes caem no mesmo conceito
var CONCEITO = map[string]string{
	"tenis": "calcado", "calcado": "calcado", "sapato": "calcado", "corrida": "corrida",
	"correr": "corrida", "maratona": "corrida", "mochila": "bolsa", "bolsa": "bolsa",
	"notebook": "laptop", "laptop": "laptop", "impermeavel": "agua", "agua": "agua",
	"fone": "audio", "bluetooth": "audio", "academia": "treino", "treino": "treino",
	"esportivo": "treino", "casual": "moda", "couro": "moda",
}
var PARADAS = map[string]bool{"de": true, "para": true, "a": true, "com": true}
var consultas = [][2]string{ // {consulta, documento relevante}
	{"sapato para correr", "d1"},
	{"tenis x200", "d6"},
	{"fone para treino", "d5"},
	{"case de notebook impermeavel", "d4"},
}

type Pontuador func(q, d string) float64
type Busca func(q string) []string

func termos(texto string) map[string]bool {
	s := map[string]bool{}
	for _, w := range strings.Fields(texto) {
		if !PARADAS[w] {
			s[w] = true
		}
	}
	return s
}

func conceitos(texto string) map[string]bool {
	s := map[string]bool{}
	for w := range termos(texto) {
		if c, ok := CONCEITO[w]; ok {
			s[c] = true
		}
	}
	return s
}

func emComum(a, b map[string]bool) int {
	n := 0
	for x := range a {
		if b[x] {
			n++
		}
	}
	return n
}

func lexical(q, d string) float64 {
	return float64(emComum(termos(q), termos(d)))
}

func densa(q, d string) float64 {
	cq := conceitos(q)
	cd := conceitos(d)
	raiz := math.Sqrt(float64(len(cq) * len(cd)))
	if raiz == 0 {
		raiz = 1
	}
	return float64(emComum(cq, cd)) / raiz
}

func ranking(q string, f Pontuador) []string { // só devolve documentos com pontuação positiva
	achados := []string{}
	for k, texto := range docs {
		if f(q, texto) > 0 {
			achados = append(achados, k)
		}
	}
	sort.Slice(achados, func(i, j int) bool {
		fi, fj := f(q, docs[achados[i]]), f(q, docs[achados[j]])
		if fi != fj {
			return fi > fj
		}
		return achados[i] < achados[j]
	})
	return achados
}

func rrf(listas [][]string, k int) []string {
	s := map[string]float64{}
	for _, lista := range listas {
		for i, d := range lista {
			s[d] += 1.0 / float64(k+i+1)
		}
	}
	ordem := []string{}
	for d := range s {
		ordem = append(ordem, d)
	}
	sort.Slice(ordem, func(i, j int) bool {
		if s[ordem[i]] != s[ordem[j]] {
			return s[ordem[i]] > s[ordem[j]]
		}
		return ordem[i] < ordem[j]
	})
	return ordem
}

func mrr(fn Busca) float64 {
	total := 0.0
	for _, c := range consultas {
		for i, d := range fn(c[0]) {
			if d == c[1] {
				total += 1.0 / float64(i+1)
				break
			}
		}
	}
	return total / float64(len(consultas))
}

// mostra a lista como o Python: ['d1', 'd2']
func mostra(lista []string) string {
	partes := []string{}
	for i, d := range lista {
		if i == 2 {
			break
		}
		partes = append(partes, "'"+d+"'")
	}
	return "[" + strings.Join(partes, ", ") + "]"
}

func main() {
	lex := func(q string) []string { return ranking(q, lexical) }
	den := func(q string) []string { return ranking(q, densa) }
	hib := func(q string) []string { return rrf([][]string{lex(q), den(q)}, 60) }
	nomes := []string{"lexical", "densa", "hibrida"}
	buscas := []Busca{lex, den, hib}
	for i, nome := range nomes {
		fmt.Printf("%-8s MRR = %.3f\n", nome, mrr(buscas[i]))
	}
	for _, c := range consultas[:2] {
		q := c[0]
		fmt.Printf("'%s': lexical %s, densa %s, hibrida %s\n", q, mostra(lex(q)), mostra(den(q)), mostra(hib(q)))
	}
}

É por isso que a maioria dos sistemas reais é híbrida.

## Arquitetura de treino e servimento

```text
 OFFLINE                                         ONLINE
 +-----------+   +-----------+   +----------+    consulta
 | catálogo  |-->| bi-encoder|-->| índice   |       |
 | produtos  |   | (lote)    |   | ANN      |   +---v--------------+
 +-----+-----+   +-----^-----+   +----+-----+   | normalização,    |
       |               |              |         | correção ortográf|
       |         +-----+-----+        |         +---+----------+---+
       |         | ajuste fino|       |             |          |
       |         | pares      |       |       +-----v---+ +----v-----+
       |         | consulta-  |       +------>| densa   | | BM25     |
       |         | clique     |               | top 200 | | top 200  |
       |         +-----^-----+                +----+----+ +----+-----+
       |               |                           +-----+-----+
       |         +-----+-----+                     +-----v-----+
       +-------->| logs de   |<--- cliques ---     | fusão RRF |
                 | busca     |                     +-----+-----+
                 +-----------+                     +-----v-----+
                                                   | re-ranker |-> top 20
                                                   +-----------+
```

O embedding da consulta é calculado online (alguns milissegundos num modelo pequeno, com cache para consultas populares). Ao trocar o bi-encoder, **todo o índice precisa ser re-embedado**, porque vetores de modelos diferentes não são comparáveis. Planeje isso como uma migração: construa o índice novo em paralelo e troque atomicamente.

## Avaliação

- **Offline**: recall@100 da recuperação (o re-ranker não salva o que não foi recuperado); NDCG@10 e MRR com julgamentos humanos; análise separada por fatias, como consultas de cauda longa e consultas com marca.
- **Online**: A/B com conversão por busca, taxa de buscas abandonadas e latência. Interleaving (misturar resultados de dois rankers na mesma lista) detecta diferenças com muito menos tráfego que um A/B tradicional.

## Monitoramento

Taxa de consultas sem resultado, distribuição da similaridade do primeiro resultado (queda indica consultas fora do domínio), frescor do índice (produtos novos ainda sem vetor), latência por estágio e drift de vocabulário: termos novos que aparecem nas consultas.

<Callout type="tip" title="Recall primeiro, precisão depois">
Ao propor a arquitetura, deixe claro que cada estágio tem sua métrica: recall@k para recuperação, NDCG para o re-ranker. Misturar as duas é um erro comum que o entrevistador costuma testar.
</Callout>

## Trade-offs

| Decisão | Opção A | Opção B |
| --- | --- | --- |
| Recuperação | Lexical: exata, barata, sem sinônimos | Densa: entende intenção, erra termos exatos |
| Re-ranker | Bi-encoder: rápido, menos preciso | Cross-encoder: preciso, caro por par |
| Índice ANN | HNSW: rápido, muita memória | IVF com quantização: menos memória, perde recall |

## Follow-ups comuns

- **Consultas em vários idiomas?** Codificador multilíngue, avaliado por idioma.
- **Produto novo sem cliques?** O bi-encoder usa só o texto, então ele já é recuperável; os sinais de popularidade entram depois.
- **Filtros (preço, tamanho)?** Filtre antes ou durante a busca ANN; filtrar depois pode deixar a página vazia.
- **Como reduzir custo?** Cache de embeddings de consultas frequentes e quantização dos vetores.
