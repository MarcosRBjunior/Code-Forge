Vazamento de dados (*data leakage*) acontece quando o modelo, durante o treino ou a avaliação, tem acesso a uma informação que não estará disponível no momento real da predição. O resultado é sempre o mesmo: métricas offline lindas, modelo decepcionante em produção. É o bug mais traiçoeiro de ML porque nada quebra; ao contrário, tudo parece funcionar melhor do que deveria.

## As formas mais comuns

- **Feature do futuro**: usar "número de compras em 30 dias" calculado hoje para um exemplo de dois meses atrás. O join point-in-time do feature store existe para evitar isso.
- **Feature que é consequência do rótulo**: num modelo de churn, a feature "abriu chamado de cancelamento" praticamente é o rótulo. Num modelo de fraude, "transação foi revisada manualmente" só existe porque alguém já suspeitou.
- **Divisão aleatória em dados temporais**: o treino passa a conter eventos posteriores aos do teste, e o modelo "lembra" de um comportamento que, na vida real, ainda não teria acontecido.
- **Mesma entidade dos dois lados**: o mesmo usuário, sessão ou documento quase duplicado no treino e no teste. O modelo memoriza a entidade em vez de generalizar.
- **Pré-processamento com o conjunto inteiro**: calcular média para normalização, vocabulário ou target encoding usando também os dados de teste.
- **Rótulo vazando pela fonte**: imagens de exames positivos vindas de um hospital específico, com uma marca d'água própria; o modelo aprende a marca, não a doença.

## Divisão temporal contra divisão aleatória

Em quase todo sistema de produção, o modelo é treinado com o passado e usado no futuro. A avaliação precisa imitar isso: treine até a data T, valide e teste depois de T. O programa simula usuários cujo comportamento muda ao longo de 100 dias e usa um modelo simples, a taxa de cliques histórica do usuário, para prever cliques.

```python
import random

random.seed(3)
DIAS, USUARIOS = 100, 300
eventos = []
for u in range(USUARIOS):
    inicio = random.uniform(0.02, 0.8)
    fim = random.uniform(0.02, 0.8)
    for dia in range(DIAS):
        p = inicio + (fim - inicio) * dia / DIAS
        eventos.append((dia, u, 1 if random.random() < p else 0))

def auc(pares):
    pares = sorted(pares)
    soma_rank, n_pos, i = 0.0, 0, 0
    while i < len(pares):
        j = i
        while j < len(pares) and pares[j][0] == pares[i][0]:
            j += 1
        rank_medio = (i + 1 + j) / 2
        pos = sum(y for _, y in pares[i:j])
        soma_rank += rank_medio * pos
        n_pos += pos
        i = j
    n_neg = len(pares) - n_pos
    return (soma_rank - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)

def avaliar(treino, teste):
    soma, cont = {}, {}
    for _, u, y in treino:
        soma[u] = soma.get(u, 0) + y
        cont[u] = cont.get(u, 0) + 1
    media = sum(y for *_, y in treino) / len(treino)
    def prever(u):
        return (soma.get(u, 0) + 5 * media) / (cont.get(u, 0) + 5)
    return auc([(prever(u), y) for _, u, y in teste])

embaralhados = eventos[:]
random.shuffle(embaralhados)
corte = int(0.8 * len(eventos))
print(f"divisao aleatoria: AUC = {avaliar(embaralhados[:corte], embaralhados[corte:]):.3f}")

treino_t = [e for e in eventos if e[0] < 80]
teste_t = [e for e in eventos if e[0] >= 80]
print(f"divisao temporal:  AUC = {avaliar(treino_t, teste_t):.3f}")

recente = [e for e in eventos if 60 <= e[0] < 80]
print(f"temporal, so os 20 dias mais recentes no treino: AUC = {avaliar(recente, teste_t):.3f}")
```

```javascript
function mulberry32(semente) {
  return () => {
    semente = (semente + 0x6d2b79f5) | 0;
    let z = Math.imul(semente ^ (semente >>> 15), 1 | semente);

    return ((z ^ (z >>> 14)) >>> 0) / 4294967296;

}
```

```java
import java.util.stream.*;

static double auc(List<double[]> entrada) {
    List<double[]> pares = new ArrayList<>(entrada);
    pares.sort((a, b) -> a[0] != b[0] ? Double.compare(a[0], b[0]) : Double.compare(a[1], b[1]));
    double somaRank = 0.0;
    long nPos = 0;
    int i = 0;
    while (i < pares.size()) {
        int j = i;
        while (j < pares.size() && pares.get(j)[0] == pares.get(i)[0]) j++;
        double rankMedio = (i + 1 + j) / 2.0;
        int pos = 0;
        for (int k = i; k < j; k++) pos += (int) pares.get(k)[1];
        somaRank += rankMedio * pos;
        nPos += pos;
        i = j;
    }
    long nNeg = pares.size() - nPos;
    return (somaRank - nPos * (nPos + 1) / 2.0) / ((double) nPos * nNeg);
}

static double avaliar(List<int[]> treino, List<int[]> teste) {
    Map<Integer, Integer> soma = new HashMap<>(), cont = new HashMap<>();
    double total = 0;
    for (int[] e : treino) {
        soma.merge(e[1], e[2], Integer::sum);
        cont.merge(e[1], 1, Integer::sum);
        total += e[2];
    }
    double media = total / treino.size();
    List<double[]> pares = new ArrayList<>();
    for (int[] e : teste) {
        int u = e[1];
        double prever = (soma.getOrDefault(u, 0) + 5 * media) / (cont.getOrDefault(u, 0) + 5);
        pares.add(new double[] {prever, e[2]});
    }
    return auc(pares);
}

    Random rng = new Random(3);
    final int DIAS = 100, USUARIOS = 300;

        double inicio = 0.02 + 0.78 * rng.nextDouble();
        double fim = 0.02 + 0.78 * rng.nextDouble();
        for (int dia = 0; dia < DIAS; dia++) {
            double p = inicio + (fim - inicio) * dia / DIAS;
            eventos.add(new int[] {dia, u, rng.nextDouble() < p ? 1 : 0});
        }
```

```csharp
    double somaRank = 0.0;
    long nPos = 0;
    int i = 0;
    while (i < pares.Count) {

        nPos += pos;
        i = j;

}

static double Avaliar(List<int[]> treino, List<int[]> teste) {
    var soma = new Dictionary<int, int>();
    var cont = new Dictionary<int, int>();
    double total = 0;
    foreach (int[] e in treino) {
        soma[e[1]] = (soma.ContainsKey(e[1]) ? soma[e[1]] : 0) + e[2];
        cont[e[1]] = (cont.ContainsKey(e[1]) ? cont[e[1]] : 0) + 1;
        total += e[2];
    }
    double media = total / treino.Count;
    var pares = new List<double[]>();
    foreach (int[] e in teste) {
        int u = e[1];
        int s = soma.ContainsKey(u) ? soma[u] : 0;
        int c = cont.ContainsKey(u) ? cont[u] : 0;
        pares.Add(new double[] { (s + 5 * media) / (c + 5), e[2] });
    }
    return Auc(pares);
}
```

```go
// os números sorteados vêm do gerador desta linguagem; a saída difere da mostrada no texto, mas a lógica e as conclusões são as mesmas
import (
	"fmt"
	"math/rand"
	"sort"
)

type Evento struct {
	dia, u, y int
}

type Par struct {
	score float64
	y     int
}

func auc(entrada []Par) float64 {
	pares := append([]Par{}, entrada...)
	sort.Slice(pares, func(a, b int) bool {
		if pares[a].score != pares[b].score {
			return pares[a].score < pares[b].score
		}
		return pares[a].y < pares[b].y
	})
	somaRank, nPos, i := 0.0, 0, 0
	for i < len(pares) {
		j := i
		for j < len(pares) && pares[j].score == pares[i].score {
			j++
		}
		rankMedio := float64(i+1+j) / 2
		pos := 0
		for k := i; k < j; k++ {
			pos += pares[k].y
		}
		somaRank += rankMedio * float64(pos)
		nPos += pos
		i = j
	}
	nNeg := len(pares) - nPos
	return (somaRank - float64(nPos)*float64(nPos+1)/2) / (float64(nPos) * float64(nNeg))
}

func avaliar(treino, teste []Evento) float64 {
	soma, cont := map[int]int{}, map[int]int{}
	total := 0
	for _, e := range treino {
		soma[e.u] += e.y
		cont[e.u]++
		total += e.y
	}
	media := float64(total) / float64(len(treino))
	prever := func(u int) float64 {
		return (float64(soma[u]) + 5*media) / float64(cont[u]+5)
	}
	var pares []Par
	for _, e := range teste {
		pares = append(pares, Par{prever(e.u), e.y})
	}
	return auc(pares)
}

func filtrar(eventos []Evento, de, ate int) []Evento {
	var r []Evento
	for _, e := range eventos {
		if de <= e.dia && e.dia < ate {
			r = append(r, e)
		}
	}
	return r
}

func main() {
	rng := rand.New(rand.NewSource(3))
	const DIAS, USUARIOS = 100, 300
	var eventos []Evento
	for u := 0; u < USUARIOS; u++ {
		inicio := 0.02 + 0.78*rng.Float64()
		fim := 0.02 + 0.78*rng.Float64()
		for dia := 0; dia < DIAS; dia++ {
			p := inicio + (fim-inicio)*float64(dia)/DIAS
			y := 0
			if rng.Float64() < p {
				y = 1
			}
			eventos = append(eventos, Evento{dia, u, y})
		}
	}

	embaralhados := append([]Evento{}, eventos...)
	rng.Shuffle(len(embaralhados), func(a, b int) { embaralhados[a], embaralhados[b] = embaralhados[b], embaralhados[a] })
	corte := int(0.8 * float64(len(eventos)))
	fmt.Printf("divisao aleatoria: AUC = %.3f\n", avaliar(embaralhados[:corte], embaralhados[corte:]))

	treinoT := filtrar(eventos, 0, 80)
	testeT := filtrar(eventos, 80, DIAS)
	fmt.Printf("divisao temporal:  AUC = %.3f\n", avaliar(treinoT, testeT))

	recente := filtrar(eventos, 60, 80)
	fmt.Printf("temporal, so os 20 dias mais recentes no treino: AUC = %.3f\n", avaliar(recente, testeT))
}
```

```text
Saída:
divisao aleatoria: AUC = 0.687
divisao temporal:  AUC = 0.649
temporal, so os 20 dias mais recentes no treino: AUC = 0.696
```

A divisão aleatória promete 0,687 de AUC, mas o modelo só entrega 0,649 quando avaliado como será usado: o treino inclui dias 81 a 99 de cada usuário, então a taxa estimada já reflete o comportamento futuro. A divisão temporal mostra o número honesto. A terceira linha traz uma lição extra: treinando só com os 20 dias mais recentes, a AUC sobe para 0,696. Quando o mundo muda, dados mais recentes podem valer mais que dados abundantes, o que motiva retreinos frequentes ou janelas de treino com peso para o recente.

## Como prevenir

| Fonte de vazamento | Defesa |
| --- | --- |
| Feature do futuro | Join point-in-time; logar features no momento da predição |
| Feature consequência do rótulo | Para cada feature, perguntar: "eu teria isso no instante da decisão?" |
| Divisão aleatória | Divisão por tempo, com intervalo entre treino e teste se o rótulo demora |
| Entidade repetida | Divisão por grupo (usuário, sessão, documento) |
| Pré-processamento global | Ajustar normalizadores e encoders só no treino |

<Callout type="tip" title="Desconfie de resultados bons demais">
Se uma feature sozinha dá AUC de 0,99, ou se o modelo novo melhora 20 pontos sobre o anterior, procure vazamento antes de comemorar. Olhe a importância das features: a campeã costuma ser a culpada.
</Callout>

Um cuidado adicional com rótulos atrasados: se o rótulo de fraude só fecha em 60 dias, deixe um intervalo entre o fim do treino e o começo do teste, e garanta que os exemplos do treino já tenham rótulo maduro.
