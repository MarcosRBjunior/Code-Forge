A recuperação precisa achar algumas centenas de itens relevantes entre milhões em poucos milissegundos. Um modelo que recebe o par usuário-item e devolve um score não serve: você teria de rodá-lo milhões de vezes por requisição. A ideia do **two-tower** (duas torres) é separar o cálculo: uma rede transforma o usuário num vetor, outra transforma o item num vetor, e a relevância é simplesmente o **produto interno** entre os dois. Como os vetores dos itens não dependem do usuário, você os calcula antes e os coloca num índice de vizinhos mais próximos.

## Como funciona

```text
 features do usuario            features do item
 (id, historico, pais,          (id, categoria, texto,
  hora, dispositivo)             idade, criador)
        |                              |
  +-----v------+                 +-----v------+
  | torre do   |                 | torre do   |
  | usuario    |                 | item       |
  +-----+------+                 +-----+------+
        | u (ex.: 64 dims)             | v (64 dims)
        +-------------+----------------+
                      |
               score = u . v
```

- **Treino:** pares positivos (o usuário clicou, assistiu, comprou) contra negativos. Os negativos mais usados são os **in-batch**: num lote de B pares, os itens dos outros B - 1 pares servem de negativos para cada usuário, e a perda é uma softmax sobre o lote. É barato, mas favorece punir itens populares (eles aparecem mais nos lotes), o que se corrige subtraindo o log da frequência do item do score durante o treino.
- **Indexação:** um job batch roda a torre do item sobre o catálogo inteiro e publica os vetores num índice ANN (HNSW, IVF, quantização de produto).
- **Servimento:** a cada requisição, roda só a torre do usuário (uma inferência), consulta o índice e recebe os K itens de maior produto interno em poucos milissegundos.

## Um two-tower de brinquedo

O programa abaixo cria 60 usuários e 90 itens de 3 gêneros. Cada usuário prefere um gênero. A torre do item soma um embedding do id com um embedding do gênero; a do usuário é um embedding por id. O treino usa descida de gradiente com perda logística e negativos amostrados. Depois comparamos o acerto em interações separadas para teste com uma recomendação por popularidade.

```python
import math
import random

random.seed(1)
D, U, I, G = 6, 60, 90, 3
genero_item = [i % G for i in range(I)]
gosto = [random.randrange(G) for _ in range(U)]

def interacoes(n):
    pares = []
    for _ in range(n):
        u = random.randrange(U)
        g = gosto[u] if random.random() < 0.85 else random.randrange(G)
        candidatos = [i for i in range(I) if genero_item[i] == g]
        pares.append((u, random.choice(candidatos[: 10 + u % 20])))
    return pares

treino, teste = interacoes(3000), interacoes(300)

def emb(n):
    return [[random.gauss(0, 0.1) for _ in range(D)] for _ in range(n)]
E_user, E_item, E_gen = emb(U), emb(I), emb(G)

def torre_usuario(u):
    return E_user[u]
def torre_item(i):
    return [a + b for a, b in zip(E_item[i], E_gen[genero_item[i]])]
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

lr = 0.1
for epoca in range(15):
    random.shuffle(treino)
    for u, pos in treino:
        for i, y in [(pos, 1)] + [(random.randrange(I), 0) for _ in range(3)]:
            uv, iv = torre_usuario(u), torre_item(i)
            g = 1 / (1 + math.exp(-dot(uv, iv))) - y
            for d in range(D):
                gu, gi = g * iv[d], g * uv[d]
                E_user[u][d] -= lr * gu
                E_item[i][d] -= lr * gi
                E_gen[genero_item[i]][d] -= lr * gi * 0.2

indice = [torre_item(i) for i in range(I)]  # pre-calculado, como num indice ANN
popular = sorted(range(I), key=lambda i: -sum(1 for _, x in treino if x == i))[:10]

def hit_rate(recomendar):
    return sum(i in recomendar(u) for u, i in teste) / len(teste)

def two_tower(u):
    uv = torre_usuario(u)
    return sorted(range(I), key=lambda i: -dot(uv, indice[i]))[:10]

print(f"hit@10 popularidade: {hit_rate(lambda u: popular):.3f}")
print(f"hit@10 two-tower:    {hit_rate(two_tower):.3f}")
top = two_tower(0)[:5]
print(f"usuario 0 gosta do genero {gosto[0]}; generos do top 5: {[genero_item[i] for i in top]}")
```

function mulberry32(semente) {
  return () => {
    semente = (semente + 0x6d2b79f5) | 0;
    let z = Math.imul(semente ^ (semente >>> 15), 1 | semente);
    z = (z + Math.imul(z ^ (z >>> 7), 61 | z)) ^ z;
    return ((z ^ (z >>> 14)) >>> 0) / 4294967296;
  };
}

const randrange = (n) => Math.floor(rng() * n);

function shuffle(lista) {
  for (let i = lista.length - 1; i > 0; i--) {
    const j = randrange(i + 1);
    [lista[i], lista[j]] = [lista[j], lista[i]];
  }
}
function gauss(mu, sigma) {
  const u1 = 1 - rng();

}

import java.util.*;
import java.util.function.*;
import java.util.stream.*;

static final int D = 6, U = 60, I = 90, G = 3;
static Random rng = new Random(1);
static int[] generoItem = new int[I];
static int[] gosto = new int[U];
static double[][] E_user, E_item, E_gen, indice;
static List<int[]> treino, teste;

static List<int[]> interacoes(int n) {
    List<int[]> pares = new ArrayList<>();
    for (int k = 0; k < n; k++) {
        int u = rng.nextInt(U);
        int g = rng.nextDouble() < 0.85 ? gosto[u] : rng.nextInt(G);
        List<Integer> candidatos = new ArrayList<>();
        for (int i = 0; i < I; i++) if (generoItem[i] == g) candidatos.add(i);
        List<Integer> primeiros = candidatos.subList(0, Math.min(10 + u % 20, candidatos.size()));
        pares.add(new int[] {u, primeiros.get(rng.nextInt(primeiros.size()))});
    }
    return pares;
}

static double[][] emb(int n) {
    double[][] m = new double[n][D];
    for (int k = 0; k < n; k++)
        for (int d = 0; d < D; d++) m[k][d] = rng.nextGaussian() * 0.1;
    return m;
}

static double[] torreUsuario(int u) {
    return E_user[u];
}

static double[] torreItem(int i) {
    double[] v = new double[D];
    for (int d = 0; d < D; d++) v[d] = E_item[i][d] + E_gen[generoItem[i]][d];
    return v;
}

static double dot(double[] a, double[] b) {
    double soma = 0.0;
    for (int d = 0; d < a.length; d++) soma += a[d] * b[d];
    return soma;
}

static double hitRate(IntFunction<List<Integer>> recomendar) {
    int acertos = 0;
    for (int[] par : teste) if (recomendar.apply(par[0]).contains(par[1])) acertos++;
    return (double) acertos / teste.size();
}

static List<Integer> twoTower(int u) {
    double[] uv = torreUsuario(u);
    return IntStream.range(0, I).boxed()
        .sorted(Comparator.comparingDouble((Integer i) -> -dot(uv, indice[i])))
        .limit(10).collect(Collectors.toList());
}

public static void main(String[] args) {
    for (int i = 0; i < I; i++) generoItem[i] = i % G;
    for (int u = 0; u < U; u++) gosto[u] = rng.nextInt(G);
    treino = interacoes(3000);
    teste = interacoes(300);
    E_user = emb(U);
    E_item = emb(I);
    E_gen = emb(G);

    double lr = 0.1;
    for (int epoca = 0; epoca < 15; epoca++) {
        Collections.shuffle(treino, rng);
        for (int[] par : treino) {
            int u = par[0];
            int[][] exemplos = {{par[1], 1}, {rng.nextInt(I), 0}, {rng.nextInt(I), 0}, {rng.nextInt(I), 0}};
            for (int[] ex : exemplos) {
                int i = ex[0], y = ex[1];
                double[] uv = torreUsuario(u), iv = torreItem(i);
                double g = 1 / (1 + Math.exp(-dot(uv, iv))) - y;
                for (int d = 0; d < D; d++) {
                    double gu = g * iv[d], gi = g * uv[d];
                    E_user[u][d] -= lr * gu;
                    E_item[i][d] -= lr * gi;
                    E_gen[generoItem[i]][d] -= lr * gi * 0.2;
                }
            }
        }
    }

    indice = new double[I][];
    for (int i = 0; i < I; i++) indice[i] = torreItem(i);  // pre-calculado, como num indice ANN
    int[] contagem = new int[I];
    for (int[] par : treino) contagem[par[1]]++;
    List<Integer> popular = IntStream.range(0, I).boxed()
        .sorted(Comparator.comparingInt((Integer i) -> -contagem[i]))
        .limit(10).collect(Collectors.toList());

    System.out.println(String.format(Locale.US, "hit@10 popularidade: %.3f", hitRate(u -> popular)));
    System.out.println(String.format(Locale.US, "hit@10 two-tower:    %.3f", hitRate(u -> twoTower(u))));
    List<Integer> top = twoTower(0).subList(0, 5);
    List<Integer> generos = new ArrayList<>();
    for (int i : top) generos.add(generoItem[i]);
    System.out.println("usuario 0 gosta do genero " + gosto[0] + "; generos do top 5: " + generos);
}

#include <algorithm>
#include <cmath>
#include <cstdio>
#include <functional>
#include <random>
#include <utility>

using namespace std;

const int D = 6, U = 60, I = 90, G = 3;
mt19937 rng(1);
uniform_real_distribution<double> uniforme(0.0, 1.0);

// equivalente ao random.randrange(n) do Python
int randrange(int n) {
    return uniform_int_distribution<int>(0, n - 1)(rng);
}

vector<int> generoItem(I), gosto(U);
vector<vector<double>> E_user, E_item, E_gen, indice;
vector<pair<int, int>> treino, teste;

vector<pair<int, int>> interacoes(int n) {
    vector<pair<int, int>> pares;
    for (int k = 0; k < n; k++) {
        int u = randrange(U);
        int g = uniforme(rng) < 0.85 ? gosto[u] : randrange(G);
        vector<int> candidatos;
        for (int i = 0; i < I; i++) if (generoItem[i] == g) candidatos.push_back(i);
        int limite = min(10 + u % 20, (int)candidatos.size());
        pares.push_back({u, candidatos[randrange(limite)]});
    }
    return pares;
}

vector<vector<double>> emb(int n) {
    normal_distribution<double> normal(0.0, 0.1);
    vector<vector<double>> m(n, vector<double>(D));
    for (auto& linha : m)
        for (double& x : linha) x = normal(rng);
    return m;
}

vector<double> torreUsuario(int u) {
    return E_user[u];
}

vector<double> torreItem(int i) {
    vector<double> v(D);
    for (int d = 0; d < D; d++) v[d] = E_item[i][d] + E_gen[generoItem[i]][d];
    return v;
}

double dot(const vector<double>& a, const vector<double>& b) {
    double soma = 0.0;
    for (size_t d = 0; d < a.size(); d++) soma += a[d] * b[d];
    return soma;
}

double hitRate(const function<vector<int>(int)>& recomendar) {
    int acertos = 0;
    for (auto [u, i] : teste) {
        vector<int> recs = recomendar(u);
        if (find(recs.begin(), recs.end(), i) != recs.end()) acertos++;
    }
    return (double)acertos / teste.size();
}

vector<int> twoTower(int u) {
    vector<double> uv = torreUsuario(u);
    vector<int> itens(I);
    for (int i = 0; i < I; i++) itens[i] = i;
    stable_sort(itens.begin(), itens.end(), [&](int a, int b) { return dot(uv, indice[a]) > dot(uv, indice[b]); });
    itens.resize(10);
    return itens;
}

    for (int k = 0; k < 5; k++) printf("%s%d", k ? ", " : "", generoItem[top[k]]);
    printf("]\n");
}

// equivalente ao random.gauss(mu, sigma) do Python (Box-Muller)
static double Gauss(double mu, double sigma) {
    double u1 = 1.0 - rng.NextDouble();
    double u2 = rng.NextDouble();
    return mu + sigma * Math.Sqrt(-2.0 * Math.Log(u1)) * Math.Cos(2.0 * Math.PI * u2);
}

// equivalente ao random.shuffle (Fisher-Yates)
static void Shuffle(List<int[]> lista) {
    for (int i = lista.Count - 1; i > 0; i--) {
        int j = rng.Next(i + 1);
        var tmp = lista[i];
        lista[i] = lista[j];
        lista[j] = tmp;
    }
}

static List<int[]> Interacoes(int n) {
    var pares = new List<int[]>();
    for (int k = 0; k < n; k++) {
        int u = rng.Next(U);
        int g = rng.NextDouble() < 0.85 ? gosto[u] : rng.Next(G);
        var candidatos = new List<int>();
        for (int i = 0; i < I; i++) if (generoItem[i] == g) candidatos.Add(i);
        var primeiros = candidatos.Take(10 + u % 20).ToList();
        pares.Add(new[] { u, primeiros[rng.Next(primeiros.Count)] });
    }
    return pares;
}

static double[][] Emb(int n) {
    var m = new double[n][];
    for (int k = 0; k < n; k++) {
        m[k] = new double[D];
        for (int d = 0; d < D; d++) m[k][d] = Gauss(0, 0.1);
    }
    return m;
}

static double[] TorreUsuario(int u) {
    return E_user[u];
}

static double[] TorreItem(int i) {
    var v = new double[D];
    for (int d = 0; d < D; d++) v[d] = E_item[i][d] + E_gen[generoItem[i]][d];
    return v;
}

static double Dot(double[] a, double[] b) {
    double soma = 0.0;
    for (int d = 0; d < a.Length; d++) soma += a[d] * b[d];
    return soma;
}

static double HitRate(Func<int, List<int>> recomendar) {
    int acertos = teste.Count(par => recomendar(par[0]).Contains(par[1]));
    return (double)acertos / teste.Count;
}

static List<int> TwoTower(int u) {
    double[] uv = TorreUsuario(u);
    return Enumerable.Range(0, I).OrderBy(i => -Dot(uv, indice[i])).Take(10).ToList();
}

static void Main() {
    var cultura = CultureInfo.InvariantCulture;
    for (int i = 0; i < I; i++) generoItem[i] = i % G;
    for (int u = 0; u < U; u++) gosto[u] = rng.Next(G);
    treino = Interacoes(3000);
    teste = Interacoes(300);
    E_user = Emb(U);
    E_item = Emb(I);
    E_gen = Emb(G);

    double lr = 0.1;
    for (int epoca = 0; epoca < 15; epoca++) {
        Shuffle(treino);
        foreach (int[] par in treino) {
            int u = par[0];
            var exemplos = new List<int[]> { new[] { par[1], 1 } };
            for (int k = 0; k < 3; k++) exemplos.Add(new[] { rng.Next(I), 0 });
            foreach (int[] ex in exemplos) {
                int i = ex[0], y = ex[1];
                double[] uv = TorreUsuario(u), iv = TorreItem(i);
                double g = 1 / (1 + Math.Exp(-Dot(uv, iv))) - y;
                for (int d = 0; d < D; d++) {
                    double gu = g * iv[d], gi = g * uv[d];
                    E_user[u][d] -= lr * gu;
                    E_item[i][d] -= lr * gi;
                    E_gen[generoItem[i]][d] -= lr * gi * 0.2;
                }
            }
        }
    }

    indice = new double[I][];
    for (int i = 0; i < I; i++) indice[i] = TorreItem(i);  // pre-calculado, como num indice ANN
    var contagem = new int[I];
    foreach (int[] par in treino) contagem[par[1]]++;
    var popular = Enumerable.Range(0, I).OrderBy(i => -contagem[i]).Take(10).ToList();

    Console.WriteLine("hit@10 popularidade: " + HitRate(usr => popular).ToString("F3", cultura));
    Console.WriteLine("hit@10 two-tower:    " + HitRate(TwoTower).ToString("F3", cultura));
    var top = TwoTower(0).Take(5);
    string generos = string.Join(", ", top.Select(i => generoItem[i]));
    Console.WriteLine($"usuario 0 gosta do genero {gosto[0]}; generos do top 5: [{generos}]");
}

import (
	"fmt"
	"math"
	"math/rand"
	"sort"
	"strings"
)

const D, U, I, G = 6, 60, 90, 3

var rng = rand.New(rand.NewSource(1))
var generoItem = make([]int, I)
var gosto = make([]int, U)
var E_user, E_item, E_gen, indice [][]float64
var treino, teste [][2]int

func interacoes(n int) [][2]int {
	var pares [][2]int
	for k := 0; k < n; k++ {
		u := rng.Intn(U)
		g := gosto[u]
		if rng.Float64() >= 0.85 {
			g = rng.Intn(G)
		}
		var candidatos []int
		for i := 0; i < I; i++ {
			if generoItem[i] == g {
				candidatos = append(candidatos, i)
			}
		}
		limite := 10 + u%20
		if limite > len(candidatos) {
			limite = len(candidatos)
		}
		pares = append(pares, [2]int{u, candidatos[rng.Intn(limite)]})
	}
	return pares
}

func emb(n int) [][]float64 {
	m := make([][]float64, n)
	for k := range m {
		m[k] = make([]float64, D)
		for d := range m[k] {
			m[k][d] = rng.NormFloat64() * 0.1
		}
	}
	return m
}

func torreUsuario(u int) []float64 {
	return E_user[u]
}

func torreItem(i int) []float64 {
	v := make([]float64, D)
	for d := 0; d < D; d++ {
		v[d] = E_item[i][d] + E_gen[generoItem[i]][d]
	}
	return v
}

func dot(a, b []float64) float64 {
	soma := 0.0
	for d := range a {
		soma += a[d] * b[d]
	}
	return soma
}

func contem(lista []int, x int) bool {
	for _, v := range lista {
		if v == x {
			return true
		}
	}
	return false
}

func hitRate(recomendar func(int) []int) float64 {
	acertos := 0
	for _, par := range teste {
		if contem(recomendar(par[0]), par[1]) {
			acertos++
		}
	}
	return float64(acertos) / float64(len(teste))
}

func twoTower(u int) []int {
	uv := torreUsuario(u)
	itens := make([]int, I)
	for i := range itens {
		itens[i] = i
	}
	sort.SliceStable(itens, func(a, b int) bool { return dot(uv, indice[itens[a]]) > dot(uv, indice[itens[b]]) })
	return itens[:10]
}

func main() {
	for i := 0; i < I; i++ {
		generoItem[i] = i % G
	}
	for u := 0; u < U; u++ {
		gosto[u] = rng.Intn(G)
	}
	treino = interacoes(3000)
	teste = interacoes(300)
	E_user, E_item, E_gen = emb(U), emb(I), emb(G)

	lr := 0.1
	for epoca := 0; epoca < 15; epoca++ {
		rng.Shuffle(len(treino), func(a, b int) { treino[a], treino[b] = treino[b], treino[a] })
		for _, par := range treino {
			u := par[0]
			exemplos := [][2]int{{par[1], 1}}
			for k := 0; k < 3; k++ {
				exemplos = append(exemplos, [2]int{rng.Intn(I), 0})
			}
			for _, ex := range exemplos {
				i, y := ex[0], ex[1]
				uv, iv := torreUsuario(u), torreItem(i)
				g := 1/(1+math.Exp(-dot(uv, iv))) - float64(y)
				for d := 0; d < D; d++ {
					gu, gi := g*iv[d], g*uv[d]
					E_user[u][d] -= lr * gu
					E_item[i][d] -= lr * gi
					E_gen[generoItem[i]][d] -= lr * gi * 0.2
				}
			}
		}
	}

	for i := 0; i < I; i++ {
		indice = append(indice, torreItem(i)) // pre-calculado, como num indice ANN
	}
	contagem := make([]int, I)
	for _, par := range treino {
		contagem[par[1]]++
	}
	popular := make([]int, I)
	for i := range popular {
		popular[i] = i
	}
	sort.SliceStable(popular, func(a, b int) bool { return contagem[popular[a]] > contagem[popular[b]] })
	popular = popular[:10]

	fmt.Printf("hit@10 popularidade: %.3f\n", hitRate(func(int) []int { return popular }))
	fmt.Printf("hit@10 two-tower:    %.3f\n", hitRate(twoTower))
	top := twoTower(0)[:5]
	var generos []string
	for _, i := range top {
		generos = append(generos, fmt.Sprint(generoItem[i]))
	}
	fmt.Printf("usuario 0 gosta do genero %d; generos do top 5: [%s]\n", gosto[0], strings.Join(generos, ", "))
}

O two-tower acerta quase três vezes mais que a popularidade (0,44 contra 0,15) e, sem ninguém dizer quais são os gêneros, aprende a colocar no topo itens do gênero preferido do usuário. O que vale observar: a recomendação vem de um único produto interno por item, sobre vetores calculados antes. Num sistema real, essa varredura de 90 itens vira uma consulta ANN sobre milhões.

## Trade-offs

| Ponto | Vantagem | Limitação |
| --- | --- | --- |
| Separação das torres | Itens indexados offline; servimento barato | Sem interação fina entre features de usuário e item |
| Produto interno | Busca ANN rápida | Expressividade menor que um ranqueador com features cruzadas |
| Negativos in-batch | Treino eficiente | Viés de popularidade, exige correção |
| Torre do item com conteúdo | Cobre itens novos | Embedding de id ainda é fraco para itens sem histórico |

A limitação central é que usuário e item só se encontram no produto interno final. Uma feature como "este usuário já assistiu outros vídeos deste criador" não cabe naturalmente. Por isso o two-tower é ótimo para recuperação e raramente é o ranqueador final.

Outros cuidados: os vetores do índice e a torre do usuário precisam vir **da mesma versão** do modelo (se você atualizar uma torre sem reindexar, os espaços deixam de ser compatíveis); e a torre do usuário pode usar features de sessão em tempo real, o que torna a recuperação sensível ao contexto.

<Callout type="note" title="Itens novos">
Se a torre do item usa só o id, um item recém-publicado tem embedding aleatório. Incluir conteúdo (texto, categoria, criador) na torre resolve boa parte do cold start na recuperação.
</Callout>
