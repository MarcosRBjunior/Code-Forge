Imagine três times de ML na mesma empresa, cada um calculando "número de compras do usuário nos últimos 30 dias" com seu próprio SQL. Um conta pedidos cancelados, outro não; um usa fuso UTC, outro o horário local. Pior: no treino a feature vem de uma consulta batch no data warehouse, e no servimento vem de um código Java escrito por outra pessoa. Os valores divergem, e o modelo, ótimo offline, piora em produção. Esse descompasso tem nome, **training-serving skew**, e o feature store existe principalmente para eliminá-lo.

## O que é um feature store

É uma camada que guarda **definições** de features e seus **valores**, servindo os mesmos números para treino e para inferência. Tem quatro partes:

- **Registro de definições**: cada feature tem nome, entidade (usuário, item, comerciante), tipo, dono, fonte e a transformação que a calcula, escrita uma vez só.
- **Armazenamento offline**: histórico completo dos valores com carimbo de tempo, num data lake ou warehouse. Serve para montar datasets de treino.
- **Armazenamento online**: só o valor mais recente por entidade, num banco chave-valor de baixa latência (Redis, DynamoDB, Cassandra). Serve para o modelo em produção, em poucos milissegundos.
- **Materialização**: jobs batch e de streaming que calculam as features e escrevem nos dois armazenamentos.

```text
              definições de features (código versionado)
                              │
            ┌─────────────────┴─────────────────┐
            v                                   v
     job batch diário                  job de streaming
            │                                   │
            v                                   v
   offline store (histórico) ──sincroniza──> online store (último valor)
            │                                   │
   join point-in-time                    leitura por chave, p99 de poucos ms
            │                                   │
            v                                   v
     dataset de treino                  serviço de predição
```

## A consulta point-in-time

O ponto mais sutil é montar o dataset de treino. Para cada exemplo rotulado (usuário, momento, rótulo), você precisa do valor da feature **como estava naquele momento**, não como está hoje. Se usar o valor atual, você vaza o futuro para o passado. O feature store oferece um join "as of": para cada exemplo, pega o último valor com carimbo anterior ou igual ao momento do evento.

```python
import bisect

historico = {
    "u1": [("2026-01-05", 2), ("2026-02-01", 5), ("2026-03-01", 9)],
    "u2": [("2026-01-20", 0), ("2026-02-25", 1)],
}

def as_of(usuario, momento):
    linhas = historico.get(usuario, [])
    datas = [d for d, _ in linhas]
    i = bisect.bisect_right(datas, momento)
    return linhas[i - 1][1] if i else None

def ultimo_valor(usuario):
    return historico[usuario][-1][1]

exemplos = [("u1", "2026-01-15", 0), ("u1", "2026-02-10", 1), ("u2", "2026-02-01", 0), ("u2", "2026-01-10", 0)]
print("usuario momento     correto  ingenuo")
for usuario, momento, rotulo in exemplos:
    print(f"{usuario}      {momento}  {str(as_of(usuario, momento)):>7}  {ultimo_valor(usuario):>7}")

online = {u: ultimo_valor(u) for u in historico}
print("online store:", online)
```

```javascript
const historico = {
  u1: [["2026-01-05", 2], ["2026-02-01", 5], ["2026-03-01", 9]],
  u2: [["2026-01-20", 0], ["2026-02-25", 1]],

// equivalente a bisect.bisect_right: primeira posição com valor maior que x
function bisectRight(lista, x) {
  let lo = 0, hi = lista.length;
  while (lo < hi) {
    const meio = Math.floor((lo + hi) / 2);
    if (x < lista[meio]) hi = meio;
    else lo = meio + 1;
  }
  return lo;
}

function asOf(usuario, momento) {
  const linhas = historico[usuario] || [];
  const datas = linhas.map(([d]) => d);
  const i = bisectRight(datas, momento);
  return i ? linhas[i - 1][1] : null;
}

  const linhas = historico[usuario];
  return linhas[linhas.length - 1][1];
}
```

```java
import java.util.*;

static class Linha {
    final String data;
    final int valor;

    Linha(String data, int valor) {
        this.data = data;
        this.valor = valor;
    }
}

static final Map<String, List<Linha>> historico = new LinkedHashMap<>();

// equivalente a bisect.bisect_right: primeira posição com valor maior que x
static int bisectRight(List<String> lista, String x) {
    int lo = 0, hi = lista.size();
    while (lo < hi) {
        int meio = (lo + hi) / 2;
        if (x.compareTo(lista.get(meio)) < 0) hi = meio;
        else lo = meio + 1;
    }
    return lo;
}

static Integer asOf(String usuario, String momento) {
    List<Linha> linhas = historico.getOrDefault(usuario, List.of());
    List<String> datas = new ArrayList<>();
    for (Linha l : linhas) datas.add(l.data);
    int i = bisectRight(datas, momento);
    return i != 0 ? Integer.valueOf(linhas.get(i - 1).valor) : null;
}

static int ultimoValor(String usuario) {
    List<Linha> linhas = historico.get(usuario);
    return linhas.get(linhas.size() - 1).valor;
}

public static void main(String[] args) {
    historico.put("u1", List.of(new Linha("2026-01-05", 2), new Linha("2026-02-01", 5), new Linha("2026-03-01", 9)));
    historico.put("u2", List.of(new Linha("2026-01-20", 0), new Linha("2026-02-25", 1)));

    // usuario, momento, rotulo
    String[][] exemplos = {{"u1", "2026-01-15", "0"}, {"u1", "2026-02-10", "1"}, {"u2", "2026-02-01", "0"}, {"u2", "2026-01-10", "0"}};
    System.out.println("usuario momento     correto  ingenuo");
    for (String[] e : exemplos) {
        String usuario = e[0], momento = e[1];
        Integer correto = asOf(usuario, momento);
        String texto = correto == null ? "None" : correto.toString();
        System.out.println(String.format("%s      %s  %7s  %7d", usuario, momento, texto, ultimoValor(usuario)));
    }

    List<String> pares = new ArrayList<>();
    for (String u : historico.keySet()) pares.add("'" + u + "': " + ultimoValor(u));
    System.out.println("online store: {" + String.join(", ", pares) + "}");
}
```

```cpp
#include <algorithm>
#include <cstdio>
#include <map>
#include <optional>
#include <string>
#include <utility>
#include <vector>
using namespace std;

map<string, vector<pair<string, int>>> historico = {
    {"u1", {{"2026-01-05", 2}, {"2026-02-01", 5}, {"2026-03-01", 9}}},
    {"u2", {{"2026-01-20", 0}, {"2026-02-25", 1}}},
};

optional<int> asOf(const string& usuario, const string& momento) {
    auto it = historico.find(usuario);
    if (it == historico.end()) return nullopt;
    auto& linhas = it->second;
    vector<string> datas;
    for (auto& [d, _] : linhas) datas.push_back(d);
    // upper_bound faz o papel de bisect.bisect_right
    size_t i = upper_bound(datas.begin(), datas.end(), momento) - datas.begin();
    if (i == 0) return nullopt;
    return linhas[i - 1].second;
}

int ultimoValor(const string& usuario) {
    return historico[usuario].back().second;
}

struct Exemplo {
    string usuario, momento;
    int rotulo;
};

int main() {
    vector<Exemplo> exemplos = {{"u1", "2026-01-15", 0}, {"u1", "2026-02-10", 1}, {"u2", "2026-02-01", 0}, {"u2", "2026-01-10", 0}};
    printf("usuario momento     correto  ingenuo\n");
    for (auto& e : exemplos) {
        optional<int> correto = asOf(e.usuario, e.momento);
        string texto = correto ? to_string(*correto) : "None";
        printf("%s      %s  %7s  %7d\n", e.usuario.c_str(), e.momento.c_str(), texto.c_str(), ultimoValor(e.usuario));

}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Linha {
    public string Data;
    public int Valor;

    public Linha(string data, int valor) {
        Data = data;
        Valor = valor;
    }
}

static string[] usuarios = { "u1", "u2" };

static Dictionary<string, List<Linha>> historico = new Dictionary<string, List<Linha>> {
    { "u1", new List<Linha> { new Linha("2026-01-05", 2), new Linha("2026-02-01", 5), new Linha("2026-03-01", 9) } },
    { "u2", new List<Linha> { new Linha("2026-01-20", 0), new Linha("2026-02-25", 1) } },
};

// equivalente a bisect.bisect_right: primeira posição com valor maior que x
static int BisectRight(List<string> lista, string x) {
    int lo = 0, hi = lista.Count;
    while (lo < hi) {
        int meio = (lo + hi) / 2;
        if (string.CompareOrdinal(x, lista[meio]) < 0) hi = meio;
        else lo = meio + 1;
    }
    return lo;
}

static int? AsOf(string usuario, string momento) {
    List<Linha> linhas;
    if (!historico.TryGetValue(usuario, out linhas)) linhas = new List<Linha>();
    List<string> datas = linhas.Select(l => l.Data).ToList();
    int i = BisectRight(datas, momento);
    if (i == 0) return null;
    return linhas[i - 1].Valor;
}

static int UltimoValor(string usuario) {
    return historico[usuario].Last().Valor;
}

static void Main() {
    // usuario, momento, rotulo
    string[][] exemplos = {
        new[] { "u1", "2026-01-15", "0" }, new[] { "u1", "2026-02-10", "1" },
        new[] { "u2", "2026-02-01", "0" }, new[] { "u2", "2026-01-10", "0" },
    };
    Console.WriteLine("usuario momento     correto  ingenuo");
    foreach (string[] e in exemplos) {
        string usuario = e[0], momento = e[1];
        int? correto = AsOf(usuario, momento);
        string texto = correto.HasValue ? correto.Value.ToString() : "None";
        Console.WriteLine(string.Format("{0}      {1}  {2,7}  {3,7}", usuario, momento, texto, UltimoValor(usuario)));
    }

    var pares = usuarios.Select(u => "'" + u + "': " + UltimoValor(u));
    Console.WriteLine("online store: {" + string.Join(", ", pares) + "}");
}
```

```go
import (
	"fmt"
	"sort"
	"strings"
)

type Linha struct {
	data  string
	valor int
}

type Exemplo struct {
	usuario, momento string
	rotulo           int
}

var usuarios = []string{"u1", "u2"}

var historico = map[string][]Linha{
	"u1": {{"2026-01-05", 2}, {"2026-02-01", 5}, {"2026-03-01", 9}},
	"u2": {{"2026-01-20", 0}, {"2026-02-25", 1}},
}

// o segundo retorno é false quando o valor correto é ausente (None no Python)
func asOf(usuario, momento string) (int, bool) {
	linhas := historico[usuario]
	// sort.Search faz o papel de bisect.bisect_right
	i := sort.Search(len(linhas), func(j int) bool { return linhas[j].data > momento })
	if i == 0 {
		return 0, false
	}
	return linhas[i-1].valor, true
}

func ultimoValor(usuario string) int {
	linhas := historico[usuario]
	return linhas[len(linhas)-1].valor
}

func main() {
	exemplos := []Exemplo{{"u1", "2026-01-15", 0}, {"u1", "2026-02-10", 1}, {"u2", "2026-02-01", 0}, {"u2", "2026-01-10", 0}}
	fmt.Println("usuario momento     correto  ingenuo")
	for _, e := range exemplos {
		texto := "None"
		if v, ok := asOf(e.usuario, e.momento); ok {
			texto = fmt.Sprint(v)
		}
		fmt.Printf("%s      %s  %7s  %7d\n", e.usuario, e.momento, texto, ultimoValor(e.usuario))
	}

	var pares []string
	for _, u := range usuarios {
		pares = append(pares, fmt.Sprintf("'%s': %d", u, ultimoValor(u)))
	}
	fmt.Printf("online store: {%s}\n", strings.Join(pares, ", "))
}
```

O join ingênuo dá ao modelo, em janeiro, um número de compras que só existiria em março. O modelo aprende a confiar demais nessa feature e decepciona em produção, onde só existe o valor de hoje. Repare também no `u2` em 10 de janeiro: antes do primeiro registro o valor correto é ausente, e o modelo precisa aprender a lidar com isso, como acontecerá com usuários novos.

## Frescor e tipos de feature

| Tipo | Exemplo | Como materializar |
| --- | --- | --- |
| Estática ou lenta | País, categoria do item | Batch diário ou sob demanda |
| Agregado longo | Compras em 30 dias | Batch diário |
| Agregado curto | Cliques na última hora | Streaming |
| Da requisição | Hora do dia, dispositivo, consulta digitada | Calculada no próprio serviço, na hora |

Features da requisição não passam pelo store, mas a lógica precisa ser a mesma no treino: uma solução é registrar no log exatamente o vetor de features usado em cada predição e treinar com esse log.

## Trade-offs

- **Custo**: manter histórico de milhares de features por centenas de milhões de entidades é caro. Defina TTL e apague features sem uso.
- **Consistência entre stores**: o online pode estar alguns minutos à frente ou atrás do offline. Logar features no servimento resolve isso para o treino.
- **Build ou buy**: soluções abertas e gerenciadas existem; para um time pequeno, uma tabela bem modelada e um cache podem bastar no começo.

<Callout type="tip" title="Logue as features servidas">
A forma mais robusta de evitar skew é gravar, junto de cada predição, o vetor exato de features que o modelo recebeu. O próximo treino usa esse log, e treino e servimento passam a ver os mesmos números por construção.
</Callout>
