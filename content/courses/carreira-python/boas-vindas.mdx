Python é a linguagem de back-end de startups, fintechs, empresas de dados e de quase tudo que encosta em IA. No back-end, as vagas pedem um conjunto bem definido: Python moderno com tipagem, um framework web (Django, FastAPI ou Flask), banco de dados, testes com pytest, segurança e alguma noção de containers, mensageria e nuvem. Esta carreira põe esse conjunto em ordem, do primeiro programa até sistemas distribuídos rodando em Kubernetes.

O alvo é a vaga de **desenvolvedor back-end Python**: alguém que constrói e mantém APIs, modela o domínio com clareza, escreve testes que dão confiança para mudar o código e entende como o sistema roda em produção.

## Como a carreira está organizada

| Módulo | Você sai sabendo | Cursos |
|---|---|---|
| Base: fundamentos de programação com Python | Pensamento computacional, lógica e a primeira aplicação em Python | 2 |
| Nível 1: estruturando aplicações web | Git, orientação a objetos, redes, persistência, Flask, Django, FastAPI, arquitetura, SOLID e IA no back-end | 14 |
| Nível 2: qualidade, segurança e escalabilidade | Django REST Framework, Swagger, testes, design patterns, microsserviços, pipelines de CI/CD e OWASP | 13 |
| Nível 3: arquitetura, desempenho e deploy de sistemas em produção | DDD, padrões de integração e de arquitetura, RabbitMQ, Kafka, otimização com C e Kubernetes | 12 |

O Nível 1 leva você dos fundamentos até aplicações web completas nos três frameworks que o mercado usa, com código organizado. O Nível 2 é o que a maioria das vagas pleno pede no dia a dia: APIs bem feitas com Django REST Framework, testes, pipelines e segurança. O Nível 3 é o território do sênior: modelar o domínio, integrar serviços por mensagens, medir desempenho e operar em Kubernetes.

## Como usar

- **Siga a ordem dentro de cada nível.** Os cursos de Django, de Django REST Framework, de Integração Contínua e de Kubernetes são sequências: cada um parte do que o anterior construiu.
- **Marque cada capítulo como concluído** quando terminar. O progresso do módulo mostra quanto falta para fechar o nível.
- **Use as notas do CodeForge como diário de bordo.** Anote erros de configuração que custaram uma tarde, consultas do ORM que surpreenderam e decisões de arquitetura. Isso vira material para o README e para a entrevista.
- **Publique o que construir.** A plataforma de ingressos que atravessa a carreira pode virar um repositório público com README, testes e pipeline. Veja [Projetos para portfólio](/learn/projetos-portfolio) para transformá-la num projeto que conta no currículo.

<Callout type="tip" title="Python moderno desde o começo">
Muito material antigo ainda ensina Python sem tipagem, `requirements.txt` solto e Django 2. Aqui os exemplos usam Python 3.13 com type hints, `pyproject.toml`, Django 5.2, FastAPI com Pydantic 2 e SQLAlchemy 2. Se um tutorial usa `from typing import List`, `url()` no Django ou `@validator` no Pydantic, ele está desatualizado.
</Callout>

## Por onde começar

Se você nunca programou, comece pelo capítulo de pensamento computacional. Se já programa em outra linguagem, passe rápido pela Base e vá para o Nível 1, acelerando nos trechos que já conhece.
