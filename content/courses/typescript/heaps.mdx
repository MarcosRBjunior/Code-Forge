Os k maiores elementos, o algoritmo de Dijkstra, a mediana de um fluxo de números, juntar k listas ordenadas: todos pedem uma fila de prioridade. Python tem `heapq`, Java tem `PriorityQueue`, mas JavaScript não tem heap nativo. Em entrevista de TypeScript você precisa escrever um, e rápido.

## Como um heap binário funciona

Um heap mínimo é uma árvore binária completa em que cada pai é menor ou igual aos filhos. Ele cabe em um array: o nó do índice `i` tem filhos em `2i + 1` e `2i + 2`, e o pai em `Math.floor((i - 1) / 2)`. O menor elemento fica sempre no índice 0.

- Inserir: coloca no fim e "sobe" trocando com o pai enquanto for menor. O(log n).
- Remover o topo: move o último para a raiz e "desce" trocando com o menor filho. O(log n).
- Consultar o topo: O(1).

```text
array:  [1, 3, 2, 7, 4]
árvore:        1
             /   \
            3     2
           / \
          7   4
```

## Um heap genérico com comparador

Escreva uma vez, com um comparador no construtor, e você ganha heap mínimo, máximo e de tuplas. Os generics do TypeScript garantem que o tipo do elemento é coerente em todas as operações.

```typescript
class Heap<T> {
  private a: T[] = [];
  constructor(private menor: (x: T, y: T) => boolean) {}

  size(): number { return this.a.length; }
  peek(): T | undefined { return this.a[0]; }

  push(x: T): void {
    const a = this.a;
    a.push(x);
    let i = a.length - 1;
    while (i > 0) {
      const p = Math.floor((i - 1) / 2);
      if (!this.menor(a[i], a[p])) break;
      const t = a[i]; a[i] = a[p]; a[p] = t;
      i = p;
    }
  }

  pop(): T | undefined {
    const a = this.a;
    if (a.length === 0) return undefined;
    const topo = a[0];
    const ultimo = a.pop() as T;
    if (a.length > 0) {
      a[0] = ultimo;
      let i = 0;
      while (true) {
        const l = 2 * i + 1, r = l + 1;
        let m = i;
        if (l < a.length && this.menor(a[l], a[m])) m = l;
        if (r < a.length && this.menor(a[r], a[m])) m = r;
        if (m === i) break;
        const t = a[i]; a[i] = a[m]; a[m] = t;
        i = m;
      }
    }
    return topo;
  }
}

const minHeap = new Heap<number>((x, y) => x < y);
for (const n of [5, 1, 8, 3, 2]) minHeap.push(n);
const saida: number[] = [];
while (minHeap.size() > 0) saida.push(minHeap.pop() as number);
console.log(saida.join(","));

const maxHeap = new Heap<number>((x, y) => x > y);
for (const n of [5, 1, 8, 3, 2]) maxHeap.push(n);
console.log(maxHeap.pop(), maxHeap.pop());
```

```text
Saída:
1,2,3,5,8
8 5
```

Note o comparador `menor(x, y)` que responde "x deve sair antes de y?". Para trocar mínimo por máximo basta inverter a comparação.

## Exemplo: k maiores elementos

O truque clássico é manter um heap mínimo de tamanho k. Cada número novo entra; se o heap passar de k, sai o menor. No fim restam os k maiores, em O(n log k).

```typescript
class MinHeap {
  private a: number[] = [];
  size(): number { return this.a.length; }
  peek(): number { return this.a[0]; }
  push(x: number): void {
    const a = this.a;
    a.push(x);
    let i = a.length - 1;
    while (i > 0 && a[i] < a[(i - 1) >> 1]) {
      const p = (i - 1) >> 1;
      const t = a[i]; a[i] = a[p]; a[p] = t;
      i = p;
    }
  }
  pop(): number {
    const a = this.a;
    const topo = a[0];
    const ultimo = a.pop() as number;
    if (a.length > 0) {
      a[0] = ultimo;
      let i = 0;
      while (true) {
        const l = 2 * i + 1, r = l + 1;
        let m = i;
        if (l < a.length && a[l] < a[m]) m = l;
        if (r < a.length && a[r] < a[m]) m = r;
        if (m === i) break;
        const t = a[i]; a[i] = a[m]; a[m] = t;
        i = m;
      }
    }
    return topo;
  }
}

function kMaiores(nums: number[], k: number): number[] {
  const h = new MinHeap();
  for (const n of nums) {
    h.push(n);
    if (h.size() > k) h.pop();
  }
  const r: number[] = [];
  while (h.size() > 0) r.push(h.pop());
  return r;
}

console.log(kMaiores([3, 2, 1, 5, 6, 4], 2).join(","));
console.log(kMaiores([7, 7, 1, 9], 3).join(","));
```

```text
Saída:
5,6
7,7,9
```

## Heap de tuplas

Para Dijkstra você empilha pares `[distancia, no]`. Com o heap genérico, o comparador olha o primeiro elemento: `new Heap<[number, number]>((x, y) => x[0] < y[0])`. Se quiser desempate determinístico, compare o segundo campo quando o primeiro empatar.

## Armadilhas e alternativas

- Esquecer de tratar o heap vazio em `pop`: devolva `undefined` ou verifique `size` antes.
- Usar `sort` a cada inserção funciona, mas custa O(n log n) por operação; aceitável só para entradas minúsculas.
- Para k pequeno e fixo, ordenar uma vez (O(n log n)) pode ser mais simples de explicar do que o heap.

<Callout type="tip" title="Treine o código de memória">
O heap é o único código de infraestrutura que você realmente precisa saber escrever em TypeScript em poucos minutos. Pratique até conseguir digitar push e pop sem consultar nada.
</Callout>

## Na entrevista

Avise logo: "JavaScript não tem heap nativo; vou escrever um mínimo com comparador". Escreva só `push`, `pop`, `peek` e `size`. Muitos entrevistadores aceitam que você assuma uma classe `Heap` pronta se disser a interface e os custos; pergunte antes. Follow-ups comuns: "por que heap e não ordenar?" (O(n log k) contra O(n log n), e funciona em fluxo contínuo) e "como achar a mediana de um fluxo?" (dois heaps, um máximo para a metade de baixo e um mínimo para a de cima).
