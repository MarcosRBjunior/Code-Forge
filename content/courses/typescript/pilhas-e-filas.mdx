Pilhas resolvem parênteses balanceados, DFS iterativo e problemas de "próximo maior elemento". Filas são o coração da BFS. JavaScript não tem classes `Stack` nem `Queue` na biblioteca padrão: você usa o array, e precisa saber quando ele serve e quando vira armadilha.

## Pilha: o array basta

`push` e `pop` atuam no fim do array, ambos O(1) amortizado. O topo é o último elemento. Como `pop` em array vazio devolve `undefined`, verifique o tamanho antes ou trate o resultado.

```typescript
function balanceado(s: string): boolean {
  const pares: { [fecha: string]: string } = { ")": "(", "]": "[", "}": "{" };
  const pilha: string[] = [];
  for (const ch of s.split("")) {
    if (ch === "(" || ch === "[" || ch === "{") {
      pilha.push(ch);
    } else if (pares[ch] !== undefined) {
      if (pilha.length === 0 || pilha.pop() !== pares[ch]) return false;
    }
  }
  return pilha.length === 0;
}

console.log(balanceado("([]{})"), balanceado("(]"), balanceado("(("));
```

```text
Saída:
true false false
```

## Pilha monotônica

Uma variação muito cobrada é a pilha que mantém os elementos em ordem, guardando índices. Ela resolve "próximo maior elemento" em O(n), porque cada índice entra e sai uma única vez.

```typescript

function proximoMaior(nums: number[]): number[] {
  const resp: number[] = new Array(nums.length).fill(-1);
  const pilha: number[] = [];
  for (let i = 0; i < nums.length; i++) {
    while (pilha.length > 0 && nums[pilha[pilha.length - 1]] < nums[i]) {
      const j = pilha.pop() as number;
      resp[j] = nums[i];
    }
    pilha.push(i);
  }
  return resp;
}

console.log(proximoMaior([2, 1, 5, 3, 6]).join(","));
```

```text
Saída:
5,5,6,6,-1
```

O `as number` informa ao compilador que o `pop` não devolve `undefined` ali, já que o laço garante a pilha não vazia. Use asserções só quando você mesmo provou a condição.

## Fila: cuidado com shift

`shift` remove do início, mas desloca todos os elementos: custa O(n). Uma BFS que faz `shift` a cada nó vira O(n²) em grafos grandes. A solução mais simples é manter um índice de leitura `head` e nunca remover nada.

```typescript

function distancias(adj: number[][], origem: number): number[] {
  const dist: number[] = new Array(adj.length).fill(-1);
  const fila: number[] = [origem];
  let head = 0;
  dist[origem] = 0;
  while (head < fila.length) {
    const u = fila[head++];
    for (const v of adj[u]) {
      if (dist[v] === -1) {
        dist[v] = dist[u] + 1;
        fila.push(v);
      }
    }
  }
  return dist;
}

const grafo: number[][] = [[1, 2], [3], [3], [4], []];
console.log(distancias(grafo, 0).join(","));
```

```text
Saída:
0,1,1,2,3
```

O array cresce com todos os nós visitados, o que usa O(n) de memória: o mesmo que uma fila de verdade guardaria no pior caso.

## Deque

Para inserir e remover nas duas pontas (janela deslizante máxima, por exemplo), você pode implementar um deque com um buffer circular ou com dois índices sobre um objeto. Em entrevista, uma classe pequena basta:

```typescript
class Deque<T> {
  private dados: { [i: number]: T } = {};
  private ini = 0;
  private fim = 0;
  pushBack(x: T): void { this.dados[this.fim++] = x; }
  pushFront(x: T): void { this.dados[--this.ini] = x; }
  popFront(): T | undefined {
    if (this.ini === this.fim) return undefined;
    const x = this.dados[this.ini];
    delete this.dados[this.ini++];
    return x;
  }
  popBack(): T | undefined {
    if (this.ini === this.fim) return undefined;
    const x = this.dados[--this.fim];
    delete this.dados[this.fim];
    return x;
  }
  size(): number { return this.fim - this.ini; }
}

const d = new Deque<number>();
d.pushBack(1); d.pushBack(2); d.pushFront(0);
console.log(d.popFront(), d.popBack(), d.size());
```

```text
Saída:
0 2 1
```

Todas as operações são O(1). Para a maioria dos problemas, porém, o array com índice `head` já resolve.
