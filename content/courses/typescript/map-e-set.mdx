Tabelas hash transformam buscas O(n) em O(1) e aparecem em metade dos problemas de entrevista: two sum, contagem de frequência, detecção de duplicatas. Em JavaScript muita gente usa objetos simples para isso, mas `Map` e `Set` são a escolha certa, e o TypeScript tipa chaves e valores.

## Por que não usar um objeto

Um objeto comum converte toda chave em string: a chave `1` e a chave `"1"` são a mesma. Ele também herda propriedades do protótipo, não tem `size` e não guarda a ordem de inserção de chaves numéricas. `Map<K, V>` aceita qualquer tipo de chave, mantém a ordem de inserção e tem métodos claros.

```typescript

const obj: { [k: string]: number } = {};
obj[1] = 10;
obj["1"] = 20;
console.log(Object.keys(obj).length, obj[1]);

const m = new Map<number | string, number>();
m.set(1, 10);
m.set("1", 20);
console.log(m.size, m.get(1), m.get("1"));
```

```text
Saída:
1 20
2 10 20
```

## Map na prática

Os métodos são `set`, `get`, `has`, `delete` e `size`. `get` devolve `V | undefined`, então use `?? 0` para contagens. O padrão de frequência fica assim:

```typescript

function frequencias(palavras: string[]): Map<string, number> {
  const freq = new Map<string, number>();
  for (const p of palavras) {
    freq.set(p, (freq.get(p) ?? 0) + 1);
  }
  return freq;
}

const f = frequencias(["a", "b", "a", "c", "a", "b"]);
f.forEach((qtd, palavra) => console.log(palavra, qtd));
console.log(f.has("z"), f.get("z"));

const ordenadas = Array.from(f.entries()).sort((x, y) => y[1] - x[1]);
console.log(JSON.stringify(ordenadas));
```

```text
Saída:
a 3
b 2
c 1
false undefined
[["a",3],["b",2],["c",1]]
```

`forEach` em um `Map` recebe o valor primeiro e a chave depois. Para ordenar ou filtrar, converta com `Array.from(m.entries())` ou com spread. Em ambientes modernos você também percorre com `for (const [k, v] of m)`.

## Set

`Set<T>` guarda valores únicos com `add`, `has`, `delete` e `size`. É o jeito idiomático de remover duplicatas e de marcar visitados.

```typescript

function primeiroRepetido(nums: number[]): number {
  const vistos = new Set<number>();
  for (const n of nums) {
    if (vistos.has(n)) return n;
    vistos.add(n);
  }
  return -1;
}

console.log(primeiroRepetido([3, 1, 4, 1, 5]), primeiroRepetido([1, 2, 3]));
const unicos = Array.from(new Set([5, 3, 5, 1, 3]));
console.log(unicos.join(","));
```

```text
Saída:
1 -1
5,3,1
```

## A armadilha das chaves objeto

`Map` e `Set` comparam chaves com a mesma regra de `===` (com a exceção de que `NaN` é igual a si mesmo). Dois arrays com o mesmo conteúdo são objetos diferentes, então `set.has([1, 2])` é falso mesmo depois de `set.add([1, 2])`. Para usar coordenadas ou tuplas como chave, serialize: `` `${r},${c}` `` ou `r * colunas + c`.

```typescript

const errado = new Set<number[]>();
errado.add([1, 2]);
console.log(errado.has([1, 2]));

const certo = new Set<string>();
certo.add(1 + "," + 2);
console.log(certo.has(1 + "," + 2));
```

```text
Saída:
false
true
```

<Callout type="warning" title="Ordem garantida, mas não ordenada">
Map e Set iteram na ordem de inserção, não em ordem crescente. Não existe TreeMap nativo: se precisar de chaves ordenadas, ordene as chaves na hora ou implemente uma estrutura própria.
</Callout>

## Custos

`get`, `set`, `has` e `delete` são O(1) em média. Iterar é O(n). Como no Python, o pior caso teórico de uma tabela hash é O(n), mas em entrevista se assume o caso médio.

## Na entrevista

Diga "vou usar um `Map` de valor para índice" e justifique com a busca O(1). Para chaves compostas, mencione a serialização. Follow-ups comuns: "por que não um objeto?" (chaves viram string, protótipo, sem `size`) e "a iteração de um `Map` é ordenada?" (só pela ordem de inserção).
