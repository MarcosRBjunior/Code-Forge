Imagine uma função que devolve o primeiro elemento de um array. Se você a tipar com `number[]`, ela só serve para números. Se tipar com `any`, ela serve para tudo, mas o resultado volta sem tipo e o compilador deixa de ajudar. Generics resolvem isso: você escreve o código uma vez e o tipo concreto é decidido em cada chamada.

## Parâmetros de tipo

Um parâmetro de tipo é uma variável que vive no nível dos tipos. Por convenção usa-se `T`, `U`, `K`, `V`. Ele aparece entre sinais de menor e maior logo depois do nome da função.

```typescript
function primeiro<T>(itens: T[]): T | undefined {
  return itens[0];
}

const n = primeiro([10, 20, 30]);
const s = primeiro(["a", "b"]);
const vazio = primeiro<number>([]);

console.log(n, s, vazio);
console.log(typeof n, typeof s);
```

```text
Saída:
10 a undefined
number string
```

Na primeira chamada o compilador infere `T = number` a partir do argumento, e `n` ganha o tipo `number | undefined`. Você só escreve o tipo explicitamente (`primeiro<number>`) quando não há argumento do qual inferir, como no array vazio.

## Genéricos em tipos e classes

Interfaces, type aliases e classes também aceitam parâmetros de tipo. É assim que se descreve uma estrutura de dados que funciona para qualquer elemento, algo que você fará toda vez que implementar uma pilha ou uma fila numa entrevista.

```typescript
class Pilha<T> {
  private itens: T[] = [];

  empilhar(valor: T): void {
    this.itens.push(valor);
  }

  desempilhar(): T | undefined {
    return this.itens.pop();
  }

  tamanho(): number {
    return this.itens.length;
  }
}

const numeros = new Pilha<number>();
numeros.empilhar(1);
numeros.empilhar(2);
console.log(numeros.desempilhar(), numeros.tamanho());

const palavras = new Pilha<string>();
palavras.empilhar("ts");
console.log(palavras.desempilhar(), palavras.desempilhar());
```

```text
Saída:
2 1
ts undefined
```

Se você tentasse `numeros.empilhar("x")`, o compilador reclamaria. Esse é o ganho: a mesma classe, com segurança de tipos para cada uso.

## Restrições com extends

Às vezes a função precisa saber algo sobre `T`. Com `T extends Tipo` você restringe o que é aceito e ganha acesso aos membros desse tipo.

```typescript
interface ComTamanho {
  length: number;
}

function maisLongo<T extends ComTamanho>(a: T, b: T): T {
  return a.length >= b.length ? a : b;
}

console.log(maisLongo("casa", "apartamento"));
console.log(maisLongo([1, 2, 3], [4, 5]));
```

```text
Saída:
apartamento
[ 1, 2, 3 ]
```

Strings e arrays têm `length`, então ambos servem. Um número seria rejeitado em tempo de compilação. Outra restrição comum é `K extends keyof T`, que garante que a chave existe no objeto:

```typescript
function pegar<T, K extends keyof T>(obj: T, chave: K): T[K] {
  return obj[chave];
}

const pessoa = { nome: "Ana", idade: 30 };
const idade = pegar(pessoa, "idade"); // tipo number
// pegar(pessoa, "email"); // erro: "email" não é chave de pessoa
```

## Valores padrão e armadilhas

Parâmetros de tipo aceitam valor padrão (`interface Resposta<T = string>`). Duas armadilhas frequentes:

- Generics existem só na compilação. Em tempo de execução o JavaScript gerado não tem `T`, então você não pode escrever `new T()` nem `x instanceof T`.
- Não crie um parâmetro de tipo que aparece uma única vez na assinatura. Uma função `f<T>(x: T): void` não ganha nada sobre `f(x: unknown): void`.

<Callout type="tip" title="Menos é mais">
Se o compilador consegue inferir `T`, não o escreva. Anotar tudo à mão deixa o código ruidoso e esconde o que realmente importa.
</Callout>

## Na entrevista

Generics aparecem quando você implementa uma estrutura de dados reutilizável (pilha, fila, cache LRU, grafo) e o entrevistador pergunta "e se os elementos não forem números?". Responder com `class Cache<K, V>` mostra domínio. Para comparar elementos, aceite uma função como parâmetro (`comparador: (a: T, b: T) => number`) em vez de assumir que `<` funciona.

Follow-ups comuns: "qual a diferença entre `T` e `any`?" (`T` preserva a relação entre entrada e saída; `any` desliga a checagem) e "por que não dá para instanciar `T`?" (os tipos são apagados na compilação).
