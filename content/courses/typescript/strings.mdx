Problemas de string aparecem em toda entrevista: anagramas, palíndromos, janelas deslizantes, parsing. Em TypeScript a string é o tipo primitivo `string` do JavaScript, imutável e indexável. O compilador ajuda pouco aqui; o que importa é conhecer os custos e as armadilhas de Unicode.

## Imutabilidade e o custo de concatenar

Nenhum método altera a string original: `toUpperCase`, `replace` e `slice` devolvem strings novas. Atribuir a `s[0]` não tem efeito (e o TypeScript acusa erro, porque o índice é somente leitura). Para construir um resultado caractere a caractere, acumule partes em um array e use `join` no final.

```typescript
const s = "entrevista";
const maior = s.toUpperCase();
console.log(s, maior);
console.log(s[0], s.charAt(1), s.length);

const partes: string[] = [];
for (let i = s.length - 1; i >= 0; i--) partes.push(s[i]);
console.log(partes.join(""));
console.log(s.split("").reverse().join(""));
```

```text
Saída:
entrevista ENTREVISTA
e n 10
atsivertne
atsivertne
```

Os motores modernos otimizam `+=` em muitos casos, mas o array com `join` deixa a complexidade explícita e evita surpresas.

## Códigos de caractere

Para contar letras de `a` a `z` sem um `Map`, use `charCodeAt` e um array de 26 posições. É o truque padrão de anagramas.

```typescript

function ehAnagrama(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  const cont: number[] = new Array(26).fill(0);
  const base = "a".charCodeAt(0);
  for (let i = 0; i < a.length; i++) {
    cont[a.charCodeAt(i) - base]++;
    cont[b.charCodeAt(i) - base]--;
  }
  return cont.every((c) => c === 0);
}

console.log(ehAnagrama("roma", "amor"), ehAnagrama("casa", "saca"), ehAnagrama("abc", "abd"));
console.log("a".charCodeAt(0), String.fromCharCode(98));
```

```text
Saída:
true true false
97 b
```

## Métodos do dia a dia

- `slice(i, j)` extrai do índice `i` até antes de `j`; aceita negativos contando do fim.
- `indexOf(sub)` devolve a posição ou `-1`.
- `split(sep)` quebra em array; `trim` remove espaços das pontas.
- `startsWith`, `endsWith`, `includes`, `repeat` e `padStart` resolvem formatação rápida.
- `localeCompare` compara textos respeitando acentos.

```typescript

const frase = "  ola, mundo, ts  ";
const campos = frase.trim().split(", ");
console.log(campos.length, campos[1]);
console.log("abcdef".slice(1, 4), "abcdef".slice(-2));
console.log("banana".indexOf("na"), "banana".lastIndexOf("na"));
console.log("7".padStart(3, "0"), "ab".repeat(3));
console.log("banana".split("a").join("o"));
```

```text
Saída:
3 mundo
bcd ef
2 4
007 ababab
bonono
```

A última linha mostra um jeito de substituir todas as ocorrências sem regex. `replace` com string substitui só a primeira; `replaceAll` existe nas versões recentes da biblioteca.

## Unicode e length

`length` conta unidades UTF-16, não caracteres visíveis. Emojis e alguns símbolos ocupam duas unidades, então `"😀".length` é `2` e `s[0]` devolve metade do par. Em problemas com texto arbitrário, `Array.from(s)` separa por ponto de código. Nos problemas típicos de entrevista a entrada é ASCII, mas mencionar isso mostra maturidade.

```typescript
// "😀".length          -> 2
// Array.from("😀").length -> 1
// "é".length           -> 1 (forma composta)
```

## Comparar e ordenar

`<` e `>` comparam strings pela ordem das unidades UTF-16, o que coloca maiúsculas antes de minúsculas. Para ordenar palavras, `sort()` sem comparador já faz ordem lexicográfica; com acentos, use `a.localeCompare(b)`.

## Armadilhas

- `s.split("")` quebra emojis no meio; prefira `Array.from(s)` se isso importar.
- Fatiar dentro de um laço (`s.slice(i)`) custa O(n) a cada volta e pode tornar a solução quadrática.
- Strings são comparadas por valor com `===`, ao contrário de arrays.

## Na entrevista

Avise que strings são imutáveis e que você vai montar o resultado em um array. Para contagem de letras minúsculas, use o vetor de 26 posições; para alfabetos maiores, um `Map`. Follow-ups comuns: "qual a complexidade de concatenar em laço?" (potencialmente quadrática; o `join` resolve) e "e se a entrada tiver emojis?" (`length` conta unidades UTF-16).
