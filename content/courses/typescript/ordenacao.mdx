Ordenar é o primeiro passo de muitas soluções: dois ponteiros, intervalos, agrupamento, busca binária. Em TypeScript você usa `Array.prototype.sort`, que tem uma armadilha famosa: sem comparador, ele ordena como texto. Essa é a pegadinha mais comum de JavaScript em entrevista.

## O padrão é ordem de string

Sem argumento, `sort` converte cada elemento em string e compara as unidades UTF-16. Para números isso dá resultados errados, e o compilador não reclama, porque a chamada é válida.

```typescript
const nums: number[] = [10, 9, 2, 100, 1];
const errado = nums.slice().sort();
const certo = nums.slice().sort((a, b) => a - b);
const desc = nums.slice().sort((a, b) => b - a);

console.log(errado.join(","));
console.log(certo.join(","));
console.log(desc.join(","));
```

```text
Saída:
1,10,100,2,9
1,2,9,10,100
100,10,9,2,1
```

O comparador recebe dois elementos e devolve um número: negativo se `a` vem antes, positivo se `b` vem antes, zero se empatam. `a - b` dá ordem crescente; `b - a`, decrescente.

## sort muda o array

`sort` ordena no lugar e devolve o mesmo array. Se a entrada não pode ser alterada, copie antes com `slice()` ou spread. Versões novas da biblioteca têm `toSorted`, que devolve uma cópia, mas nem toda plataforma oferece.

## Estabilidade e custo

Desde o ES2019 o `sort` é estável: elementos que empatam mantêm a ordem relativa original. O V8 usa TimSort, com O(n log n) no pior caso e O(n) em dados quase ordenados. A estabilidade permite ordenar por vários critérios em passos, mas é mais claro escrever um comparador composto.

```typescript
interface Pessoa { nome: string; idade: number; }

const pessoas: Pessoa[] = [
  { nome: "Bia", idade: 30 },
  { nome: "Ana", idade: 25 },
  { nome: "Caio", idade: 30 },
  { nome: "Duda", idade: 25 },
];

pessoas.sort((a, b) => {
  if (a.idade !== b.idade) return b.idade - a.idade;
  return a.nome < b.nome ? -1 : a.nome > b.nome ? 1 : 0;
});

for (const p of pessoas) console.log(p.nome, p.idade);
```

```text
Saída:
Bia 30
Caio 30
Ana 25
Duda 25
```

O comparador tipado com `Pessoa` garante que você não erre o nome de um campo. Para strings, `a.localeCompare(b)` também funciona e respeita acentos.

## Cuidados com o comparador

- Subtração só é segura para números finitos; com valores enormes ou `Infinity` prefira comparações explícitas.
- Um comparador que devolve `boolean` (`a > b`) não funciona: `true` e `false` viram 1 e 0, e nunca há resultado negativo.
- O comparador precisa ser consistente; resultados aleatórios produzem ordens imprevisíveis.

## Ordenar intervalos e usar índices

Problemas de intervalos começam ordenando pelo início. Quando você precisa lembrar a posição original, ordene um array de índices em vez dos valores.

```typescript
function mesclar(intervalos: [number, number][]): [number, number][] {
  const ord = intervalos.slice().sort((x, y) => x[0] - y[0]);
  const res: [number, number][] = [];
  for (const [ini, fim] of ord) {
    const ult = res[res.length - 1];
    if (ult !== undefined && ini <= ult[1]) {
      ult[1] = Math.max(ult[1], fim);
    } else {
      res.push([ini, fim]);
    }
  }
  return res;
}

console.log(JSON.stringify(mesclar([[8, 10], [1, 3], [2, 6], [15, 18]])));

const notas: number[] = [70, 95, 80];
const idx = [0, 1, 2].sort((i, j) => notas[j] - notas[i]);
console.log(idx.join(","));
```

```text
Saída:
[[1,6],[8,10],[15,18]]
1,2,0
```

Dois detalhes do primeiro exemplo: `ult` é uma referência ao último intervalo do resultado, então alterar `ult[1]` estende o intervalo já guardado; e o `slice()` antes do `sort` preserva a entrada de quem chamou. No segundo, `idx` lista as posições dos alunos da maior para a menor nota, sem perder a informação de quem é quem.
