O TypeScript pega muitos erros antes de o código rodar: propriedade inexistente, argumento do tipo errado, `undefined` esquecido. Mas ele não muda a semântica do JavaScript que está por baixo. As armadilhas abaixo compilam sem nenhum aviso e produzem respostas erradas, e são exatamente as que aparecem quando você está com pressa numa entrevista.

## Ordenação e comparação

`sort` sem comparador converte tudo em texto. E arrays e objetos são comparados por referência, não por conteúdo.

```typescript
const nums = [10, 1, 5, 100];
console.log(nums.slice().sort().join(","));
console.log(nums.slice().sort((a, b) => a - b).join(","));

console.log([1, 2] === [1, 2]);
console.log(JSON.stringify([1, 2]) === JSON.stringify([1, 2]));

const vistos = new Set<number[]>();
vistos.add([0, 0]);
console.log(vistos.has([0, 0]));

const vistosTexto = new Set<string>();
vistosTexto.add(0 + "," + 0);
console.log(vistosTexto.has("0,0"));

console.log(NaN === NaN, Number.isNaN(NaN));
```

```text
Saída:
1,10,100,5
1,5,10,100
false
true
false
true
false true
```

O caso do `Set` é o mais comum em problemas de grade: você guarda a coordenada `[r, c]` como "visitada" e a checagem nunca acha nada, porque cada array literal é um objeto novo. Codifique o par como string (`r + "," + c`) ou como um número (`r * colunas + c`).

Repare também no `slice()` antes do `sort`: o método ordena no lugar e devolve o próprio array. Sem a cópia, você altera a entrada do chamador.

## Criação de arrays

Há três jeitos de errar ao criar um array.

```typescript
const errada: number[][] = new Array(3).fill([]);
errada[0].push(7);
console.log(errada.map((l) => l.length).join(","));

const certa: number[][] = Array.from({ length: 3 }, () => []);
certa[0].push(7);
console.log(certa.map((l) => l.length).join(","));

const esparso = new Array<number>(3);
console.log(esparso.map(() => 1).length, esparso.map(() => 1)[0]);
console.log(new Array<number>(3).fill(0).map(() => 1).join(","));

const grade = Array.from({ length: 2 }, () => new Array<number>(3).fill(0));
grade[1][2] = 9;
console.log(grade.map((l) => l.join("")).join("|"));
```

```text
Saída:
1,1,1
1,0,0
3 undefined
1,1,1
000|009
```

- `fill([])` coloca a **mesma** lista em todas as posições. Mudar uma muda todas, o mesmo erro de `[[]] * 3` em Python.
- `new Array(n)` cria um array esparso, cheio de "buracos". `map` e `forEach` pulam os buracos, então o `map` não faz nada. Preencha com `fill` antes.
- Para matrizes, use `Array.from` com uma função que cria uma linha nova a cada chamada.

## Outras armadilhas frequentes

- **Checagem de verdade com zero.** `if (mapa.get(chave))` falha quando o valor guardado é `0`. Use `mapa.has(chave)` ou compare com `undefined`.
- **`for...in` em arrays.** Percorre as chaves como strings (`"0"`, `"1"`), não os valores. Use `for...of` ou um `for` com índice.
- **`==` em vez de `===`.** `0 == ""` é `true`. Use sempre a igualdade estrita.
- **`Math.max(...arr)` em arrays enormes.** O espalhamento passa cada elemento como argumento e pode estourar a pilha com centenas de milhares de itens. Use `reduce` ou um laço.
- **Recursão profunda.** A pilha do Node aguenta alguns milhares de chamadas. Uma DFS recursiva numa lista encadeada de 100 mil nós estoura; converta para pilha explícita.
- **Divisão e resto.** `/` devolve fração e `%` mantém o sinal negativo. Veja o capítulo de números.
- **Não há heap nativo.** Se o problema precisa de fila de prioridade, avise logo que vai implementar um, em vez de descobrir no meio.

<Callout type="tip" title="Tipos não salvam semântica">
O compilador aceita `new Array(3).fill([])` com tipo `number[][]` sem reclamar. Os tipos dizem a forma dos dados, não se as linhas são objetos distintos.
</Callout>

## Na entrevista

Muitos entrevistadores conhecem essas pegadinhas e observam se você as evita sozinho. Comentar "uso comparador numérico porque o `sort` padrão é lexicográfico" ou "guardo a coordenada como string porque arrays comparam por referência" custa cinco segundos e transmite segurança. Ao revisar o código antes de entregar, passe por esta lista mentalmente: ordenação, criação de matriz, checagem de zero, recursão.

Follow-ups comuns: "por que `[1,2] === [1,2]` é falso?" (são dois objetos distintos na memória) e "como você usaria um par como chave de `Map`?" (serializando em string ou combinando num inteiro).
