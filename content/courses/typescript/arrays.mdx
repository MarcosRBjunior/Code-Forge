O array é a estrutura que você mais vai usar em entrevista: entrada de quase todo problema, base para pilhas, filas e tabelas de programação dinâmica. Em TypeScript ele é o array dinâmico do JavaScript, agora com um tipo de elemento que o compilador confere em cada `push` e cada leitura.

## Declarar e tipar

Escreva `number[]` ou `Array<number>`; são equivalentes. Arrays de arrays (matrizes) ficam `number[][]`. Para uma lista que não deve ser alterada, `readonly number[]` remove do tipo os métodos que mutam, como `push` e `sort`.

```typescript
const nums: number[] = [3, 1, 4];
nums.push(1);
const grade: number[][] = [[1, 2], [3, 4]];
const fixo: readonly number[] = [10, 20];
// fixo.push(30);  // erro: push não existe em readonly number[]

console.log(nums.length, nums[0], nums[nums.length - 1]);
console.log(grade[1][0], fixo.length);
console.log(nums[10]);
```

```text
Saída:
4 3 1
3 2
undefined
```

Note a última linha: ler fora dos limites não lança erro, devolve `undefined`. O tipo de `nums[10]` continua sendo `number` no modo padrão, então o compilador não avisa. A opção `noUncheckedIndexedAccess` mudaria isso para `number | undefined`, mas raramente está ligada em plataformas de entrevista; a verificação de limites é por sua conta.

## Criar com tamanho e valor inicial

Para tabelas de DP e vetores de visitados, crie o array já preenchido. Cuidado com matrizes: `new Array(3).fill([])` coloca o mesmo array interno em todas as linhas.

```typescript

const dp: number[] = new Array(5).fill(0);
dp[2] = 7;

const errada: number[][] = new Array(3).fill([]);
errada[0].push(1);

const certa: number[][] = Array.from({ length: 3 }, () => []);
certa[0].push(1);

console.log(dp.join(","));
console.log(JSON.stringify(errada));
console.log(JSON.stringify(certa));
```

```text
Saída:
0,0,7,0,0
[[1],[1],[1]]
[[1],[],[]]
```

`Array.from` com uma função cria um objeto novo por posição; é o jeito seguro de montar matrizes.

## Arrays esparsos

`new Array(5)` sem `fill` cria um array com "buracos", não com `undefined` de verdade. Métodos como `map` e `forEach` pulam os buracos, o que gera resultados estranhos. Atribuir a um índice muito além do fim também cria buracos e muda o `length`.

```typescript
const buracos: number[] = new Array(3);
const dobrados = buracos.map(() => 1);
console.log(dobrados.length, dobrados[0]);

const v: number[] = [1, 2];
v[5] = 9;
console.log(v.length, v[3]);
```

```text
Saída:
3 undefined
6 undefined
```

Regra prática: sempre inicialize com `fill` ou `Array.from` antes de usar.

## Métodos essenciais e seus custos

| Operação | Método | Custo |
| --- | --- | --- |
| Inserir/remover no fim | `push`, `pop` | O(1) amortizado |
| Inserir/remover no início | `unshift`, `shift` | O(n) |
| Copiar trecho | `slice(i, j)` | O(j - i) |
| Remover/inserir no meio | `splice` | O(n) |
| Buscar | `indexOf`, `includes`, `find` | O(n) |

Os métodos funcionais (`map`, `filter`, `reduce`) criam arrays novos e mantêm os tipos: `map` sobre `number[]` com uma função que devolve `string` resulta em `string[]`.

```typescript

const valores: number[] = [5, 2, 8, 1];
const rotulos: string[] = valores.map((v, i) => i + ":" + v);
const grandes = valores.filter((v) => v > 2);
const total = valores.reduce((acc, v) => acc + v, 0);
const copia = [...valores].reverse();

console.log(rotulos.join(" "));
console.log(grandes.join(","), total);
console.log(copia.join(","), valores.join(","));
console.log(valores.includes(8), valores.indexOf(9));
```

```text
Saída:
0:5 1:2 2:8 3:1
5,8 16
1,8,2,5 5,2,8,1
true -1
```

`reverse`, `sort` e `splice` mudam o array original. Copie antes (com `slice()` ou spread) se a entrada não pode ser alterada.

## Armadilhas

- `shift` em laço de BFS torna o algoritmo quadrático; use um índice de leitura (veja o capítulo de filas).
- `reduce` sem valor inicial em array vazio lança `TypeError`.
- Comparar arrays com `===` compara referências, não conteúdo.
