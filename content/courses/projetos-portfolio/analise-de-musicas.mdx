**Em uma frase:** uma análise exploratória de um dataset público de faixas musicais que responde perguntas de negócio com gráficos claros e termina num relatório publicado.

**Nível:** iniciante a intermediário em dados · **Tempo:** 1 semana · **Pré-requisito:** Python e pandas básicos

## O que você vai construir

Um notebook organizado e um relatório (ou dashboard) que investigam um catálogo de músicas: popularidade, gêneros, duração, ano de lançamento e atributos de áudio como dançabilidade, energia e valência. Em vez de "fiz uns gráficos", o projeto parte de perguntas concretas, como alguém de uma plataforma de streaming faria: o que separa as faixas mais populares? Os gêneros estão ficando mais curtos? Músicas mais animadas tocam mais?

Use nome e visual próprios no relatório, sem logotipo de nenhuma empresa, e dados de fonte permitida: um dataset público com licença compatível (citada no README) ou a API oficial de uma plataforma, respeitando os termos dela.

## MVP

- [ ] Dataset público escolhido, com origem, data de coleta e licença no README
- [ ] Limpeza documentada: duplicatas, faixas repetidas em vários gêneros, valores ausentes e outliers
- [ ] 4 a 6 perguntas de negócio escritas antes da análise
- [ ] Um gráfico principal por pergunta, com título que já diz a conclusão
- [ ] Seção de limitações (viés do dataset, correlação não é causa)
- [ ] Notebook e relatório ou dashboard publicados, com link no README

## Etapas

1. **Escreva as perguntas antes.** Exemplos: quais atributos de áudio mais se associam à popularidade? Como a duração média das faixas mudou por década? Que gêneros são mais "dançáveis"? Perguntas escritas antes evitam caçar padrões até achar algum por acaso.
2. **Entenda e limpe os dados.** Leia a descrição de cada coluna (o que é "popularidade" nesse dataset e em que data foi medida?). Remova duplicatas, decida o que fazer com a mesma faixa listada em vários gêneros e registre cada decisão no notebook.
3. **Análise univariada.** Distribuições de popularidade, duração e atributos. Popularidade costuma ter muita faixa com valor zero: entenda isso antes de calcular médias.
4. **Responda cada pergunta.** Compare grupos com medianas e boxplots, olhe correlações com cautela e, quando fizer sentido, um modelo simples (regressão) para ver o peso de cada atributo, separando treino e teste se for avaliar previsão.
5. **Comunique.** Cada seção do relatório tem pergunta, gráfico, resposta em uma frase e ressalva. Quem lê só os títulos deve entender as conclusões.
6. **Reprodutibilidade.** Fixe versões, guarde o arquivo de dados (ou um script que baixa a mesma versão) e garanta que o notebook roda do início ao fim sem erro.

Um exemplo de análise com resposta direta:

```python
import pandas as pd

df = pd.read_csv("dados/faixas.csv").drop_duplicates(subset="track_id")
df["decada"] = (df["ano"] // 10) * 10
resumo = df.groupby("decada")["duracao_ms"].median().div(60_000).round(2)
print(resumo)  # duração mediana em minutos por década
```

<Callout type="tip" title="Título que conclui">
Troque "Duração por década" por "As faixas ficaram N segundos mais curtas desde os anos 2000", com o número que você encontrar. Recrutadores leem títulos, não eixos.
</Callout>

## Extras para se destacar

- Agrupamento (k-means) de faixas por atributos de áudio, com nomes interpretáveis para cada grupo.
- Filtros interativos por gênero e década no dashboard.
- Teste estatístico para as diferenças mais importantes entre grupos.
- Comparar dois datasets de anos diferentes para ver o que mudou.
