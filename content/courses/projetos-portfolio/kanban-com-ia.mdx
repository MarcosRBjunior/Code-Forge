**Em uma frase:** um quadro kanban com colunas e cartões que você arrasta e solta, mais uma IA que quebra uma tarefa em subtarefas e resume o andamento do quadro.

**Nível:** avançado · **Tempo:** 3 a 5 semanas · **Pré-requisito:** autenticação de usuários e o projeto de chat com streaming (ou qualquer chamada a um LLM pelo servidor)

## O que você vai construir

Um app de quadros: cada quadro tem colunas, cada coluna tem cartões, e você reorganiza tudo arrastando. Por cima disso, dois recursos de IA úteis de verdade: transformar "lançar a landing page" numa lista de subtarefas que viram cartões, e gerar um resumo do quadro ("3 tarefas atrasadas, 2 bloqueadas").

Os pontos difíceis são menos visíveis do que parecem. Manter a ordem dos cartões estável sem reescrever a coluna inteira a cada arraste, garantir que a resposta da IA tem o formato que o código espera e, se quiser, sincronizar duas abas abertas no mesmo quadro. Dê ao app nome e visual próprios.

## MVP

- [ ] Quadros, colunas e cartões, cada quadro visível só para o dono e membros convidados
- [ ] Arrastar e soltar cartões entre colunas e dentro da mesma coluna, com a ordem salva no servidor
- [ ] Botão "quebrar em subtarefas" que gera cartões a partir de uma resposta validada da IA
- [ ] Botão "resumir quadro" com um parágrafo e uma lista de riscos
- [ ] Atualização otimista na UI, com reversão se o servidor recusar
- [ ] Deploy público e README com GIF do arrastar e da IA gerando subtarefas

## Stack sugerida

| Camada | Opção principal | Alternativa |
|---|---|---|
| Front-end | Next.js + dnd-kit | React + Vite + Pragmatic drag and drop |
| Back-end | Route handlers do Next.js | NestJS ou FastAPI |
| Banco | PostgreSQL | SQLite no começo |
| IA | Provedor com saída estruturada + Zod | Modelo local com Ollama |
| Tempo real (opcional) | WebSockets ou Server-Sent Events | Polling curto |

## Fora do escopo

Anexos, automações configuráveis, calendário, notificações por e-mail, permissões finas por cartão e edição colaborativa de texto do cartão. Tempo real é opcional; o resto do MVP precisa funcionar sem ele.

## Etapas

1. **Modele a ordem.** Em vez de posições inteiras (1, 2, 3, que obrigam a renumerar a coluna), use uma chave de ordenação fracionária: ao soltar um cartão entre A e B, ele recebe um valor entre os dois. Só a linha movida é atualizada.
2. **Arrastar com atualização otimista.** A UI move o cartão na hora e manda ao servidor o id do cartão, a coluna de destino e os vizinhos. O servidor calcula a nova chave, confere se o usuário pode editar aquele quadro e responde; se falhar, a UI desfaz.
3. **Autorização no servidor.** Toda rota confere se o usuário pertence ao quadro do cartão. Não basta esconder o botão: ids são fáceis de adivinhar.
4. **Subtarefas com saída estruturada.** Peça ao modelo um JSON com uma lista de subtarefas e valide com um schema antes de criar qualquer cartão. Se a validação falhar, tente uma vez de novo e, depois disso, mostre um erro amigável.

```typescript
const Subtasks = z.object({
  subtasks: z.array(z.object({ title: z.string().min(3).max(120), estimateHours: z.number().min(0.5).max(40) })).min(1).max(10),
});
const parsed = Subtasks.safeParse(JSON.parse(modelOutput));
if (!parsed.success) throw new Error("resposta da IA fora do formato");
```

5. **Resumo do quadro.** Monte o contexto com títulos, colunas e datas (nada de dados de outros quadros) e limite o tamanho. Trate o texto dos cartões como dado, não como instrução: alguém pode escrever "ignore as regras" num cartão.
6. **Custo e limites.** Chave da API só no servidor, limite de chamadas de IA por usuário por dia e registro de tokens gastos por chamada.
7. **Tempo real (opcional).** Ao mover um cartão, o servidor publica um evento para quem está com aquele quadro aberto. Use o número de versão do quadro para descartar eventos atrasados.

<Callout type="tip" title="A IA sugere, a pessoa decide">
Mostre as subtarefas geradas numa prévia editável antes de criar os cartões. Isso melhora a experiência e é uma boa resposta quando o entrevistador perguntar o que acontece se o modelo errar.
</Callout>

## Extras para se destacar

- Desfazer e refazer movimentos.
- Chave fracionária com rebalanceamento quando os valores ficam longos demais.
- Avaliação simples da IA: um conjunto fixo de tarefas e uma checagem de qualidade das subtarefas geradas.
- Acessibilidade: mover cartões pelo teclado.

## O que este projeto mostra no portfólio

"Eu integro IA como parte do produto, com saída validada e limites de custo, e resolvi a ordenação de um kanban sem reescrever a coluna inteira a cada arraste."
