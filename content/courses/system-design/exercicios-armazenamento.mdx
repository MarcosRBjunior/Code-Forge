Revise os tipos de armazenamento: block, sistemas de arquivos distribuídos, object storage e erasure coding.

<Quiz question="Você vai hospedar um PostgreSQL em VMs na nuvem. Que tipo de armazenamento é o mais indicado?" options={["Object storage", "Block storage em SSD provisionado", "Um bucket com URLs pré-assinadas", "Um sistema de arquivos distribuído do tipo HDFS"]} answer={1} explanation="Bancos transacionais precisam de baixa latência e acesso a posições arbitrárias, o que o block storage entrega." />
<Quiz question="Um app permite upload de vídeos de até 4 GB. Qual desenho é mais adequado?" options={["O backend recebe o vídeo e grava numa tabela", "Upload direto ao object storage por URL pré-assinada, e referência guardada no banco", "Um volume de bloco compartilhado entre todos os servidores", "Enviar por e-mail interno"]} answer={1} explanation="Mídia grande vai para object storage, com upload direto do cliente, e o banco guarda apenas metadados e a chave." />
<Quiz question="No HDFS, o que o servidor de metadados faz?" options={["Armazena todos os blocos de dados", "Guarda a árvore de diretórios e a localização dos blocos", "Calcula as paridades de erasure coding", "Serve diretamente os dados para o cliente"]} answer={1} explanation="Ele mapeia arquivos para blocos e nós; os dados trafegam entre cliente e nós de dados." />
<Quiz question="Qual é o overhead de espaço de um esquema de erasure coding 10+4?" options={["10%", "40%", "100%", "200%"]} answer={1} explanation="O overhead é (k+m)/k = 14/10 = 1,4x, ou seja, 40% de espaço extra." />
<Quiz question="Um volume de bloco está cheio de snapshots esquecidos e o banco ficou lento, mesmo com 30% de espaço livre. <Quiz question="Por que espalhar os fragmentos de erasure coding por racks e zonas diferentes?" options={["Para reduzir o uso de CPU", "Para que uma falha de rack ou zona não destrua mais fragmentos do que o código tolera", "Para eliminar a necessidade de paridade", "Para acelerar escritas pequenas"]} answer={1} explanation="Falhas correlacionadas num domínio de falha só são toleradas se os fragmentos estiverem em domínios distintos." />
<Quiz question="Qual afirmação sobre durabilidade e disponibilidade no object storage é correta?" options={["São sinônimos", "Dados podem estar duráveis mesmo com o serviço temporariamente indisponível", "Durabilidade alta garante disponibilidade de 100%", "Disponibilidade é garantida pela versão do objeto"]} answer={1} explanation="Durabilidade é a chance de não perder dados; disponibilidade é a chance de acessá-los naquele momento.
