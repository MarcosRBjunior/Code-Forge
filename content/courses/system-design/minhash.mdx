Como achar páginas quase duplicadas entre bilhões, documentos semelhantes para um mecanismo de busca, usuários com gostos parecidos ou plágio? Comparar todos os pares é quadrático e impraticável. O **MinHash** cria uma assinatura curta de cada conjunto, de modo que a **similaridade de Jaccard** entre dois conjuntos possa ser estimada comparando apenas as assinaturas.

## Similaridade de Jaccard

Para dois conjuntos A e B:

```text
J(A, B) = |A interseção B| / |A união B|
```

Vale 1 para conjuntos idênticos e 0 para disjuntos. Para texto, cada documento vira o conjunto de seus **shingles** (sequências de k palavras ou caracteres consecutivos). Documentos quase iguais compartilham a maior parte dos shingles.

## A ideia do MinHash

Aplique uma função de hash h a todos os elementos de um conjunto e guarde o **menor** valor de hash, `minhash(A) = min(h(x) para x em A)`. Propriedade chave:

```text
Probabilidade[ minhash(A) == minhash(B) ] = J(A, B)
```

Intuição: o elemento com o menor hash na união A ∪ B é uniformemente aleatório. A e B terão o mesmo mínimo exatamente quando esse elemento estiver na interseção, o que acontece com probabilidade J.

Uma única comparação é um sorteio 0 ou 1. Para estimar J, use **k funções de hash diferentes**, construindo uma assinatura de k valores mínimos. A fração de posições iguais entre duas assinaturas estima J, com erro de aproximadamente 1/sqrt(k).

```python
import hashlib

def assinatura(conjunto, k=128):
    sig = []
    for i in range(k):
        sig.append(min(
            int(hashlib.md5(f"{i}:{x}".encode()).hexdigest(), 16)
            for x in conjunto
        ))
    return sig

def jaccard_estimado(s1, s2):
    return sum(a == b for a, b in zip(s1, s2)) / len(s1)
```

```java
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.*;

// md5 em hex de 32 caracteres: o menor texto é o menor número de 128 bits
static String md5(String s) {
    try {
        byte[] d = MessageDigest.getInstance("MD5").digest(s.getBytes(StandardCharsets.UTF_8));
        StringBuilder sb = new StringBuilder();
        for (byte b : d) sb.append(String.format("%02x", b));
        return sb.toString();
    } catch (Exception e) {
        throw new IllegalStateException(e);
    }
}

static List<String> assinatura(Collection<String> conjunto, int k) {
    List<String> sig = new ArrayList<>();
    for (int i = 0; i < k; i++) {
        String menor = null;
        for (String x : conjunto) {
            String h = md5(i + ":" + x);
            if (menor == null || h.compareTo(menor) < 0) menor = h;
        }
        sig.add(menor);
    }
    return sig;
}

static double jaccardEstimado(List<String> s1, List<String> s2) {
    int iguais = 0;
    for (int i = 0; i < s1.size(); i++) if (s1.get(i).equals(s2.get(i))) iguais++;
    return (double) iguais / s1.size();
}
```

```cpp
// MD5 mínimo. Devolve os 16 bytes do resumo.
string md5(const string& msg) {
    static const int S[64] = {7, 12, 17, 22, 7, 12, 17, 22, 7, 12, 17, 22, 7, 12, 17, 22, 5, 9, 14, 20, 5, 9, 14, 20, 5, 9, 14, 20, 5, 9, 14, 20,

    uint32_t K[64];
    for (int i = 0; i < 64; i++) K[i] = (uint32_t)(4294967296.0 * fabs(sin(i + 1.0)));
    uint32_t a0 = 0x67452301, b0 = 0xefcdab89, c0 = 0x98badcfe, d0 = 0x10325476;
    string m = msg;
    uint64_t bits = (uint64_t)msg.size() * 8;
    m += (char)0x80;
    while (m.size() % 64 != 56) m += (char)0;
    for (int i = 0; i < 8; i++) m += (char)(bits >> (i * 8));
    for (size_t off = 0; off < m.size(); off += 64) {
        uint32_t M[16];
        for (int i = 0; i < 16; i++) {
            M[i] = (uint32_t)(uint8_t)m[off + 4 * i] | ((uint32_t)(uint8_t)m[off + 4 * i + 1] << 8) |
                   ((uint32_t)(uint8_t)m[off + 4 * i + 2] << 16) | ((uint32_t)(uint8_t)m[off + 4 * i + 3] << 24);
        }
        uint32_t A = a0, B = b0, C = c0, D = d0;
        for (int i = 0; i < 64; i++) {
            uint32_t F;
            int g;
            if (i < 16) { F = (B & C) | (~B & D); g = i; }
            else if (i < 32) { F = (D & B) | (~D & C); g = (5 * i + 1) % 16; }
            else if (i < 48) { F = B ^ C ^ D; g = (3 * i + 5) % 16; }
            else { F = C ^ (B | ~D); g = (7 * i) % 16; }
            F = F + A + K[i] + M[g];
            A = D; D = C; C = B;
            B = B + ((F << S[i]) | (F >> (32 - S[i])));
        }
        a0 += A; b0 += B; c0 += C; d0 += D;
    }
    string out;
    for (uint32_t v : {a0, b0, c0, d0}) for (int j = 0; j < 4; j++) out += (char)(v >> (j * 8));
    return out;
}

string hex(const string& bytes) {
    static const char* d = "0123456789abcdef";
    string r;
    for (unsigned char c : bytes) { r += d[c >> 4]; r += d[c & 15]; }
    return r;
}

// md5 em hex de 32 caracteres: o menor texto é o menor número de 128 bits
vector<string> assinatura(const set<string>& conjunto, int k = 128) {
    vector<string> sig;
    for (int i = 0; i < k; i++) {
        string menor;
        bool primeiro = true;
        for (auto& x : conjunto) {
            string h = hex(md5(to_string(i) + ":" + x));
            if (primeiro || h < menor) { menor = h; primeiro = false; }

        sig.push_back(menor);
    }

}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Security.Cryptography;
using System.Text;

// md5 em hex de 32 caracteres: o menor texto é o menor número de 128 bits
static string Md5(string s)
{
    using (var md5 = MD5.Create())
    {
        return string.Concat(md5.ComputeHash(Encoding.UTF8.GetBytes(s)).Select(b => b.ToString("x2")));
    }
}

static List<string> Assinatura(IEnumerable<string> conjunto, int k = 128)
{
    var sig = new List<string>();
    for (int i = 0; i < k; i++)
    {
        int j = i;
        sig.Add(conjunto.Select(x => Md5(j + ":" + x)).OrderBy(h => h, StringComparer.Ordinal).First());
    }
    return sig;
}

static double JaccardEstimado(List<string> s1, List<string> s2)
{
    int iguais = 0;
    for (int i = 0; i < s1.Count; i++) if (s1[i] == s2[i]) iguais++;
    return (double)iguais / s1.Count;
}
```

```go
import (
	"crypto/md5"
	"encoding/hex"
	"fmt"
)

// md5 em hex de 32 caracteres: o menor texto é o menor número de 128 bits
func md5Hex(s string) string {
	h := md5.Sum([]byte(s))
	return hex.EncodeToString(h[:])
}

func assinatura(conjunto []string, k int) []string {
	sig := []string{}
	for i := 0; i < k; i++ {
		menor := ""
		for j, x := range conjunto {
			h := md5Hex(fmt.Sprintf("%d:%s", i, x))
			if j == 0 || h < menor {
				menor = h
			}
		}
		sig = append(sig, menor)
	}
	return sig
}

func jaccardEstimado(s1, s2 []string) float64 {
	iguais := 0
	for i := range s1 {
		if s1[i] == s2[i] {
			iguais++
		}
	}
	return float64(iguais) / float64(len(s1))
}
```

Com k = 128, o erro típico é cerca de 9%; com k = 1.024, cerca de 3%. Cada documento, por maior que seja, vira 128 inteiros.

## LSH: evitando comparar todos os pares

Mesmo com assinaturas, comparar todos os pares é caro. O **Locality-Sensitive Hashing** em bandas resolve:

1. Divida a assinatura de k posições em b bandas de r posições cada.
2. Para cada banda, faça o hash das r posições para um bucket.
3. Dois documentos são **candidatos** se caírem no mesmo bucket em pelo menos uma banda.

A probabilidade de virarem candidatos é `1 - (1 - J^r)^b`, uma curva em S. Ajustando b e r, você escolhe o limiar: pares muito similares quase sempre colidem, e pares diferentes quase nunca. Depois, só os candidatos são conferidos com precisão.

## Aplicações

- **Deduplicação de documentos e páginas** em buscadores e crawlers (AltaVista foi pioneiro).
- **Sistemas de recomendação:** usuários ou itens com muitos vizinhos em comum.
- **Detecção de plágio e spam** em escala.
- **Agrupamento de notícias** quase iguais.
- **Genômica:** comparação de sequências (Mash).

## Armadilhas

- **Escolha de shingles:** pequenos demais geram falsa similaridade; grandes demais, falsa diferença.
- **Mede conjuntos, não ordem ou semântica.** Textos reordenados ou parafraseados têm Jaccard baixo; para semântica, use embeddings.
- **Variantes** como b-bit MinHash e one-permutation hashing reduzem o custo de calcular k hashes por elemento.
- É estimativa: valide candidatos importantes com a comparação exata.

<Callout type="tip" title="Comparação com SimHash">
SimHash estima similaridade de cosseno com uma assinatura de poucos bits e é comum para deduplicação web. MinHash é a escolha para Jaccard de conjuntos.
</Callout>
