Uma página de produto faz cinco consultas ao banco, cada uma levando 20 ms. Se mil pessoas pedem a mesma página por segundo, o banco refaz o mesmo trabalho mil vezes, e a latência e o custo sobem sem necessidade. Um cache guarda o resultado de operações caras em um armazenamento mais rápido, geralmente memória, para que leituras repetidas não precisem ir até a fonte original. Uma leitura em Redis leva menos de 1 ms, contra dezenas de milissegundos de um banco sob carga, e o cache ainda protege o banco de picos de tráfego.

## Onde o cache mora

Há camadas em série: o cache do navegador, uma CDN para conteúdo estático, um cache de aplicação (Redis ou Memcached) e o cache interno do próprio banco. Quanto mais perto do usuário, menor a latência, mas mais difícil manter o dado fresco.

## Estratégias de escrita

- **Cache-aside:** a aplicação lê do cache; se não encontrar (*miss*), lê do banco e grava no cache. É a mais comum, porque o cache só guarda o que realmente é pedido.
- **Write-through:** toda escrita vai ao cache e ao banco ao mesmo tempo. Leituras sempre frescas, escritas mais lentas.
- **Write-back:** a escrita vai só ao cache e é persistida depois. Rápida, mas pode perder dados se o cache cair.

## Invalidação

O problema difícil do cache é saber quando um dado ficou velho. As ferramentas são o **TTL** (expira depois de um tempo), a **invalidação explícita** na escrita e o **versionamento da chave** (a chave muda quando o conteúdo muda).

```python
def get_usuario(id):
```

<Callout type="note" title="Políticas de remoção">
Quando o cache enche, algo precisa sair. LRU remove o menos usado recentemente e é o padrão na maioria dos casos.
</Callout>

## Um LRU que roda

Veja uma implementação mínima de cache com LRU e TTL, usando só a biblioteca padrão. O `OrderedDict` mantém a ordem de uso: o que foi acessado vai para o fim e o mais antigo sai pelo começo.

```python
import time
from collections import OrderedDict

class CacheLRU:
    def __init__(self, capacidade, ttl):
        self.capacidade, self.ttl = capacidade, ttl
        self.dados = OrderedDict()

    def get(self, chave):
        item = self.dados.get(chave)
        if item is None or item[1] < time.time():
            self.dados.pop(chave, None)
            return None
        self.dados.move_to_end(chave)
        return item[0]

    def set(self, chave, valor):
        self.dados[chave] = (valor, time.time() + self.ttl)
        self.dados.move_to_end(chave)
        if len(self.dados) > self.capacidade:
            self.dados.popitem(last=False)

c = CacheLRU(2, ttl=60)
c.set("a", 1); c.set("b", 2); c.get("a"); c.set("c", 3)
print(c.get("b"), c.get("a"))  # None 1
```

```java
import java.util.*;

class CacheLRU {
    private final int capacidade;
    private final double ttl;   // em segundos
    // accessOrder = true: cada get/put move a chave para o fim (a mais recente)
    private final LinkedHashMap<String, double[]> dados = new LinkedHashMap<>(16, 0.75f, true);

    CacheLRU(int capacidade, double ttl) {
        this.capacidade = capacidade;
        this.ttl = ttl;
    }

    private double agora() {
        return System.currentTimeMillis() / 1000.0;
    }

    Integer get(String chave) {
        double[] item = dados.get(chave);
        if (item == null || item[1] < agora()) {
            dados.remove(chave);
            return null;
        }
        return (int) item[0];
    }

    void set(String chave, int valor) {
        dados.put(chave, new double[]{valor, agora() + ttl});
        if (dados.size() > capacidade) {
            dados.remove(dados.keySet().iterator().next());   // remove o mais antigo
        }
    }
}

public static void main(String[] args) {
    CacheLRU c = new CacheLRU(2, 60);
    c.set("a", 1); c.set("b", 2); c.get("a"); c.set("c", 3);
    System.out.println(c.get("b") + " " + c.get("a"));  // null 1
}
```

```cpp
#include <chrono>
#include <iostream>
#include <list>
#include <optional>
#include <string>
#include <unordered_map>
using namespace std;

class CacheLRU {
    struct Item { string chave; int valor; double expira; };
    size_t capacidade;
    double ttl;   // em segundos
    list<Item> ordem;   // frente = mais recente
    unordered_map<string, list<Item>::iterator> indice;

    double agora() {
        return chrono::duration<double>(chrono::system_clock::now().time_since_epoch()).count();
    }

public:
    CacheLRU(size_t capacidade, double ttl) : capacidade(capacidade), ttl(ttl) {}

    optional<int> get(const string& chave) {
        auto it = indice.find(chave);
        if (it == indice.end()) return nullopt;
        if (it->second->expira < agora()) {
            ordem.erase(it->second);
            indice.erase(it);
            return nullopt;
        }
        ordem.splice(ordem.begin(), ordem, it->second);   // passa a ser o mais recente
        return it->second->valor;
    }

    void set(const string& chave, int valor) {
        auto it = indice.find(chave);
        if (it != indice.end()) {
            ordem.erase(it->second);
        }
        ordem.push_front({chave, valor, agora() + ttl});
        indice[chave] = ordem.begin();
        if (ordem.size() > capacidade) {
            indice.erase(ordem.back().chave);             // remove o mais antigo
            ordem.pop_back();
        }
    }
};

int main() {
    CacheLRU c(2, 60);
    c.set("a", 1); c.set("b", 2); c.get("a"); c.set("c", 3);
    auto b = c.get("b"), a = c.get("a");
    cout << (b ? to_string(*b) : "None") << " " << (a ? to_string(*a) : "None") << endl;  // None 1
}
```

```csharp
using System;
using System.Collections.Generic;

class CacheLRU
{
    private class Item { public string Chave; public int Valor; public double Expira; }

    private readonly int capacidade;
    private readonly double ttl;   // em segundos
    private readonly LinkedList<Item> ordem = new LinkedList<Item>();   // início = mais recente
    private readonly Dictionary<string, LinkedListNode<Item>> indice = new Dictionary<string, LinkedListNode<Item>>();

    public CacheLRU(int capacidade, double ttl)
    {
        this.capacidade = capacidade;
        this.ttl = ttl;
    }

    private static double Agora()
    {
        return DateTimeOffset.UtcNow.ToUnixTimeMilliseconds() / 1000.0;
    }

    public int? Get(string chave)
    {
        LinkedListNode<Item> no;
        if (!indice.TryGetValue(chave, out no)) return null;
        if (no.Value.Expira < Agora())
        {
            ordem.Remove(no);
            indice.Remove(chave);
            return null;
        }
        ordem.Remove(no);
        ordem.AddFirst(no);        // passa a ser o mais recente
        return no.Value.Valor;
    }

    public void Set(string chave, int valor)
    {
        LinkedListNode<Item> existente;
        if (indice.TryGetValue(chave, out existente))
        {
            ordem.Remove(existente);
        }
        indice[chave] = ordem.AddFirst(new Item { Chave = chave, Valor = valor, Expira = Agora() + ttl });
        if (ordem.Count > capacidade)
        {
            var maisAntigo = ordem.Last;   // remove o mais antigo
            ordem.RemoveLast();
            indice.Remove(maisAntigo.Value.Chave);
        }
    }
}

static void Main()
{
    var c = new CacheLRU(2, 60);
    c.Set("a", 1); c.Set("b", 2); c.Get("a"); c.Set("c", 3);
    int? b = c.Get("b"), a = c.Get("a");
    Console.WriteLine((b.HasValue ? b.Value.ToString() : "None") + " " + (a.HasValue ? a.Value.ToString() : "None"));  // None 1
}
```

```go
import (
	"container/list"
	"fmt"
	"time"
)

type item struct {
	chave  string
	valor  int
	expira time.Time
}

type CacheLRU struct {
	capacidade int
	ttl        time.Duration
	ordem      *list.List // frente = mais recente
	indice     map[string]*list.Element
}

func novoCache(capacidade int, ttl time.Duration) *CacheLRU {
	return &CacheLRU{capacidade: capacidade, ttl: ttl, ordem: list.New(), indice: map[string]*list.Element{}}
}

func (c *CacheLRU) get(chave string) (int, bool) {
	el, ok := c.indice[chave]
	if !ok {
		return 0, false
	}
	if el.Value.(item).expira.Before(time.Now()) {
		c.ordem.Remove(el)
		delete(c.indice, chave)
		return 0, false
	}
	c.ordem.MoveToFront(el) // passa a ser o mais recente
	return el.Value.(item).valor, true
}

func (c *CacheLRU) set(chave string, valor int) {
	if el, ok := c.indice[chave]; ok {
		c.ordem.Remove(el)
	}
	c.indice[chave] = c.ordem.PushFront(item{chave, valor, time.Now().Add(c.ttl)})
	if c.ordem.Len() > c.capacidade {
		maisAntigo := c.ordem.Back() // remove o mais antigo
		c.ordem.Remove(maisAntigo)
		delete(c.indice, maisAntigo.Value.(item).chave)
	}
}

func main() {
	c := novoCache(2, 60*time.Second)
	c.set("a", 1)
	c.set("b", 2)
	c.get("a")
	c.set("c", 3)
	b, okB := c.get("b")
	a, okA := c.get("a")
	mostra := func(v int, ok bool) string {
		if !ok {
			return "None"
		}
		return fmt.Sprint(v)
	}
	fmt.Println(mostra(b, okB), mostra(a, okA)) // None 1
}
```

## Armadilhas

- **Dado desatualizado:** com TTL longo, o usuário vê informação velha. Escolha o TTL pelo quanto de defasagem o negócio tolera.
- **Cache stampede:** quando uma chave popular expira, centenas de requisições batem no banco ao mesmo tempo. Mitigue com um lock por chave, TTL com variação aleatória ou renovação antecipada.
- **Cache frio:** logo após um deploy ou reinício, o cache está vazio e o banco recebe toda a carga. Considere aquecer as chaves mais quentes.
- **Consistência:** entre a escrita no banco e a invalidação do cache existe uma janela em que leitores veem o valor antigo. Em dados críticos, como saldo bancário, prefira ler direto da fonte.
- **Cache de ausências:** consultas por chaves inexistentes sempre falham no cache e martelam o banco. Guarde também o resultado vazio, com TTL curto.
