<Quiz question="Sua API guarda a sessão do usuário na memória de cada servidor. Você adiciona mais servidores atrás de um load balancer e os usuários começam a ser deslogados aleatoriamente. Qual a correção mais adequada?" options={["Comprar um servidor maior e voltar a operar com uma instância só, sem balanceador","Mover as sessões para um armazenamento compartilhado, como Redis, deixando os servidores stateless","Aumentar o timeout do load balancer para manter as conexões abertas por mais tempo em cada servidor","Desligar o cache da aplicação para que cada requisição busque os dados do zero no banco de dados"]} answer={1} explanation="Escala horizontal exige que qualquer instância atenda qualquer requisição. Com a sessão num armazenamento compartilhado, os servidores ficam sem estado." />
<Quiz question="Uma requisição passa por gateway (99,95%), serviço (99,9%) e banco (99,9%), todos obrigatórios. Qual a disponibilidade aproximada?" options={["99,95%", "99,9%", "99,75%", "99,99%"]} answer={2} explanation="Em série, multiplica-se: 0,9995 x 0,999 x 0,999 dá aproximadamente 0,9975, ou 99,75%. O conjunto é menos disponível que qualquer parte." />
<Quiz question="Qual afirmação diferencia corretamente disponibilidade de confiabilidade?" options={["São sinônimos, e os dois termos medem exatamente a mesma propriedade do sistema distribuído em produção","Um sistema pode responder o tempo todo e devolver resultados incorretos: disponível, mas não confiável","A confiabilidade se aplica somente ao hardware, e nunca ao software, às redes ou aos dados do sistema","A disponibilidade mede a correção dos dados devolvidos, e não se o sistema responde às requisições"]} answer={1} explanation="Disponibilidade mede se o sistema responde; confiabilidade mede se ele continua funcionando corretamente diante de defeitos." />
<Quiz question="Seu serviço faz retry 3 vezes, o gateway faz retry 3 vezes e o cliente também 3 vezes. A dependência final está sobrecarregada. Qual o risco?" options={["Nenhum risco, porque retries em várias camadas aumentam a chance de sucesso","Amplificação: uma falha pode gerar até 27 chamadas, piorando a sobrecarga","O cliente recebe a resposta mais rápido, pois alguma tentativa acaba funcionando","O banco de dados é desligado automaticamente quando recebe tentativas repetidas"]} answer={1} explanation="Retries em camadas se multiplicam. Concentre-os em um ponto e use backoff exponencial com jitter." />
<Quiz question="Um serviço atende 1.000 req/s com latência média de 80 ms. Quantas conexões simultâneas ao banco ele precisa, aproximadamente, se cada requisição usa uma conexão o tempo todo?" options={["8", "80", "800", "12,5"]} answer={1} explanation="Pela Lei de Little, concorrência = 1.000 x 0,08 = 80." />
<Quiz question="Você tem um cache distribuído com 20 nós usando hash % N. Um nó cai e a taxa de acerto despenca, sobrecarregando o banco. O que resolveria?" options={["Aumentar o TTL de todas as chaves para que menos delas expirem durante a falha","Usar hashing consistente com nós virtuais, movendo só cerca de 1/N das chaves","Substituir o cluster por um único nó de cache maior, sem necessidade de hash","Desativar o cache enquanto durar a falha, até o nó voltar a ficar disponível"]} answer={1} explanation="Com módulo, quase todas as chaves mudam de nó quando N muda. Hashing consistente limita a movimentação ao arco do nó que saiu." />
<Quiz question="Durante uma partição de rede, um serviço de carrinho de compras continua aceitando adições nos dois lados e mescla os carrinhos depois. Como ele se classifica no CAP?" options={["CP", "AP", "CA", "Não se aplica"]} answer={1} explanation="Ele prioriza responder sempre (disponibilidade) e aceita divergência temporária, resolvida por reconciliação quando a rede volta." />
<Quiz question="Qual componente é o único ponto de falha, sem nenhuma redundância, neste desenho: DNS em um único provedor, load balancer gerenciado multi-zona, 6 instâncias de app em 3 zonas, banco com réplica síncrona em outra zona?" options={["As instâncias de aplicação", "O load balancer", "O provedor de DNS único", "A réplica do banco"]} answer={2} explanation="Todo o resto tem redundância entre zonas, mas se o único provedor de DNS falhar, os clientes não conseguem resolver o endereço do serviço." />
