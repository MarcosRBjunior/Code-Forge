Sua loja usa um gateway de pagamento. O cliente paga por boleto, e a confirmação pode chegar minutos ou dias depois. Ficar consultando a API do gateway a cada minuto para cada pedido pendente é caro e lento. O caminho natural é inverter a direção: **o gateway avisa você**. Um **webhook** é exatamente isso: uma requisição HTTP que um sistema faz para uma URL registrada por outro sistema quando um evento acontece. É, na prática, uma "API reversa" entre servidores.

## Como funciona

```text
1. Você registra no provedor: URL https://loja.com/webhooks/pagamentos
   e os eventos de interesse: pagamento.aprovado, pagamento.estornado

2. Evento acontece no provedor.

3. Provedor faz:
   POST https://loja.com/webhooks/pagamentos
   Content-Type: application/json
   Webhook-Id: evt_7f3a
   Webhook-Timestamp: 1761750000
   Webhook-Signature: v1,9a1b...

   {"id": "evt_7f3a", "tipo": "pagamento.aprovado", "pedido": 9001, "valor": 15980}

4. Sua API responde 2xx rapidamente. Se não responder (erro ou timeout),
   o provedor tenta de novo mais tarde, com backoff.
```

## Construindo um receptor robusto

### 1. Verifique a assinatura

A URL do webhook é pública; qualquer um pode mandar um POST para ela. O provedor assina o corpo com um segredo compartilhado (normalmente HMAC-SHA256), e você confere:

<CodeTabs>

```python
import hmac, hashlib, time

def verificar(corpo_bruto: bytes, ts: str, assinatura: str, segredo: bytes) -> bool:
    if abs(time.time() - int(ts)) > 300:          # rejeita replays antigos
        return False
    base = ts.encode() + b"." + corpo_bruto
    esperado = hmac.new(segredo, base, hashlib.sha256).hexdigest()
    return hmac.compare_digest(esperado, assinatura)
```

```javascript
const { createHmac, timingSafeEqual } = require("crypto");
```

```java
import java.security.MessageDigest;

static boolean verificar(byte[] corpoBruto, String ts, String assinatura, byte[] segredo) throws Exception {
    if (Math.abs(System.currentTimeMillis() / 1000.0 - Long.parseLong(ts)) > 300) { // rejeita replays antigos
        return false;
    }
    byte[] prefixo = (ts + ".").getBytes(StandardCharsets.UTF_8);
    byte[] base = new byte[prefixo.length + corpoBruto.length];
    System.arraycopy(prefixo, 0, base, 0, prefixo.length);
    System.arraycopy(corpoBruto, 0, base, prefixo.length, corpoBruto.length);

    Mac mac = Mac.getInstance("HmacSHA256");
    mac.init(new SecretKeySpec(segredo, "HmacSHA256"));
    StringBuilder esperado = new StringBuilder();
    for (byte b : mac.doFinal(base)) esperado.append(String.format("%02x", b));
    // compara em tempo constante
    return MessageDigest.isEqual(esperado.toString().getBytes(StandardCharsets.UTF_8), assinatura.getBytes(StandardCharsets.UTF_8));
```

```cpp
    string m = msg;
    uint64_t bits = (uint64_t)msg.size() * 8;
    m += (char)0x80;
    while (m.size() % 64 != 56) m += (char)0;
    for (int i = 7; i >= 0; i--) m += (char)(bits >> (i * 8));
    auto rotr = [](uint32_t x, int n) { return (x >> n) | (x << (32 - n)); };
    for (size_t off = 0; off < m.size(); off += 64) {
        uint32_t w[64];
        for (int i = 0; i < 16; i++) {
            w[i] = ((uint32_t)(uint8_t)m[off + 4 * i] << 24) | ((uint32_t)(uint8_t)m[off + 4 * i + 1] << 16) |
                   ((uint32_t)(uint8_t)m[off + 4 * i + 2] << 8) | (uint32_t)(uint8_t)m[off + 4 * i + 3];
        }
        for (int i = 16; i < 64; i++) {
            uint32_t s0 = rotr(w[i - 15], 7) ^ rotr(w[i - 15], 18) ^ (w[i - 15] >> 3);
            uint32_t s1 = rotr(w[i - 2], 17) ^ rotr(w[i - 2], 19) ^ (w[i - 2] >> 10);
            w[i] = w[i - 16] + s0 + w[i - 7] + s1;
        }
        uint32_t a = h[0], b = h[1], c = h[2], d = h[3], e = h[4], f = h[5], g = h[6], hh = h[7];
        for (int i = 0; i < 64; i++) {
            uint32_t t1 = hh + (rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25)) + ((e & f) ^ (~e & g)) + K[i] + w[i];
            uint32_t t2 = (rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22)) + ((a & b) ^ (a & c) ^ (b & c));
            hh = g; g = f; f = e; e = d + t1; d = c; c = b; b = a; a = t1 + t2;
        }
        h[0] += a; h[1] += b; h[2] += c; h[3] += d; h[4] += e; h[5] += f; h[6] += g; h[7] += hh;
    }
    string out;
    for (int i = 0; i < 8; i++) for (int j = 3; j >= 0; j--) out += (char)(h[i] >> (j * 8));
    return out;
}

string hex(const string& bytes) {
    static const char* d = "0123456789abcdef";
    string r;
    for (unsigned char c : bytes) { r += d[c >> 4]; r += d[c & 15]; }
    return r;
}

// HMAC-SHA256 (bloco de 64 bytes)
string hmacSha256(string chave, const string& msg) {
    if (chave.size() > 64) chave = sha256(chave);
    chave.resize(64, '\0');
    string ipad(64, 0), opad(64, 0);
    for (int i = 0; i < 64; i++) { ipad[i] = chave[i] ^ 0x36; opad[i] = chave[i] ^ 0x5c; }
    return sha256(opad + sha256(ipad + msg));
}

// compara em tempo constante
bool iguaisEmTempoConstante(const string& a, const string& b) {
    if (a.size() != b.size()) return false;
    unsigned char dif = 0;
    for (size_t i = 0; i < a.size(); i++) dif |= (unsigned char)(a[i] ^ b[i]);
    return dif == 0;
}

bool verificar(const string& corpoBruto, const string& ts, const string& assinatura, const string& segredo) {
    long agora = chrono::duration_cast<chrono::seconds>(chrono::system_clock::now().time_since_epoch()).count();
    if (labs(agora - stol(ts)) > 300) { // rejeita replays antigos
        return false;
    }
    string base = ts + "." + corpoBruto;
    string esperado = hex(hmacSha256(segredo, base));
    return iguaisEmTempoConstante(esperado, assinatura);
}
```

```csharp
using System;
using System.Linq;
using System.Security.Cryptography;
using System.Text;

static bool VerificarAssinatura(byte[] corpoBruto, string ts, string assinatura, byte[] segredo)
{
    long agora = DateTimeOffset.UtcNow.ToUnixTimeSeconds();
    if (Math.Abs(agora - long.Parse(ts)) > 300) // rejeita replays antigos
    {
        return false;
    }
    byte[] prefixo = Encoding.UTF8.GetBytes(ts + ".");
    byte[] baseBytes = prefixo.Concat(corpoBruto).ToArray();
    using (var hmac = new HMACSHA256(segredo))
    {
        string esperado = string.Concat(hmac.ComputeHash(baseBytes).Select(b => b.ToString("x2")));
        // compara em tempo constante
        byte[] x = Encoding.UTF8.GetBytes(esperado), y = Encoding.UTF8.GetBytes(assinatura);
        if (x.Length != y.Length) return false;
        int dif = 0;
        for (int i = 0; i < x.Length; i++) dif |= x[i] ^ y[i];
        return dif == 0;
    }
}
```

```go
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
	"math"
	"strconv"
	"time"

func verificar(corpoBruto []byte, ts, assinatura string, segredo []byte) bool {
	n, err := strconv.ParseInt(ts, 10, 64)
	if err != nil || math.Abs(float64(time.Now().Unix()-n)) > 300 { // rejeita replays antigos
		return false
	}
	base := append([]byte(ts+"."), corpoBruto...)
	mac := hmac.New(sha256.New, segredo)

	return hmac.Equal([]byte(esperado), []byte(assinatura)) // tempo constante
}
```

Detalhes: assine e verifique sobre o **corpo bruto**, não sobre o JSON reserializado; inclua o timestamp na assinatura para impedir reenvio de requisições capturadas; e use comparação em tempo constante.

### 2. Responda rápido, processe depois

O provedor tem timeout curto (geralmente poucos segundos). Valide, grave o evento numa fila ou tabela e responda 200. O processamento pesado (atualizar estoque, enviar e-mail) acontece num worker.

### 3. Seja idempotente

Provedores entregam **pelo menos uma vez**: se sua resposta se perder, o mesmo evento chega de novo. Guarde o ID do evento com restrição única e ignore duplicatas.

### 4. Não confie na ordem

`pagamento.estornado` pode chegar antes de `pagamento.aprovado` por causa de retentativas. Use timestamps ou versões do recurso, ou trate o webhook como um "algo mudou" e busque o estado atual na API do provedor.

## Construindo o lado emissor

Se você é quem envia webhooks para clientes:

- **Fila de saída:** gere o evento, grave numa fila e deixe workers fazerem as chamadas, nunca na thread da requisição do usuário.
- **Retentativas com backoff exponencial** ao longo de horas ou dias, e um destino para falhas definitivas (dead letter), com reenvio manual pelo painel.
- **Timeouts curtos e isolamento:** um cliente com endpoint lento não pode travar a entrega para os outros.
- **Desativação automática** de endpoints que falham por dias, com aviso ao dono.
- **Segurança:** assinatura HMAC, rotação de segredos e proteção contra SSRF (não permita URLs que apontem para a sua rede interna).

<Callout type="tip" title="Reconciliação">
Webhooks podem se perder mesmo com retentativas, por exemplo se seu endpoint ficou fora do ar por mais tempo que a política do provedor. Um job periódico que compara o estado local com a API do provedor fecha essa lacuna.
</Callout>

## Webhooks vs alternativas

| Abordagem | Quem inicia | Latência | Observação |
| --- | --- | --- | --- |
| Polling na API | Consumidor | Intervalo de consulta | Simples, desperdiça requisições |
| Webhook | Provedor | Segundos | Exige endpoint público e robusto |
| Fila ou stream compartilhado | Ambos via broker | Baixa | Comum dentro da mesma empresa |

## Na entrevista

Webhooks aparecem em integrações com pagamentos, GitHub, mensageria e qualquer plataforma que notifique terceiros. Destaque assinatura HMAC com timestamp, resposta rápida com processamento assíncrono, idempotência pelo ID do evento e retentativas com backoff. Se você for o emissor, fale de filas de saída, isolamento por cliente e dead letter. Follow-ups comuns: o que acontece se o receptor ficar fora do ar, como garantir ordem e como evitar SSRF.
