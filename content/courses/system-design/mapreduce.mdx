Em 2004, o Google publicou o modelo MapReduce para processar terabytes em milhares de máquinas comuns sem que o programador lide com paralelismo, distribuição de dados e falhas. Você escreve duas funções simples, e o framework cuida do resto. O Hadoop popularizou a ideia em código aberto, e embora Spark e Flink o tenham superado, o modelo ainda é a base conceitual do processamento distribuído de dados.

## As duas funções

- **map(entrada) -> lista de pares (chave, valor):** processa cada registro de forma independente.
- **reduce(chave, lista de valores) -> resultado:** combina todos os valores de uma mesma chave.

Entre elas existe a fase de **shuffle**: o framework agrupa os pares emitidos pelos mappers por chave e envia todos os valores de uma chave ao mesmo reducer, normalmente por `hash(chave) mod R`.

## Exemplo: contagem de palavras

```python
def mapper(linha):
    for palavra in linha.lower().split():
        yield (palavra, 1)

def reducer(palavra, contagens):
    yield (palavra, sum(contagens))

# execução local simulando as fases
from collections import defaultdict

def mapreduce(linhas):
    agrupado = defaultdict(list)                 # shuffle
    for linha in linhas:
        for chave, valor in mapper(linha):
            agrupado[chave].append(valor)
    return dict(r for k, v in agrupado.items() for r in reducer(k, v))

print(mapreduce(["a b a", "b c"]))   # {'a': 2, 'b': 2, 'c': 1}
```

```javascript
function* mapper(linha) {
  for (const palavra of linha.toLowerCase().split(/\s+/).filter(Boolean)) {
    yield [palavra, 1];
  }
}

function* reducer(palavra, contagens) {
  yield [palavra, contagens.reduce((a, b) => a + b, 0)];
}

// execução local simulando as fases
function mapreduce(linhas) {
  const agrupado = new Map();                       // shuffle
  for (const linha of linhas) {
    for (const [chave, valor] of mapper(linha)) {
      if (!agrupado.has(chave)) agrupado.set(chave, []);
      agrupado.get(chave).push(valor);
    }
  }
  const saida = {};
  for (const [k, v] of agrupado) {
    for (const [palavra, total] of reducer(k, v)) saida[palavra] = total;
  }
  return saida;
}

console.log(mapreduce(["a b a", "b c"]));   // { a: 2, b: 2, c: 1 }
```

```typescript
function mapreduce(linhas: string[]): Record<string, number> {
  const agrupado = new Map<string, number[]>();     // shuffle
  for (const linha of linhas) {
    for (const [chave, valor] of mapper(linha)) {
```

```java
import java.util.*;

static List<Map.Entry<String, Integer>> mapper(String linha) {
    List<Map.Entry<String, Integer>> saida = new ArrayList<>();
    for (String palavra : linha.toLowerCase().split("\\s+")) {
        if (!palavra.isEmpty()) saida.add(Map.entry(palavra, 1));
    }
    return saida;
}

static Map.Entry<String, Integer> reducer(String palavra, List<Integer> contagens) {
    int soma = 0;
    for (int c : contagens) soma += c;
    return Map.entry(palavra, soma);
}

// execução local simulando as fases
static Map<String, Integer> mapreduce(List<String> linhas) {
    Map<String, List<Integer>> agrupado = new TreeMap<>();      // shuffle
    for (String linha : linhas) {
        for (Map.Entry<String, Integer> par : mapper(linha)) {
            agrupado.computeIfAbsent(par.getKey(), k -> new ArrayList<>()).add(par.getValue());
        }
    }
    Map<String, Integer> saida = new TreeMap<>();
    for (Map.Entry<String, List<Integer>> e : agrupado.entrySet()) {
        Map.Entry<String, Integer> r = reducer(e.getKey(), e.getValue());
        saida.put(r.getKey(), r.getValue());
    }
    return saida;
}

public static void main(String[] args) {
    System.out.println(mapreduce(List.of("a b a", "b c")));   // {a=2, b=2, c=1}
}
```

```cpp
#include <iostream>

using namespace std;

vector<pair<string, int>> mapper(const string& linha) {
    vector<pair<string, int>> saida;
    istringstream fluxo(linha);
    string palavra;
    while (fluxo >> palavra) {
        for (char& c : palavra) c = tolower(c);
        saida.push_back({palavra, 1});
    }
    return saida;
}

pair<string, int> reducer(const string& palavra, const vector<int>& contagens) {
    int soma = 0;
    for (int c : contagens) soma += c;
    return {palavra, soma};
}

// execução local simulando as fases
map<string, int> mapreduce(const vector<string>& linhas) {
    map<string, vector<int>> agrupado;      // shuffle
    for (const string& linha : linhas) {
        for (const auto& [chave, valor] : mapper(linha)) {
            agrupado[chave].push_back(valor);
        }
    }
    map<string, int> saida;
    for (const auto& [k, v] : agrupado) {
        auto r = reducer(k, v);
        saida[r.first] = r.second;
    }
    return saida;
}

int main() {
    cout << "{";
    bool primeiro = true;
    for (const auto& [palavra, total] : mapreduce({"a b a", "b c"})) {
        cout << (primeiro ? "" : ", ") << palavra << ": " << total;
        primeiro = false;
    }
    cout << "}" << endl;   // {a: 2, b: 2, c: 1}
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

static IEnumerable<KeyValuePair<string, int>> Mapper(string linha)
{
    foreach (string palavra in linha.ToLower().Split(new[] { ' ' }, StringSplitOptions.RemoveEmptyEntries))
    {
        yield return new KeyValuePair<string, int>(palavra, 1);
    }
}

static KeyValuePair<string, int> Reducer(string palavra, List<int> contagens)
{
    return new KeyValuePair<string, int>(palavra, contagens.Sum());
}

// execução local simulando as fases
static SortedDictionary<string, int> Mapreduce(IEnumerable<string> linhas)
{
    var agrupado = new SortedDictionary<string, List<int>>();     // shuffle
    foreach (string linha in linhas)
    {
        foreach (var par in Mapper(linha))
        {
            if (!agrupado.ContainsKey(par.Key)) agrupado[par.Key] = new List<int>();
            agrupado[par.Key].Add(par.Value);
        }
    }
    var saida = new SortedDictionary<string, int>();
    foreach (var e in agrupado)
    {
        var r = Reducer(e.Key, e.Value);
        saida[r.Key] = r.Value;
    }
    return saida;
}

static void Main()
{
    var r = Mapreduce(new[] { "a b a", "b c" });
    Console.WriteLine("{" + string.Join(", ", r.Select(p => p.Key + ": " + p.Value)) + "}");   // {a: 2, b: 2, c: 1}
}
```

```go
import (
	"fmt"
	"strings"
)

type chaveValor struct {
	chave string
	valor int
}

func mapper(linha string) []chaveValor {
	saida := []chaveValor{}
	for _, palavra := range strings.Fields(strings.ToLower(linha)) {
		saida = append(saida, chaveValor{palavra, 1})
	}
	return saida
}

func reducer(palavra string, contagens []int) chaveValor {
	soma := 0
	for _, c := range contagens {
		soma += c
	}
	return chaveValor{palavra, soma}
}

// execução local simulando as fases
func mapreduce(linhas []string) map[string]int {
	agrupado := map[string][]int{} // shuffle
	for _, linha := range linhas {
		for _, par := range mapper(linha) {
			agrupado[par.chave] = append(agrupado[par.chave], par.valor)
		}
	}
	saida := map[string]int{}
	for k, v := range agrupado {
		r := reducer(k, v)
		saida[r.chave] = r.valor
	}
	return saida
}

func main() {
	fmt.Println(mapreduce([]string{"a b a", "b c"})) // map[a:2 b:2 c:1]
}
```

## Como o framework executa

```text
Entrada em blocos (HDFS) -> mappers em paralelo (perto dos dados)
   -> spill em disco local -> shuffle pela rede -> reducers
   -> saída gravada no HDFS
```

1. A entrada é dividida em *splits* (por exemplo, 128 MB); cada um vira uma tarefa map. O escalonador prefere rodar o map **na máquina que já tem o bloco** (localidade de dados), pois mover código é mais barato que mover dados.
2. Cada mapper grava a saída ordenada por chave em disco local, particionada para os reducers.
3. Os reducers buscam (*fetch*) suas partições em todos os mappers, mesclam e executam o reduce.
4. Um **combiner** opcional faz uma pré-agregação no lado do mapper (somar contagens locais), reduzindo o tráfego do shuffle.

## Tolerância a falhas

O mestre acompanha as tarefas por heartbeat. Se uma máquina falha, as tarefas dela são **reexecutadas** em outra, o que só é seguro porque map e reduce são **determinísticos e sem efeitos colaterais**. Tarefas lentas (*stragglers*) recebem execução especulativa: uma cópia é lançada em outro nó, e vale a que terminar primeiro.

## Limitações e evolução

- **Disco a cada etapa:** o resultado intermediário é gravado em disco; jobs encadeados ficam lentos. O **Spark** mantém dados em memória e expressa DAGs de transformações, sendo muito mais rápido para iterações (aprendizado de máquina).
- **Modelo restritivo:** joins, grafos e consultas interativas são desajeitados em MapReduce puro. Hive e Pig surgiram para escrever SQL e traduzir para jobs.
- **Latência alta:** minutos a horas; não serve para tempo real (use stream).
- **Skew:** uma chave muito frequente sobrecarrega um reducer. Mitigue com combiners, salting da chave ou particionadores customizados.

| Aspecto | MapReduce | Spark |
| --- | --- | --- |
| Intermediários | Disco | Memória (com spill) |
| Modelo | Map e reduce | DAG com muitos operadores |
| Iteração | Lenta | Rápida |
| Uso hoje | Legado e conceito | Padrão em batch |

<Callout type="note" title="O padrão está em todo lugar">
Mesmo sem Hadoop, o raciocínio map, shuffle e reduce aparece em GROUP BY distribuído, em Spark, em Elasticsearch e em bancos MPP: processe perto dos dados e agrupe por chave.
