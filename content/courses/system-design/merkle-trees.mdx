Duas réplicas de um banco devem ter os mesmos dados, mas após falhas podem ter divergido em algumas linhas. Como descobrir **quais** registros diferem sem enviar todos os dados pela rede nem comparar bilhões de linhas uma a uma? A **Merkle tree** (árvore de hashes) resolve com muito pouco tráfego: compara-se um hash da raiz e, só se diferir, desce-se até as folhas que mudaram.

## Estrutura

- Cada **folha** contém o hash de um bloco de dados (um intervalo de chaves, um arquivo, uma transação).
- Cada **nó interno** contém o hash da concatenação dos hashes dos filhos.
- A **raiz** resume todo o conjunto: se um bit de qualquer dado mudar, o hash da raiz muda.

```text
             H(H12 + H34)         <- raiz
            /            \
        H12=H(h1+h2)   H34=H(h3+h4)
        /     \         /     \
       h1     h2       h3     h4  <- hashes dos blocos
```

```python
import hashlib

def h(b: bytes) -> bytes:
    return hashlib.sha256(b).digest()

def raiz(blocos):
    nivel = [h(b) for b in blocos]
    while len(nivel) > 1:
        if len(nivel) % 2:
            nivel.append(nivel[-1])          # duplica o último se for ímpar
        nivel = [h(nivel[i] + nivel[i + 1]) for i in range(0, len(nivel), 2)]
    return nivel[0]
```

```javascript
  return nivel[0];
}
```

```java
import java.util.*;

static byte[] h(byte[] b) {
    try {
        return MessageDigest.getInstance("SHA-256").digest(b);
    } catch (Exception e) {
        throw new IllegalStateException(e);
    }

static byte[] raiz(List<byte[]> blocos) {
    List<byte[]> nivel = new ArrayList<>();
    for (byte[] b : blocos) nivel.add(h(b));
    while (nivel.size() > 1) {
        if (nivel.size() % 2 == 1) {
            nivel.add(nivel.get(nivel.size() - 1)); // duplica o último se for ímpar

        List<byte[]> proximo = new ArrayList<>();
        for (int i = 0; i < nivel.size(); i += 2) {
            byte[] a = nivel.get(i), b = nivel.get(i + 1);
            byte[] juntos = Arrays.copyOf(a, a.length + b.length);
            System.arraycopy(b, 0, juntos, a.length, b.length);
            proximo.add(h(juntos));
        }
        nivel = proximo;
    }
    return nivel.get(0);
}
```

```cpp
    string m = msg;
    uint64_t bits = (uint64_t)msg.size() * 8;
    m += (char)0x80;
    while (m.size() % 64 != 56) m += (char)0;
    for (int i = 7; i >= 0; i--) m += (char)(bits >> (i * 8));
    auto rotr = [](uint32_t x, int n) { return (x >> n) | (x << (32 - n)); };
    for (size_t off = 0; off < m.size(); off += 64) {
        uint32_t w[64];
        for (int i = 0; i < 16; i++) {
            w[i] = ((uint32_t)(uint8_t)m[off + 4 * i] << 24) | ((uint32_t)(uint8_t)m[off + 4 * i + 1] << 16) |
                   ((uint32_t)(uint8_t)m[off + 4 * i + 2] << 8) | (uint32_t)(uint8_t)m[off + 4 * i + 3];
        }
        for (int i = 16; i < 64; i++) {
            uint32_t s0 = rotr(w[i - 15], 7) ^ rotr(w[i - 15], 18) ^ (w[i - 15] >> 3);
            uint32_t s1 = rotr(w[i - 2], 17) ^ rotr(w[i - 2], 19) ^ (w[i - 2] >> 10);
            w[i] = w[i - 16] + s0 + w[i - 7] + s1;
        }
        uint32_t a = h[0], b = h[1], c = h[2], d = h[3], e = h[4], f = h[5], g = h[6], hh = h[7];
        for (int i = 0; i < 64; i++) {
            uint32_t t1 = hh + (rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25)) + ((e & f) ^ (~e & g)) + K[i] + w[i];
            uint32_t t2 = (rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22)) + ((a & b) ^ (a & c) ^ (b & c));
            hh = g; g = f; f = e; e = d + t1; d = c; c = b; b = a; a = t1 + t2;
        }
        h[0] += a; h[1] += b; h[2] += c; h[3] += d; h[4] += e; h[5] += f; h[6] += g; h[7] += hh;
    }
    string out;
    for (int i = 0; i < 8; i++) for (int j = 3; j >= 0; j--) out += (char)(h[i] >> (j * 8));
    return out;
}

// h() devolve os 32 bytes do SHA-256; string guarda bytes
string h(const string& b) { return sha256(b); }

string raiz(const vector<string>& blocos) {
    vector<string> nivel;
    for (auto& b : blocos) nivel.push_back(h(b));
    while (nivel.size() > 1) {
        if (nivel.size() % 2) {
            nivel.push_back(nivel.back()); // duplica o último se for ímpar
        }
        vector<string> proximo;
        for (size_t i = 0; i < nivel.size(); i += 2) {
            proximo.push_back(h(nivel[i] + nivel[i + 1]));
        }
        nivel = proximo;
    }
    return nivel[0];
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Security.Cryptography;

static byte[] H(byte[] b)
{
    using (var sha = SHA256.Create())
    {
        return sha.ComputeHash(b);
    }
}

static byte[] Raiz(List<byte[]> blocos)
{
    var nivel = blocos.Select(b => H(b)).ToList();
    while (nivel.Count > 1)
    {
        if (nivel.Count % 2 == 1)
        {
            nivel.Add(nivel[nivel.Count - 1]); // duplica o último se for ímpar
        }
        var proximo = new List<byte[]>();
        for (int i = 0; i < nivel.Count; i += 2)
        {
            proximo.Add(H(nivel[i].Concat(nivel[i + 1]).ToArray()));
        }
        nivel = proximo;
    }
    return nivel[0];
}
```

```go
import "crypto/sha256"

func h(b []byte) []byte {
	soma := sha256.Sum256(b)
	return soma[:]
}

func raiz(blocos [][]byte) []byte {
	nivel := [][]byte{}
	for _, b := range blocos {
		nivel = append(nivel, h(b))
	}
	for len(nivel) > 1 {
		if len(nivel)%2 == 1 {
			nivel = append(nivel, nivel[len(nivel)-1]) // duplica o último se for ímpar
		}
		proximo := [][]byte{}

			juntos := append(append([]byte{}, nivel[i]...), nivel[i+1]...)
			proximo = append(proximo, h(juntos))
		}
		nivel = proximo
	}
	return nivel[0]
}
```

## Anti-entropy: sincronizando réplicas

1. Cada réplica constrói uma Merkle tree sobre seus intervalos de chaves.
2. Trocam as raízes. Se forem iguais, os dados são idênticos: fim, com um único hash trafegado.
3. Se diferirem, comparam os filhos e descem **apenas pelos ramos cujos hashes diferem**.
4. Ao chegar nas folhas divergentes, sincronizam só esses intervalos.

O custo cresce com log n para localizar uma diferença, em vez de n. Cassandra e DynamoDB (e o Riak) usam isso nos processos de reparo (*anti-entropy repair*).

## Prova de inclusão

Para provar que um bloco pertence ao conjunto sem enviar tudo, basta enviar o bloco mais os **hashes irmãos ao longo do caminho até a raiz**: cerca de log n hashes. O verificador recalcula a raiz e compara com a raiz confiável.

```text
Provar h3 em 4 blocos: enviar h3, h4 e H12.
Verificador: H34 = H(h3 + h4); raiz = H(H12 + H34) e compara.
```

Isso é a base de:

- **Git:** objetos de árvore e commits formam uma estrutura de hashes que detecta qualquer alteração.
- **Bitcoin e Ethereum:** cada bloco tem a raiz Merkle de suas transações; clientes leves verificam uma transação com poucos hashes (SPV).
- **Certificate Transparency:** logs públicos de certificados com provas de inclusão e consistência.
- **Sistemas de arquivos e distribuição de dados:** ZFS, IPFS, BitTorrent v2 e Dynamo para verificação de integridade.

## Trade-offs

- **Custo de manutenção:** cada escrita invalida os hashes do caminho até a raiz (log n atualizações). Em bancos com muitas escritas, a árvore é reconstruída periodicamente ou por intervalos.
- **Granularidade:** folhas grandes reduzem a árvore, mas obrigam a sincronizar blocos maiores quando há diferença.
- **Dados em memória ou disco:** árvore muito grande precisa de armazenamento dedicado.
- **Escolha do hash:** SHA-256 ou similar para segurança; para detecção de divergência interna basta algo mais barato.

<Callout type="note" title="Detecta divergência, não corrige sozinha">
A Merkle tree diz onde as réplicas diferem. Quem decide qual versão vale é outra regra: timestamp, vetor de versões ou líder.
</Callout>
