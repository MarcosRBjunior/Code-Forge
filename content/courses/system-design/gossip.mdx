Em um cluster de centenas de nós, como cada um descobre quem está vivo, quem entrou e qual é a configuração atual? Um servidor central de registro vira gargalo e ponto único de falha. Enviar tudo para todos (broadcast) custa N ao quadrado mensagens. O protocolo **gossip** (ou epidêmico) resolve isso imitando a propagação de boatos: cada nó conversa periodicamente com poucos vizinhos aleatórios, e a informação se espalha por todo o cluster.

## Como funciona

A cada intervalo (por exemplo, 1 segundo), cada nó:

1. Escolhe aleatoriamente um ou alguns pares.
2. Troca com eles o que sabe (lista de membros, versões de dados, contadores de heartbeat).
3. Mescla a informação recebida com a sua, mantendo o dado mais novo.

```python
import random

def rodada_gossip(meu_estado, pares, fanout=2):
    # estado: dict nó -> (heartbeat, status)
    for par in random.sample(pares, k=min(fanout, len(pares))):
        recebido = par.trocar(meu_estado)
        for no, (hb, st) in recebido.items():
            if no not in meu_estado or hb > meu_estado[no][0]:
                meu_estado[no] = (hb, st)
```

```javascript
// estado: Map nó -> [heartbeat, status]
function amostra(lista, k) {
  const copia = [...lista];
  for (let i = copia.length - 1; i > 0; i--) { // embaralha (Fisher-Yates)
    const j = Math.floor(Math.random() * (i + 1));
    [copia[i], copia[j]] = [copia[j], copia[i]];
  }
  return copia.slice(0, k);
}

function rodadaGossip(meuEstado, pares, fanout = 2) {
  for (const par of amostra(pares, Math.min(fanout, pares.length))) {
    const recebido = par.trocar(meuEstado);
    for (const [no, [hb, st]] of recebido) {
      if (!meuEstado.has(no) || hb > meuEstado.get(no)[0]) {
        meuEstado.set(no, [hb, st]);
      }
    }
  }
}

// peça de apoio do exemplo: um par que devolve o próprio estado
const parA = { trocar: (estado) => new Map([["a", [5, "vivo"]], ["b", [1, "vivo"]]]) };
const parB = { trocar: (estado) => new Map([["b", [9, "vivo"]], ["c", [2, "suspeito"]]]) };
const meu = new Map([["a", [3, "vivo"]]]);
rodadaGossip(meu, [parA, parB], 2);
console.log([...meu.entries()].sort().map(([no, [hb, st]]) => `${no}:${hb}:${st}`).join(" "));
```

```typescript
type Estado = Map<string, [number, string]>; // nó -> [heartbeat, status]

interface Par { trocar(estado: Estado): Estado }

function amostra<T>(lista: T[], k: number): T[] {
  const copia = lista.slice();
  for (let i = copia.length - 1; i > 0; i--) { // embaralha (Fisher-Yates)
    const j = Math.floor(Math.random() * (i + 1));
    const tmp = copia[i];
    copia[i] = copia[j];
    copia[j] = tmp;
  }
  return copia.slice(0, k);
}

function rodadaGossip(meuEstado: Estado, pares: Par[], fanout: number = 2): void {
  for (const par of amostra(pares, Math.min(fanout, pares.length))) {
    const recebido = par.trocar(meuEstado);
    recebido.forEach((valor, no) => {
      const [hb, st] = valor;
      const atual = meuEstado.get(no);
      if (atual === undefined || hb > atual[0]) {
        meuEstado.set(no, [hb, st]);
      }
    });
  }
}
```

```java
import java.util.*;

// estado: nó -> (heartbeat, status)
class Entrada {
    int hb;
    String st;
    Entrada(int hb, String st) { this.hb = hb; this.st = st; }
}

interface Par {
    Map<String, Entrada> trocar(Map<String, Entrada> estado);
}

static void rodadaGossip(Map<String, Entrada> meuEstado, List<Par> pares, int fanout) {
    List<Par> sorteio = new ArrayList<>(pares);
    Collections.shuffle(sorteio);
    for (Par par : sorteio.subList(0, Math.min(fanout, pares.size()))) {
        Map<String, Entrada> recebido = par.trocar(meuEstado);
        for (Map.Entry<String, Entrada> e : recebido.entrySet()) {
            Entrada atual = meuEstado.get(e.getKey());
            if (atual == null || e.getValue().hb > atual.hb) {
                meuEstado.put(e.getKey(), e.getValue());
            }
        }
    }
}

// peça de apoio do exemplo: um par que devolve o próprio estado
static Par parDe(String n1, int h1, String s1, String n2, int h2, String s2) {
    return estado -> {
        Map<String, Entrada> m = new HashMap<>();
        m.put(n1, new Entrada(h1, s1));
        m.put(n2, new Entrada(h2, s2));
        return m;
    };
}

public static void main(String[] args) {
    Map<String, Entrada> meu = new TreeMap<>();
    meu.put("a", new Entrada(3, "vivo"));
    rodadaGossip(meu, Arrays.asList(parDe("a", 5, "vivo", "b", 1, "vivo"), parDe("b", 9, "vivo", "c", 2, "suspeito")), 2);
    StringBuilder sb = new StringBuilder();
    for (Map.Entry<String, Entrada> e : meu.entrySet()) {
        sb.append(e.getKey()).append(":").append(e.getValue().hb).append(":").append(e.getValue().st).append(" ");
    }
    System.out.println(sb.toString().trim());
}
```

```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <map>
#include <random>
#include <string>
#include <utility>
#include <vector>
using namespace std;

// estado: nó -> (heartbeat, status)
using Estado = map<string, pair<int, string>>;

struct Par {
    function<Estado(const Estado&)> trocar;
};

void rodadaGossip(Estado& meuEstado, vector<Par> pares, int fanout = 2) {
    static mt19937 rng(random_device{}());
    shuffle(pares.begin(), pares.end(), rng);
    int k = min<int>(fanout, pares.size());
    for (int i = 0; i < k; i++) {
        Estado recebido = pares[i].trocar(meuEstado);
        for (const auto& [no, v] : recebido) {
            auto it = meuEstado.find(no);
            if (it == meuEstado.end() || v.first > it->second.first) {
                meuEstado[no] = v;
            }
        }
    }
}

int main() {
    // peça de apoio do exemplo: um par que devolve o próprio estado
    Par parA{[](const Estado&) { return Estado{{"a", {5, "vivo"}}, {"b", {1, "vivo"}}}; }};
    Par parB{[](const Estado&) { return Estado{{"b", {9, "vivo"}}, {"c", {2, "suspeito"}}}; }};
    Estado meu{{"a", {3, "vivo"}}};
    rodadaGossip(meu, {parA, parB}, 2);
    for (const auto& [no, v] : meu) cout << no << ":" << v.first << ":" << v.second << " ";
    cout << endl;
}
```

```csharp
class Entrada
{
    public int Hb;
    public string St;
}

interface IPar
{
    Dictionary<string, Entrada> Trocar(Dictionary<string, Entrada> estado);
}

class ParFixo : IPar
{
    private readonly Dictionary<string, Entrada> resposta;
    public ParFixo(Dictionary<string, Entrada> resposta) { this.resposta = resposta; }
    public Dictionary<string, Entrada> Trocar(Dictionary<string, Entrada> estado) { return resposta; }
}

static void RodadaGossip(Dictionary<string, Entrada> meuEstado, List<IPar> pares, int fanout = 2)
{
    var rnd = new Random();
    var sorteio = pares.OrderBy(p => rnd.Next()).Take(Math.Min(fanout, pares.Count));
    foreach (var par in sorteio)
    {
        var recebido = par.Trocar(meuEstado);
        foreach (var kv in recebido)
        {
            if (!meuEstado.ContainsKey(kv.Key) || kv.Value.Hb > meuEstado[kv.Key].Hb)
            {
                meuEstado[kv.Key] = kv.Value;
            }
        }
    }
}

static void Main()
{
    // peça de apoio do exemplo: um par que devolve o próprio estado
    var parA = new ParFixo(new Dictionary<string, Entrada> {
        { "a", new Entrada { Hb = 5, St = "vivo" } }, { "b", new Entrada { Hb = 1, St = "vivo" } } });
    var parB = new ParFixo(new Dictionary<string, Entrada> {
        { "b", new Entrada { Hb = 9, St = "vivo" } }, { "c", new Entrada { Hb = 2, St = "suspeito" } } });
```

```go
package main

import (
	"fmt"
	"math/rand"
	"sort"
)

// estado: nó -> (heartbeat, status)
type Entrada struct {
	hb int
	st string
}

type Estado map[string]Entrada

type Par interface {
	trocar(estado Estado) Estado
}

func rodadaGossip(meuEstado Estado, pares []Par, fanout int) {
	sorteio := append([]Par{}, pares...)
	rand.Shuffle(len(sorteio), func(i, j int) { sorteio[i], sorteio[j] = sorteio[j], sorteio[i] })
	k := fanout
	if len(pares) < k {
		k = len(pares)
	}
	for _, par := range sorteio[:k] {
		recebido := par.trocar(meuEstado)
		for no, v := range recebido {
			atual, ok := meuEstado[no]
			if !ok || v.hb > atual.hb {
				meuEstado[no] = v
			}
		}
	}
}

// peça de apoio do exemplo: um par que devolve o próprio estado
type ParFixo struct{ resposta Estado }

func (p ParFixo) trocar(estado Estado) Estado { return p.resposta }

func main() {
	parA := ParFixo{Estado{"a": {5, "vivo"}, "b": {1, "vivo"}}}
	parB := ParFixo{Estado{"b": {9, "vivo"}, "c": {2, "suspeito"}}}
	meu := Estado{"a": {3, "vivo"}}
	rodadaGossip(meu, []Par{parA, parB}, 2)
	nos := []string{}
	for no := range meu {
		nos = append(nos, no)
	}
	sort.Strings(nos)
	for _, no := range nos {
		fmt.Printf("%s:%d:%s ", no, meu[no].hb, meu[no].st)
	}
	fmt.Println()
}
```

## Por que funciona

A informação cresce de forma exponencial: se cada nó repassa a 2 outros por rodada, após k rodadas cerca de 2 elevado a k nós sabem. Todo o cluster é alcançado em aproximadamente **log N rodadas**. Com 1.000 nós, algumas dezenas de segundos já bastam, com carga constante por nó, independentemente do tamanho do cluster.

## Usos típicos

- **Membership e detecção de falhas:** Cassandra, Consul (Serf) e Redis Cluster usam gossip para saber quem está vivo. Um nó que não aumenta seu heartbeat por um tempo é marcado como suspeito, depois como morto.
- **Disseminação de metadados:** esquema, topologia do anel, configuração.
- **Agregação:** estimar médias, contagens e máximos de forma aproximada.
- **Anti-entropy:** réplicas comparam resumos (por exemplo, Merkle trees) e sincronizam diferenças.

## Variações

| Estilo | Ideia |
| --- | --- |
| Push | O nó envia o que sabe |
| Pull | O nó pergunta o que há de novo |
| Push-pull | Troca nos dois sentidos, converge mais rápido |
| SWIM | Gossip com sondagens diretas e indiretas para reduzir falsos positivos na detecção de falhas |

## Trade-offs

- **Consistência eventual:** em dado instante, nós têm visões diferentes. Não serve para decisões que exigem acordo imediato, como eleger líder único (use consenso).
- **Escalável e resiliente:** sem ponto central, tolera nós e mensagens perdidos.
- **Tráfego redundante:** o mesmo dado chega várias vezes; ajuste fanout e intervalo.
- **Falsos positivos:** lentidão pode ser confundida com falha. Detectores adaptativos como phi accrual e confirmação indireta do SWIM ajudam.
- **Segurança:** um nó malicioso pode espalhar informação falsa; em ambientes hostis, autentique as mensagens.

<Callout type="note" title="Gossip e consenso se complementam">
Sistemas como Cassandra usam gossip para descobrir membros e topologia, e outro mecanismo (Paxos leve, por exemplo) onde precisam de acordo forte.
</Callout>

## Na entrevista

Cite gossip quando precisar de membership ou detecção de falhas em cluster grande sem coordenador central. Follow-ups: "quanto tempo até todos saberem?" (cerca de log N rodadas), "e se um nó só estiver lento?" (SWIM com sondagem indireta, limiar adaptativo), "por que não um registro central?" (gargalo e SPOF).
