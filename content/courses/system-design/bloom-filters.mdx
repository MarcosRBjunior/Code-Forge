Você precisa responder "esse item já existe?" milhões de vezes por segundo, para bilhões de itens: essa URL já foi rastreada? Esse e-mail já está cadastrado? Essa chave está nesta SSTable em disco? Guardar tudo em um conjunto de memória custa caro, e consultar o banco a cada pergunta custa latência. O **Bloom filter** responde com uma fração da memória, aceitando um erro controlado de um só tipo.

## Como funciona

Um Bloom filter é um array de m bits, todos zero no início, mais k funções de hash independentes.

- **Inserir x:** calcule k hashes e ligue (bit = 1) as k posições.
- **Consultar x:** calcule os k hashes. Se **algum** bit é 0, x **definitivamente não está**. Se todos são 1, x **provavelmente está**.

```python
import hashlib

class Bloom:
    def __init__(self, m=1000, k=3):
        self.m, self.k, self.bits = m, k, [0] * m

    def _posicoes(self, item):
        for i in range(self.k):
            h = hashlib.sha256(f"{i}:{item}".encode()).hexdigest()
            yield int(h, 16) % self.m

    def adicionar(self, item):
        for p in self._posicoes(item):
            self.bits[p] = 1

    def pode_conter(self, item):
        return all(self.bits[p] for p in self._posicoes(item))
```

const { createHash } = require("crypto");

const sha256Hex = (s) => createHash("sha256").update(s).digest("hex");
// int(hex, 16) % m, sem perder precisão
const modHex = (hex, m) => Number(BigInt("0x" + hex) % BigInt(m));

class Bloom {
  constructor(m = 1000, k = 3) {
    this.m = m;
    this.k = k;
    this.bits = new Array(m).fill(0);
  }

  *_posicoes(item) {
    for (let i = 0; i < this.k; i++) {
      yield modHex(sha256Hex(`${i}:${item}`), this.m);
    }
  }

  adicionar(item) {
    for (const p of this._posicoes(item)) this.bits[p] = 1;
  }

  podeConter(item) {
    return [...this._posicoes(item)].every((p) => this.bits[p]);
  }
}

import java.math.BigInteger;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.*;

static String sha256Hex(String s) {
    try {
        byte[] d = MessageDigest.getInstance("SHA-256").digest(s.getBytes(StandardCharsets.UTF_8));
        return String.format("%064x", new BigInteger(1, d));
    } catch (Exception e) {
        throw new IllegalStateException(e);
    }
}

// int(hex, 16) % m
static int modHex(String hex, int m) {
    return new BigInteger(hex, 16).mod(BigInteger.valueOf(m)).intValue();
}

class Bloom {
    private final int m, k;
    private final int[] bits;

    Bloom(int m, int k) {
        this.m = m;
        this.k = k;
        this.bits = new int[m];
    }

    Bloom() {
        this(1000, 3);
    }

    private List<Integer> posicoes(String item) {
        List<Integer> r = new ArrayList<>();
        for (int i = 0; i < k; i++) r.add(modHex(sha256Hex(i + ":" + item), m));
        return r;
    }

    void adicionar(String item) {
        for (int p : posicoes(item)) bits[p] = 1;
    }

    boolean podeConter(String item) {
        for (int p : posicoes(item)) if (bits[p] == 0) return false;
        return true;
    }
}

static string Sha256Hex(string s)
{
    using (var sha = SHA256.Create())
    {
        return string.Concat(sha.ComputeHash(Encoding.UTF8.GetBytes(s)).Select(b => b.ToString("x2")));
    }
}

// int(hex, 16) % m, sem precisar de inteiros enormes
static int ModHex(string hex, int m)
{
    long r = 0;
    foreach (char c in hex) r = (r * 16 + Convert.ToInt32(c.ToString(), 16)) % m;
    return (int)r;
}

class Bloom
{
    private readonly int m, k;
    private readonly int[] bits;

    public Bloom(int m = 1000, int k = 3)
    {
        this.m = m;
        this.k = k;
        bits = new int[m];
    }

    private IEnumerable<int> Posicoes(string item)
    {
        for (int i = 0; i < k; i++)
        {
            yield return ModHex(Sha256Hex(i + ":" + item), m);
        }
    }

    public void Adicionar(string item)
    {
        foreach (int p in Posicoes(item)) bits[p] = 1;
    }

    public bool PodeConter(string item)
    {
        return Posicoes(item).All(p => bits[p] == 1);
    }
}

import (

func sha256Hex(s string) string {
	h := sha256.Sum256([]byte(s))
	return hex.EncodeToString(h[:])

// int(hex, 16) % m
func modHex(h string, m int) int {
	n := new(big.Int)
	n.SetString(h, 16)
	return int(n.Mod(n, big.NewInt(int64(m))).Int64())
}

	m, k int
	bits []int

	r := []int{}
	for i := 0; i < b.k; i++ {

		}

## Garantias

- **Sem falsos negativos:** se o filtro diz "não", o item não foi inserido.
- **Falsos positivos possíveis:** bits ligados por outros itens podem coincidir. A resposta "sim" significa "talvez".
- **Sem remoção:** desligar um bit apagaria outros itens também. Variantes: counting Bloom filter (contadores no lugar de bits) ou cuckoo filter.
- **Não lista os elementos** nem os recupera.

## Dimensionamento

Para n itens e taxa de falso positivo p desejada, valem as aproximações:

```text
bits por item  ~ 1,44 * log2(1/p)
k ótimo        ~ (m/n) * ln 2
```

Na prática: cerca de 10 bits por item e 7 hashes dão ~1% de falsos positivos. Para 1 bilhão de itens, isso é ~1,2 GB, contra dezenas de GB de um conjunto exato. Com 15 bits por item, a taxa cai para cerca de 0,1%.

## Onde é usado

- **LSM trees (Cassandra, HBase, RocksDB):** cada SSTable tem um filtro; consultas por chaves inexistentes evitam leituras de disco.
- **Crawlers:** "já visitei esta URL?".
- **Cache e CDN:** impedir que objetos acessados uma única vez ocupem cache (admitir só na segunda vez), e evitar *cache penetration* de chaves inexistentes.
- **Verificação de senhas vazadas ou URLs maliciosas**, antes de uma consulta cara ao servidor.
- **Bancos distribuídos:** reduzir joins e trocas de dados entre nós.

## Armadilhas

- O filtro lotado aumenta rápido a taxa de erro. Planeje a capacidade e reconstrua ou use *scalable Bloom filters*.
- O falso positivo precisa ser aceitável: o fluxo "sim, talvez" deve ser confirmado pela fonte de verdade.
- É preciso dimensionar bem com antecedência; filtros não crescem sem recriação.

<Callout type="tip" title="Use como pré-filtro">
O padrão é: se o filtro diz não, responda direto (barato e certo); se diz talvez, consulte o armazenamento real. Assim o filtro reduz muito as consultas caras.
</Callout>
