Quando você distribui dados ou requisições entre vários servidores (shards de cache, partições de banco), precisa de uma regra que diga em qual servidor cada chave mora. A regra mais simples é `hash(chave) % N`, em que N é o número de servidores. Ela funciona bem até o dia em que N muda.

## O problema do módulo

Suponha 4 servidores de cache e a regra `hash % 4`. Um servidor cai e N passa a ser 3. Agora quase toda chave muda de lugar: uma chave com hash 10 ia para o servidor 2 (10 % 4) e passa a ir para o servidor 1 (10 % 3). Em média, ao ir de N para N+1 servidores, cerca de N/(N+1) das chaves se movem, ou seja, quase todas.

Num cache, isso significa uma avalanche de cache misses batendo no banco ao mesmo tempo. Num banco particionado, significa migrar praticamente todos os dados.

## A ideia do anel

O hashing consistente coloca servidores e chaves no mesmo espaço de hash, visto como um círculo (por exemplo, de 0 a 2 elevado a 32, menos 1, voltando a 0).

1. Cada servidor é posicionado no anel pelo hash do seu identificador.
2. Cada chave é posicionada pelo hash dela.
3. A chave pertence ao **primeiro servidor encontrado andando no sentido horário** a partir da sua posição.

```text
posições no anel (0 a 99, por simplicidade), sentido horário:

  0 ---- 20 ---- 45 ---- 70 ---- 99 -> volta ao 0
         S_A     S_B     S_C

chave com hash 12 -> próximo servidor: S_A (20)
chave com hash 30 -> próximo servidor: S_B (45)
chave com hash 80 -> passa do fim, volta ao início: S_A (20)

cada servidor é dono do arco entre o servidor anterior e ele
```

Quando um servidor sai, só as chaves do arco dele passam para o próximo servidor. Quando um servidor entra, ele "rouba" apenas uma parte do arco do vizinho. Em média, apenas cerca de 1/N das chaves se move.

## Nós virtuais

Com poucos servidores, as posições no anel ficam desiguais: um servidor pode acabar com um arco enorme e receber 50% das chaves. Além disso, quando um servidor sai, toda a carga dele cai sobre um único vizinho.

A solução são **nós virtuais**: cada servidor físico ocupa várias posições no anel (por exemplo, 100 a 200), usando hashes como `servidorA#0`, `servidorA#1` e assim por diante. Isso suaviza a distribuição e, quando um servidor sai, a carga dele se espalha entre muitos servidores. Também permite dar pesos: uma máquina com o dobro de capacidade recebe o dobro de nós virtuais.

```python
import bisect
import hashlib

def _hash(valor: str) -> int:
    return int(hashlib.md5(valor.encode()).hexdigest(), 16)

class AnelConsistente:
    def __init__(self, vnodes: int = 100):
        self.vnodes = vnodes
        self.posicoes = []   # hashes ordenados
        self.dono = {}       # hash -> servidor

    def adicionar(self, servidor: str):
        for i in range(self.vnodes):
            h = _hash(f"{servidor}#{i}")
            bisect.insort(self.posicoes, h)
            self.dono[h] = servidor

    def remover(self, servidor: str):
        for i in range(self.vnodes):
            h = _hash(f"{servidor}#{i}")
            self.posicoes.remove(h)
            del self.dono[h]

    def servidor_para(self, chave: str) -> str:
        h = _hash(chave)
        idx = bisect.bisect_right(self.posicoes, h) % len(self.posicoes)
        return self.dono[self.posicoes[idx]]

anel = AnelConsistente()
for s in ["cache-a", "cache-b", "cache-c"]:
    anel.adicionar(s)
print(anel.servidor_para("usuario:42"))
```

```javascript
const { createHash } = require("crypto");

// md5 em hex de 32 caracteres: comparar o texto equivale a comparar os números de 128 bits
const hash = (valor) => createHash("md5").update(valor).digest("hex");

class AnelConsistente {
  constructor(vnodes = 100) {
    this.vnodes = vnodes;
    this.posicoes = []; // hashes ordenados
    this.dono = new Map(); // hash -> servidor
  }

  // índice do primeiro elemento maior que h (o bisect_right do Python)
  #direita(h) {
    let lo = 0;
    let hi = this.posicoes.length;
    while (lo < hi) {
      const meio = (lo + hi) >> 1;
      if (this.posicoes[meio] <= h) lo = meio + 1;
      else hi = meio;
    }
    return lo;
  }

  adicionar(servidor) {
    for (let i = 0; i < this.vnodes; i++) {
      const h = hash(`${servidor}#${i}`);
      this.posicoes.splice(this.#direita(h), 0, h);
      this.dono.set(h, servidor);
    }
  }

  remover(servidor) {
    for (let i = 0; i < this.vnodes; i++) {
      const h = hash(`${servidor}#${i}`);
      this.posicoes.splice(this.posicoes.indexOf(h), 1);
      this.dono.delete(h);
    }
  }

  servidorPara(chave) {
    const h = hash(chave);
    const idx = this.#direita(h) % this.posicoes.length;
    return this.dono.get(this.posicoes[idx]);
  }
}
```

```java
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.*;

// md5 em hex de 32 caracteres: comparar o texto equivale a comparar os números de 128 bits
static String hash(String valor) {
    try {
        byte[] d = MessageDigest.getInstance("MD5").digest(valor.getBytes(StandardCharsets.UTF_8));
        StringBuilder sb = new StringBuilder();
        for (byte b : d) sb.append(String.format("%02x", b));
        return sb.toString();
    } catch (Exception e) {
        throw new IllegalStateException(e);
    }
}

class AnelConsistente {
    private final int vnodes;
    private final TreeMap<String, String> anel = new TreeMap<>(); // hash (ordenado) -> servidor

    AnelConsistente(int vnodes) {
        this.vnodes = vnodes;
    }

    AnelConsistente() {
        this(100);
    }

    void adicionar(String servidor) {
        for (int i = 0; i < vnodes; i++) anel.put(hash(servidor + "#" + i), servidor);
    }

    void remover(String servidor) {
        for (int i = 0; i < vnodes; i++) anel.remove(hash(servidor + "#" + i));
    }

    String servidorPara(String chave) {
        Map.Entry<String, String> e = anel.higherEntry(hash(chave)); // primeiro maior que h (bisect_right)
        if (e == null) e = anel.firstEntry(); // dá a volta no anel
        return e.getValue();
    }
}

public static void main(String[] args) {
    AnelConsistente anel = new AnelConsistente();
    for (String s : List.of("cache-a", "cache-b", "cache-c")) {
        anel.adicionar(s);
    }
    System.out.println(anel.servidorPara("usuario:42"));
}
```

```cpp
#include <cstdint>
#include <iostream>

using namespace std;

// MD5 mínimo. Devolve os 16 bytes do resumo.
string md5(const string& msg) {
    static const int S[64] = {7, 12, 17, 22, 7, 12, 17, 22, 7, 12, 17, 22, 7, 12, 17, 22, 5, 9, 14, 20, 5, 9, 14, 20, 5, 9, 14, 20, 5, 9, 14, 20,
                              4, 11, 16, 23, 4, 11, 16, 23, 4, 11, 16, 23, 4, 11, 16, 23, 6, 10, 15, 21, 6, 10, 15, 21, 6, 10, 15, 21, 6, 10, 15, 21};
    uint32_t K[64];
    for (int i = 0; i < 64; i++) K[i] = (uint32_t)(4294967296.0 * fabs(sin(i + 1.0)));
    uint32_t a0 = 0x67452301, b0 = 0xefcdab89, c0 = 0x98badcfe, d0 = 0x10325476;
    string m = msg;
    uint64_t bits = (uint64_t)msg.size() * 8;
    m += (char)0x80;
    while (m.size() % 64 != 56) m += (char)0;
    for (int i = 0; i < 8; i++) m += (char)(bits >> (i * 8));
    for (size_t off = 0; off < m.size(); off += 64) {
        uint32_t M[16];
        for (int i = 0; i < 16; i++) {
            M[i] = (uint32_t)(uint8_t)m[off + 4 * i] | ((uint32_t)(uint8_t)m[off + 4 * i + 1] << 8) |
                   ((uint32_t)(uint8_t)m[off + 4 * i + 2] << 16) | ((uint32_t)(uint8_t)m[off + 4 * i + 3] << 24);
        }
        uint32_t A = a0, B = b0, C = c0, D = d0;
        for (int i = 0; i < 64; i++) {
            uint32_t F;
            int g;
            if (i < 16) { F = (B & C) | (~B & D); g = i; }
            else if (i < 32) { F = (D & B) | (~D & C); g = (5 * i + 1) % 16; }
            else if (i < 48) { F = B ^ C ^ D; g = (3 * i + 5) % 16; }
            else { F = C ^ (B | ~D); g = (7 * i) % 16; }
            F = F + A + K[i] + M[g];
            A = D; D = C; C = B;
            B = B + ((F << S[i]) | (F >> (32 - S[i])));
        }
        a0 += A; b0 += B; c0 += C; d0 += D;
    }
    string out;
    for (uint32_t v : {a0, b0, c0, d0}) for (int j = 0; j < 4; j++) out += (char)(v >> (j * 8));
    return out;
}

string hex(const string& bytes) {
    static const char* d = "0123456789abcdef";
    string r;
    for (unsigned char c : bytes) { r += d[c >> 4]; r += d[c & 15]; }
    return r;
}

// md5 em hex de 32 caracteres: comparar o texto equivale a comparar os números de 128 bits
string hashDe(const string& valor) { return hex(md5(valor)); }

class AnelConsistente {
    int vnodes;
    map<string, string> anel; // hash (ordenado) -> servidor

public:
    AnelConsistente(int vnodes = 100) : vnodes(vnodes) {}

    void adicionar(const string& servidor) {
        for (int i = 0; i < vnodes; i++) anel[hashDe(servidor + "#" + to_string(i))] = servidor;
    }

    void remover(const string& servidor) {
        for (int i = 0; i < vnodes; i++) anel.erase(hashDe(servidor + "#" + to_string(i)));
    }

    string servidorPara(const string& chave) const {
        auto it = anel.upper_bound(hashDe(chave)); // primeiro maior que h (bisect_right)
        if (it == anel.end()) it = anel.begin();   // dá a volta no anel
        return it->second;
    }
};

int main() {
    AnelConsistente anel;
    for (string s : {"cache-a", "cache-b", "cache-c"}) {
        anel.adicionar(s);
    }
    cout << anel.servidorPara("usuario:42") << endl;
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Security.Cryptography;
using System.Text;

// md5 em hex de 32 caracteres: comparar o texto equivale a comparar os números de 128 bits
static string Hash(string valor)
{
    using (var md5 = MD5.Create())
    {
        return string.Concat(md5.ComputeHash(Encoding.UTF8.GetBytes(valor)).Select(b => b.ToString("x2")));
    }
}

class AnelConsistente
{
    private readonly int vnodes;
    private readonly List<string> posicoes = new List<string>(); // hashes ordenados
    private readonly Dictionary<string, string> dono = new Dictionary<string, string>(); // hash -> servidor

    public AnelConsistente(int vnodes = 100)
    {
        this.vnodes = vnodes;
    }

    // índice do primeiro elemento maior que h (o bisect_right do Python)
    private int Direita(string h)
    {
        int lo = 0, hi = posicoes.Count;
        while (lo < hi)
        {
            int meio = (lo + hi) / 2;
            if (string.CompareOrdinal(posicoes[meio], h) <= 0) lo = meio + 1;
            else hi = meio;
        }
        return lo;
    }

    public void Adicionar(string servidor)
    {
        for (int i = 0; i < vnodes; i++)
        {
            string h = Hash(servidor + "#" + i);
            posicoes.Insert(Direita(h), h);
            dono[h] = servidor;
        }
    }

    public void Remover(string servidor)
    {
        for (int i = 0; i < vnodes; i++)
        {
            string h = Hash(servidor + "#" + i);
            posicoes.Remove(h);
            dono.Remove(h);
        }
    }

    public string ServidorPara(string chave)
    {
        string h = Hash(chave);
        int idx = Direita(h) % posicoes.Count;
        return dono[posicoes[idx]];
    }
}

static void Main()
{
    var anel = new AnelConsistente();
    foreach (var s in new[] { "cache-a", "cache-b", "cache-c" })
    {
        anel.Adicionar(s);
    }
    Console.WriteLine(anel.ServidorPara("usuario:42"));
}
```

```go
import (
	"crypto/md5"
	"encoding/hex"
	"fmt"
	"sort"
)

// md5 em hex de 32 caracteres: comparar o texto equivale a comparar os números de 128 bits
func hash(valor string) string {
	h := md5.Sum([]byte(valor))
	return hex.EncodeToString(h[:])
}

type AnelConsistente struct {
	vnodes   int
	posicoes []string          // hashes ordenados
	dono     map[string]string // hash -> servidor
}

func NovoAnel(vnodes int) *AnelConsistente {
	return &AnelConsistente{vnodes: vnodes, dono: map[string]string{}}
}

// índice do primeiro elemento maior que h (o bisect_right do Python)
func (a *AnelConsistente) direita(h string) int {
	return sort.Search(len(a.posicoes), func(i int) bool { return a.posicoes[i] > h })
}

func (a *AnelConsistente) adicionar(servidor string) {
	for i := 0; i < a.vnodes; i++ {
		h := hash(fmt.Sprintf("%s#%d", servidor, i))
		pos := a.direita(h)
		a.posicoes = append(a.posicoes, "")
		copy(a.posicoes[pos+1:], a.posicoes[pos:])
		a.posicoes[pos] = h
		a.dono[h] = servidor
	}
}

func (a *AnelConsistente) remover(servidor string) {
	for i := 0; i < a.vnodes; i++ {
		h := hash(fmt.Sprintf("%s#%d", servidor, i))
		pos := sort.SearchStrings(a.posicoes, h)
		a.posicoes = append(a.posicoes[:pos], a.posicoes[pos+1:]...)
		delete(a.dono, h)
	}
}

func (a *AnelConsistente) servidorPara(chave string) string {
	h := hash(chave)
	idx := a.direita(h) % len(a.posicoes)
	return a.dono[a.posicoes[idx]]
}

func main() {
	anel := NovoAnel(100)
	for _, s := range []string{"cache-a", "cache-b", "cache-c"} {
		anel.adicionar(s)
	}
	fmt.Println(anel.servidorPara("usuario:42"))
}
```

A busca usa pesquisa binária na lista ordenada, então custa O(log V), em que V é o total de nós virtuais. O `% len(...)` faz a volta no anel quando a chave fica depois da última posição. MD5 aparece aqui só como função de distribuição, não por segurança.

## Onde é usado

- Clientes de cache distribuído (Memcached) para escolher o servidor de cada chave.
- Bancos como Cassandra e DynamoDB para distribuir partições; a réplica de uma chave costuma ir para os próximos nós no anel.
- Load balancers que precisam de afinidade (mesmo cliente no mesmo backend) sem quebrar tudo quando um backend muda.

<Callout type="note" title="Alternativas">
Existem outras abordagens com a mesma propriedade de mover poucas chaves, como rendezvous hashing (cada chave escolhe o servidor com maior hash combinado) e jump consistent hash. Muitos bancos também usam um número fixo de partições lógicas mapeadas para nós, movendo partições inteiras em vez de chaves.
</Callout>
