Quantos usuários únicos visitaram o site hoje? Quantos IPs distintos acessaram a API? Contar exatamente exige guardar todos os identificadores já vistos: um conjunto de 1 bilhão de ids de 8 bytes ocupa cerca de 8 GB e precisa ser combinado entre servidores. O **HyperLogLog (HLL)** estima a **cardinalidade** (número de elementos distintos) com erro de cerca de 1% usando apenas alguns kilobytes.

## A intuição

Imagine jogar uma moeda repetidamente. Ver uma sequência de 10 caras seguidas é raro, e só acontece, em média, depois de cerca de 2 elevado a 10 sequências tentadas. Portanto, se o maior número de caras seguidas que você observou foi 10, você provavelmente fez cerca de mil tentativas.

O HLL aplica isso a hashes. Cada elemento é transformado em um hash uniforme de bits. Quanto mais **zeros à esquerda** um hash tem, mais raro ele é: um hash com k zeros iniciais ocorre com probabilidade de 1 em 2 elevado a k+1. O maior número de zeros iniciais já visto estima a ordem de grandeza da quantidade de itens distintos. Elementos repetidos geram o mesmo hash, então **duplicatas não alteram o resultado**.

## Reduzindo a variância

Uma única observação é muito ruidosa (um azar de hash distorce tudo). O HLL divide os hashes em **m registradores** (buckets):

1. Use os primeiros p bits do hash para escolher um registrador (m = 2 elevado a p).
2. Nos bits restantes, conte os zeros à esquerda (mais um) e guarde no registrador o **máximo** visto.
3. A estimativa final é uma **média harmônica** dos valores 2 elevado ao registrador, multiplicada por m ao quadrado e por uma constante de correção.

O erro padrão é aproximadamente `1,04 / sqrt(m)`. Com m = 16.384 registradores de 6 bits (cerca de 12 KB), o erro fica em torno de 0,81%, para cardinalidades de bilhões.

```python
import hashlib

def hll_basico(itens, p=10):
    m = 1 << p
    regs = [0] * m
    for item in itens:
        h = int(hashlib.sha256(str(item).encode()).hexdigest(), 16) & ((1 << 64) - 1)
        idx = h >> (64 - p)
        resto = h & ((1 << (64 - p)) - 1)
        rank = (64 - p) - resto.bit_length() + 1
        regs[idx] = max(regs[idx], rank)
    alpha = 0.7213 / (1 + 1.079 / m)
    return alpha * m * m / sum(2.0 ** -r for r in regs)
```

```javascript
const { createHash } = require("crypto");

function hllBasico(itens, p = 10) {
  const m = 1 << p;
  const regs = new Array(m).fill(0);
  for (const item of itens) {
    const hex = createHash("sha256").update(String(item)).digest("hex");
    const h = BigInt("0x" + hex.slice(-16)); // os 64 bits de baixo
    const idx = Number(h >> BigInt(64 - p));
    const resto = h & ((BigInt(1) << BigInt(64 - p)) - BigInt(1));
    const bitLength = resto === BigInt(0) ? 0 : resto.toString(2).length;
    const rank = 64 - p - bitLength + 1;
    regs[idx] = Math.max(regs[idx], rank);
  }
  const alpha = 0.7213 / (1 + 1.079 / m);
  let soma = 0;
  for (const r of regs) soma += 2.0 ** -r;
  return (alpha * m * m) / soma;
}
```

```java
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.*;

static double hllBasico(Iterable<?> itens, int p) throws Exception {
    int m = 1 << p;
    int[] regs = new int[m];
    MessageDigest sha = MessageDigest.getInstance("SHA-256");
    for (Object item : itens) {
        byte[] d = sha.digest(String.valueOf(item).getBytes(StandardCharsets.UTF_8));
        long h = 0; // os 64 bits de baixo (últimos 8 bytes)
        for (int i = 24; i < 32; i++) h = (h << 8) | (d[i] & 0xFFL);
        int idx = (int) (h >>> (64 - p));
        long resto = h & ((1L << (64 - p)) - 1);
        int bitLength = 64 - Long.numberOfLeadingZeros(resto);
        int rank = (64 - p) - bitLength + 1;
        regs[idx] = Math.max(regs[idx], rank);
    }
    double alpha = 0.7213 / (1 + 1.079 / m);
    double soma = 0;
    for (int r : regs) soma += Math.pow(2.0, -r);
    return alpha * m * m / soma;
}

static double hllBasico(Iterable<?> itens) throws Exception {
    return hllBasico(itens, 10);
}
```

```cpp
        0x19a4c116, 0x1e376c08, 0x2748774c, 0x34b0bcb5, 0x391c0cb3, 0x4ed8aa4a, 0x5b9cca4f, 0x682e6ff3,

    uint32_t h[8] = {0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a, 0x510e527f, 0x9b05688c, 0x1f83d9ab, 0x5be0cd19};
    string m = msg;
    uint64_t bits = (uint64_t)msg.size() * 8;
    m += (char)0x80;
    while (m.size() % 64 != 56) m += (char)0;
    for (int i = 7; i >= 0; i--) m += (char)(bits >> (i * 8));
    auto rotr = [](uint32_t x, int n) { return (x >> n) | (x << (32 - n)); };
    for (size_t off = 0; off < m.size(); off += 64) {
        uint32_t w[64];
        for (int i = 0; i < 16; i++) {
            w[i] = ((uint32_t)(uint8_t)m[off + 4 * i] << 24) | ((uint32_t)(uint8_t)m[off + 4 * i + 1] << 16) |
                   ((uint32_t)(uint8_t)m[off + 4 * i + 2] << 8) | (uint32_t)(uint8_t)m[off + 4 * i + 3];
        }
        for (int i = 16; i < 64; i++) {
            uint32_t s0 = rotr(w[i - 15], 7) ^ rotr(w[i - 15], 18) ^ (w[i - 15] >> 3);
            uint32_t s1 = rotr(w[i - 2], 17) ^ rotr(w[i - 2], 19) ^ (w[i - 2] >> 10);
            w[i] = w[i - 16] + s0 + w[i - 7] + s1;
        }
        uint32_t a = h[0], b = h[1], c = h[2], d = h[3], e = h[4], f = h[5], g = h[6], hh = h[7];
        for (int i = 0; i < 64; i++) {
            uint32_t t1 = hh + (rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25)) + ((e & f) ^ (~e & g)) + K[i] + w[i];
            uint32_t t2 = (rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22)) + ((a & b) ^ (a & c) ^ (b & c));
            hh = g; g = f; f = e; e = d + t1; d = c; c = b; b = a; a = t1 + t2;
        }
        h[0] += a; h[1] += b; h[2] += c; h[3] += d; h[4] += e; h[5] += f; h[6] += g; h[7] += hh;
    }
    string out;
    for (int i = 0; i < 8; i++) for (int j = 3; j >= 0; j--) out += (char)(h[i] >> (j * 8));
    return out;
}

string hex(const string& bytes) {
    static const char* d = "0123456789abcdef";
    string r;
    for (unsigned char c : bytes) { r += d[c >> 4]; r += d[c & 15]; }
    return r;
}

template <typename Itens>
double hllBasico(const Itens& itens, int p = 10) {
    int m = 1 << p;
    vector<int> regs(m, 0);
    for (const auto& item : itens) {
        string hx = hex(sha256(to_string(item)));
        uint64_t h = stoull(hx.substr(48), nullptr, 16); // os 64 bits de baixo
        int idx = (int)(h >> (64 - p));
        uint64_t resto = h & ((1ULL << (64 - p)) - 1);
        int bitLength = 0;
        for (uint64_t r = resto; r; r >>= 1) bitLength++;
        int rank = (64 - p) - bitLength + 1;
        regs[idx] = max(regs[idx], rank);
    }
    double alpha = 0.7213 / (1 + 1.079 / m);
    double soma = 0;
    for (int r : regs) soma += pow(2.0, -r);
    return alpha * m * m / soma;
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Security.Cryptography;
using System.Text;

static double HllBasico(IEnumerable<object> itens, int p = 10)
{
    int m = 1 << p;
    var regs = new int[m];
    using (var sha = SHA256.Create())
    {
        foreach (var item in itens)
        {
            byte[] d = sha.ComputeHash(Encoding.UTF8.GetBytes(item.ToString()));
            ulong h = 0; // os 64 bits de baixo (últimos 8 bytes)
            for (int i = 24; i < 32; i++) h = (h << 8) | d[i];
            int idx = (int)(h >> (64 - p));
            ulong resto = h & ((1UL << (64 - p)) - 1);
            int bitLength = 0;
            for (ulong r = resto; r != 0; r >>= 1) bitLength++;
            int rank = (64 - p) - bitLength + 1;
            regs[idx] = Math.Max(regs[idx], rank);
        }
    }
    double alpha = 0.7213 / (1 + 1.079 / m);
    double soma = regs.Sum(r => Math.Pow(2.0, -r));
    return alpha * m * m / soma;
}
```

```go
import (
	"crypto/sha256"
	"encoding/binary"
	"fmt"
	"math"
	"math/bits"
)

func hllBasico(itens []interface{}, p int) float64 {
	m := 1 << p
	regs := make([]int, m)
	for _, item := range itens {
		d := sha256.Sum256([]byte(fmt.Sprint(item)))
		h := binary.BigEndian.Uint64(d[24:]) // os 64 bits de baixo
		idx := int(h >> uint(64-p))
		resto := h & ((uint64(1) << uint(64-p)) - 1)
		rank := (64 - p) - bits.Len64(resto) + 1
		if rank > regs[idx] {
			regs[idx] = rank
		}
	}
	alpha := 0.7213 / (1 + 1.079/float64(m))
	soma := 0.0
	for _, r := range regs {
		soma += math.Pow(2.0, -float64(r))
	}
	return alpha * float64(m) * float64(m) / soma
}
```

## Propriedades úteis

- **Memória fixa:** não cresce com o número de itens distintos.
- **Mesclável:** a união de dois HLLs é o máximo registrador a registrador. Cada servidor mantém o seu e o agregador mescla, ideal para sistemas distribuídos e janelas de tempo (some 7 dias mesclando 7 HLLs diários).
- **Idempotente:** reprocessar eventos não distorce.

## Limitações

- Estimativa, não contagem exata: não serve para cobrança.
- Não responde "o item x está no conjunto?" nem lista os elementos.
- Interseção e diferença só podem ser estimadas por inclusão-exclusão, com erro maior.
- Não suporta remoção.

## Onde usar

Redis (`PFADD`, `PFCOUNT`, `PFMERGE`), BigQuery (`APPROX_COUNT_DISTINCT`), Presto, Druid, Redshift e Postgres (extensão). Casos clássicos: usuários únicos por dia (DAU), visitantes por página, IPs únicos por alvo (detecção de ataque), valores distintos para otimizadores de consulta.

<Callout type="tip" title="Combine com janelas">
Guarde um HLL por hora ou por dia. Para "únicos nos últimos 7 dias" basta mesclar sete deles, sem reprocessar os eventos.
</Callout>

## Na entrevista

Em "contar visualizações únicas" ou "DAU em escala", proponha HLL: 12 KB por contador, erro de cerca de 1%, mesclagem entre nós. Follow-ups: "e se precisar do número exato?" (conjunto exato ou banco com agregação), "como somar entre regiões?" (mesclar por máximo), "como saber se um usuário específico já viu?" (Bloom filter, não HLL).
