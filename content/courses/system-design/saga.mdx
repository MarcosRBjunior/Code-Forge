Uma saga troca uma grande transação distribuída por uma **sequência de transações locais**, cada uma confirmada no banco do próprio serviço. Se algum passo falhar, a saga executa **transações de compensação** que desfazem, em termos de negócio, o que os passos anteriores fizeram. O termo vem de um artigo de 1987 sobre transações longas em bancos de dados e virou o padrão de fato para consistência entre microsserviços.

## Exemplo: reservar uma viagem

| Passo | Ação | Compensação |
| --- | --- | --- |
| T1 | Criar pedido como PENDENTE | Marcar pedido como CANCELADO |
| T2 | Reservar voo | Cancelar reserva do voo |
| T3 | Reservar hotel | Cancelar reserva do hotel |
| T4 | Cobrar cartão | Estornar cobrança |
| T5 | Marcar pedido como CONFIRMADO | (último passo, não precisa) |

Se T4 falhar, a saga executa C3, C2 e C1, nessa ordem inversa. Repare que a compensação não apaga o histórico: um estorno é um novo lançamento, não a remoção do anterior.

## Coreografia versus orquestração

### Coreografia

Não há um controlador central. Cada serviço reage a eventos e publica os seus:

```text
Pedidos  --PedidoCriado-->  Voos  --VooReservado-->  Hotéis  --HotelReservado-->  Pagamentos
                                                                                     |
Hotéis <--PagamentoRecusado--------------------------------------------------------- |
  (cancela hotel e publica HotelCancelado, que Voos escuta, e assim por diante)
```

É simples para fluxos curtos e mantém os serviços desacoplados. Mas o fluxo fica espalhado: para entender a saga inteira você precisa ler o código de todos os serviços, e ciclos de eventos são fáceis de criar sem querer.

### Orquestração

Um **orquestrador** (um serviço ou um motor de workflow como Temporal ou AWS Step Functions) conhece a sequência, envia comandos a cada serviço e decide quando compensar.

```python
class Saga:
    def __init__(self):
        self.passos = []   # pares (acao, compensacao)

    def passo(self, acao, compensacao):
        self.passos.append((acao, compensacao))
        return self

    def executar(self, ctx):
        feitos = []
        for acao, compensacao in self.passos:
            try:
                acao(ctx)
                feitos.append(compensacao)
            except Exception as erro:
                print(f"falhou: {erro}; compensando")
                for comp in reversed(feitos):
                    comp(ctx)   # em produção: com retry até dar certo

        return True
```

```java
import java.util.*;
import java.util.function.Consumer;

class Saga {
    private final List<Consumer<Integer>[]> passos = new ArrayList<>();   // pares {acao, compensacao}

    @SuppressWarnings("unchecked")
    Saga passo(Consumer<Integer> acao, Consumer<Integer> compensacao) {
        passos.add(new Consumer[]{acao, compensacao});
        return this;
    }

    boolean executar(int ctx) {
        List<Consumer<Integer>> feitos = new ArrayList<>();
        for (Consumer<Integer>[] par : passos) {
            try {
                par[0].accept(ctx);
                feitos.add(par[1]);
            } catch (RuntimeException erro) {
                System.out.println("falhou: " + erro.getMessage() + "; compensando");
                Collections.reverse(feitos);
                for (Consumer<Integer> comp : feitos) {
                    comp.accept(ctx);   // em produção: com retry até dar certo
                }
                return false;
            }
        }
        return true;
    }
}

static void cobrar(int ctx) {
    throw new RuntimeException("cartão recusado");
}

public static void main(String[] args) {
    Saga saga = new Saga()
        .passo(c -> System.out.println("pedido criado"), c -> System.out.println("pedido cancelado"))
        .passo(c -> System.out.println("voo reservado"), c -> System.out.println("voo cancelado"))
        .passo(Main::cobrar, c -> System.out.println("estorno"));
    System.out.println(saga.executar(42));
}
```

```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <stdexcept>
#include <utility>
#include <vector>
using namespace std;

class Saga {
    using Passo = function<void(int)>;
    vector<pair<Passo, Passo>> passos;   // pares (acao, compensacao)

public:
    Saga& passo(Passo acao, Passo compensacao) {
        passos.push_back({acao, compensacao});
        return *this;
    }

    bool executar(int ctx) {
        vector<Passo> feitos;
        for (auto& [acao, compensacao] : passos) {
            try {
                acao(ctx);
                feitos.push_back(compensacao);
            } catch (const exception& erro) {
                cout << "falhou: " << erro.what() << "; compensando" << endl;
                for (auto it = feitos.rbegin(); it != feitos.rend(); ++it) {
                    (*it)(ctx);   // em produção: com retry até dar certo
                }
                return false;
            }
        }
        return true;
    }
};
```

```csharp
using System;
using System.Collections.Generic;

class Saga
{
    private readonly List<Tuple<Action<int>, Action<int>>> passos = new List<Tuple<Action<int>, Action<int>>>();   // pares (acao, compensacao)

}
```

```go
import (
	"errors"
	"fmt"
)

type passo struct {
	acao         func(ctx int) error
	compensacao  func(ctx int)
}

type Saga struct {
	passos []passo
}

func (s *Saga) passo(acao func(int) error, compensacao func(int)) *Saga {
	s.passos = append(s.passos, passo{acao, compensacao})
	return s
}

func (s *Saga) executar(ctx int) bool {
	feitos := []func(int){}
	for _, p := range s.passos {
		if err := p.acao(ctx); err != nil {
			fmt.Printf("falhou: %v; compensando\n", err)
			for i := len(feitos) - 1; i >= 0; i-- {
				feitos[i](ctx) // em produção: com retry até dar certo
			}
			return false
		}
		feitos = append(feitos, p.compensacao)
	}
	return true
}

func cobrar(ctx int) error {
	return errors.New("cartão recusado")
}

func main() {
	ok := func(msg string) func(int) error {
		return func(int) error { fmt.Println(msg); return nil }
	}
	imprime := func(msg string) func(int) { return func(int) { fmt.Println(msg) } }
	saga := (&Saga{}).
		passo(ok("pedido criado"), imprime("pedido cancelado")).
		passo(ok("voo reservado"), imprime("voo cancelado")).
		passo(cobrar, imprime("estorno"))
	fmt.Println(saga.executar(42))
}
```

Num orquestrador real, o estado da saga (quais passos foram feitos) é persistido a cada transição, para que ela continue de onde parou depois de uma queda.

| Critério | Coreografia | Orquestração |
| --- | --- | --- |
| Visibilidade do fluxo | Espalhada | Centralizada |
| Acoplamento | Baixo, via eventos | Serviços conhecem o orquestrador |
| Fluxos longos ou com ramificações | Difícil | Natural |
| Ponto central | Não há | Orquestrador (precisa ser resiliente) |

## Regras para não se machucar

- **Compensações devem ser idempotentes e sempre possíveis.** Elas podem rodar mais de uma vez por causa de retries, e não podem "falhar por regra de negócio". Se uma compensação nunca pode ser rejeitada, a saga sempre termina.
- **Ordene os passos pelo risco.** Coloque cedo os passos que mais falham (validação, reserva) e tarde os que não têm desfazer, como enviar um e-mail. Um passo sem compensação depois do qual nada mais falha é chamado de *pivot*.
- **Falta isolamento.** Outro usuário pode ver o voo reservado de uma viagem que vai ser cancelada. Mitigue com estados semânticos (PENDENTE), *semantic locks* (marcar o registro como em uso por uma saga) ou relendo valores antes de confirmar.

<Callout type="warning" title="Compensar não é voltar no tempo">
Se o cliente recebeu uma notificação de "voo reservado", o estorno não apaga a notificação. Desenhe as compensações pensando no que o mundo externo já viu, e adie efeitos visíveis para depois do pivot.
</Callout>
