Janelas de contexto cresceram muito, e a tentação é óbvia: colocar o manual inteiro, toda a conversa e todos os documentos no prompt e deixar o modelo se virar. Funciona em demonstrações e falha em produção por três motivos. Cada token de entrada custa dinheiro em toda chamada. O prefill de um prompt enorme aumenta o tempo até o primeiro token e ocupa memória de KV cache que limitaria o batch. E modelos tendem a aproveitar pior informações enterradas no meio de contextos muito longos. Contexto é um recurso escasso, e o sistema precisa decidir o que entra.

## O orçamento de contexto

Trate a janela como um orçamento com fatias:

```text
janela do modelo
 |- reserva para a saida (max_tokens)
 |- instrucoes de sistema e formato        fixo, candidato a cache de prefixo
 |- memoria de longo prazo do usuario      poucos fatos relevantes
 |- documentos recuperados (RAG)           os mais relevantes, ate o limite
 |- historico recente                      ultimos turnos completos
 |- resumo do historico antigo             compacto
 '- mensagem atual                         nunca cortada
```

A regra de ouro é **montar o prompt por prioridade, não por ordem de chegada**. A mensagem atual e as instruções nunca saem; documentos e histórico disputam o resto conforme a relevância.

## Um montador de contexto

O programa abaixo implementa um orçamento simples com números hipotéticos. Ele reserva a saída, inclui instruções e mensagem atual, depois preenche com trechos recuperados em ordem de relevância (descartando os abaixo de um score mínimo) e por fim com os turnos mais recentes do histórico. O que sobra do histórico vira resumo.

```python
JANELA = 16_000
RESERVA_SAIDA = 1_500
SCORE_MIN = 0.55

sistema, mensagem, resumo_antigo = 1_200, 150, 300
trechos = [("politica-ferias", 0.91, 1_800), ("faq-rh", 0.84, 2_200), ("manual-ponto", 0.72, 3_000),
           ("ata-2019", 0.58, 2_500), ("cardapio", 0.31, 900)]
historico = [900, 1_100, 700, 1_300, 800, 600, 1_200, 1_000]   # tokens por turno, do mais antigo ao mais recente

def montar(limite_docs_pct=0.6):
    livre = JANELA - RESERVA_SAIDA - sistema - mensagem - resumo_antigo
    teto_docs = int(livre * limite_docs_pct)
    usados, docs = 0, []
    for nome, score, tok in sorted(trechos, key=lambda t: -t[1]):
        if score >= SCORE_MIN and usados + tok <= teto_docs:
            docs.append(nome)
            usados += tok
    livre -= usados
    turnos, hist = 0, 0
    for tok in reversed(historico):
        if hist + tok > livre:
            break
        hist += tok
        turnos += 1
    return docs, usados, turnos, hist, livre - hist

docs, t_docs, turnos, t_hist, sobra = montar()
print(f"documentos: {docs} ({t_docs} tokens)")
print(f"historico: ultimos {turnos} de {len(historico)} turnos ({t_hist} tokens); resto resumido")
total = sistema + mensagem + resumo_antigo + t_docs + t_hist
print(f"prompt: {total} tokens, sobra {sobra}, reserva de saida {RESERVA_SAIDA}")

# Custo de mandar tudo versus o orcamento (preco hipotetico de entrada por milhao)
tudo = sistema + mensagem + sum(t[2] for t in trechos) + sum(historico) + 40_000  # + manual inteiro
preco = 1.0
for nome, tok in (("orcamento", total), ("tudo no prompt", tudo)):
    print(f"{nome:<15} {tok:>6} tokens  US$ {tok * preco / 1e6 * 1_000_000:,.0f} por milhao de chamadas")
```

```javascript
const JANELA = 16_000;
const RESERVA_SAIDA = 1_500;
const SCORE_MIN = 0.55;

const [sistema, mensagem, resumoAntigo] = [1_200, 150, 300];
const trechos = [["politica-ferias", 0.91, 1_800], ["faq-rh", 0.84, 2_200], ["manual-ponto", 0.72, 3_000],
                 ["ata-2019", 0.58, 2_500], ["cardapio", 0.31, 900]];
const historico = [900, 1_100, 700, 1_300, 800, 600, 1_200, 1_000];   // tokens por turno, do mais antigo ao mais recente

function montar(limiteDocsPct = 0.6) {
  let livre = JANELA - RESERVA_SAIDA - sistema - mensagem - resumoAntigo;
  const tetoDocs = Math.trunc(livre * limiteDocsPct);
  let usados = 0;
  const docs = [];
  for (const [nome, score, tok] of [...trechos].sort((a, b) => b[1] - a[1])) {
    if (score >= SCORE_MIN && usados + tok <= tetoDocs) {
      docs.push(nome);
      usados += tok;
    }
  }
  livre -= usados;
  let turnos = 0, hist = 0;
  for (const tok of [...historico].reverse()) {
    if (hist + tok > livre) break;
    hist += tok;
    turnos += 1;
  }
  return [docs, usados, turnos, hist, livre - hist];
}

const [docs, tDocs, turnos, tHist, sobra] = montar();

const total = sistema + mensagem + resumoAntigo + tDocs + tHist;
console.log(`prompt: ${total} tokens, sobra ${sobra}, reserva de saida ${RESERVA_SAIDA}`);

}
```

```java
import java.util.*;

static final int JANELA = 16_000;
static final int RESERVA_SAIDA = 1_500;
static final double SCORE_MIN = 0.55;

static final int sistema = 1_200, mensagem = 150, resumoAntigo = 300;

static class Trecho {
    final String nome;
    final double score;
    final int tok;

    Trecho(String nome, double score, int tok) {
        this.nome = nome;
        this.score = score;
        this.tok = tok;
    }
}

static final List<Trecho> trechos = List.of(new Trecho("politica-ferias", 0.91, 1_800), new Trecho("faq-rh", 0.84, 2_200),
        new Trecho("manual-ponto", 0.72, 3_000), new Trecho("ata-2019", 0.58, 2_500), new Trecho("cardapio", 0.31, 900));
static final int[] historico = {900, 1_100, 700, 1_300, 800, 600, 1_200, 1_000};   // tokens por turno, do mais antigo ao mais recente

// o que montar() devolve
static class Montagem {
    List<String> docs = new ArrayList<>();
    int usados, turnos, hist, sobra;
}

static Montagem montar(double limiteDocsPct) {
    Montagem m = new Montagem();
    int livre = JANELA - RESERVA_SAIDA - sistema - mensagem - resumoAntigo;
    int tetoDocs = (int) (livre * limiteDocsPct);

    for (Trecho t : ordenados) {

            m.docs.add(t.nome);
            m.usados += t.tok;

    for (int i = historico.length - 1; i >= 0; i--) {
        int tok = historico[i];
        if (m.hist + tok > livre) break;
        m.hist += tok;
        m.turnos += 1;
    }
    m.sobra = livre - m.hist;
    return m;
}

    return montar(0.6);
}

    System.out.println("documentos: " + m.docs + " (" + m.usados + " tokens)");
```

```cpp
#include <cstdio>
#include <numeric>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

const int JANELA = 16'000;
const int RESERVA_SAIDA = 1'500;
const double SCORE_MIN = 0.55;

const int sistema = 1'200, mensagem = 150, resumoAntigo = 300;
const vector<tuple<string, double, int>> trechos = {{"politica-ferias", 0.91, 1'800}, {"faq-rh", 0.84, 2'200}, {"manual-ponto", 0.72, 3'000},
                                                    {"ata-2019", 0.58, 2'500}, {"cardapio", 0.31, 900}};
const vector<int> historico = {900, 1'100, 700, 1'300, 800, 600, 1'200, 1'000};   // tokens por turno, do mais antigo ao mais recente

tuple<vector<string>, int, int, int, int> montar(double limiteDocsPct = 0.6) {
    int livre = JANELA - RESERVA_SAIDA - sistema - mensagem - resumoAntigo;
    int tetoDocs = (int)(livre * limiteDocsPct);
    int usados = 0;
    vector<string> docs;
    auto ordenados = trechos;
    stable_sort(ordenados.begin(), ordenados.end(), [](const auto& a, const auto& b) { return get<1>(a) > get<1>(b); });
    for (auto& [nome, score, tok] : ordenados) {
        if (score >= SCORE_MIN && usados + tok <= tetoDocs) {
            docs.push_back(nome);
            usados += tok;
        }
    }
    livre -= usados;
    int turnos = 0, hist = 0;
    for (auto it = historico.rbegin(); it != historico.rend(); ++it) {
        if (hist + *it > livre) break;
        hist += *it;
        turnos += 1;
    }
    return {docs, usados, turnos, hist, livre - hist};
}

// "1250" -> "1,250", como o {:,.0f}
string milhar(double x) {
    char texto[64];
    snprintf(texto, sizeof texto, "%.0f", x);
    string s = texto;
    for (int i = (int)s.size() - 3; i > 0; i -= 3) s.insert(i, ",");
    return s;
}

int main() {
    auto [docs, tDocs, turnos, tHist, sobra] = montar();
    string lista;
    for (size_t i = 0; i < docs.size(); i++) lista += (i ? ", '" : "'") + docs[i] + "'";
    printf("documentos: [%s] (%d tokens)\n", lista.c_str(), tDocs);
    printf("historico: ultimos %d de %zu turnos (%d tokens); resto resumido\n", turnos, historico.size(), tHist);
    int total = sistema + mensagem + resumoAntigo + tDocs + tHist;
    printf("prompt: %d tokens, sobra %d, reserva de saida %d\n", total, sobra, RESERVA_SAIDA);

    // Custo de mandar tudo versus o orcamento (preco hipotetico de entrada por milhao)
    int somaTrechos = 0;
    for (auto& t : trechos) somaTrechos += get<2>(t);
    int tudo = sistema + mensagem + somaTrechos + accumulate(historico.begin(), historico.end(), 0) + 40'000;  // + manual inteiro
    double preco = 1.0;
    for (auto& [nome, tok] : vector<pair<string, int>>{{"orcamento", total}, {"tudo no prompt", tudo}}) {
        printf("%-15s %6d tokens  US$ %s por milhao de chamadas\n", nome.c_str(), tok, milhar(tok * preco / 1e6 * 1'000'000).c_str());
    }
}
```

```csharp
const int sistema = 1200, mensagem = 150, resumoAntigo = 300;

class Trecho {
    public string Nome;
    public double Score;
    public int Tok;
    public Trecho(string nome, double score, int tok) { Nome = nome; Score = score; Tok = tok; }
}

static readonly List<Trecho> trechos = new List<Trecho> {
    new Trecho("politica-ferias", 0.91, 1800), new Trecho("faq-rh", 0.84, 2200), new Trecho("manual-ponto", 0.72, 3000),

    public int Usados, Turnos, Hist, Sobra;
}

static Montagem Montar(double limiteDocsPct = 0.6) {
    var m = new Montagem();

    int tetoDocs = (int)(livre * limiteDocsPct);

        m.Hist += tok;
        m.Turnos += 1;
    }
    m.Sobra = livre - m.Hist;
    return m;
}
```

O resultado mostra a diferença: o prompt orçado fica em uma fração do "manda tudo" e custa proporcionalmente menos em cada chamada, além de ter prefill mais rápido. O teto de 60% para documentos impede que a recuperação expulse todo o histórico, e o score mínimo impede que trechos irrelevantes ocupem espaço só porque cabem.

## Técnicas de gestão

- **Janela deslizante com resumo.** Mantenha os últimos N turnos literais e um resumo cumulativo dos anteriores, atualizado de forma assíncrona depois de cada resposta, para não somar latência.
- **Memória de longo prazo.** Fatos estáveis sobre o usuário (preferências, contexto do projeto) ficam num armazenamento à parte e entram só os relevantes, recuperados como qualquer documento.
- **Recuperação em vez de inclusão.** Em vez de colar o manual inteiro, indexe-o e recupere os trechos necessários. Para perguntas que realmente exigem o documento todo (resumo de um contrato), use map-reduce: resuma partes em paralelo e combine.
- **Posição importa.** Coloque as informações mais importantes no início ou no fim do contexto, e instruções críticas perto da pergunta.
- **Cache de prefixo.** Mantenha a parte fixa do prompt sempre igual e no começo, para reaproveitar o KV cache entre chamadas.

| Abordagem | Qualidade | Custo e latência | Complexidade |
| --- | --- | --- | --- |
| Tudo no prompt | Boa em textos curtos, cai em muito longos | Altos | Baixa |
| Janela deslizante | Perde detalhes antigos | Baixos | Baixa |
| Resumo cumulativo | Preserva o essencial | Baixos, mais uma chamada assíncrona | Média |
| RAG sobre o histórico e documentos | Boa se a busca for boa | Baixos | Alta |

<Callout type="warning" title="Truncar do jeito errado quebra a conversa">
Cortar o prompt por caracteres a partir do fim pode remover a mensagem atual ou deixar um JSON pela metade. Corte por unidades lógicas (turnos, trechos) e sempre a partir das partes de menor prioridade.
</Callout>

## Na entrevista
