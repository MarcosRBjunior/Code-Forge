No começo de um produto com IA, o prompt mora numa string dentro do código. Funciona até o dia em que alguém ajusta uma frase para corrigir um caso, a qualidade cai em outros dez casos e ninguém sabe qual versão estava em produção quando o cliente reclamou. Em escala, prompts são **configuração de comportamento** do sistema: mudam com frequência, afetam a qualidade de forma difícil de prever e precisam do mesmo rigor que código. Este capítulo trata de dois problemas ligados: como montar o prompt de cada requisição (orquestração) e como mudar prompts com segurança (versionamento).

## Orquestração: montando a requisição

Um prompt real é composto de várias partes, montadas em tempo de execução:

```text
[instrucoes de sistema]      versao fixa do template
[exemplos (few-shot)]        opcionais, escolhidos por similaridade
[contexto recuperado]        trechos de documentos (RAG), resultados de ferramentas
[historico da conversa]      ultimos turnos, ou resumo dos antigos
[mensagem do usuario]        texto atual
[formato de saida]           esquema JSON, regras de citacao
```

O **orquestrador** é o serviço que executa esse fluxo: busca o template certo, chama a recuperação, decide quanto histórico cabe, chama o modelo, valida a saída e, em fluxos com ferramentas, repete o ciclo. Em produtos mais complexos, ele vira um pequeno grafo de passos (classificar intenção, buscar, gerar, verificar) com timeouts e retries por passo. Mantenha a lógica de cada passo explícita e observável; frameworks ajudam, mas o importante é que cada passo registre entradas, saídas, tokens e latência.

## Versionamento: o registro de prompts

Tire os prompts do código e coloque-os num **registro de prompts**: um repositório (pode ser o próprio Git, com um serviço que publica versões) em que cada prompt tem nome, versão imutável, modelo-alvo, parâmetros (temperatura, máximo de tokens) e o esquema de saída esperado.

```json
{
  "nome": "resumo-chamado",
  "versao": 7,
  "modelo": "medio",
  "temperatura": 0.2,
  "max_tokens": 400,
  "template": "Resuma o chamado abaixo em até 5 tópicos...",
  "avaliacao": {"conjunto": "chamados-v3", "nota_minima": 0.85}
}
```

O fluxo de mudança fica parecido com o de código:

1. Alguém cria a versão 8 e roda o **conjunto de avaliação** offline: centenas de entradas representativas com critérios de qualidade.
2. Se passar do limiar e não piorar casos críticos, a versão 8 entra em **canário** para uma fração dos usuários.
3. Métricas online (feedback, taxa de reformulação, erros de formato, custo por resposta) comparam 7 e 8.
4. Se tudo estiver bem, a porcentagem sobe até 100%. Se não, o rollback é trocar um ponteiro, sem deploy.

Cada resposta gravada no log carrega nome e versão do prompt, modelo e parâmetros. Sem isso, você não consegue reproduzir nem investigar uma reclamação.

## Canário determinístico

A atribuição de versão deve ser **estável por usuário**: alguém que caiu na versão nova continua nela, para não ver comportamentos alternados na mesma conversa. Um hash do ID do usuário resolve.

```python
import hashlib

REGISTRO = {
    "resumo-chamado": {
        7: "Resuma o chamado em ate 5 topicos.\nChamado: $texto",
        8: "Voce e um analista de suporte. Resuma em ate 5 topicos objetivos.\nChamado: $texto",
    }
}
ROLLOUT = {"resumo-chamado": {"estavel": 7, "canario": 8, "pct_canario": 10}}

def balde(usuario, nome):
    h = hashlib.sha256(f"{nome}:{usuario}".encode()).hexdigest()
    return int(h[:8], 16) % 100

def versao_para(usuario, nome):
    cfg = ROLLOUT[nome]
    return cfg["canario"] if balde(usuario, nome) < cfg["pct_canario"] else cfg["estavel"]

def montar(usuario, nome, texto):
    from string import Template
    v = versao_para(usuario, nome)
    return v, Template(REGISTRO[nome][v]).substitute(texto=texto)

contagem = {7: 0, 8: 0}
for i in range(10_000):
    contagem[versao_para(f"u{i}", "resumo-chamado")] += 1
print("distribuicao:", {v: f"{n / 100:.1f}%" for v, n in contagem.items()})
print("estavel por usuario:", versao_para("u42", "resumo-chamado") == versao_para("u42", "resumo-chamado"))

v, prompt = montar("u7", "resumo-chamado", "impressora nao imprime desde ontem")
print(f"u7 recebe v{v}:")
print(prompt)

import java.security.MessageDigest;
import java.util.*;

static class Rollout {
    int estavel, canario, pctCanario;
    Rollout(int estavel, int canario, int pctCanario) { this.estavel = estavel; this.canario = canario; this.pctCanario = pctCanario; }
}

static final Map<String, Map<Integer, String>> REGISTRO = Map.of(
    "resumo-chamado", Map.of(
        7, "Resuma o chamado em ate 5 topicos.\nChamado: $texto",
        8, "Voce e um analista de suporte. Resuma em ate 5 topicos objetivos.\nChamado: $texto"));
static final Map<String, Rollout> ROLLOUT = Map.of("resumo-chamado", new Rollout(7, 8, 10));

static int balde(String usuario, String nome) throws Exception {
    byte[] resumo = MessageDigest.getInstance("SHA-256").digest((nome + ":" + usuario).getBytes(StandardCharsets.UTF_8));
    // os 8 primeiros dígitos hex são os 4 primeiros bytes; long porque podem passar de Integer.MAX_VALUE
    long h8 = 0;
    for (int i = 0; i < 4; i++) h8 = (h8 << 8) | (resumo[i] & 0xff);
    return (int) (h8 % 100);
}

static int versaoPara(String usuario, String nome) throws Exception {
    Rollout cfg = ROLLOUT.get(nome);
    return balde(usuario, nome) < cfg.pctCanario ? cfg.canario : cfg.estavel;
}

// imita o string.Template(...).substitute(...) do Python: troca cada $nome pelo valor
static String substituir(String modelo, Map<String, String> valores) {
    Matcher m = Pattern.compile("\\$(\\w+)").matcher(modelo);
    StringBuffer sb = new StringBuffer();
    while (m.find()) {
        String valor = valores.get(m.group(1));
        if (valor == null) throw new NoSuchElementException("KeyError: " + m.group(1));
        m.appendReplacement(sb, Matcher.quoteReplacement(valor));
    }
    m.appendTail(sb);
    return sb.toString();
}

static Object[] montar(String usuario, String nome, String texto) throws Exception {
    int v = versaoPara(usuario, nome);
    return new Object[]{v, substituir(REGISTRO.get(nome).get(v), Map.of("texto", texto))};
}

public static void main(String[] args) throws Exception {
    LinkedHashMap<Integer, Integer> contagem = new LinkedHashMap<>();
    contagem.put(7, 0);
    contagem.put(8, 0);
    for (int i = 0; i < 10_000; i++) {
        contagem.merge(versaoPara("u" + i, "resumo-chamado"), 1, Integer::sum);
    }
    StringJoiner partes = new StringJoiner(", ", "{", "}");
    for (Map.Entry<Integer, Integer> e : contagem.entrySet()) {
        partes.add(String.format(Locale.US, "%d: '%.1f%%'", e.getKey(), e.getValue() / 100.0));
    }
    System.out.println("distribuicao: " + partes);
    System.out.println("estavel por usuario: " + (versaoPara("u42", "resumo-chamado") == versaoPara("u42", "resumo-chamado")));

    Object[] r = montar("u7", "resumo-chamado", "impressora nao imprime desde ontem");
    System.out.println("u7 recebe v" + r[0] + ":");
    System.out.println(r[1]);
}

string sha256(const string& msg) {
    static const uint32_t K[64] = {
        0x428a2f98, 0x71374491, 0xb5c0fbcf, 0xe9b5dba5, 0x3956c25b, 0x59f111f1, 0x923f82a4, 0xab1c5ed5,

        0x19a4c116, 0x1e376c08, 0x2748774c, 0x34b0bcb5, 0x391c0cb3, 0x4ed8aa4a, 0x5b9cca4f, 0x682e6ff3,
        0x748f82ee, 0x78a5636f, 0x84c87814, 0x8cc70208, 0x90befffa, 0xa4506ceb, 0xbef9a3f7, 0xc67178f2};
    uint32_t h[8] = {0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a, 0x510e527f, 0x9b05688c, 0x1f83d9ab, 0x5be0cd19};
    string m = msg;
    uint64_t bits = (uint64_t)msg.size() * 8;
    m += (char)0x80;
    while (m.size() % 64 != 56) m += (char)0;
    for (int i = 7; i >= 0; i--) m += (char)(bits >> (i * 8));
    auto rotr = [](uint32_t x, int n) { return (x >> n) | (x << (32 - n)); };
    for (size_t off = 0; off < m.size(); off += 64) {
        uint32_t w[64];
        for (int i = 0; i < 16; i++) {
            w[i] = ((uint32_t)(uint8_t)m[off + 4 * i] << 24) | ((uint32_t)(uint8_t)m[off + 4 * i + 1] << 16) |
                   ((uint32_t)(uint8_t)m[off + 4 * i + 2] << 8) | (uint32_t)(uint8_t)m[off + 4 * i + 3];
        }
        for (int i = 16; i < 64; i++) {
            uint32_t s0 = rotr(w[i - 15], 7) ^ rotr(w[i - 15], 18) ^ (w[i - 15] >> 3);
            uint32_t s1 = rotr(w[i - 2], 17) ^ rotr(w[i - 2], 19) ^ (w[i - 2] >> 10);
            w[i] = w[i - 16] + s0 + w[i - 7] + s1;
        }
        uint32_t a = h[0], b = h[1], c = h[2], d = h[3], e = h[4], f = h[5], g = h[6], hh = h[7];
        for (int i = 0; i < 64; i++) {
            uint32_t t1 = hh + (rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25)) + ((e & f) ^ (~e & g)) + K[i] + w[i];
            uint32_t t2 = (rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22)) + ((a & b) ^ (a & c) ^ (b & c));
            hh = g; g = f; f = e; e = d + t1; d = c; c = b; b = a; a = t1 + t2;
        }
        h[0] += a; h[1] += b; h[2] += c; h[3] += d; h[4] += e; h[5] += f; h[6] += g; h[7] += hh;
    }
    string out;
    for (int i = 0; i < 8; i++) for (int j = 3; j >= 0; j--) out += (char)(h[i] >> (j * 8));
    return out;
}

string hexdigest(const string& bytes) {
    static const char* d = "0123456789abcdef";
    string r;
    for (unsigned char c : bytes) { r += d[c >> 4]; r += d[c & 15]; }
    return r;
}

// imita o string.Template(...).substitute(...) do Python: troca cada $nome pelo valor
string substituir(const string& modelo, const map<string, string>& valores) {
    string r;
    size_t i = 0;
    while (i < modelo.size()) {
        if (modelo[i] == '$') {
            size_t j = i + 1;
            while (j < modelo.size() && (isalnum((unsigned char)modelo[j]) || modelo[j] == '_')) j++;
            string nome = modelo.substr(i + 1, j - i - 1);
            auto it = valores.find(nome);
            if (it == valores.end()) throw out_of_range("KeyError: " + nome);
            r += it->second;
            i = j;
        } else {
            r += modelo[i++];
        }
    }
    return r;
}

using System.Collections.Generic;
using System.Globalization;
using System.Linq;
using System.Security.Cryptography;
using System.Text;
using System.Text.RegularExpressions;

class Rollout
{
    public int Estavel, Canario, PctCanario;
    public Rollout(int estavel, int canario, int pctCanario) { Estavel = estavel; Canario = canario; PctCanario = pctCanario; }
}

static readonly Dictionary<string, Dictionary<int, string>> REGISTRO = new Dictionary<string, Dictionary<int, string>>
{
    { "resumo-chamado", new Dictionary<int, string>
        {
            { 7, "Resuma o chamado em ate 5 topicos.\nChamado: $texto" },
            { 8, "Voce e um analista de suporte. Resuma em ate 5 topicos objetivos.\nChamado: $texto" },
        }
    },
};
static readonly Dictionary<string, Rollout> ROLLOUT = new Dictionary<string, Rollout> { { "resumo-chamado", new Rollout(7, 8, 10) } };

static int Balde(string usuario, string nome)
{
    using (var sha = SHA256.Create())
    {
        byte[] resumo = sha.ComputeHash(Encoding.UTF8.GetBytes($"{nome}:{usuario}"));
        string h = string.Concat(resumo.Select(b => b.ToString("x2")));
        return (int)(Convert.ToUInt32(h.Substring(0, 8), 16) % 100);
    }
}

static int VersaoPara(string usuario, string nome)
{
    var cfg = ROLLOUT[nome];
    return Balde(usuario, nome) < cfg.PctCanario ? cfg.Canario : cfg.Estavel;
}

static string Substituir(string modelo, Dictionary<string, string> valores)
{
    return Regex.Replace(modelo, @"\$(\w+)", m =>
    {
        if (!valores.ContainsKey(m.Groups[1].Value)) throw new KeyNotFoundException("KeyError: " + m.Groups[1].Value);
        return valores[m.Groups[1].Value];
    });
}

static string Montar(string usuario, string nome, string texto, out int v)
{
    v = VersaoPara(usuario, nome);
    return Substituir(REGISTRO[nome][v], new Dictionary<string, string> { { "texto", texto } });
}

{

}

var marcador = regexp.MustCompile(`\$(\w+)`)

// imita o string.Template(...).substitute(...) do Python: troca cada $nome pelo valor
func substituir(modelo string, valores map[string]string) string {
	return marcador.ReplaceAllStringFunc(modelo, func(m string) string {
		valor, ok := valores[m[1:]]
		if !ok {
			panic("KeyError: " + m[1:])
		}
		return valor
	})
}

func montar(usuario, nome, texto string) (int, string) {
	v := versaoPara(usuario, nome)
	return v, substituir(REGISTRO[nome][v], map[string]string{"texto": texto})
}

func main() {
	versoes := []int{7, 8} // ordem de impressão, como o dict do Python
	contagem := map[int]int{7: 0, 8: 0}
	for i := 0; i < 10_000; i++ {
		contagem[versaoPara(fmt.Sprintf("u%d", i), "resumo-chamado")] += 1
	}
	partes := []string{}
	for _, v := range versoes {
		partes = append(partes, fmt.Sprintf("%d: '%.1f%%'", v, float64(contagem[v])/100))
	}
	fmt.Println("distribuicao:", "{"+strings.Join(partes, ", ")+"}")
	fmt.Println("estavel por usuario:", versaoPara("u42", "resumo-chamado") == versaoPara("u42", "resumo-chamado"))

	v, prompt := montar("u7", "resumo-chamado", "impressora nao imprime desde ontem")
	fmt.Printf("u7 recebe v%d:\n", v)
	fmt.Println(prompt)
}
```

Note que o nome do prompt entra no hash. Assim, os usuários que estão no canário de um prompt não são sempre os mesmos do canário de outro, o que evita que uma pequena parcela da base absorva todo o risco.

## Trade-offs e armadilhas

- **Prompt acoplado ao modelo.** Um prompt otimizado para um modelo pode piorar em outro. Versione o par prompt e modelo, e reavalie ao trocar qualquer um.
- **Mudança silenciosa do provedor.** Se o provedor atualiza o modelo por trás do mesmo nome, sua avaliação de ontem não vale. Fixe versões de modelo quando possível e rode a avaliação periodicamente.
- **Interpolação perigosa.** Texto do usuário e de documentos entra no prompt; delimite claramente essas partes e nunca as trate como instruções confiáveis.
- **Excesso de abstração.** Grafos de orquestração muito genéricos escondem o que acontece. Prefira passos explícitos e logs completos.

<Callout type="tip" title="Prompt é código, avaliação é teste">
Uma frase que funciona bem na entrevista: "trato prompts como código, com revisão, versão imutável, testes de regressão no conjunto de avaliação e liberação gradual com rollback instantâneo".
</Callout>

## Na entrevista

Mostre o orquestrador como um serviço próprio entre a aplicação e o gateway de modelos, e o registro de prompts como fonte de verdade. Mencione que cada resposta registra a versão do prompt e o modelo. Follow-ups comuns: "como você testa uma mudança de prompt?"
