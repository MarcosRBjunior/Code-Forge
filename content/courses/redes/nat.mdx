Sua casa tem dezenas de dispositivos e um único IPv4 público. Uma VPC tem centenas de instâncias em sub-redes privadas que precisam baixar pacotes da internet. Em ambos os casos alguém reescreve endereços no caminho: o **NAT** (Network Address Translation). Ele foi o remendo que adiou o fim do IPv4 por décadas, e entendê-lo explica por que conexões de entrada "não chegam", por que conexões ociosas morrem misteriosamente e por que um NAT gateway pode virar gargalo de portas.

## Como funciona

A forma mais comum é o NAT com tradução de portas (PAT, ou NAPT, ou "masquerade" no Linux). Quando um pacote sai da rede privada, o roteador troca o IP e a porta de origem pelos seus, e anota a troca numa tabela. Quando a resposta volta, ele consulta a tabela e desfaz a troca.

```text
 Rede privada                    Roteador NAT                    Internet
 10.0.0.5:51000 ----------> [ 203.0.113.7:40001 ] ----------> 93.184.216.34:443
                            tabela:
                            40001 <-> 10.0.0.5:51000, destino 93.184.216.34:443

 10.0.0.5:51000 <---------- [ desfaz a troca ]   <---------- 93.184.216.34:443
                                                           (para 203.0.113.7:40001)
```

Cada entrada identifica um fluxo pela tupla (protocolo, IP e porta internos, IP e porta externos). Como o roteador muda os endereços, ele também precisa recalcular os checksums do IP e do TCP/UDP.

## Simulando a tabela

A simulação abaixo mostra alocação de portas, tradução da resposta, descarte de pacote não solicitado e expiração por inatividade.

```python
class Nat:
    def __init__(self, ip_publico, porta_inicial, timeout):
        self.ip, self.prox, self.timeout = ip_publico, porta_inicial, timeout
        self.saida = {}    # (ip_int, porta_int, destino) -> porta_pub
        self.entrada = {}  # porta_pub -> [ip_int, porta_int, destino, ultimo_uso]

    def sair(self, ip, porta, destino, agora):
        chave = (ip, porta, destino)
        if chave not in self.saida:
            self.saida[chave] = self.prox
            self.entrada[self.prox] = [ip, porta, destino, agora]
            self.prox += 1
        p = self.saida[chave]
        self.entrada[p][3] = agora
        return f"t={agora:3} saida {ip}:{porta} -> {self.ip}:{p} para {destino}"

    def chegar(self, porta_pub, origem, agora):
        e = self.entrada.get(porta_pub)
        if e is None or e[2] != origem:
            return f"t={agora:3} entrada em :{porta_pub} de {origem}: DESCARTADO (sem entrada)"
        if agora - e[3] > self.timeout:
            del self.entrada[porta_pub]
            del self.saida[(e[0], e[1], e[2])]
            return f"t={agora:3} entrada em :{porta_pub} de {origem}: DESCARTADO (expirou)"
        e[3] = agora
        return f"t={agora:3} entrada em :{porta_pub} -> {e[0]}:{e[1]}"

nat = Nat("203.0.113.7", 40000, timeout=300)
web = "93.184.216.34:443"
print(nat.sair("10.0.0.5", 51000, web, 0))
print(nat.sair("10.0.0.6", 51000, web, 1))
print(nat.chegar(40000, web, 2))
print(nat.chegar(40001, web, 3))
print(nat.chegar(40000, "198.51.100.9:22", 4))
print(nat.chegar(40001, web, 400))
```

```javascript
class Nat {
  constructor(ipPublico, portaInicial, timeout) {
    this.ip = ipPublico;
    this.prox = portaInicial;
    this.timeout = timeout;
    this.saida = new Map();   // "ip_int|porta_int|destino" -> porta_pub
    this.entrada = new Map(); // porta_pub -> [ip_int, porta_int, destino, ultimo_uso]
  }

  sair(ip, porta, destino, agora) {
    const chave = `${ip}|${porta}|${destino}`;
    if (!this.saida.has(chave)) {
      this.saida.set(chave, this.prox);
      this.entrada.set(this.prox, [ip, porta, destino, agora]);
      this.prox += 1;
    }
    const p = this.saida.get(chave);
    this.entrada.get(p)[3] = agora;
    return `t=${String(agora).padStart(3)} saida ${ip}:${porta} -> ${this.ip}:${p} para ${destino}`;
  }

  chegar(portaPub, origem, agora) {
    const t = String(agora).padStart(3);
    const e = this.entrada.get(portaPub);
    if (e === undefined || e[2] !== origem) {
      return `t=${t} entrada em :${portaPub} de ${origem}: DESCARTADO (sem entrada)`;
    }
    if (agora - e[3] > this.timeout) {
      this.entrada.delete(portaPub);
      this.saida.delete(`${e[0]}|${e[1]}|${e[2]}`);
      return `t=${t} entrada em :${portaPub} de ${origem}: DESCARTADO (expirou)`;
    }
    e[3] = agora;
    return `t=${t} entrada em :${portaPub} -> ${e[0]}:${e[1]}`;
  }
}
```

```java
import java.util.*;

static class Entrada {
    String ip;
    int porta;
    String destino;
    int ultimoUso;

    Entrada(String ip, int porta, String destino, int ultimoUso) {
        this.ip = ip;
        this.porta = porta;
        this.destino = destino;
        this.ultimoUso = ultimoUso;
    }
}

static class Nat {
    String ip;
    int prox, timeout;
    Map<String, Integer> saida = new HashMap<>();    // "ip_int|porta_int|destino" -> porta_pub
    Map<Integer, Entrada> entrada = new HashMap<>(); // porta_pub -> entrada

    Nat(String ipPublico, int portaInicial, int timeout) {
        this.ip = ipPublico;
        this.prox = portaInicial;
        this.timeout = timeout;
    }

    String sair(String ip, int porta, String destino, int agora) {
        String chave = ip + "|" + porta + "|" + destino;
        if (!saida.containsKey(chave)) {
            saida.put(chave, prox);
            entrada.put(prox, new Entrada(ip, porta, destino, agora));
            prox += 1;
        }
        int p = saida.get(chave);
        entrada.get(p).ultimoUso = agora;
        return String.format("t=%3d saida %s:%d -> %s:%d para %s", agora, ip, porta, this.ip, p, destino);
    }

    String chegar(int portaPub, String origem, int agora) {
        Entrada e = entrada.get(portaPub);
        if (e == null || !e.destino.equals(origem)) {
            return String.format("t=%3d entrada em :%d de %s: DESCARTADO (sem entrada)", agora, portaPub, origem);
        }
        if (agora - e.ultimoUso > timeout) {
            entrada.remove(portaPub);
            saida.remove(e.ip + "|" + e.porta + "|" + e.destino);
            return String.format("t=%3d entrada em :%d de %s: DESCARTADO (expirou)", agora, portaPub, origem);
        }
        e.ultimoUso = agora;
        return String.format("t=%3d entrada em :%d -> %s:%d", agora, portaPub, e.ip, e.porta);
    }
}
```

```cpp
#include <format>
#include <iostream>
#include <map>
#include <string>
#include <tuple>
using namespace std;

struct Entrada {
    string ip;
    int porta;
    string destino;
    int ultimoUso;
};

class Nat {
    string ip;
    int prox, timeout;
    map<tuple<string, int, string>, int> saida;  // (ip_int, porta_int, destino) -> porta_pub
    map<int, Entrada> entrada;                   // porta_pub -> entrada

public:
    Nat(string ipPublico, int portaInicial, int timeout)
        : ip(ipPublico), prox(portaInicial), timeout(timeout) {}

    string sair(const string& ipInt, int porta, const string& destino, int agora) {
        auto chave = make_tuple(ipInt, porta, destino);
        if (!saida.count(chave)) {
            saida[chave] = prox;
            entrada[prox] = {ipInt, porta, destino, agora};
            prox += 1;
        }
        int p = saida[chave];
        entrada[p].ultimoUso = agora;
        return format("t={:3} saida {}:{} -> {}:{} para {}", agora, ipInt, porta, ip, p, destino);
    }

    string chegar(int portaPub, const string& origem, int agora) {
        auto it = entrada.find(portaPub);
        if (it == entrada.end() || it->second.destino != origem) {
            return format("t={:3} entrada em :{} de {}: DESCARTADO (sem entrada)", agora, portaPub, origem);
        }
        Entrada& e = it->second;
        if (agora - e.ultimoUso > timeout) {
            saida.erase(make_tuple(e.ip, e.porta, e.destino));
            entrada.erase(it);
            return format("t={:3} entrada em :{} de {}: DESCARTADO (expirou)", agora, portaPub, origem);
        }
        e.ultimoUso = agora;
        return format("t={:3} entrada em :{} -> {}:{}", agora, portaPub, e.ip, e.porta);
    }
};
```

```go
import "fmt"

type chaveSaida struct {
	ip      string
	porta   int
	destino string
}

type entrada struct {
	ip        string
	porta     int
	destino   string
	ultimoUso int
}

type Nat struct {
	ip            string
	prox, timeout int
	saida         map[chaveSaida]int // (ip_int, porta_int, destino) -> porta_pub
	entrada       map[int]*entrada   // porta_pub -> entrada
}

func novoNat(ipPublico string, portaInicial, timeout int) *Nat {
	return &Nat{ipPublico, portaInicial, timeout, map[chaveSaida]int{}, map[int]*entrada{}}
}

func (n *Nat) sair(ip string, porta int, destino string, agora int) string {
	chave := chaveSaida{ip, porta, destino}
	if _, ok := n.saida[chave]; !ok {
		n.saida[chave] = n.prox
		n.entrada[n.prox] = &entrada{ip, porta, destino, agora}
		n.prox++
	}
	p := n.saida[chave]
	n.entrada[p].ultimoUso = agora
	return fmt.Sprintf("t=%3d saida %s:%d -> %s:%d para %s", agora, ip, porta, n.ip, p, destino)
}

func (n *Nat) chegar(portaPub int, origem string, agora int) string {
	e, ok := n.entrada[portaPub]
	if !ok || e.destino != origem {
		return fmt.Sprintf("t=%3d entrada em :%d de %s: DESCARTADO (sem entrada)", agora, portaPub, origem)
	}
	if agora-e.ultimoUso > n.timeout {
		delete(n.entrada, portaPub)
		delete(n.saida, chaveSaida{e.ip, e.porta, e.destino})
		return fmt.Sprintf("t=%3d entrada em :%d de %s: DESCARTADO (expirou)", agora, portaPub, origem)
	}
	e.ultimoUso = agora
	return fmt.Sprintf("t=%3d entrada em :%d -> %s:%d", agora, portaPub, e.ip, e.porta)
}

func main() {
	nat := novoNat("203.0.113.7", 40000, 300)
	web := "93.184.216.34:443"
	fmt.Println(nat.sair("10.0.0.5", 51000, web, 0))
	fmt.Println(nat.sair("10.0.0.6", 51000, web, 1))
	fmt.Println(nat.chegar(40000, web, 2))
	fmt.Println(nat.chegar(40001, web, 3))
	fmt.Println(nat.chegar(40000, "198.51.100.9:22", 4))
	fmt.Println(nat.chegar(40001, web, 400))
}
```

## Limites de portas

Para um único destino (mesmo IP e porta), um IP público tem cerca de 64 mil portas de origem. Um NAT gateway que concentra milhares de conexões curtas para a mesma API pode esgotá-las, e o sintoma são erros de conexão intermitentes. Conexões em `TIME_WAIT` seguram a porta por mais tempo do que você imagina.

## Tipos e consequências

| Tipo | O que faz | Onde aparece |
| --- | --- | --- |
| SNAT / masquerade | Troca a origem na saída | Casa, NAT gateway de nuvem |
| DNAT / port forwarding | Troca o destino na entrada | Expor um serviço interno, load balancers L4 |
| NAT 1:1 | Um IP público fixo para um privado | IP elástico associado a instância |
| CGNAT | NAT do provedor em cima do seu NAT | Operadoras móveis e de banda larga |

Consequências que causam bugs reais:

- **Conexões de entrada não chegam** sem DNAT explícito. Aplicações P2P (chamadas de vídeo, jogos) usam STUN para descobrir o endereço público e "furar" o NAT, e TURN como relay quando isso falha.
- **Timeout de inatividade:** uma conexão TCP parada por alguns minutos perde a entrada; o próximo pacote é descartado e o cliente só percebe com um timeout longo. Keepalives curtos resolvem.
- **IP de origem compartilhado:** rate limiting por IP pune todos os usuários atrás do mesmo CGNAT.
- **Logs:** o servidor vê o IP do NAT, não o do cliente. Atrás de proxies HTTP, use `X-Forwarded-For`; em L4, o protocolo PROXY.

<Callout type="tip" title="NAT não é firewall">
O descarte de pacotes não solicitados parece proteção, mas é efeito colateral. Use regras de firewall explícitas; em IPv6, onde não há NAT, elas são obrigatórias.
</Callout>
