Cada camada precisa de informação própria para fazer o seu trabalho: o transporte quer portas, a rede quer endereços IP, o enlace quer endereços MAC. Em vez de misturar tudo num formato único, cada camada pega o que veio de cima, trata como uma caixa fechada (o **payload**) e cola o seu próprio **cabeçalho** na frente. Isso é encapsulamento. Na chegada, o processo inverso, o desencapsulamento, remove um cabeçalho por camada até sobrar a mensagem original.

## A boneca russa

```text
Aplicação                          [ GET / HTTP/1.1 ... ]
Transporte              [ TCP 20B ][ dados da aplicação ]          = segmento
Rede          [ IPv4 20B ][ TCP 20B ][ dados ]                     = pacote
Enlace [ Eth 14B ][ IPv4 ][ TCP ][ dados ][ FCS 4B ]               = quadro
Física  preâmbulo 8B + quadro + intervalo entre quadros 12B        = bits
```

Repare em três consequências:

1. **Cada salto troca o envelope de enlace.** Um roteador remove o cabeçalho Ethernet, decide a rota olhando o IP, decrementa o TTL e coloca um cabeçalho Ethernet novo com o MAC do próximo salto. O IP de destino continua o mesmo de ponta a ponta (fora NAT).
2. **Cabeçalhos custam banda.** Em mensagens pequenas, o overhead domina.
3. **O tamanho máximo vem de baixo.** O payload Ethernet padrão é de 1.500 bytes (a **MTU**). Tirando 20 de IP e 20 de TCP, sobram 1.460 bytes de dados por segmento: o **MSS** que o TCP anuncia no handshake.

## Montando um quadro byte a byte

O programa abaixo encapsula uma mensagem em UDP, IPv4 e Ethernet usando `struct`, calcula o checksum do cabeçalho IP e depois faz o caminho inverso, como faria a pilha do receptor.

```python
import struct, ipaddress

def checksum(dados: bytes) -> int:
    if len(dados) % 2:
        dados += b"\x00"
    soma = sum(struct.unpack(f"!{len(dados)//2}H", dados))
    while soma >> 16:
        soma = (soma & 0xFFFF) + (soma >> 16)
    return ~soma & 0xFFFF

payload = b"ola, camada 7"
udp = struct.pack("!HHHH", 50000, 9999, 8 + len(payload), 0) + payload

src = ipaddress.IPv4Address("192.168.0.10").packed
dst = ipaddress.IPv4Address("192.168.0.20").packed
total = 20 + len(udp)
cab_ip = struct.pack("!BBHHHBBH4s4s", 0x45, 0, total, 1, 0, 64, 17, 0, src, dst)
cab_ip = cab_ip[:10] + struct.pack("!H", checksum(cab_ip)) + cab_ip[12:]
pacote = cab_ip + udp

mac_dst = bytes.fromhex("aabbccddeeff")
mac_src = bytes.fromhex("112233445566")
quadro = mac_dst + mac_src + struct.pack("!H", 0x0800) + pacote

print("tamanho do quadro:", len(quadro), "bytes, sendo", len(payload), "de dados")
print("cabecalho IP:", cab_ip.hex(" "))

# desencapsulamento
ethertype = struct.unpack("!H", quadro[12:14])[0]
ip = quadro[14:]
ver_ihl, _, tot, _, _, ttl, proto, csum, s, d = struct.unpack("!BBHHHBBH4s4s", ip[:20])
print(f"EtherType 0x{ethertype:04x} -> IPv{ver_ihl >> 4}, TTL {ttl}, protocolo {proto}")
print("checksum confere:", checksum(ip[:20]) == 0)
sport, dport, ulen, _ = struct.unpack("!HHHH", ip[20:28])
print(f"{ipaddress.IPv4Address(s)}:{sport} -> {ipaddress.IPv4Address(d)}:{dport}")
print("dados:", ip[28:28 + ulen - 8].decode())
```

```java
import java.nio.ByteBuffer;
import java.nio.charset.StandardCharsets;

static int checksum(byte[] dados, int de, int ate) {
    int soma = 0;
    for (int i = de; i < ate; i += 2) {
        int baixo = i + 1 < ate ? dados[i + 1] & 0xFF : 0; // byte ímpar: completa com zero
        soma += ((dados[i] & 0xFF) << 8) | baixo;
    }
    while ((soma >> 16) != 0) soma = (soma & 0xFFFF) + (soma >> 16);
    return ~soma & 0xFFFF;
}

// IP em texto -> 4 bytes (como IPv4Address(...).packed)
static byte[] ipBytes(String ip) {
    String[] p = ip.split("\\.");
    byte[] b = new byte[4];
    for (int i = 0; i < 4; i++) b[i] = (byte) Integer.parseInt(p[i]);
    return b;
}

static String hex(byte[] b, int de, int ate) {
    StringBuilder sb = new StringBuilder();
    for (int i = de; i < ate; i++) sb.append(i > de ? " " : "").append(String.format("%02x", b[i] & 0xFF));
    return sb.toString();
}

static String ipTexto(byte[] b, int de) {
    return (b[de] & 0xFF) + "." + (b[de + 1] & 0xFF) + "." + (b[de + 2] & 0xFF) + "." + (b[de + 3] & 0xFF);
}

public static void main(String[] args) {
    byte[] payload = "ola, camada 7".getBytes(StandardCharsets.UTF_8);
    int total = 20 + 8 + payload.length;
    ByteBuffer quadro = ByteBuffer.allocate(14 + total); // big-endian (ordem de rede)

    // Ethernet
    quadro.put(new byte[] {(byte) 0xAA, (byte) 0xBB, (byte) 0xCC, (byte) 0xDD, (byte) 0xEE, (byte) 0xFF});
    quadro.put(new byte[] {0x11, 0x22, 0x33, 0x44, 0x55, 0x66});
    quadro.putShort((short) 0x0800);
    // IP (checksum em zero por enquanto)
    quadro.put((byte) 0x45).put((byte) 0).putShort((short) total).putShort((short) 1).putShort((short) 0);
    quadro.put((byte) 64).put((byte) 17).putShort((short) 0);
    quadro.put(ipBytes("192.168.0.10")).put(ipBytes("192.168.0.20"));
    // UDP
    quadro.putShort((short) 50000).putShort((short) 9999).putShort((short) (8 + payload.length)).putShort((short) 0);
    quadro.put(payload);
    byte[] q = quadro.array();
    quadro.putShort(14 + 10, (short) checksum(q, 14, 34));

    System.out.println("tamanho do quadro: " + q.length + " bytes, sendo " + payload.length + " de dados");
    System.out.println("cabecalho IP: " + hex(q, 14, 34));

    // desencapsulamento
    ByteBuffer leitor = ByteBuffer.wrap(q);
    int ethertype = leitor.getShort(12) & 0xFFFF;
    int ip = 14; // o pacote IP começa aqui
    int verIhl = q[ip] & 0xFF, ttl = q[ip + 8] & 0xFF, proto = q[ip + 9] & 0xFF;
    System.out.printf("EtherType 0x%04x -> IPv%d, TTL %d, protocolo %d%n", ethertype, verIhl >> 4, ttl, proto);
    System.out.println("checksum confere: " + (checksum(q, ip, ip + 20) == 0));
    int sport = leitor.getShort(ip + 20) & 0xFFFF, dport = leitor.getShort(ip + 22) & 0xFFFF, ulen = leitor.getShort(ip + 24) & 0xFFFF;
    System.out.println(ipTexto(q, ip + 12) + ":" + sport + " -> " + ipTexto(q, ip + 16) + ":" + dport);
    System.out.println("dados: " + new String(q, ip + 28, ulen - 8, StandardCharsets.UTF_8));
}
```

```cpp
using Bytes = vector<uint8_t>;

uint16_t checksum(const uint8_t* dados, size_t n) {
    uint32_t soma = 0;
    for (size_t i = 0; i < n; i += 2) {
        soma += (dados[i] << 8) | (i + 1 < n ? dados[i + 1] : 0);  // byte ímpar: completa com zero
    }
    while (soma >> 16) soma = (soma & 0xFFFF) + (soma >> 16);
    return ~soma & 0xFFFF;
}

// grava 16 bits em big-endian (ordem de rede)
void put16(Bytes& v, uint16_t x) {
    v.push_back(x >> 8);
    v.push_back(x & 0xFF);
}
uint16_t get16(const uint8_t* p) { return (p[0] << 8) | p[1]; }

string hex(const uint8_t* b, size_t n) {
    string s;
    char buf[4];
    for (size_t i = 0; i < n; i++) {
        snprintf(buf, sizeof buf, i ? " %02x" : "%02x", b[i]);
        s += buf;
    }
    return s;
}

    return to_string(b[0]) + "." + to_string(b[1]) + "." + to_string(b[2]) + "." + to_string(b[3]);
}

    string payload = "ola, camada 7";

    for (uint16_t campo : {50000, 9999, (int)(8 + payload.size()), 0}) put16(udp, campo);
```

```go
import (
	"encoding/binary"
	"encoding/hex"
	"fmt"
	"net"
)

func checksum(dados []byte) uint16 {
	if len(dados)%2 == 1 {
		dados = append(dados, 0) // byte ímpar: completa com zero
	}
	var soma uint32
	for i := 0; i < len(dados); i += 2 {
		soma += uint32(binary.BigEndian.Uint16(dados[i:]))
	}
	for soma>>16 != 0 {
		soma = soma&0xFFFF + soma>>16
	}
	return uint16(^soma & 0xFFFF)
}

// struct.pack("!H...") em big-endian
func u16(xs ...uint16) []byte {
	b := make([]byte, 2*len(xs))
	for i, x := range xs {
		binary.BigEndian.PutUint16(b[2*i:], x)
	}
	return b
}

func main() {
	payload := []byte("ola, camada 7")
	udp := append(u16(50000, 9999, uint16(8+len(payload)), 0), payload...)

	src := net.ParseIP("192.168.0.10").To4() // como IPv4Address(...).packed
	dst := net.ParseIP("192.168.0.20").To4()
	total := 20 + len(udp)
	cabIp := []byte{0x45, 0}
	cabIp = append(cabIp, u16(uint16(total), 1, 0)...)
	cabIp = append(cabIp, 64, 17)
	cabIp = append(cabIp, u16(0)...)
	cabIp = append(cabIp, src...)
	cabIp = append(cabIp, dst...)
	binary.BigEndian.PutUint16(cabIp[10:], checksum(cabIp))
	pacote := append(append([]byte{}, cabIp...), udp...)

	macDst, _ := hex.DecodeString("aabbccddeeff")
	macSrc, _ := hex.DecodeString("112233445566")
	quadro := append(append(macDst, macSrc...), u16(0x0800)...)
	quadro = append(quadro, pacote...)

	fmt.Println("tamanho do quadro:", len(quadro), "bytes, sendo", len(payload), "de dados")
	fmt.Printf("cabecalho IP: % x\n", cabIp)

	// desencapsulamento
	ethertype := binary.BigEndian.Uint16(quadro[12:14])
	ip := quadro[14:]
	verIhl, ttl, proto := ip[0], ip[8], ip[9]
	fmt.Printf("EtherType 0x%04x -> IPv%d, TTL %d, protocolo %d\n", ethertype, verIhl>>4, ttl, proto)
	fmt.Println("checksum confere:", checksum(ip[:20]) == 0)
	sport, dport, ulen := binary.BigEndian.Uint16(ip[20:]), binary.BigEndian.Uint16(ip[22:]), int(binary.BigEndian.Uint16(ip[24:]))
	fmt.Printf("%s:%d -> %s:%d\n", net.IP(ip[12:16]), sport, net.IP(ip[16:20]), dport)
	fmt.Println("dados:", string(ip[28:28+ulen-8]))
}
```

Um detalhe útil: somar o cabeçalho inteiro, já com o checksum dentro, dá zero depois do complemento. É assim que o receptor valida sem recalcular campo a campo. Como o roteador altera o TTL, ele precisa recalcular esse checksum a cada salto, um dos motivos de o IPv6 ter removido o campo.

Isso explica por que o algoritmo de Nagle agrupa escritas pequenas, por que protocolos binários e compressão de cabeçalho (HPACK no HTTP/2) importam em alto volume, e por que túneis (VPN, VXLAN, IPsec) reduzem o espaço útil.

<Callout type="warning" title="O bug clássico da MTU">
Dentro de um túnel, pacotes de 1.500 bytes não cabem. Se o remetente marcou "não fragmentar" e um firewall bloqueia o ICMP que avisaria "pacote grande demais", a conexão abre (o handshake é pequeno), mas trava ao transferir dados grandes. O sintoma típico: SSH conecta e congela no primeiro comando com saída longa. A correção é reduzir a MTU ou ajustar o MSS no túnel (MSS clamping).
</Callout>

## Trade-offs

| Escolha | Ganho | Custo |
| --- | --- | --- |
| Cabeçalhos independentes por camada | Troca de tecnologia sem afetar o resto | Overhead em mensagens pequenas |
| Jumbo frames (MTU 9000) | Menos pacotes e menos CPU por byte | Todo o caminho precisa suportar |
| Fragmentação IP | Pacote grande atravessa enlace pequeno | Perder um fragmento perde o pacote inteiro |
