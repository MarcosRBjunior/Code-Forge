Um roteador recebe um pacote, olha o destino e precisa decidir por qual interface ele sai. Essa decisão é rápida e local: consultar a tabela de rotas com longest prefix match. A parte difícil é **construir** a tabela. Dentro de uma organização, o objetivo é achar o caminho mais curto e reagir rápido a falhas; entre organizações, o que manda são contratos e política. Daí dois mundos: protocolos internos como o **OSPF** e o protocolo da internet, o **BGP**.

## Plano de dados e plano de controle

```text
           plano de controle (lento, software)
   OSPF / BGP / rotas estáticas  -->  RIB (todas as rotas conhecidas)
                                         |  escolhe a melhor por destino
                                         v
           plano de dados (rápido, hardware)
   pacote chega --> FIB (longest prefix match) --> interface de saída
```

Os protocolos de roteamento trocam informações e preenchem a tabela; o encaminhamento em si nem sabe que eles existem. Quando um enlace cai, há um intervalo até o plano de controle convergir. Nesse intervalo, pacotes podem ser descartados ou andar em laço até o TTL acabar.

## OSPF: cada roteador conhece o mapa

O OSPF é um protocolo de **estado de enlace**. Cada roteador anuncia aos vizinhos seus enlaces e o custo de cada um (normalmente derivado da banda). Esses anúncios se espalham por inundação até que todos tenham o mesmo mapa da área. Então cada roteador roda Dijkstra sozinho e calcula a árvore de caminhos mínimos a partir de si.

enlaces = {
    "R1": {"R2": 10, "R3": 1},
    "R2": {"R1": 10, "R4": 1},
    "R3": {"R1": 1, "R4": 5, "R5": 2},

def spf(grafo, origem):
    dist, prox_salto = {origem: 0}, {}
    fila = [(0, origem, None)]
    while fila:
        d, no, primeiro = heapq.heappop(fila)
        if d > dist.get(no, float("inf")):

                heapq.heappush(fila, (nd, viz, primeiro or viz))
    return dist, prox_salto

// heap mínimo de [d, no, primeiro] (JavaScript não tem heapq)
function menor(a, b) {
  if (a[0] !== b[0]) return a[0] < b[0];
  if (a[1] !== b[1]) return a[1] < b[1];
  return (a[2] ?? "") < (b[2] ?? "");
}

function heappush(heap, item) {
  heap.push(item);
  let i = heap.length - 1;
  while (i > 0) {
    const pai = (i - 1) >> 1;
    if (!menor(heap[i], heap[pai])) break;
    [heap[i], heap[pai]] = [heap[pai], heap[i]];
    i = pai;
  }
}

function heappop(heap) {
  const topo = heap[0];
  const ultimo = heap.pop();
  if (heap.length > 0) {
    heap[0] = ultimo;
    let i = 0;
    while (true) {
      const e = 2 * i + 1, d = 2 * i + 2;
      let m = i;
      if (e < heap.length && menor(heap[e], heap[m])) m = e;
      if (d < heap.length && menor(heap[d], heap[m])) m = d;
      if (m === i) break;
      [heap[i], heap[m]] = [heap[m], heap[i]];
      i = m;
    }
  }
  return topo;
}

import java.util.*;

static Map<String, TreeMap<String, Integer>> enlaces = new HashMap<>();

static void enlace(String no, Object... vizinhos) {
    TreeMap<String, Integer> m = new TreeMap<>(); // TreeMap: vizinhos em ordem, como sorted()
    for (int i = 0; i < vizinhos.length; i += 2) m.put((String) vizinhos[i], (Integer) vizinhos[i + 1]);
    enlaces.put(no, m);
}

// item da fila: d, no, primeiro salto
static class Item {
    int d;
    String no, primeiro;

    Item(int d, String no, String primeiro) {
        this.d = d;
        this.no = no;
        this.primeiro = primeiro;
    }
}

static List<Map<String, ?>> spf(Map<String, TreeMap<String, Integer>> grafo, String origem) {
    Map<String, Integer> dist = new HashMap<>();
    Map<String, String> proxSalto = new HashMap<>();
    dist.put(origem, 0);
    PriorityQueue<Item> fila = new PriorityQueue<>(
        Comparator.<Item>comparingInt(x -> x.d).thenComparing(x -> x.no));
    fila.add(new Item(0, origem, null));
    while (!fila.isEmpty()) {
        Item it = fila.poll();
        if (it.d > dist.getOrDefault(it.no, Integer.MAX_VALUE)) continue;
        for (Map.Entry<String, Integer> e : grafo.get(it.no).entrySet()) {
            String viz = e.getKey();
            int nd = it.d + e.getValue();
            if (nd < dist.getOrDefault(viz, Integer.MAX_VALUE)) {
                dist.put(viz, nd);
                String salto = it.primeiro != null ? it.primeiro : viz;
                proxSalto.put(viz, salto);
                fila.add(new Item(nd, viz, salto));
            }
        }
    }
    return List.of(dist, proxSalto);
}

static void tabela(Map<String, TreeMap<String, Integer>> grafo) {
    List<Map<String, ?>> r = spf(grafo, "R1");
    Map<String, ?> dist = r.get(0), salto = r.get(1);
    for (String destino : new TreeSet<>(dist.keySet())) {
        if (!destino.equals("R1")) {
            System.out.println(String.format("  %s: custo %2d via %s", destino, dist.get(destino), salto.get(destino)));
        }
    }
}

public static void main(String[] args) {
    enlace("R1", "R2", 10, "R3", 1);
    enlace("R2", "R1", 10, "R4", 1);
    enlace("R3", "R1", 1, "R4", 5, "R5", 2);
    enlace("R4", "R2", 1, "R3", 5, "R5", 1);

}

Grafo enlaces = {
    {"R1", {{"R2", 10}, {"R3", 1}}},
    {"R2", {{"R1", 10}, {"R4", 1}}},
    {"R3", {{"R1", 1}, {"R4", 5}, {"R5", 2}}},

pair<map<string, int>, map<string, string>> spf(const Grafo& grafo, const string& origem) {
    map<string, int> dist = {{origem, 0}};
    map<string, string> proxSalto;
    // (d, no, primeiro); primeiro vazio = ainda na origem
    using Item = tuple<int, string, string>;
    priority_queue<Item, vector<Item>, greater<Item>> fila;
    fila.push({0, origem, ""});
    auto distDe = [&](const string& n) { return dist.count(n) ? dist[n] : INT_MAX; };
    while (!fila.empty()) {
        auto [d, no, primeiro] = fila.top();
        fila.pop();
        if (d > distDe(no)) continue;
        for (auto& [viz, custo] : grafo.at(no)) {
            int nd = d + custo;
            if (nd < distDe(viz)) {
                dist[viz] = nd;
                string salto = primeiro.empty() ? viz : primeiro;
                proxSalto[viz] = salto;
                fila.push({nd, viz, salto});
            }
        }
    }
    return {dist, proxSalto};
}

void tabela(const Grafo& grafo) {
    auto [dist, salto] = spf(grafo, "R1");
    for (auto& [destino, custo] : dist) {
        if (destino != "R1") {
            cout << format("  {}: custo {:2} via {}", destino, custo, salto[destino]) << "\n";
        }
    }
}

using System;
using System.Collections.Generic;
using System.Linq;

// item da fila: d, no, primeiro salto
class Item
{
    public int D;
    public string No, Primeiro;

    public Item(int d, string no, string primeiro)
    {
        D = d;
        No = no;
        Primeiro = primeiro;
    }
}

// heap mínimo (o Mono não tem PriorityQueue)
static bool Menor(Item a, Item b)
{
    if (a.D != b.D) return a.D < b.D;
    return string.CompareOrdinal(a.No, b.No) < 0;
}

static void HeapPush(List<Item> heap, Item item)
{
    heap.Add(item);
    int i = heap.Count - 1;
    while (i > 0)
    {
        int pai = (i - 1) / 2;
        if (!Menor(heap[i], heap[pai])) break;
        var tmp = heap[i]; heap[i] = heap[pai]; heap[pai] = tmp;
        i = pai;
    }
}

static Item HeapPop(List<Item> heap)
{
    var topo = heap[0];
    heap[0] = heap[heap.Count - 1];
    heap.RemoveAt(heap.Count - 1);
    int i = 0;
    while (true)
    {
        int e = 2 * i + 1, d = 2 * i + 2, m = i;
        if (e < heap.Count && Menor(heap[e], heap[m])) m = e;
        if (d < heap.Count && Menor(heap[d], heap[m])) m = d;
        if (m == i) break;
        var tmp = heap[i]; heap[i] = heap[m]; heap[m] = tmp;
        i = m;
    }
    return topo;
}

static Dictionary<string, SortedDictionary<string, int>> enlaces = new Dictionary<string, SortedDictionary<string, int>>

static void Spf(Dictionary<string, SortedDictionary<string, int>> grafo, string origem,
                Dictionary<string, int> dist, Dictionary<string, string> proxSalto)
{
    dist[origem] = 0;
    var fila = new List<Item> { new Item(0, origem, null) };
    while (fila.Count > 0)
    {
        var it = HeapPop(fila);
        if (it.D > (dist.ContainsKey(it.No) ? dist[it.No] : int.MaxValue)) continue;
        foreach (var par in grafo[it.No])
        {
            string viz = par.Key;
            int nd = it.D + par.Value;
            if (nd < (dist.ContainsKey(viz) ? dist[viz] : int.MaxValue))
            {
                dist[viz] = nd;
                string salto = it.Primeiro ?? viz;
                proxSalto[viz] = salto;
                HeapPush(fila, new Item(nd, viz, salto));
            }
        }
    }
}

import (
	"container/heap"
	"fmt"
	"sort"
)

// item da fila: d, no, primeiro salto ("" = ainda na origem)
type item struct {
	d        int
	no       string
	primeiro string
}

type fila []item

func (f fila) Len() int { return len(f) }
func (f fila) Less(i, j int) bool {
	if f[i].d != f[j].d {
		return f[i].d < f[j].d
	}
	return f[i].no < f[j].no
}
func (f fila) Swap(i, j int)        { f[i], f[j] = f[j], f[i] }
func (f *fila) Push(x interface{}) { *f = append(*f, x.(item)) }
func (f *fila) Pop() interface{} {
	velha := *f
	x := velha[len(velha)-1]
	*f = velha[:len(velha)-1]
	return x
}

var enlaces = map[string]map[string]int{
	"R1": {"R2": 10, "R3": 1},
	"R2": {"R1": 10, "R4": 1},
	"R3": {"R1": 1, "R4": 5, "R5": 2},
	"R4": {"R2": 1, "R3": 5, "R5": 1},
	"R5": {"R3": 2, "R4": 1},

func chavesOrdenadas[V any](m map[string]V) []string {
	ks := make([]string, 0, len(m))
	for k := range m {
		ks = append(ks, k)
	}
	sort.Strings(ks)
	return ks
}

func spf(grafo map[string]map[string]int, origem string) (map[string]int, map[string]string) {
	dist := map[string]int{origem: 0}
	proxSalto := map[string]string{}
	f := &fila{{0, origem, ""}}
	for f.Len() > 0 {
		it := heap.Pop(f).(item)
		if dd, ok := dist[it.no]; ok && it.d > dd {
			continue
		}
		for _, viz := range chavesOrdenadas(grafo[it.no]) {
			nd := it.d + grafo[it.no][viz]
			if dv, ok := dist[viz]; !ok || nd < dv {
				dist[viz] = nd
				salto := it.primeiro
				if salto == "" {
					salto = viz
				}
				proxSalto[viz] = salto
				heap.Push(f, item{nd, viz, salto})
			}
		}
	}
	return dist, proxSalto
}

func tabela(grafo map[string]map[string]int) {
	dist, salto := spf(grafo, "R1")
	for _, destino := range chavesOrdenadas(dist) {
		if destino != "R1" {
			fmt.Printf("  %s: custo %2d via %s\n", destino, dist[destino], salto[destino])
		}
	}
}

O OSPF converge em segundos ou menos, e redes grandes são divididas em **áreas** para limitar o tamanho do mapa e o raio de cada inundação.

## BGP: política entre sistemas autônomos

A internet é formada por dezenas de milhares de **sistemas autônomos** (AS), cada um com um número (ASN): provedores, nuvens, grandes empresas. O BGP troca rotas entre eles, mas não compartilha mapa algum. Cada AS anuncia prefixos com um **AS_PATH**, a lista de ASes pelos quais o anúncio passou. Isso serve para detectar laços (se meu ASN já está no caminho, descarto) e como critério de escolha. Por isso se diz que o BGP é de **vetor de caminho**.

A escolha da melhor rota segue uma sequência de desempates. Os primeiros passos, simplificados:

1. Maior **LOCAL_PREF**: preferência configurada pelo próprio AS (por exemplo, preferir enlaces de peering gratuitos a trânsito pago).
2. Menor **AS_PATH**.
3. Menor **MED**, uma sugestão do vizinho sobre por onde entrar.
4. Rotas aprendidas de fora (eBGP) antes das internas, depois menor custo interno até a saída.

// a é preferível a b? maior local_pref, depois AS_PATH mais curto, depois menor MED
func preferivel(a, b rota) bool {
	if a.localPref != b.localPref {
		return a.localPref > b.localPref
	}
	if len(a.asPath) != len(b.asPath) {
		return len(a.asPath) < len(b.asPath)
	}
	return a.med < b.med
}

func melhor(rotas []rota) rota {
	m := rotas[0]
	for _, r := range rotas[1:] {
		if preferivel(r, m) {
			m = r
		}
	}
	return m
}

O peering vence mesmo com o caminho mais longo, porque política vem antes de distância. É assim que o BGP funciona: o "melhor" caminho é o que o dono da rede quer, não o mais rápido.

## Comparação

| Aspecto | OSPF | BGP |
| --- | --- | --- |
| Escopo | Dentro de um AS | Entre ASes (e dentro, com iBGP) |
| Tipo | Estado de enlace | Vetor de caminho |
| Critério | Menor custo | Política, depois AS_PATH |
| Escala | Centenas a milhares de roteadores | Mais de um milhão de prefixos |
| Convergência | Rápida | Lenta, de segundos a minutos |
| Transporte | IP direto (protocolo 89) | TCP, porta 179 |

## Quando dá errado

O BGP confia nos anúncios dos vizinhos. Um AS que anuncia por engano um prefixo que não é seu, ou um prefixo mais específico, atrai o tráfego do mundo (lembre do longest prefix match). Vazamentos e sequestros de rotas já derrubaram grandes serviços, e um erro de configuração que retira os anúncios de um provedor faz ele simplesmente sumir da internet, inclusive seus servidores de DNS. RPKI, que assina quais ASes podem originar cada prefixo, mitiga parte disso.

## Na entrevista

Separe encaminhamento (consulta à tabela) de roteamento (construção da tabela). Diga que OSPF calcula caminhos mínimos com o mapa completo e BGP escolhe por política com vetor de caminho.
