O HTTP/1.1 obriga cada conexão a carregar uma resposta por vez, e a indústria passou anos abrindo seis conexões por domínio para compensar. O HTTP/2 ataca o problema na raiz: mantém a semântica (métodos, status, cabeçalhos continuam iguais), mas troca o formato de texto por **frames binários** que permitem misturar muitas requisições numa única conexão TCP.

## Frames, streams e a conexão

Toda comunicação vira frames. Cada frame tem um cabeçalho fixo de 9 bytes:

```text
+-----------------------------------------------+
|              Length (24 bits)                 |  tamanho do payload
+---------------+---------------+---------------+
|  Type (8)     |  Flags (8)    |
+-+-------------+---------------+---------------+
|R|           Stream Identifier (31 bits)       |  a qual stream pertence
+-+---------------------------------------------+
|              Payload (Length bytes)           |
+-----------------------------------------------+
```

Um **stream** é uma troca requisição/resposta, identificada por um número: o cliente usa ímpares (1, 3, 5...), o servidor pares, e o stream 0 é a própria conexão. Os tipos mais importantes:

| Tipo | Código | Função |
| --- | --- | --- |
| DATA | 0x0 | corpo da mensagem |
| HEADERS | 0x1 | cabeçalhos comprimidos com HPACK |
| RST_STREAM | 0x3 | cancela um stream sem derrubar a conexão |
| SETTINGS | 0x4 | parâmetros da conexão (ex.: máximo de streams simultâneos) |
| PING | 0x6 | mede RTT e mantém a conexão viva |
| GOAWAY | 0x7 | "não aceito streams novos depois do id N" (desligamento gracioso) |
| WINDOW_UPDATE | 0x8 | libera crédito de controle de fluxo |

Como cada frame diz a qual stream pertence, o remetente pode intercalá-los livremente. O programa a seguir monta frames de dois streams intercalados e depois os separa do lado do receptor, como faria uma implementação real.

```python
import struct

TIPOS = {0: "DATA", 1: "HEADERS"}
END_STREAM, END_HEADERS = 0x1, 0x4

def frame(tipo, flags, stream, payload):
    tamanho = len(payload)
    cab = struct.pack("!BHBBI", tamanho >> 16, tamanho & 0xFFFF, tipo, flags, stream & 0x7FFFFFFF)
    return cab + payload

fio = b"".join([
    frame(1, END_HEADERS, 1, b"<hpack /a>"),
    frame(1, END_HEADERS, 3, b"<hpack /b>"),
    frame(0, 0, 3, b"bbbb"),
    frame(0, 0, 1, b"aaaaaa"),
    frame(0, END_STREAM, 3, b"bb"),
    frame(0, END_STREAM, 1, b"aa"),
])
print("bytes no fio:", len(fio))

pos, streams = 0, {}
while pos < len(fio):
    alto, baixo, tipo, flags, sid = struct.unpack("!BHBBI", fio[pos:pos + 9])
    tamanho = (alto << 16) | baixo
    payload = fio[pos + 9:pos + 9 + tamanho]
    pos += 9 + tamanho
    fim = " END_STREAM" if tipo == 0 and flags & END_STREAM else ""
    print(f"stream {sid}: {TIPOS[tipo]:7} {tamanho:2} bytes{fim}")
    if tipo == 0:
        streams[sid] = streams.get(sid, b"") + payload
for sid, corpo in sorted(streams.items()):
    print("corpo do stream", sid, "=", corpo.decode())
```

```javascript
const TIPOS = { 0: "DATA", 1: "HEADERS" };
const END_STREAM = 0x1, END_HEADERS = 0x4;

function frame(tipo, flags, stream, payload) {
  const tamanho = payload.length;
  // cabeçalho de 9 bytes: tamanho (24 bits), tipo, flags e stream (31 bits), tudo big-endian
  const cab = Buffer.alloc(9);
  cab.writeUInt8(tamanho >> 16, 0);
  cab.writeUInt16BE(tamanho & 0xffff, 1);
  cab.writeUInt8(tipo, 3);
  cab.writeUInt8(flags, 4);
  cab.writeUInt32BE(stream & 0x7fffffff, 5);
  return Buffer.concat([cab, payload]);
}

const fio = Buffer.concat([
  frame(1, END_HEADERS, 1, Buffer.from("<hpack /a>")),
  frame(1, END_HEADERS, 3, Buffer.from("<hpack /b>")),
  frame(0, 0, 3, Buffer.from("bbbb")),
  frame(0, 0, 1, Buffer.from("aaaaaa")),
  frame(0, END_STREAM, 3, Buffer.from("bb")),
  frame(0, END_STREAM, 1, Buffer.from("aa")),
]);
console.log("bytes no fio:", fio.length);

let pos = 0;
const streams = new Map();
while (pos < fio.length) {
  const alto = fio.readUInt8(pos), baixo = fio.readUInt16BE(pos + 1);
  const tipo = fio.readUInt8(pos + 3), flags = fio.readUInt8(pos + 4), sid = fio.readUInt32BE(pos + 5);
  const tamanho = (alto << 16) | baixo;
  const payload = fio.subarray(pos + 9, pos + 9 + tamanho);
  pos += 9 + tamanho;
  const fim = tipo === 0 && flags & END_STREAM ? " END_STREAM" : "";
  console.log(`stream ${sid}: ${TIPOS[tipo].padEnd(7)} ${String(tamanho).padStart(2)} bytes${fim}`);
  if (tipo === 0) {
    streams.set(sid, Buffer.concat([streams.get(sid) ?? Buffer.alloc(0), payload]));
  }
}
for (const [sid, corpo] of [...streams.entries()].sort((a, b) => a[0] - b[0])) {
  console.log("corpo do stream", sid, "=", corpo.toString());
}
```

```java
import java.io.ByteArrayOutputStream;
import java.nio.ByteBuffer;
import java.nio.charset.StandardCharsets;
import java.util.*;

static final String[] TIPOS = {"DATA", "HEADERS"};
static final int END_STREAM = 0x1, END_HEADERS = 0x4;

static byte[] frame(int tipo, int flags, int stream, String texto) {
    byte[] payload = texto.getBytes(StandardCharsets.US_ASCII);
    int tamanho = payload.length;
    // cabeçalho de 9 bytes: tamanho (24 bits), tipo, flags e stream (31 bits); ByteBuffer já é big-endian
    ByteBuffer cab = ByteBuffer.allocate(9 + tamanho);
    cab.put((byte) (tamanho >> 16));
    cab.putShort((short) (tamanho & 0xFFFF));
    cab.put((byte) tipo);
    cab.put((byte) flags);
    cab.putInt(stream & 0x7FFFFFFF);
    cab.put(payload);
    return cab.array();
}

public static void main(String[] args) {
    ByteArrayOutputStream junta = new ByteArrayOutputStream();
    junta.writeBytes(frame(1, END_HEADERS, 1, "<hpack /a>"));
    junta.writeBytes(frame(1, END_HEADERS, 3, "<hpack /b>"));
    junta.writeBytes(frame(0, 0, 3, "bbbb"));
    junta.writeBytes(frame(0, 0, 1, "aaaaaa"));
    junta.writeBytes(frame(0, END_STREAM, 3, "bb"));
    junta.writeBytes(frame(0, END_STREAM, 1, "aa"));
    byte[] fio = junta.toByteArray();
    System.out.println("bytes no fio: " + fio.length);

    ByteBuffer buf = ByteBuffer.wrap(fio);
    int pos = 0;
    Map<Integer, String> streams = new TreeMap<>();
    while (pos < fio.length) {
        int alto = buf.get(pos) & 0xFF, baixo = buf.getShort(pos + 1) & 0xFFFF;
        int tipo = buf.get(pos + 3) & 0xFF, flags = buf.get(pos + 4) & 0xFF, sid = buf.getInt(pos + 5);
        int tamanho = (alto << 16) | baixo;
        String payload = new String(fio, pos + 9, tamanho, StandardCharsets.US_ASCII);
        pos += 9 + tamanho;
        String fim = tipo == 0 && (flags & END_STREAM) != 0 ? " END_STREAM" : "";
        System.out.println(String.format("stream %d: %-7s %2d bytes%s", sid, TIPOS[tipo], tamanho, fim));
        if (tipo == 0) {
            streams.put(sid, streams.getOrDefault(sid, "") + payload);
        }
    }
    for (Map.Entry<Integer, String> e : streams.entrySet()) {
        System.out.println("corpo do stream " + e.getKey() + " = " + e.getValue());
    }
}
```

```go
import (
	"encoding/binary"
	"fmt"
	"sort"
)

var TIPOS = map[byte]string{0: "DATA", 1: "HEADERS"}

const END_STREAM, END_HEADERS = 0x1, 0x4

func frame(tipo, flags byte, stream uint32, payload string) []byte {
	tamanho := len(payload)
	// cabeçalho de 9 bytes: tamanho (24 bits), tipo, flags e stream (31 bits), tudo big-endian
	cab := make([]byte, 9)
	cab[0] = byte(tamanho >> 16)
	binary.BigEndian.PutUint16(cab[1:3], uint16(tamanho&0xFFFF))
	cab[3] = tipo
	cab[4] = flags
	binary.BigEndian.PutUint32(cab[5:9], stream&0x7FFFFFFF)
	return append(cab, payload...)
}

func main() {
	fio := []byte{}
	for _, q := range [][]byte{
		frame(1, END_HEADERS, 1, "<hpack /a>"),
		frame(1, END_HEADERS, 3, "<hpack /b>"),
		frame(0, 0, 3, "bbbb"),
		frame(0, 0, 1, "aaaaaa"),
		frame(0, END_STREAM, 3, "bb"),
		frame(0, END_STREAM, 1, "aa"),
	} {
		fio = append(fio, q...)
	}
	fmt.Println("bytes no fio:", len(fio))

	pos, streams := 0, map[uint32]string{}
	for pos < len(fio) {
		alto, baixo := int(fio[pos]), int(binary.BigEndian.Uint16(fio[pos+1:pos+3]))
		tipo, flags, sid := fio[pos+3], fio[pos+4], binary.BigEndian.Uint32(fio[pos+5:pos+9])
		tamanho := (alto << 16) | baixo
		payload := string(fio[pos+9 : pos+9+tamanho])
		pos += 9 + tamanho
		fim := ""
		if tipo == 0 && flags&END_STREAM != 0 {
			fim = " END_STREAM"
		}
		fmt.Printf("stream %d: %-7s %2d bytes%s\n", sid, TIPOS[tipo], tamanho, fim)
		if tipo == 0 {
			streams[sid] += payload
		}
	}
	sids := []uint32{}
	for sid := range streams {
		sids = append(sids, sid)
	}
	sort.Slice(sids, func(i, j int) bool { return sids[i] < sids[j] })
	for _, sid := range sids {
		fmt.Println("corpo do stream", sid, "=", streams[sid])
	}
}
```

Esse intercalamento elimina o head-of-line blocking **na camada HTTP**: uma resposta lenta não impede que frames de outras respostas passem. Uma conexão por origem basta, e as gambiarras do 1.1 (domain sharding, sprites) passam a atrapalhar, porque espalham o tráfego por conexões que não compartilham compressão nem janela de congestionamento.

## HPACK: comprimir cabeçalhos com estado

No 1.1, cada requisição reenvia `cookie`, `user-agent` e `authorization` inteiros, e isso pode passar de 1 KB por requisição. O HPACK mantém, dos dois lados, uma **tabela estática** de 61 cabeçalhos comuns (como `:method: GET`) e uma **tabela dinâmica** com o que já foi enviado nesta conexão. Um cabeçalho repetido vira um índice de um ou dois bytes. A simulação simplificada abaixo mostra o efeito em três requisições seguidas.

```python
ESTATICA = [(":method", "GET"), (":scheme", "https"), (":path", "/")]

class CompressorSimples:
    def __init__(self):
        self.dinamica = []

    def codificar(self, cabecalhos):
        total = 0
        for par in cabecalhos:
            tabela = ESTATICA + self.dinamica
            if par in tabela:
                total += 1  # só o índice
            else:
                total += 2 + len(par[0]) + len(par[1])  # literal
                self.dinamica.insert(0, par)  # entra na tabela dinâmica
        return total

cabs = [(":method", "GET"), (":scheme", "https"), (":authority", "api.loja.com"),
        ("user-agent", "app-ios/7.3.1 (iPhone; iOS 18)"), ("cookie", "sessao=" + "x" * 120)]
comp = CompressorSimples()
for i, caminho in enumerate(["/pedidos", "/carrinho", "/perfil"], 1):
    pedido = cabs + [(":path", caminho)]
    texto = sum(len(k) + len(v) + 4 for k, v in pedido)
    print(f"requisicao {i}: texto ~{texto} bytes, comprimido {comp.codificar(pedido)} bytes")
```

```javascript
const ESTATICA = [[":method", "GET"], [":scheme", "https"], [":path", "/"]];

class CompressorSimples {
  constructor() {
    this.dinamica = [];
  }

  codificar(cabecalhos) {
    let total = 0;
    for (const par of cabecalhos) {
      const tabela = [...ESTATICA, ...this.dinamica];
      if (tabela.some(([k, v]) => k === par[0] && v === par[1])) {
        total += 1; // só o índice
      } else {
        total += 2 + par[0].length + par[1].length; // literal
        this.dinamica.unshift(par); // entra na tabela dinâmica
      }
    }
    return total;
  }
}

const cabs = [[":method", "GET"], [":scheme", "https"], [":authority", "api.loja.com"],
  ["user-agent", "app-ios/7.3.1 (iPhone; iOS 18)"], ["cookie", "sessao=" + "x".repeat(120)]];

["/pedidos", "/carrinho", "/perfil"].forEach((caminho, idx) => {
  const i = idx + 1;
  const pedido = [...cabs, [":path", caminho]];
  const texto = pedido.reduce((s, [k, v]) => s + k.length + v.length + 4, 0);
  console.log(`requisicao ${i}: texto ~${texto} bytes, comprimido ${comp.codificar(pedido)} bytes`);
});
```

```java
import java.util.*;

static final List<List<String>> ESTATICA = List.of(
    List.of(":method", "GET"), List.of(":scheme", "https"), List.of(":path", "/"));

static class CompressorSimples {
    List<List<String>> dinamica = new ArrayList<>();

    int codificar(List<List<String>> cabecalhos) {
        int total = 0;
        for (List<String> par : cabecalhos) {
            List<List<String>> tabela = new ArrayList<>(ESTATICA);
            tabela.addAll(dinamica);
            if (tabela.contains(par)) {
                total += 1; // só o índice
            } else {
                total += 2 + par.get(0).length() + par.get(1).length(); // literal
                dinamica.add(0, par); // entra na tabela dinâmica
            }
        }
        return total;
    }
}

    List<List<String>> cabs = List.of(List.of(":method", "GET"), List.of(":scheme", "https"),
```

## Controle de fluxo e priorização

Multiplexar cria um problema novo: um download grande pode encher os buffers do receptor e sufocar o resto. Por isso o HTTP/2 tem controle de fluxo próprio, **por stream e por conexão**, com janela inicial de 65.535 bytes. O receptor libera crédito com WINDOW_UPDATE. Uma janela pequena demais num link de alta latência limita a vazão mesmo com banda sobrando, um erro comum em proxies e clientes gRPC mal configurados.

A priorização original (árvore de dependências com pesos) era complexa e mal implementada; hoje se usa um esquema mais simples de urgência anunciado em cabeçalho. O **server push** também existiu e foi abandonado pelos navegadores: o servidor raramente sabia o que o cliente já tinha em cache.

## O que o HTTP/2 não resolve

Todos os streams compartilham **uma** conexão TCP, e o TCP entrega bytes em ordem. Se um segmento se perde, tudo que veio depois fica parado no buffer do kernel até a retransmissão chegar, inclusive frames de streams que nada tinham a ver com o pacote perdido. Em redes com perda (celular, Wi-Fi ruim), o HTTP/2 pode ficar pior que seis conexões HTTP/1.1. Esse é o head-of-line blocking **de transporte**, e é a motivação do HTTP/3.

<Callout type="note" title="Como a versão é negociada">
Navegadores só usam HTTP/2 sobre TLS. A escolha acontece dentro do próprio handshake TLS, pela extensão ALPN: o cliente oferece `h2` e `http/1.1`, e o servidor escolhe. Não há ida e volta extra.
</Callout>
