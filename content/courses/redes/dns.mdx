Quase toda requisição que seu serviço faz começa com uma pergunta ao DNS, e boa parte dos incidentes misteriosos de "a API ficou lenta por alguns segundos" ou "metade dos clientes ainda vai para o servidor antigo" tem a ver com ele. Aqui você vai abrir a mensagem DNS byte a byte, entender o que cada tipo de registro faz e ver como o cache com TTL decide quanto tempo uma mudança leva para valer.

## A mensagem DNS por dentro

O DNS usa a mesma estrutura para pergunta e resposta: um cabeçalho fixo de 12 bytes seguido de quatro seções (pergunta, respostas, autoridade e adicionais). Por padrão a consulta vai em um único datagrama UDP para a porta 53.

```text
 0                16               31
+-----------------+-----------------+
|       ID        |      FLAGS      |   ID casa resposta com pergunta
+-----------------+-----------------+   FLAGS: QR, opcode, AA, TC, RD, RA, RCODE
|     QDCOUNT     |     ANCOUNT     |   quantos itens há em cada seção
+-----------------+-----------------+
|     NSCOUNT     |     ARCOUNT     |
+-----------------+-----------------+
| pergunta: nome em rótulos + QTYPE + QCLASS
| respostas, autoridade, adicionais: nome, tipo, classe, TTL, RDLENGTH, RDATA
```

Os bits de FLAGS que mais aparecem em diagnóstico:

| Bit | Significado |
| --- | --- |
| QR | 0 = pergunta, 1 = resposta |
| AA | resposta veio de um servidor autoritativo, não de cache |
| TC | resposta truncada: não coube no UDP, refaça por TCP |
| RD / RA | cliente pede recursão / servidor oferece recursão |
| RCODE | 0 = NOERROR, 2 = SERVFAIL, 3 = NXDOMAIN |

O nome não vai como texto com pontos: cada rótulo é precedido do seu tamanho, e o nome termina com um byte zero. `api.loja.com` vira `3api4loja3com0`. O programa abaixo monta uma consulta do tipo A exatamente como um resolvedor faria, sem enviar nada pela rede.

```java
import java.nio.ByteBuffer;
import java.nio.charset.StandardCharsets;

static byte[] codificarNome(String nome) {
    ByteBuffer saida = ByteBuffer.allocate(nome.length() + 2);
    for (String rotulo : nome.split("\\.")) {
        byte[] b = rotulo.getBytes(StandardCharsets.UTF_8);
        saida.put((byte) b.length).put(b);
    }
    saida.put((byte) 0);
    return java.util.Arrays.copyOf(saida.array(), saida.position());
}

static byte[] montarConsulta(int id, String nome, int qtype) {
    int flags = 0x0100; // RD=1: peço recursão
    byte[] qname = codificarNome(nome);
    ByteBuffer buf = ByteBuffer.allocate(12 + qname.length + 4); // big-endian (ordem de rede)
    for (int campo : new int[] {id, flags, 1, 0, 0, 0}) buf.putShort((short) campo);
    buf.put(qname);
    buf.putShort((short) qtype).putShort((short) 1); // classe IN
    return buf.array();
}

static String hex(byte[] b, int de, int ate) {
    StringBuilder sb = new StringBuilder();
    for (int i = de; i < ate; i++) sb.append(i > de ? " " : "").append(String.format("%02x", b[i] & 0xFF));
    return sb.toString();
}

public static void main(String[] args) {
    byte[] msg = montarConsulta(0xBEEF, "api.loja.com", 1);
    System.out.println(msg.length + " bytes");
    System.out.println(hex(msg, 0, 12));
    System.out.println(hex(msg, 12, msg.length));
}
```

## Compressão de nomes

Uma resposta repete o mesmo nome várias vezes (na pergunta e em cada registro). Para economizar espaço, um nome pode ser substituído por um **ponteiro**: dois bytes cujos dois bits mais altos valem 1 e o resto é o deslocamento, a partir do início da mensagem, onde o nome já apareceu. `c0 0c` significa "o nome que começa no byte 12", ou seja, logo depois do cabeçalho. O parser abaixo lê uma resposta com dois registros A e segue esses ponteiros.

<CodeTabs>

```python
import struct

def ler_nome(msg, pos):
    rotulos = []
    while True:
        tam = msg[pos]
        if tam & 0xC0 == 0xC0:  # ponteiro de compressão
            destino = struct.unpack("!H", msg[pos:pos + 2])[0] & 0x3FFF
            nome, _ = ler_nome(msg, destino)
            rotulos.append(nome)
            return ".".join(rotulos), pos + 2
        if tam == 0:
            return ".".join(rotulos), pos + 1
        rotulos.append(msg[pos + 1:pos + 1 + tam].decode())
        pos += 1 + tam

nome = b"\x03api\x04loja\x03com\x00"
cab = struct.pack("!HHHHHH", 0xBEEF, 0x8180, 1, 2, 0, 0)
pergunta = nome + struct.pack("!HH", 1, 1)
def registro_a(ip, ttl):
    return b"\xc0\x0c" + struct.pack("!HHIH", 1, 1, ttl, 4) + bytes(int(x) for x in ip.split("."))
resposta = cab + pergunta + registro_a("203.0.113.10", 300) + registro_a("203.0.113.11", 300)

id_, flags, qd, an, ns, ar = struct.unpack("!HHHHHH", resposta[:12])
print(f"id={id_:#x} resposta={flags >> 15} rcode={flags & 0xF} respostas={an}")
q, pos = ler_nome(resposta, 12)
pos += 4
print("pergunta:", q)
for _ in range(an):
    n, pos = ler_nome(resposta, pos)
    tipo, classe, ttl, rdlen = struct.unpack("!HHIH", resposta[pos:pos + 10])
    pos += 10
    ip = ".".join(str(b) for b in resposta[pos:pos + rdlen])
    pos += rdlen
    print(f"{n} tipo={tipo} ttl={ttl} -> {ip}")
print("tamanho total:", len(resposta), "bytes")
```

```java
import java.nio.ByteBuffer;
import java.nio.charset.StandardCharsets;
import java.util.*;

static int pos; // posição de leitura (o Python devolve a tupla (nome, pos))

static String lerNome(byte[] msg, int inicio) {
    List<String> rotulos = new ArrayList<>();
    int p = inicio;
    while (true) {
        int tam = msg[p] & 0xFF;
        if ((tam & 0xC0) == 0xC0) { // ponteiro de compressão
            int destino = ByteBuffer.wrap(msg, p, 2).getShort() & 0x3FFF;
            rotulos.add(lerNome(msg, destino));
            pos = p + 2;
            return String.join(".", rotulos);
        }
        if (tam == 0) {
            pos = p + 1;
            return String.join(".", rotulos);
        }
        rotulos.add(new String(msg, p + 1, tam, StandardCharsets.UTF_8));
        p += 1 + tam;
    }
}

static byte[] registroA(String ip, int ttl) {
    ByteBuffer b = ByteBuffer.allocate(16);
    b.put((byte) 0xC0).put((byte) 0x0C);
    b.putShort((short) 1).putShort((short) 1).putInt(ttl).putShort((short) 4);
    for (String x : ip.split("\\.")) b.put((byte) Integer.parseInt(x));
    return b.array();
}

public static void main(String[] args) {
    byte[] nome = "\u0003api\u0004loja\u0003com\u0000".getBytes(StandardCharsets.US_ASCII);
    ByteBuffer buf = ByteBuffer.allocate(12 + nome.length + 4 + 32); // big-endian (ordem de rede)
    for (int campo : new int[] {0xBEEF, 0x8180, 1, 2, 0, 0}) buf.putShort((short) campo);
    buf.put(nome).putShort((short) 1).putShort((short) 1);
    buf.put(registroA("203.0.113.10", 300)).put(registroA("203.0.113.11", 300));
    byte[] resposta = buf.array();

    ByteBuffer leitor = ByteBuffer.wrap(resposta);
    int id = leitor.getShort(0) & 0xFFFF, flags = leitor.getShort(2) & 0xFFFF, an = leitor.getShort(6) & 0xFFFF;
    System.out.println("id=0x" + Integer.toHexString(id) + " resposta=" + (flags >> 15) + " rcode=" + (flags & 0xF) + " respostas=" + an);
    String q = lerNome(resposta, 12);
    pos += 4;
    System.out.println("pergunta: " + q);
    for (int i = 0; i < an; i++) {
        String n = lerNome(resposta, pos);
        int tipo = leitor.getShort(pos) & 0xFFFF;
        long ttl = leitor.getInt(pos + 4) & 0xFFFFFFFFL;
        int rdlen = leitor.getShort(pos + 8) & 0xFFFF;
        pos += 10;
        StringJoiner ip = new StringJoiner(".");
        for (int k = pos; k < pos + rdlen; k++) ip.add(String.valueOf(resposta[k] & 0xFF));
        pos += rdlen;
        System.out.println(n + " tipo=" + tipo + " ttl=" + ttl + " -> " + ip);
    }
    System.out.println("tamanho total: " + resposta.length + " bytes");
}
```

```cpp
#include <cstdint>
#include <cstdio>
#include <sstream>
#include <string>
#include <utility>
#include <vector>
using namespace std;

using Bytes = vector<uint8_t>;

// grava 16/32 bits em big-endian (ordem de rede)
void put16(Bytes& v, uint16_t x) { v.push_back(x >> 8); v.push_back(x & 0xFF); }
void put32(Bytes& v, uint32_t x) { put16(v, x >> 16); put16(v, x & 0xFFFF); }
uint16_t get16(const Bytes& v, size_t p) { return (v[p] << 8) | v[p + 1]; }
uint32_t get32(const Bytes& v, size_t p) { return ((uint32_t)get16(v, p) << 16) | get16(v, p + 2); }

pair<string, size_t> lerNome(const Bytes& msg, size_t pos) {
    string nome;
    auto juntar = [&](const string& r) { nome += (nome.empty() ? "" : ".") + r; };
    while (true) {
        int tam = msg[pos];
        if ((tam & 0xC0) == 0xC0) {  // ponteiro de compressão
            size_t destino = get16(msg, pos) & 0x3FFF;
            juntar(lerNome(msg, destino).first);
            return {nome, pos + 2};
        }
        if (tam == 0) return {nome, pos + 1};
        juntar(string(msg.begin() + pos + 1, msg.begin() + pos + 1 + tam));
        pos += 1 + tam;
    }
}

Bytes registroA(const string& ip, uint32_t ttl) {
    Bytes r = {0xC0, 0x0C};
    put16(r, 1);
    put16(r, 1);
    put32(r, ttl);
    put16(r, 4);
    stringstream ss(ip);
    string parte;
    while (getline(ss, parte, '.')) r.push_back(stoi(parte));
    return r;
}

int main() {
    string nome = string("\x03" "api" "\x04" "loja" "\x03" "com") + '\0';
    Bytes resposta;
    for (uint16_t campo : {0xBEEF, 0x8180, 1, 2, 0, 0}) put16(resposta, campo);
    resposta.insert(resposta.end(), nome.begin(), nome.end());

    put16(resposta, 1);
    for (auto ip : {"203.0.113.10", "203.0.113.11"}) {
        Bytes r = registroA(ip, 300);
```

```csharp
static void Put16(List<byte> v, int x) { v.Add((byte)(x >> 8)); v.Add((byte)x); }
static void Put32(List<byte> v, uint x) { Put16(v, (int)(x >> 16)); Put16(v, (int)(x & 0xFFFF)); }
static int Get16(byte[] v, int p) => (v[p] << 8) | v[p + 1];
static uint Get32(byte[] v, int p) => ((uint)Get16(v, p) << 16) | (uint)Get16(v, p + 2);

// devolve o nome e a posição logo depois dele (o Python devolve a tupla)
static string LerNome(byte[] msg, int pos, out int depois) {
    var rotulos = new List<string>();
    while (true) {
        int tam = msg[pos];
        if ((tam & 0xC0) == 0xC0) { // ponteiro de compressão
            int destino = Get16(msg, pos) & 0x3FFF;
            rotulos.Add(LerNome(msg, destino, out _));
            depois = pos + 2;
            return string.Join(".", rotulos);

        if (tam == 0) {
            depois = pos + 1;
            return string.Join(".", rotulos);
        }
        rotulos.Add(Encoding.UTF8.GetString(msg, pos + 1, tam));
        pos += 1 + tam;
    }
}

}
```

```go
	}

// struct.pack("!H...") em big-endian
func u16(xs ...uint16) []byte {
	b := make([]byte, 2*len(xs))
	for i, x := range xs {
		binary.BigEndian.PutUint16(b[2*i:], x)
	}
	return b
}

		n, _ := strconv.Atoi(x)
		r = append(r, byte(n))
	}
	return r
}
```

## Tipos de registro que você precisa saber

| Tipo | Código | Para que serve |
| --- | --- | --- |
| A | 1 | nome para endereço IPv4 |
| AAAA | 28 | nome para endereço IPv6 |
| CNAME | 5 | apelido: "este nome é outro nome"; o resolvedor recomeça a busca |
| NS | 2 | quais servidores são autoritativos para a zona (delegação) |
| MX | 15 | servidores de e-mail, com prioridade |
| TXT | 16 | texto livre: SPF, DKIM, verificação de domínio |
| SOA | 6 | metadados da zona, incluindo o TTL de respostas negativas |
| SRV | 33 | serviço, porta e peso (usado em descoberta de serviços) |
| PTR | 12 | DNS reverso: IP para nome |

Duas regras caem em entrevista. Primeiro, um nome que tem CNAME não pode ter outros registros, por isso o apex da zona (`loja.com`, sem subdomínio) não pode ser CNAME: ele já tem SOA e NS. Provedores contornam isso com registros sintéticos do tipo ALIAS ou ANAME, resolvidos no próprio servidor. Segundo, cada CNAME numa cadeia é potencialmente mais uma consulta, e cadeias longas de CDN somam latência.

```bash
dig +noall +answer www.exemplo.com.br A
```

```text
www.exemplo.com.br.   300   IN  CNAME  exemplo.cdn.net.
exemplo.cdn.net.      60    IN  A      198.51.100.7
```

## TTL, cache negativo e propagação

Não existe "propagação" de DNS: existe cache expirando. Cada resolvedor guarda a resposta pelo TTL e só pergunta de novo depois. Respostas NXDOMAIN também são cacheadas, pelo tempo indicado no SOA, o que pega muita gente que consulta um nome antes de criá-lo.

## Trade-offs e falhas reais

- **TTL baixo** (30 a 60 s) permite failover rápido, mas multiplica consultas e expõe você à latência e à disponibilidade do autoritativo. **TTL alto** é barato e resiliente, mas trava migrações. A prática comum é baixar o TTL dias antes de uma troca planejada.
- **UDP e truncamento**: respostas grandes (muitos registros, DNSSEC) passam do limite do UDP; o servidor marca TC e o cliente refaz por TCP, pagando um handshake. A extensão EDNS0 anuncia um buffer maior e evita isso na maioria dos casos.
- **Clientes que ignoram TTL**: a JVM, por exemplo, pode cachear por tempo próprio, e pools de conexão mantêm o IP antigo enquanto a conexão viver.

<Callout type="warning" title="Timeout de DNS vira latência de cauda">
Se o resolvedor perde um pacote UDP, o cliente só tenta de novo depois do timeout, que costuma ser de 1 a 5 segundos. Um p99 com saltos de exatamente 5 s é um sinal clássico de perda de pacotes de DNS.
</Callout>
