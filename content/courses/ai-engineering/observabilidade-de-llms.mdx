Um usuário reclama: "o assistente me deu uma resposta errada ontem à tarde". Sem observabilidade, você não sabe qual prompt foi usado, que trechos o RAG recuperou, qual modelo respondeu (o principal ou o fallback?), quais ferramentas o agente chamou e com quais argumentos. Logs HTTP comuns mostram só "200 OK em 4,2 s". Sistemas com LLM precisam de observabilidade que capture **o conteúdo e a cadeia de decisões**, além de latência e erros, porque a falha mais comum não é uma exceção: é uma resposta ruim com status de sucesso.

## Traces: a árvore de cada requisição

A unidade central é o **trace**: o registro de uma requisição inteira, dividido em **spans** aninhados, um para cada etapa (reescrita da consulta, busca, re-ranking, chamada ao LLM, cada tool call, cada iteração do agente). Cada span guarda início, duração, entradas, saídas e atributos.

```text
trace 7f3a  "cadê meu pedido?"                         3.1 s   US$ 0.004
├─ reescrever_consulta  (modelo pequeno)              0.4 s   210 tokens
├─ buscar               (híbrida, top 20)              0.1 s
├─ rerank                                              0.2 s
└─ agente
   ├─ llm  passo 1  → tool_call consultar_pedido       0.9 s   1.900 tokens
   ├─ tool consultar_pedido(A-981)                     0.3 s
   └─ llm  passo 2  → resposta final                   1.2 s   2.300 tokens
```

O padrão aberto mais usado para isso é o OpenTelemetry, que já tem convenções semânticas para chamadas de IA generativa; há também plataformas especializadas em observabilidade de LLM, abertas e comerciais. O programa mostra a ideia com um tracer mínimo e um relógio simulado.

```python
from contextlib import contextmanager

class Tracer:
    def __init__(self):
        self.relogio, self.pilha, self.spans = 0.0, [], []

    @contextmanager
    def span(self, nome, **attrs):
        registro = {"nome": nome, "nivel": len(self.pilha), "inicio": self.relogio, **attrs}
        self.spans.append(registro)
        self.pilha.append(registro)
        try:
            yield registro
        finally:
            registro["duracao"] = round(self.relogio - registro["inicio"], 2)
            self.pilha.pop()

    def avancar(self, segundos):   # simula o tempo gasto pela etapa
        self.relogio += segundos

t = Tracer()
with t.span("requisicao", usuario="u-17"):
    with t.span("buscar", top_k=20):
        t.avancar(0.12)
    with t.span("llm", modelo="principal", tokens_entrada=1900, tokens_saida=40) as s:
        t.avancar(0.9)
        s["finish_reason"] = "tool_use"
    with t.span("tool", nome_tool="consultar_pedido"):
        t.avancar(0.3)
    with t.span("llm", modelo="principal", tokens_entrada=2300, tokens_saida=120) as s:
        t.avancar(1.2)
        s["finish_reason"] = "end"

for s in t.spans:
    extras = {k: v for k, v in s.items() if k not in ("nome", "nivel", "inicio", "duracao")}
    print(f"{'  ' * s['nivel']}{s['nome']:12s} {s['duracao']:.2f}s {extras}")
```

```javascript
// o toFixed arredonda o valor exato do double, mas leva o empate para cima (0.125 -> "0.13");
// o Python leva o empate exato para o par ("0.12"). Com 30 casas a mais, os dígitos exatos mostram o empate.
function fixoPar(x, casas) {
  const exato = Math.abs(x).toFixed(casas + 30);
  const corte = exato.length - 30;
  if (exato.slice(corte) !== "5" + "0".repeat(29)) return x.toFixed(casas);
  const baixo = exato.slice(0, casas > 0 ? corte : corte - 1); // sem o 5 (e sem o ponto, se casas = 0)
  const par = Number(baixo[baixo.length - 1]) % 2 === 0 ? baixo : Math.abs(x).toFixed(casas);
  return (x < 0 ? "-" : "") + par;
}

class Tracer {
  constructor() {
    this.relogio = 0.0;
    this.pilha = [];
    this.spans = [];
  }

  // o bloco "with" vira um callback; o try/finally fecha o span mesmo se der erro
  span(nome, attrs, corpo) {
    const registro = { nome, nivel: this.pilha.length, inicio: this.relogio, ...attrs };
    this.spans.push(registro);
    this.pilha.push(registro);
    try {
      corpo(registro);
    } finally {
      registro.duracao = Number(fixoPar(this.relogio - registro.inicio, 2));
      this.pilha.pop();
    }
  }

  avancar(segundos) {   // simula o tempo gasto pela etapa
    this.relogio += segundos;
  }
}

});
```

```java
import java.math.*;
import java.util.*;

// o %.2f do Java arredonda a forma decimal curta e leva o empate para cima; o Python arredonda o valor
// binário exato do double (o que o construtor BigDecimal(double) guarda), com empate para o par
static String fixoPar(double x, int casas) {
    return new BigDecimal(x).setScale(casas, RoundingMode.HALF_EVEN).toPlainString();
}

// round() do Python: arredonda o valor exato do double, com empate para o par
static double arred(double x, int casas) {
    return new BigDecimal(x).setScale(casas, RoundingMode.HALF_EVEN).doubleValue();
}

// dicionário que guarda a ordem de inserção, como o dict do Python
static Map<String, Object> mapa(Object... kv) {
    Map<String, Object> m = new LinkedHashMap<>();
    for (int i = 0; i < kv.length; i += 2) m.put((String) kv[i], kv[i + 1]);
    return m;
}

static class Tracer {
    double relogio = 0.0;
    Deque<Map<String, Object>> pilha = new ArrayDeque<>();
    List<Map<String, Object>> spans = new ArrayList<>();

    // o "with" vira try-with-resources: close() roda ao sair do bloco, mesmo se der erro
    class Span implements AutoCloseable {
        Map<String, Object> registro;

        Span(Map<String, Object> registro) { this.registro = registro; }

        @Override
        public void close() {
            registro.put("duracao", arred(relogio - (Double) registro.get("inicio"), 2));
            pilha.pop();
        }
    }

    Span span(String nome, Map<String, Object> attrs) {
        Map<String, Object> registro = mapa("nome", nome, "nivel", pilha.size(), "inicio", relogio);
        registro.putAll(attrs);
        spans.add(registro);
        pilha.push(registro);
        return new Span(registro);
    }

    void avancar(double segundos) {   // simula o tempo gasto pela etapa
        relogio += segundos;
    }
}

public static void main(String[] args) {
    Tracer t = new Tracer();
    try (Tracer.Span req = t.span("requisicao", mapa("usuario", "u-17"))) {
        try (Tracer.Span s = t.span("buscar", mapa("top_k", 20))) {
            t.avancar(0.12);
        }
        try (Tracer.Span s = t.span("llm", mapa("modelo", "principal", "tokens_entrada", 1900, "tokens_saida", 40))) {
            t.avancar(0.9);
            s.registro.put("finish_reason", "tool_use");
        }
        try (Tracer.Span s = t.span("tool", mapa("nome_tool", "consultar_pedido"))) {
            t.avancar(0.3);
        }
        try (Tracer.Span s = t.span("llm", mapa("modelo", "principal", "tokens_entrada", 2300, "tokens_saida", 120))) {
            t.avancar(1.2);
            s.registro.put("finish_reason", "end");
        }
    }

    for (Map<String, Object> s : t.spans) {
        StringJoiner extras = new StringJoiner(", ", "{", "}");
        for (Map.Entry<String, Object> e : s.entrySet()) {
            if (List.of("nome", "nivel", "inicio", "duracao").contains(e.getKey())) continue;
            String valor = e.getValue() instanceof String ? "'" + e.getValue() + "'" : String.valueOf(e.getValue());
            extras.add("'" + e.getKey() + "': " + valor);
        }
        String recuo = "  ".repeat((Integer) s.get("nivel"));
        System.out.println(String.format(Locale.US, "%s%-12s %ss %s", recuo, s.get("nome"), fixoPar((Double) s.get("duracao"), 2), extras));
    }
}
```

```cpp
struct Registro {
    string nome;
    int nivel;

class Tracer;

// o "with" vira RAII: o destrutor roda ao sair do bloco, mesmo se der erro
class Span {
    Tracer& tracer;

public:
    shared_ptr<Registro> registro;

    Span(Tracer& tracer, shared_ptr<Registro> registro) : tracer(tracer), registro(registro) {}
    Span(const Span&) = delete;
    ~Span();
};

class Tracer {
public:
    double relogio = 0.0;
    vector<shared_ptr<Registro>> pilha, spans;

    shared_ptr<Registro> abrir(const string& nome, const Atributos& attrs) {
        auto registro = make_shared<Registro>(Registro{nome, int(pilha.size()), relogio, 0, attrs});
        spans.push_back(registro);
        pilha.push_back(registro);
        return registro;
    }

    void avancar(double segundos) {   // simula o tempo gasto pela etapa
        relogio += segundos;
    }
};

// round() do Python: o printf arredonda o valor exato do double, com empate para o par
double arred(double x, int casas) {
    char texto[64];
    snprintf(texto, sizeof texto, "%.*f", casas, x);
    return strtod(texto, nullptr);
}

Span::~Span() {
    registro->duracao = arred(tracer.relogio - registro->inicio, 2);
    tracer.pilha.pop_back();
}

// imita o repr() do Python para imprimir o dicionário de extras
string repr(const Atributos& extras) {
    string r = "{";
    for (size_t i = 0; i < extras.size(); i++) {
        const auto& [chave, valor] = extras[i];
        string texto = holds_alternative<string>(valor) ? "'" + get<string>(valor) + "'" : to_string(get<int>(valor));
        r += (i ? ", '" : "'") + chave + "': " + texto;
    }
    return r + "}";
}

int main() {
    Tracer t;
    {
        Span req(t, t.abrir("requisicao", {{"usuario", "u-17"}}));
        {
            Span s(t, t.abrir("buscar", {{"top_k", 20}}));
            t.avancar(0.12);
```

```csharp
using System;
using System.Collections.Generic;
using System.Globalization;
using System.Linq;

// dicionário que guarda a ordem de inserção, como o dict do Python
static Dictionary<string, object> Mapa(params object[] kv)
{
    var m = new Dictionary<string, object>();
    for (int i = 0; i < kv.Length; i += 2) m[(string)kv[i]] = kv[i + 1];
    return m;
}

// o F2 do C# arredonda a forma decimal curta, e o Math.Round(x, 2) multiplica por 100 antes (2.675 vira 267.5);
// o Python arredonda o valor binário exato do double, com empate para o par. Aqui o valor exato
// (mantissa * 2^expoente) é montado em decimal, com 28 dígitos, e arredondado para o par.
static string FixoPar(double x, int casas)
{
    long bits = BitConverter.DoubleToInt64Bits(Math.Abs(x));
    int campo = (int)(bits >> 52);
    decimal d = bits & 0xFFFFFFFFFFFFFL;
    if (campo > 0) d += 1L << 52;
    for (int e = Math.Max(campo, 1) - 1075; e > 0; e--) d *= 2;
    for (int e = Math.Max(campo, 1) - 1075; e < 0; e++) d /= 2;
    if (x < 0) d = -d;
    return Math.Round(d, casas, MidpointRounding.ToEven).ToString("F" + casas, CultureInfo.InvariantCulture);
}

// round() do Python: o mesmo arredondamento, de volta para double
static double Arred(double x, int casas)
{
    return double.Parse(FixoPar(x, casas), CultureInfo.InvariantCulture);
}

class Tracer
{
    public double Relogio = 0.0;
    public Stack<Dictionary<string, object>> Pilha = new Stack<Dictionary<string, object>>();
    public List<Dictionary<string, object>> Spans = new List<Dictionary<string, object>>();

    // o "with" vira using: Dispose() roda ao sair do bloco, mesmo se der erro
    public class SpanAberto : IDisposable
    {
        readonly Tracer tracer;
        public Dictionary<string, object> Registro;

        public SpanAberto(Tracer tracer, Dictionary<string, object> registro)
        {
            this.tracer = tracer;
            Registro = registro;
        }

        public void Dispose()
        {
            Registro["duracao"] = Arred(tracer.Relogio - (double)Registro["inicio"], 2);
            tracer.Pilha.Pop();
        }
    }

    public SpanAberto Span(string nome, Dictionary<string, object> attrs)
    {
        var registro = Mapa("nome", nome, "nivel", Pilha.Count, "inicio", Relogio);
        foreach (var a in attrs) registro[a.Key] = a.Value;
        Spans.Add(registro);
        Pilha.Push(registro);
        return new SpanAberto(this, registro);
    }

    public void Avancar(double segundos)   // simula o tempo gasto pela etapa
    {
        Relogio += segundos;
    }
}

static void Main()
{
    var t = new Tracer();
    using (t.Span("requisicao", Mapa("usuario", "u-17")))
    {
        using (t.Span("buscar", Mapa("top_k", 20)))
        {
            t.Avancar(0.12);
        }
        using (var s = t.Span("llm", Mapa("modelo", "principal", "tokens_entrada", 1900, "tokens_saida", 40)))
        {
            t.Avancar(0.9);
            s.Registro["finish_reason"] = "tool_use";
        }
        using (t.Span("tool", Mapa("nome_tool", "consultar_pedido")))
        {
            t.Avancar(0.3);
        }
        using (var s = t.Span("llm", Mapa("modelo", "principal", "tokens_entrada", 2300, "tokens_saida", 120)))
        {
            t.Avancar(1.2);
            s.Registro["finish_reason"] = "end";
        }
    }

    var ocultos = new HashSet<string> { "nome", "nivel", "inicio", "duracao" };
    foreach (var r in t.Spans)
    {
        var extras = r.Where(e => !ocultos.Contains(e.Key))
            .Select(e => $"'{e.Key}': " + (e.Value is string ? $"'{e.Value}'" : e.Value.ToString()));
        string recuo = new string(' ', 2 * (int)r["nivel"]);
        string duracao = FixoPar((double)r["duracao"], 2);
        Console.WriteLine($"{recuo}{r["nome"],-12} {duracao}s {{{string.Join(", ", extras)}}}");
    }
}
```

```go
import (
	"fmt"
	"strconv"
	"strings"
)

// Campo guarda a ordem de inserção, que um map do Go não guarda
type Campo struct {
	Chave string
	Valor any
}

type Registro struct {
	Nome    string
	Nivel   int
	Inicio  float64
	Duracao float64
	Extras  []Campo
}

type Tracer struct {
	relogio float64
	pilha   []*Registro
	spans   []*Registro
}

// round() do Python: o strconv arredonda o valor exato do double, com empate para o par
func arred(x float64, casas int) float64 {
	r, _ := strconv.ParseFloat(strconv.FormatFloat(x, 'f', casas, 64), 64)
	return r
}

// o "with" vira defer: span devolve a função que o fecha, e o defer a chama mesmo em caso de panic
func (t *Tracer) span(nome string, attrs ...Campo) (*Registro, func()) {
	registro := &Registro{Nome: nome, Nivel: len(t.pilha), Inicio: t.relogio, Extras: attrs}
	t.spans = append(t.spans, registro)
	t.pilha = append(t.pilha, registro)
	return registro, func() {
		registro.Duracao = arred(t.relogio-registro.Inicio, 2)
		t.pilha = t.pilha[:len(t.pilha)-1]
	}
}

func (t *Tracer) avancar(segundos float64) { // simula o tempo gasto pela etapa
	t.relogio += segundos
}

// imita o repr() do Python para imprimir o dicionário de extras
func repr(extras []Campo) string {
	partes := []string{}
	for _, c := range extras {
		if texto, ok := c.Valor.(string); ok {
			partes = append(partes, fmt.Sprintf("'%s': '%s'", c.Chave, texto))
		} else {
			partes = append(partes, fmt.Sprintf("'%s': %v", c.Chave, c.Valor))
		}
	}
	return "{" + strings.Join(partes, ", ") + "}"
}

func main() {
	t := &Tracer{}
	func() {
		_, fim := t.span("requisicao", Campo{"usuario", "u-17"})
		defer fim()
		func() {
			_, fim := t.span("buscar", Campo{"top_k", 20})
			defer fim()
			t.avancar(0.12)
		}()
		func() {
			s, fim := t.span("llm", Campo{"modelo", "principal"}, Campo{"tokens_entrada", 1900}, Campo{"tokens_saida", 40})
			defer fim()
			t.avancar(0.9)
			s.Extras = append(s.Extras, Campo{"finish_reason", "tool_use"})
		}()
		func() {
			_, fim := t.span("tool", Campo{"nome_tool", "consultar_pedido"})
			defer fim()
			t.avancar(0.3)
		}()
		func() {
			s, fim := t.span("llm", Campo{"modelo", "principal"}, Campo{"tokens_entrada", 2300}, Campo{"tokens_saida", 120})
			defer fim()
			t.avancar(1.2)
			s.Extras = append(s.Extras, Campo{"finish_reason", "end"})
		}()
```

## O que registrar em cada chamada ao modelo

- Modelo e versão, provedor, parâmetros (temperatura, limite de saída).
- **Versão do prompt** (id do template, não só o texto final).
- Tokens de entrada, de saída e em cache; custo calculado.
- Latência total e **tempo até o primeiro token**.
- **Motivo de término** (fim natural, limite de tokens, tool call, bloqueio por política). Muitas respostas cortadas indicam limite de saída baixo.
- Tool calls com argumentos e resultados; ids dos trechos recuperados com seus scores.
- Identificadores de usuário, sessão e funcionalidade, para agregar.

## Métricas e alertas

Dos traces saem as métricas operacionais: latência p50/p95/p99, taxa de erro e de fallback, custo por funcionalidade e por cliente, tokens por requisição, taxa de respostas cortadas, taxa de "não sei" e de escalonamento para humano.

```csharp
// o Python arredonda o valor binário exato do double, com empate para o par. Aqui o valor exato
// (mantissa * 2^expoente) é montado em decimal, com 28 dígitos, e arredondado para o par.
static string FixoPar(double x, int casas)
{
    long bits = BitConverter.DoubleToInt64Bits(Math.Abs(x));
    int campo = (int)(bits >> 52);
    decimal d = bits & 0xFFFFFFFFFFFFFL;
    if (campo > 0) d += 1L << 52;
    for (int e = Math.Max(campo, 1) - 1075; e > 0; e--) d *= 2;
    for (int e = Math.Max(campo, 1) - 1075; e < 0; e++) d /= 2;
    if (x < 0) d = -d;
    return Math.Round(d, casas, MidpointRounding.ToEven).ToString("F" + casas, CultureInfo.InvariantCulture);
}
```

## Qualidade em produção

Métricas operacionais não dizem se as respostas estão boas. Complete com:

- **Feedback explícito** (polegar, nota) e implícito (usuário reformulou a pergunta, copiou a resposta, abriu um ticket depois).
- **Avaliação online por amostragem:** um juiz LLM avalia uma fração dos traces (fidelidade, adequação), gerando tendências e alertas.
- **Revisão humana** de amostras e de todos os casos com feedback negativo, alimentando o conjunto de avaliação offline.

<Callout type="warning" title="Logs com prompts são dados sensíveis">
Prompts e respostas contêm dados pessoais e segredos de negócio. Mascare PII antes de gravar, restrinja quem pode ler traces, defina retenção e respeite pedidos de exclusão. Observabilidade não pode virar o maior vazamento do sistema.
</Callout>
