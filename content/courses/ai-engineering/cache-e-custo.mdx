Um protótipo com LLM custa centavos por dia. O mesmo produto com 100 mil usuários pode custar mais que a equipe que o mantém, e responder em 8 segundos quando o usuário tolera 2. Custo e latência em sistemas com LLM seguem regras próprias: você paga por token de entrada e de saída, a latência é dominada pela geração e cada chamada extra no pipeline soma tempo. As alavancas principais são: enviar menos tokens, gerar menos tokens, usar modelos menores quando possível e não recalcular o que já foi calculado.

## A conta

```text
custo por requisição = tokens_entrada × preço_entrada + tokens_saída × preço_saída
latência ≈ fila + tempo até o primeiro token (TTFT) + tokens_saída × tempo por token
```

Tokens de saída costumam ser bem mais caros e mais lentos que os de entrada. Um RAG que envia 6 mil tokens de contexto e gera 300 tem o custo dominado pela entrada; um agente que escreve relatórios longos, pela saída. Meça antes de otimizar. O programa usa preços **hipotéticos** para comparar estratégias.

## Três tipos de cache

**1. Cache exato.** Chave = hash do prompt normalizado (modelo, parâmetros, mensagens). Se a mesma requisição chegar de novo, devolve a resposta salva. Ótimo para perguntas repetidas idênticas, classificações de textos já vistos e testes. Cuidado com dados por usuário na chave.

**2. Cache de prompt (do provedor).** Muitos provedores reaproveitam o processamento de um **prefixo** idêntico entre chamadas (system prompt longo, definições de ferramentas, documentos fixos). O prefixo em cache é cobrado com desconto e reduz o tempo até o primeiro token. Para aproveitar, deixe as partes estáveis no início e as variáveis (pergunta, data, nome do usuário) no fim. Um timestamp no começo do system prompt invalida o cache em toda chamada.

**3. Cache semântico.** Embeda a pergunta e procura perguntas anteriores **parecidas**; acima de um limiar de similaridade, devolve a resposta salva. Aumenta muito a taxa de acerto, mas pode devolver a resposta de uma pergunta que só parecia igual.

```python
import math, re
from collections import Counter

def emb(t):
    return Counter(re.findall(r"\w+", t.lower()))

def cos(a, b):
    num = sum(a[k] * b[k] for k in a)
    den = math.sqrt(sum(v * v for v in a.values())) * math.sqrt(sum(v * v for v in b.values()))
    return num / den if den else 0.0

class CacheSemantico:
    def __init__(self, limiar):
        self.limiar, self.itens = limiar, []

    def buscar(self, pergunta):
        e = emb(pergunta)
        melhor = max(self.itens, key=lambda it: cos(e, it[0]), default=None)
        if melhor and cos(e, melhor[0]) >= self.limiar:
            return melhor[1], round(cos(e, melhor[0]), 2)
        return None, None

    def guardar(self, pergunta, resposta):
        self.itens.append((emb(pergunta), resposta))

cache = CacheSemantico(limiar=0.7)
cache.guardar("qual o horário de atendimento da loja", "Das 9h às 18h.")
cache.guardar("como cancelar minha assinatura", "Em Configurações > Assinatura.")

for p in ["qual o horário de atendimento da loja?",
          "qual o horário de atendimento da loja no domingo",
          "como cancelar meu pedido"]:
    resp, score = cache.buscar(p)
    print(f"{p!r}: {'HIT ' + str(score) + ' -> ' + resp if resp else 'MISS'}")
```

```javascript
  const norma = (c) => Math.sqrt([...c.values()].reduce((s, v) => s + v * v, 0));
```

```java
import java.math.*;
import java.util.*;
import java.util.regex.*;

// UNICODE_CHARACTER_CLASS faz o \w aceitar letras acentuadas, como no Python
static final Pattern PALAVRA = Pattern.compile("\\w+", Pattern.UNICODE_CHARACTER_CLASS);

static Map<String, Integer> emb(String t) {
    Map<String, Integer> cont = new LinkedHashMap<>();
    Matcher m = PALAVRA.matcher(t.toLowerCase(Locale.ROOT));
    while (m.find()) cont.merge(m.group(), 1, Integer::sum);
    return cont;
}

static double norma(Map<String, Integer> c) {
    double s = 0;
    for (int v : c.values()) s += v * v;
    return Math.sqrt(s);
}

static double cos(Map<String, Integer> a, Map<String, Integer> b) {
    double num = 0;
    for (Map.Entry<String, Integer> e : a.entrySet()) num += e.getValue() * b.getOrDefault(e.getKey(), 0);
    double den = norma(a) * norma(b);
    return den != 0 ? num / den : 0.0;
}

// round() do Python: arredonda o valor exato do double, com empate para o par
static double arred(double x, int casas) {
    return new BigDecimal(x).setScale(casas, RoundingMode.HALF_EVEN).doubleValue();
}

class Item {
    final Map<String, Integer> vetor;
    final String resposta;
    Item(Map<String, Integer> vetor, String resposta) { this.vetor = vetor; this.resposta = resposta; }
}

class Resultado {
    final String resposta;
    final double score;
    Resultado(String resposta, double score) { this.resposta = resposta; this.score = score; }
}

class CacheSemantico {
    final double limiar;
    final List<Item> itens = new ArrayList<>();

    CacheSemantico(double limiar) { this.limiar = limiar; }

    // devolve null no lugar do (None, None) do Python
    Resultado buscar(String pergunta) {
        Map<String, Integer> e = emb(pergunta);
        // como o max do Python: no empate fica o primeiro
        Item melhor = null;
        for (Item it : itens) {
            if (melhor == null || cos(e, it.vetor) > cos(e, melhor.vetor)) melhor = it;
        }
        if (melhor != null && cos(e, melhor.vetor) >= limiar) {
            return new Resultado(melhor.resposta, arred(cos(e, melhor.vetor), 2));
        }
        return null;
    }

    void guardar(String pergunta, String resposta) {
        itens.add(new Item(emb(pergunta), resposta));
    }
}

public static void main(String[] args) {
    CacheSemantico cache = new CacheSemantico(0.7);
    cache.guardar("qual o horário de atendimento da loja", "Das 9h às 18h.");
    cache.guardar("como cancelar minha assinatura", "Em Configurações > Assinatura.");

    String[] perguntas = {
        "qual o horário de atendimento da loja?",
        "qual o horário de atendimento da loja no domingo",
        "como cancelar meu pedido",
    };
    for (String p : perguntas) {
        Resultado r = cache.buscar(p);
        System.out.println("'" + p + "': " + (r != null ? "HIT " + r.score + " -> " + r.resposta : "MISS"));
    }
}
```

```cpp
#include <cctype>

#include <cstdio>
#include <cstdlib>
#include <map>
#include <optional>
#include <string>
#include <utility>
#include <vector>

// imita re.findall(r"\w+", t.lower()): o std::regex não entende UTF-8, então a
// tokenização é à mão; bytes >= 0x80 (pedaços de letras acentuadas) contam como letra
map<string, int> emb(const string& t) {
    map<string, int> cont;
    string atual;
    for (unsigned char c : t) {
        if (isalnum(c) || c == '_' || c >= 0x80) {
            atual += (char)(c < 0x80 ? tolower(c) : c);
        } else if (!atual.empty()) {
            cont[atual]++;
            atual.clear();
        }
    }
    if (!atual.empty()) cont[atual]++;
    return cont;
}

double norma(const map<string, int>& c) {
    double s = 0;
    for (const auto& [k, v] : c) s += v * v;
    return sqrt(s);
}

double cos(const map<string, int>& a, const map<string, int>& b) {
    double num = 0;
    for (const auto& [k, v] : a) {
        auto it = b.find(k);
        if (it != b.end()) num += v * it->second;
    }
    double den = norma(a) * norma(b);
    return den ? num / den : 0.0;
}

}

    if (s.find_first_of(".e") == string::npos) s += ".0";
    return s;
}

class CacheSemantico {
    double limiar;
    vector<pair<map<string, int>, string>> itens;
```

```csharp
// o \w do .NET já aceita letras acentuadas, como o do Python
static Dictionary<string, int> Emb(string t) {
    var cont = new Dictionary<string, int>();
    foreach (Match m in Regex.Matches(t.ToLowerInvariant(), @"\w+")) {
        cont.TryGetValue(m.Value, out int n);
        cont[m.Value] = n + 1;
    }
    return cont;
}

static double Norma(Dictionary<string, int> c) {
    return Math.Sqrt(c.Values.Sum(v => (double)v * v));
}

static double Cos(Dictionary<string, int> a, Dictionary<string, int> b) {
    double num = 0;
    foreach (var e in a) {
        b.TryGetValue(e.Key, out int vb);
        num += e.Value * vb;
    }
    double den = Norma(a) * Norma(b);
    return den != 0 ? num / den : 0.0;
}

// round() do Python: parte da forma binária exata (G17) e arredonda com empate para o par
static double Arred(double x, int casas) {
    decimal d = decimal.Parse(x.ToString("G17", Inv), NumberStyles.Float, Inv);
    return (double)Math.Round(d, casas, MidpointRounding.ToEven);
}

// str(float) do Python: 0.88, 1.0

    return x == Math.Floor(x) ? x.ToString("F1", Inv) : x.ToString("R", Inv);
}
```

```go
import (

	"math"
	"regexp"
	"strconv"
	"strings"

// o \w do Go só conhece ASCII; \p{L}\p{N} aceita letras acentuadas, como o \w do Python
var palavra = regexp.MustCompile(`[\p{L}\p{N}_]+`)

func emb(t string) map[string]int {
	cont := map[string]int{}
	for _, x := range palavra.FindAllString(strings.ToLower(t), -1) {
		cont[x]++
	}
	return cont
}

func norma(c map[string]int) float64 {
	s := 0
	for _, v := range c {
		s += v * v
	}
	return math.Sqrt(float64(s))
}

func cos(a, b map[string]int) float64 {
	num := 0
	for k, v := range a {
		num += v * b[k]
	}
	den := norma(a) * norma(b)
	if den == 0 {
		return 0.0
	}
	return float64(num) / den
}

// round() do Python: o strconv arredonda o valor exato do double, com empate para o par
func arred(x float64, casas int) float64 {
	r, _ := strconv.ParseFloat(strconv.FormatFloat(x, 'f', casas, 64), 64)
	return r
}

// str(float) do Python: 0.88, 1.0
func pyFloat(x float64) string {
	s := strconv.FormatFloat(x, 'f', -1, 64)
	if !strings.Contains(s, ".") {
		s += ".0"
	}
	return s
}

type item struct {
	vetor    map[string]int
	resposta string
}

type CacheSemantico struct {
	limiar float64
	itens  []item
}

// o terceiro valor diz se houve acerto, no lugar do (None, None) do Python
func (c *CacheSemantico) buscar(pergunta string) (string, float64, bool) {
	e := emb(pergunta)
	// como o max do Python: no empate fica o primeiro
	var melhor *item
	for i := range c.itens {
		if melhor == nil || cos(e, c.itens[i].vetor) > cos(e, melhor.vetor) {
			melhor = &c.itens[i]
		}
	}
	if melhor != nil && cos(e, melhor.vetor) >= c.limiar {
		return melhor.resposta, arred(cos(e, melhor.vetor), 2), true
	}
	return "", 0, false
}

	c.itens = append(c.itens, item{emb(pergunta), resposta})
}
```

Repare no segundo caso: "no domingo" muda a resposta, mas a similaridade alta faz o cache devolver o horário de dias úteis. Esse é o risco central do cache semântico. Calibre o limiar com pares rotulados, restrinja-o a perguntas sem contexto pessoal e defina expiração para respostas que envelhecem.

<Callout type="warning" title="Cache e isolamento">
Uma resposta gerada com dados do usuário A nunca pode ser servida ao usuário B. Inclua tenant, usuário ou nível de permissão na chave do cache, ou só use cache compartilhado em respostas que não dependem de dados privados.
</Callout>

## Outras alavancas

- **Roteamento por dificuldade:** um modelo pequeno (ou um classificador) atende as perguntas fáceis e escala as difíceis para o grande.
- **Menos contexto:** menos trechos recuperados, histórico resumido, resultados de ferramentas enxutos.
- **Menos saída:** peça respostas concisas e use limite de tokens de saída.
- **Streaming:** não reduz o tempo total, mas o usuário começa a ler após o primeiro token, o que melhora muito a percepção.
- **Paralelismo:** chamadas independentes (busca lexical e vetorial, várias ferramentas) ao mesmo tempo.
- **APIs em lote:** para trabalho que pode esperar (classificar um backlog), processamento assíncrono costuma ter desconto.
