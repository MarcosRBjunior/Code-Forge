Um LLM sozinho só produz texto. Ele não sabe o saldo do cliente, não consegue consultar o status de um pedido nem abrir um chamado. **Tool calling** (ou function calling) é o mecanismo que liga o modelo ao mundo: você descreve funções disponíveis, o modelo decide quando chamar uma delas e com quais argumentos, e **a sua aplicação** executa a chamada e devolve o resultado. O modelo nunca executa nada; ele só pede.

## O protocolo

```text
app ──► LLM:  mensagens + lista de ferramentas (nome, descrição, JSON Schema dos argumentos)
LLM ──► app:  "chame consultar_pedido com {"id": "A-981"}"     (uma tool call estruturada)
app:          valida os argumentos, executa a função de verdade
app ──► LLM:  mensagens + resultado da ferramenta (associado ao id da chamada)
LLM ──► app:  resposta final em texto (ou outra tool call)
```

A definição de uma ferramenta tem três partes: um **nome**, uma **descrição** (que o modelo lê para decidir quando usá-la) e um **esquema** dos parâmetros:

```json
{
  "name": "consultar_pedido",
  "description": "Busca status e previsão de entrega de um pedido pelo id. Use quando o cliente perguntar sobre um pedido específico.",
  "input_schema": {
    "type": "object",
    "properties": {
      "pedido_id": { "type": "string", "description": "Id no formato A-123" }
    },
    "required": ["pedido_id"]
  }
}
```

Os nomes dos campos variam entre provedores, mas a ideia é a mesma em todos. A descrição é parte do prompt: escreva-a como escreveria documentação para um colega, dizendo quando usar e quando **não** usar a ferramenta.

## Despachando chamadas

Do lado da aplicação, tool calling é um despachante: um registro de funções, validação de argumentos e tratamento de erro. O programa implementa isso com JSON e a stdlib.

```python
import json

PEDIDOS = {"A-981": {"status": "em transito", "previsao": "2026-11-03"}}

def consultar_pedido(pedido_id):
    if pedido_id not in PEDIDOS:
        raise LookupError(f"pedido {pedido_id} não encontrado")
    return PEDIDOS[pedido_id]

def calcular_frete(cep, peso_kg):
    return {"valor": round(15 + 2.5 * peso_kg, 2)}

FERRAMENTAS = {
    "consultar_pedido": (consultar_pedido, {"pedido_id": str}),
    "calcular_frete": (calcular_frete, {"cep": str, "peso_kg": (int, float)}),
}

def despachar(chamada_json):
    chamada = json.loads(chamada_json)
    nome, args = chamada["name"], chamada["arguments"]
    if nome not in FERRAMENTAS:
        return {"erro": f"ferramenta desconhecida: {nome}"}
    funcao, esquema = FERRAMENTAS[nome]
    faltando = [p for p in esquema if p not in args]
    errados = [p for p, t in esquema.items() if p in args and not isinstance(args[p], t)]
    if faltando or errados:
        return {"erro": f"argumentos inválidos: faltando={faltando} tipo_errado={errados}"}
    try:
        return {"resultado": funcao(**args)}
    except Exception as e:  # o erro volta para o modelo, não derruba a aplicação
        return {"erro": str(e)}

chamadas = [
    '{"name": "consultar_pedido", "arguments": {"pedido_id": "A-981"}}',
    '{"name": "calcular_frete", "arguments": {"cep": "01310-000", "peso_kg": "2"}}',
    '{"name": "consultar_pedido", "arguments": {"pedido_id": "Z-000"}}',
    '{"name": "cancelar_tudo", "arguments": {}}',
]
for c in chamadas:
    print(despachar(c))
```

```javascript
  if (!(pedido_id in PEDIDOS)) {

// o toFixed arredonda o valor exato do double, mas leva o empate para cima (0.125 -> "0.13");
// o Python leva o empate exato para o par ("0.12"). Com 30 casas a mais, os dígitos exatos mostram o empate.
function fixoPar(x, casas) {
  const exato = Math.abs(x).toFixed(casas + 30);
  const corte = exato.length - 30;
  if (exato.slice(corte) !== "5" + "0".repeat(29)) return x.toFixed(casas);
  const baixo = exato.slice(0, casas > 0 ? corte : corte - 1); // sem o 5 (e sem o ponto, se casas = 0)
  const par = Number(baixo[baixo.length - 1]) % 2 === 0 ? baixo : Math.abs(x).toFixed(casas);
  return (x < 0 ? "-" : "") + par;
}

function calcularFrete({ cep, peso_kg }) {
  return { valor: Number(fixoPar(15 + 2.5 * peso_kg, 2)) };
}

const FERRAMENTAS = {
  consultar_pedido: [consultarPedido, { pedido_id: "string" }],
  calcular_frete: [calcularFrete, { cep: "string", peso_kg: "number" }],
};

function repr(v) {
  if (typeof v === "string") return v.includes("'") ? `"${v}"` : `'${v}'`;
  if (Array.isArray(v)) return `[${v.map(repr).join(", ")}]`;
  if (typeof v === "object") return `{${Object.entries(v).map(([k, x]) => `'${k}': ${repr(x)}`).join(", ")}}`;
  return String(v);
}

    return { resultado: funcao(args) };
  } catch (e) {  // o erro volta para o modelo, não derruba a aplicação
    return { erro: e.message };

}
```

```java
import java.util.*;
import java.util.function.Function;

// JSON mínimo: a biblioteca padrão não traz parser (em produção: Jackson ou Gson).
// Objeto -> LinkedHashMap (guarda a ordem, como o dict), lista -> ArrayList, inteiro -> Long, real -> Double.
class Json {
    private final String s;
    private int i = 0;

    private Json(String s) { this.s = s; }

    static Object loads(String texto) {
        Json p = new Json(texto);
        Object v = p.valor();
        p.pular();
        if (p.i < texto.length()) throw new IllegalArgumentException("Extra data");
        return v;
    }

    private void pular() { while (i < s.length() && Character.isWhitespace(s.charAt(i))) i++; }

    private boolean ver(char c) { pular(); return i < s.length() && s.charAt(i) == c; }

    private void esperar(char c) {
        if (!ver(c)) throw new IllegalArgumentException("Expecting '" + c + "' delimiter");
        i++;
    }

    private Object valor() {
        if (ver('{')) {
            i++;
            Map<String, Object> m = new LinkedHashMap<>();
            if (ver('}')) { i++; return m; }
            while (true) {
                String chave = texto();
                esperar(':');
                m.put(chave, valor());
                if (!ver(',')) break;
                i++;
            }
            esperar('}');
            return m;
        }
        if (ver('[')) {
            i++;
            List<Object> l = new ArrayList<>();
            if (ver(']')) { i++; return l; }
            while (true) {
                l.add(valor());
                if (!ver(',')) break;
                i++;
            }
            esperar(']');
            return l;
        }
        if (ver('"')) return texto();
        for (String lit : new String[]{"true", "false", "null"}) {
            if (s.startsWith(lit, i)) { i += lit.length(); return lit.equals("null") ? null : lit.equals("true"); }
        }
        int ini = i;
        while (i < s.length() && "+-0123456789.eE".indexOf(s.charAt(i)) >= 0) i++;
        String num = s.substring(ini, i);
        if (num.isEmpty()) throw new IllegalArgumentException("Expecting value");
        if (num.matches("-?\\d+")) return Long.parseLong(num);
        return Double.parseDouble(num);
    }

    private String texto() {
        if (!ver('"')) throw new IllegalArgumentException("Expecting property name enclosed in double quotes");
        i++;
        StringBuilder sb = new StringBuilder();
        while (s.charAt(i) != '"') {
            char c = s.charAt(i++);
            if (c != '\\') { sb.append(c); continue; }
            char e = s.charAt(i++);
            if (e == 'n') sb.append('\n');
            else if (e == 'u') { sb.append((char) Integer.parseInt(s.substring(i, i + 4), 16)); i += 4; }
            else sb.append(e);  // \" \\ \/
        }
        i++;
        return sb.toString();
    }

    // como o json.dumps do Python: separadores ", " e ": ", e ensure_ascii (acentos viram \\uXXXX)
    static String dumps(Object v) {
        if (v == null) return "null";
        if (v instanceof String) {
            StringBuilder sb = new StringBuilder("\"");
            for (char c : ((String) v).toCharArray()) {
                if (c == '"' || c == '\\') sb.append('\\').append(c);
                else if (c == '\n') sb.append("\\n");
                else if (c < 0x20 || c > 0x7e) sb.append(String.format("\\u%04x", (int) c));
                else sb.append(c);
            }
            return sb.append('"').toString();
        }
        if (v instanceof Map) {
            StringJoiner j = new StringJoiner(", ", "{", "}");
            for (Map.Entry<?, ?> e : ((Map<?, ?>) v).entrySet()) j.add(dumps(e.getKey()) + ": " + dumps(e.getValue()));
            return j.toString();
        }
        if (v instanceof List) {
            StringJoiner j = new StringJoiner(", ", "[", "]");
            for (Object x : (List<?>) v) j.add(dumps(x));
            return j.toString();
        }
        return String.valueOf(v);  // números e booleanos
    }
}

// imita o repr() do Python para imprimir dicionários e listas
static String repr(Object v) {
    if (v == null) return "None";
    if (v instanceof Boolean) return (Boolean) v ? "True" : "False";
    if (v instanceof String) return ((String) v).contains("'") ? "\"" + v + "\"" : "'" + v + "'";
    if (v instanceof Map) {
        StringJoiner j = new StringJoiner(", ", "{", "}");
        for (Map.Entry<?, ?> e : ((Map<?, ?>) v).entrySet()) j.add(repr(e.getKey()) + ": " + repr(e.getValue()));
        return j.toString();
    }
    if (v instanceof List) {
        StringJoiner j = new StringJoiner(", ", "[", "]");
        for (Object x : (List<?>) v) j.add(repr(x));
        return j.toString();
    }
    return String.valueOf(v);
}

// dicionário que guarda a ordem de inserção, como o dict do Python
static Map<String, Object> mapa(Object... kv) {
    Map<String, Object> m = new LinkedHashMap<>();
    for (int i = 0; i < kv.length; i += 2) m.put((String) kv[i], kv[i + 1]);
    return m;
}

@SuppressWarnings("unchecked")
static Map<String, Object> obj(Object v) { return (Map<String, Object>) v; }

static final Map<String, Object> PEDIDOS = mapa("A-981", mapa("status", "em transito", "previsao", "2026-11-03"));

// os argumentos chegam num mapa (o papel do **kwargs do Python)
static Object consultarPedido(Map<String, Object> args) {
    String pedidoId = (String) args.get("pedido_id");
    if (!PEDIDOS.containsKey(pedidoId)) {
        throw new NoSuchElementException("pedido " + pedidoId + " não encontrado");
    }
    return PEDIDOS.get(pedidoId);
}

// round() do Python: arredonda o valor exato do double, com empate para o par
static double arred(double x, int casas) {
    return new java.math.BigDecimal(x).setScale(casas, java.math.RoundingMode.HALF_EVEN).doubleValue();
}

static Object calcularFrete(Map<String, Object> args) {
    double pesoKg = ((Number) args.get("peso_kg")).doubleValue();
    return mapa("valor", arred(15 + 2.5 * pesoKg, 2));
}

// o papel do isinstance: cada parâmetro diz quais classes aceita
static class Ferramenta {
    Function<Map<String, Object>, Object> funcao;
    Map<String, List<Class<?>>> esquema;
    Ferramenta(Function<Map<String, Object>, Object> funcao, Map<String, List<Class<?>>> esquema) {
        this.funcao = funcao;
        this.esquema = esquema;
    }
}

static boolean eInstancia(Object v, List<Class<?>> tipos) {
    for (Class<?> t : tipos) if (t.isInstance(v)) return true;
    return false;
}

static final Map<String, Ferramenta> FERRAMENTAS = new LinkedHashMap<>();
static {
    Map<String, List<Class<?>>> paraPedido = new LinkedHashMap<>();
    paraPedido.put("pedido_id", List.of(String.class));
    FERRAMENTAS.put("consultar_pedido", new Ferramenta(a -> consultarPedido(a), paraPedido));
    Map<String, List<Class<?>>> paraFrete = new LinkedHashMap<>();
    paraFrete.put("cep", List.of(String.class));
    paraFrete.put("peso_kg", List.of(Long.class, Double.class));
    FERRAMENTAS.put("calcular_frete", new Ferramenta(a -> calcularFrete(a), paraFrete));
}

static Map<String, Object> despachar(String chamadaJson) {
    Map<String, Object> chamada = obj(Json.loads(chamadaJson));
    String nome = (String) chamada.get("name");
    Map<String, Object> args = obj(chamada.get("arguments"));
    if (!FERRAMENTAS.containsKey(nome)) {
        return mapa("erro", "ferramenta desconhecida: " + nome);
    }
    Ferramenta f = FERRAMENTAS.get(nome);
    List<Object> faltando = new ArrayList<>(), errados = new ArrayList<>();
    for (Map.Entry<String, List<Class<?>>> p : f.esquema.entrySet()) {
        if (!args.containsKey(p.getKey())) faltando.add(p.getKey());
        else if (!eInstancia(args.get(p.getKey()), p.getValue())) errados.add(p.getKey());
    }
    if (!faltando.isEmpty() || !errados.isEmpty()) {
        return mapa("erro", "argumentos inválidos: faltando=" + repr(faltando) + " tipo_errado=" + repr(errados));
    }
    try {
        return mapa("resultado", f.funcao.apply(args));
    } catch (RuntimeException e) {  // o erro volta para o modelo, não derruba a aplicação
        return mapa("erro", e.getMessage());
    }
}
```

```cpp
// valor dinâmico, como o que o json.loads do Python devolve: o C++ não traz um tipo assim
struct Valor {
    enum Tipo { NULO, BOOL, INT, REAL, TEXTO, LISTA, OBJETO } tipo = NULO;
    bool b = false;
    long long i = 0;
    double d = 0;
    string s;
    vector<Valor> itens;    // LISTA, ou os valores de um OBJETO
    vector<string> chaves;  // OBJETO: chaves na ordem de inserção, como o dict do Python

    Valor() {}
    Valor(bool v) : tipo(BOOL), b(v) {}
    Valor(int v) : tipo(INT), i(v) {}
    Valor(long long v) : tipo(INT), i(v) {}
    Valor(double v) : tipo(REAL), d(v) {}
    Valor(const char* v) : tipo(TEXTO), s(v) {}
    Valor(const string& v) : tipo(TEXTO), s(v) {}
    Valor(initializer_list<pair<const char*, Valor>> kv) : tipo(OBJETO) {
        for (auto& [k, v] : kv) definir(k, v);
    }
    static Valor objeto() { Valor r; r.tipo = OBJETO; return r; }
    static Valor lista(vector<Valor> v) { Valor r; r.tipo = LISTA; r.itens = move(v); return r; }

    bool tem(const string& k) const { return find(chaves.begin(), chaves.end(), k) != chaves.end(); }
    const Valor& operator[](const string& k) const {
        for (size_t j = 0; j < chaves.size(); j++) if (chaves[j] == k) return itens[j];
        throw out_of_range("KeyError: " + k);
    }
    void definir(const string& k, const Valor& v) {
        for (size_t j = 0; j < chaves.size(); j++) if (chaves[j] == k) { itens[j] = v; return; }
        chaves.push_back(k);
        itens.push_back(v);
    }
};

// JSON mínimo: a biblioteca padrão não traz parser (em produção: nlohmann/json)
struct LeitorJson {
    const string& s;
    size_t i = 0;

    void pular() { while (i < s.size() && isspace((unsigned char)s[i])) i++; }
    bool ver(char c) { pular(); return i < s.size() && s[i] == c; }
    void esperar(char c) {
        if (!ver(c)) throw invalid_argument(string("Expecting '") + c + "' delimiter");
        i++;
    }

    string texto() {
        if (!ver('"')) throw invalid_argument("Expecting property name enclosed in double quotes");
        i++;
        string r;
        while (s[i] != '"') {
            char c = s[i++];
            if (c != '\\') { r += c; continue; }
            char e = s[i++];
            if (e == 'n') r += '\n';
            else if (e == 'u') {  // \uXXXX volta a ser UTF-8
                unsigned cp = stoul(s.substr(i, 4), nullptr, 16);
                i += 4;
                if (cp < 0x80) r += char(cp);
                else if (cp < 0x800) r += char(0xC0 | cp >> 6), r += char(0x80 | (cp & 0x3F));
                else r += char(0xE0 | cp >> 12), r += char(0x80 | (cp >> 6 & 0x3F)), r += char(0x80 | (cp & 0x3F));
            } else r += e;  // \" \\ \/
        }
        i++;
        return r;
    }

    Valor valor() {
        if (ver('{')) {
            i++;
            Valor m = Valor::objeto();
            if (ver('}')) { i++; return m; }
            while (true) {
                string chave = texto();
                esperar(':');
                m.definir(chave, valor());
                if (!ver(',')) break;
                i++;
            }
            esperar('}');
            return m;
        }
        if (ver('[')) {
            i++;
            Valor l = Valor::lista({});
            if (ver(']')) { i++; return l; }
            while (true) {
                l.itens.push_back(valor());
                if (!ver(',')) break;
                i++;
            }

        }

        size_t ini = i;

        string num = s.substr(ini, i - ini);

// como o json.dumps do Python: separadores ", " e ": ", e ensure_ascii (acentos viram \uXXXX)
string dumps(const Valor& v) {
    switch (v.tipo) {
        case Valor::NULO: return "null";
        case Valor::BOOL: return v.b ? "true" : "false";
        case Valor::INT: return to_string(v.i);
        case Valor::REAL: return numero(v.d);
        case Valor::TEXTO: {
            string r = "\"";
            for (size_t k = 0; k < v.s.size(); k++) {
                unsigned char c = v.s[k];
                if (c == '"' || c == '\\') r += '\\', r += c;
                else if (c == '\n') r += "\\n";
                else if (c >= 0x80) {  // decodifica o UTF-8 para escrever o código do caractere
                    int n = c >= 0xE0 ? 2 : 1;
                    unsigned cp = c & (n == 2 ? 0x0F : 0x1F);
                    for (int m = 0; m < n; m++) cp = (cp << 6) | (v.s[++k] & 0x3F);
                    char esc[8];
                    snprintf(esc, sizeof esc, "\\u%04x", cp);
                    r += esc;
                } else r += c;
            }
            return r + "\"";
        }
        case Valor::LISTA: {
            string r = "[";
            for (size_t j = 0; j < v.itens.size(); j++) r += (j ? ", " : "") + dumps(v.itens[j]);
            return r + "]";
        }
        default: {
            string r = "{";
            for (size_t j = 0; j < v.chaves.size(); j++)
                r += (j ? ", " : "") + dumps(Valor(v.chaves[j])) + ": " + dumps(v.itens[j]);
            return r + "}";
        }
    }
}

        case Valor::TEXTO: return v.s.find("'") != string::npos ? "\"" + v.s + "\"" : "'" + v.s + "'";
        case Valor::LISTA: {

            for (size_t j = 0; j < v.itens.size(); j++) r += (j ? ", " : "") + repr(v.itens[j]);

        }
```

```csharp
static string FixoPar(double x, int casas)
{
    long bits = BitConverter.DoubleToInt64Bits(Math.Abs(x));
    int campo = (int)(bits >> 52);
    decimal d = bits & 0xFFFFFFFFFFFFFL;
    if (campo > 0) d += 1L << 52;
    for (int e = Math.Max(campo, 1) - 1075; e > 0; e--) d *= 2;
    for (int e = Math.Max(campo, 1) - 1075; e < 0; e++) d /= 2;
    if (x < 0) d = -d;
    return Math.Round(d, casas, MidpointRounding.ToEven).ToString("F" + casas, System.Globalization.CultureInfo.InvariantCulture);
}
```

```cpp
string dumps(const Valor& v) {

        case Valor::NULO: return "null";
        case Valor::BOOL: return v.b ? "true" : "false";
        case Valor::INT: return to_string(v.i);
        case Valor::REAL: return numero(v.d);
        case Valor::TEXTO: {
            string r = "\"";
            for (size_t k = 0; k < v.s.size(); k++) {
                unsigned char c = v.s[k];
                if (c == '"' || c == '\\') r += '\\', r += c;
                else if (c == '\n') r += "\\n";
                else if (c >= 0x80) {  // decodifica o UTF-8 para escrever o código do caractere
                    int n = c >= 0xE0 ? 2 : 1;
                    unsigned cp = c & (n == 2 ? 0x0F : 0x1F);
                    for (int m = 0; m < n; m++) cp = (cp << 6) | (v.s[++k] & 0x3F);
                    char esc[8];
                    snprintf(esc, sizeof esc, "\\u%04x", cp);
                    r += esc;
                } else r += c;
            }
            return r + "\"";
        }
        case Valor::LISTA: {
            string r = "[";
            for (size_t j = 0; j < v.itens.size(); j++) r += (j ? ", " : "") + dumps(v.itens[j]);
            return r + "]";
        }
        default: {
            string r = "{";
            for (size_t j = 0; j < v.chaves.size(); j++)
                r += (j ? ", " : "") + dumps(Valor(v.chaves[j])) + ": " + dumps(v.itens[j]);
            return r + "}";
        }
    }
}
```

```go
	"fmt"

type ToolCall struct {
	ID        string
	Name      string
	Arguments string // JSON em texto, como nas APIs de verdade

	Role       string
	Content    string
	ToolCall   *ToolCall
	ToolCallID string

	ToolCall *ToolCall
	Text     string

	Status   string `json:"status"`
	Previsao string `json:"previsao"`

// imita o json.dumps do Python no único formato impresso aqui: o json.Marshal não põe espaço depois de ":"
func dumpsArgumento(chave, valor string) string {
	k, _ := json.Marshal(chave)
	v, _ := json.Marshal(valor)
	return fmt.Sprintf("{%s: %s}", k, v)
}

// os argumentos chegam num map (o papel do **kwargs do Python)
func consultarPedido(args map[string]any) Pedido {
	return Pedido{"em transito", "3 de novembro"}
}

func llmFalso(mensagens []Mensagem) RespostaLlm {
	ultima := mensagens[len(mensagens)-1]
	if ultima.Role == "user" {
		return RespostaLlm{ToolCall: &ToolCall{"call_1", "consultar_pedido", dumpsArgumento("pedido_id", "A-981")}}
	}
	var dado Pedido
	json.Unmarshal([]byte(ultima.Content), &dado)
	return RespostaLlm{Text: fmt.Sprintf("Seu pedido está %s, com previsão para %s.", dado.Status, dado.Previsao)}
}

func main() {
	mensagens := []Mensagem{{Role: "user", Content: "Cadê meu pedido A-981?"}}
	resposta := llmFalso(mensagens)
	if resposta.ToolCall != nil {
		call := resposta.ToolCall
		fmt.Println("modelo pediu:", call.Name, call.Arguments)
		var args map[string]any
		json.Unmarshal([]byte(call.Arguments), &args)
		resultado, _ := json.Marshal(consultarPedido(args))
		mensagens = append(mensagens, Mensagem{Role: "assistant", ToolCall: call})
		mensagens = append(mensagens, Mensagem{Role: "tool", ToolCallID: call.ID, Content: string(resultado)})
		resposta = llmFalso(mensagens)
```

Quando o modelo pode pedir várias ferramentas e encadear chamadas até terminar, você tem um agente, assunto do próximo capítulo.

## Boas práticas

- **Poucas ferramentas, bem descritas.** Dezenas de ferramentas parecidas confundem a escolha e ocupam contexto. Agrupe ou carregue sob demanda.
- **Argumentos validados sempre**, mesmo com esquema imposto pelo provedor. Trate o modelo como um cliente não confiável da sua API.
- **Resultados enxutos:** devolva só os campos úteis, não o JSON inteiro de 5 mil tokens do backend.
- **Erros acionáveis:** "pedido_id deve ter formato A-123" ajuda o modelo a se corrigir; um stack trace, não.
- **Chamadas paralelas:** muitos provedores permitem várias tool calls numa resposta; execute-as em paralelo quando forem independentes.

<Callout type="warning" title="Ações com efeito colateral">
Ferramentas que escrevem (pagar, enviar e-mail, apagar) precisam de autorização com as permissões do usuário, idempotência e, para ações sensíveis, confirmação humana. O modelo pode ser induzido por prompt injection a chamar a ferramenta errada.
</Callout>

## Na entrevista

Deixe claro que o modelo só gera uma chamada estruturada e que a execução, validação e autorização ficam na aplicação. Mostre o ciclo pedido → execução → resultado → resposta, e fale de descrições, validação, erros devolvidos ao modelo e cuidados com ações destrutivas.
