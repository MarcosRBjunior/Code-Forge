Seu cliente quer um assistente que responda sobre os manuais internos da empresa, a política de férias atualizada ontem e o histórico de tickets. Nada disso está nos pesos do modelo, e mesmo que estivesse, mudaria toda semana. **RAG** (Retrieval-Augmented Generation, geração aumentada por recuperação) resolve isso com uma ideia simples: antes de chamar o LLM, busque os trechos relevantes nos seus dados e coloque-os no prompt. O modelo deixa de responder "de memória" e passa a responder com base em evidências que você controla.

## As duas fases

```text
INGESTÃO (offline)
documentos ──► limpeza ──► chunking ──► embeddings ──► índice (vetorial + lexical)
                                                       + metadados (fonte, data, permissão)

CONSULTA (online)
pergunta ──► (reescrita) ──► busca no índice ──► re-ranking ──► top-k trechos
                                                                    │
            resposta com citações ◄── LLM ◄── prompt: instruções + trechos + pergunta
```

A ingestão roda quando os documentos mudam. A consulta roda a cada pergunta e precisa ser rápida. Os próximos capítulos detalham chunking, recuperação e re-ranking; aqui está o esqueleto inteiro em miniatura.

import math, re
from collections import Counter

DOCS = {
    "ferias.md#1": "Ferias podem ser divididas em ate tres periodos, um deles com pelo menos 14 dias.",
    "ferias.md#2": "O pedido de ferias deve ser feito no portal com 30 dias de antecedencia.",
    "reembolso.md#1": "Despesas de viagem sao reembolsadas em ate 10 dias uteis apos a aprovacao.",
    "vpn.md#1": "Para acessar a VPN instale o cliente corporativo e use o token do celular.",
}

def vetor(texto):
    return Counter(re.findall(r"\w+", texto.lower()))

def cosseno(a, b):
    num = sum(a[t] * b[t] for t in a)
    den = math.sqrt(sum(v * v for v in a.values())) * math.sqrt(sum(v * v for v in b.values()))
    return num / den if den else 0.0

INDICE = {doc_id: vetor(texto) for doc_id, texto in DOCS.items()}

def recuperar(pergunta, k=2):
    q = vetor(pergunta)
    ranking = sorted(INDICE, key=lambda d: -cosseno(q, INDICE[d]))
    return [(d, round(cosseno(q, INDICE[d]), 2)) for d in ranking[:k]]

def montar_prompt(pergunta, trechos):
    contexto = "\n".join(f"[{d}] {DOCS[d]}" for d, _ in trechos)
    return (
        "Responda usando apenas os trechos abaixo e cite a fonte entre colchetes.\n"
        "Se a resposta nao estiver nos trechos, diga que nao sabe.\n\n"
        f"{contexto}\n\nPergunta: {pergunta}"
    )

pergunta = "Com quantos dias de antecedencia peco ferias?"
trechos = recuperar(pergunta)
print(trechos)
print(montar_prompt(pergunta, trechos))

import java.math.*;
import java.util.*;
import java.util.regex.*;

// UNICODE_CHARACTER_CLASS faz o \w aceitar letras acentuadas, como no Python
static final Pattern PALAVRA = Pattern.compile("\\w+", Pattern.UNICODE_CHARACTER_CLASS);

static final Map<String, String> DOCS = new LinkedHashMap<>();
static {
    DOCS.put("ferias.md#1", "Ferias podem ser divididas em ate tres periodos, um deles com pelo menos 14 dias.");
    DOCS.put("ferias.md#2", "O pedido de ferias deve ser feito no portal com 30 dias de antecedencia.");
    DOCS.put("reembolso.md#1", "Despesas de viagem sao reembolsadas em ate 10 dias uteis apos a aprovacao.");
    DOCS.put("vpn.md#1", "Para acessar a VPN instale o cliente corporativo e use o token do celular.");
}

static Map<String, Integer> vetor(String texto) {
    Map<String, Integer> cont = new LinkedHashMap<>();
    Matcher m = PALAVRA.matcher(texto.toLowerCase(Locale.ROOT));
    while (m.find()) cont.merge(m.group(), 1, Integer::sum);
    return cont;
}

static double norma(Map<String, Integer> c) {
    double s = 0;
    for (int v : c.values()) s += v * v;
    return Math.sqrt(s);
}

static double cosseno(Map<String, Integer> a, Map<String, Integer> b) {
    double num = 0;
    for (Map.Entry<String, Integer> e : a.entrySet()) num += e.getValue() * b.getOrDefault(e.getKey(), 0);
    double den = norma(a) * norma(b);
    return den != 0 ? num / den : 0.0;
}

// round() do Python: arredonda o valor exato do double, com empate para o par
static double arred(double x, int casas) {
    return new BigDecimal(x).setScale(casas, RoundingMode.HALF_EVEN).doubleValue();
}

static final Map<String, Map<String, Integer>> INDICE = new LinkedHashMap<>();
static {
    for (Map.Entry<String, String> e : DOCS.entrySet()) INDICE.put(e.getKey(), vetor(e.getValue()));
}

static List<Map.Entry<String, Double>> recuperar(String pergunta, int k) {
    Map<String, Integer> q = vetor(pergunta);
    List<String> ranking = new ArrayList<>(INDICE.keySet());
    // List.sort é estável, como o sorted do Python
    ranking.sort(Comparator.comparingDouble(d -> -cosseno(q, INDICE.get(d))));
    List<Map.Entry<String, Double>> saida = new ArrayList<>();
    for (String d : ranking.subList(0, k)) saida.add(new AbstractMap.SimpleEntry<>(d, arred(cosseno(q, INDICE.get(d)), 2)));
    return saida;
}

static String montarPrompt(String pergunta, List<Map.Entry<String, Double>> trechos) {
    List<String> linhas = new ArrayList<>();
    for (Map.Entry<String, Double> t : trechos) linhas.add("[" + t.getKey() + "] " + DOCS.get(t.getKey()));
    String contexto = String.join("\n", linhas);
    return "Responda usando apenas os trechos abaixo e cite a fonte entre colchetes.\n"
        + "Se a resposta nao estiver nos trechos, diga que nao sabe.\n\n"
        + contexto + "\n\nPergunta: " + pergunta;
}

public static void main(String[] args) {

vector<pair<string, string>> DOCS = {
    {"ferias.md#1", "Ferias podem ser divididas em ate tres periodos, um deles com pelo menos 14 dias."},
    {"ferias.md#2", "O pedido de ferias deve ser feito no portal com 30 dias de antecedencia."},

// imita re.findall(r"\w+", texto.lower()): o std::regex não entende UTF-8, então a
// tokenização é à mão; bytes >= 0x80 (pedaços de letras acentuadas) contam como letra
vector<string> palavras(const string& texto) {
    vector<string> saida;
    string atual;
    for (unsigned char c : texto) {
        if (isalnum(c) || c == '_' || c >= 0x80) {
            atual += (char)(c < 0x80 ? tolower(c) : c);
        } else if (!atual.empty()) {
            saida.push_back(atual);
            atual.clear();
        }
    }
    if (!atual.empty()) saida.push_back(atual);
    return saida;
}

map<string, int> vetor(const string& texto) {
    map<string, int> cont;
    for (const string& t : palavras(texto)) cont[t]++;
    return cont;
}

double norma(const map<string, int>& c) {
    double s = 0;
    for (const auto& [t, v] : c) s += v * v;
    return sqrt(s);
}

double cosseno(const map<string, int>& a, const map<string, int>& b) {
    double num = 0;
    for (const auto& [t, v] : a) {
        auto it = b.find(t);
        if (it != b.end()) num += v * it->second;
    }
    double den = norma(a) * norma(b);
    return den ? num / den : 0.0;
}

// round() do Python: o printf arredonda o valor exato do double, com empate para o par
double arred(double x, int casas) {
    char texto[64];
    snprintf(texto, sizeof texto, "%.*f", casas, x);
    return strtod(texto, nullptr);
}

// repr de float do Python: 0.57, 1.0
string pyFloat(double x) {
    char texto[64];
    snprintf(texto, sizeof texto, "%.15g", x);
    string s = texto;
    if (s.find_first_of(".e") == string::npos) s += ".0";
    return s;
}

map<string, map<string, int>> INDICE;

string doc(const string& id) {
    for (const auto& [d, texto] : DOCS)
        if (d == id) return texto;
    return "";
}

vector<pair<string, double>> recuperar(const string& pergunta, size_t k = 2) {
    map<string, int> q = vetor(pergunta);
    vector<string> ranking;
    for (const auto& [d, texto] : DOCS) ranking.push_back(d);
    // stable_sort mantém a ordem original nos empates, como o sorted do Python
    stable_sort(ranking.begin(), ranking.end(), [&](const string& x, const string& y) {
        return cosseno(q, INDICE[x]) > cosseno(q, INDICE[y]);
    });
    vector<pair<string, double>> saida;
    for (size_t i = 0; i < k && i < ranking.size(); i++)
        saida.push_back({ranking[i], arred(cosseno(q, INDICE[ranking[i]]), 2)});
    return saida;
}

string montarPrompt(const string& pergunta, const vector<pair<string, double>>& trechos) {
    string contexto;
    for (size_t i = 0; i < trechos.size(); i++) {
        if (i) contexto += "\n";
        contexto += "[" + trechos[i].first + "] " + doc(trechos[i].first);
    }
    return "Responda usando apenas os trechos abaixo e cite a fonte entre colchetes.\n"
           "Se a resposta nao estiver nos trechos, diga que nao sabe.\n\n" +
           contexto + "\n\nPergunta: " + pergunta;
}

int main() {
    for (const auto& [d, texto] : DOCS) INDICE[d] = vetor(texto);

    string pergunta = "Com quantos dias de antecedencia peco ferias?";
    auto trechos = recuperar(pergunta);
    string lista = "[";
    for (size_t i = 0; i < trechos.size(); i++)
        lista += (i ? ", " : "") + string("('") + trechos[i].first + "', " + pyFloat(trechos[i].second) + ")";
    printf("%s]\n", lista.c_str());
    printf("%s\n", montarPrompt(pergunta, trechos).c_str());
}

static Dictionary<string, int> Vetor(string texto) {
    var cont = new Dictionary<string, int>();
    foreach (Match m in Regex.Matches(texto.ToLowerInvariant(), @"\w+")) {
        cont.TryGetValue(m.Value, out int n);
        cont[m.Value] = n + 1;
    }
    return cont;
}

static double Norma(Dictionary<string, int> c) {
    return Math.Sqrt(c.Values.Sum(v => (double)v * v));
}

static double Cosseno(Dictionary<string, int> a, Dictionary<string, int> b) {
    double num = 0;
    foreach (var e in a) {
        b.TryGetValue(e.Key, out int vb);
        num += e.Value * vb;
    }
    double den = Norma(a) * Norma(b);
    return den != 0 ? num / den : 0.0;
}

static Dictionary<string, Dictionary<string, int>> INDICE =
    DOCS.ToDictionary(e => e.Key, e => Vetor(e.Value));

static List<KeyValuePair<string, double>> Recuperar(string pergunta, int k = 2) {
    var q = Vetor(pergunta);
    // OrderBy é estável, como o sorted do Python
    var ranking = INDICE.Keys.OrderBy(d => -Cosseno(q, INDICE[d])).ToList();
    return ranking.Take(k)
        .Select(d => new KeyValuePair<string, double>(d, Math.Round(Cosseno(q, INDICE[d]), 2, MidpointRounding.ToEven)))
        .ToList();
}

static string MontarPrompt(string pergunta, List<KeyValuePair<string, double>> trechos) {
    string contexto = string.Join("\n", trechos.Select(t => $"[{t.Key}] {DOCS[t.Key]}"));
    return "Responda usando apenas os trechos abaixo e cite a fonte entre colchetes.\n"
        + "Se a resposta nao estiver nos trechos, diga que nao sabe.\n\n"
        + $"{contexto}\n\nPergunta: {pergunta}";
}

static void Main() {
    string pergunta = "Com quantos dias de antecedencia peco ferias?";

// fatia de pares: o dict do Python mantém a ordem de inserção, o map do Go não
var docs = []struct{ id, texto string }{
	{"ferias.md#1", "Ferias podem ser divididas em ate tres periodos, um deles com pelo menos 14 dias."},
	{"ferias.md#2", "O pedido de ferias deve ser feito no portal com 30 dias de antecedencia."},
	{"reembolso.md#1", "Despesas de viagem sao reembolsadas em ate 10 dias uteis apos a aprovacao."},
	{"vpn.md#1", "Para acessar a VPN instale o cliente corporativo e use o token do celular."},
}

// o \w do Go só conhece ASCII; \p{L}\p{N} aceita letras acentuadas, como o \w do Python
var palavra = regexp.MustCompile(`[\p{L}\p{N}_]+`)

func vetor(texto string) map[string]int {
	cont := map[string]int{}
	for _, t := range palavra.FindAllString(strings.ToLower(texto), -1) {
		cont[t]++
	}
	return cont
}

func norma(c map[string]int) float64 {
	s := 0
	for _, v := range c {
		s += v * v
	}
	return math.Sqrt(float64(s))
}

func cosseno(a, b map[string]int) float64 {
	num := 0
	for t, v := range a {
		num += v * b[t]
	}
	den := norma(a) * norma(b)
	if den == 0 {
		return 0.0
	}
	return float64(num) / den
}

// round() do Python: o strconv arredonda o valor exato do double, com empate para o par
func arred(x float64, casas int) float64 {
	r, _ := strconv.ParseFloat(strconv.FormatFloat(x, 'f', casas, 64), 64)
	return r
}

var indice = map[string]map[string]int{}

func doc(id string) string {
	for _, d := range docs {
		if d.id == id {
			return d.texto
		}
	}
	return ""
}

type trecho struct {
	doc   string
	score float64
}

func recuperar(pergunta string, k int) []trecho {
	q := vetor(pergunta)
	ranking := []string{}
	for _, d := range docs {
		ranking = append(ranking, d.id)
	}
	// SliceStable mantém a ordem original nos empates, como o sorted do Python
	sort.SliceStable(ranking, func(i, j int) bool {
		return cosseno(q, indice[ranking[i]]) > cosseno(q, indice[ranking[j]])
	})
	saida := []trecho{}
	for _, d := range ranking[:k] {
		saida = append(saida, trecho{d, arred(cosseno(q, indice[d]), 2)})
	}
	return saida
}

func montarPrompt(pergunta string, trechos []trecho) string {
	linhas := []string{}
	for _, t := range trechos {
		linhas = append(linhas, fmt.Sprintf("[%s] %s", t.doc, doc(t.doc)))
	}
	contexto := strings.Join(linhas, "\n")
	return "Responda usando apenas os trechos abaixo e cite a fonte entre colchetes.\n" +
		"Se a resposta nao estiver nos trechos, diga que nao sabe.\n\n" +
		contexto + "\n\nPergunta: " + pergunta
}

func main() {
	for _, d := range docs {
		indice[d.id] = vetor(d.texto)
	}

	pergunta := "Com quantos dias de antecedencia peco ferias?"
	trechos := recuperar(pergunta, 2)
	partes := []string{}
	for _, t := range trechos {
		partes = append(partes, fmt.Sprintf("('%s', %s)", t.doc, strconv.FormatFloat(t.score, 'f', -1, 64)))
	}
	fmt.Println("[" + strings.Join(partes, ", ") + "]")
	fmt.Println(montarPrompt(pergunta, trechos))
}

## Respostas fundamentadas e o direito de dizer "não sei"

RAG reduz alucinação, mas não a elimina. Três práticas fazem diferença:

- **Instruir a usar só o contexto** e a admitir quando a informação não está lá.
- **Citações:** pedir que cada afirmação aponte o id do trecho permite ao usuário conferir e a você avaliar automaticamente.
- **Limiar de relevância:** se nem o melhor trecho é parecido com a pergunta, nem chame o modelo para responder; devolva uma mensagem de "não encontrei".

O modelo falso abaixo é extrativo: devolve a frase do contexto que mais se parece com a pergunta, com a fonte, ou recusa quando a recuperação é fraca.

import math, re
from collections import Counter

DOCS = {
    "ferias.md#2": "O pedido de ferias deve ser feito no portal com 30 dias de antecedencia.",
    "vpn.md#1": "Para acessar a VPN instale o cliente corporativo e use o token do celular.",
}

STOP = {"o", "a", "de", "do", "da", "com", "e", "qual", "como", "para", "deve", "ser"}

def vetor(texto):
    return Counter(t for t in re.findall(r"\w+", texto.lower()) if t not in STOP)

def cosseno(a, b):
    num = sum(a[t] * b[t] for t in a)
    den = math.sqrt(sum(v * v for v in a.values())) * math.sqrt(sum(v * v for v in b.values()))
    return num / den if den else 0.0

def responder(pergunta, limiar=0.25):
    q = vetor(pergunta)
    melhor = max(DOCS, key=lambda d: cosseno(q, vetor(DOCS[d])))
    score = cosseno(q, vetor(DOCS[melhor]))
    if score < limiar:
        return f"Nao encontrei isso na base (melhor score {score:.2f})."
    return f"{DOCS[melhor]} [{melhor}]"

print(responder("como acessar a VPN de casa?"))
print(responder("qual o valor do vale refeicao?"))

static {

    DOCS.put("vpn.md#1", "Para acessar a VPN instale o cliente corporativo e use o token do celular.");

    "o", "a", "de", "do", "da", "com", "e", "qual", "como", "para", "deve", "ser"));

static Map<String, Integer> vetor(String texto) {
    Map<String, Integer> cont = new LinkedHashMap<>();
    Matcher m = PALAVRA.matcher(texto.toLowerCase(Locale.ROOT));
    while (m.find()) {
        if (!STOP.contains(m.group())) cont.merge(m.group(), 1, Integer::sum);
    }
    return cont;
}

static double norma(Map<String, Integer> c) {
    double s = 0;
    for (int v : c.values()) s += v * v;

}

}

// imita re.findall(r"\w+", texto.lower()): o std::regex não entende UTF-8, então a
// tokenização é à mão; bytes >= 0x80 (pedaços de letras acentuadas) contam como letra
vector<string> palavras(const string& texto) {
    vector<string> saida;
    string atual;
    for (unsigned char c : texto) {
        if (isalnum(c) || c == '_' || c >= 0x80) {
            atual += (char)(c < 0x80 ? tolower(c) : c);
        } else if (!atual.empty()) {
            saida.push_back(atual);
            atual.clear();
        }
    }
    if (!atual.empty()) saida.push_back(atual);
    return saida;
}

map<string, int> vetor(const string& texto) {
    map<string, int> cont;
    for (const string& t : palavras(texto))
        if (!STOP.count(t)) cont[t]++;
    return cont;
}

double norma(const map<string, int>& c) {
    double s = 0;
    for (const auto& [t, v] : c) s += v * v;
    return sqrt(s);
}

double cosseno(const map<string, int>& a, const map<string, int>& b) {
    double num = 0;
    for (const auto& [t, v] : a) {
        auto it = b.find(t);
        if (it != b.end()) num += v * it->second;
    }
    double den = norma(a) * norma(b);
    return den ? num / den : 0.0;
}

    size_t melhor = 0;

        if (cosseno(q, vetor(DOCS[i].second)) > cosseno(q, vetor(DOCS[melhor].second))) melhor = i;

## RAG, contexto longo ou fine-tuning?

| Abordagem | Quando usar | Limitações |
| --- | --- | --- |
| RAG | Conhecimento que muda, grande, privado, com controle de acesso e necessidade de citar fonte | Qualidade depende da recuperação; mais componentes para operar |
| Contexto longo (tudo no prompt) | Poucos documentos, consultas raras, protótipos | Custo e latência por chamada; perda no meio |
| Fine-tuning | Ensinar formato, estilo, vocabulário ou tarefa específica | Ruim para injetar fatos que mudam; difícil atualizar e citar |

As abordagens se combinam: um modelo ajustado para seguir seu formato pode responder com base em trechos recuperados.

<Callout type="warning" title="A maioria das falhas é de recuperação">
Quando um RAG responde errado, o culpado mais frequente não é o LLM: o trecho certo não foi recuperado, foi cortado no chunking ou ficou abaixo de trechos parecidos. Avalie a recuperação separadamente da geração antes de trocar de modelo.
</Callout>

## Armadilhas

- **Permissões:** filtre por quem pode ver cada documento **na busca**, não depois da resposta. Um trecho que entra no prompt pode vazar.
- **Dados desatualizados:** sem reindexação incremental, o assistente cita a política antiga.
- **Documentos sujos:** cabeçalhos repetidos, tabelas quebradas e PDFs mal extraídos poluem o índice.
