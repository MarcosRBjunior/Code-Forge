Em software tradicional, um teste diz se a função retorna 42. Com LLMs, a saída é texto livre, varia entre execuções e "correto" muitas vezes é questão de grau. Sem avaliação, todo ajuste vira opinião: alguém testa cinco perguntas, gosta do resultado e publica um prompt que piora 15% dos casos. **Avaliação (evals)** é o que transforma um protótipo impressionante num produto confiável, e é o assunto que mais separa candidatos em entrevistas de AI engineering.

## O conjunto de avaliação

Tudo começa com um **dataset de casos**: entradas reais (ou realistas) com o resultado esperado ou critérios de aceitação. Fontes boas: logs de produção anonimizados, perguntas que deram problema, casos difíceis criados pela equipe e exemplos sintéticos gerados por LLM e revisados por humanos. Algumas dezenas de casos bem escolhidos já pegam regressões grosseiras; centenas dão confiança estatística por categoria.

Cubra: casos típicos, casos de borda, perguntas sem resposta na base (o sistema deve dizer "não sei"), tentativas de abuso e cada categoria importante do produto.

## Tipos de métrica

| Tipo | Exemplos | Quando usar |
| --- | --- | --- |
| Determinística | Correspondência exata, regex, JSON válido, F1 de tokens, a resposta contém o número certo | Extração, classificação, formato, respostas curtas |
| Recuperação | Recall@k, MRR, nDCG | Etapa de busca do RAG |
| LLM como juiz | Nota de 1 a 5 com rubrica, comparação par a par, verificação de fidelidade | Respostas abertas, tom, completude |
| Humana | Revisão de especialistas, notas de usuários | Calibrar o juiz, casos de alto risco |
| Online | Taxa de resolução, polegar para cima/baixo, retenção, escalonamento para humano | Medir impacto real após publicar |

Prefira métricas determinísticas sempre que possível: são baratas, rápidas e reprodutíveis. O programa compara duas versões de um sistema com correspondência exata e F1 de tokens, que dá crédito parcial.

```python
from collections import Counter

def normalizar(t):
    return t.lower().replace(".", "").replace(",", "").split()

def exato(pred, ref):
    return float(normalizar(pred) == normalizar(ref))

def f1(pred, ref):
    p, r = normalizar(pred), normalizar(ref)
    comuns = sum((Counter(p) & Counter(r)).values())
    if comuns == 0:
        return 0.0
    precisao, revocacao = comuns / len(p), comuns / len(r)
    return 2 * precisao * revocacao / (precisao + revocacao)

casos = [
    ("prazo de reembolso?", "10 dias úteis"),
    ("aceita pix?", "sim"),
    ("horário de suporte?", "das 8h às 18h"),
]
saidas = {
    "v1": ["em até 10 dias úteis", "Sim, aceitamos.", "das 9h às 17h"],
    "v2": ["10 dias úteis", "sim", "das 8h às 18h"],
}
for versao, preds in saidas.items():
    em = sum(exato(p, ref) for p, (_, ref) in zip(preds, casos)) / len(casos)
    f = sum(f1(p, ref) for p, (_, ref) in zip(preds, casos)) / len(casos)
    print(f"{versao}: exato={em:.2f} f1={f:.2f}")
```

```csharp
using System.Collections.Generic;
using System.Globalization;
using System.Linq;

static string[] Normalizar(string t) {
    return t.ToLowerInvariant().Replace(".", "").Replace(",", "")
        .Split((char[])null, StringSplitOptions.RemoveEmptyEntries);
}

static double Exato(string pred, string refe) {
    return Normalizar(pred).SequenceEqual(Normalizar(refe)) ? 1.0 : 0.0;
}

static double F1(string pred, string refe) {
    string[] p = Normalizar(pred), r = Normalizar(refe);
    // Counter(p) & Counter(r): fica o mínimo das contagens de cada palavra
    var cp = p.GroupBy(x => x).ToDictionary(g => g.Key, g => g.Count());
    var cr = r.GroupBy(x => x).ToDictionary(g => g.Key, g => g.Count());
    int comuns = cp.Sum(e => Math.Min(e.Value, cr.ContainsKey(e.Key) ? cr[e.Key] : 0));
    if (comuns == 0) return 0.0;
    double precisao = (double)comuns / p.Length, revocacao = (double)comuns / r.Length;
    return 2 * precisao * revocacao / (precisao + revocacao);
}
```

```go
func normalizar(t string) []string {
	t = strings.ReplaceAll(strings.ReplaceAll(strings.ToLower(t), ".", ""), ",", "")
	return strings.Fields(t)
}

func exato(pred, ref string) float64 {
	p, r := normalizar(pred), normalizar(ref)
	if len(p) != len(r) {
		return 0.0
	}
	for i := range p {
		if p[i] != r[i] {
			return 0.0
		}
	}
	return 1.0
}

func f1(pred, ref string) float64 {
	p, r := normalizar(pred), normalizar(ref)
	// Counter(p) & Counter(r): fica o mínimo das contagens de cada palavra
	cp, cr := map[string]int{}, map[string]int{}
	for _, x := range p {
		cp[x]++
	}
	for _, x := range r {
		cr[x]++
	}
	comuns := 0
	for t, n := range cp {
		if cr[t] < n {
			n = cr[t]
		}
		comuns += n

		return 0.0
	}
	precisao, revocacao := float64(comuns)/float64(len(p)), float64(comuns)/float64(len(r))

}
```

## LLM como juiz

Para respostas abertas, você usa outro modelo para avaliar, com uma **rubrica** explícita ("a resposta cita a fonte? contradiz o contexto? responde à pergunta?"). Funciona bem quando calibrado, mas tem vieses conhecidos:

- **Posição:** em comparações A versus B, tende a preferir uma das posições. Rode as duas ordens.
- **Verbosidade:** tende a preferir respostas longas.
- **Autopreferência:** pode favorecer textos do próprio modelo.

Calibre o juiz comparando as notas dele com notas humanas numa amostra, e prefira perguntas binárias e específicas ("a resposta contém alguma afirmação ausente do contexto?") a notas genéricas de 1 a 10.

Em RAG, a métrica mais importante costuma ser a **fidelidade** (faithfulness): cada afirmação da resposta tem suporte no contexto recuperado? Um verificador de brinquedo, que checa se cada frase da resposta tem a maioria das palavras presente no contexto, mostra a ideia (um juiz real usaria um LLM ou um modelo de inferência textual):

```python
import re

def palavras(t):
    return set(re.findall(r"\w+", t.lower()))

def fidelidade(resposta, contexto, minimo=0.6):
    ctx = palavras(contexto)
    frases = [f for f in re.split(r"(?<=\.)\s+", resposta) if f]
    resultado = []
    for frase in frases:
        p = palavras(frase)
        cobertura = len(p & ctx) / len(p)
        resultado.append((frase, round(cobertura, 2), cobertura >= minimo))
    return resultado

contexto = "O plano anual custa 480 reais. O cancelamento é gratuito nos primeiros 7 dias."
resposta = "O plano anual custa 480 reais. O cancelamento é gratuito em 7 dias. Inclui suporte 24 horas por telefone."
for frase, cob, ok in fidelidade(resposta, contexto):
    print(f"{'OK ' if ok else 'SEM SUPORTE'} {cob:.2f} | {frase}")
```

```java
import java.math.*;
import java.util.*;
import java.util.regex.*;

// UNICODE_CHARACTER_CLASS faz o \w aceitar letras acentuadas, como no Python
static final Pattern PALAVRA = Pattern.compile("\\w+", Pattern.UNICODE_CHARACTER_CLASS);

static Set<String> palavras(String t) {
    Set<String> s = new HashSet<>();
    Matcher m = PALAVRA.matcher(t.toLowerCase(Locale.ROOT));
    while (m.find()) s.add(m.group());
    return s;
}

// round() do Python: arredonda o valor exato do double, com empate para o par
static double arred(double x, int casas) {
    return new BigDecimal(x).setScale(casas, RoundingMode.HALF_EVEN).doubleValue();
}

static class Avaliada {
    final String frase;
    final double cobertura;
    final boolean ok;
    Avaliada(String frase, double cobertura, boolean ok) { this.frase = frase; this.cobertura = cobertura; this.ok = ok; }
}

static List<Avaliada> fidelidade(String resposta, String contexto, double minimo) {
    Set<String> ctx = palavras(contexto);
    List<Avaliada> resultado = new ArrayList<>();
    for (String frase : resposta.split("(?<=\\.)\\s+")) {
        if (frase.isEmpty()) continue;
        Set<String> p = palavras(frase);
        Set<String> comuns = new HashSet<>(p);
        comuns.retainAll(ctx);
        double cobertura = (double) comuns.size() / p.size();
        resultado.add(new Avaliada(frase, arred(cobertura, 2), cobertura >= minimo));
    }
    return resultado;
}

public static void main(String[] args) {
    String contexto = "O plano anual custa 480 reais. O cancelamento é gratuito nos primeiros 7 dias.";
    String resposta = "O plano anual custa 480 reais. O cancelamento é gratuito em 7 dias. Inclui suporte 24 horas por telefone.";
    for (Avaliada a : fidelidade(resposta, contexto, 0.6)) {
        // o valor já vem arredondado; BigDecimal evita o arredondamento para cima do %.2f
        String cob = new BigDecimal(a.cobertura).setScale(2, RoundingMode.HALF_EVEN).toPlainString();
        System.out.println((a.ok ? "OK " : "SEM SUPORTE") + " " + cob + " | " + a.frase);
    }
}
```

```cpp
        if (isalnum(c) || c == '_' || c >= 0x80) {
            atual += (char)(c < 0x80 ? tolower(c) : c);
        } else if (!atual.empty()) {
            saida.insert(atual);
            atual.clear();
        }
    }
    if (!atual.empty()) saida.insert(atual);
    return saida;
}

// round() do Python: o printf arredonda o valor exato do double, com empate para o par
double arred(double x, int casas) {
    char texto[64];
    snprintf(texto, sizeof texto, "%.*f", casas, x);
    return strtod(texto, nullptr);
}

// re.split(r"(?<=\.)\s+", ...): corta nos espaços que vêm logo depois de um ponto
vector<string> frasesDe(const string& s) {
    vector<string> frases;
    string atual;
    for (size_t i = 0; i < s.size(); i++) {
        if (isspace((unsigned char)s[i]) && i > 0 && s[i - 1] == '.') {
            while (i + 1 < s.size() && isspace((unsigned char)s[i + 1])) i++;
            frases.push_back(atual);
            atual.clear();
        } else {
            atual += s[i];
        }
    }
    frases.push_back(atual);
    return frases;
}

vector<tuple<string, double, bool>> fidelidade(const string& resposta, const string& contexto, double minimo = 0.6) {
    set<string> ctx = palavras(contexto);
    vector<tuple<string, double, bool>> resultado;
    for (const string& frase : frasesDe(resposta)) {
        if (frase.empty()) continue;
        set<string> p = palavras(frase);
        int comuns = 0;
        for (const string& w : p) comuns += ctx.count(w);
        double cobertura = (double)comuns / p.size();
        resultado.push_back({frase, arred(cobertura, 2), cobertura >= minimo});
    }
    return resultado;
}

int main() {
    string contexto = "O plano anual custa 480 reais. O cancelamento é gratuito nos primeiros 7 dias.";
    string resposta = "O plano anual custa 480 reais. O cancelamento é gratuito em 7 dias. Inclui suporte 24 horas por telefone.";
    for (const auto& [frase, cob, ok] : fidelidade(resposta, contexto))
        printf("%s %.2f | %s\n", ok ? "OK " : "SEM SUPORTE", cob, frase.c_str());
}
```

```go
// o \w do Go só conhece ASCII; \p{L}\p{N} aceita letras acentuadas, como o \w do Python
var palavra = regexp.MustCompile(`[\p{L}\p{N}_]+`)

func palavras(t string) map[string]bool {
	s := map[string]bool{}
	for _, w := range palavra.FindAllString(strings.ToLower(t), -1) {
		s[w] = true
	}
	return s
}

// round() do Python: o strconv arredonda o valor exato do double, com empate para o par
func arred(x float64, casas int) float64 {
	r, _ := strconv.ParseFloat(strconv.FormatFloat(x, 'f', casas, 64), 64)
	return r
}

// o RE2 do Go não tem lookbehind: no lugar de re.split(r"(?<=\.)\s+", ...),
// acha os trechos "\.\s+" e corta logo depois do ponto
var fimDeFrase = regexp.MustCompile(`\.\s+`)

func frasesDe(s string) []string {
	frases := []string{}
	inicio := 0
	for _, m := range fimDeFrase.FindAllStringIndex(s, -1) {
		frases = append(frases, s[inicio:m[0]+1])
		inicio = m[1]
	}
	return append(frases, s[inicio:])
}

type avaliada struct {
	frase     string
	cobertura float64
	ok        bool
}

func fidelidade(resposta, contexto string, minimo float64) []avaliada {
	ctx := palavras(contexto)
	resultado := []avaliada{}
	for _, frase := range frasesDe(resposta) {
		if frase == "" {
			continue
		}
		p := palavras(frase)
		comuns := 0
		for w := range p {
			if ctx[w] {
				comuns++
			}
		}
		cobertura := float64(comuns) / float64(len(p))
		resultado = append(resultado, avaliada{frase, arred(cobertura, 2), cobertura >= minimo})
	}
	return resultado
}

func main() {
	contexto := "O plano anual custa 480 reais. O cancelamento é gratuito nos primeiros 7 dias."
	resposta := "O plano anual custa 480 reais. O cancelamento é gratuito em 7 dias. Inclui suporte 24 horas por telefone."
	for _, a := range fidelidade(resposta, contexto, 0.6) {
		marca := "SEM SUPORTE"
		if a.ok {
			marca = "OK "
		}
		fmt.Printf("%s %.2f | %s\n", marca, a.cobertura, a.frase)
	}
}
```

## Avaliação no ciclo de desenvolvimento

```text
mudança (prompt, modelo, chunking) ──► roda evals offline ──► compara com a versão atual
         ▲                                                          │ melhorou e não regrediu?
         │                                                          ▼
   novos casos ◄── falhas e feedback de produção ◄── publica (A/B ou canário)
```

Rode as evals no CI a cada mudança relevante, acompanhe métricas por categoria (uma média boa pode esconder uma categoria que piorou) e transforme cada bug de produção num caso novo.

<Callout type="tip" title="Olhe os dados">
Nenhuma métrica substitui ler saídas reais. Separe um tempo para revisar amostras de falhas e acertos: é assim que você descobre os critérios que deveriam virar métricas.
</Callout>
