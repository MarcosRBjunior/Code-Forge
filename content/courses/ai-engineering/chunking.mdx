Você não indexa um manual de 80 páginas como um vetor só: o embedding viraria uma média borrada de todos os assuntos, e o trecho devolvido não caberia no prompt. Também não indexa frase por frase, porque cada frase isolada perde o contexto ("ele deve ser renovado anualmente": quem é "ele"?). **Chunking** é a decisão de como cortar documentos em pedaços recuperáveis, e é uma das alavancas de qualidade mais subestimadas de um RAG.

## O dilema do tamanho

| Chunks pequenos | Chunks grandes |
| --- | --- |
| Embedding focado, busca mais precisa | Mais contexto em cada trecho |
| Perdem referências e contexto ao redor | Embedding diluído, misturam assuntos |
| Mais vetores, índice maior | Menos trechos cabem no prompt |

Não existe tamanho universal. Valores entre algumas centenas e cerca de mil tokens são pontos de partida comuns; o certo para a sua base sai de avaliação com perguntas reais.

## Estratégias

**Tamanho fixo com sobreposição.** Corta a cada N tokens (ou palavras) e repete os últimos M no início do próximo chunk. A sobreposição evita que uma ideia cortada no meio fique sem metade em ambos os pedaços. É simples e serve como baseline.

```python
texto = (
    "O reembolso de viagens exige nota fiscal. A nota deve estar no nome da empresa. "

    passo = tamanho - sobreposicao
    chunks = []
    for inicio in range(0, len(palavras), passo):
        pedaco = palavras[inicio:inicio + tamanho]
        chunks.append(" ".join(pedaco))
        if inicio + tamanho >= len(palavras):
```

```java
static List<String> chunkFixo(String texto, int tamanho, int sobreposicao) {
    String[] palavras = texto.trim().split("\\s+");
    int passo = tamanho - sobreposicao;
    List<String> chunks = new ArrayList<>();
```

```cpp
vector<string> chunkFixo(const string& texto, size_t tamanho, size_t sobreposicao) {
    // texto.split(): quebra em qualquer espaço em branco
    vector<string> palavras;
    istringstream in(texto);
    for (string p; in >> p;) palavras.push_back(p);

    size_t passo = tamanho - sobreposicao;
    vector<string> chunks;
    for (size_t inicio = 0; inicio < palavras.size(); inicio += passo) {
        string pedaco;
        for (size_t i = inicio; i < inicio + tamanho && i < palavras.size(); i++)
            pedaco += (i > inicio ? " " : "") + palavras[i];
        chunks.push_back(pedaco);
        if (inicio + tamanho >= palavras.size()) break;
    }
    return chunks;
}
```

```csharp
using System;

static List<string> ChunkFixo(string texto, int tamanho, int sobreposicao) {
    // Split sem argumentos quebra em qualquer espaço; o RemoveEmptyEntries imita o split() do Python
    string[] palavras = texto.Split((char[])null, StringSplitOptions.RemoveEmptyEntries);
    int passo = tamanho - sobreposicao;
    var chunks = new List<string>();
    for (int inicio = 0; inicio < palavras.Length; inicio += passo) {
        var pedaco = palavras.Skip(inicio).Take(tamanho);
        chunks.Add(string.Join(" ", pedaco));
        if (inicio + tamanho >= palavras.Length) break;
    }
    return chunks;
}
```

```go
import (
	"fmt"
	"strings"
)

func chunkFixo(texto string, tamanho, sobreposicao int) []string {
	palavras := strings.Fields(texto) // como o split() do Python
	passo := tamanho - sobreposicao
	chunks := []string{}
	for inicio := 0; inicio < len(palavras); inicio += passo {
		fim := inicio + tamanho
		if fim > len(palavras) {
			fim = len(palavras)
		}
		chunks = append(chunks, strings.Join(palavras[inicio:fim], " "))
		if inicio+tamanho >= len(palavras) {
			break
		}
	}
	return chunks
}

func main() {
	texto := "O reembolso de viagens exige nota fiscal. A nota deve estar no nome da empresa. " +
		"Pedidos sem nota são recusados. O prazo de pagamento é de dez dias úteis. " +
		"Viagens internacionais seguem a mesma regra com câmbio do dia."
	for i, c := range chunkFixo(texto, 14, 4) {
		fmt.Printf("[%d] %s\n", i, c)
	}
}
```

O chunk 0 termina no meio de "no nome da empresa"; graças à sobreposição, o chunk 1 repete o fim e traz a frase completa. Sem ela, nenhum dos dois pedaços conteria a regra inteira.

**Recursivo por separadores.** Tenta cortar primeiro nos limites mais "naturais" (seções, depois parágrafos, depois frases, depois palavras), descendo de nível só quando um pedaço ainda passa do limite. Respeita a estrutura do texto e é o padrão de muitas bibliotecas.

**Estrutural.** Usa a estrutura do formato: títulos de Markdown e HTML, seções de um contrato, funções e classes em código, linhas de uma tabela. Tabelas e blocos de código nunca deveriam ser cortados no meio.

**Semântico.** Calcula embeddings de frases consecutivas e corta onde a similaridade cai (mudança de assunto). Pode ajudar em textos sem estrutura, mas custa mais e nem sempre supera o recursivo.

## Enriquecendo o chunk

Um chunk solto perde o "endereço" dele no documento. Duas técnicas baratas ajudam muito:

- **Prefixar o caminho de títulos** (documento › seção › subseção) ao texto que vai para o embedding.
- **Guardar metadados**: id do documento, seção, página, data, permissões. Eles servem para filtrar, citar e reconstruir o contexto vizinho.

```python
DOC = """# Política de viagens
## Reembolso
Despesas são reembolsadas com nota fiscal em nome da empresa.
O prazo de pagamento é de dez dias úteis.
## Hospedagem
O limite diário de hotel depende da cidade.
Capitais têm limite maior.
"""

def chunk_por_secao(md, max_palavras=12):
    titulo_doc, secao, linhas, chunks = "", "", [], []

    def fechar():
        if not linhas:
            return
        atual = []
        for linha in linhas:
            if atual and len(" ".join(atual + [linha]).split()) > max_palavras:
                chunks.append({"secao": secao, "texto": f"{titulo_doc} > {secao}: " + " ".join(atual)})
                atual = []
            atual.append(linha)
        chunks.append({"secao": secao, "texto": f"{titulo_doc} > {secao}: " + " ".join(atual)})
        linhas.clear()

    for linha in md.strip().splitlines():
        if linha.startswith("## "):
            fechar()
            secao = linha[3:]
        elif linha.startswith("# "):
            titulo_doc = linha[2:]
        elif linha.strip():
            linhas.append(linha.strip())
    fechar()
    return chunks

for c in chunk_por_secao(DOC):
    print(c["texto"])
```

```java
import java.util.*;

static final String DOC = "# Política de viagens\n"
    + "## Reembolso\n"
    + "Despesas são reembolsadas com nota fiscal em nome da empresa.\n"
    + "O prazo de pagamento é de dez dias úteis.\n"
    + "## Hospedagem\n"
    + "O limite diário de hotel depende da cidade.\n"
    + "Capitais têm limite maior.\n";

class Chunk {
    final String secao, texto;
    Chunk(String secao, String texto) { this.secao = secao; this.texto = texto; }
}

// o Java não tem funções aninhadas: o estado que o fechar() do Python enxerga vira campos
class Fatiador {
    final int maxPalavras;
    String tituloDoc = "", secao = "";
    final List<String> linhas = new ArrayList<>();
    final List<Chunk> chunks = new ArrayList<>();

    Fatiador(int maxPalavras) { this.maxPalavras = maxPalavras; }

    static int contaPalavras(String s) {
        String t = s.trim();
        return t.isEmpty() ? 0 : t.split("\\s+").length;
    }

    void fechar() {
        if (linhas.isEmpty()) return;
        List<String> atual = new ArrayList<>();
        for (String linha : linhas) {
            if (!atual.isEmpty() && contaPalavras(String.join(" ", atual) + " " + linha) > maxPalavras) {
                chunks.add(new Chunk(secao, tituloDoc + " > " + secao + ": " + String.join(" ", atual)));
                atual = new ArrayList<>();
            }
            atual.add(linha);
        }
        chunks.add(new Chunk(secao, tituloDoc + " > " + secao + ": " + String.join(" ", atual)));
        linhas.clear();
    }

    List<Chunk> processar(String md) {
        for (String linha : md.strip().split("\n")) {
            if (linha.startsWith("## ")) {
                fechar();
                secao = linha.substring(3);
            } else if (linha.startsWith("# ")) {
                tituloDoc = linha.substring(2);
            } else if (!linha.strip().isEmpty()) {
                linhas.add(linha.strip());
            }
        }
        fechar();
        return chunks;
    }
}

static List<Chunk> chunkPorSecao(String md, int maxPalavras) {
    return new Fatiador(maxPalavras).processar(md);
}

public static void main(String[] args) {
    for (Chunk c : chunkPorSecao(DOC, 12)) System.out.println(c.texto);
}
```

```cpp
#include <functional>
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

const string DOC = R"(# Política de viagens
## Reembolso
Despesas são reembolsadas com nota fiscal em nome da empresa.
O prazo de pagamento é de dez dias úteis.
## Hospedagem
O limite diário de hotel depende da cidade.
Capitais têm limite maior.
)";

struct Chunk {
    string secao, texto;
};

int contaPalavras(const string& s) {
    istringstream in(s);
    int n = 0;
    for (string p; in >> p;) n++;
    return n;
}

string juntar(const vector<string>& partes) {
    string s;
    for (size_t i = 0; i < partes.size(); i++) s += (i ? " " : "") + partes[i];
    return s;
}

string aparar(const string& s) {
    size_t ini = s.find_first_not_of(" \t\r\n");
    if (ini == string::npos) return "";
    size_t fim = s.find_last_not_of(" \t\r\n");
    return s.substr(ini, fim - ini + 1);
}

vector<Chunk> chunkPorSecao(const string& md, size_t maxPalavras = 12) {
    string tituloDoc, secao;
    vector<string> linhas;
    vector<Chunk> chunks;

    // a lambda captura por referência o mesmo estado que o fechar() do Python enxerga
    function<void()> fechar = [&]() {
        if (linhas.empty()) return;
        vector<string> atual;
        for (const string& linha : linhas) {
            if (!atual.empty() && (size_t)contaPalavras(juntar(atual) + " " + linha) > maxPalavras) {
                chunks.push_back({secao, tituloDoc + " > " + secao + ": " + juntar(atual)});
                atual.clear();
            }
            atual.push_back(linha);
        }
        chunks.push_back({secao, tituloDoc + " > " + secao + ": " + juntar(atual)});
        linhas.clear();
    };

    istringstream in(aparar(md));
    for (string linha; getline(in, linha);) {
        if (linha.rfind("## ", 0) == 0) {
            fechar();
            secao = linha.substr(3);
        } else if (linha.rfind("# ", 0) == 0) {
            tituloDoc = linha.substr(2);
        } else if (!aparar(linha).empty()) {
            linhas.push_back(aparar(linha));
        }
    }
    fechar();
    return chunks;
}

int main() {
    for (const Chunk& c : chunkPorSecao(DOC)) cout << c.texto << "\n";
}
```

```go
func chunkPorSecao(md string, maxPalavras int) []chunk {
	tituloDoc, secao := "", ""
	linhas := []string{}
	chunks := []chunk{}

	// o closure enxerga as variáveis de fora, como o fechar() do Python
	fechar := func() {
		if len(linhas) == 0 {
			return
		}
		atual := []string{}
		for _, linha := range linhas {
			if len(atual) > 0 && len(strings.Fields(strings.Join(atual, " ")+" "+linha)) > maxPalavras {
				chunks = append(chunks, chunk{secao, tituloDoc + " > " + secao + ": " + strings.Join(atual, " ")})
				atual = []string{}
			}
			atual = append(atual, linha)
		}
		chunks = append(chunks, chunk{secao, tituloDoc + " > " + secao + ": " + strings.Join(atual, " ")})
		linhas = linhas[:0]

	for _, linha := range strings.Split(strings.TrimSpace(md), "\n") {
		if strings.HasPrefix(linha, "## ") {
			fechar()
			secao = linha[3:]
		} else if strings.HasPrefix(linha, "# ") {
			tituloDoc = linha[2:]
		} else if strings.TrimSpace(linha) != "" {
			linhas = append(linhas, strings.TrimSpace(linha))
		}
	}
	fechar()
	return chunks
}
```

Cada chunk agora "sabe" de que seção veio, o que melhora a busca ("limite de hotel" encontra "Hospedagem") e a citação.

<Callout type="tip" title="Recupere pequeno, entregue grande">
Uma técnica eficaz é indexar chunks pequenos (busca precisa) e, ao montar o prompt, entregar o chunk junto com seus vizinhos ou a seção inteira de onde ele veio (contexto suficiente). Chama-se às vezes de parent document retrieval ou small-to-big.
</Callout>

## Armadilhas

- **Extração ruim antes do chunking:** PDF com colunas embaralhadas, cabeçalhos e rodapés repetidos em todo chunk, tabelas viradas em sopa de números. Limpe antes de cortar.
- **Cortar no meio de tabela ou código:** o pedaço fica sem sentido para o modelo e para o embedding.
- **Ignorar o limite do modelo de embedding:** texto acima do limite é truncado em silêncio.
- **Mudar a estratégia sem reavaliar:** chunking altera recall; trate como mudança que exige rodar a avaliação de recuperação.

## Na entrevista

Diga que começaria com chunking recursivo (algumas centenas de tokens, sobreposição de 10% a 20%), respeitando estrutura do documento, com títulos e metadados anexados, e que ajustaria o tamanho medindo recall@k num conjunto de perguntas. Follow-ups: "como tratar tabelas?" (manter a tabela inteira, ou uma linha por chunk com o cabeçalho repetido) e "a resposta precisa de informação espalhada em várias seções, e agora?" (chunks maiores, recuperar vizinhos ou técnicas multi-hop do capítulo de RAG avançado).
