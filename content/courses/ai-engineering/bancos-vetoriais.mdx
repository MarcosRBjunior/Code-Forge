Com mil documentos, comparar a pergunta contra todos os vetores leva microssegundos. Com cem milhões de trechos de mil dimensões, a busca exata vira centenas de bilhões de multiplicações por consulta, e a latência sai do aceitável. **Bancos vetoriais** existem para responder "quais são os k vetores mais próximos?" rápido em escala, usando índices de vizinho mais próximo **aproximado** (ANN): você troca um pouco de precisão por ordens de grandeza de velocidade.

## Busca exata: a linha de base

A busca exata (força bruta, ou kNN plano) calcula a similaridade contra todos os vetores e mantém os k melhores num heap. É simples, 100% correta e, até algumas dezenas ou centenas de milhares de vetores, frequentemente boa o bastante, sobretudo com filtros que reduzem o conjunto. Ela também é a referência para medir o **recall** de qualquer índice aproximado.

import heapq, math, random

rng = random.Random(7)
DIM, N = 8, 2000

def normalizar(v):
    n = math.sqrt(sum(x * x for x in v))
    return [x / n for x in v]

base = [normalizar([rng.gauss(0, 1) for _ in range(DIM)]) for _ in range(N)]
consulta = normalizar([rng.gauss(0, 1) for _ in range(DIM)])

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def busca_exata(q, k):
    return heapq.nlargest(k, range(len(base)), key=lambda i: dot(q, base[i]))

top = busca_exata(consulta, 5)
print("top-5 ids:", top)
print("scores:", [round(dot(consulta, base[i]), 3) for i in top])
print("comparacoes:", N)

## Famílias de índices aproximados

| Índice | Ideia | Pontos fortes | Pontos fracos |
| --- | --- | --- | --- |
| IVF | Agrupa vetores (k-means) e só visita os grupos mais próximos | Simples, pouca memória extra | Recall cai se a consulta fica na borda dos grupos |
| HNSW | Grafo de vizinhança em camadas, busca gulosa | Ótimo recall e latência, inserção incremental | Usa bastante memória, construção cara |
| Quantização (PQ, escalar, binária) | Comprime cada vetor em poucos bytes | Cabe muito mais em RAM | Perde precisão; costuma exigir re-ranking com vetor completo |
| Em disco (estilo DiskANN) | Grafo otimizado para SSD | Bilhões de vetores com pouca RAM | Mais complexo, latência um pouco maior |

## Como o HNSW funciona

O **HNSW** (Hierarchical Navigable Small World) liga cada vetor aos seus vizinhos mais próximos, formando um grafo em que dá para "caminhar" na direção da consulta. Para não começar a caminhada longe demais, ele mantém várias camadas: as de cima têm poucos nós e arestas longas (como rodovias), as de baixo têm todos os nós e arestas curtas (como ruas).

```text
camada 2:  A ─────────────────────── F            poucos nós, saltos longos
camada 1:  A ───── C ────────── E ── F
camada 0:  A ─ B ─ C ─ D ─ E ─ F ─ G ─ H          todos os nós, vizinhos próximos
busca: entra no topo, desce quando não consegue melhorar, refina embaixo
```

Na busca, a partir de um ponto de entrada, você vai para o vizinho mais próximo da consulta enquanto houver melhora; ao travar, desce uma camada. Na camada 0, mantém uma lista de candidatos de tamanho `ef` para não parar num mínimo local. Os parâmetros principais: `M` (vizinhos por nó, afeta memória e recall), `ef_construction` (qualidade do grafo) e `ef_search` (recall versus latência na consulta).

O programa abaixo implementa só a camada 0 (um grafo navegável simples) com busca gulosa e lista de candidatos, e mede recall contra a busca exata.

```python
import heapq, math, random

rng = random.Random(7)
DIM, N, M = 8, 800, 8

def normalizar(v):
    n = math.sqrt(sum(x * x for x in v))
    return [x / n for x in v]

def dist(a, b):
    return 1 - sum(x * y for x, y in zip(a, b))

base = [normalizar([rng.gauss(0, 1) for _ in range(DIM)]) for _ in range(N)]

# construção: cada nó novo se liga aos M mais próximos já inseridos (arestas nos dois sentidos)
vizinhos = {0: set()}
for i in range(1, N):
    proximos = heapq.nsmallest(M, range(i), key=lambda j: dist(base[i], base[j]))
    vizinhos[i] = set(proximos)
    for j in proximos:
        vizinhos[j].add(i)

def busca_grafo(q, k, ef):
    calculos = 0
    def d(i):
        nonlocal calculos
        calculos += 1
        return dist(q, base[i])
    visitados = {0}
    candidatos = [(d(0), 0)]          # min-heap: o que explorar
    melhores = [(-candidatos[0][0], 0)]  # max-heap dos ef melhores
    while candidatos:
        dc, c = heapq.heappop(candidatos)
        if dc > -melhores[0][0] and len(melhores) >= ef:
            break
        for v in vizinhos[c]:
            if v in visitados:
                continue
            visitados.add(v)
            dv = d(v)
            if len(melhores) < ef or dv < -melhores[0][0]:
                heapq.heappush(candidatos, (dv, v))
                heapq.heappush(melhores, (-dv, v))
                if len(melhores) > ef:
                    heapq.heappop(melhores)
    return [v for _, v in sorted((-nd, v) for nd, v in melhores)][:k], calculos

consultas = [normalizar([rng.gauss(0, 1) for _ in range(DIM)]) for _ in range(20)]
for ef in (10, 40):
    acertos, total_calc = 0, 0
    for q in consultas:
        exato = set(heapq.nsmallest(10, range(N), key=lambda j: dist(q, base[j])))
        achados, calc = busca_grafo(q, 10, ef)
        acertos += len(exato & set(achados))
        total_calc += calc
    print(f"ef={ef}: recall@10={acertos / (10 * len(consultas)):.2f} "
          f"distancias por consulta={total_calc // len(consultas)} (exata: {N})")
```

// gerador com semente (mulberry32) + Box-Muller: a sequência difere da do Python
function mulberry32(semente) {
  return () => {
    semente = (semente + 0x6d2b79f5) | 0;
    let t = Math.imul(semente ^ (semente >>> 15), 1 | semente);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
const rng = mulberry32(7);
const gauss = () => Math.sqrt(-2 * Math.log(1 - rng())) * Math.cos(2 * Math.PI * rng());

const DIM = 8, N = 800, M = 8;

function normalizar(v) {
  const n = Math.sqrt(v.reduce((s, x) => s + x * x, 0));
  return v.map((x) => x / n);
}

const dist = (a, b) => 1 - a.reduce((s, x, i) => s + x * b[i], 0);

const vetorAleatorio = () => normalizar(Array.from({ length: DIM }, gauss));
const base = Array.from({ length: N }, vetorAleatorio);

// heap mínimo de pares [distância, id], comparados como as tuplas do heapq
const menor = (a, b) => a[0] < b[0] || (a[0] === b[0] && a[1] < b[1]);

function heapPush(h, item) {
  h.push(item);
  let i = h.length - 1;
  while (i > 0) {
    const pai = (i - 1) >> 1;
    if (!menor(h[i], h[pai])) break;
    [h[i], h[pai]] = [h[pai], h[i]];
    i = pai;
  }
}

function heapPop(h) {
  const raiz = h[0], ultimo = h.pop();
  if (h.length > 0) {
    h[0] = ultimo;
    let i = 0;
    while (true) {
      const esq = 2 * i + 1, dir = esq + 1;
      let m = i;
      if (esq < h.length && menor(h[esq], h[m])) m = esq;
      if (dir < h.length && menor(h[dir], h[m])) m = dir;
      if (m === i) break;
      [h[i], h[m]] = [h[m], h[i]];
      i = m;
    }
  }
  return raiz;
}

// como heapq.nsmallest: os k ids de range(n) mais próximos de q; no empate, o menor id (sort estável)
function maisProximos(q, n, k) {
  const ds = base.slice(0, n).map((v) => dist(q, v));
  return [...ds.keys()].sort((a, b) => ds[a] - ds[b]).slice(0, k);
}

// construção: cada nó novo se liga aos M mais próximos já inseridos (arestas nos dois sentidos)
// lista em vez de set: os ids não se repetem, porque o nó i ainda não está em nenhuma lista
const vizinhos = [[]];
for (let i = 1; i < N; i++) {
  const proximos = maisProximos(base[i], i, M);
  vizinhos.push(proximos);
  for (const j of proximos) vizinhos[j].push(i);
}

function buscaGrafo(q, k, ef) {
  let calculos = 0;
  const d = (i) => {
    calculos += 1;
    return dist(q, base[i]);
  };
  const visitados = new Set([0]);
  const candidatos = [[d(0), 0]];               // heap mínimo: o que explorar
  const melhores = [[-candidatos[0][0], 0]];    // heap máximo dos ef melhores (distância negada)
  while (candidatos.length > 0) {
    const [dc, c] = heapPop(candidatos);
    if (dc > -melhores[0][0] && melhores.length >= ef) break;
    for (const v of vizinhos[c]) {
      if (visitados.has(v)) continue;
      visitados.add(v);
      const dv = d(v);
      if (melhores.length < ef || dv < -melhores[0][0]) {
        heapPush(candidatos, [dv, v]);
        heapPush(melhores, [-dv, v]);
        if (melhores.length > ef) heapPop(melhores);
      }
    }
  }
  const ordenados = melhores.map(([nd, v]) => [-nd, v]).sort((a, b) => a[0] - b[0] || a[1] - b[1]);
  return [ordenados.slice(0, k).map(([, v]) => v), calculos];
}

// toFixed arredonda o empate para cima (0.625 -> "0.63"); o Python arredonda para o par ("0.62")
function fixoPar(x, casas) {
  const m = x * 10 ** casas, r = Math.round(m);
  const n = Math.abs(m % 1) === 0.5 && r % 2 !== 0 ? r - 1 : r;
  return (n / 10 ** casas).toFixed(casas);
}

const consultas = Array.from({ length: 20 }, vetorAleatorio);
for (const ef of [10, 40]) {
  let acertos = 0, totalCalc = 0;
  for (const q of consultas) {
    const exato = new Set(maisProximos(q, N, 10));
    const [achados, calc] = buscaGrafo(q, 10, ef);
    acertos += achados.filter((v) => exato.has(v)).length;
    totalCalc += calc;

function mulberry32(semente: number): () => number {
  return () => {
    semente = (semente + 0x6d2b79f5) | 0;
    let t = Math.imul(semente ^ (semente >>> 15), 1 | semente);

// heap mínimo de pares [distância, id], comparados como as tuplas do heapq
type Item = [number, number];
const menor = (a: Item, b: Item): boolean => a[0] < b[0] || (a[0] === b[0] && a[1] < b[1]);

function heapPush(h: Item[], item: Item): void {
  h.push(item);
  let i = h.length - 1;
  while (i > 0) {
    const pai = (i - 1) >> 1;
    if (!menor(h[i], h[pai])) break;
    const t = h[i]; h[i] = h[pai]; h[pai] = t;
    i = pai;
  }
}

function heapPop(h: Item[]): Item {
  const raiz = h[0], ultimo = h.pop() as Item;
  if (h.length > 0) {
    h[0] = ultimo;
    let i = 0;
    while (true) {
      const esq = 2 * i + 1, dir = esq + 1;
      let m = i;
      if (esq < h.length && menor(h[esq], h[m])) m = esq;
      if (dir < h.length && menor(h[dir], h[m])) m = dir;
      if (m === i) break;
      const t = h[i]; h[i] = h[m]; h[m] = t;
      i = m;
    }
  }
  return raiz;
}

function buscaGrafo(q: number[], k: number, ef: number): [number[], number] {
  let calculos = 0;
  const d = (i: number): number => {
    calculos += 1;
    return dist(q, base[i]);
  };
  const visitados = new Set<number>([0]);
  const candidatos: Item[] = [[d(0), 0]];               // heap mínimo: o que explorar
  const melhores: Item[] = [[-candidatos[0][0], 0]];    // heap máximo dos ef melhores (distância negada)
  while (candidatos.length > 0) {
    const [dc, c] = heapPop(candidatos);
    if (dc > -melhores[0][0] && melhores.length >= ef) break;
    for (const v of vizinhos[c]) {
      if (visitados.has(v)) continue;
      visitados.add(v);
      const dv = d(v);
      if (melhores.length < ef || dv < -melhores[0][0]) {
        heapPush(candidatos, [dv, v]);
        heapPush(melhores, [-dv, v]);
        if (melhores.length > ef) heapPop(melhores);
      }
    }
  }
  const ordenados = melhores.map(([nd, v]): Item => [-nd, v]).sort((a, b) => a[0] - b[0] || a[1] - b[1]);
  return [ordenados.slice(0, k).map((par) => par[1]), calculos];
}

  const n = Math.abs(m % 1) === 0.5 && r % 2 !== 0 ? r - 1 : r;
  return (n / Math.pow(10, casas)).toFixed(casas);
}

	d := func(i int) float64 {
		calculos++
		return dist(q, base[i])
	}
	visitados := map[int]bool{0: true}
	d0 := d(0)
	candidatos := &Heap{{d0, 0}}  // heap mínimo: o que explorar
	melhores := &Heap{{-d0, 0}}   // heap máximo dos ef melhores (distância negada)
	for candidatos.Len() > 0 {
		atual := heap.Pop(candidatos).(Item)
		if atual.D > -(*melhores)[0].D && melhores.Len() >= ef {
			break
		}
		for _, v := range vizinhos[atual.Id] {
			if visitados[v] {
				continue
			}
			visitados[v] = true
			dv := d(v)
			if melhores.Len() < ef || dv < -(*melhores)[0].D {
				heap.Push(candidatos, Item{dv, v})
				heap.Push(melhores, Item{-dv, v})
				if melhores.Len() > ef {
					heap.Pop(melhores)
				}
			}
		}
	}
	ordenados := []Item{}
	for _, x := range *melhores {
		ordenados = append(ordenados, Item{-x.D, x.Id})
	}
	sort.Slice(ordenados, func(i, j int) bool { return menor(ordenados[i], ordenados[j]) })
	achados := []int{}
	for i := 0; i < k && i < len(ordenados); i++ {
		achados = append(achados, ordenados[i].Id)
	}
	return achados, calculos
}

func main() {
	for i := 0; i < N; i++ {
		base = append(base, vetorAleatorio())
	}

	// construção: cada nó novo se liga aos M mais próximos já inseridos (arestas nos dois sentidos)
	// lista em vez de set: os ids não se repetem, porque o nó i ainda não está em nenhuma lista
	vizinhos = make([][]int, N)
	for i := 1; i < N; i++ {
		vizinhos[i] = maisProximos(base[i], i, M)
		for _, j := range vizinhos[i] {
			vizinhos[j] = append(vizinhos[j], i)
		}
	}

	consultas := [][]float64{}
	for i := 0; i < 20; i++ {
		consultas = append(consultas, vetorAleatorio())
	}
	for _, ef := range []int{10, 40} {
		acertos, totalCalc := 0, 0
		for _, q := range consultas {
			exato := map[int]bool{}
			for _, j := range maisProximos(q, N, 10) {
				exato[j] = true
			}
			achados, calc := buscaGrafo(q, 10, ef)
			for _, v := range achados {
				if exato[v] {
					acertos++
				}
			}
			totalCalc += calc
		}
		fmt.Printf("ef=%d: recall@10=%.2f distancias por consulta=%d (exata: %d)\n", ef,
			float64(acertos)/float64(10*len(consultas)), totalCalc/len(consultas), N)
	}
}

## O que um banco vetorial adiciona

Um índice ANN sozinho é uma biblioteca (como FAISS ou hnswlib). Um banco vetorial acrescenta: persistência, atualização e remoção de itens, **filtros por metadados** (tenant, idioma, data), busca híbrida, réplicas, sharding e controle de acesso. Existem bancos dedicados e extensões vetoriais em bancos tradicionais (por exemplo, pgvector no PostgreSQL). Se você já usa Postgres e tem poucos milhões de vetores, a extensão costuma ser a escolha mais simples.

<Callout type="warning" title="Filtros e ANN não se dão bem de graça">
Filtrar depois da busca (pós-filtro) pode devolver menos que k resultados quando o filtro é seletivo. Filtrar antes (pré-filtro) pode quebrar a navegação do grafo. Verifique como o seu banco combina filtros e índice, e teste o recall com os filtros reais de produção, como o filtro por tenant.
</Callout>
