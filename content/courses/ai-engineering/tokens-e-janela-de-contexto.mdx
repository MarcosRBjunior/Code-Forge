Um LLM não lê caracteres nem palavras: lê **tokens**. Tudo o que importa na operação de um produto (preço, limite de entrada, latência, até a qualidade em idiomas diferentes do inglês) é medido nessa unidade. Se você estima custo contando palavras, vai errar; se ignora o limite de contexto, sua aplicação quebra justamente nas conversas mais longas, que costumam ser as dos melhores clientes.

## O que é um token

Um tokenizador quebra o texto em pedaços de um vocabulário fixo, normalmente com dezenas a centenas de milhares de entradas. Palavras comuns viram um token só; palavras raras, nomes próprios e código são quebrados em vários pedaços. A técnica mais usada é a **BPE** (byte pair encoding): começa com caracteres (ou bytes) e, repetidamente, funde o par adjacente mais frequente num símbolo novo.

```python
from collections import Counter

palavras = ["banana", "bandana", "cabana", "banda"]
seqs = [list(p) for p in palavras]

def par_mais_frequente(seqs):
    pares = Counter()
    for s in seqs:
        pares.update(zip(s, s[1:]))
    return pares.most_common(1)[0]

def fundir(seqs, par):
    novo = par[0] + par[1]
    resultado = []
    for s in seqs:
        i, out = 0, []
        while i < len(s):
            if i + 1 < len(s) and (s[i], s[i + 1]) == par:
                out.append(novo)
                i += 2
            else:
                out.append(s[i])
                i += 1
        resultado.append(out)
    return resultado

for passo in range(1, 5):
    par, freq = par_mais_frequente(seqs)
    seqs = fundir(seqs, par)
    print(f"fusao {passo}: {par[0]}+{par[1]} (freq {freq}) -> {seqs[0]}")
print("tokens por palavra:", [len(s) for s in seqs])
```

```java
static String[] parMaisFrequente(List<List<String>> seqs) {
    LinkedHashMap<List<String>, Integer> pares = new LinkedHashMap<>();
    for (List<String> s : seqs) {
        for (int i = 0; i + 1 < s.size(); i++) pares.merge(List.of(s.get(i), s.get(i + 1)), 1, Integer::sum);
    }
    List<String> melhor = null;
    int freq = 0;
    for (Map.Entry<List<String>, Integer> e : pares.entrySet()) {
        if (e.getValue() > freq) {
            melhor = e.getKey();
            freq = e.getValue();
        }
    }
    return new String[]{melhor.get(0), melhor.get(1), String.valueOf(freq)};
}

                i += 2;

                i += 1;

}
```

```cpp
// no empate vence o par visto primeiro, como no Counter (por isso um vector, e não um map)
pair<Par, int> parMaisFrequente(const vector<Seq>& seqs) {
    vector<pair<Par, int>> pares;
    for (auto& s : seqs) {
        for (size_t i = 0; i + 1 < s.size(); i++) {
            Par p = {s[i], s[i + 1]};
            bool achou = false;
            for (auto& [q, n] : pares)
                if (q == p) { n++; achou = true; break; }
            if (!achou) pares.push_back({p, 1});
        }
    }
    pair<Par, int> melhor = pares[0];
    for (auto& e : pares)
        if (e.second > melhor.second) melhor = e;
    return melhor;
}

vector<Seq> fundir(const vector<Seq>& seqs, const Par& par) {
    string novo = par.first + par.second;
    vector<Seq> resultado;
    for (auto& s : seqs) {
        Seq out;
        size_t i = 0;
        while (i < s.size()) {
            if (i + 1 < s.size() && s[i] == par.first && s[i + 1] == par.second) {
                out.push_back(novo);
                i += 2;
            } else {
                out.push_back(s[i]);
                i += 1;
            }
        }
        resultado.push_back(out);
    }
    return resultado;
}

    string r = "[";
    for (size_t i = 0; i < s.size(); i++) r += (i ? ", '" : "'") + s[i] + "'";

}
```

```csharp
static string[] ParMaisFrequente(List<List<string>> seqs)
{
    var pares = new List<string[]>();   // {primeiro, segundo}
    var contagem = new List<int>();
    foreach (var s in seqs)
    {
        for (int i = 0; i + 1 < s.Count; i++)
        {
            int j = pares.FindIndex(p => p[0] == s[i] && p[1] == s[i + 1]);
            if (j >= 0) contagem[j]++;
            else
            {
                pares.Add(new[] { s[i], s[i + 1] });
                contagem.Add(1);
            }
        }
    }
    int melhor = 0;
    for (int i = 1; i < pares.Count; i++)
        if (contagem[i] > contagem[melhor]) melhor = i;
    return new[] { pares[melhor][0], pares[melhor][1], contagem[melhor].ToString() };
}
```

Depois de milhares de fusões num corpus gigante, sobra um vocabulário em que "banana" provavelmente é um token só. A consequência prática: a mesma frase pode custar mais tokens em português do que em inglês, porque os tokenizadores costumam ser treinados com mais texto em inglês. Como regra grosseira, em inglês um token fica perto de três quartos de uma palavra; em português e em código a razão é pior. Para números exatos, use o tokenizador do próprio modelo.

Tokenização também explica erros clássicos: o modelo tem dificuldade para contar letras ou inverter strings porque não "vê" letras, vê pedaços.

## A janela de contexto

A **janela de contexto** é o número máximo de tokens que o modelo processa numa chamada, somando tudo:

```text
┌────────────────────── janela de contexto ──────────────────────┐
│ system prompt │ ferramentas │ histórico │ documentos │ pergunta │ saída │
└─────────────────────────────────────────────────────────────────┘
```

A saída também ocupa espaço: se você reservar pouco, a resposta é cortada no meio. Janelas atuais vão de alguns milhares a centenas de milhares de tokens, mas caber não significa funcionar bem. Três problemas aparecem com contexto grande:

- **Custo e latência** crescem com cada token enviado, em toda chamada.
- **Perda no meio:** modelos tendem a usar melhor o que está no começo e no fim do contexto; um detalhe enterrado no meio de 100 páginas pode ser ignorado.
- **Distração:** informação irrelevante compete com a relevante e piora a resposta.

## Gerenciando o orçamento

Em um chat, o histórico cresce até estourar. As estratégias comuns são: janela deslizante (manter as últimas N mensagens), resumir as antigas numa mensagem curta, ou recuperar só os trechos relevantes (RAG). Sempre preserve o system prompt e reserve espaço para a resposta.

```python
def contar_tokens(texto):
    # aproximação didática: 1 token a cada 4 caracteres, no mínimo 1
    return max(1, len(texto) // 4)

def montar_contexto(system, historico, limite, reserva_saida):
    orcamento = limite - reserva_saida - contar_tokens(system)
    escolhidas = []
    for msg in reversed(historico):          # das mais recentes para as antigas
        custo = contar_tokens(msg)
        if custo > orcamento:
            break
        escolhidas.append(msg)
```

```java
import java.util.*;

static int contarTokens(String texto) {
    // aproximação didática: 1 token a cada 4 caracteres, no mínimo 1
    return Math.max(1, texto.length() / 4);
}

static int orcamento; // o Python devolve uma tupla; aqui a sobra fica neste campo

static List<String> montarContexto(String system, List<String> historico, int limite, int reservaSaida) {
    orcamento = limite - reservaSaida - contarTokens(system);
    List<String> escolhidas = new ArrayList<>();
    for (int i = historico.size() - 1; i >= 0; i--) { // das mais recentes para as antigas
        String msg = historico.get(i);
        int custo = contarTokens(msg);
        if (custo > orcamento) break;
        escolhidas.add(msg);
        orcamento -= custo;
    }
    Collections.reverse(escolhidas);
    List<String> contexto = new ArrayList<>();
    contexto.add(system);
    contexto.addAll(escolhidas);
    return contexto;
}

    List<String> mantidas = new ArrayList<>();
```

```csharp
        if (custo > orcamento) break;
        escolhidas.Add(historico[i]);
        orcamento -= custo;
    }
    escolhidas.Reverse();
    var contexto = new List<string> { system };
    contexto.AddRange(escolhidas);
    return contexto;
}

static void Main()
{
    string system = "Voce e um assistente de suporte.";
    var historico = Enumerable.Range(1, 8).Select(i => "mensagem " + i + ": " + new string('x', 40)).ToList();
    int sobra;
    var contexto = MontarContexto(system, historico, 80, 20, out sobra);
    var mantidas = contexto.Skip(1).Select(m => "'" + m.Split(':')[0] + "'");
    Console.WriteLine("mensagens mantidas: [" + string.Join(", ", mantidas) + "]");
```

```go
import (
	"fmt"
	"strings"
)

func contarTokens(texto string) int {
	// aproximação didática: 1 token a cada 4 caracteres, no mínimo 1
	if n := len(texto) / 4; n > 1 {
		return n
	}
	return 1
}

func montarContexto(system string, historico []string, limite, reservaSaida int) ([]string, int) {
	orcamento := limite - reservaSaida - contarTokens(system)
	escolhidas := []string{}
	for i := len(historico) - 1; i >= 0; i-- { // das mais recentes para as antigas
		custo := contarTokens(historico[i])
		if custo > orcamento {
			break
		}
		escolhidas = append(escolhidas, historico[i])
		orcamento -= custo
	}
	contexto := []string{system}
	for i := len(escolhidas) - 1; i >= 0; i-- {
		contexto = append(contexto, escolhidas[i])
	}
	return contexto, orcamento
}

func main() {
	system := "Voce e um assistente de suporte."
	historico := []string{}
	for i := 1; i < 9; i++ {
		historico = append(historico, fmt.Sprintf("mensagem %d: ", i)+strings.Repeat("x", 40))
	}
	contexto, sobra := montarContexto(system, historico, 80, 20)
	mantidas := []string{}
	for _, m := range contexto[1:] {
		mantidas = append(mantidas, strings.Split(m, ":")[0])
	}
	fmt.Printf("mensagens mantidas: %q\n", mantidas)
	fmt.Println("tokens sobrando:", sobra)
}
```
