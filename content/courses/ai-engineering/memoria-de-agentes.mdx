O modelo não lembra de nada entre chamadas. Tudo o que parece memória num assistente, desde "como eu disse antes" até "você prefere respostas curtas, certo?", é a sua aplicação decidindo o que guardar e o que colocar de volta no contexto. Sem um desenho deliberado, você cai em um de dois extremos: o assistente esquece o que o usuário disse há dez mensagens, ou você reenvia o histórico inteiro até estourar a janela e a conta.

## Tipos de memória

| Tipo | O que guarda | Onde costuma ficar | Exemplo |
| --- | --- | --- | --- |
| Curto prazo (trabalho) | A conversa e os passos da tarefa atual | No próprio contexto | Últimas mensagens, resultados de ferramentas |
| Longo prazo semântica | Fatos sobre o usuário ou o domínio | Banco chave-valor, documento ou vetorial | "Prefere respostas em inglês", "trabalha com Go" |
| Longo prazo episódica | O que aconteceu em sessões passadas | Resumos indexados por data e assunto | "Em março resolvemos o erro de deploy trocando a região" |
| Procedimental | Como fazer as coisas | Instruções e prompts atualizados | "Neste repositório, rode os testes com make test" |

## Memória de curto prazo: caber na janela

A conversa cresce sem parar. As estratégias clássicas são janela deslizante (manter as N últimas mensagens), resumo progressivo (comprimir as antigas num parágrafo que fica no início) e descarte seletivo (remover resultados volumosos de ferramentas já usados). O resumo preserva o essencial e libera espaço, mas perde detalhes: um número de pedido citado há 30 mensagens pode sumir.

def resumir(mensagens):
    # no lugar de um LLM: guarda só as frases marcadas como importantes
    fatos = [m.split("!")[1].strip() for m in mensagens if "!" in m]
    return "RESUMO: " + "; ".join(fatos) if fatos else "RESUMO: conversa sem fatos relevantes"

        self.limite, self.resumo, self.msgs = limite_palavras, "", []

    // no lugar de um LLM: guarda só as frases marcadas como importantes
    List<String> fatos = new ArrayList<>();
    for (String m : mensagens) {
        if (m.contains("!")) fatos.add(m.split("!", -1)[1].trim());

static class MemoriaCurta {

    List<String> msgs = new ArrayList<>();

    MemoriaCurta(int limitePalavras) {
        limite = limitePalavras;

        int s = 0;

#include <vector>

int contar(const string& msg) {
    istringstream in(msg);
    int n = 0;
    for (string w; in >> w;) n++;
    return n;
}

string aparar(const string& s) {
    size_t i = s.find_first_not_of(" \t\n"), j = s.find_last_not_of(" \t\n");
    return i == string::npos ? "" : s.substr(i, j - i + 1);
}

string resumir(const vector<string>& mensagens) {
    // no lugar de um LLM: guarda só as frases marcadas como importantes
    vector<string> fatos;
    for (auto& m : mensagens) {
        size_t a = m.find('!');
        if (a == string::npos) continue;
        size_t b = m.find('!', a + 1); // como m.split("!")[1]: o trecho entre o 1º e o 2º "!"
        fatos.push_back(aparar(m.substr(a + 1, b == string::npos ? string::npos : b - a - 1)));
    }
    if (fatos.empty()) return "RESUMO: conversa sem fatos relevantes";
    string r = "RESUMO: ";
    for (size_t i = 0; i < fatos.size(); i++) r += (i ? "; " : "") + fatos[i];
    return r;
}

class MemoriaCurta {
    int limite;
    string resumo;
    vector<string> msgs;

    int total() const {
        int s = 0;
        for (auto& m : msgs) s += contar(m);
        return s;
    }

public:
    explicit MemoriaCurta(int limitePalavras) : limite(limitePalavras) {}

    void adicionar(const string& msg) {
        msgs.push_back(msg);
        while (total() > limite && msgs.size() > 2) {
            vector<string> entrada;
            if (!resumo.empty()) {
                string r = resumo;
                r.replace(r.find("RESUMO:"), 7, "!");
                entrada.push_back(r);

            msgs.erase(msgs.begin(), msgs.begin() + 2);
            resumo = resumir(entrada);
        }
    }

    vector<string> contexto() const {
        vector<string> r;
        if (!resumo.empty()) r.push_back(resumo);
        r.insert(r.end(), msgs.begin(), msgs.end());
        return r;
    }
};

## Memória de longo prazo: escrever e recuperar

Memória persistente tem duas metades:

- **Escrita:** decidir o que vale guardar. Pode ser explícita (o agente tem uma ferramenta "lembrar") ou um processo em segundo plano que, ao fim da sessão, extrai fatos com um LLM. Precisa lidar com **atualização**: se o usuário mudou de cidade, o fato antigo deve ser substituído, não somado.
- **Leitura:** a cada nova conversa, buscar as memórias relevantes e inserir no contexto. A pontuação costuma combinar relevância (similaridade com a mensagem), recência e importância.

```python
import math

class MemoriaLonga:
    def __init__(self):
        self.fatos = {}  # chave -> (valor, dia em que foi gravado, importância)

    def lembrar(self, chave, valor, dia, importancia=1.0):
        self.fatos[chave] = (valor, dia, importancia)   # sobrescreve: atualização

    def recuperar(self, consulta, hoje, k=2, meia_vida=30):
        termos = set(consulta.lower().split())
        pontuados = []
        for chave, (valor, dia, imp) in self.fatos.items():
            relevancia = len(termos & set(f"{chave} {valor}".lower().split()))
            if relevancia == 0:
                continue
            recencia = math.exp(-math.log(2) * (hoje - dia) / meia_vida)
            pontuados.append((round(relevancia * recencia * imp, 3), chave, valor))
        return sorted(pontuados, reverse=True)[:k]

mem = MemoriaLonga()
mem.lembrar("cidade", "mora em Recife", dia=1)
mem.lembrar("linguagem", "programa em Go no trabalho", dia=10, importancia=1.5)
mem.lembrar("cidade", "mora em Curitiba", dia=80)          # mudou-se
mem.lembrar("restaurante", "é vegetariano", dia=85)

print(mem.recuperar("onde ele mora", hoje=90))
print(mem.recuperar("sugira um restaurante onde ele mora", hoje=90, k=3))
```

// o toFixed arredonda o valor exato do double, mas leva o empate para cima (0.125 -> "0.13");
// o Python leva o empate exato para o par ("0.12"). Com 30 casas a mais, os dígitos exatos mostram o empate.
function fixoPar(x, casas) {
  const exato = Math.abs(x).toFixed(casas + 30);
  const corte = exato.length - 30;
  if (exato.slice(corte) !== "5" + "0".repeat(29)) return x.toFixed(casas);
  const baixo = exato.slice(0, casas > 0 ? corte : corte - 1); // sem o 5 (e sem o ponto, se casas = 0)
  const par = Number(baixo[baixo.length - 1]) % 2 === 0 ? baixo : Math.abs(x).toFixed(casas);
  return (x < 0 ? "-" : "") + par;
}

// round() do Python: o mesmo arredondamento, de volta para number
function arred(x, casas) {
  return Number(fixoPar(x, casas));
}

class MemoriaLonga {
  constructor() {
    this.fatos = new Map(); // chave -> [valor, dia em que foi gravado, importância]
  }

  lembrar(chave, valor, dia, importancia = 1.0) {
    this.fatos.set(chave, [valor, dia, importancia]); // sobrescreve: atualização
  }

  recuperar(consulta, hoje, k = 2, meiaVida = 30) {
    const termos = new Set(consulta.toLowerCase().split(/\s+/));
    const pontuados = [];
    for (const [chave, [valor, dia, imp]] of this.fatos) {
      const palavras = new Set(`${chave} ${valor}`.toLowerCase().split(/\s+/));
      const relevancia = [...termos].filter((t) => palavras.has(t)).length;
      if (relevancia === 0) continue;
      const recencia = Math.exp(-Math.log(2) * (hoje - dia) / meiaVida);
      pontuados.push([arred(relevancia * recencia * imp, 3), chave, valor]);
    }
    // como sorted(..., reverse=True) em tuplas: compara campo a campo, do maior para o menor
    const cmp = (a, b) => (a < b ? -1 : a > b ? 1 : 0);
    pontuados.sort((a, b) => cmp(b[0], a[0]) || cmp(b[1], a[1]) || cmp(b[2], a[2]));
    return pontuados.slice(0, k);
  }
}

import java.math.RoundingMode;
import java.nio.charset.StandardCharsets;
import java.util.*;

// round() do Python: arredonda o valor exato do double, com empate para o par
static double arred(double x, int casas) {
    return new BigDecimal(x).setScale(casas, RoundingMode.HALF_EVEN).doubleValue();
}

static class Fato {
    String valor;
    int dia;
    double importancia;

    Fato(String valor, int dia, double importancia) {
        this.valor = valor;
        this.dia = dia;
        this.importancia = importancia;
    }
}

static class Pontuado {
    double score;
    String chave, valor;

    Pontuado(double score, String chave, String valor) {
        this.score = score;
        this.chave = chave;
        this.valor = valor;
    }

    public String toString() {
        return "(" + score + ", '" + chave + "', '" + valor + "')";
    }
}

static class MemoriaLonga {
    LinkedHashMap<String, Fato> fatos = new LinkedHashMap<>(); // put numa chave existente mantém a posição, como o dict

    void lembrar(String chave, String valor, int dia, double importancia) {
        fatos.put(chave, new Fato(valor, dia, importancia)); // sobrescreve: atualização
    }

    List<Pontuado> recuperar(String consulta, int hoje, int k, int meiaVida) {
        Set<String> termos = new HashSet<>(Arrays.asList(consulta.toLowerCase().split("\\s+")));
        List<Pontuado> pontuados = new ArrayList<>();
        for (Map.Entry<String, Fato> e : fatos.entrySet()) {
            Fato f = e.getValue();
            Set<String> palavras = new HashSet<>(Arrays.asList((e.getKey() + " " + f.valor).toLowerCase().split("\\s+")));
            palavras.retainAll(termos);
            int relevancia = palavras.size();
            if (relevancia == 0) continue;
            double recencia = Math.exp(-Math.log(2) * (hoje - f.dia) / meiaVida);
            double score = arred(relevancia * recencia * f.importancia, 3);
            pontuados.add(new Pontuado(score, e.getKey(), f.valor));
        }
        // como sorted(..., reverse=True) em tuplas: compara campo a campo, do maior para o menor
        pontuados.sort(Comparator.comparingDouble((Pontuado p) -> p.score)
                .thenComparing(p -> p.chave).thenComparing(p -> p.valor).reversed());
        return pontuados.subList(0, Math.min(k, pontuados.size()));
    }
}

    set<string> r;

        r.insert(w);
    }
    return r;
}

using System;
using System.Collections.Generic;
using System.Globalization;
using System.Linq;

// o F2 do C# arredonda a forma decimal curta, e o Math.Round(x, 2) multiplica por 100 antes (2.675 vira 267.5);
// o Python arredonda o valor binário exato do double, com empate para o par. Aqui o valor exato
// (mantissa * 2^expoente) é montado em decimal, com 28 dígitos, e arredondado para o par.
static string FixoPar(double x, int casas) {
    long bits = BitConverter.DoubleToInt64Bits(Math.Abs(x));
    int campo = (int)(bits >> 52);
    decimal d = bits & 0xFFFFFFFFFFFFFL;
    if (campo > 0) d += 1L << 52;
    for (int e = Math.Max(campo, 1) - 1075; e > 0; e--) d *= 2;
    for (int e = Math.Max(campo, 1) - 1075; e < 0; e++) d /= 2;
    if (x < 0) d = -d;
    return Math.Round(d, casas, MidpointRounding.ToEven).ToString("F" + casas, CultureInfo.InvariantCulture);
}

// round() do Python: o mesmo arredondamento, de volta para double
static double Arred(double x, int casas) {
    return double.Parse(FixoPar(x, casas), CultureInfo.InvariantCulture);
}

class Fato
{
    public string Chave, Valor;
    public int Dia;
    public double Importancia;
}

class Pontuado
{
    public double Score;
    public string Chave, Valor;

    public override string ToString()
    {
        return "(" + Score.ToString(CultureInfo.InvariantCulture) + ", '" + Chave + "', '" + Valor + "')";
    }
}

class MemoriaLonga
{
    List<Fato> fatos = new List<Fato>(); // lista para manter a ordem de inserção, como o dict

    public void Lembrar(string chave, string valor, int dia, double importancia = 1.0)
    {
        var novo = new Fato { Chave = chave, Valor = valor, Dia = dia, Importancia = importancia };
        int i = fatos.FindIndex(f => f.Chave == chave);
        if (i >= 0) fatos[i] = novo; // sobrescreve: atualização
        else fatos.Add(novo);
    }

    static HashSet<string> Palavras(string texto)
    {
        return new HashSet<string>(texto.ToLowerInvariant().Split((char[])null, StringSplitOptions.RemoveEmptyEntries));
    }

    public List<Pontuado> Recuperar(string consulta, int hoje, int k = 2, int meiaVida = 30)
    {
        var termos = Palavras(consulta);
        var pontuados = new List<Pontuado>();
        foreach (var f in fatos)
        {
            int relevancia = Palavras(f.Chave + " " + f.Valor).Count(p => termos.Contains(p));
            if (relevancia == 0) continue;
            double recencia = Math.Exp(-Math.Log(2) * (hoje - f.Dia) / meiaVida);
            double score = Arred(relevancia * recencia * f.Importancia, 3);
            pontuados.Add(new Pontuado { Score = score, Chave = f.Chave, Valor = f.Valor });
        }
        // como sorted(..., reverse=True) em tuplas: compara campo a campo, do maior para o menor
        return pontuados.OrderByDescending(p => p.Score)
            .ThenByDescending(p => p.Chave, StringComparer.Ordinal)
            .ThenByDescending(p => p.Valor, StringComparer.Ordinal)
            .Take(k).ToList();
    }
}

import (
	"fmt"
	"math"
	"sort"
	"strconv"
	"strings"
)

// round() do Python: o strconv arredonda o valor exato do double, com empate para o par
func arred(x float64, casas int) float64 {
	r, _ := strconv.ParseFloat(strconv.FormatFloat(x, 'f', casas, 64), 64)
	return r
}

type Fato struct {
	Valor       string
	Dia         int
	Importancia float64
}

type Pontuado struct {
	Score        float64
	Chave, Valor string
}

func (p Pontuado) String() string {
	return fmt.Sprintf("(%v, '%s', '%s')", p.Score, p.Chave, p.Valor)
}

type MemoriaLonga struct {
	fatos map[string]Fato
	ordem []string // o map do Go não guarda ordem; a ordem de inserção fica aqui, como no dict
}

func (m *MemoriaLonga) lembrar(chave, valor string, dia int, importancia float64) {
	if _, existe := m.fatos[chave]; !existe {
		m.ordem = append(m.ordem, chave)
	}
	m.fatos[chave] = Fato{valor, dia, importancia} // sobrescreve: atualização
}

func palavras(texto string) map[string]bool {
	r := map[string]bool{}
	for _, w := range strings.Fields(strings.ToLower(texto)) {
		r[w] = true
	}
	return r
}

func (m *MemoriaLonga) recuperar(consulta string, hoje, k, meiaVida int) []Pontuado {
	termos := palavras(consulta)
	pontuados := []Pontuado{}
	for _, chave := range m.ordem {
		f := m.fatos[chave]
		relevancia := 0
		for p := range palavras(chave + " " + f.Valor) {
			if termos[p] {
				relevancia++
			}
		}
		if relevancia == 0 {
			continue
		}
		recencia := math.Exp(-math.Log(2) * float64(hoje-f.Dia) / float64(meiaVida))
		score := arred(float64(relevancia)*recencia*f.Importancia, 3)
		pontuados = append(pontuados, Pontuado{score, chave, f.Valor})
	}
	// como sorted(..., reverse=True) em tuplas: compara campo a campo, do maior para o menor
	sort.SliceStable(pontuados, func(i, j int) bool {
		a, b := pontuados[i], pontuados[j]
		if a.Score != b.Score {
			return a.Score > b.Score
		}
		if a.Chave != b.Chave {
			return a.Chave > b.Chave
		}
		return a.Valor > b.Valor
	})
	if len(pontuados) > k {
		pontuados = pontuados[:k]
	}
	return pontuados
}

func main() {
	mem := &MemoriaLonga{fatos: map[string]Fato{}}
	mem.lembrar("cidade", "mora em Recife", 1, 1.0)
	mem.lembrar("linguagem", "programa em Go no trabalho", 10, 1.5)
	mem.lembrar("cidade", "mora em Curitiba", 80, 1.0) // mudou-se
	mem.lembrar("restaurante", "é vegetariano", 85, 1.0)

	fmt.Println(mem.recuperar("onde ele mora", 90, 2, 30))
	fmt.Println(mem.recuperar("sugira um restaurante onde ele mora", 90, 3, 30))
}

<Callout type="warning" title="Memória é dado pessoal">
O que o agente lembra sobre um usuário está sujeito a leis de proteção de dados (como a LGPD). Mostre ao usuário o que foi guardado, permita apagar, isole memórias por usuário e tenant e nunca deixe a memória de um vazar para outro. Memórias também são vetor de injeção: um texto malicioso gravado hoje é instrução amanhã.
</Callout>

## Armadilhas

- **Guardar tudo:** a memória vira ruído, e fatos irrelevantes poluem o contexto de toda conversa.
- **Fatos contraditórios:** sem atualização, o agente recebe "mora em Recife" e "mora em Curitiba" juntos.
- **Memória que nunca expira:** preferências mudam; use decaimento, datas e revisão.
- **Resumo como única fonte:** guarde também o histórico bruto em armazenamento barato, para auditoria e para reprocessar.

## Na entrevista

Separe curto prazo (gestão do contexto: janela, resumo, descarte) de longo prazo (fatos e episódios persistidos, com políticas de escrita, atualização, recuperação e expiração). Fale de privacidade e isolamento. Follow-ups: "como evitar que o resumo perca dados importantes?" (extrair entidades e fatos estruturados separadamente do resumo em prosa) e "como decidir o que vai para a memória longa?" (critérios de importância, confirmação do usuário para dados sensíveis, deduplicação e atualização por chave).
