Quando a resposta do LLM é lida por uma pessoa, texto livre basta. Quando ela é lida por código (gravar no banco, chamar uma API, preencher um formulário), você precisa de uma estrutura confiável. Um `json.loads` que falha em 2% das chamadas vira 2% de requisições com erro em produção, e um campo com tipo errado pode passar despercebido até corromper dados.

## Três níveis de garantia

1. **Só no prompt:** você descreve o formato e dá um exemplo. Funciona na maioria das vezes, mas o modelo pode envolver o JSON em texto ("Claro! Aqui está:"), esquecer um campo ou inventar outro.
2. **Modo JSON:** o provedor garante que a saída é JSON sintaticamente válido, mas não que segue o seu esquema.
3. **Esquema imposto (decodificação restrita):** você envia um JSON Schema e o servidor só permite, a cada passo, tokens que mantêm a saída válida para aquele esquema. A estrutura fica garantida por construção; o conteúdo, não.

A decodificação restrita funciona mascarando a distribuição do próximo token: tokens que quebrariam a gramática recebem probabilidade zero antes do sorteio. Vários provedores e bibliotecas de inferência local oferecem isso, cada um com o seu subconjunto suportado de JSON Schema. O mesmo mecanismo existe em tool calling: os argumentos de uma ferramenta são uma saída estruturada.

Um esquema típico para extrair dados de um e-mail de suporte:

```json
{
  "type": "object",
  "properties": {
    "categoria": { "type": "string", "enum": ["cobranca", "entrega", "defeito", "outro"] },
    "pedido_id": { "type": ["string", "null"] },
    "urgente": { "type": "boolean" },
    "resumo": { "type": "string" }
  },
  "required": ["categoria", "pedido_id", "urgente", "resumo"],
  "additionalProperties": false
}
```

Repare em `pedido_id` aceitando `null`: dar ao modelo uma saída legítima para "não encontrei" reduz a chance de ele inventar um número.

## Valide sempre do seu lado

Mesmo com esquema imposto, valide. Você pode trocar de provedor, cair num fallback sem suporte ou ter regras que o esquema não expressa (um CPF com dígito verificador, uma data no futuro). Em Python, bibliotecas como Pydantic fazem isso; abaixo, um validador mínimo só com a stdlib.

```python
import json

ESQUEMA = {
    "categoria": (str, {"cobranca", "entrega", "defeito", "outro"}),
    "pedido_id": ((str, type(None)), None),
    "urgente": (bool, None),
    "resumo": (str, None),
}

def validar(texto):
    try:
        dado = json.loads(texto)
    except json.JSONDecodeError as e:
        return None, [f"JSON invalido: {e.msg}"]
    erros = []
    for campo, (tipo, permitidos) in ESQUEMA.items():
        if campo not in dado:
            erros.append(f"falta o campo {campo}")
        elif not isinstance(dado[campo], tipo):
            erros.append(f"{campo} com tipo errado")
        elif permitidos and dado[campo] not in permitidos:
            erros.append(f"{campo} fora do enum: {dado[campo]}")
    extras = set(dado) - set(ESQUEMA)
    if extras:
        erros.append(f"campos extras: {sorted(extras)}")
    return (dado if not erros else None), erros

saidas = [
    '{"categoria": "entrega", "pedido_id": "A-981", "urgente": true, "resumo": "atrasou"}',
    'Claro! Aqui esta: {"categoria": "entrega"}',
    '{"categoria": "reembolso", "pedido_id": null, "urgente": "sim", "resumo": "quer o dinheiro"}',
]
for s in saidas:
    dado, erros = validar(s)
    print("ok" if dado else "falhou", erros)
```

```javascript
// campo -> [tipos aceitos (como o typeof do JS chama), valores permitidos ou null]
const ESQUEMA = {
  categoria: [["string"], new Set(["cobranca", "entrega", "defeito", "outro"])],
  pedido_id: [["string", "null"], null],
  urgente: [["boolean"], null],
  resumo: [["string"], null],
};

const tipo = (v) => (v === null ? "null" : typeof v);

function validar(texto) {
  let dado;
  try {
    dado = JSON.parse(texto);
  } catch (e) {
    return [null, [`JSON invalido: ${e.message}`]];  // a mensagem é a do parser do JS
  }
  const erros = [];
  for (const [campo, [tipos, permitidos]] of Object.entries(ESQUEMA)) {
    if (!(campo in dado)) {
      erros.push(`falta o campo ${campo}`);
    } else if (!tipos.includes(tipo(dado[campo]))) {
      erros.push(`${campo} com tipo errado`);
    } else if (permitidos && !permitidos.has(dado[campo])) {
      erros.push(`${campo} fora do enum: ${dado[campo]}`);
    }
  }
  const extras = Object.keys(dado).filter((k) => !(k in ESQUEMA));
  if (extras.length) {
    erros.push(`campos extras: [${extras.sort().map((k) => `'${k}'`).join(", ")}]`);
  }
  return [erros.length === 0 ? dado : null, erros];
}
```

```java
import java.util.*;

// JSON mínimo: a biblioteca padrão não traz parser (em produção: Jackson ou Gson).
// Objeto -> LinkedHashMap (guarda a ordem, como o dict), lista -> ArrayList, inteiro -> Long, real -> Double.
class Json {
    private final String s;
    private int i = 0;

    private Json(String s) { this.s = s; }

    static Object loads(String texto) {
        Json p = new Json(texto);
        Object v = p.valor();
        p.pular();
        if (p.i < texto.length()) throw new IllegalArgumentException("Extra data");
        return v;
    }

    private void pular() { while (i < s.length() && Character.isWhitespace(s.charAt(i))) i++; }

    private boolean ver(char c) { pular(); return i < s.length() && s.charAt(i) == c; }

    private void esperar(char c) {
        if (!ver(c)) throw new IllegalArgumentException("Expecting '" + c + "' delimiter");
        i++;
    }

    private Object valor() {
        if (ver('{')) {
            i++;
            Map<String, Object> m = new LinkedHashMap<>();
            if (ver('}')) { i++; return m; }
            while (true) {
                String chave = texto();
                esperar(':');
                m.put(chave, valor());
                if (!ver(',')) break;
                i++;
            }
            esperar('}');
            return m;
        }
        if (ver('[')) {
            i++;
            List<Object> l = new ArrayList<>();
            if (ver(']')) { i++; return l; }
            while (true) {
                l.add(valor());
                if (!ver(',')) break;
                i++;
            }
            esperar(']');
            return l;
        }
        if (ver('"')) return texto();
        for (String lit : new String[]{"true", "false", "null"}) {
            if (s.startsWith(lit, i)) { i += lit.length(); return lit.equals("null") ? null : lit.equals("true"); }
        }
        int ini = i;
        while (i < s.length() && "+-0123456789.eE".indexOf(s.charAt(i)) >= 0) i++;
        String num = s.substring(ini, i);
        if (num.isEmpty()) throw new IllegalArgumentException("Expecting value");
        if (num.matches("-?\\d+")) return Long.parseLong(num);
        return Double.parseDouble(num);
    }

    private String texto() {
        if (!ver('"')) throw new IllegalArgumentException("Expecting property name enclosed in double quotes");
        i++;
        StringBuilder sb = new StringBuilder();
        while (s.charAt(i) != '"') {
            char c = s.charAt(i++);
            if (c != '\\') { sb.append(c); continue; }
            char e = s.charAt(i++);
            if (e == 'n') sb.append('\n');
            else if (e == 'u') { sb.append((char) Integer.parseInt(s.substring(i, i + 4), 16)); i += 4; }
            else sb.append(e);  // \" \\ \/
        }
        i++;
        return sb.toString();
    }
}

// o nome que o Python daria ao tipo de cada valor vindo do JSON (o isinstance olha para isso)
static String tipo(Object v) {
    if (v == null) return "None";
    if (v instanceof String) return "str";
    if (v instanceof Boolean) return "bool";
    if (v instanceof Long) return "int";
    if (v instanceof Double) return "float";
    return v instanceof Map ? "dict" : "list";
}

static class Regra {
    Set<String> tipos;
    Set<String> permitidos;  // null: qualquer valor
    Regra(Set<String> tipos, Set<String> permitidos) { this.tipos = tipos; this.permitidos = permitidos; }
}

static final Map<String, Regra> ESQUEMA = new LinkedHashMap<>();
static {
    ESQUEMA.put("categoria", new Regra(Set.of("str"), Set.of("cobranca", "entrega", "defeito", "outro")));
    ESQUEMA.put("pedido_id", new Regra(Set.of("str", "None"), null));
    ESQUEMA.put("urgente", new Regra(Set.of("bool"), null));
    ESQUEMA.put("resumo", new Regra(Set.of("str"), null));
}

static class Validacao {
    Map<String, Object> dado;  // null quando falhou
    List<String> erros;
    Validacao(Map<String, Object> dado, List<String> erros) { this.dado = dado; this.erros = erros; }
}

@SuppressWarnings("unchecked")
static Validacao validar(String texto) {
    Map<String, Object> dado;
    try {
        dado = (Map<String, Object>) Json.loads(texto);
    } catch (IllegalArgumentException e) {
        return new Validacao(null, List.of("JSON invalido: " + e.getMessage()));
    }
    List<String> erros = new ArrayList<>();
    for (Map.Entry<String, Regra> e : ESQUEMA.entrySet()) {
        String campo = e.getKey();
        Regra regra = e.getValue();
        if (!dado.containsKey(campo)) {
            erros.add("falta o campo " + campo);
        } else if (!regra.tipos.contains(tipo(dado.get(campo)))) {
            erros.add(campo + " com tipo errado");
        } else if (regra.permitidos != null && !regra.permitidos.contains(dado.get(campo))) {
            erros.add(campo + " fora do enum: " + dado.get(campo));
        }
    }
    TreeSet<String> extras = new TreeSet<>(dado.keySet());
    extras.removeAll(ESQUEMA.keySet());
    if (!extras.isEmpty()) {
        erros.add("campos extras: " + extras);
    }
    return new Validacao(erros.isEmpty() ? dado : null, erros);
}

public static void main(String[] args) {
    String[] saidas = {
        "{\"categoria\": \"entrega\", \"pedido_id\": \"A-981\", \"urgente\": true, \"resumo\": \"atrasou\"}",
        "Claro! Aqui esta: {\"categoria\": \"entrega\"}",
        "{\"categoria\": \"reembolso\", \"pedido_id\": null, \"urgente\": \"sim\", \"resumo\": \"quer o dinheiro\"}",
    };
    for (String s : saidas) {
        Validacao v = validar(s);
        System.out.println((v.dado != null ? "ok" : "falhou") + " " + v.erros);
    }
}
```

```cpp
// valor dinâmico, como o que o json.loads do Python devolve: o C++ não traz um tipo assim
struct Valor {
    enum Tipo { NULO, BOOL, INT, REAL, TEXTO, LISTA, OBJETO } tipo = NULO;
    bool b = false;
    long long i = 0;
    double d = 0;
    string s;
    vector<Valor> itens;    // LISTA, ou os valores de um OBJETO
    vector<string> chaves;  // OBJETO: chaves na ordem de inserção, como o dict do Python

    Valor() {}
    Valor(bool v) : tipo(BOOL), b(v) {}
    Valor(long long v) : tipo(INT), i(v) {}
    Valor(double v) : tipo(REAL), d(v) {}
    Valor(const string& v) : tipo(TEXTO), s(v) {}
    static Valor objeto() { Valor r; r.tipo = OBJETO; return r; }
    static Valor lista() { Valor r; r.tipo = LISTA; return r; }

    bool tem(const string& k) const { return find(chaves.begin(), chaves.end(), k) != chaves.end(); }
    const Valor& operator[](const string& k) const {
        for (size_t j = 0; j < chaves.size(); j++) if (chaves[j] == k) return itens[j];
        throw out_of_range("KeyError: " + k);
    }
    void definir(const string& k, const Valor& v) {
        for (size_t j = 0; j < chaves.size(); j++) if (chaves[j] == k) { itens[j] = v; return; }
        chaves.push_back(k);
        itens.push_back(v);
    }
};

// JSON mínimo: a biblioteca padrão não traz parser (em produção: nlohmann/json)
struct LeitorJson {
    const string& s;
    size_t i = 0;

    void pular() { while (i < s.size() && isspace((unsigned char)s[i])) i++; }
    bool ver(char c) { pular(); return i < s.size() && s[i] == c; }
    void esperar(char c) {
        if (!ver(c)) throw invalid_argument(string("Expecting '") + c + "' delimiter");
        i++;
    }

    string texto() {
        if (!ver('"')) throw invalid_argument("Expecting property name enclosed in double quotes");
        i++;
        string r;
        while (s[i] != '"') {
            char c = s[i++];
            if (c != '\\') { r += c; continue; }
            char e = s[i++];
            if (e == 'n') r += '\n';
            else if (e == 'u') {  // \uXXXX volta a ser UTF-8
                unsigned cp = stoul(s.substr(i, 4), nullptr, 16);
                i += 4;
                if (cp < 0x80) r += char(cp);
                else if (cp < 0x800) r += char(0xC0 | cp >> 6), r += char(0x80 | (cp & 0x3F));
                else r += char(0xE0 | cp >> 12), r += char(0x80 | (cp >> 6 & 0x3F)), r += char(0x80 | (cp & 0x3F));
            } else r += e;  // \" \\ \/
        }
        i++;
        return r;
    }

    Valor valor() {
        if (ver('{')) {
            i++;
            Valor m = Valor::objeto();
            if (ver('}')) { i++; return m; }
            while (true) {
                string chave = texto();
                esperar(':');
                m.definir(chave, valor());
                if (!ver(',')) break;
                i++;
            }
            esperar('}');
            return m;
        }
        if (ver('[')) {
            i++;
            Valor l = Valor::lista();
            if (ver(']')) { i++; return l; }
            while (true) {
                l.itens.push_back(valor());
                if (!ver(',')) break;
                i++;
            }
            esperar(']');
            return l;
        }
        if (ver('"')) return texto();
        if (s.compare(i, 4, "true") == 0) { i += 4; return true; }
        if (s.compare(i, 5, "false") == 0) { i += 5; return false; }
        if (s.compare(i, 4, "null") == 0) { i += 4; return Valor(); }
        size_t ini = i;
        while (i < s.size() && s[i] && strchr("+-0123456789.eE", s[i])) i++;
        string num = s.substr(ini, i - ini);
        if (num.empty()) throw invalid_argument("Expecting value");
        if (num.find_first_of(".eE") == string::npos) return stoll(num);
        return stod(num);
    }
};

Valor loads(const string& texto) {
    LeitorJson p{texto};
    Valor v = p.valor();
    p.pular();
    if (p.i < texto.size()) throw invalid_argument("Extra data");
    return v;
}

// o nome que o Python daria ao tipo de cada valor vindo do JSON (o isinstance olha para isso)
string tipo(const Valor& v) {
    const char* nomes[] = {"None", "bool", "int", "float", "str", "list", "dict"};
    return nomes[v.tipo];
}

struct Regra {
    string campo;
    set<string> tipos;
    set<string> permitidos;  // vazio: qualquer valor
};

const vector<Regra> ESQUEMA = {
    {"categoria", {"str"}, {"cobranca", "entrega", "defeito", "outro"}},
    {"pedido_id", {"str", "None"}, {}},
    {"urgente", {"bool"}, {}},
    {"resumo", {"str"}, {}},
};

string lista(const vector<string>& v) {
    string r = "[";
    for (size_t j = 0; j < v.size(); j++) r += (j ? ", '" : "'") + v[j] + "'";
    return r + "]";
}

pair<optional<Valor>, vector<string>> validar(const string& texto) {
    Valor dado;
    try {
        dado = loads(texto);
    } catch (const invalid_argument& e) {
        return {nullopt, {string("JSON invalido: ") + e.what()}};
    }
    vector<string> erros;
    for (auto& [campo, tipos, permitidos] : ESQUEMA) {
        if (!dado.tem(campo)) {
            erros.push_back("falta o campo " + campo);
        } else if (!tipos.count(tipo(dado[campo]))) {
            erros.push_back(campo + " com tipo errado");
        } else if (!permitidos.empty() && !permitidos.count(dado[campo].s)) {
            erros.push_back(campo + " fora do enum: " + dado[campo].s);
        }
    }
    vector<string> extras;
    for (auto& k : dado.chaves) {
        bool conhecido = false;
        for (auto& r : ESQUEMA) conhecido = conhecido || r.campo == k;
        if (!conhecido) extras.push_back(k);
    }
    sort(extras.begin(), extras.end());
    if (!extras.empty()) {
        erros.push_back("campos extras: " + lista(extras));
    }
    if (erros.empty()) return {dado, erros};
    return {nullopt, erros};
}

int main() {
    vector<string> saidas = {
        R"({"categoria": "entrega", "pedido_id": "A-981", "urgente": true, "resumo": "atrasou"})",
        R"(Claro! Aqui esta: {"categoria": "entrega"})",
        R"({"categoria": "reembolso", "pedido_id": null, "urgente": "sim", "resumo": "quer o dinheiro"})",
    };
    for (auto& s : saidas) {
        auto [dado, erros] = validar(s);
        cout << (dado ? "ok" : "falhou") << " " << lista(erros) << "\n";
    }
}
```

```csharp
// JSON mínimo: o Mono do Judge0 não traz System.Text.Json (em produção: System.Text.Json).
// Objeto -> Dictionary (guarda a ordem de inserção), lista -> List<object>, inteiro -> long, real -> double.
```

```java
    private int i = 0;

    private Json(String s) { this.s = s; }

    static Object loads(String texto) {
        Json p = new Json(texto);
        Object v = p.valor();
        p.pular();
        if (p.i < texto.length()) throw new IllegalArgumentException("Extra data");
        return v;
    }

    private void pular() { while (i < s.length() && Character.isWhitespace(s.charAt(i))) i++; }

    private boolean ver(char c) { pular(); return i < s.length() && s.charAt(i) == c; }

    private void esperar(char c) {
        if (!ver(c)) throw new IllegalArgumentException("Expecting '" + c + "' delimiter");
        i++;
    }

    private Object valor() {
        if (ver('{')) {
            i++;
            Map<String, Object> m = new LinkedHashMap<>();
            if (ver('}')) { i++; return m; }
            while (true) {
                String chave = texto();
                esperar(':');
                m.put(chave, valor());
                if (!ver(',')) break;
                i++;

            esperar('}');

            i++;
            List<Object> l = new ArrayList<>();
            if (ver(']')) { i++; return l; }

                if (!ver(',')) break;
                i++;

            return l;

        String num = s.substring(ini, i);
        if (num.isEmpty()) throw new IllegalArgumentException("Expecting value");
        if (num.matches("-?\\d+")) return Long.parseLong(num);
        return Double.parseDouble(num);
    }

        if (!ver('"')) throw new IllegalArgumentException("Expecting property name enclosed in double quotes");

        if (v instanceof String) {
            StringBuilder sb = new StringBuilder("\"");
            for (char c : ((String) v).toCharArray()) {
                if (c == '"' || c == '\\') sb.append('\\').append(c);
                else if (c == '\n') sb.append("\\n");
                else if (c < 0x20 || c > 0x7e) sb.append(String.format("\\u%04x", (int) c));
                else sb.append(c);
            }
            return sb.append('"').toString();
        }
        if (v instanceof Map) {
            StringJoiner j = new StringJoiner(", ", "{", "}");
```

```cpp
        return stod(num);
    }
};

Valor loads(const string& texto) {
    LeitorJson p{texto};
    Valor v = p.valor();
    p.pular();
    if (p.i < texto.size()) throw invalid_argument("Extra data");
    return v;
}

// número real como o Python escreve: a forma mais curta, com ".0" se for inteiro
string numero(double d) {
    char buf[32];
    string t(buf, to_chars(buf, buf + sizeof buf, d).ptr);
    if (t.find_first_of(".e") == string::npos) t += ".0";
    return t;
}

// como o json.dumps do Python: separadores ", " e ": ", e ensure_ascii (acentos viram \uXXXX)
string dumps(const Valor& v) {
    switch (v.tipo) {
        case Valor::NULO: return "null";
        case Valor::BOOL: return v.b ? "true" : "false";
        case Valor::INT: return to_string(v.i);
        case Valor::REAL: return numero(v.d);
        case Valor::TEXTO: {
            string r = "\"";
            for (size_t k = 0; k < v.s.size(); k++) {
                unsigned char c = v.s[k];
                if (c == '"' || c == '\\') r += '\\', r += c;
                else if (c == '\n') r += "\\n";
                else if (c >= 0x80) {  // decodifica o UTF-8 para escrever o código do caractere
                    int n = c >= 0xE0 ? 2 : 1;
                    unsigned cp = c & (n == 2 ? 0x0F : 0x1F);
                    for (int m = 0; m < n; m++) cp = (cp << 6) | (v.s[++k] & 0x3F);
                    char esc[8];
                    snprintf(esc, sizeof esc, "\\u%04x", cp);
                    r += esc;
                } else r += c;
            }
            return r + "\"";
        }
        case Valor::LISTA: {
            string r = "[";
            for (size_t j = 0; j < v.itens.size(); j++) r += (j ? ", " : "") + dumps(v.itens[j]);
            return r + "]";
        }
        default: {
            string r = "{";
            for (size_t j = 0; j < v.chaves.size(); j++)
                r += (j ? ", " : "") + dumps(Valor(v.chaves[j])) + ": " + dumps(v.itens[j]);
            return r + "}";
        }
    }
}

// imita o repr() do Python para imprimir dicionários e listas
string repr(const Valor& v) {
    switch (v.tipo) {
        case Valor::NULO: return "None";
        case Valor::BOOL: return v.b ? "True" : "False";
        case Valor::TEXTO: return v.s.find("'") != string::npos ? "\"" + v.s + "\"" : "'" + v.s + "'";
        case Valor::LISTA: {
            string r = "[";
            for (size_t j = 0; j < v.itens.size(); j++) r += (j ? ", " : "") + repr(v.itens[j]);
            return r + "]";
        }
        case Valor::OBJETO: {

        }
        default: return dumps(v);
    }
}
```

```csharp
using System.Collections.Generic;

// JSON mínimo: o Mono do Judge0 não traz System.Text.Json (em produção: System.Text.Json).
// Objeto -> Dictionary (guarda a ordem de inserção), lista -> List<object>, inteiro -> long, real -> double.
class Json
{
    readonly string s;
    int i;

    Json(string s) { this.s = s; }

    public static object Loads(string texto)
    {
        var p = new Json(texto);
        object v = p.Valor();
        p.Pular();
        if (p.i < texto.Length) throw new FormatException("Extra data");
        return v;
    }

    void Pular() { while (i < s.Length && char.IsWhiteSpace(s[i])) i++; }

    bool Ver(char c) { Pular(); return i < s.Length && s[i] == c; }

    void Esperar(char c)
    {
        if (!Ver(c)) throw new FormatException("Expecting '" + c + "' delimiter");
        i++;
    }

    object Valor()
    {
        if (Ver('{'))
        {
            i++;
            var m = new Dictionary<string, object>();
            if (Ver('}')) { i++; return m; }
            while (true)
            {
                string chave = Texto();
                Esperar(':');
                m[chave] = Valor();
                if (!Ver(',')) break;
                i++;
            }
            Esperar('}');
            return m;
        }
        if (Ver('['))
        {
            i++;
            var l = new List<object>();
            if (Ver(']')) { i++; return l; }
            while (true)
            {
                l.Add(Valor());
                if (!Ver(',')) break;
                i++;
            }
            Esperar(']');
            return l;
        }
        if (Ver('"')) return Texto();
        if (string.CompareOrdinal(s, i, "true", 0, 4) == 0) { i += 4; return true; }
        if (string.CompareOrdinal(s, i, "false", 0, 5) == 0) { i += 5; return false; }
        if (string.CompareOrdinal(s, i, "null", 0, 4) == 0) { i += 4; return null; }
        int ini = i;
        while (i < s.Length && "+-0123456789.eE".IndexOf(s[i]) >= 0) i++;
        string num = s.Substring(ini, i - ini);
        if (num.Length == 0) throw new FormatException("Expecting value");
        if (num.IndexOfAny(new[] { '.', 'e', 'E' }) < 0) return long.Parse(num);
        return double.Parse(num, System.Globalization.CultureInfo.InvariantCulture);
    }

    string Texto()
    {
        if (!Ver('"')) throw new FormatException("Expecting property name enclosed in double quotes");
        i++;
        var sb = new StringBuilder();
        while (s[i] != '"')
        {
            char c = s[i++];
            if (c != '\\') { sb.Append(c); continue; }
            char e = s[i++];
            if (e == 'n') sb.Append('\n');
            else if (e == 'u') { sb.Append((char)Convert.ToInt32(s.Substring(i, 4), 16)); i += 4; }
            else sb.Append(e);  // \" \\ \/
        }
        i++;
        return sb.ToString();
    }

    // como o json.dumps do Python: separadores ", " e ": ", e ensure_ascii (acentos viram \uXXXX)
    public static string Dumps(object v)
    {
        if (v == null) return "null";
        if (v is bool b) return b ? "true" : "false";
        if (v is string s)
        {
            var sb = new StringBuilder("\"");
            foreach (char c in s)
            {
                if (c == '"' || c == '\\') sb.Append('\\').Append(c);
                else if (c == '\n') sb.Append("\\n");
                else if (c < 0x20 || c > 0x7e) sb.Append("\\u").Append(((int)c).ToString("x4"));
                else sb.Append(c);
            }
            return sb.Append('"').ToString();
        }
        if (v is Dictionary<string, object> d)
            return "{" + string.Join(", ", d.Select(e => Dumps(e.Key) + ": " + Dumps(e.Value))) + "}";
        if (v is List<object> l)
            return "[" + string.Join(", ", l.Select(Dumps)) + "]";
        return Convert.ToString(v, System.Globalization.CultureInfo.InvariantCulture);  // números
    }
}

}
```

## Armadilhas

- **Esquemas grandes e profundos** pioram a qualidade e podem não ser suportados pela decodificação restrita. Prefira estruturas rasas e campos com nomes autoexplicativos, com descrições.
- **Ordem dos campos importa:** se houver um campo de justificativa, coloque-o antes da conclusão, para o modelo "pensar" antes de decidir.
- **Formato forçado demais pode atrapalhar o raciocínio:** em tarefas difíceis, deixe o modelo raciocinar livre numa etapa e estruture o resultado em outra.
- **Enum sem saída de escape:** sem uma opção "outro", o modelo encaixa à força em uma categoria errada.
