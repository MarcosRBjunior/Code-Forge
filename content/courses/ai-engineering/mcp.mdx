Cada aplicação de IA que quer acessar GitHub, Slack, um banco de dados ou o sistema interno da empresa acaba escrevendo sua própria integração, no formato de ferramentas do seu framework. Com M aplicações e N sistemas, são M × N integrações. O **MCP (Model Context Protocol)** é um protocolo aberto que padroniza essa conexão: um sistema expõe suas capacidades uma vez, como **servidor MCP**, e qualquer aplicação compatível (o **cliente**) consegue descobri-las e usá-las. É a mesma ideia que padrões como o LSP trouxeram para editores e linguagens: o problema vira M + N.

## Papéis

```text
┌──────────── host (app de chat, IDE, agente) ────────────┐
│  LLM  ◄──►  cliente MCP ──┬──► servidor MCP: arquivos     │
│                           ├──► servidor MCP: banco SQL    │
│                           └──► servidor MCP: tickets      │
└──────────────────────────────────────────────────────────┘
```

- **Host:** a aplicação com a qual o usuário interage. Ela contém o LLM e decide o que mostrar e o que permitir.
- **Cliente:** a parte do host que mantém uma conexão com cada servidor.
- **Servidor:** um processo que expõe capacidades de um sistema.

As mensagens seguem **JSON-RPC 2.0**. O transporte pode ser local (o host inicia o servidor como subprocesso e conversa por stdin/stdout) ou remoto, via HTTP, quando o servidor roda como serviço, normalmente com autenticação baseada em OAuth.

## O que um servidor expõe

- **Ferramentas (tools):** funções que o modelo pode chamar, com nome, descrição e JSON Schema, exatamente como em tool calling.
- **Recursos (resources):** dados que a aplicação pode ler e colocar no contexto (arquivos, registros, documentos), identificados por URI.
- **Prompts:** modelos de prompt reutilizáveis que o usuário pode acionar.

A conexão começa com uma negociação de versão e capacidades; depois o cliente lista o que existe e chama o que precisa. O programa simula um servidor em memória e um cliente trocando mensagens JSON-RPC.

import json

class ServidorTickets:
    TOOLS = [{
        "name": "buscar_ticket",
        "description": "Busca um ticket de suporte pelo número.",
        "inputSchema": {"type": "object", "properties": {"numero": {"type": "integer"}},
                        "required": ["numero"]},
    }]
    DADOS = {42: "Impressora do 3o andar sem toner"}

    def tratar(self, bruto):
        req = json.loads(bruto)
        metodo, params = req["method"], req.get("params", {})
        if metodo == "initialize":
            resultado = {"serverInfo": {"name": "tickets"}, "capabilities": {"tools": {}}}
        elif metodo == "tools/list":
            resultado = {"tools": self.TOOLS}
        elif metodo == "tools/call":
            numero = params["arguments"]["numero"]
            texto = self.DADOS.get(numero, "ticket não encontrado")
            resultado = {"content": [{"type": "text", "text": texto}]}
        else:
            return json.dumps({"jsonrpc": "2.0", "id": req["id"],
                               "error": {"code": -32601, "message": "método não existe"}})
        return json.dumps({"jsonrpc": "2.0", "id": req["id"], "result": resultado})

class Cliente:
    def __init__(self, servidor):
        self.servidor, self.proximo_id = servidor, 1

    def chamar(self, metodo, params=None):
        req = {"jsonrpc": "2.0", "id": self.proximo_id, "method": metodo, "params": params or {}}
        self.proximo_id += 1
        resp = json.loads(self.servidor.tratar(json.dumps(req)))
        return resp.get("result", resp.get("error"))

cliente = Cliente(ServidorTickets())
print(cliente.chamar("initialize")["serverInfo"])
print([t["name"] for t in cliente.chamar("tools/list")["tools"]])
print(cliente.chamar("tools/call", {"name": "buscar_ticket", "arguments": {"numero": 42}}))
print(cliente.chamar("resources/list"))

import java.util.*;

// JSON mínimo: a biblioteca padrão não traz parser (em produção: Jackson ou Gson).
// Objeto -> LinkedHashMap (guarda a ordem, como o dict), lista -> ArrayList, inteiro -> Long, real -> Double.
class Json {
    private final String s;
    private int i = 0;

    private Json(String s) { this.s = s; }

    static Object loads(String texto) {
        Json p = new Json(texto);
        Object v = p.valor();
        p.pular();
        if (p.i < texto.length()) throw new IllegalArgumentException("Extra data");
        return v;
    }

    private void pular() { while (i < s.length() && Character.isWhitespace(s.charAt(i))) i++; }

    private boolean ver(char c) { pular(); return i < s.length() && s.charAt(i) == c; }

    private void esperar(char c) {
        if (!ver(c)) throw new IllegalArgumentException("Expecting '" + c + "' delimiter");
        i++;
    }

    private Object valor() {
        if (ver('{')) {
            i++;
            Map<String, Object> m = new LinkedHashMap<>();
            if (ver('}')) { i++; return m; }
            while (true) {
                String chave = texto();
                esperar(':');
                m.put(chave, valor());
                if (!ver(',')) break;
                i++;
            }
            esperar('}');
            return m;
        }
        if (ver('[')) {
            i++;
            List<Object> l = new ArrayList<>();
            if (ver(']')) { i++; return l; }
            while (true) {
                l.add(valor());
                if (!ver(',')) break;
                i++;
            }
            esperar(']');
            return l;
        }
        if (ver('"')) return texto();
        for (String lit : new String[]{"true", "false", "null"}) {
            if (s.startsWith(lit, i)) { i += lit.length(); return lit.equals("null") ? null : lit.equals("true"); }
        }
        int ini = i;
        while (i < s.length() && "+-0123456789.eE".indexOf(s.charAt(i)) >= 0) i++;
        String num = s.substring(ini, i);
        if (num.isEmpty()) throw new IllegalArgumentException("Expecting value");
        if (num.matches("-?\\d+")) return Long.parseLong(num);
        return Double.parseDouble(num);
    }

    private String texto() {
        if (!ver('"')) throw new IllegalArgumentException("Expecting property name enclosed in double quotes");
        i++;
        StringBuilder sb = new StringBuilder();
        while (s.charAt(i) != '"') {
            char c = s.charAt(i++);
            if (c != '\\') { sb.append(c); continue; }
            char e = s.charAt(i++);
            if (e == 'n') sb.append('\n');
            else if (e == 'u') { sb.append((char) Integer.parseInt(s.substring(i, i + 4), 16)); i += 4; }
            else sb.append(e);  // \" \\ \/
        }
        i++;
        return sb.toString();
    }

    // como o json.dumps do Python: separadores ", " e ": ", e ensure_ascii (acentos viram \\uXXXX)
    static String dumps(Object v) {
        if (v == null) return "null";
        if (v instanceof String) {
            StringBuilder sb = new StringBuilder("\"");
            for (char c : ((String) v).toCharArray()) {
                if (c == '"' || c == '\\') sb.append('\\').append(c);
                else if (c == '\n') sb.append("\\n");
                else if (c < 0x20 || c > 0x7e) sb.append(String.format("\\u%04x", (int) c));
                else sb.append(c);
            }
            return sb.append('"').toString();
        }
        if (v instanceof Map) {
            StringJoiner j = new StringJoiner(", ", "{", "}");
            for (Map.Entry<?, ?> e : ((Map<?, ?>) v).entrySet()) j.add(dumps(e.getKey()) + ": " + dumps(e.getValue()));
            return j.toString();
        }
        if (v instanceof List) {
            StringJoiner j = new StringJoiner(", ", "[", "]");
            for (Object x : (List<?>) v) j.add(dumps(x));
            return j.toString();
        }
        return String.valueOf(v);  // números e booleanos
    }
}

// imita o repr() do Python para imprimir dicionários e listas
static String repr(Object v) {
    if (v == null) return "None";
    if (v instanceof Boolean) return (Boolean) v ? "True" : "False";
    if (v instanceof String) return "'" + v + "'";
    if (v instanceof Map) {
        StringJoiner j = new StringJoiner(", ", "{", "}");
        for (Map.Entry<?, ?> e : ((Map<?, ?>) v).entrySet()) j.add(repr(e.getKey()) + ": " + repr(e.getValue()));
        return j.toString();
    }
    if (v instanceof List) {
        StringJoiner j = new StringJoiner(", ", "[", "]");
        for (Object x : (List<?>) v) j.add(repr(x));
        return j.toString();
    }
    return String.valueOf(v);
}

// dicionário que guarda a ordem de inserção, como o dict do Python
static Map<String, Object> mapa(Object... kv) {
    Map<String, Object> m = new LinkedHashMap<>();
    for (int i = 0; i < kv.length; i += 2) m.put((String) kv[i], kv[i + 1]);
    return m;
}

@SuppressWarnings("unchecked")
static Map<String, Object> obj(Object v) { return (Map<String, Object>) v; }

class ServidorTickets {
    static final List<Object> TOOLS = List.of(mapa(
        "name", "buscar_ticket",
        "description", "Busca um ticket de suporte pelo número.",
        "inputSchema", mapa("type", "object", "properties", mapa("numero", mapa("type", "integer")),
                            "required", List.of("numero"))));
    static final Map<Long, String> DADOS = Map.of(42L, "Impressora do 3o andar sem toner");

    String tratar(String bruto) {
        Map<String, Object> req = obj(Json.loads(bruto));
        String metodo = (String) req.get("method");
        Map<String, Object> params = obj(req.getOrDefault("params", mapa()));
        Object resultado;
        if (metodo.equals("initialize")) {
            resultado = mapa("serverInfo", mapa("name", "tickets"), "capabilities", mapa("tools", mapa()));
        } else if (metodo.equals("tools/list")) {
            resultado = mapa("tools", TOOLS);
        } else if (metodo.equals("tools/call")) {
            Long numero = (Long) obj(params.get("arguments")).get("numero");
            String texto = DADOS.getOrDefault(numero, "ticket não encontrado");
            resultado = mapa("content", List.of(mapa("type", "text", "text", texto)));
        } else {
            return Json.dumps(mapa("jsonrpc", "2.0", "id", req.get("id"),
                                   "error", mapa("code", -32601, "message", "método não existe")));
        }
        return Json.dumps(mapa("jsonrpc", "2.0", "id", req.get("id"), "result", resultado));
    }
}

class Cliente {
    ServidorTickets servidor;
    long proximoId = 1;

    Cliente(ServidorTickets servidor) { this.servidor = servidor; }

    Object chamar(String metodo, Map<String, Object> params) {
        Map<String, Object> req = mapa("jsonrpc", "2.0", "id", proximoId, "method", metodo,
                                       "params", params != null ? params : mapa());
        proximoId++;
        Map<String, Object> resp = obj(Json.loads(servidor.tratar(Json.dumps(req))));
        return resp.containsKey("result") ? resp.get("result") : resp.get("error");
    }

    Object chamar(String metodo) { return chamar(metodo, null); }
}

public static void main(String[] args) {
    Cliente cliente = new Cliente(new ServidorTickets());
    System.out.println(repr(obj(cliente.chamar("initialize")).get("serverInfo")));
    List<Object> nomes = new ArrayList<>();
    for (Object t : (List<?>) obj(cliente.chamar("tools/list")).get("tools")) nomes.add(obj(t).get("name"));
    System.out.println(repr(nomes));
    System.out.println(repr(cliente.chamar("tools/call", mapa("name", "buscar_ticket", "arguments", mapa("numero", 42)))));
    System.out.println(repr(cliente.chamar("resources/list")));
}

#include <algorithm>
#include <charconv>
#include <cstdio>
#include <cstring>
#include <iostream>
#include <map>
#include <stdexcept>
#include <string>
#include <utility>

using namespace std;

// valor dinâmico, como o que o json.loads do Python devolve: o C++ não traz um tipo assim
struct Valor {
    enum Tipo { NULO, BOOL, INT, REAL, TEXTO, LISTA, OBJETO } tipo = NULO;
    bool b = false;
    long long i = 0;
    double d = 0;
    string s;
    vector<Valor> itens;    // LISTA, ou os valores de um OBJETO
    vector<string> chaves;  // OBJETO: chaves na ordem de inserção, como o dict do Python

    Valor() {}
    Valor(bool v) : tipo(BOOL), b(v) {}
    Valor(int v) : tipo(INT), i(v) {}
    Valor(long long v) : tipo(INT), i(v) {}
    Valor(double v) : tipo(REAL), d(v) {}
    Valor(const char* v) : tipo(TEXTO), s(v) {}
    Valor(const string& v) : tipo(TEXTO), s(v) {}
    Valor(initializer_list<pair<const char*, Valor>> kv) : tipo(OBJETO) {
        for (auto& [k, v] : kv) definir(k, v);
    }
    static Valor objeto() { Valor r; r.tipo = OBJETO; return r; }
    static Valor lista(vector<Valor> v) { Valor r; r.tipo = LISTA; r.itens = move(v); return r; }

    bool tem(const string& k) const { return find(chaves.begin(), chaves.end(), k) != chaves.end(); }
    const Valor& operator[](const string& k) const {
        for (size_t j = 0; j < chaves.size(); j++) if (chaves[j] == k) return itens[j];
        throw out_of_range("KeyError: " + k);
    }
    void definir(const string& k, const Valor& v) {
        for (size_t j = 0; j < chaves.size(); j++) if (chaves[j] == k) { itens[j] = v; return; }
        chaves.push_back(k);
        itens.push_back(v);
    }
};

// JSON mínimo: a biblioteca padrão não traz parser (em produção: nlohmann/json)
struct LeitorJson {
    const string& s;
    size_t i = 0;

    void pular() { while (i < s.size() && isspace((unsigned char)s[i])) i++; }
    bool ver(char c) { pular(); return i < s.size() && s[i] == c; }
    void esperar(char c) {
        if (!ver(c)) throw invalid_argument(string("Expecting '") + c + "' delimiter");
        i++;
    }

    string texto() {
        if (!ver('"')) throw invalid_argument("Expecting property name enclosed in double quotes");
        i++;
        string r;
        while (s[i] != '"') {
            char c = s[i++];
            if (c != '\\') { r += c; continue; }
            char e = s[i++];
            if (e == 'n') r += '\n';
            else if (e == 'u') {  // \uXXXX volta a ser UTF-8
                unsigned cp = stoul(s.substr(i, 4), nullptr, 16);
                i += 4;
                if (cp < 0x80) r += char(cp);
                else if (cp < 0x800) r += char(0xC0 | cp >> 6), r += char(0x80 | (cp & 0x3F));
                else r += char(0xE0 | cp >> 12), r += char(0x80 | (cp >> 6 & 0x3F)), r += char(0x80 | (cp & 0x3F));
            } else r += e;  // \" \\ \/
        }
        i++;
        return r;
    }

    Valor valor() {
        if (ver('{')) {
            i++;
            Valor m = Valor::objeto();
            if (ver('}')) { i++; return m; }
            while (true) {
                string chave = texto();
                esperar(':');
                m.definir(chave, valor());
                if (!ver(',')) break;
                i++;
            }
            esperar('}');
            return m;
        }
        if (ver('[')) {
            i++;
            Valor l = Valor::lista({});
            if (ver(']')) { i++; return l; }
            while (true) {
                l.itens.push_back(valor());
                if (!ver(',')) break;
                i++;
            }
            esperar(']');
            return l;
        }
        if (ver('"')) return texto();
        if (s.compare(i, 4, "true") == 0) { i += 4; return true; }
        if (s.compare(i, 5, "false") == 0) { i += 5; return false; }
        if (s.compare(i, 4, "null") == 0) { i += 4; return Valor(); }
        size_t ini = i;
        while (i < s.size() && s[i] && strchr("+-0123456789.eE", s[i])) i++;
        string num = s.substr(ini, i - ini);
        if (num.empty()) throw invalid_argument("Expecting value");
        if (num.find_first_of(".eE") == string::npos) return stoll(num);
        return stod(num);
    }
};

Valor loads(const string& texto) {
    LeitorJson p{texto};
    Valor v = p.valor();
    p.pular();
    if (p.i < texto.size()) throw invalid_argument("Extra data");
    return v;
}

// número real como o Python escreve: a forma mais curta, com ".0" se for inteiro
string numero(double d) {
    char buf[32];
    string t(buf, to_chars(buf, buf + sizeof buf, d).ptr);
    if (t.find_first_of(".e") == string::npos) t += ".0";
    return t;
}

// como o json.dumps do Python: separadores ", " e ": ", e ensure_ascii (acentos viram \uXXXX)
string dumps(const Valor& v) {
    switch (v.tipo) {
        case Valor::NULO: return "null";
        case Valor::BOOL: return v.b ? "true" : "false";
        case Valor::INT: return to_string(v.i);
        case Valor::REAL: return numero(v.d);
        case Valor::TEXTO: {
            string r = "\"";
            for (size_t k = 0; k < v.s.size(); k++) {
                unsigned char c = v.s[k];
                if (c == '"' || c == '\\') r += '\\', r += c;
                else if (c == '\n') r += "\\n";
                else if (c >= 0x80) {  // decodifica o UTF-8 para escrever o código do caractere
                    int n = c >= 0xE0 ? 2 : 1;
                    unsigned cp = c & (n == 2 ? 0x0F : 0x1F);
                    for (int m = 0; m < n; m++) cp = (cp << 6) | (v.s[++k] & 0x3F);
                    char esc[8];
                    snprintf(esc, sizeof esc, "\\u%04x", cp);
                    r += esc;
                } else r += c;
            }
            return r + "\"";
        }
        case Valor::LISTA: {
            string r = "[";
            for (size_t j = 0; j < v.itens.size(); j++) r += (j ? ", " : "") + dumps(v.itens[j]);
            return r + "]";
        }
        default: {
            string r = "{";
            for (size_t j = 0; j < v.chaves.size(); j++)
                r += (j ? ", " : "") + dumps(Valor(v.chaves[j])) + ": " + dumps(v.itens[j]);
            return r + "}";
        }
    }
}

// imita o repr() do Python para imprimir dicionários e listas
string repr(const Valor& v) {
    switch (v.tipo) {
        case Valor::NULO: return "None";
        case Valor::BOOL: return v.b ? "True" : "False";
        case Valor::TEXTO: return "'" + v.s + "'";
        case Valor::LISTA: {
            string r = "[";
            for (size_t j = 0; j < v.itens.size(); j++) r += (j ? ", " : "") + repr(v.itens[j]);
            return r + "]";
        }
        case Valor::OBJETO: {
            string r = "{";
            for (size_t j = 0; j < v.chaves.size(); j++)
                r += (j ? ", " : "") + repr(Valor(v.chaves[j])) + ": " + repr(v.itens[j]);
            return r + "}";
        }
        default: return dumps(v);
    }
}

using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

// JSON mínimo: o Mono do Judge0 não traz System.Text.Json (em produção: System.Text.Json).
// Objeto -> Dictionary (guarda a ordem de inserção), lista -> List<object>, inteiro -> long, real -> double.
class Json
{
    readonly string s;
    int i;

    Json(string s) { this.s = s; }

    public static object Loads(string texto)
    {
        var p = new Json(texto);
        object v = p.Valor();
        p.Pular();
        if (p.i < texto.Length) throw new FormatException("Extra data");
        return v;
    }

    void Pular() { while (i < s.Length && char.IsWhiteSpace(s[i])) i++; }

    bool Ver(char c) { Pular(); return i < s.Length && s[i] == c; }

    void Esperar(char c)
    {
        if (!Ver(c)) throw new FormatException("Expecting '" + c + "' delimiter");
        i++;
    }

    object Valor()
    {
        if (Ver('{'))
        {
            i++;
            var m = new Dictionary<string, object>();
            if (Ver('}')) { i++; return m; }
            while (true)
            {
                string chave = Texto();
                Esperar(':');
                m[chave] = Valor();
                if (!Ver(',')) break;
                i++;
            }
            Esperar('}');
            return m;
        }
        if (Ver('['))
        {
            i++;
            var l = new List<object>();
            if (Ver(']')) { i++; return l; }
            while (true)
            {
                l.Add(Valor());
                if (!Ver(',')) break;
                i++;
            }
            Esperar(']');
            return l;
        }
        if (Ver('"')) return Texto();
        if (string.CompareOrdinal(s, i, "true", 0, 4) == 0) { i += 4; return true; }
        if (string.CompareOrdinal(s, i, "false", 0, 5) == 0) { i += 5; return false; }
        if (string.CompareOrdinal(s, i, "null", 0, 4) == 0) { i += 4; return null; }
        int ini = i;
        while (i < s.Length && "+-0123456789.eE".IndexOf(s[i]) >= 0) i++;
        string num = s.Substring(ini, i - ini);
        if (num.Length == 0) throw new FormatException("Expecting value");
        if (num.IndexOfAny(new[] { '.', 'e', 'E' }) < 0) return long.Parse(num);
        return double.Parse(num, System.Globalization.CultureInfo.InvariantCulture);
    }

    string Texto()
    {
        if (!Ver('"')) throw new FormatException("Expecting property name enclosed in double quotes");
        i++;
        var sb = new StringBuilder();
        while (s[i] != '"')
        {
            char c = s[i++];
            if (c != '\\') { sb.Append(c); continue; }
            char e = s[i++];
            if (e == 'n') sb.Append('\n');
            else if (e == 'u') { sb.Append((char)Convert.ToInt32(s.Substring(i, 4), 16)); i += 4; }
            else sb.Append(e);  // \" \\ \/
        }
        i++;
        return sb.ToString();
    }

    // como o json.dumps do Python: separadores ", " e ": ", e ensure_ascii (acentos viram \uXXXX)
    public static string Dumps(object v)
    {
        if (v == null) return "null";
        if (v is bool b) return b ? "true" : "false";
        if (v is string s)
        {
            var sb = new StringBuilder("\"");
            foreach (char c in s)
            {
                if (c == '"' || c == '\\') sb.Append('\\').Append(c);
                else if (c == '\n') sb.Append("\\n");
                else if (c < 0x20 || c > 0x7e) sb.Append("\\u").Append(((int)c).ToString("x4"));
                else sb.Append(c);
            }
            return sb.Append('"').ToString();
        }
        if (v is Dictionary<string, object> d)
            return "{" + string.Join(", ", d.Select(e => Dumps(e.Key) + ": " + Dumps(e.Value))) + "}";
        if (v is List<object> l)
            return "[" + string.Join(", ", l.Select(Dumps)) + "]";
        return Convert.ToString(v, System.Globalization.CultureInfo.InvariantCulture);  // números
    }
}

// imita o repr() do Python para imprimir dicionários e listas
static string Repr(object v)
{
    if (v == null) return "None";
    if (v is bool b) return b ? "True" : "False";
    if (v is string s) return "'" + s + "'";
    if (v is Dictionary<string, object> d)
        return "{" + string.Join(", ", d.Select(e => Repr(e.Key) + ": " + Repr(e.Value))) + "}";
    if (v is List<object> l)
        return "[" + string.Join(", ", l.Select(Repr)) + "]";
    return Json.Dumps(v);
}

// dicionário montado na ordem dos argumentos, como o literal {...} do Python
static Dictionary<string, object> Mapa(params object[] kv)
{
    var m = new Dictionary<string, object>();
    for (int i = 0; i < kv.Length; i += 2) m[(string)kv[i]] = kv[i + 1];
    return m;
}

static Dictionary<string, object> Obj(object v) => (Dictionary<string, object>)v;

class ServidorTickets
{
    static readonly List<object> Tools = new List<object>
    {
        Mapa("name", "buscar_ticket",
             "description", "Busca um ticket de suporte pelo número.",
             "inputSchema", Mapa("type", "object", "properties", Mapa("numero", Mapa("type", "integer")),
                                 "required", new List<object> { "numero" })),
    };
    static readonly Dictionary<long, string> Dados = new Dictionary<long, string> { [42] = "Impressora do 3o andar sem toner" };

    public string Tratar(string bruto)
    {
        var req = Obj(Json.Loads(bruto));
        string metodo = (string)req["method"];
        var parametros = req.ContainsKey("params") ? Obj(req["params"]) : Mapa();
        object resultado;
        if (metodo == "initialize")
            resultado = Mapa("serverInfo", Mapa("name", "tickets"), "capabilities", Mapa("tools", Mapa()));
        else if (metodo == "tools/list")
            resultado = Mapa("tools", Tools);
        else if (metodo == "tools/call")
        {
            long numero = (long)Obj(parametros["arguments"])["numero"];
            string texto = Dados.TryGetValue(numero, out string t) ? t : "ticket não encontrado";
            resultado = Mapa("content", new List<object> { Mapa("type", "text", "text", texto) });
        }
        else
            return Json.Dumps(Mapa("jsonrpc", "2.0", "id", req["id"],
                                   "error", Mapa("code", -32601, "message", "método não existe")));
        return Json.Dumps(Mapa("jsonrpc", "2.0", "id", req["id"], "result", resultado));
    }
}

## Do MCP para o LLM

O modelo não fala MCP. O host lista as ferramentas de todos os servidores conectados, converte cada uma para o formato de ferramenta da API do modelo que está usando e, quando o modelo pede uma tool call, roteia a chamada para o servidor certo. Prefixar o nome com o servidor evita colisões entre ferramentas homônimas.

<Callout type="warning" title="Servidor MCP é código de terceiros com acesso ao seu contexto">
Um servidor pode devolver texto com instruções maliciosas (prompt injection), descrever ferramentas de forma enganosa ou mudar de comportamento após uma atualização. Instale só servidores confiáveis, fixe versões, dê o mínimo de permissão e exija confirmação do usuário para ações sensíveis.
</Callout>

## Trade-offs

| Vantagem | Custo |
| --- | --- |
| Integração escrita uma vez, usada por vários hosts | Mais um processo ou serviço para operar |
| Descoberta dinâmica de ferramentas | Muitas ferramentas listadas consomem contexto |
| Ecossistema de servidores prontos | Qualidade e segurança variam entre servidores |
| Separação clara entre app e sistema | Latência extra em transporte remoto |

Se a sua aplicação só usa duas ferramentas internas, chamar as funções diretamente é mais simples. O MCP compensa quando há muitos sistemas, vários hosts ou quando você quer que usuários pluguem as próprias integrações.
