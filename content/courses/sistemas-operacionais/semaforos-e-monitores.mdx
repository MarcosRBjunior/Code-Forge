Um lock resolve "só um de cada vez". Mas muitos problemas reais pedem outra coisa: "no máximo 10 conexões simultâneas ao banco", "o consumidor espera até haver item na fila", "o produtor espera até haver espaço". Para isso existem dois blocos de construção clássicos: o **semáforo**, um contador protegido, e o **monitor**, que junta lock e condições de espera numa abstração mais segura. Toda fila bloqueante, pool de conexões e rate limiter que você usa é construído com eles.

## Semáforos

Um semáforo é um inteiro não negativo com duas operações atômicas:

- **wait** (também `P`, `acquire`, `down`): se o valor é maior que zero, decrementa e segue; se é zero, bloqueia até alguém incrementar.
- **signal** (também `V`, `release`, `up`): incrementa e acorda uma thread bloqueada, se houver.

Com valor inicial 1, ele funciona como um lock (**semáforo binário**). Com valor inicial N, ele limita a N o número de threads num trecho (**semáforo contador**). Diferente de um mutex, o semáforo não tem dono: uma thread pode fazer `wait` e outra o `signal`, o que o torna útil para sinalização entre threads.

O exemplo limita a 3 o número de "consultas ao banco" simultâneas, mesmo com 8 threads querendo entrar, e registra o pico de concorrência observado:

<CodeTabs>

```python
import threading

vagas = threading.Semaphore(3)
trava = threading.Lock()
ativas = 0
pico = 0
atendidas = 0

def consultar():
    global ativas, pico, atendidas
    with vagas:
        with trava:
            ativas += 1
            pico = max(pico, ativas)
        for _ in range(20_000):   # simula trabalho
            pass
        with trava:
            ativas -= 1
            atendidas += 1

threads = [threading.Thread(target=consultar) for _ in range(8)]
for t in threads:
    t.start()
for t in threads:
    t.join()
print("atendidas:", atendidas)
print("pico de concorrencia <= 3:", pico <= 3)
```

```java
import java.util.*;
import java.util.concurrent.Semaphore;

static final Semaphore vagas = new Semaphore(3);
static final Object trava = new Object();
static int ativas = 0;
static int pico = 0;
static int atendidas = 0;

static void consultar() {
    vagas.acquireUninterruptibly();
    try {
        synchronized (trava) {
            ativas += 1;
            pico = Math.max(pico, ativas);
        }
        for (int i = 0; i < 20_000; i++) { }   // simula trabalho
        synchronized (trava) {
            ativas -= 1;
            atendidas += 1;
        }
    } finally {
        vagas.release();
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> threads = new ArrayList<>();
    for (int i = 0; i < 8; i++) threads.add(new Thread(() -> consultar()));
    for (Thread t : threads) t.start();
    for (Thread t : threads) t.join();
    System.out.println("atendidas: " + atendidas);
    System.out.println("pico de concorrencia <= 3: " + (pico <= 3 ? "True" : "False"));
}
```

```go
	}
	wg.Wait()
```

## Produtor e consumidor

O problema clássico: produtores colocam itens num buffer de capacidade limitada, consumidores retiram. Precisamos de três coisas: exclusão mútua no buffer, consumidor esperar quando vazio e produtor esperar quando cheio. Com semáforos, a receita usa três deles:

```text
 mutex  = 1          protege o buffer
 vazios = N          vagas livres
 cheios = 0          itens disponíveis

 produtor:  wait(vazios); wait(mutex); coloca; signal(mutex); signal(cheios)
 consumidor: wait(cheios); wait(mutex); retira; signal(mutex); signal(vazios)
```

A ordem importa. Se o produtor fizer `wait(mutex)` antes de `wait(vazios)` com o buffer cheio, ele dorme segurando o mutex, e o consumidor nunca consegue entrar para liberar espaço: deadlock. É o tipo de erro sutil que levou à criação dos monitores.

## Monitores e variáveis de condição

Um **monitor** é um objeto cujos métodos executam com exclusão mútua automática e que oferece **variáveis de condição** para esperar por um predicado. `wait` na condição solta o lock e dorme atomicamente; ao acordar, readquire o lock. `notify` acorda quem espera. Em Java, todo objeto é um monitor (`synchronized`, `wait`, `notify`); em Python, você monta um com `threading.Condition`.

<CodeTabs>

```python
import threading
from collections import deque

class BufferLimitado:
    def __init__(self, capacidade):
        self.itens = deque()
        self.capacidade = capacidade
        self.cond = threading.Condition()
        self.maior_ocupacao = 0

    def colocar(self, item):
        with self.cond:
            while len(self.itens) == self.capacidade:   # while, nunca if
                self.cond.wait()
            self.itens.append(item)
            self.maior_ocupacao = max(self.maior_ocupacao, len(self.itens))
            self.cond.notify_all()

    def retirar(self):
        with self.cond:
            while not self.itens:
                self.cond.wait()
            item = self.itens.popleft()
            self.cond.notify_all()
            return item

buf = BufferLimitado(capacidade=4)
consumidos = []

def produtor(base):
    for i in range(50):
        buf.colocar(base + i)

def consumidor():
    for _ in range(50):
        consumidos.append(buf.retirar())

ts = [threading.Thread(target=produtor, args=(b,)) for b in (0, 1000)]
ts += [threading.Thread(target=consumidor) for _ in range(2)]
for t in ts:
    t.start()
for t in ts:
    t.join()
print("itens consumidos:", len(consumidos), "soma:", sum(consumidos))
print("ocupacao nunca passou da capacidade:", buf.maior_ocupacao <= 4)
```

```java
import java.util.*;

static class BufferLimitado {
    private final ArrayDeque<Integer> itens = new ArrayDeque<>();
    private final int capacidade;
    int maiorOcupacao = 0;

    BufferLimitado(int capacidade) {
        this.capacidade = capacidade;
    }

    synchronized void colocar(int item) throws InterruptedException {
        while (itens.size() == capacidade) {   // while, nunca if
            wait();
        }
        itens.addLast(item);
        maiorOcupacao = Math.max(maiorOcupacao, itens.size());
        notifyAll();
    }

    synchronized int retirar() throws InterruptedException {
        while (itens.isEmpty()) {
            wait();
        }
        int item = itens.pollFirst();
        notifyAll();
        return item;
    }
}

static final BufferLimitado buf = new BufferLimitado(4);
static final List<Integer> consumidos = Collections.synchronizedList(new ArrayList<>());

static void produtor(int base) {
    try {
        for (int i = 0; i < 50; i++) buf.colocar(base + i);
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    }
}

static void consumidor() {
    try {
        for (int i = 0; i < 50; i++) consumidos.add(buf.retirar());
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    }
}

public static void main(String[] args) throws InterruptedException {
    List<Thread> ts = new ArrayList<>();
    for (int b : new int[]{0, 1000}) ts.add(new Thread(() -> produtor(b)));
    for (int i = 0; i < 2; i++) ts.add(new Thread(() -> consumidor()));
    for (Thread t : ts) t.start();
    for (Thread t : ts) t.join();
    long soma = 0;
    for (int x : consumidos) soma += x;
    System.out.println("itens consumidos: " + consumidos.size() + " soma: " + soma);
    System.out.println("ocupacao nunca passou da capacidade: " + (buf.maiorOcupacao <= 4 ? "True" : "False"));
}
```

```cpp
#include <algorithm>
#include <condition_variable>
#include <deque>
#include <iostream>
#include <mutex>
#include <thread>
#include <vector>
using namespace std;

class BufferLimitado {
    deque<int> itens;
    size_t capacidade;
    mutex m;
    condition_variable cond;

public:
    size_t maiorOcupacao = 0;

    explicit BufferLimitado(size_t capacidade) : capacidade(capacidade) {}

    void colocar(int item) {
        unique_lock<mutex> trava(m);
        while (itens.size() == capacidade) {   // while, nunca if
            cond.wait(trava);
        }
        itens.push_back(item);
        maiorOcupacao = max(maiorOcupacao, itens.size());
        cond.notify_all();
    }

    int retirar() {
        unique_lock<mutex> trava(m);
        while (itens.empty()) {
            cond.wait(trava);
        }
        int item = itens.front();
        itens.pop_front();
        cond.notify_all();
        return item;
    }
};

BufferLimitado buf(4);
vector<int> consumidos;
mutex travaConsumidos;

void produtor(int base) {
    for (int i = 0; i < 50; i++) buf.colocar(base + i);
}

void consumidor() {
    for (int i = 0; i < 50; i++) {
        int item = buf.retirar();
        lock_guard<mutex> guarda(travaConsumidos);
        consumidos.push_back(item);
    }
}

int main() {
    vector<thread> ts;
    for (int b : {0, 1000}) ts.emplace_back(produtor, b);
    for (int i = 0; i < 2; i++) ts.emplace_back(consumidor);
    for (auto& t : ts) t.join();
    long long soma = 0;
    for (int x : consumidos) soma += x;
    cout << "itens consumidos: " << consumidos.size() << " soma: " << soma << endl;
    cout << "ocupacao nunca passou da capacidade: " << (buf.maiorOcupacao <= 4 ? "True" : "False") << endl;
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Threading;

class BufferLimitado
{
    private readonly Queue<int> itens = new Queue<int>();
    private readonly int capacidade;
    private readonly object cond = new object();
    public int MaiorOcupacao = 0;

    public BufferLimitado(int capacidade)
    {
        this.capacidade = capacidade;
    }

    public void Colocar(int item)
    {
        lock (cond)
        {
            while (itens.Count == capacidade)   // while, nunca if
                Monitor.Wait(cond);
            itens.Enqueue(item);
            MaiorOcupacao = Math.Max(MaiorOcupacao, itens.Count);
            Monitor.PulseAll(cond);
        }
    }

    public int Retirar()
    {
        lock (cond)
        {
            while (itens.Count == 0)
                Monitor.Wait(cond);
            int item = itens.Dequeue();
            Monitor.PulseAll(cond);
            return item;
        }
    }
}

static readonly BufferLimitado buf = new BufferLimitado(4);
static readonly List<int> consumidos = new List<int>();

static void Produtor(int b)
{
    for (int i = 0; i < 50; i++) buf.Colocar(b + i);
}

static void Consumidor()
{
    for (int i = 0; i < 50; i++)
    {
        int item = buf.Retirar();
        lock (consumidos) { consumidos.Add(item); }
    }
}

static void Main()
{
    var ts = new List<Thread>();
    foreach (int b in new[] { 0, 1000 }) ts.Add(new Thread(() => Produtor(b)));
    for (int i = 0; i < 2; i++) ts.Add(new Thread(Consumidor));
    foreach (var t in ts) t.Start();
    foreach (var t in ts) t.Join();
    long soma = 0;
    foreach (int x in consumidos) soma += x;
```

```go
import (
	"fmt"
	"sync"
)

type BufferLimitado struct {
	itens         []int
	capacidade    int
	mu            sync.Mutex
	cond          *sync.Cond
	maiorOcupacao int
}

func NovoBufferLimitado(capacidade int) *BufferLimitado {
	b := &BufferLimitado{capacidade: capacidade}
	b.cond = sync.NewCond(&b.mu)
	return b
}

func (b *BufferLimitado) colocar(item int) {
	b.mu.Lock()
	defer b.mu.Unlock()
	for len(b.itens) == b.capacidade { // for (o "while" do Go), nunca if
		b.cond.Wait()
	}
	b.itens = append(b.itens, item)
	if len(b.itens) > b.maiorOcupacao {
		b.maiorOcupacao = len(b.itens)
	}
	b.cond.Broadcast()
}

func (b *BufferLimitado) retirar() int {
	b.mu.Lock()
	defer b.mu.Unlock()
	for len(b.itens) == 0 {
		b.cond.Wait()
	}
	item := b.itens[0]
	b.itens = b.itens[1:]
	b.cond.Broadcast()
	return item
}

var buf = NovoBufferLimitado(4)
var consumidos []int
var travaConsumidos sync.Mutex

func produtor(base int, wg *sync.WaitGroup) {
	defer wg.Done()
	for i := 0; i < 50; i++ {
		buf.colocar(base + i)
	}
}

func consumidor(wg *sync.WaitGroup) {
	defer wg.Done()
	for i := 0; i < 50; i++ {
		item := buf.retirar()
		travaConsumidos.Lock()
		consumidos = append(consumidos, item)
		travaConsumidos.Unlock()
	}
}

func main() {
	var wg sync.WaitGroup
	for _, b := range []int{0, 1000} {
		wg.Add(1)
		go produtor(b, &wg)
	}
	for i := 0; i < 2; i++ {
		wg.Add(1)
		go consumidor(&wg)
	}
	wg.Wait()
	soma := 0
	for _, x := range consumidos {
		soma += x
	}
	fmt.Println("itens consumidos:", len(consumidos), "soma:", soma)
	if buf.maiorOcupacao <= 4 {
		fmt.Println("ocupacao nunca passou da capacidade: True")
	} else {
		fmt.Println("ocupacao nunca passou da capacidade: False")
	}
}
```

Repare no `while` em volta do `wait`. Uma thread acordada não tem garantia de que a condição ainda é verdadeira: outra pode ter chegado antes, e existem **despertares espúrios**, em que `wait` retorna sem ninguém ter notificado. Por isso a condição sempre é testada de novo.

## Comparação

| Primitiva | Ideal para | Armadilha comum |
| --- | --- | --- |
| Mutex | Exclusão mútua simples | Esquecer de liberar em caso de exceção |
| Semáforo contador | Limitar concorrência, pools | Ordem errada de `wait` gera deadlock |
| Variável de condição | Esperar por um predicado | Usar `if` em vez de `while` |
| Monitor | Encapsular estado e sincronização juntos | Chamar código externo segurando o lock |
| Fila bloqueante pronta | Produtor e consumidor | Fila sem limite cresce até estourar a memória |

<Callout type="tip" title="Use a abstração mais alta disponível">
Em código de produção, prefira `queue.Queue`, `BlockingQueue` do Java, canais do Go ou pools de conexão prontos. Eles já resolvem as ordens corretas de espera. Escrever com semáforos crus é ótimo para entender e para entrevistas, não para o dia a dia.
</Callout>
