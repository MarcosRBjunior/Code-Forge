Sempre que a CPU fica livre, o kernel precisa responder a uma pergunta: qual dos processos prontos roda agora? A regra usada para isso é o **algoritmo de escalonamento**, e ela muda muito a experiência de quem usa o sistema. Neste capítulo você vai ver os dois algoritmos mais simples, FCFS e SJF, e as métricas usadas para compará-los. Eles quase não são usados puros em kernels modernos, mas aparecem o tempo todo em filas de requisições, jobs em lote e perguntas de entrevista.

## Métricas que importam

| Métrica | Definição | Quem se importa |
| --- | --- | --- |
| Tempo de espera | Tempo total na fila de prontos | Todos |
| Turnaround | Término menos chegada | Jobs em lote |
| Tempo de resposta | Primeira execução menos chegada | Usuários interativos |
| Vazão | Processos concluídos por unidade de tempo | Throughput do sistema |
| Utilização | Fração do tempo com CPU ocupada | Custo de infraestrutura |

## FCFS: quem chega primeiro, roda primeiro

**First-Come, First-Served** é uma fila simples. O processo roda até terminar ou bloquear, sem preempção. É justo no sentido de ordem de chegada, fácil de implementar e não causa inanição. O problema é o **efeito comboio**: se um processo longo chega primeiro, todos os curtos ficam presos atrás dele, como carros atrás de um caminhão numa estrada de pista única.

## SJF: o mais curto primeiro

**Shortest Job First** escolhe, entre os prontos, o processo com a menor rajada de CPU. Dá para provar que ele minimiza o tempo médio de espera: colocar um job curto antes de um longo reduz a espera do curto mais do que aumenta a do longo. A versão preemptiva, **SRTF** (Shortest Remaining Time First), interrompe o processo atual se chegar alguém com tempo restante menor.

O simulador abaixo roda os três algoritmos sobre o mesmo conjunto de processos, com tempos de chegada diferentes, e calcula espera e turnaround médios.

```python
procs = [("P1", 0, 8), ("P2", 1, 4), ("P3", 2, 9), ("P4", 3, 5)]  # nome, chegada, rajada

def fcfs(ps):
    t, fim = 0, {}
    for nome, cheg, raj in sorted(ps, key=lambda p: p[1]):
        t = max(t, cheg) + raj
        fim[nome] = t
    return fim

def sjf(ps):
    t, fim, restantes = 0, {}, list(ps)
    while restantes:
        prontos = [p for p in restantes if p[1] <= t] or [min(restantes, key=lambda p: p[1])]
        nome, cheg, raj = min(prontos, key=lambda p: (p[2], p[1]))
        t = max(t, cheg) + raj
        fim[nome] = t
        restantes.remove((nome, cheg, raj))
    return fim

def srtf(ps):
    t, fim = 0, {}
    resta = {n: r for n, _, r in ps}
    chegada = {n: c for n, c, _ in ps}
    while resta:
        prontos = [n for n in resta if chegada[n] <= t]
        if not prontos:
            t += 1
            continue
        n = min(prontos, key=lambda x: (resta[x], chegada[x]))
        resta[n] -= 1
        t += 1
        if resta[n] == 0:
            del resta[n]
            fim[n] = t
    return fim

for nome_alg, alg in [("FCFS", fcfs), ("SJF", sjf), ("SRTF", srtf)]:
    fim = alg(procs)
    esperas = {n: fim[n] - c - r for n, c, r in procs}
    turn = {n: fim[n] - c for n, c, _ in procs}
    print(f"{nome_alg:<5} espera={esperas}  media_espera={sum(esperas.values()) / 4:.2f}"
          f"  media_turnaround={sum(turn.values()) / 4:.2f}")
```

```javascript
const procs = [["P1", 0, 8], ["P2", 1, 4], ["P3", 2, 9], ["P4", 3, 5]]; // nome, chegada, rajada

function fcfs(ps) {
  let t = 0;
  const fim = {};
  for (const [nome, cheg, raj] of [...ps].sort((a, b) => a[1] - b[1])) {
    t = Math.max(t, cheg) + raj;
    fim[nome] = t;
  }
  return fim;
}

function sjf(ps) {
  let t = 0;
  const fim = {}, restantes = [...ps];
  while (restantes.length) {
    let prontos = restantes.filter((p) => p[1] <= t);
    if (prontos.length === 0) {
      prontos = [restantes.reduce((m, p) => (p[1] < m[1] ? p : m))];
    }
    const escolhido = prontos.reduce((m, p) => (p[2] < m[2] || (p[2] === m[2] && p[1] < m[1]) ? p : m));
    const [nome, cheg, raj] = escolhido;
    t = Math.max(t, cheg) + raj;
    fim[nome] = t;
    restantes.splice(restantes.indexOf(escolhido), 1);
  }
  return fim;
}

function srtf(ps) {
  let t = 0;
  const fim = {}, resta = new Map(), chegada = {};
  for (const [n, c, r] of ps) {
    resta.set(n, r);
    chegada[n] = c;
  }
  while (resta.size) {
    const prontos = [...resta.keys()].filter((n) => chegada[n] <= t);
    if (prontos.length === 0) {
      t += 1;
      continue;
    }
    const n = prontos.reduce((m, x) =>
      resta.get(x) < resta.get(m) || (resta.get(x) === resta.get(m) && chegada[x] < chegada[m]) ? x : m);
    resta.set(n, resta.get(n) - 1);
    t += 1;
    if (resta.get(n) === 0) {
      resta.delete(n);
      fim[n] = t;
    }
  }
  return fim;
}

for (const [nomeAlg, alg] of [["FCFS", fcfs], ["SJF", sjf], ["SRTF", srtf]]) {
  const fim = alg(procs);
  const esperas = {}, turn = {};
  for (const [n, c, r] of procs) esperas[n] = fim[n] - c - r;
  for (const [n, c] of procs) turn[n] = fim[n] - c;
  const soma = (d) => Object.values(d).reduce((a, b) => a + b, 0);
  const textoEsperas = procs.map(([n]) => `'${n}': ${esperas[n]}`).join(", ");
  console.log(`${nomeAlg.padEnd(5)} espera={${textoEsperas}}  media_espera=${(soma(esperas) / 4).toFixed(2)}` +
    `  media_turnaround=${(soma(turn) / 4).toFixed(2)}`);
}
```

```java
import java.util.*;

class Proc {
    final String nome;
    final int chegada, rajada;

    Proc(String nome, int chegada, int rajada) {
        this.nome = nome;
        this.chegada = chegada;
        this.rajada = rajada;
    }
}

static Map<String, Integer> fcfs(List<Proc> ps) {
    int t = 0;
    Map<String, Integer> fim = new HashMap<>();
    List<Proc> ordenados = new ArrayList<>(ps);
    ordenados.sort(Comparator.comparingInt(p -> p.chegada));
    for (Proc p : ordenados) {
        t = Math.max(t, p.chegada) + p.rajada;
        fim.put(p.nome, t);
    }
    return fim;
}

static Map<String, Integer> sjf(List<Proc> ps) {
    int t = 0;
    Map<String, Integer> fim = new HashMap<>();
    List<Proc> restantes = new ArrayList<>(ps);
    while (!restantes.isEmpty()) {
        List<Proc> prontos = new ArrayList<>();
        for (Proc p : restantes) if (p.chegada <= t) prontos.add(p);
        if (prontos.isEmpty()) prontos.add(Collections.min(restantes, Comparator.comparingInt(p -> p.chegada)));
        Proc p = Collections.min(prontos, Comparator.comparingInt((Proc x) -> x.rajada).thenComparingInt(x -> x.chegada));
        t = Math.max(t, p.chegada) + p.rajada;
        fim.put(p.nome, t);
        restantes.remove(p);
    }
    return fim;
}

static Map<String, Integer> srtf(List<Proc> ps) {
    int t = 0;
    Map<String, Integer> fim = new HashMap<>();
    Map<String, Integer> resta = new LinkedHashMap<>(), chegada = new HashMap<>();
    for (Proc p : ps) {
        resta.put(p.nome, p.rajada);
        chegada.put(p.nome, p.chegada);
    }
    while (!resta.isEmpty()) {
        List<String> prontos = new ArrayList<>();
        for (String n : resta.keySet()) if (chegada.get(n) <= t) prontos.add(n);
        if (prontos.isEmpty()) {
            t += 1;
            continue;
        }
        String n = Collections.min(prontos, Comparator.comparingInt((String x) -> resta.get(x)).thenComparingInt(x -> chegada.get(x)));
        resta.put(n, resta.get(n) - 1);
        t += 1;
        if (resta.get(n) == 0) {
            resta.remove(n);
            fim.put(n, t);
        }
    }
    return fim;
}

public static void main(String[] args) {
    List<Proc> procs = List.of(new Proc("P1", 0, 8), new Proc("P2", 1, 4), new Proc("P3", 2, 9), new Proc("P4", 3, 5)); // nome, chegada, rajada
    String[] nomes = {"FCFS", "SJF", "SRTF"};
    List<Map<String, Integer>> fins = List.of(fcfs(procs), sjf(procs), srtf(procs));
    for (int i = 0; i < nomes.length; i++) {
        Map<String, Integer> fim = fins.get(i);
        Map<String, Integer> esperas = new LinkedHashMap<>();
        int somaEspera = 0, somaTurn = 0;
        for (Proc p : procs) {
            esperas.put(p.nome, fim.get(p.nome) - p.chegada - p.rajada);
            somaEspera += fim.get(p.nome) - p.chegada - p.rajada;
            somaTurn += fim.get(p.nome) - p.chegada;
        }
        System.out.println(String.format(Locale.US, "%-5s espera=%s  media_espera=%.2f  media_turnaround=%.2f",
                nomes[i], esperas, somaEspera / 4.0, somaTurn / 4.0));
    }
}
```

```cpp
#include <algorithm>
#include <cstdio>
#include <map>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

struct Proc {
    string nome;
    int chegada, rajada;
};

map<string, int> fcfs(const vector<Proc>& ps) {
    int t = 0;
    map<string, int> fim;
    vector<Proc> ordenados = ps;
    stable_sort(ordenados.begin(), ordenados.end(), [](const Proc& a, const Proc& b) { return a.chegada < b.chegada; });
    for (auto& p : ordenados) {
        t = max(t, p.chegada) + p.rajada;
        fim[p.nome] = t;
    }
    return fim;
}

map<string, int> sjf(const vector<Proc>& ps) {
    int t = 0;
    map<string, int> fim;
    vector<Proc> restantes = ps;
    while (!restantes.empty()) {
        vector<Proc> prontos;
        for (auto& p : restantes) if (p.chegada <= t) prontos.push_back(p);
        if (prontos.empty())
            prontos.push_back(*min_element(restantes.begin(), restantes.end(),
                                           [](const Proc& a, const Proc& b) { return a.chegada < b.chegada; }));
        Proc p = *min_element(prontos.begin(), prontos.end(), [](const Proc& a, const Proc& b) {
            return tie(a.rajada, a.chegada) < tie(b.rajada, b.chegada);
        });
        t = max(t, p.chegada) + p.rajada;
        fim[p.nome] = t;
        restantes.erase(find_if(restantes.begin(), restantes.end(), [&](const Proc& x) { return x.nome == p.nome; }));
    }
    return fim;
}

map<string, int> srtf(const vector<Proc>& ps) {
    int t = 0;
    map<string, int> fim, chegada;
    vector<pair<string, int>> resta; // na ordem original, como o dict do Python
    for (auto& p : ps) {
        resta.push_back({p.nome, p.rajada});
        chegada[p.nome] = p.chegada;
    }
    while (!resta.empty()) {
        int melhor = -1;
        for (int i = 0; i < (int)resta.size(); i++) {
            if (chegada[resta[i].first] > t) continue;
            if (melhor == -1 || make_pair(resta[i].second, chegada[resta[i].first]) <
                                    make_pair(resta[melhor].second, chegada[resta[melhor].first]))
                melhor = i;
        }
        if (melhor == -1) {
            t += 1;
            continue;
        }
        resta[melhor].second -= 1;
        t += 1;
        if (resta[melhor].second == 0) {
            fim[resta[melhor].first] = t;
            resta.erase(resta.begin() + melhor);
        }
    }
    return fim;
}

int main() {
    vector<Proc> procs = {{"P1", 0, 8}, {"P2", 1, 4}, {"P3", 2, 9}, {"P4", 3, 5}}; // nome, chegada, rajada
    vector<pair<string, map<string, int> (*)(const vector<Proc>&)>> algoritmos = {{"FCFS", fcfs}, {"SJF", sjf}, {"SRTF", srtf}};
    for (auto& [nomeAlg, alg] : algoritmos) {
        map<string, int> fim = alg(procs);
        string esperas;
        int somaEspera = 0, somaTurn = 0;
        for (auto& p : procs) {
            int espera = fim[p.nome] - p.chegada - p.rajada;
            esperas += (esperas.empty() ? "'" : ", '") + p.nome + "': " + to_string(espera);
            somaEspera += espera;
            somaTurn += fim[p.nome] - p.chegada;
        }
        printf("%-5s espera={%s}  media_espera=%.2f  media_turnaround=%.2f\n",
               nomeAlg.c_str(), esperas.c_str(), somaEspera / 4.0, somaTurn / 4.0);
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Globalization;
using System.Linq;

class Proc {
    public string Nome;
    public int Chegada, Rajada;
    public Proc(string nome, int chegada, int rajada) { Nome = nome; Chegada = chegada; Rajada = rajada; }
}

static Dictionary<string, int> Fcfs(List<Proc> ps) {
    int t = 0;
    var fim = new Dictionary<string, int>();
    foreach (var p in ps.OrderBy(p => p.Chegada)) {
        t = Math.Max(t, p.Chegada) + p.Rajada;
        fim[p.Nome] = t;
    }
    return fim;
}

static Dictionary<string, int> Sjf(List<Proc> ps) {
    int t = 0;
    var fim = new Dictionary<string, int>();
    var restantes = new List<Proc>(ps);
    while (restantes.Count > 0) {
        var prontos = restantes.Where(p => p.Chegada <= t).ToList();
        if (prontos.Count == 0) prontos.Add(restantes.OrderBy(p => p.Chegada).First());
        var escolhido = prontos.OrderBy(p => p.Rajada).ThenBy(p => p.Chegada).First();
        t = Math.Max(t, escolhido.Chegada) + escolhido.Rajada;
        fim[escolhido.Nome] = t;
        restantes.Remove(escolhido);
    }
    return fim;
}

static Dictionary<string, int> Srtf(List<Proc> ps) {
    int t = 0;
    var fim = new Dictionary<string, int>();
    var ordem = ps.Select(p => p.Nome).ToList(); // ordem original, como o dict do Python
    var resta = ps.ToDictionary(p => p.Nome, p => p.Rajada);
    var chegada = ps.ToDictionary(p => p.Nome, p => p.Chegada);
    while (resta.Count > 0) {
        var prontos = ordem.Where(x => resta.ContainsKey(x) && chegada[x] <= t).ToList();
        if (prontos.Count == 0) {
            t += 1;
            continue;
        }
        var n = prontos.OrderBy(x => resta[x]).ThenBy(x => chegada[x]).First();
        resta[n] -= 1;
        t += 1;
        if (resta[n] == 0) {
            resta.Remove(n);
            fim[n] = t;
        }
    }
    return fim;
}

static void Main() {
    var procs = new List<Proc> { new Proc("P1", 0, 8), new Proc("P2", 1, 4), new Proc("P3", 2, 9), new Proc("P4", 3, 5) }; // nome, chegada, rajada
    var nomes = new[] { "FCFS", "SJF", "SRTF" };
    var algs = new Func<List<Proc>, Dictionary<string, int>>[] { Fcfs, Sjf, Srtf };
    var inv = CultureInfo.InvariantCulture;
    for (int i = 0; i < nomes.Length; i++) {
        var fim = algs[i](procs);
        var esperas = procs.Select(p => "'" + p.Nome + "': " + (fim[p.Nome] - p.Chegada - p.Rajada));
        double mediaEspera = procs.Sum(p => fim[p.Nome] - p.Chegada - p.Rajada) / 4.0;
        double mediaTurn = procs.Sum(p => fim[p.Nome] - p.Chegada) / 4.0;
        Console.WriteLine(nomes[i].PadRight(5) + " espera={" + string.Join(", ", esperas) + "}  media_espera=" +
            mediaEspera.ToString("F2", inv) + "  media_turnaround=" + mediaTurn.ToString("F2", inv));
    }
}
```

```go
import (
	"fmt"
	"sort"
	"strings"
)

type Proc struct {
	nome            string
	chegada, rajada int
}

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func fcfs(ps []Proc) map[string]int {
	t, fim := 0, map[string]int{}
	ordenados := append([]Proc{}, ps...)
	sort.SliceStable(ordenados, func(i, j int) bool { return ordenados[i].chegada < ordenados[j].chegada })
	for _, p := range ordenados {
		t = max(t, p.chegada) + p.rajada
		fim[p.nome] = t
	}
	return fim
}

func sjf(ps []Proc) map[string]int {
	t, fim, restantes := 0, map[string]int{}, append([]Proc{}, ps...)
	for len(restantes) > 0 {
		prontos := []int{} // índices em restantes
		for i, p := range restantes {
			if p.chegada <= t {
				prontos = append(prontos, i)
			}
		}
		if len(prontos) == 0 {
			primeiro := 0
			for i, p := range restantes {
				if p.chegada < restantes[primeiro].chegada {
					primeiro = i
				}
			}
			prontos = append(prontos, primeiro)
		}
		idx := prontos[0]
		for _, i := range prontos {
			p, m := restantes[i], restantes[idx]
			if p.rajada < m.rajada || p.rajada == m.rajada && p.chegada < m.chegada {
				idx = i
			}
		}
		p := restantes[idx]
		t = max(t, p.chegada) + p.rajada
		fim[p.nome] = t
		restantes = append(restantes[:idx], restantes[idx+1:]...)
	}
	return fim
}

func srtf(ps []Proc) map[string]int {
	t, fim := 0, map[string]int{}
	resta, chegada := map[string]int{}, map[string]int{}
	for _, p := range ps {
		resta[p.nome] = p.rajada
		chegada[p.nome] = p.chegada
	}
	for len(resta) > 0 {
		n := ""
		for _, p := range ps { // ordem original, como o dict do Python
			x := p.nome
			r, vivo := resta[x]
			if !vivo || chegada[x] > t {
				continue
			}
			if n == "" || r < resta[n] || r == resta[n] && chegada[x] < chegada[n] {
				n = x
			}
		}
		if n == "" {
			t++
			continue
		}
		resta[n]--
		t++
		if resta[n] == 0 {
			delete(resta, n)
			fim[n] = t
		}
	}
	return fim
}

func main() {
	procs := []Proc{{"P1", 0, 8}, {"P2", 1, 4}, {"P3", 2, 9}, {"P4", 3, 5}} // nome, chegada, rajada
	nomes := []string{"FCFS", "SJF", "SRTF"}
	algs := []func([]Proc) map[string]int{fcfs, sjf, srtf}
	for i, alg := range algs {
		fim := alg(procs)
		esperas := []string{}
		somaEspera, somaTurn := 0, 0
		for _, p := range procs {
			espera := fim[p.nome] - p.chegada - p.rajada
			esperas = append(esperas, fmt.Sprintf("'%s': %d", p.nome, espera))
			somaEspera += espera
			somaTurn += fim[p.nome] - p.chegada
		}
		fmt.Printf("%-5s espera={%s}  media_espera=%.2f  media_turnaround=%.2f\n",
			nomes[i], strings.Join(esperas, ", "), float64(somaEspera)/4, float64(somaTurn)/4)
	}
}
```

## Por que SJF não é usado puro

1. **Ninguém sabe o futuro.** O kernel não conhece a duração da próxima rajada. Na prática ela é estimada pela média exponencial das rajadas anteriores: `estimativa = a * ultima + (1 - a) * estimativa_anterior`.
2. **Inanição.** Se jobs curtos não param de chegar, um job longo pode nunca rodar.
3. **Sem preempção, sem interatividade.** FCFS e SJF não preemptivo deixam um processo dominar a CPU.

| Algoritmo | Preemptivo | Espera média | Inanição | Precisa prever duração |
| --- | --- | --- | --- | --- |
| FCFS | Não | Ruim com comboio | Não | Não |
| SJF | Não | Ótima (não preemptivo) | Sim | Sim |
| SRTF | Sim | Ótima | Sim | Sim |

<Callout type="tip" title="A mesma ideia fora do kernel">
Filas de jobs, balanceadores e bancos de dados enfrentam o mesmo dilema. Separar requisições curtas e longas em filas diferentes, ou limitar o tempo de cada consulta, é a forma prática de evitar que uma requisição pesada crie um comboio de latência para as leves.
</Callout>
