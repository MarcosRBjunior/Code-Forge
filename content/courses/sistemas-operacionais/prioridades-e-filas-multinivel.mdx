Nem todo processo merece o mesmo tratamento. O tratador de áudio precisa rodar a cada poucos milissegundos ou o som falha; o backup noturno pode esperar. **Escalonamento por prioridade** atribui um número a cada processo e sempre escolhe o pronto de maior prioridade. Simples na teoria, mas traz dois problemas sérios: inanição e inversão de prioridade. As **filas multinível com realimentação** (MLFQ) resolvem parte disso e são a base conceitual de vários escalonadores reais.

## Prioridade e inanição

Com prioridade estrita, um processo de baixa prioridade só roda quando não há ninguém mais importante pronto. Num sistema carregado, isso pode ser nunca: é a **inanição** (starvation). A correção clássica é o **envelhecimento** (aging): a prioridade efetiva de quem espera aumenta com o tempo, até que ele inevitavelmente rode.

A simulação abaixo mostra o mesmo cenário com e sem aging. Chegam continuamente tarefas de alta prioridade; o processo `relatorio` tem prioridade baixa (número maior significa menos prioridade).

```python
def simular(aging, ciclos=16):
    prontos = {"relatorio": 9}
    espera = {"relatorio": 0}
    linha = []
    for t in range(ciclos):
        nova = f"req{t}"
        prontos[nova] = 2          # a cada ciclo chega uma requisicao urgente

        del espera[escolhido]

            espera[n] += 1

for aging in [False, True]:
```

```javascript
function simular(aging, ciclos = 16) {
  const prontos = new Map([["relatorio", 9]]);
  const espera = new Map([["relatorio", 0]]);
  const linha = [];
  for (let t = 0; t < ciclos; t++) {
    const nova = `req${t}`;
    prontos.set(nova, 2); // a cada ciclo chega uma requisicao urgente
    espera.set(nova, 0);
    const efetiva = new Map();
    for (const [n, p] of prontos) {
      efetiva.set(n, p - (aging ? Math.floor(espera.get(n) / 2) : 0));
    }
    // menor prioridade efetiva; empate decidido pelo nome
    let escolhido = null;
    for (const n of efetiva.keys()) {
      if (escolhido === null || efetiva.get(n) < efetiva.get(escolhido) ||
          (efetiva.get(n) === efetiva.get(escolhido) && n < escolhido)) {
        escolhido = n;
      }

    prontos.delete(escolhido);
    espera.delete(escolhido);
    for (const n of espera.keys()) {
      espera.set(n, espera.get(n) + 1);
    }
  }
  return [linha.join(""), prontos.has("relatorio")];
```

Sem aging, o relatório nunca roda. Com aging, a cada dois ciclos de espera sua prioridade sobe um nível, e em algum momento ele passa à frente das requisições novas.

## Inversão de prioridade

Imagine três tarefas: **A** (alta), **M** (média) e **B** (baixa). B pega um lock. A acorda e precisa do mesmo lock, então bloqueia esperando B. Agora M, que não usa o lock, fica pronta e, por ter prioridade maior que B, a preempta. Resultado: A, a mais importante, espera M, que nem tem relação com o lock. Foi exatamente esse bug que reiniciava a sonda Mars Pathfinder em 1997. A correção é a **herança de prioridade**: enquanto B segura um lock que A quer, B herda a prioridade de A, termina rápido e libera o lock.

## Filas multinível com realimentação

A ideia da MLFQ é aprender o comportamento do processo em vez de exigir que alguém informe a prioridade:

```text
 fila 0 (prioridade alta)   quantum 2   ◄── todo processo novo entra aqui
 fila 1                     quantum 4
 fila 2 (prioridade baixa)  quantum 8   ◄── processos que gastam CPU descem
```

Regras:

1. Roda sempre a fila mais alta que não estiver vazia; dentro dela, Round Robin.
2. Processo novo entra no topo.
3. Se usou o quantum inteiro, desce um nível (parece limitado por CPU).
4. Se bloqueou antes do fim do quantum, fica no mesmo nível (parece interativo).
5. De tempos em tempos, todos voltam ao topo (**boost**), o que evita inanição e corrige processos que mudaram de comportamento.

```python
from collections import deque

QUANTUM = [2, 4, 8]
# rajadas de CPU de cada processo; 'io' bloqueia e volta pronto no mesmo nivel
procs = {"editor": [1, "io", 1, "io", 1], "compilador": [14], "script": [3, "io", 2]}
filas = [deque(sorted(procs)), deque(), deque()]
estado = {n: list(r) for n, r in procs.items()}
t, log = 0, []

while any(filas):
    nivel = next(i for i, f in enumerate(filas) if f)
    n = filas[nivel].popleft()
    rajada = estado[n].pop(0)
    uso = min(rajada, QUANTUM[nivel])
    t += uso
    log.append(f"t={t:>2} {n:<10} nivel {nivel} usou {uso}")
    if uso < rajada:                         # gastou o quantum inteiro: desce
        estado[n].insert(0, rajada - uso)
        filas[min(nivel + 1, 2)].append(n)
    elif estado[n] and estado[n][0] == "io":  # bloqueou: mantem o nivel
        estado[n].pop(0)
        filas[nivel].append(n)

print("\n".join(log))
```

```java
import java.util.*;

static final int[] QUANTUM = {2, 4, 8};
static final int IO = -1; // marca de E/S: bloqueia e volta pronto no mesmo nivel

public static void main(String[] args) {
    // rajadas de CPU de cada processo
    Map<String, List<Integer>> procs = new TreeMap<>();
    procs.put("editor", Arrays.asList(1, IO, 1, IO, 1));
    procs.put("compilador", Arrays.asList(14));
    procs.put("script", Arrays.asList(3, IO, 2));
    List<Deque<String>> filas = new ArrayList<>();
    filas.add(new ArrayDeque<>(procs.keySet())); // TreeMap: chaves já em ordem
    filas.add(new ArrayDeque<>());
    filas.add(new ArrayDeque<>());
    Map<String, LinkedList<Integer>> estado = new HashMap<>();
    for (Map.Entry<String, List<Integer>> e : procs.entrySet()) {
        estado.put(e.getKey(), new LinkedList<>(e.getValue()));
    }
    int t = 0;
    List<String> log = new ArrayList<>();

    while (filas.stream().anyMatch(f -> !f.isEmpty())) {
        int nivel = 0;
        while (filas.get(nivel).isEmpty()) nivel++;
        String n = filas.get(nivel).pollFirst();
        int rajada = estado.get(n).removeFirst();
        int uso = Math.min(rajada, QUANTUM[nivel]);
        t += uso;
        log.add(String.format("t=%2d %-10s nivel %d usou %d", t, n, nivel, uso));
        if (uso < rajada) { // gastou o quantum inteiro: desce
            estado.get(n).addFirst(rajada - uso);
            filas.get(Math.min(nivel + 1, 2)).addLast(n);
        } else if (!estado.get(n).isEmpty() && estado.get(n).getFirst() == IO) { // bloqueou: mantem o nivel
            estado.get(n).removeFirst();
            filas.get(nivel).addLast(n);
        }
    }

    System.out.println(String.join("\n", log));
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

static readonly int[] QUANTUM = { 2, 4, 8 };
const int IO = -1; // marca de E/S: bloqueia e volta pronto no mesmo nivel

static void Main()
{
    // rajadas de CPU de cada processo (SortedDictionary: nomes já em ordem ordinal)
    var procs = new SortedDictionary<string, int[]>(StringComparer.Ordinal)
    {
        { "editor", new[] { 1, IO, 1, IO, 1 } },
        { "compilador", new[] { 14 } },
        { "script", new[] { 3, IO, 2 } },
    };
    var filas = new List<Queue<string>> { new Queue<string>(procs.Keys), new Queue<string>(), new Queue<string>() };
    var estado = procs.ToDictionary(p => p.Key, p => new LinkedList<int>(p.Value));
    int t = 0;
    var log = new List<string>();

    while (filas.Any(f => f.Count > 0))
    {
        int nivel = filas.FindIndex(f => f.Count > 0);
        string n = filas[nivel].Dequeue();
        int rajada = estado[n].First.Value;
        estado[n].RemoveFirst();
        int uso = Math.Min(rajada, QUANTUM[nivel]);
        t += uso;
        log.Add(string.Format("t={0,2} {1,-10} nivel {2} usou {3}", t, n, nivel, uso));
        if (uso < rajada) // gastou o quantum inteiro: desce
        {
            estado[n].AddFirst(rajada - uso);
            filas[Math.Min(nivel + 1, 2)].Enqueue(n);
        }
        else if (estado[n].Count > 0 && estado[n].First.Value == IO) // bloqueou: mantem o nivel
        {
            estado[n].RemoveFirst();
            filas[nivel].Enqueue(n);
        }
    }
```

```go
import (
	"fmt"
	"sort"
	"strings"
)

var QUANTUM = []int{2, 4, 8}

const IO = -1 // marca de E/S: bloqueia e volta pronto no mesmo nivel

func main() {
	// rajadas de CPU de cada processo
	procs := map[string][]int{"editor": {1, IO, 1, IO, 1}, "compilador": {14}, "script": {3, IO, 2}}
	nomes := []string{}
	for n := range procs {
		nomes = append(nomes, n)
	}
	sort.Strings(nomes)
	filas := [][]string{nomes, {}, {}}
	estado := map[string][]int{}
	for n, r := range procs {
		estado[n] = append([]int{}, r...)
	}
	t := 0
	log := []string{}

	for len(filas[0])+len(filas[1])+len(filas[2]) > 0 {
		nivel := 0
		for len(filas[nivel]) == 0 {
			nivel++
		}
		n := filas[nivel][0]
		filas[nivel] = filas[nivel][1:]
		rajada := estado[n][0]
		estado[n] = estado[n][1:]
		uso := rajada
		if QUANTUM[nivel] < uso {
			uso = QUANTUM[nivel]
		}
		t += uso
		log = append(log, fmt.Sprintf("t=%2d %-10s nivel %d usou %d", t, n, nivel, uso))
		if uso < rajada { // gastou o quantum inteiro: desce
			estado[n] = append([]int{rajada - uso}, estado[n]...)
			abaixo := nivel + 1
			if abaixo > 2 {
				abaixo = 2
			}
			filas[abaixo] = append(filas[abaixo], n)
		} else if len(estado[n]) > 0 && estado[n][0] == IO { // bloqueou: mantem o nivel
			estado[n] = estado[n][1:]
			filas[nivel] = append(filas[nivel], n)
		}
	}

	fmt.Println(strings.Join(log, "\n"))
}
```

## Do conceito ao Linux

| Escalonador | Ideia central |
| --- | --- |
| MLFQ clássico | Filas por prioridade, rebaixa quem consome CPU |
| CFS (Linux 2.6.23 a 6.5) | Roda quem acumulou menos tempo virtual de CPU; `nice` muda o peso |
| EEVDF (Linux 6.6+) | Justiça por tempo virtual mais prazos para favorecer latência |
| Tempo real (`SCHED_FIFO`, `SCHED_RR`) | Prioridade estrita acima dos processos normais |

<Callout type="warning" title="Cuidado com prioridade de tempo real">
Um processo `SCHED_FIFO` em laço infinito monopoliza o núcleo e pode travar a máquina. O Linux reserva por padrão 5% do tempo para tarefas normais (`sched_rt_runtime_us`) justamente para permitir que você recupere o controle.
</Callout>

```bash
nice -n 10 ./backup.sh          # roda com prioridade menor
renice -n -5 -p 1234            # aumenta a prioridade (exige privilégio)
chrt -f 50 ./controle           # tempo real FIFO, prioridade 50
```
