A CPU está executando seu laço quando um pacote chega na placa de rede. Como ela fica sabendo? Uma opção seria perguntar à placa o tempo todo ("chegou algo?"), o chamado **polling**. A outra é deixar a placa avisar: ela levanta um sinal elétrico, a CPU suspende o que estava fazendo e executa um tratador. Isso é uma **interrupção**, e é ela que permite ao SO reagir a eventos sem desperdiçar ciclos esperando.

## Três tipos de evento

| Tipo | Origem | Exemplo | Síncrono? |
| --- | --- | --- | --- |
| Interrupção de hardware | Dispositivo externo | Timer, disco terminou, pacote chegou | Não |
| Exceção (trap/fault) | A própria instrução | Divisão por zero, page fault | Sim |
| Interrupção de software | Instrução explícita | `syscall`, `int 0x80` | Sim |

O **timer** merece destaque: ele interrompe a CPU periodicamente (por exemplo, a cada 1 a 4 ms). É isso que devolve o controle ao kernel mesmo quando um processo entra num laço infinito, e é a base da preempção que você verá em escalonamento.

## O que acontece quando chega uma interrupção

```text
 executando instrução i do processo
          │
          ▼
 fim da instrução: há interrupção pendente e habilitada?
          │ sim
          ▼
 CPU salva PC e flags, muda para modo kernel
          │
          ▼
 consulta a tabela de vetores (IDT) pelo número da interrupção
          │
          ▼
 tratador roda: parte rápida (top half) reconhece o dispositivo
          │
          ▼
 trabalho pesado agendado para depois (bottom half / softirq)
          │
          ▼
 retorna: restaura PC e continua — ou escalona outro processo
```

A CPU só verifica interrupções entre instruções, então a interrupção nunca corta uma instrução ao meio. O tratador precisa ser curto, porque enquanto ele roda outras interrupções do mesmo tipo podem ficar bloqueadas. Por isso o Linux divide o trabalho: a parte urgente responde ao hardware e o resto (processar o pacote TCP, por exemplo) roda depois, em contexto mais tranquilo.

A simulação abaixo mostra uma CPU que executa instruções de um programa e, entre elas, atende interrupções pendentes em ordem de prioridade (número menor é mais urgente):

<CodeTabs>

```python
import heapq

programa = ["load", "add", "store", "jump", "load", "mul"]
eventos = {1: [(2, "disco")], 3: [(0, "timer"), (1, "rede")], 4: [(2, "disco")]}

pendentes = []
for ciclo, instr in enumerate(programa):
    print(f"ciclo {ciclo}: executa {instr}")
    for evento in eventos.get(ciclo, []):
        heapq.heappush(pendentes, evento)
    while pendentes:
        prioridade, origem = heapq.heappop(pendentes)
        print(f"   -> interrupcao {origem} (prio {prioridade}): salva PC={ciclo + 1}, trata, volta")
```

```javascript
// heap mínimo de pares [prioridade, origem] (o JavaScript não tem um pronto)
const menor = (a, b) => a[0] < b[0] || (a[0] === b[0] && a[1] < b[1]);

function heappush(h, item) {
  h.push(item);
  let i = h.length - 1;
  while (i > 0) {
    const pai = (i - 1) >> 1;
    if (!menor(h[i], h[pai])) break;
    [h[i], h[pai]] = [h[pai], h[i]];
    i = pai;
  }
}

function heappop(h) {
  const topo = h[0];
  const ultimo = h.pop();
  if (h.length) {
    h[0] = ultimo;
    let i = 0;
    for (;;) {
      const e = 2 * i + 1, d = e + 1;
      let m = i;
      if (e < h.length && menor(h[e], h[m])) m = e;
      if (d < h.length && menor(h[d], h[m])) m = d;
      if (m === i) break;
      [h[i], h[m]] = [h[m], h[i]];
      i = m;
    }
  }
  return topo;
}

const eventos = { 1: [[2, "disco"]], 3: [[0, "timer"], [1, "rede"]], 4: [[2, "disco"]] };

const pendentes = [];
programa.forEach((instr, ciclo) => {
  console.log(`ciclo ${ciclo}: executa ${instr}`);

    heappush(pendentes, evento);
```

```java
import java.util.*;

class Evento {
    final int prioridade;
    final String origem;

    Evento(int prioridade, String origem) {
        this.prioridade = prioridade;
        this.origem = origem;
    }
}

public static void main(String[] args) {
    String[] programa = {"load", "add", "store", "jump", "load", "mul"};
    Map<Integer, List<Evento>> eventos = Map.of(
        1, List.of(new Evento(2, "disco")),
        3, List.of(new Evento(0, "timer"), new Evento(1, "rede")),
        4, List.of(new Evento(2, "disco")));

    PriorityQueue<Evento> pendentes = new PriorityQueue<>(
        Comparator.comparingInt((Evento e) -> e.prioridade).thenComparing(e -> e.origem));
    for (int ciclo = 0; ciclo < programa.length; ciclo++) {
        System.out.println("ciclo " + ciclo + ": executa " + programa[ciclo]);
        pendentes.addAll(eventos.getOrDefault(ciclo, List.of()));
        while (!pendentes.isEmpty()) {
            Evento e = pendentes.poll();
            System.out.println("   -> interrupcao " + e.origem + " (prio " + e.prioridade + "): salva PC=" + (ciclo + 1) + ", trata, volta");
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;

// heap mínimo de eventos (o Mono não tem PriorityQueue)
class Evento {
    public int Prioridade;
    public string Origem;
    public Evento(int prioridade, string origem) { Prioridade = prioridade; Origem = origem; }
    public bool Menor(Evento o) => Prioridade < o.Prioridade || (Prioridade == o.Prioridade && string.CompareOrdinal(Origem, o.Origem) < 0);
}

static void HeapPush(List<Evento> h, Evento item) {
    h.Add(item);
    int i = h.Count - 1;
    while (i > 0) {
        int pai = (i - 1) / 2;
        if (!h[i].Menor(h[pai])) break;
        var tmp = h[i]; h[i] = h[pai]; h[pai] = tmp;
        i = pai;
    }
}

static Evento HeapPop(List<Evento> h) {
    var topo = h[0];
    h[0] = h[h.Count - 1];
    h.RemoveAt(h.Count - 1);
    int i = 0;
    while (true) {
        int e = 2 * i + 1, d = e + 1, m = i;
        if (e < h.Count && h[e].Menor(h[m])) m = e;
        if (d < h.Count && h[d].Menor(h[m])) m = d;
        if (m == i) break;
        var tmp = h[i]; h[i] = h[m]; h[m] = tmp;
        i = m;
    }
    return topo;
}

static void Main() {
    var programa = new[] { "load", "add", "store", "jump", "load", "mul" };
    var eventos = new Dictionary<int, Evento[]> {
        [1] = new[] { new Evento(2, "disco") },
        [3] = new[] { new Evento(0, "timer"), new Evento(1, "rede") },
        [4] = new[] { new Evento(2, "disco") } };

    var pendentes = new List<Evento>();
    for (int ciclo = 0; ciclo < programa.Length; ciclo++) {
        Console.WriteLine($"ciclo {ciclo}: executa {programa[ciclo]}");
        Evento[] chegando;
        if (eventos.TryGetValue(ciclo, out chegando))
            foreach (var evento in chegando) HeapPush(pendentes, evento);
        while (pendentes.Count > 0) {
            var e = HeapPop(pendentes);
            Console.WriteLine($"   -> interrupcao {e.Origem} (prio {e.Prioridade}): salva PC={ciclo + 1}, trata, volta");
        }
    }
}
```

```go
import (
	"container/heap"
	"fmt"
)

type Evento struct {
	prioridade int
	origem     string
}

// Pendentes implementa heap.Interface: um heap mínimo de eventos
type Pendentes []Evento

func (h Pendentes) Len() int { return len(h) }
func (h Pendentes) Less(i, j int) bool {
	if h[i].prioridade != h[j].prioridade {
		return h[i].prioridade < h[j].prioridade
	}
	return h[i].origem < h[j].origem
}
func (h Pendentes) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *Pendentes) Push(x interface{}) { *h = append(*h, x.(Evento)) }
func (h *Pendentes) Pop() interface{} {
	velho := *h
	x := velho[len(velho)-1]
	*h = velho[:len(velho)-1]
	return x
}

func main() {
	programa := []string{"load", "add", "store", "jump", "load", "mul"}
	eventos := map[int][]Evento{1: {{2, "disco"}}, 3: {{0, "timer"}, {1, "rede"}}, 4: {{2, "disco"}}}

	pendentes := &Pendentes{}
	for ciclo, instr := range programa {
		fmt.Printf("ciclo %d: executa %s\n", ciclo, instr)
		for _, evento := range eventos[ciclo] {
			heap.Push(pendentes, evento)
		}
		for pendentes.Len() > 0 {
			e := heap.Pop(pendentes).(Evento)
			fmt.Printf("   -> interrupcao %s (prio %d): salva PC=%d, trata, volta\n", e.origem, e.prioridade, ciclo+1)
		}
	}
}
```

O kernel pode **mascarar** interrupções temporariamente, por exemplo enquanto atualiza uma estrutura que o próprio tratador também usa. Esse período precisa ser curtíssimo, senão eventos se acumulam e a latência do sistema inteiro sobe. Existe ainda a **NMI** (interrupção não mascarável), reservada para situações graves como erros de hardware e para detectores de travamento do kernel, o watchdog.

## Polling ou interrupção?

Interrupção parece sempre melhor, mas tem custo fixo: salvar estado, poluir caches, trocar de modo. Com eventos raros, ela ganha de longe. Com eventos muito frequentes, o custo por evento domina e o polling passa a compensar. Essa conta, simplificada:

<CodeTabs>

```python
CUSTO_INTERRUPCAO = 2.0   # microssegundos por evento
CUSTO_CONSULTA = 0.1      # microssegundos por verificacao
CONSULTAS_POR_SEG = 100_000

print("eventos/s   interrupcao(us)   polling(us)   melhor")
for eventos in [100, 1_000, 5_000, 100_000]:
    custo_irq = eventos * CUSTO_INTERRUPCAO
    custo_poll = CONSULTAS_POR_SEG * CUSTO_CONSULTA + eventos * CUSTO_CONSULTA
    melhor = "interrupcao" if custo_irq < custo_poll else "polling"
    print(f"{eventos:>9}   {custo_irq:>15.0f}   {custo_poll:>11.0f}   {melhor}")
```

É exatamente o que sistemas reais fazem. O **NAPI** do Linux começa com interrupções e, sob carga alta de rede, desliga a interrupção da placa e passa a consultar em lote. Frameworks como DPDK vão além e fazem polling o tempo todo num núcleo dedicado, trocando um núcleo inteiro por latência mínima. Placas modernas também fazem **coalescência**: agrupam vários pacotes numa só interrupção.

<Callout type="tip" title="Efeito em latência">
Interrupções em excesso aparecem como tempo alto de `si` (softirq) e `hi` no `top`. Num servidor de rede com muitos pacotes pequenos, distribuir as filas da placa entre núcleos (RSS, `irqbalance`) evita que um único núcleo vire gargalo.
</Callout>
