Seu serviço mostra 2 GB livres no total, mas uma alocação de 64 MB falha. Ou o RSS de um processo Python cresce durante horas e nunca volta, mesmo depois que os objetos foram liberados. Os dois sintomas têm a mesma raiz: **fragmentação**. Sempre que memória é dividida em pedaços que nascem e morrem em momentos diferentes, buracos aparecem, e o jeito de escolher onde colocar cada pedido determina quanto espaço se perde.

## Dois tipos de fragmentação

- **Externa:** há memória livre suficiente no total, mas espalhada em buracos não contíguos, nenhum grande o bastante para o pedido.
- **Interna:** o bloco entregue é maior que o pedido, e a sobra dentro dele fica desperdiçada. Acontece quando a memória é dividida em tamanhos fixos (páginas de 4 KB, classes de tamanho de um alocador).

```text
 externa: 30 KB livres no total, mas o maior buraco tem 12 KB
 ┌──────┬────────┬──────┬────────┬──────┬────────┐
 │ usado│ livre 8│ usado│livre 12│ usado│ livre10│   pedido de 20 KB falha
 └──────┴────────┴──────┴────────┴──────┴────────┘

 interna: pediu 5 KB, recebeu um bloco de 8 KB
 ┌──────────────────┬──────────┐
 │ 5 KB em uso      │ 3 KB perdidos │
 └──────────────────┴──────────┘
```

## Estratégias de posicionamento

Quando a memória é alocada em pedaços de tamanho variável, o alocador mantém uma lista de buracos livres e precisa escolher um:

| Estratégia | Regra | Característica |
| --- | --- | --- |
| First fit | Primeiro buraco que serve | Rápida; acumula lascas no começo |
| Next fit | Como first fit, mas continua de onde parou | Espalha alocações |
| Best fit | Menor buraco que serve | Deixa sobras minúsculas e inúteis |
| Worst fit | Maior buraco disponível | Mantém sobras grandes, mas some com os buracos grandes |

O simulador aplica a mesma sequência de alocações e liberações a uma memória de 100 unidades com cada estratégia, e registra quais pedidos não couberam:

```python
def simular(estrategia):
    livres = [(0, 100)]            # (inicio, tamanho)
    blocos = {}

    def alocar(nome, tam):
        candidatos = [b for b in livres if b[1] >= tam]
        if not candidatos:
            return False
        if estrategia == "first":
            escolhido = candidatos[0]
        elif estrategia == "best":
            escolhido = min(candidatos, key=lambda b: (b[1], b[0]))
        else:
            escolhido = max(candidatos, key=lambda b: (b[1], -b[0]))
        livres.remove(escolhido)
        inicio, tamanho = escolhido
        if tamanho > tam:
            livres.append((inicio + tam, tamanho - tam))
            livres.sort()
        blocos[nome] = (inicio, tam)
        return True

    def liberar(nome):
        livres.append(blocos.pop(nome))
        livres.sort()
        fundidos = []
        for ini, tam in livres:      # junta buracos vizinhos
            if fundidos and fundidos[-1][0] + fundidos[-1][1] == ini:
                fundidos[-1] = (fundidos[-1][0], fundidos[-1][1] + tam)
            else:
                fundidos.append((ini, tam))
        livres[:] = fundidos

    for nome, tam in [("a", 20), ("b", 10), ("c", 25), ("d", 15), ("e", 20)]:
        alocar(nome, tam)
    liberar("b")
    liberar("d")
    falhas = [n for n, t in [("f", 8), ("g", 12), ("h", 10)] if not alocar(n, t)]
    return livres, falhas

for e in ["first", "best", "worst"]:
    livres, falhas = simular(e)
    print(f"{e:<6} buracos_restantes={[t for _, t in livres]} falharam={falhas}")
```

```javascript
function simular(estrategia) {
  let livres = [[0, 100]]; // [inicio, tamanho]
  const blocos = new Map();
  const ordenar = () => livres.sort((x, y) => x[0] - y[0] || x[1] - y[1]);

  function alocar(nome, tam) {
    const candidatos = livres.filter((b) => b[1] >= tam);
    if (candidatos.length === 0) return false;
    let escolhido;
    if (estrategia === "first") {
      escolhido = candidatos[0];
    } else if (estrategia === "best") {
      escolhido = candidatos.reduce((m, b) => (b[1] < m[1] || (b[1] === m[1] && b[0] < m[0]) ? b : m));
    } else {
      escolhido = candidatos.reduce((m, b) => (b[1] > m[1] || (b[1] === m[1] && b[0] < m[0]) ? b : m));
    }
    livres.splice(livres.indexOf(escolhido), 1);
    const [inicio, tamanho] = escolhido;
    if (tamanho > tam) {
      livres.push([inicio + tam, tamanho - tam]);
      ordenar();
    }
    blocos.set(nome, [inicio, tam]);
    return true;
  }

  function liberar(nome) {
    livres.push(blocos.get(nome));
    blocos.delete(nome);
    ordenar();
    const fundidos = [];
    for (const [ini, tam] of livres) { // junta buracos vizinhos
      const ult = fundidos[fundidos.length - 1];
      if (ult && ult[0] + ult[1] === ini) {
        fundidos[fundidos.length - 1] = [ult[0], ult[1] + tam];
      } else {
        fundidos.push([ini, tam]);
      }
    }
    livres = fundidos;
  }

  for (const [nome, tam] of [["a", 20], ["b", 10], ["c", 25], ["d", 15], ["e", 20]]) {
    alocar(nome, tam);
  }
  liberar("b");
  liberar("d");
  const falhas = [["f", 8], ["g", 12], ["h", 10]].filter(([n, t]) => !alocar(n, t)).map(([n]) => n);
  return [livres, falhas];
}

for (const e of ["first", "best", "worst"]) {
  const [livres, falhas] = simular(e);
  const buracos = livres.map(([, t]) => t).join(", ");
  console.log(`${e.padEnd(6)} buracos_restantes=[${buracos}] falharam=[${falhas.map((n) => `'${n}'`).join(", ")}]`);
}
```

```java
import java.util.*;

class Simulador {
    final String estrategia;
    List<int[]> livres = new ArrayList<>(); // {inicio, tamanho}
    final Map<String, int[]> blocos = new HashMap<>();

    Simulador(String estrategia) {
        this.estrategia = estrategia;
        livres.add(new int[]{0, 100});
    }

    void ordenar() {
        livres.sort((x, y) -> x[0] != y[0] ? Integer.compare(x[0], y[0]) : Integer.compare(x[1], y[1]));
    }

    boolean alocar(String nome, int tam) {
        List<int[]> candidatos = new ArrayList<>();
        for (int[] b : livres) if (b[1] >= tam) candidatos.add(b);
        if (candidatos.isEmpty()) return false;
        int[] escolhido = candidatos.get(0);
        if (estrategia.equals("best")) {
            for (int[] b : candidatos)
                if (b[1] < escolhido[1] || (b[1] == escolhido[1] && b[0] < escolhido[0])) escolhido = b;
        } else if (estrategia.equals("worst")) {
            for (int[] b : candidatos)
                if (b[1] > escolhido[1] || (b[1] == escolhido[1] && b[0] < escolhido[0])) escolhido = b;
        }
        livres.remove(escolhido);
        int inicio = escolhido[0], tamanho = escolhido[1];
        if (tamanho > tam) {
            livres.add(new int[]{inicio + tam, tamanho - tam});
            ordenar();
        }
        blocos.put(nome, new int[]{inicio, tam});
        return true;
    }

    void liberar(String nome) {
        livres.add(blocos.remove(nome));
        ordenar();
        List<int[]> fundidos = new ArrayList<>();
        for (int[] b : livres) { // junta buracos vizinhos
            int ini = b[0], tam = b[1];
            if (!fundidos.isEmpty()) {
                int[] ult = fundidos.get(fundidos.size() - 1);
                if (ult[0] + ult[1] == ini) {
                    fundidos.set(fundidos.size() - 1, new int[]{ult[0], ult[1] + tam});
                    continue;
                }
            }
            fundidos.add(new int[]{ini, tam});
        }
        livres = fundidos;
    }

    List<String> rodar() {
        String[] nomes = {"a", "b", "c", "d", "e"};
        int[] tams = {20, 10, 25, 15, 20};
        for (int i = 0; i < nomes.length; i++) alocar(nomes[i], tams[i]);
        liberar("b");
        liberar("d");
        List<String> falhas = new ArrayList<>();
        String[] extras = {"f", "g", "h"};
        int[] extrasTam = {8, 12, 10};
        for (int i = 0; i < extras.length; i++)
            if (!alocar(extras[i], extrasTam[i])) falhas.add("'" + extras[i] + "'");
        return falhas;
    }
}

public static void main(String[] args) {
    for (String e : new String[]{"first", "best", "worst"}) {
        Simulador sim = new Simulador(e);
        List<String> falhas = sim.rodar();
        List<Integer> buracos = new ArrayList<>();
        for (int[] b : sim.livres) buracos.add(b[1]);
        System.out.println(String.format("%-6s buracos_restantes=%s falharam=%s", e, buracos, falhas));
    }
}
```

```cpp
pair<vector<pair<int, int>>, vector<string>> simular(const string& estrategia) {

        vector<pair<int, int>> candidatos;

            for (auto& b : candidatos)

                if (b.second > escolhido.second || (b.second == escolhido.second && b.first < escolhido.first)) escolhido = b;
        }
        livres.erase(find(livres.begin(), livres.end(), escolhido));
        auto [inicio, tamanho] = escolhido;

            livres.push_back({inicio + tam, tamanho - tam});
            sort(livres.begin(), livres.end());
        }
        blocos[nome] = {inicio, tam};
        return true;

                fundidos.back().second += tam;
            } else {
                fundidos.push_back({ini, tam});
            }
        }
        livres = fundidos;
    };

    vector<pair<string, int>> pedidos = {{"a", 20}, {"b", 10}, {"c", 25}, {"d", 15}, {"e", 20}};
```

```csharp
class Simulador {
    readonly string estrategia;
    public List<int[]> livres = new List<int[]> { new[] { 0, 100 } }; // {inicio, tamanho}
    readonly Dictionary<string, int[]> blocos = new Dictionary<string, int[]>();

    public Simulador(string estrategia) { this.estrategia = estrategia; }

    void Ordenar() {
        livres = livres.OrderBy(b => b[0]).ThenBy(b => b[1]).ToList();
    }

    bool Alocar(string nome, int tam) {
        var candidatos = livres.Where(b => b[1] >= tam).ToList();
        if (candidatos.Count == 0) return false;
        int[] escolhido;
        if (estrategia == "first") {
            escolhido = candidatos[0];
        } else if (estrategia == "best") {
            escolhido = candidatos.OrderBy(b => b[1]).ThenBy(b => b[0]).First();
        } else {
            escolhido = candidatos.OrderByDescending(b => b[1]).ThenBy(b => b[0]).First();
        }
        livres.Remove(escolhido);
        int inicio = escolhido[0], tamanho = escolhido[1];
        if (tamanho > tam) {
            livres.Add(new[] { inicio + tam, tamanho - tam });
            Ordenar();
        }
        blocos[nome] = new[] { inicio, tam };
        return true;
    }

    void Liberar(string nome) {
        livres.Add(blocos[nome]);
        blocos.Remove(nome);
        Ordenar();
        var fundidos = new List<int[]>();
        foreach (var b in livres) { // junta buracos vizinhos
            int ini = b[0], tam = b[1];
            if (fundidos.Count > 0 && fundidos[fundidos.Count - 1][0] + fundidos[fundidos.Count - 1][1] == ini) {
                var ult = fundidos[fundidos.Count - 1];
                fundidos[fundidos.Count - 1] = new[] { ult[0], ult[1] + tam };
            } else {
                fundidos.Add(new[] { ini, tam });
            }
        }
        livres = fundidos;
    }

        string[] nomes = { "a", "b", "c", "d", "e" };

            if (!Alocar(extras[i], extrasTam[i])) falhas.Add("'" + extras[i] + "'");
```

```go
import (
	"fmt"
	"sort"
	"strings"
)

func simular(estrategia string) ([][2]int, []string) {
	livres := [][2]int{{0, 100}} // {inicio, tamanho}
	blocos := map[string][2]int{}
	ordenar := func() {
		sort.Slice(livres, func(i, j int) bool {
			if livres[i][0] != livres[j][0] {
				return livres[i][0] < livres[j][0]
			}
			return livres[i][1] < livres[j][1]
		})
	}

	alocar := func(nome string, tam int) bool {
		idx := -1 // índice do escolhido em livres
		for i, b := range livres {
			if b[1] < tam {
				continue
			}
			if idx == -1 { // first fica com o primeiro candidato
				idx = i
				continue
			}
			e := livres[idx]
			if estrategia == "best" && (b[1] < e[1] || b[1] == e[1] && b[0] < e[0]) {
				idx = i
			} else if estrategia == "worst" && (b[1] > e[1] || b[1] == e[1] && b[0] < e[0]) {
				idx = i
			}
		}
		if idx == -1 {
			return false
		}
		escolhido := livres[idx]
		livres = append(livres[:idx], livres[idx+1:]...)
		inicio, tamanho := escolhido[0], escolhido[1]
		if tamanho > tam {
			livres = append(livres, [2]int{inicio + tam, tamanho - tam})
			ordenar()
		}
		blocos[nome] = [2]int{inicio, tam}
		return true
	}

	liberar := func(nome string) {
		livres = append(livres, blocos[nome])
		delete(blocos, nome)
		ordenar()
		fundidos := [][2]int{}
		for _, b := range livres { // junta buracos vizinhos
			ini, tam := b[0], b[1]
			if n := len(fundidos); n > 0 && fundidos[n-1][0]+fundidos[n-1][1] == ini {
				fundidos[n-1][1] += tam
			} else {
				fundidos = append(fundidos, [2]int{ini, tam})
			}
		}
		livres = fundidos
	}

	nomes := []string{"a", "b", "c", "d", "e"}
	tams := []int{20, 10, 25, 15, 20}
	for i := range nomes {
		alocar(nomes[i], tams[i])
	}
	liberar("b")
	liberar("d")
	falhas := []string{}
	extras := []string{"f", "g", "h"}
	extrasTam := []int{8, 12, 10}
	for i := range extras {
		if !alocar(extras[i], extrasTam[i]) {
			falhas = append(falhas, extras[i])
		}
	}
	return livres, falhas
}

func main() {
	for _, e := range []string{"first", "best", "worst"} {
		livres, falhas := simular(e)
		buracos := []string{}
		for _, b := range livres {
			buracos = append(buracos, fmt.Sprint(b[1]))
		}
		nomes := []string{}
		for _, n := range falhas {
			nomes = append(nomes, "'"+n+"'")
		}
		fmt.Printf("%-6s buracos_restantes=[%s] falharam=[%s]\n", e, strings.Join(buracos, ", "), strings.Join(nomes, ", "))
	}
}
```

Depois de liberar `b` e `d`, sobram três buracos (10, 15 e 10). First e best fit atendem os três pedidos seguintes, mas deixam lascas de 2 e 3 unidades que dificilmente servirão para alguém. Worst fit gasta o buraco de 15 com um pedido de 8 e, quando chega `g` com 12, nenhum buraco serve, embora haja 27 unidades livres. Com outra sequência de pedidos o resultado pode se inverter: nenhuma estratégia vence sempre, e por isso alocadores reais combinam várias técnicas.

## Como os alocadores reais atacam o problema

- **Paginação** (próximo capítulo) elimina a fragmentação externa da memória física: qualquer quadro livre serve para qualquer página. Em troca, aceita fragmentação interna de até uma página por região.
- **Buddy system:** o kernel Linux aloca páginas físicas em blocos de potências de 2. Dividir e reunir "irmãos" é rápido, mas um pedido de 33 páginas consome 64.
- **Slab/classes de tamanho:** o kernel e alocadores como jemalloc, tcmalloc e o próprio `pymalloc` mantêm caixas separadas para objetos de cada tamanho. Objetos parecidos ficam juntos, o que reduz fragmentação e acelera a alocação.
- **Compactação:** mover blocos para juntar os buracos. Só é viável quando dá para atualizar todos os ponteiros, como num coletor de lixo com compactação (JVM, .NET).

```javascript
function buddy(paginas) {
```

<Callout type="tip" title="Por que o RSS não volta">
Um alocador só devolve memória ao SO quando uma página (ou arena) inteira fica vazia. Se um único objeto vivo sobra em cada página, nada é devolvido, e o RSS fica alto mesmo com pouca memória "em uso". Trocar o malloc por jemalloc, reduzir `MALLOC_ARENA_MAX` em serviços com muitas threads ou reciclar workers periodicamente são correções comuns.
</Callout>
