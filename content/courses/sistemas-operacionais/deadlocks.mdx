A thread 1 pega o lock da conta A e tenta pegar o da conta B. Ao mesmo tempo, a thread 2 pega o lock de B e tenta pegar o de A. Cada uma espera pela outra, para sempre. Nenhuma usa CPU, nenhum erro aparece no log, e as requisições simplesmente param de responder. Isso é um **deadlock**: um conjunto de processos em que cada um espera por um recurso segurado por outro do mesmo conjunto.

## As quatro condições de Coffman

Um deadlock só pode acontecer se as quatro condições valerem ao mesmo tempo:

| Condição | Significado | Como quebrar |
| --- | --- | --- |
| Exclusão mútua | O recurso só pode ser usado por um de cada vez | Recursos compartilháveis (leitura, cópias) |
| Posse e espera | Quem segura um recurso pede outro | Pedir tudo de uma vez no início |
| Sem preempção | Ninguém tira o recurso à força | Liberar o que tem se não conseguir o próximo (`tryLock` com timeout) |
| Espera circular | Existe um ciclo de esperas | **Ordem global de aquisição de locks** |

Quebrar qualquer uma impede o deadlock. Na prática, a técnica mais usada é eliminar a espera circular: todo código adquire locks numa ordem fixa, por exemplo pelo id da conta. Se todo mundo pega A antes de B, nunca existe alguém com B esperando A.

```python
def transferir(origem, destino, valor, locks):
    primeiro, segundo = sorted([origem, destino])   # ordem global por id
    with locks[primeiro], locks[segundo]:
        ...
```

## Quatro estratégias

1. **Prevenção:** projetar para que uma das condições nunca valha (ordem de locks).
2. **Evitação:** antes de conceder um recurso, verificar se o sistema continua num estado seguro (algoritmo do banqueiro).
3. **Detecção e recuperação:** deixar acontecer, procurar ciclos periodicamente e matar ou reverter uma vítima. É o que bancos de dados fazem.
4. **Ignorar:** o "algoritmo do avestruz". A maioria dos SOs de uso geral não trata deadlocks de aplicação; isso é problema do seu código.

## Detecção: ciclo no grafo de espera

Monte um grafo em que uma aresta T1 → T2 significa "T1 espera um recurso que T2 segura". Existe deadlock se e somente se o grafo tem ciclo (com uma instância por recurso). O PostgreSQL e o InnoDB fazem exatamente isso e abortam uma das transações com erro de deadlock.

```java
import java.util.*;

class Detector {
    final Map<String, List<String>> espera;
    final Set<String> visitando = new HashSet<>(), visitados = new HashSet<>();
    final List<String> caminho = new ArrayList<>();

    Detector(Map<String, List<String>> espera) {
        this.espera = espera;
    }

    List<String> dfs(String no) {
        visitando.add(no);
        caminho.add(no);
        for (String prox : espera.getOrDefault(no, List.of())) {
            if (visitando.contains(prox)) {
                List<String> ciclo = new ArrayList<>(caminho.subList(caminho.indexOf(prox), caminho.size()));
                ciclo.add(prox);
                return ciclo;
            }
            if (!visitados.contains(prox)) {
                List<String> ciclo = dfs(prox);
                if (ciclo != null) return ciclo;
            }
        }
        visitando.remove(no);
        visitados.add(no);
        caminho.remove(caminho.size() - 1);
        return null;
    }
}

static List<String> acharCiclo(Map<String, List<String>> espera) {
    Detector d = new Detector(espera);
    for (String no : new TreeSet<>(espera.keySet())) {
        if (!d.visitados.contains(no)) {
            List<String> ciclo = d.dfs(no);
            if (ciclo != null) return ciclo;
        }
    }
    return null;
}

public static void main(String[] args) {
    Map<String, List<String>> semCiclo = Map.of("T1", List.of("T2"), "T2", List.of("T3"), "T3", List.of());
    Map<String, List<String>> comCiclo = Map.of("T1", List.of("T2"), "T2", List.of("T4"), "T3", List.of("T1"), "T4", List.of("T3"));
    System.out.println("sem_ciclo: " + acharCiclo(semCiclo));
    System.out.println("com_ciclo: " + String.join(" -> ", acharCiclo(comCiclo)));
}
```

```cpp
optional<vector<string>> acharCiclo(const map<string, vector<string>>& espera) {
    set<string> visitando, visitados;
    vector<string> caminho;

    function<optional<vector<string>>(const string&)> dfs = [&](const string& no) -> optional<vector<string>> {
        visitando.insert(no);
        caminho.push_back(no);
        auto it = espera.find(no);
        if (it != espera.end()) {
            for (const string& prox : it->second) {
                if (visitando.count(prox)) {
                    vector<string> ciclo(find(caminho.begin(), caminho.end(), prox), caminho.end());
                    ciclo.push_back(prox);
                    return ciclo;
                }
                if (!visitados.count(prox)) {
                    auto ciclo = dfs(prox);
                    if (ciclo) return ciclo;
                }
            }
        }
        visitando.erase(no);
        visitados.insert(no);
        caminho.pop_back();
        return nullopt;
    };

    for (auto& [no, _] : espera) { // map já percorre em ordem
        if (!visitados.count(no)) {
            auto ciclo = dfs(no);
            if (ciclo) return ciclo;
        }
    }
    return nullopt;
}
```

```csharp
static List<string> AcharCiclo(Dictionary<string, List<string>> espera) {
    var visitando = new HashSet<string>();
    var visitados = new HashSet<string>();
    var caminho = new List<string>();

    Func<string, List<string>> dfs = null;
    dfs = no => {
        visitando.Add(no);
        caminho.Add(no);
        List<string> vizinhos;
        if (!espera.TryGetValue(no, out vizinhos)) vizinhos = new List<string>();
        foreach (var prox in vizinhos) {
            if (visitando.Contains(prox)) {
                var ciclo = caminho.Skip(caminho.IndexOf(prox)).ToList();
                ciclo.Add(prox);
                return ciclo;
            }
            if (!visitados.Contains(prox)) {
                var ciclo = dfs(prox);
                if (ciclo != null) return ciclo;
            }
        }
        visitando.Remove(no);
        visitados.Add(no);
        caminho.RemoveAt(caminho.Count - 1);
        return null;
    };

    foreach (var no in espera.Keys.OrderBy(k => k, StringComparer.Ordinal)) {
        if (!visitados.Contains(no)) {
            var ciclo = dfs(no);
            if (ciclo != null) return ciclo;
        }
    }
    return null;
}
```

```go
import (
	"fmt"
	"sort"
	"strings"
)

func acharCiclo(espera map[string][]string) []string {
	visitando, visitados := map[string]bool{}, map[string]bool{}
	caminho := []string{}

	var dfs func(no string) []string
	dfs = func(no string) []string {
		visitando[no] = true
		caminho = append(caminho, no)
		for _, prox := range espera[no] {
			if visitando[prox] {
				for i, c := range caminho {
					if c == prox {
						ciclo := append([]string{}, caminho[i:]...)
						return append(ciclo, prox)
					}
				}
			}
			if !visitados[prox] {
				if ciclo := dfs(prox); ciclo != nil {
					return ciclo
				}
			}
		}
		delete(visitando, no)
		visitados[no] = true
		caminho = caminho[:len(caminho)-1]
		return nil
	}

	nos := []string{}
	for no := range espera {
		nos = append(nos, no)
	}
	sort.Strings(nos)
	for _, no := range nos {
		if !visitados[no] {
			if ciclo := dfs(no); ciclo != nil {
				return ciclo
			}
		}
	}
	return nil
}

	comCiclo := map[string][]string{"T1": {"T2"}, "T2": {"T4"}, "T3": {"T1"}, "T4": {"T3"}}

		fmt.Println("sem_ciclo: None")

		fmt.Println("sem_ciclo:", r)
```

## Evitação: o algoritmo do banqueiro

O banqueiro exige que cada processo declare antecipadamente o máximo de cada recurso que pode pedir. Um estado é **seguro** se existe alguma ordem em que todos os processos conseguem terminar: alguém cujas necessidades restantes cabem no que está disponível termina, devolve tudo, e isso libera recursos para o próximo. Um pedido só é atendido se o estado resultante continua seguro.

```python
def estado_seguro(disponivel, alocado, maximo):
    trabalho = list(disponivel)
    falta = {p: [m - a for m, a in zip(maximo[p], alocado[p])] for p in alocado}
    terminou, ordem = set(), []
    progrediu = True
    while progrediu:
        progrediu = False
        for p in sorted(alocado):
            if p not in terminou and all(f <= t for f, t in zip(falta[p], trabalho)):
                trabalho = [t + a for t, a in zip(trabalho, alocado[p])]
                terminou.add(p)
                ordem.append(p)
                progrediu = True
    return len(terminou) == len(alocado), ordem
```

```javascript
function estadoSeguro(disponivel, alocado, maximo) {
  let trabalho = [...disponivel];
  const falta = {};
  for (const p in alocado) falta[p] = maximo[p].map((m, i) => m - alocado[p][i]);
  const terminou = new Set(), ordem = [];
  let progrediu = true;
  while (progrediu) {
    progrediu = false;
    for (const p of Object.keys(alocado).sort()) {
      if (!terminou.has(p) && falta[p].every((f, i) => f <= trabalho[i])) {
        trabalho = trabalho.map((t, i) => t + alocado[p][i]);
        terminou.add(p);
        ordem.push(p);
        progrediu = true;
      }
    }
  }
  return [terminou.size === Object.keys(alocado).length, ordem];
}
```

```java
import java.util.*;

static String estadoSeguro(int[] disponivel, Map<String, int[]> alocado, Map<String, int[]> maximo) {
    int[] trabalho = disponivel.clone();
    Map<String, int[]> falta = new HashMap<>();
    for (String p : alocado.keySet()) {
        int[] f = new int[trabalho.length];
        for (int i = 0; i < f.length; i++) f[i] = maximo.get(p)[i] - alocado.get(p)[i];
        falta.put(p, f);
    }
    Set<String> terminou = new HashSet<>();
    List<String> ordem = new ArrayList<>();
    boolean progrediu = true;
    while (progrediu) {
        progrediu = false;
        for (String p : new TreeSet<>(alocado.keySet())) {
            if (terminou.contains(p)) continue;
            boolean cabe = true;
            for (int i = 0; i < trabalho.length; i++) if (falta.get(p)[i] > trabalho[i]) cabe = false;
            if (cabe) {
                for (int i = 0; i < trabalho.length; i++) trabalho[i] += alocado.get(p)[i];
                terminou.add(p);
                ordem.add("'" + p + "'");
                progrediu = true;
            }
        }
    }
    boolean seguro = terminou.size() == alocado.size();
    return "(" + (seguro ? "True" : "False") + ", " + ordem + ")";
}
```

```csharp
using System;
using System.Collections.Generic;

static string EstadoSeguro(int[] disponivel, Dictionary<string, int[]> alocado, Dictionary<string, int[]> maximo) {
    var trabalho = (int[])disponivel.Clone();
    var falta = alocado.Keys.ToDictionary(p => p, p => maximo[p].Select((m, i) => m - alocado[p][i]).ToArray());
    var terminou = new HashSet<string>();
    var ordem = new List<string>();
    bool progrediu = true;
    while (progrediu) {
        progrediu = false;
        foreach (var p in alocado.Keys.OrderBy(k => k, StringComparer.Ordinal)) {
            if (!terminou.Contains(p) && falta[p].Select((f, i) => f <= trabalho[i]).All(x => x)) {
                trabalho = trabalho.Select((t, i) => t + alocado[p][i]).ToArray();
                terminou.Add(p);
                ordem.Add(p);
                progrediu = true;
            }
        }
    }
    bool seguro = terminou.Count == alocado.Count;
    return "(" + (seguro ? "True" : "False") + ", [" + string.Join(", ", ordem.Select(p => "'" + p + "'")) + "])";
}
```

```go
import (
	"fmt"
	"sort"
	"strings"

func estadoSeguro(disponivel []int, alocado, maximo map[string][]int) string {
	trabalho := append([]int{}, disponivel...)
	falta := map[string][]int{}
	for p, a := range alocado {
		for i := range a {
			falta[p] = append(falta[p], maximo[p][i]-a[i])
		}
	}
	nomes := []string{}
	for p := range alocado {
		nomes = append(nomes, p)
	}
	sort.Strings(nomes)
	terminou, ordem := map[string]bool{}, []string{}
	progrediu := true
	for progrediu {
		progrediu = false
		for _, p := range nomes {
			if terminou[p] {
				continue
			}
			cabe := true
			for i := range trabalho {
				if falta[p][i] > trabalho[i] {
					cabe = false
				}
			}
			if cabe {
				for i := range trabalho {
					trabalho[i] += alocado[p][i]
				}
				terminou[p] = true
				ordem = append(ordem, "'"+p+"'")
				progrediu = true
			}
		}
	}
	seguro := "False"
	if len(terminou) == len(alocado) {
		seguro = "True"
	}
	return fmt.Sprintf("(%s, [%s])", seguro, strings.Join(ordem, ", "))
}

	alocado := map[string][]int{"P0": {0, 1, 0}, "P1": {2, 0, 0}, "P2": {3, 0, 2}, "P3": {2, 1, 1}, "P4": {0, 0, 2}}

	}
```

O pedido de P4 cabe no disponível, mas deixaria o sistema num estado em que nenhuma ordem garante o término de todos. O banqueiro o recusa e P4 espera.

O banqueiro é elegante, mas raramente usado em SOs reais: exige saber o máximo de antemão, assume número fixo de processos e custa O(n² · m) a cada pedido. Ele aparece mais em entrevistas e em sistemas de reserva de recursos especializados.

<Callout type="tip" title="Deadlocks no seu dia a dia">
Os mais comuns em produção são: duas transações atualizando as mesmas linhas em ordens diferentes; um pool de conexões esgotado por requisições que precisam de duas conexões ao mesmo tempo; e uma thread que segura um lock enquanto espera uma tarefa no mesmo pool de threads em que ela própria roda. Ordem consistente e timeouts resolvem a maioria.
</Callout>

**Livelock** é o primo do deadlock: as threads não estão bloqueadas, mas ficam reagindo umas às outras sem progredir, como duas pessoas desviando para o mesmo lado no corredor. Recuo com tempo aleatório (backoff com jitter) resolve.
