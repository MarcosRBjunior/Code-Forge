FCFS e SJF deixam um processo usar a CPU até terminar ou bloquear. Isso é péssimo para um sistema interativo: enquanto um compilador roda, o editor de texto fica congelado. **Round Robin** (RR) resolve com uma regra simples: cada processo recebe uma fatia fixa de tempo, o **quantum**. Quando a fatia acaba, o timer interrompe, o processo vai para o fim da fila de prontos e o próximo entra. Ninguém espera mais do que `(n - 1) * quantum` para voltar a rodar.

## Como funciona

```text
 fila de prontos:  [A] [B] [C]        quantum = 4

 t=0   A roda 4  → ainda falta → fim da fila  [B] [C] [A]
 t=4   B roda 3  → terminou                   [C] [A]
 t=7   C roda 4  → ainda falta → fim da fila  [A] [C]
 t=11  A roda ...
```

Dois detalhes que derrubam muita gente em exercício de entrevista:

1. Se um processo termina antes do fim do quantum, a CPU passa imediatamente ao próximo. O quantum é um teto, não um tempo fixo.
2. Quando um processo chega no mesmo instante em que outro é preemptado, a convenção mais comum é colocar o recém-chegado na fila **antes** do preemptado. Diga em voz alta qual convenção você está usando.

## Simulador

O código abaixo implementa RR com tempos de chegada, seguindo a convenção acima, e calcula espera, resposta e o número de trocas de contexto.

```python
from collections import deque

def round_robin(procs, quantum):
    procs = sorted(procs, key=lambda p: p[1])
    resta = {n: r for n, _, r in procs}
    primeira = {}
    fim = {}
    fila = deque()
    t, i, trocas, gantt = 0, 0, 0, []

    def admitir(ate):
        nonlocal i
        while i < len(procs) and procs[i][1] <= ate:
            fila.append(procs[i][0])
            i += 1

    admitir(t)
    while fila or i < len(procs):
        if not fila:
            t = procs[i][1]
            admitir(t)
        n = fila.popleft()
        primeira.setdefault(n, t)
        uso = min(quantum, resta[n])
        gantt.append(f"{n}{uso}")
        t += uso
        resta[n] -= uso
        admitir(t)                      # chegadas entram antes do preemptado
        if resta[n] > 0:
            fila.append(n)
        else:
            fim[n] = t
        trocas += 1
    return fim, primeira, trocas - 1, gantt

procs = [("A", 0, 10), ("B", 1, 4), ("C", 2, 7), ("D", 3, 3)]
for q in [2, 4, 10]:
    fim, primeira, trocas, gantt = round_robin(procs, q)
    espera = sum(fim[n] - c - r for n, c, r in procs) / len(procs)
    resposta = sum(primeira[n] - c for n, c, _ in procs) / len(procs)
    print(f"q={q:>2} espera={espera:5.2f} resposta={resposta:5.2f} trocas={trocas:>2} {' '.join(gantt)}")
```

```javascript
function roundRobin(procsEntrada, quantum) {
  const procs = [...procsEntrada].sort((a, b) => a[1] - b[1]);
  const resta = new Map(procs.map(([n, , r]) => [n, r]));
  const primeira = new Map();
  const fim = new Map();
  const fila = [];
  let t = 0, i = 0, trocas = 0;
  const gantt = [];

  function admitir(ate) {
    while (i < procs.length && procs[i][1] <= ate) {
      fila.push(procs[i][0]);
      i += 1;
    }
  }

  admitir(t);
  while (fila.length > 0 || i < procs.length) {
    if (fila.length === 0) {
      t = procs[i][1];
      admitir(t);
    }
    const n = fila.shift();
    if (!primeira.has(n)) primeira.set(n, t);
    const uso = Math.min(quantum, resta.get(n));
    gantt.push(`${n}${uso}`);
    t += uso;
    resta.set(n, resta.get(n) - uso);
    admitir(t);                      // chegadas entram antes do preemptado
    if (resta.get(n) > 0) {
      fila.push(n);
    } else {
      fim.set(n, t);
    }
    trocas += 1;
  }
  return [fim, primeira, trocas - 1, gantt];
}

const procs = [["A", 0, 10], ["B", 1, 4], ["C", 2, 7], ["D", 3, 3]];
for (const q of [2, 4, 10]) {
  const [fim, primeira, trocas, gantt] = roundRobin(procs, q);
  const espera = procs.reduce((s, [n, c, r]) => s + fim.get(n) - c - r, 0) / procs.length;
  const resposta = procs.reduce((s, [n, c]) => s + primeira.get(n) - c, 0) / procs.length;
  console.log(
    `q=${String(q).padStart(2)} espera=${espera.toFixed(2).padStart(5)} resposta=${resposta.toFixed(2).padStart(5)} ` +
      `trocas=${String(trocas).padStart(2)} ${gantt.join(" ")}`
  );
}
```

```java
import java.util.*;

static class Proc {
    String nome; int chegada; int rajada;
    Proc(String nome, int chegada, int rajada) { this.nome = nome; this.chegada = chegada; this.rajada = rajada; }
}

static class Resultado {
    Map<String, Integer> fim, primeira; int trocas; List<String> gantt;
    Resultado(Map<String, Integer> fim, Map<String, Integer> primeira, int trocas, List<String> gantt) {
        this.fim = fim; this.primeira = primeira; this.trocas = trocas; this.gantt = gantt;
    }
}

static Resultado roundRobin(List<Proc> entrada, int quantum) {
    List<Proc> procs = new ArrayList<>(entrada);
    procs.sort(Comparator.comparingInt(p -> p.chegada));
    Map<String, Integer> resta = new HashMap<>();
    for (Proc p : procs) resta.put(p.nome, p.rajada);
    Map<String, Integer> primeira = new HashMap<>();
    Map<String, Integer> fim = new HashMap<>();
    ArrayDeque<String> fila = new ArrayDeque<>();
    int t = 0, i = 0, trocas = 0;
    List<String> gantt = new ArrayList<>();

    // admitir(ate): enfileira quem já chegou; devolve o novo i
    i = admitir(procs, fila, i, t);
    while (!fila.isEmpty() || i < procs.size()) {
        if (fila.isEmpty()) {
            t = procs.get(i).chegada;
            i = admitir(procs, fila, i, t);
        }
        String n = fila.pollFirst();
        primeira.putIfAbsent(n, t);
        int uso = Math.min(quantum, resta.get(n));
        gantt.add(n + uso);
        t += uso;
        resta.put(n, resta.get(n) - uso);
        i = admitir(procs, fila, i, t);   // chegadas entram antes do preemptado
        if (resta.get(n) > 0) {
            fila.addLast(n);
        } else {
            fim.put(n, t);
        }
        trocas += 1;
    }
    return new Resultado(fim, primeira, trocas - 1, gantt);
}

static int admitir(List<Proc> procs, ArrayDeque<String> fila, int i, int ate) {
    while (i < procs.size() && procs.get(i).chegada <= ate) {
        fila.addLast(procs.get(i).nome);
        i += 1;
    }
    return i;
}

public static void main(String[] args) {
    List<Proc> procs = List.of(new Proc("A", 0, 10), new Proc("B", 1, 4), new Proc("C", 2, 7), new Proc("D", 3, 3));
    for (int q : new int[]{2, 4, 10}) {
        Resultado res = roundRobin(procs, q);
        double espera = 0, resposta = 0;
        for (Proc p : procs) {
            espera += res.fim.get(p.nome) - p.chegada - p.rajada;
            resposta += res.primeira.get(p.nome) - p.chegada;
        }
        espera /= procs.size();
        resposta /= procs.size();
        System.out.println(String.format(Locale.US, "q=%2d espera=%5.2f resposta=%5.2f trocas=%2d %s",
                q, espera, resposta, res.trocas, String.join(" ", res.gantt)));
    }
}
```

```cpp
    map<string, int> resta;
    for (auto& p : procs) resta[p.nome] = p.rajada;

            admitir(t);

        } else {
            fim[n] = t;
        }
        trocas += 1;
    }

}
```

```csharp
using System;
using System.Collections.Generic;
using System.Globalization;
using System.Linq;

class Proc
{
    public string Nome; public int Chegada; public int Rajada;
    public Proc(string nome, int chegada, int rajada) { Nome = nome; Chegada = chegada; Rajada = rajada; }
}

static void RoundRobin(List<Proc> entrada, int quantum, Dictionary<string, int> fim,
                       Dictionary<string, int> primeira, List<string> gantt, out int trocasTotais)
{
    var procs = entrada.OrderBy(p => p.Chegada).ToList();   // OrderBy é estável, como o sorted do Python
    var resta = procs.ToDictionary(p => p.Nome, p => p.Rajada);
    var fila = new Queue<string>();
    int t = 0, i = 0, trocas = 0;

    Action<int> admitir = ate =>
    {
        while (i < procs.Count && procs[i].Chegada <= ate)
        {
            fila.Enqueue(procs[i].Nome);
            i += 1;
        }
    };

    admitir(t);
    while (fila.Count > 0 || i < procs.Count)
    {
        if (fila.Count == 0)
        {
            t = procs[i].Chegada;
            admitir(t);
        }
        string n = fila.Dequeue();
        if (!primeira.ContainsKey(n)) primeira[n] = t;
        int uso = Math.Min(quantum, resta[n]);
        gantt.Add(n + uso);
        t += uso;
        resta[n] -= uso;
        admitir(t);                 // chegadas entram antes do preemptado
        if (resta[n] > 0)
            fila.Enqueue(n);
        else
            fim[n] = t;
        trocas += 1;
    }
    trocasTotais = trocas - 1;
}

static void Main()
{
    var procs = new List<Proc> { new Proc("A", 0, 10), new Proc("B", 1, 4), new Proc("C", 2, 7), new Proc("D", 3, 3) };
    foreach (int q in new[] { 2, 4, 10 })
    {
        var fim = new Dictionary<string, int>();
        var primeira = new Dictionary<string, int>();
        var gantt = new List<string>();
        RoundRobin(procs, q, fim, primeira, gantt, out int trocas);
        double espera = procs.Sum(p => fim[p.Nome] - p.Chegada - p.Rajada) / (double)procs.Count;
        double resposta = procs.Sum(p => primeira[p.Nome] - p.Chegada) / (double)procs.Count;
        Console.WriteLine(string.Format(CultureInfo.InvariantCulture, "q={0,2} espera={1,5:F2} resposta={2,5:F2} trocas={3,2} {4}",
            q, espera, resposta, trocas, string.Join(" ", gantt)));
    }
}
```

```go
import (
	"fmt"
	"sort"
	"strings"
)

type Proc struct {
	nome    string
	chegada int
	rajada  int
}

func roundRobin(entrada []Proc, quantum int) (map[string]int, map[string]int, int, []string) {
	procs := append([]Proc{}, entrada...)
	sort.SliceStable(procs, func(a, b int) bool { return procs[a].chegada < procs[b].chegada })
	resta := map[string]int{}
	for _, p := range procs {
		resta[p.nome] = p.rajada
	}
	primeira := map[string]int{}
	fim := map[string]int{}
	fila := []string{}
	t, i, trocas := 0, 0, 0
	gantt := []string{}

	admitir := func(ate int) {
		for i < len(procs) && procs[i].chegada <= ate {
			fila = append(fila, procs[i].nome)
			i += 1
		}
	}

	admitir(t)
	for len(fila) > 0 || i < len(procs) {
		if len(fila) == 0 {
			t = procs[i].chegada
			admitir(t)
		}
		n := fila[0]
		fila = fila[1:]
		if _, ok := primeira[n]; !ok {
			primeira[n] = t
		}
		uso := quantum
		if resta[n] < uso {
			uso = resta[n]
		}
		gantt = append(gantt, fmt.Sprintf("%s%d", n, uso))
		t += uso
		resta[n] -= uso
		admitir(t) // chegadas entram antes do preemptado
		if resta[n] > 0 {
			fila = append(fila, n)
		} else {
			fim[n] = t
		}
		trocas += 1
	}
	return fim, primeira, trocas - 1, gantt
}

func main() {
	procs := []Proc{{"A", 0, 10}, {"B", 1, 4}, {"C", 2, 7}, {"D", 3, 3}}
	for _, q := range []int{2, 4, 10} {
		fim, primeira, trocas, gantt := roundRobin(procs, q)
		espera, resposta := 0.0, 0.0
		for _, p := range procs {
			espera += float64(fim[p.nome] - p.chegada - p.rajada)
			resposta += float64(primeira[p.nome] - p.chegada)
		}
		espera /= float64(len(procs))
		resposta /= float64(len(procs))
		fmt.Printf("q=%2d espera=%5.2f resposta=%5.2f trocas=%2d %s\n", q, espera, resposta, trocas, strings.Join(gantt, " "))
	}
}
```

Repare no padrão: com quantum pequeno, a **resposta** é ótima (todo mundo começa logo), mas o número de trocas explode. Com quantum igual à maior rajada, RR vira FCFS: poucas trocas, resposta ruim.

## Escolhendo o quantum

Duas forças puxam em direções opostas:

- **Quantum muito pequeno:** boa interatividade, mas a fração da CPU gasta em troca de contexto cresce. Com quantum de 10 µs e troca de 5 µs, um terço do tempo vai embora.
- **Quantum muito grande:** degenera em FCFS e volta o efeito comboio.

Uma regra prática clássica: escolha o quantum de modo que a maioria das rajadas de CPU (algo como 80%) caiba numa fatia só. Assim processos interativos, que rodam pouco e logo bloqueiam em E/S, raramente são preemptados, e só os processos longos pagam o custo de serem fatiados. Kernels reais usam fatias de alguns milissegundos.

O programa a seguir mostra o efeito do quantum quando há uma troca de contexto de custo fixo, comparando o tempo total para completar o mesmo trabalho:

```cpp
#include <cstdio>
#include <string>
#include <vector>
using namespace std;

int main() {
    vector<int> rajadas = {10, 4, 7, 3};
    const double CUSTO_TROCA = 0.5;

    for (int q : {1, 2, 4, 8, 16}) {
        int fatias = 0, soma = 0;
        for (int r : rajadas) {
            fatias += (r + q - 1) / q;   // teto de r / q
            soma += r;
        }
        int trocas = fatias - 1;
        double total = soma + trocas * CUSTO_TROCA;
```

## Trade-offs

| Aspecto | Round Robin |
| --- | --- |
| Justiça | Alta: todos recebem fatias iguais |
| Tempo de resposta | Bom, limitado por `(n - 1) * quantum` |
| Turnaround médio | Geralmente pior que SJF |
| Inanição | Não ocorre |
| Overhead | Cresce com quantum pequeno |
| Diferenciação | Nenhuma: tratar um job de backup igual a uma requisição web é ruim |

<Callout type="note" title="RR em lugares inesperados">
O mesmo raciocínio aparece em balanceadores (round robin entre servidores), em rate limiting justo entre clientes e em runtimes de linguagem. O agendador de goroutines do Go, por exemplo, preempta uma goroutine que roda há mais de cerca de 10 ms para que as outras não passem fome.
</Callout>

## Na entrevista

Se pedirem um cálculo de RR, monte a fila passo a passo, anote o instante de cada chegada e declare a convenção de desempate. Na parte conceitual, mostre o trade-off do quantum com números. Follow-ups comuns: "RR com quantum infinito vira o quê?" (FCFS) e "por que processos limitados por E/S se dão bem em RR?" (usam pouco da fatia e voltam rápido à fila, então têm boa latência).
