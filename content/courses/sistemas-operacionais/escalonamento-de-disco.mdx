Num disco rígido, ler um bloco envolve mover fisicamente um braço até a trilha certa (**seek**) e esperar o prato girar até o setor passar sob a cabeça (**latência rotacional**). Juntos, levam alguns milissegundos, uma eternidade comparada à RAM. Quando há várias requisições pendentes, a ordem em que são atendidas muda drasticamente o tempo total: atender na ordem de chegada pode fazer o braço ir e voltar de uma ponta à outra. Os **algoritmos de escalonamento de disco** reordenam a fila para reduzir o movimento.

## O custo de um acesso

| Componente | HD 7.200 rpm | SSD NVMe |
| --- | --- | --- |
| Seek | 4 a 10 ms | não existe |
| Latência rotacional média | cerca de 4 ms | não existe |
| Transferência de 4 KB | microssegundos | microssegundos |
| Leituras aleatórias por segundo | cerca de 100 a 200 | centenas de milhares |

O seek domina no HD, e é isso que os algoritmos clássicos atacam.

## Os algoritmos

- **FCFS:** atende na ordem de chegada. Justo, mas o braço viaja muito.
- **SSTF** (Shortest Seek Time First): atende o pedido mais próximo da posição atual. Reduz o movimento, mas pedidos nas pontas podem passar fome.
- **SCAN (elevador):** o braço varre numa direção atendendo tudo pelo caminho até o fim do disco, depois inverte.
- **C-SCAN:** varre numa direção só; ao chegar ao fim, volta ao início sem atender e recomeça. Dá tempos de espera mais uniformes.
- **LOOK / C-LOOK:** como SCAN e C-SCAN, mas inverte (ou volta) no último pedido, sem ir até a borda do disco.

```text
 cilindros:  0 ─────────────────────────────────────────── 199
 cabeça em 53, subindo; fila: 98 183 37 122 14 124 65 67

 SCAN:   53 → 65 → 67 → 98 → 122 → 124 → 183 → (199) → 37 → 14
 C-SCAN: 53 → 65 → 67 → 98 → 122 → 124 → 183 → (199) ⇢ (0) → 14 → 37
```

```python
def sstf(cabeca, fila):
    pendentes, ordem, pos = list(fila), [], cabeca
    while pendentes:
        prox = min(pendentes, key=lambda c: (abs(c - pos), c))
        ordem.append(prox)
        pendentes.remove(prox)
        pos = prox
    return ordem

def scan(cabeca, fila, fim=199):
    acima = sorted(c for c in fila if c >= cabeca)
    abaixo = sorted((c for c in fila if c < cabeca), reverse=True)
    return acima + ([fim] if abaixo else []) + abaixo

def c_scan(cabeca, fila, fim=199):
    acima = sorted(c for c in fila if c >= cabeca)
    abaixo = sorted(c for c in fila if c < cabeca)
    return acima + ([fim, 0] if abaixo else []) + abaixo

def look(cabeca, fila):
    acima = sorted(c for c in fila if c >= cabeca)
    abaixo = sorted((c for c in fila if c < cabeca), reverse=True)
```

```javascript
const crescente = (a, b) => a - b;

function fcfs(cabeca, fila) {
  return [...fila];
}

function sstf(cabeca, fila) {
  const pendentes = [...fila], ordem = [];
  let pos = cabeca;
  while (pendentes.length) {
    const prox = pendentes.reduce((m, c) =>
      Math.abs(c - pos) < Math.abs(m - pos) || (Math.abs(c - pos) === Math.abs(m - pos) && c < m) ? c : m);
    ordem.push(prox);
    pendentes.splice(pendentes.indexOf(prox), 1);
    pos = prox;
  }
  return ordem;
}

function scan(cabeca, fila, fim = 199) {
  const acima = fila.filter((c) => c >= cabeca).sort(crescente);
  const abaixo = fila.filter((c) => c < cabeca).sort((a, b) => b - a);
  return [...acima, ...(abaixo.length ? [fim] : []), ...abaixo];
}

function cScan(cabeca, fila, fim = 199) {
  const acima = fila.filter((c) => c >= cabeca).sort(crescente);
  const abaixo = fila.filter((c) => c < cabeca).sort(crescente);
  return [...acima, ...(abaixo.length ? [fim, 0] : []), ...abaixo];
}

function look(cabeca, fila) {
  const acima = fila.filter((c) => c >= cabeca).sort(crescente);
  const abaixo = fila.filter((c) => c < cabeca).sort((a, b) => b - a);
  return [...acima, ...abaixo];
}

function movimento(cabeca, ordem) {
  let total = 0, pos = cabeca;
  for (const c of ordem) {
    total += Math.abs(c - pos);
    pos = c;
  }
  return total;
}
```

```java
import java.util.*;
import java.util.function.*;

static List<Integer> fcfs(int cabeca, List<Integer> fila) {
    return new ArrayList<>(fila);
}

static List<Integer> sstf(int cabeca, List<Integer> fila) {
    List<Integer> pendentes = new ArrayList<>(fila), ordem = new ArrayList<>();
    int pos = cabeca;
    while (!pendentes.isEmpty()) {
        final int p = pos;
        int prox = Collections.min(pendentes, Comparator.comparingInt((Integer c) -> Math.abs(c - p)).thenComparingInt(c -> c));
        ordem.add(prox);
        pendentes.remove(Integer.valueOf(prox));
        pos = prox;
    }
    return ordem;
}

static List<Integer> acima(int cabeca, List<Integer> fila) {
    List<Integer> r = new ArrayList<>();
    for (int c : fila) if (c >= cabeca) r.add(c);
    Collections.sort(r);
    return r;
}

static List<Integer> abaixo(int cabeca, List<Integer> fila, boolean decrescente) {
    List<Integer> r = new ArrayList<>();
    for (int c : fila) if (c < cabeca) r.add(c);
    r.sort(decrescente ? Comparator.reverseOrder() : Comparator.naturalOrder());
    return r;
}

static List<Integer> scan(int cabeca, List<Integer> fila) {
    int fim = 199;
    List<Integer> r = acima(cabeca, fila), baixo = abaixo(cabeca, fila, true);
    if (!baixo.isEmpty()) r.add(fim);
    r.addAll(baixo);
    return r;
}

static List<Integer> cScan(int cabeca, List<Integer> fila) {
    int fim = 199;
    List<Integer> r = acima(cabeca, fila), baixo = abaixo(cabeca, fila, false);
    if (!baixo.isEmpty()) r.addAll(List.of(fim, 0));
    r.addAll(baixo);
    return r;
}

static List<Integer> look(int cabeca, List<Integer> fila) {
    List<Integer> r = acima(cabeca, fila);
    r.addAll(abaixo(cabeca, fila, true));
    return r;
}

static int movimento(int cabeca, List<Integer> ordem) {
    int total = 0, pos = cabeca;
    for (int c : ordem) {
        total += Math.abs(c - pos);
        pos = c;
    }
    return total;
}

public static void main(String[] args) {
    List<Integer> fila = List.of(98, 183, 37, 122, 14, 124, 65, 67);
    int cabeca = 53;
    Map<String, BiFunction<Integer, List<Integer>, List<Integer>>> algoritmos = new LinkedHashMap<>();
    algoritmos.put("FCFS", (c, f) -> fcfs(c, f));
    algoritmos.put("SSTF", (c, f) -> sstf(c, f));

        System.out.println(String.format("%-7s movimento=%4d  ordem=%s", e.getKey(), movimento(cabeca, ordem), ordem));
    }
```

```cpp
    vector<int> pendentes = fila, ordem;
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

static List<int> Fcfs(int cabeca, List<int> fila) {
    return new List<int>(fila);
}

static List<int> Sstf(int cabeca, List<int> fila) {
    var pendentes = new List<int>(fila);
    var ordem = new List<int>();
    int pos = cabeca;
    while (pendentes.Count > 0) {
        int prox = pendentes.OrderBy(c => Math.Abs(c - pos)).ThenBy(c => c).First();
        ordem.Add(prox);
        pendentes.Remove(prox);
        pos = prox;
    }
    return ordem;
}

static List<int> Scan(int cabeca, List<int> fila) {
    int fim = 199;
    var acima = fila.Where(c => c >= cabeca).OrderBy(c => c).ToList();
    var abaixo = fila.Where(c => c < cabeca).OrderByDescending(c => c).ToList();
    return acima.Concat(abaixo.Count > 0 ? new[] { fim } : new int[0]).Concat(abaixo).ToList();
}

static List<int> CScan(int cabeca, List<int> fila) {
    int fim = 199;

    var abaixo = fila.Where(c => c < cabeca).OrderBy(c => c).ToList();
    return acima.Concat(abaixo.Count > 0 ? new[] { fim, 0 } : new int[0]).Concat(abaixo).ToList();
}

static List<int> Look(int cabeca, List<int> fila) {
    var acima = fila.Where(c => c >= cabeca).OrderBy(c => c);
    var abaixo = fila.Where(c => c < cabeca).OrderByDescending(c => c);

}
```

```go
import (
	"fmt"
	"sort"
	"strings"
)

func abs(x int) int {
	if x < 0 {
		return -x
	}
	return x
}

func fcfs(cabeca int, fila []int) []int {
	return append([]int{}, fila...)
}

func sstf(cabeca int, fila []int) []int {
	pendentes, ordem, pos := append([]int{}, fila...), []int{}, cabeca
	for len(pendentes) > 0 {
		idx := 0
		for i, c := range pendentes {
			m := pendentes[idx]
			if abs(c-pos) < abs(m-pos) || abs(c-pos) == abs(m-pos) && c < m {
				idx = i
			}
		}
		prox := pendentes[idx]
		ordem = append(ordem, prox)
		pendentes = append(pendentes[:idx], pendentes[idx+1:]...)
		pos = prox
	}
	return ordem
}

func separar(cabeca int, fila []int, decrescente bool) ([]int, []int) {
	acima, abaixo := []int{}, []int{}
	for _, c := range fila {
		if c >= cabeca {
			acima = append(acima, c)
		} else {
			abaixo = append(abaixo, c)
		}
	}
	sort.Ints(acima)
	if decrescente {
		sort.Sort(sort.Reverse(sort.IntSlice(abaixo)))
	} else {
		sort.Ints(abaixo)
	}
	return acima, abaixo
}

func scan(cabeca int, fila []int) []int {
	fim := 199
	acima, abaixo := separar(cabeca, fila, true)
	if len(abaixo) > 0 {
		acima = append(acima, fim)
	}
	return append(acima, abaixo...)
}

func cScan(cabeca int, fila []int) []int {
	fim := 199
	acima, abaixo := separar(cabeca, fila, false)
	if len(abaixo) > 0 {
		acima = append(acima, fim, 0)
	}
	return append(acima, abaixo...)
}

func look(cabeca int, fila []int) []int {
	acima, abaixo := separar(cabeca, fila, true)
	return append(acima, abaixo...)
}

func movimento(cabeca int, ordem []int) int {
	total, pos := 0, cabeca
	for _, c := range ordem {
		total += abs(c - pos)
		pos = c
	}
	return total
}

		ordem := alg(cabeca, fila)

		for _, c := range ordem {
			partes = append(partes, fmt.Sprint(c))
		}
```

## Inanição no SSTF

O SSTF parece ótimo, mas com pedidos chegando continuamente perto da cabeça, um pedido distante pode esperar indefinidamente:

<CodeTabs>

```python

    novos = [pos + 2, pos - 3]                 # chegam sempre pedidos perto
    prox = min(novos + [distante], key=lambda c: abs(c - pos))
    atendidos.append(prox)
    pos = prox
print("atendidos:", atendidos)
print("pedido em 190 atendido?", distante in atendidos)
```

SCAN e suas variantes garantem que o braço passa por todas as trilhas a cada varredura, limitando a espera.

## E nos SSDs?

SSDs não têm braço: o tempo de acesso não depende da distância entre endereços. Reordenar por posição é inútil, e o que importa passa a ser **paralelismo** (vários chips e filas de comando, até 64 mil filas no NVMe) e **justiça entre processos**. Por isso os escalonadores de E/S do Linux mudaram:

| Escalonador | Ideia | Bom para |
| --- | --- | --- |
| `none` | Sem reordenar, entrega direto ao dispositivo | NVMe rápido |
| `mq-deadline` | Ordena, mas impõe prazo máximo por pedido | SSD SATA, HD |
| `bfq` | Divide banda por processo, prioriza interativos | Desktops, HD |
| `kyber` | Controla latência por filas de leitura e escrita | SSD rápido com mistura de cargas |

<Callout type="tip" title="Sequencial ainda vence aleatório">
Mesmo em SSD, ler sequencialmente é mais rápido que aleatório, por causa de prefetch e de páginas internas grandes. Estruturas como LSM-trees (RocksDB, Cassandra) e logs append-only existem justamente para transformar escritas aleatórias em sequenciais.
</Callout>
