Se qualquer programa pudesse escrever direto no controlador de disco ou mudar a tabela de páginas, um bug num script derrubaria a máquina inteira. Por isso a CPU tem pelo menos dois **modos de execução**: o **modo usuário**, em que instruções perigosas são proibidas, e o **modo kernel** (ou supervisor), em que tudo é permitido. Seu código roda em modo usuário. Quando precisa de algo que só o kernel pode fazer, ele faz uma **chamada de sistema** (syscall).

## Como uma syscall acontece

Uma syscall não é uma chamada de função comum. O programa coloca o número da chamada e os argumentos em registradores e executa uma instrução especial (`syscall` em x86-64, `svc` em ARM). A CPU muda para modo kernel e salta para um ponto de entrada fixo, definido pelo próprio kernel. O programa não escolhe para onde pular: isso é o que torna a fronteira segura.

```text
 modo usuário                          modo kernel
 ------------                          -----------
 read(fd, buf, 4096)
   libc: rax = 0 (número do read)
         rdi, rsi, rdx = argumentos
   instrução syscall  ───────────────►  entrada de syscall
                                        valida fd e ponteiro buf
                                        tabela[0] → sys_read
                                        copia dados para buf
   continua com rax = bytes lidos ◄────  retorno ao modo usuário
```

O kernel trata os argumentos como hostis: confere se o descritor existe e se o ponteiro aponta para memória do próprio processo. Se algo estiver errado, devolve um código de erro (`errno`) em vez de travar.

A simulação a seguir modela essa despachante: uma tabela de números para funções, validação de argumentos e contagem de trocas de modo.

```python
class Kernel:
    def __init__(self):
        self.arquivos = {3: b"config=prod"}
        self.trocas_de_modo = 0
        self.tabela = {0: self.sys_read, 1: self.sys_write, 39: self.sys_getpid}
        self.saida = []

    def syscall(self, numero, *args):
        self.trocas_de_modo += 2  # entrar e sair do modo kernel
        handler = self.tabela.get(numero)
        if handler is None:
            return "ENOSYS"
        return handler(*args)

    def sys_read(self, fd, n):
        if fd not in self.arquivos:
            return "EBADF"
        return self.arquivos[fd][:n]

    def sys_write(self, fd, dados):
        if fd != 1:
            return "EBADF"
        self.saida.append(dados)
        return len(dados)

    def sys_getpid(self):
        return 4242

k = Kernel()
print("read(3, 6)  ->", k.syscall(0, 3, 6))
print("read(7, 6)  ->", k.syscall(0, 7, 6))
print("write(1)    ->", k.syscall(1, 1, b"ola"))
print("getpid()    ->", k.syscall(39))
print("syscall 999 ->", k.syscall(999))
print("trocas de modo:", k.trocas_de_modo)
```

```javascript
class Kernel {
  constructor() {
    this.arquivos = new Map([[3, Buffer.from("config=prod")]]);
    this.trocasDeModo = 0;
    this.tabela = new Map([
      [0, (...args) => this.sysRead(...args)],
      [1, (...args) => this.sysWrite(...args)],
      [39, (...args) => this.sysGetpid(...args)],
    ]);
    this.saida = [];
  }

  syscall(numero, ...args) {
    this.trocasDeModo += 2; // entrar e sair do modo kernel
    const handler = this.tabela.get(numero);
    if (handler === undefined) {
      return "ENOSYS";
    }
    return handler(...args);
  }

      return "EBADF";
    }
    this.saida.push(dados);
    return dados.length;

    return 4242;
  }
}
```

```java
import java.util.*;
import java.util.function.Function;

class Kernel {
    Map<Integer, byte[]> arquivos = new HashMap<>();
    int trocasDeModo = 0;
    Map<Integer, Function<Object[], Object>> tabela = new HashMap<>();
    List<byte[]> saida = new ArrayList<>();

    Kernel() {
        arquivos.put(3, "config=prod".getBytes());
        tabela.put(0, a -> sysRead((int) a[0], (int) a[1]));
        tabela.put(1, a -> sysWrite((int) a[0], (byte[]) a[1]));
        tabela.put(39, a -> sysGetpid());
    }

    Object syscall(int numero, Object... args) {
        trocasDeModo += 2; // entrar e sair do modo kernel
        Function<Object[], Object> handler = tabela.get(numero);
        if (handler == null) {
            return "ENOSYS";
        }
        return handler.apply(args);
    }

    Object sysRead(int fd, int n) {
        if (!arquivos.containsKey(fd)) {
            return "EBADF";
        }
        byte[] dados = arquivos.get(fd);
        return Arrays.copyOf(dados, Math.min(n, dados.length));
    }

    Object sysWrite(int fd, byte[] dados) {
        if (fd != 1) {
            return "EBADF";
        }
        saida.add(dados);
        return dados.length;
    }

    Object sysGetpid() {
        return 4242;
    }
}

static String mostrar(Object valor) {
    if (valor instanceof byte[]) {
        return "b'" + new String((byte[]) valor) + "'";
    }
    return String.valueOf(valor);
}

    Kernel k = new Kernel();
```

```cpp
#include <functional>
#include <iostream>
#include <map>
#include <string>
#include <variant>
#include <vector>
using namespace std;

using Bytes = vector<unsigned char>;
using Valor = variant<long, string, Bytes>;  // um inteiro, um código de erro ou bytes
using Handler = function<Valor(const vector<Valor>&)>;

Bytes bytesDe(const string& texto) {
    return Bytes(texto.begin(), texto.end());
}

class Kernel {
public:
    map<long, Bytes> arquivos{{3, bytesDe("config=prod")}};
    int trocasDeModo = 0;
    map<long, Handler> tabela;
    vector<Bytes> saida;

    Kernel() {
        tabela[0] = [this](const vector<Valor>& a) { return sysRead(get<long>(a[0]), get<long>(a[1])); };
        tabela[1] = [this](const vector<Valor>& a) { return sysWrite(get<long>(a[0]), get<Bytes>(a[1])); };
        tabela[39] = [this](const vector<Valor>&) { return sysGetpid(); };
    }

    Valor syscall(long numero, const vector<Valor>& args = {}) {
        trocasDeModo += 2;  // entrar e sair do modo kernel
        auto it = tabela.find(numero);
        if (it == tabela.end()) {
            return string("ENOSYS");
        }
        return it->second(args);
    }

    Valor sysRead(long fd, long n) {
        if (!arquivos.count(fd)) {
            return string("EBADF");
        }
        const Bytes& dados = arquivos[fd];
        return Bytes(dados.begin(), dados.begin() + min<long>(n, dados.size()));
    }

    Valor sysWrite(long fd, const Bytes& dados) {
        if (fd != 1) {
            return string("EBADF");
        }
        saida.push_back(dados);
        return (long)dados.size();
    }

    Valor sysGetpid() {
        return 4242L;
    }
};

// imita o repr do Python: bytes aparecem como b'...'
string mostrar(const Valor& valor) {
    if (auto* n = get_if<long>(&valor)) return to_string(*n);
    if (auto* s = get_if<string>(&valor)) return *s;
    const Bytes& b = get<Bytes>(valor);
    return "b'" + string(b.begin(), b.end()) + "'";
}

int main() {
    Kernel k;
    cout << "read(3, 6)  -> " << mostrar(k.syscall(0, {3L, 6L})) << "\n";
    cout << "read(7, 6)  -> " << mostrar(k.syscall(0, {7L, 6L})) << "\n";
    cout << "write(1)    -> " << mostrar(k.syscall(1, {1L, bytesDe("ola")})) << "\n";
    cout << "getpid()    -> " << mostrar(k.syscall(39)) << "\n";
    cout << "syscall 999 -> " << mostrar(k.syscall(999)) << "\n";
    cout << "trocas de modo: " << k.trocasDeModo << "\n";
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

class Kernel
{
    public Dictionary<int, byte[]> Arquivos = new Dictionary<int, byte[]>();
    public int TrocasDeModo = 0;
    public Dictionary<int, Func<object[], object>> Tabela = new Dictionary<int, Func<object[], object>>();
    public List<byte[]> Saida = new List<byte[]>();

    public Kernel()
    {
        Arquivos[3] = Encoding.ASCII.GetBytes("config=prod");
        Tabela[0] = a => SysRead((int)a[0], (int)a[1]);
        Tabela[1] = a => SysWrite((int)a[0], (byte[])a[1]);
        Tabela[39] = a => SysGetpid();
    }

    public object Syscall(int numero, params object[] args)
    {
        TrocasDeModo += 2; // entrar e sair do modo kernel
        Func<object[], object> handler;
        if (!Tabela.TryGetValue(numero, out handler))
        {
            return "ENOSYS";
        }
        return handler(args);
    }

    public object SysRead(int fd, int n)
    {
        if (!Arquivos.ContainsKey(fd))
        {
            return "EBADF";
        }
        return Arquivos[fd].Take(n).ToArray();
    }

    public object SysWrite(int fd, byte[] dados)
    {
        if (fd != 1)
        {
            return "EBADF";
        }
        Saida.Add(dados);
        return dados.Length;
    }

    public object SysGetpid()
    {
        return 4242;
    }
}

{
    var bytes = valor as byte[];
    if (bytes != null)
    {
        return "b'" + Encoding.ASCII.GetString(bytes) + "'";
    }
    return valor.ToString();
}
```

```go
import "fmt"

type Handler func(args ...any) any

type Kernel struct {
	arquivos     map[int][]byte
	trocasDeModo int
	tabela       map[int]Handler
	saida        [][]byte
}

func NovoKernel() *Kernel {
	k := &Kernel{arquivos: map[int][]byte{3: []byte("config=prod")}}
	k.tabela = map[int]Handler{
		0:  func(a ...any) any { return k.sysRead(a[0].(int), a[1].(int)) },
		1:  func(a ...any) any { return k.sysWrite(a[0].(int), a[1].([]byte)) },
		39: func(a ...any) any { return k.sysGetpid() },
	}
	return k
}

func (k *Kernel) syscall(numero int, args ...any) any {
	k.trocasDeModo += 2 // entrar e sair do modo kernel
	handler, ok := k.tabela[numero]
	if !ok {
		return "ENOSYS"
	}
	return handler(args...)
}

func (k *Kernel) sysRead(fd, n int) any {
	dados, ok := k.arquivos[fd]
	if !ok {
		return "EBADF"
	}
	if n > len(dados) {
		n = len(dados)
	}
	return dados[:n]
}

func (k *Kernel) sysWrite(fd int, dados []byte) any {
	if fd != 1 {
		return "EBADF"
	}
	k.saida = append(k.saida, dados)
	return len(dados)
}

func (k *Kernel) sysGetpid() any {
	return 4242
}

// imita o repr do Python: bytes aparecem como b'...'
func mostrar(valor any) string {
	if b, ok := valor.([]byte); ok {
		return "b'" + string(b) + "'"
	}
	return fmt.Sprint(valor)
}

func main() {
	k := NovoKernel()
	fmt.Println("read(3, 6)  ->", mostrar(k.syscall(0, 3, 6)))
	fmt.Println("read(7, 6)  ->", mostrar(k.syscall(0, 7, 6)))
	fmt.Println("write(1)    ->", mostrar(k.syscall(1, 1, []byte("ola"))))
	fmt.Println("getpid()    ->", mostrar(k.syscall(39)))
	fmt.Println("syscall 999 ->", mostrar(k.syscall(999)))
	fmt.Println("trocas de modo:", k.trocasDeModo)
}
```

## O erro chega como errno

No mundo real, o mesmo acontece. Pedir ao kernel para ler um descritor que não existe não derruba nada: a syscall volta com `EBADF`, e o Python transforma isso em `OSError`.

```python
import errno
import os

try:
    os.read(987654, 10)
except OSError as e:
    print("errno:", e.errno, errno.errorcode[e.errno])

r, w = os.pipe()
print("escrito:", os.write(w, b"ping"))
print("lido:", os.read(r, 4))
os.close(r)
os.close(w)
```

```text
Saída:
errno: 9 EBADF
escrito: 4
lido: b'ping'
```

Repare que quase nada do que você escreve no dia a dia é syscall direta. Um `print` em Python passa pelo objeto de arquivo, pelo buffer de texto e só no fim chama `write`. Um `socket.recv` vira `recvfrom`. Um `time.sleep` vira `clock_nanosleep`. A biblioteca padrão é uma camada fina e conveniente sobre a interface do kernel, e ferramentas como `strace` deixam essa camada visível.

## Quanto custa atravessar a fronteira

Uma syscall simples custa da ordem de 100 nanossegundos a alguns microssegundos, bem mais que uma chamada de função (cerca de 1 ns). Além da troca de modo, há salvamento de registradores, verificações de segurança e, desde as mitigações para Meltdown, às vezes troca de tabelas de páginas. Isso explica várias decisões que você vê em bibliotecas:

| Técnica | Ideia | Onde aparece |
| --- | --- | --- |
| Buffer em espaço de usuário | Juntar muitas escritas pequenas numa syscall | `BufferedWriter`, `stdio`, loggers |
| vDSO | Executar certas chamadas sem entrar no kernel | `clock_gettime`, `gettimeofday` |
| Chamadas em lote | Uma syscall para muitas operações | `writev`, `sendmmsg`, `io_uring` |
| Mapear em vez de copiar | Evitar cópias entre kernel e usuário | `mmap`, `sendfile` |

<Callout type="note" title="Kernel monolítico ou microkernel">
Linux é monolítico: drivers, sistema de arquivos e rede rodam todos em modo kernel, o que é rápido, mas um driver com bug pode derrubar o sistema. Microkernels (seL4, QNX) movem esses serviços para processos em modo usuário, ganhando isolamento ao custo de mais trocas de mensagem.
</Callout>

## Ferramentas para observar

```bash
strace -c python3 script.py      # conta syscalls por tipo
strace -e trace=openat,read ls   # mostra só algumas chamadas
ltrace ./programa                # chamadas de biblioteca, não do kernel
```

Rodar `strace -c` num serviço lento costuma revelar milhares de `write` minúsculos ou `futex` em excesso, pistas diretas do gargalo.
