Um método agrupa um pedaço de lógica com nome, parâmetros e tipo de retorno. Em entrevista, quase toda solução é um método (ou alguns auxiliares), então vale dominar passagem de parâmetros, sobrecarga e funções locais, inclusive para escrever recursão limpa.

## Declaração e chamada

A assinatura tem o tipo de retorno antes do nome. Métodos sem retorno usam `void`. Métodos `static` pertencem ao tipo, e os demais exigem uma instância.

```csharp
using System;

class Program
{
    static int Somar(int a, int b)
    {
        return a + b;
    }

    static int Dobro(int x) => x * 2;      // corpo em expressão

    static void Main()
    {
        Console.WriteLine(Somar(2, 3));
        Console.WriteLine(Dobro(21));
    }
}
```

```text
Saída:
5
42
```

O corpo em expressão (`=>`) serve para métodos de uma única expressão e deixa helpers curtos.

## Passagem de parâmetros

Por padrão, parâmetros são passados por valor. Para tipos de valor, o método recebe uma cópia; para tipos de referência, recebe uma cópia da referência, então pode alterar o objeto apontado, mas não trocar o objeto na variável do chamador. Duas palavras-chave mudam isso:

- `ref`: passa a própria variável; ela deve estar inicializada antes.
- `out`: o método é obrigado a atribuir o valor; a variável não precisa estar inicializada.

```csharp
using System;

class Program
{
    static void Incrementar(int x) { x++; }
    static void IncrementarRef(ref int x) { x++; }

    static bool Dividir(int a, int b, out int quociente, out int resto)
    {
        if (b == 0) { quociente = 0; resto = 0; return false; }
        quociente = a / b;
        resto = a % b;
        return true;
    }

    static void Trocar(ref int a, ref int b)
    {
        int tmp = a; a = b; b = tmp;
    }

    static void Main()
    {
        int n = 5;
        Incrementar(n);
        Console.WriteLine(n);
        IncrementarRef(ref n);
        Console.WriteLine(n);

        int q, r;
        if (Dividir(17, 5, out q, out r))
            Console.WriteLine(q + " " + r);

        int x = 1, y = 2;
        Trocar(ref x, ref y);
        Console.WriteLine(x + " " + y);
    }
}
```

```text
Saída:
5
6
3 2
2 1
```

O padrão `bool Tentar(..., out T resultado)` é o idioma da biblioteca (`int.TryParse`, `Dictionary.TryGetValue`). Em C# 7 você pode declarar na chamada: `Dividir(17, 5, out int q, out int r)`.

## Sobrecarga, valores padrão e params

Vários métodos podem ter o mesmo nome com parâmetros diferentes (sobrecarga); o tipo de retorno sozinho não diferencia. Parâmetros opcionais recebem um valor padrão, e `params` aceita número variável de argumentos como array.

```csharp
using System;

class Program
{
    static int Soma(params int[] valores)
    {
        int s = 0;
        foreach (int v in valores) s += v;
        return s;
    }

    static string Saudar(string nome, string saudacao = "Olá")
    {
        return saudacao + ", " + nome;
    }

    static int Maior(int a, int b) { return a > b ? a : b; }
    static long Maior(long a, long b) { return a > b ? a : b; }

    static void Main()
    {
        Console.WriteLine(Soma());
        Console.WriteLine(Soma(1, 2, 3, 4));
        Console.WriteLine(Saudar("Rita"));
        Console.WriteLine(Saudar("Rita", saudacao: "Oi"));
        Console.WriteLine(Maior(3, 9));
    }
}
```

```text
Saída:
0
10
Olá, Rita
Oi, Rita
9
```

Argumentos nomeados (`saudacao: "Oi"`) tornam chamadas com vários opcionais legíveis.

## Recursão e funções locais

Recursão com memoização costuma ser um método auxiliar que recebe o cache como parâmetro:

```csharp
using System;

class Program
{
    static int Fib(int k, int[] memo)
    {
        if (k < 2) return k;
        if (memo[k] != 0) return memo[k];
        memo[k] = Fib(k - 1, memo) + Fib(k - 2, memo);
        return memo[k];
    }

    static int Fibonacci(int n)
    {
        return Fib(n, new int[n + 1]);
    }

    static void Main()
    {
        Console.WriteLine(Fibonacci(10));
        Console.WriteLine(Fibonacci(40));
    }
}
```

```text
Saída:
55
102334155
```

Em C# 7 ou superior você pode declarar o auxiliar dentro do método (função local), capturando as variáveis do método externo, sem passar o cache como parâmetro:

```csharp
static int Fibonacci(int n)
{
    int[] memo = new int[n + 1];
    int Fib(int k)
    {
        if (k < 2) return k;
        if (memo[k] != 0) return memo[k];
        return memo[k] = Fib(k - 1) + Fib(k - 2);
    }
    return Fib(n);   // Fibonacci(10) devolve 55
}
```

<Callout type="note" title="Versão">
Funções locais exigem C# 7 (Visual Studio 2017 ou .NET Core 2.0 ou superior). É o estilo mais comum hoje em recursões de entrevista.
</Callout>

Cuidado com a profundidade: o tamanho da pilha é limitado (cerca de 1 MB por thread por padrão), e uma recursão com centenas de milhares de níveis estoura com `StackOverflowException`, que não pode ser capturada. Se a entrada permitir profundidade grande, converta para iteração com uma `Stack`.

## Na entrevista

Dê nomes que descrevem a intenção, mantenha cada método com uma responsabilidade e extraia helpers quando a lógica se repetir.
