Python e JavaScript deixam você misturar tipos livremente. C# é estaticamente tipado: cada variável tem um tipo fixo, conhecido na compilação. Isso elimina uma classe inteira de bugs, mas exige saber quais tipos existem, qual o tamanho de cada um e a diferença entre tipos de valor e de referência.

## Tipos primitivos

Os tipos numéricos que aparecem em entrevistas:

| Tipo | Tamanho | Faixa aproximada |
|---|---|---|
| `int` | 32 bits | -2,1 bilhões a 2,1 bilhões |
| `long` | 64 bits | cerca de 9,2 quintilhões |
| `double` | 64 bits | ponto flutuante, ~15 dígitos |
| `decimal` | 128 bits | dinheiro, base decimal |
| `bool` | 1 byte | `true` ou `false` |
| `char` | 16 bits | uma unidade UTF-16 |

Inteiros literais são `int`; para um `long` use o sufixo `L` (`5000000000L`). Para `double`, `3.14`; para `decimal`, `3.14m`; para `float`, `3.14f`. Todos têm alias de palavra-chave: `int` é `System.Int32`, `long` é `System.Int64`, `string` é `System.String`.

## var e inferência

`var` deixa o compilador deduzir o tipo pelo lado direito. O tipo continua fixo; não é como o `var` do JavaScript.

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var n = 42;                       // int
        var nome = "Ana";                 // string
        var lista = new List<int>();      // List<int>
        lista.Add(n);
        Console.WriteLine(n.GetType());
        Console.WriteLine(nome.GetType());
        Console.WriteLine(lista.GetType().Name);
        // n = "texto";  // erro de compilação: n é int
    }
}
```

```text
Saída:
System.Int32
System.String
List`1
```

Use `var` quando o tipo é óbvio na linha (`new ...`) e escreva o tipo explicitamente quando isso ajuda a leitura, por exemplo em `int total = Calcular();`.

## Tipos de valor e de referência

Esta é a distinção mais importante. Tipos de valor (`int`, `bool`, `char`, `struct`, `enum`) guardam o dado na própria variável; atribuir copia o valor. Tipos de referência (`class`, `string`, arrays, `List`) guardam uma referência para um objeto no heap; atribuir copia a referência, e as duas variáveis apontam para o mesmo objeto.

```csharp
using System;

class Program
{
    static void Main()
    {
        int a = 5;
        int b = a;
        b = 99;
        Console.WriteLine(a);        // a não mudou

        int[] x = { 1, 2, 3 };
        int[] y = x;
        y[0] = 100;
        Console.WriteLine(x[0]);     // x mudou: mesmo array

        int[] z = (int[])x.Clone();
        z[0] = -1;
        Console.WriteLine(x[0]);     // cópia independente
    }
}
```

```text
Saída:
5
100
100
```

Isso explica a armadilha de "copiar" uma lista com `=` e depois se surpreender ao ver o original alterado. Para copiar de verdade, crie uma nova coleção: `new List<int>(original)`.

## Valores padrão e constantes

Campos e elementos de array começam com o valor padrão do tipo: `0` para numéricos, `false` para `bool`, `null` para referências. Variáveis locais, porém, precisam ser atribuídas antes do uso, ou o compilador reclama. Para valores imutáveis use `const` (resolvido na compilação) ou `readonly` (atribuído uma vez, no construtor).

## String é imutável

`string` é um tipo de referência, mas imutável: toda operação cria uma nova string. Veja o capítulo de strings para as consequências em complexidade.

## Na entrevista

Prefira `int` na maioria dos casos, mas pare e pense quando o enunciado fala em somas grandes, produtos ou contagens acima de 2 bilhões: use `long`. Para `char`, lembre que ele é numérico por baixo (`'a' + 1` vira `int`). Follow-ups comuns: "qual a diferença entre `struct` e `class`?" (valor versus referência) e "o que acontece se eu passar uma lista para um método e modificá-la lá dentro?" (o chamador vê a mudança, pois a referência é a mesma).
