Ordenar é o pré-processamento mais comum em entrevistas: ordenar intervalos antes de mesclá-los, ordenar para usar dois ponteiros, ordenar objetos por um campo. Em C# você tem `Array.Sort`, `List.Sort` e o `OrderBy` do LINQ, e precisa saber qual usar e como escrever um comparador sem erro.

## Ordenação padrão

Para tipos que sabem se comparar (números, strings, `char`), basta chamar `Sort`. As duas formas ordenam no lugar, em O(n log n).

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        int[] v = { 5, 2, 9, 1 };
        Array.Sort(v);
        Console.WriteLine(string.Join(" ", v));

        var nomes = new List<string> { "caio", "ana", "bia" };
        nomes.Sort();
        Console.WriteLine(string.Join(" ", nomes));

        Array.Reverse(v);                    // truque para ordem decrescente
        Console.WriteLine(string.Join(" ", v));
    }
}
```

```text
Saída:
1 2 5 9
ana bia caio
9 5 2 1
```

Há um aviso importante: `Array.Sort` e `List.Sort` usam introsort e não são estáveis (itens iguais podem trocar de ordem relativa). Se a estabilidade importa, use `OrderBy` do LINQ, que é estável e devolve uma nova sequência.

## Comparadores com delegate

Para ordenar por um critério próprio, passe um `Comparison<T>`: uma função que recebe dois itens e devolve um número negativo se o primeiro vem antes, zero se empatam e positivo se vem depois. O jeito seguro é usar `CompareTo`.

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        int[][] intervalos = new int[][]
        {
            new int[] { 8, 10 }, new int[] { 1, 3 }, new int[] { 2, 6 }, new int[] { 1, 2 }
        };
        // por início crescente, desempate por fim crescente
        Array.Sort(intervalos, (a, b) =>
        {
            int c = a[0].CompareTo(b[0]);
            return c != 0 ? c : a[1].CompareTo(b[1]);
        });
        foreach (int[] it in intervalos)
            Console.Write("[" + it[0] + "," + it[1] + "] ");
        Console.WriteLine();

        var nums = new List<int> { 3, 10, 1, 7 };
        nums.Sort((a, b) => b.CompareTo(a));     // decrescente
        Console.WriteLine(string.Join(" ", nums));

        var palavras = new List<string> { "kiwi", "fig", "banana", "uva" };
        palavras.Sort((a, b) =>
        {
            int c = a.Length.CompareTo(b.Length);
            return c != 0 ? c : string.CompareOrdinal(a, b);
        });
        Console.WriteLine(string.Join(" ", palavras));
    }
}
```

```text
Saída:
[1,2] [1,3] [2,6] [8,10] 
10 7 3 1
fig uva kiwi banana
```

Note o erro clássico a evitar: escrever `(a, b) => b - a`. Parece funcionar, mas se os valores estiverem perto dos limites do `int`, a subtração estoura e a ordem fica errada. `b.CompareTo(a)` nunca estoura.

## IComparable e IComparer

Quando uma classe tem uma ordem natural, implemente `IComparable<T>` e ela passa a funcionar com `Sort()` sem argumentos. Para ordens alternativas, crie uma classe `IComparer<T>` separada.

```csharp
using System;
using System.Collections.Generic;

class Pessoa : IComparable<Pessoa>
{
    public string Nome;
    public int Idade;

    public Pessoa(string nome, int idade) { Nome = nome; Idade = idade; }

    public int CompareTo(Pessoa outra)
    {
        return Idade.CompareTo(outra.Idade);
    }
}

class PorNome : IComparer<Pessoa>
{
    public int Compare(Pessoa a, Pessoa b)
    {
        return string.CompareOrdinal(a.Nome, b.Nome);
    }
}

class Program
{
    static void Main()
    {
        var gente = new List<Pessoa>
        {
            new Pessoa("Rui", 40), new Pessoa("Ana", 55), new Pessoa("Leo", 33)
        };
        gente.Sort();
        foreach (Pessoa p in gente) Console.Write(p.Nome + " ");
        Console.WriteLine();

        gente.Sort(new PorNome());
        foreach (Pessoa p in gente) Console.Write(p.Nome + " ");
        Console.WriteLine();
    }
}
```

```text
Saída:
Leo Rui Ana
Ana Leo Rui
```

A primeira chamada usa a ordem natural (`CompareTo`, por idade); a segunda usa o comparador externo, por nome.

## OrderBy do LINQ

`OrderBy`, `OrderByDescending`, `ThenBy` e `ThenByDescending` expressam critérios múltiplos de forma legível e são estáveis, ao custo de criar uma nova sequência.

```csharp
// requer using System.Linq;
var ordenado = gente.OrderBy(p => p.Idade).ThenBy(p => p.Nome).ToList();
// ordem estável por idade, desempate por nome
```

Se precisa só do menor ou do maior elemento, não ordene: `Min`/`Max` percorrem em O(n).

## Busca binária

Em dados ordenados, `Array.BinarySearch` e `List.BinarySearch` buscam em O(log n). Se o item não existe, devolvem o complemento bit a bit da posição de inserção: `~resultado` dá o índice onde ele entraria.
