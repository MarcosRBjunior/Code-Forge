A estrutura que você mais vai digitar em C# é `List<T>`: um array redimensionável. Quando o tamanho da entrada não é conhecido, ou você vai ir acrescentando resultados, é a escolha padrão. `LinkedList<T>` existe, mas aparece bem menos.

## List de T

Por baixo, `List<T>` guarda um array e um contador. Ao estourar a capacidade, aloca outro array com o dobro do tamanho e copia. Por isso `Add` no final é O(1) amortizado, e o acesso por índice é O(1). Inserir ou remover no meio ou no início é O(n), porque desloca os elementos seguintes.

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var lista = new List<int> { 5, 3, 8 };
        lista.Add(1);
        lista.Insert(0, 10);            // O(n)
        Console.WriteLine(string.Join(" ", lista));

        lista.Remove(8);                // remove a primeira ocorrência, O(n)
        lista.RemoveAt(0);              // por índice, O(n)
        Console.WriteLine(string.Join(" ", lista));

        Console.WriteLine(lista.Count);
        Console.WriteLine(lista[1]);
        Console.WriteLine(lista.Contains(3));     // O(n)
        Console.WriteLine(lista.IndexOf(1));

        lista.Sort();
        lista.Reverse();
        Console.WriteLine(string.Join(" ", lista));

        lista.AddRange(new int[] { 7, 7 });
        Console.WriteLine(lista.Count);
        lista.Clear();
        Console.WriteLine(lista.Count);
    }
}
```

```text
Saída:
10 5 3 8 1
5 3 1
3
3
True
2
5 3 1
5
0
```

Repare: o tamanho é `Count` (propriedade), e `Length` é de arrays e strings. `Remove` devolve um `bool` indicando se achou. `Sort` é in-place e O(n log n).

## Conversões e cópias

Para criar uma cópia independente, passe a lista original ao construtor. Para ir e voltar de array, use `ToArray()` e `new List<int>(array)`. Um `List<List<int>>` é a forma comum de montar resultados do tipo "todas as combinações".

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var a = new List<int> { 1, 2, 3 };
        var alias = a;
        var copia = new List<int>(a);
        a.Add(4);
        Console.WriteLine(alias.Count + " " + copia.Count);

        var resultado = new List<List<int>>();
        resultado.Add(new List<int>(a));
        a.Clear();
        Console.WriteLine(resultado[0].Count);

        int[] arr = copia.ToArray();
        Console.WriteLine(arr.Length);
        var sub = a.GetRange(0, 0);
        Console.WriteLine(sub.Count);
    }
}
```

```text
Saída:
4 3
4
3
0
```

Note a linha `resultado.Add(new List<int>(a))`: sem a cópia, o resultado guardaria a mesma lista que depois seria esvaziada. Esse é um dos erros mais comuns em backtracking.

## LinkedList de T

`LinkedList<T>` é uma lista duplamente encadeada. Inserir ou remover num nó já conhecido é O(1) (`AddFirst`, `AddLast`, `AddBefore`, `AddAfter`, `Remove(nó)`), mas não há acesso por índice: encontrar o k-ésimo elemento é O(k). A memória é espalhada em nós, o que é pior para o cache do processador.

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var ll = new LinkedList<int>();
        ll.AddLast(2);
        ll.AddLast(3);
        ll.AddFirst(1);
        LinkedListNode<int> no = ll.Find(2);
        ll.AddAfter(no, 99);
        ll.Remove(no);                      // O(1) porque já temos o nó
        Console.WriteLine(string.Join(" ", ll));
        Console.WriteLine(ll.First.Value + " " + ll.Last.Value);
        ll.RemoveFirst();
        Console.WriteLine(ll.Count);
    }
}
```

```text
Saída:
1 99 3
1 3
2
```

Na prática, `List<T>` vence `LinkedList<T>` em quase tudo, até em inserções no meio para tamanhos moderados, graças ao cache. Reserve `LinkedList` para casos como um cache LRU, em que você guarda os nós num dicionário e move para a frente em O(1).

## Armadilhas

- Remover dentro de `foreach` lança `InvalidOperationException`. Use `for` de trás para frente ou `RemoveAll(predicado)`.
- `lista.Contains` e `IndexOf` são O(n). Se testa pertinência em laço, use `HashSet`.
- `RemoveAt(0)` repetido em fila de n itens custa O(n²); use `Queue`.
- Acessar `lista[lista.Count]` lança `ArgumentOutOfRangeException`.

## Na entrevista

Use `List<T>` para acumular resultados e quando o enunciado for em termos de "sequência dinâmica". Se for adicionar muitos itens e souber o tamanho, `new List<int>(capacidade)` evita realocações. Follow-ups comuns: "qual a complexidade de `Add`?" (O(1) amortizado, explicando o dobro da capacidade) e "quando prefere `LinkedList`?" (inserções e remoções em nós já conhecidos).
