Quando um enunciado fala em "contar ocorrências", "achar duplicados" ou "o complemento de um número", a resposta quase sempre é uma tabela hash. Em C#, os dois tipos que você precisa dominar são `Dictionary<TKey, TValue>` (mapa de chave para valor) e `HashSet<T>` (conjunto sem repetições). São o equivalente a `dict` e `set` do Python, ou `Map` e `Set` do JavaScript.

## Como funciona

Uma tabela hash calcula `GetHashCode()` da chave para escolher um balde; dentro do balde, compara com `Equals`. Com boa distribuição, inserir, buscar e remover custam O(1) em média. No pior caso (muitas colisões) degeneram para O(n), mas isso é raro com tipos nativos.

## Dictionary

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var idade = new Dictionary<string, int>();
        idade["ana"] = 30;
        idade["bia"] = 25;
        idade.Add("caio", 41);
        idade["ana"] = 31;                    // sobrescreve

        Console.WriteLine(idade.Count);
        Console.WriteLine(idade["ana"]);
        Console.WriteLine(idade.ContainsKey("duda"));

        int v;
        if (idade.TryGetValue("bia", out v))
            Console.WriteLine("bia = " + v);
        if (!idade.TryGetValue("zeca", out v))
            Console.WriteLine("sem zeca");

        idade.Remove("caio");
        foreach (KeyValuePair<string, int> par in idade)
            Console.WriteLine(par.Key + ":" + par.Value);
    }
}
```

```text
Saída:
3
31
False
bia = 25
sem zeca
ana:31
bia:25
```

Pontos críticos: ler `idade["duda"]` de uma chave inexistente lança `KeyNotFoundException` (em Python também seria `KeyError`, mas em JS devolveria `undefined`). `Add` com chave repetida lança `ArgumentException`, enquanto o indexador `d[k] = v` sobrescreve. Para ler com segurança, use `TryGetValue`. Não confie na ordem de iteração: ela costuma refletir a inserção, mas não é garantida, principalmente após remoções.

## Padrão de contagem

O idioma mais usado é contar frequências:

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        string texto = "abracadabra";
        var freq = new Dictionary<char, int>();
        foreach (char c in texto)
        {
            int atual;
            freq.TryGetValue(c, out atual);   // atual vira 0 se não existir
            freq[c] = atual + 1;
        }

        var chaves = new List<char>(freq.Keys);
        chaves.Sort();
        foreach (char c in chaves)
            Console.WriteLine(c + "=" + freq[c]);

        var grupos = new Dictionary<int, List<string>>();
        string[] palavras = { "um", "dois", "tres", "oito", "seis" };
        foreach (string p in palavras)
        {
            if (!grupos.ContainsKey(p.Length))
                grupos[p.Length] = new List<string>();
            grupos[p.Length].Add(p);
        }
        Console.WriteLine(string.Join(",", grupos[4]));
    }
}
```

```text
Saída:
a=5
b=2
c=1
d=1
r=2
dois,tres,oito,seis
```

Quando `TryGetValue` não encontra a chave, o parâmetro `out` recebe o valor padrão do tipo (zero para `int`), o que simplifica a contagem. Para valores que são coleções, inicialize a lista na primeira vez, como acima.

## HashSet

`HashSet<T>` guarda elementos únicos. `Add` devolve `false` se o elemento já existia, o que é perfeito para detectar duplicados. Há operações de conjunto: `UnionWith`, `IntersectWith`, `ExceptWith`.

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static bool TemDuplicado(int[] v)
    {
        var vistos = new HashSet<int>();
        foreach (int x in v)
            if (!vistos.Add(x)) return true;
        return false;
    }

    static void Main()
    {
        Console.WriteLine(TemDuplicado(new int[] { 1, 2, 3, 1 }));
        Console.WriteLine(TemDuplicado(new int[] { 1, 2, 3 }));

        var a = new HashSet<int> { 1, 2, 3, 4 };
        var b = new HashSet<int> { 3, 4, 5 };
        a.IntersectWith(b);
        Console.WriteLine(a.Count + " " + a.Contains(3));
    }
}
```

```text
Saída:
True
False
2 True
```

## Chaves personalizadas e variantes ordenadas

Se a chave é uma classe sua, sobrescreva `Equals` e `GetHashCode` juntos; sem isso, duas instâncias iguais em valor contam como chaves diferentes. `struct` e tipos como `string` já fazem o certo. Nunca altere uma chave depois de inseri-la.

Quando precisar de ordem, existem `SortedDictionary` e `SortedSet`, baseados em árvores balanceadas: operações em O(log n), com iteração ordenada, e `SortedSet` ainda oferece `Min` e `Max`.
