Condições e laços formam o esqueleto de qualquer solução. A sintaxe é familiar para quem conhece JavaScript, mas C# tem detalhes próprios: condições precisam ser `bool` de verdade, o `switch` não deixa cair para o caso seguinte e o `foreach` é a forma preferida de percorrer coleções.

## if, else e o operador ternário

A condição do `if` deve ser um `bool`. Não existe "truthy" como em Python e JS: `if (n)` com `n` inteiro não compila; escreva `if (n != 0)`.

```csharp
using System;

class Program
{
    static string Classificar(int n)
    {
        if (n < 0) return "negativo";
        else if (n == 0) return "zero";
        return n % 2 == 0 ? "par positivo" : "impar positivo";
    }

    static void Main()
    {
        Console.WriteLine(Classificar(-4));
        Console.WriteLine(Classificar(0));
        Console.WriteLine(Classificar(8));
        Console.WriteLine(Classificar(7));
    }
}
```

```text
Saída:
negativo
zero
par positivo
impar positivo
```

O ternário `cond ? a : b` é uma expressão e cabe bem em retornos curtos.

## Laços: for, while, do-while e foreach

O `for` clássico tem três partes. O `foreach` percorre qualquer coleção enumerável e não permite alterar a coleção durante a iteração (uma `InvalidOperationException` é lançada se você tentar adicionar ou remover). A variável do `foreach` é somente leitura.

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        int[] v = { 4, 8, 15, 16 };
        int soma = 0;
        for (int i = 0; i < v.Length; i++) soma += v[i];
        Console.WriteLine(soma);

        int prod = 1;
        foreach (int x in v) prod *= 2;
        Console.WriteLine(prod);

        int n = 27, passos = 0;
        while (n != 1)
        {
            n = n % 2 == 0 ? n / 2 : 3 * n + 1;
            passos++;
        }
        Console.WriteLine(passos);

        int k = 0;
        do { k++; } while (k < 3);
        Console.WriteLine(k);

        var letras = new List<char> { 'x', 'y' };
        foreach (char c in letras) Console.Write(c);
        Console.WriteLine();
    }
}
```

```text
Saída:
43
16
111
3
xy
```

Para percorrer em ordem inversa ou pular elementos, use `for`. Use `foreach` quando só precisa dos valores: é mais curto e evita erros de índice.

## break, continue e rótulos

`break` sai do laço mais interno, `continue` pula para a próxima iteração. Para sair de laços aninhados, C# não tem `break rotulado`; as opções são uma variável `bool`, extrair o laço para um método com `return` ou usar `goto` (raro, mas válido).

## switch

O `switch` clássico exige que cada caso termine com `break`, `return` ou similar. Não há fall-through implícito, o que é um alívio comparado a Java e C.

```csharp
using System;

class Program
{
    static int Dias(int mes)
    {
        switch (mes)
        {
            case 2:
                return 28;
            case 4:
            case 6:
            case 9:
            case 11:
                return 30;
            default:
                return 31;
        }
    }

    static void Main()
    {
        Console.WriteLine(Dias(2));
        Console.WriteLine(Dias(6));
        Console.WriteLine(Dias(12));
    }
}
```

```text
Saída:
28
30
31
```

Casos vazios empilhados (como 4, 6, 9, 11) compartilham o mesmo bloco. Você pode usar `switch` com `string`, `char` e `enum`.

## switch expression

Em C# 8 ou superior existe a forma de expressão, bem mais concisa:

```csharp
// C# 8 ou superior
int Dias(int mes) => mes switch
{
    2 => 28,
    4 or 6 or 9 or 11 => 30,   // "or" em padrões exige C# 9
    _ => 31
};
// Dias(6) devolve 30
```

<Callout type="note" title="Versão">
Switch expressions pedem C# 8 (.NET Core 3.0 ou superior), e o padrão `or` pede C# 9 (.NET 5 ou superior).
</Callout>
