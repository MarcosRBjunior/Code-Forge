Textos aparecem em metade dos problemas de entrevista: palíndromos, anagramas, parsing, janelas deslizantes. Em C#, `string` é um tipo de referência imutável, e entender essa imutabilidade é a chave para escrever código correto e com a complexidade certa.

## Imutabilidade

Nenhum método de `string` altera a string original; todos devolvem uma nova. Por isso `s.ToUpper();` sozinho não faz nada útil: o resultado precisa ser atribuído.

```csharp
using System;

class Program
{
    static void Main()
    {
        string s = "codeforge";
        s.ToUpper();                       // resultado descartado
        Console.WriteLine(s);
        string u = s.ToUpper();
        Console.WriteLine(u);

        Console.WriteLine(s.Length);
        Console.WriteLine(s[0]);
        Console.WriteLine(s.Substring(4, 3));
        Console.WriteLine(s.IndexOf("for"));
        Console.WriteLine(s.Contains("ode"));
        Console.WriteLine(s.Replace("e", "E"));
        Console.WriteLine(string.Join("-", "a b c".Split(' ')));
        Console.WriteLine("  oi  ".Trim() + "|");
        Console.WriteLine(string.Compare("abc", "abd", StringComparison.Ordinal) < 0);
    }
}
```

```text
Saída:
codeforge
CODEFORGE
9
c
for
4
True
codEforgE
a-b-c
oi|
True
```

`Substring(início, tamanho)` recebe o tamanho, não o fim (diferente de `slice` em JS). `s[i]` devolve um `char`. `==` entre strings compara o conteúdo. Cada operação que devolve texto novo custa O(n).

## O custo de concatenar em laço

Como a string é imutável, `s += x` copia tudo a cada passo. Num laço de n iterações isso vira O(n²). A solução é `StringBuilder`, que mantém um buffer mutável e anexa em tempo amortizado O(1).

```csharp
using System;
using System.Text;

class Program
{
    static void Main()
    {
        var sb = new StringBuilder();
        for (int i = 0; i < 5; i++)
        {
            sb.Append(i);
            if (i < 4) sb.Append(',');
        }
        sb.Insert(0, "[").Append("]");
        Console.WriteLine(sb.ToString());
        Console.WriteLine(sb.Length);

        sb.Clear();
        sb.Append("abc");
        sb[1] = 'X';
        Console.WriteLine(sb);

        char[] letras = "stressed".ToCharArray();
        Array.Reverse(letras);
        Console.WriteLine(new string(letras));
    }
}
```

```text
Saída:
[0,1,2,3,4]
11
aXc
desserts
```

`StringBuilder` permite alterar um caractere por índice, `Insert`, `Remove` e `Append` encadeado. Ao final, `ToString()` gera a string. Para inverter ou modificar caracteres de forma barata, converta com `ToCharArray()`, trabalhe no array e volte com `new string(array)`.

## Caracteres e contagem

Uma técnica constante em entrevistas é contar letras com um array de 26 posições, usando `c - 'a'` como índice. Os utilitários de `char` ajudam: `char.IsLetter`, `char.IsDigit`, `char.IsUpper`, `char.ToLower`.

```csharp
using System;

class Program
{
    static bool Anagrama(string a, string b)
    {
        if (a.Length != b.Length) return false;
        int[] cont = new int[26];
        for (int i = 0; i < a.Length; i++)
        {
            cont[a[i] - 'a']++;
            cont[b[i] - 'a']--;
        }
        foreach (int c in cont)
            if (c != 0) return false;
        return true;
    }

    static void Main()
    {
        Console.WriteLine(Anagrama("listen", "silent"));
        Console.WriteLine(Anagrama("rato", "roto"));
    }
}
```

```text
Saída:
True
False
```

Essa solução é O(n) em tempo e O(1) em memória, melhor do que ordenar as duas strings (O(n log n)).

## Interpolação e comparação

`$"x = {x}"` monta strings legíveis. Para comparar sem diferenciar maiúsculas, use `string.Equals(a, b, StringComparison.OrdinalIgnoreCase)`. Prefira comparações ordinais: são mais rápidas e independem da cultura.

## Armadilhas

- `string` com `null` e `""` são coisas diferentes; `string.IsNullOrEmpty(s)` cobre ambos.
- Strings são UTF-16: emojis ocupam dois `char`. Em entrevistas o enunciado quase sempre garante ASCII.
- `s.Length` é propriedade, e `s.Split` devolve um array.

## Na entrevista

Se for modificar texto caractere a caractere, anuncie que vai usar `StringBuilder` ou um array de `char` para evitar O(n²). Follow-ups comuns: "por que strings são imutáveis?" (segurança, cache de hash, uso seguro como chave) e "qual o custo de `s.Substring`?" (O(k), pois copia).
