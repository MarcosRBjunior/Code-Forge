Pilha (último a entrar, primeiro a sair) e fila (primeiro a entrar, primeiro a sair) são a base de parênteses balanceados, avaliação de expressões, DFS iterativo e BFS. Em C# existem `Stack<T>` e `Queue<T>` prontas. Não há uma classe `Deque` dedicada, mas `LinkedList<T>` cumpre o papel quando você precisa das duas pontas.

## Stack de T

`Stack<T>` usa um array interno. As operações são `Push` (empilha), `Pop` (remove e devolve o topo), `Peek` (olha o topo sem remover) e `Count`. Todas são O(1) amortizado. `Pop` e `Peek` em pilha vazia lançam `InvalidOperationException`, então teste `Count` antes.

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static bool Balanceado(string s)
    {
        var pilha = new Stack<char>();
        foreach (char c in s)
        {
            if (c == '(' || c == '[' || c == '{')
                pilha.Push(c);
            else
            {
                if (pilha.Count == 0) return false;
                char topo = pilha.Pop();
                if (c == ')' && topo != '(') return false;
                if (c == ']' && topo != '[') return false;
                if (c == '}' && topo != '{') return false;
            }
        }
        return pilha.Count == 0;
    }

    static void Main()
    {
        Console.WriteLine(Balanceado("([]{})"));
        Console.WriteLine(Balanceado("([)]"));
        Console.WriteLine(Balanceado("(("));

        var p = new Stack<int>();
        p.Push(1); p.Push(2); p.Push(3);
        Console.WriteLine(p.Peek());
        Console.WriteLine(string.Join(" ", p));
    }
}
```

```text
Saída:
True
False
False
3
3 2 1
```

A enumeração de uma `Stack` vai do topo para a base, ao contrário da ordem de inserção. Isso surpreende na hora de imprimir ou converter com `ToArray()`.

## Queue de T

`Queue<T>` é um buffer circular. `Enqueue` adiciona no fim, `Dequeue` remove do início e `Peek` observa o primeiro. Todas O(1). É a estrutura da busca em largura.

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static int Distancia(int[][] grafo, int origem, int destino)
    {
        int[] dist = new int[grafo.Length];
        for (int i = 0; i < dist.Length; i++) dist[i] = -1;
        var fila = new Queue<int>();
        dist[origem] = 0;
        fila.Enqueue(origem);
        while (fila.Count > 0)
        {
            int u = fila.Dequeue();
            if (u == destino) return dist[u];
            foreach (int v in grafo[u])
            {
                if (dist[v] != -1) continue;
                dist[v] = dist[u] + 1;
                fila.Enqueue(v);
            }
        }
        return -1;
    }

    static void Main()
    {
        int[][] g = new int[5][];
        g[0] = new int[] { 1, 2 };
        g[1] = new int[] { 3 };
        g[2] = new int[] { 3 };
        g[3] = new int[] { 4 };
        g[4] = new int[0];
        Console.WriteLine(Distancia(g, 0, 4));
        Console.WriteLine(Distancia(g, 4, 0));
    }
}
```

```text
Saída:
3
-1
```

Marque o vértice como visitado ao enfileirar, e não ao desenfileirar. Do contrário o mesmo nó entra várias vezes e o BFS perde eficiência.

## Deque com LinkedList

Para inserir e remover nas duas pontas em O(1), use `LinkedList<T>` com `AddFirst`, `AddLast`, `RemoveFirst`, `RemoveLast`, `First` e `Last`. É a estrutura do padrão "janela deslizante com máximo monotônico".

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static int[] MaximosDaJanela(int[] v, int k)
    {
        var res = new List<int>();
        var dq = new LinkedList<int>();      // guarda índices, valores decrescentes
        for (int i = 0; i < v.Length; i++)
        {
            while (dq.Count > 0 && dq.First.Value <= i - k) dq.RemoveFirst();
            while (dq.Count > 0 && v[dq.Last.Value] <= v[i]) dq.RemoveLast();
            dq.AddLast(i);
            if (i >= k - 1) res.Add(v[dq.First.Value]);
        }
        return res.ToArray();
    }

    static void Main()
    {
        int[] r = MaximosDaJanela(new int[] { 1, 3, -1, -3, 5, 3, 6, 7 }, 3);
        Console.WriteLine(string.Join(" ", r));
    }
}
```

```text
Saída:
3 3 5 5 6 7
```

A solução é O(n), pois cada índice entra e sai do deque no máximo uma vez. Note que `LinkedList` permite ler `First` e `Last` em O(1), mas não indexar.

## Armadilhas

- `Dequeue` em fila vazia lança `InvalidOperationException`; em C# há `TryDequeue` e `TryPop` apenas em versões recentes (.NET Core 2.0 ou superior).
- Usar `List` como fila com `RemoveAt(0)` é O(n) por operação.
- A enumeração de `Stack` é do topo para a base.
- Nem `Stack` nem `Queue` oferecem acesso por índice.
