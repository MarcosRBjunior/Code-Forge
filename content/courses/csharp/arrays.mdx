O array é a estrutura mais básica: uma sequência de tamanho fixo, com elementos do mesmo tipo, guardados lado a lado na memória. Por isso o acesso por índice é O(1) e a iteração é muito rápida. Em quase todo problema de entrevista a entrada chega como array, então vale conhecer a sintaxe e os utilitários da classe `Array`.

## Criar e acessar

O tamanho é definido na criação e não muda. Todo array é um objeto de referência, e `Length` é uma propriedade (sem parênteses, ao contrário de Python).

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] a = new int[5];             // cinco zeros
        int[] b = { 3, 1, 4, 1, 5 };      // literal
        string[] nomes = new string[2];   // dois null

        a[0] = 7;
        Console.WriteLine(a.Length);
        Console.WriteLine(a[0] + " " + a[1]);
        Console.WriteLine(b[b.Length - 1]);
        Console.WriteLine(nomes[0] == null);
    }
}
```

```text
Saída:
5
7 0
5
True
```

Índices fora do intervalo lançam `IndexOutOfRangeException`. Índices negativos não existem: `b[-1]` é erro, ao contrário de Python. Em C# 8 existe `b[^1]` para o último elemento, mas só em versões novas.

## Utilitários de Array

A classe estática `Array` oferece as operações comuns:

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] v = { 5, 2, 9, 1, 7 };

        int[] copia = (int[])v.Clone();
        Array.Sort(copia);
        Console.WriteLine(string.Join(" ", copia));
        Console.WriteLine(string.Join(" ", v));

        Console.WriteLine(Array.BinarySearch(copia, 7));
        Console.WriteLine(Array.IndexOf(v, 9));

        Array.Reverse(copia);
        Console.WriteLine(string.Join(" ", copia));

        int[] grande = new int[7];
        Array.Copy(v, grande, v.Length);
        Console.WriteLine(string.Join(" ", grande));

        int[] preenchido = new int[4];
        Array.Fill(preenchido, -1);
        Console.WriteLine(string.Join(" ", preenchido));

        Array.Resize(ref v, 7);
        Console.WriteLine(v.Length);
    }
}
```

```text
Saída:
1 2 5 7 9
5 2 9 1 7
3
2
9 7 5 2 1
5 2 9 1 7 0 0
-1 -1 -1 -1
7
```

Observações: `Array.Sort` ordena no lugar (O(n log n)), por isso clonamos antes. `BinarySearch` exige array já ordenado e devolve um número negativo se o item não existe. `Array.Resize` não aumenta o array: cria um novo, copia os elementos e atualiza a referência (daí o `ref`), custando O(n). Se você precisa crescer com frequência, use `List`.

## Arrays multidimensionais e jagged

Há duas formas de matriz. A retangular `int[,]` é um bloco único; a irregular `int[][]` é um array de arrays, em que cada linha pode ter tamanho diferente. Em entrevistas, a mais comum é `int[][]` (é o que grids de entrada costumam usar), e a retangular aparece ao criar tabelas de DP.

```csharp
using System;

class Program
{
    static void Main()
    {
        int[,] tabela = new int[3, 4];
        tabela[1, 2] = 8;
        Console.WriteLine(tabela.GetLength(0) + " x " + tabela.GetLength(1));
        Console.WriteLine(tabela[1, 2]);

        int[][] grade = new int[2][];
        grade[0] = new int[] { 1, 2, 3 };
        grade[1] = new int[] { 4, 5 };
        Console.WriteLine(grade[1].Length);
        Console.WriteLine(grade[0][2]);
    }
}
```

```text
Saída:
3 x 4
8
2
3
```

Em `int[,]`, use `GetLength(dimensão)` para obter as dimensões; `Length` devolve o total de células. Em `int[][]`, é preciso alocar cada linha, ou você terá `null` e uma `NullReferenceException`.

## Armadilhas

- Atribuir `int[] y = x` não copia: ambas variáveis apontam para o mesmo array.
- `==` em arrays compara referências, não conteúdo. Para comparar elementos, use um laço ou `SequenceEqual` (de LINQ).
- Arrays são covariantes: `object[] o = new string[1]; o[0] = 1;` compila, mas lança `ArrayTypeMismatchException` em tempo de execução.
