**Programação dinâmica** (DP) resolve problemas que se quebram em subproblemas **sobrepostos**: os mesmos cálculos aparecem várias vezes. Em vez de refazê-los, você guarda cada resposta e a reutiliza. Uma recursão exponencial costuma virar polinomial.

## Os dois ingredientes

1. **Subestrutura ótima:** a resposta do problema pode ser montada a partir das respostas de problemas menores.
2. **Sobreposição:** esses problemas menores se repetem.

O exemplo mais simples é subir uma escada de n degraus dando passos de 1 ou 2. Para chegar ao degrau n, o último passo veio do degrau n − 1 ou do n − 2, então `formas(n) = formas(n - 1) + formas(n - 2)`. Sem guardar resultados, essa recursão recalcula os mesmos degraus um número exponencial de vezes.

## Top-down: recursão com memória

Escreva a recursão natural e guarde cada resultado na primeira vez que for calculado:

<CodeTabs>

```python
from functools import cache

def formas_escada(n):
    @cache
    def f(i):
        if i <= 1:
            return 1
        return f(i - 1) + f(i - 2)
    return f(n)

print(formas_escada(10))  # 89
```

```javascript
function formasEscada(n) {
  const memo = new Map();
  function f(i) {
    if (i <= 1) {
      return 1;
    }
    if (!memo.has(i)) {
      memo.set(i, f(i - 1) + f(i - 2));
    }
    return memo.get(i);
  }
  return f(n);
}

console.log(formasEscada(10));  // 89
```

```cpp
#include <functional>
#include <iostream>
#include <unordered_map>
using namespace std;

int formasEscada(int n) {
    unordered_map<int, int> memo;
    function<int(int)> f = [&](int i) -> int {
        if (i <= 1) {
            return 1;
        }
        auto it = memo.find(i);
        if (it != memo.end()) {
            return it->second;
        }
        return memo[i] = f(i - 1) + f(i - 2);
    };
    return f(n);
}

int main() {
    cout << formasEscada(10) << endl;  // 89
}
```

## Bottom-up: tabela iterativa

Preencha a tabela dos casos menores para os maiores. Não há recursão, e muitas vezes dá para guardar só as últimas posições:

<CodeTabs>

```python
def formas_escada_iter(n):
    anterior, atual = 1, 1     # f(0), f(1)
    for _ in range(2, n + 1):
        anterior, atual = atual, anterior + atual
    return atual

print(formas_escada_iter(10))  # 89
```

```javascript
function formasEscadaIter(n) {
  let anterior = 1, atual = 1;     // f(0), f(1)
  for (let i = 2; i <= n; i++) {
    [anterior, atual] = [atual, anterior + atual];
  }
  return atual;
}

console.log(formasEscadaIter(10));  // 89
```


```java
static int formasEscadaIter(int n) {
```

| Abordagem | Vantagem | Desvantagem |
| --- | --- | --- |
| Top-down | Mais fácil de derivar da recursão; só calcula estados alcançados | Usa pilha de chamadas; pode estourar o limite de recursão |
| Bottom-up | Sem recursão; permite reduzir o espaço | Exige pensar na ordem de preenchimento |

## Como achar o estado

O passo difícil é definir **o que um subproblema significa**. Um roteiro que funciona:

1. Resolva por força bruta, recursivamente. Pergunte: qual decisão eu tomo agora?
2. Veja quais parâmetros mudam entre as chamadas. Eles são o **estado** (um índice, uma capacidade restante, duas posições em duas strings).
3. Escreva em português o que `dp[estado]` significa. Exemplo: "`dp[i]` é o maior valor que consigo roubando apenas as casas de 0 a i".
4. Escreva a transição e os casos base.
5. A complexidade é número de estados vezes o custo de cada transição.

<CodeTabs>

```python
def roubo_maximo(casas):
    # dp[i]: melhor valor usando as casas até i, sem duas vizinhas
    pegar_ate_ant, melhor = 0, 0
    for valor in casas:
        pegar_ate_ant, melhor = melhor, max(melhor, pegar_ate_ant + valor)
    return melhor

print(roubo_maximo([2, 7, 9, 3, 1]))  # 12
```

```javascript
function rouboMaximo(casas) {
  // dp[i]: melhor valor usando as casas até i, sem duas vizinhas

    [pegarAteAnt, melhor] = [melhor, Math.max(melhor, pegarAteAnt + valor)];
  }
  return melhor;
}
```

```go
import "fmt"

func rouboMaximo(casas []int) int {
	// dp[i]: melhor valor usando as casas até i, sem duas vizinhas
	pegarAteAnt, melhor := 0, 0
	for _, valor := range casas {
		novo := melhor
		if pegarAteAnt+valor > novo {
			novo = pegarAteAnt + valor
		}
		pegarAteAnt, melhor = melhor, novo
	}
	return melhor
}

func main() {
	fmt.Println(rouboMaximo([]int{2, 7, 9, 3, 1})) // 12
}
```

## Na entrevista

Comece pela recursão de força bruta e diga por que ela é exponencial. Depois mostre a sobreposição, adicione a memória e só então, se houver tempo, converta para bottom-up e reduza o espaço. Esse caminho mostra o raciocínio completo, que é o que o entrevistador quer avaliar.
