Uma **árvore binária** é formada por nós em que cada um tem no máximo dois filhos, esquerdo e direito. O nó sem pai é a raiz; nós sem filhos são folhas. A **altura** é o número de níveis do caminho mais longo da raiz até uma folha.

## Pensar recursivamente

Toda árvore é uma raiz mais duas subárvores, que também são árvores. Por isso a maioria das soluções segue a mesma receita: resolva para a subárvore esquerda, resolva para a direita e combine os resultados no nó atual.

Existem dois estilos de recursão em árvores. No primeiro, cada chamada **devolve** um valor que o pai combina, como a altura abaixo. No segundo, você **passa informação para baixo** como parâmetro, por exemplo a soma acumulada do caminho ou os limites que um valor precisa respeitar. Muitos problemas ficam simples quando você identifica qual dos dois estilos o enunciado pede.

```python
class No:
    def __init__(self, val, esq=None, dir=None):
        self.val = val
        self.esq = esq
        self.dir = dir

def altura(no):
    if no is None:          # caso base: árvore vazia
        return 0
    return 1 + max(altura(no.esq), altura(no.dir))

raiz = No(1, No(2, No(4), No(5)), No(3))
print(altura(raiz))  # 3
```

<Callout type="tip" title="Confie na recursão">
Ao escrever a função, assuma que a chamada nas subárvores já devolve a resposta certa. Sua única tarefa é definir o caso base e como combinar os dois resultados no nó atual.
</Callout>

## Percursos em profundidade (DFS)

Os três percursos diferem apenas no momento em que o nó atual é processado:

| Percurso | Ordem | Uso típico |
| --- | --- | --- |
| Pré-ordem | nó, esquerda, direita | Copiar ou serializar a árvore |
| Em ordem | esquerda, nó, direita | Em uma árvore de busca, sai em ordem crescente |
| Pós-ordem | esquerda, direita, nó | Calcular algo que depende dos filhos (altura, tamanho) |

```python
def em_ordem(no, out):
    if no:
        em_ordem(no.esq, out)
        out.append(no.val)
        em_ordem(no.dir, out)
    return out

print(em_ordem(raiz, []))  # [4, 2, 5, 1, 3]
```

## Percurso em largura (BFS)

Para processar a árvore **nível a nível**, use uma fila. O truque é medir o tamanho da fila no início de cada nível para saber quantos nós pertencem a ele.

```python
from collections import deque

def niveis(raiz):
    if not raiz:
        return []
    resultado, fila = [], deque([raiz])
    while fila:
        nivel = []
        for _ in range(len(fila)):
            no = fila.popleft()
            nivel.append(no.val)
            if no.esq:
                fila.append(no.esq)
            if no.dir:
                fila.append(no.dir)
        resultado.append(nivel)
    return resultado

print(niveis(raiz))  # [[1], [2, 3], [4, 5]]
```

BFS é a escolha natural para "menor profundidade", "visão lateral" e qualquer pergunta que mencione níveis.

## Na entrevista

Diga a complexidade em função de n (número de nós) e h (altura): os percursos visitam cada nó uma vez, O(n) de tempo, e a recursão usa O(h) de pilha. Lembre que h vai de log n, numa árvore balanceada, até n, numa árvore degenerada que parece uma lista. Mencionar esse pior caso mostra que você entende o custo real da recursão.
