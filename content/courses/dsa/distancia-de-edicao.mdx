Dadas duas palavras `word1` e `word2`, retorne o menor número de operações para transformar `word1` em `word2`. Cada operação é uma destas, aplicada a um único caractere:

- inserir um caractere;
- remover um caractere;
- substituir um caractere por outro.

Esse número é conhecido como distância de Levenshtein.

## Exemplo

```text
Entrada: word1 = "sol", word2 = "solar"
Saída: 2
Explicação: insira "a" e depois "r" no final.
```

## Restrições

- 0 ≤ tamanho de cada palavra ≤ 500
- Só letras minúsculas.

## Dica

`dp[i][j]` é a distância entre os prefixos de tamanho `i` e `j`. Se os últimos caracteres coincidem, não custa nada; se não, some 1 ao melhor entre as três operações, cada uma correspondendo a uma célula vizinha da tabela. A linha 0 e a coluna 0 são os casos com prefixo vazio.
