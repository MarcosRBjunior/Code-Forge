Implemente um cache com capacidade fixa e política **LRU** (*least recently used*): quando não há espaço, sai o item que está há mais tempo sem ser usado. A classe `LRUCache(capacity)` tem:

- `get(key)`: retorna o valor da chave, ou `-1` se ela não estiver no cache. Uma leitura bem-sucedida conta como uso.
- `put(key, value)`: grava ou atualiza a chave, o que também conta como uso. Se a inserção fizer o cache passar de `capacity` itens, remova o menos recentemente usado.

As duas operações devem rodar em O(1) médio. Cada teste é uma sequência de chamadas, começando pelo construtor.

## Exemplo

```text
Operações: LRUCache(2), put(1, 1), put(2, 2), get(1), put(3, 3), get(2), put(4, 4), get(1), get(3), get(4)
Saída:     null,        null,      null,      1,      null,      -1,     null,      -1,     3,      4
Explicação: get(1) torna a chave 1 recente, então put(3, 3) expulsa a 2; depois put(4, 4) expulsa a 1.
```

## Restrições

- 1 ≤ `capacity` ≤ 3000
- 0 ≤ `key` ≤ 10⁴ e 0 ≤ `value` ≤ 10⁵
- No máximo 2 × 10⁵ chamadas.

## Dica

Um hash encontra a chave em O(1); falta manter a ordem de uso. Uma lista duplamente ligada permite mover um nó para o fim e retirar o do início em O(1), desde que o hash aponte direto para o nó.
