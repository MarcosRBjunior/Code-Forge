Cada elemento de `intervals` é um par `[inicio, fim]`. Junte todos os intervalos que se sobrepõem e retorne a lista resultante, sem sobreposições, **ordenada pelo início**. Intervalos que apenas se tocam, como `[1, 4]` e `[4, 5]`, também devem ser mesclados.

## Exemplo

```text
Entrada: intervals = [[1, 3], [2, 6], [8, 10], [15, 18]]
Saída: [[1, 6], [8, 10], [15, 18]]
Explicação: [1, 3] e [2, 6] se sobrepõem e viram [1, 6].
```

## Restrições

- 1 ≤ tamanho de `intervals` ≤ 10⁴
- 0 ≤ `inicio` ≤ `fim` ≤ 10⁴
- A entrada pode vir fora de ordem.

## Dica

Se os intervalos estiverem ordenados pelo início, basta comparar cada um com o último intervalo já mesclado.
