Dada uma string `s`, retorne o tamanho da maior **subsequência** de `s` que seja um palíndromo, isto é, que se leia igual nos dois sentidos. A subsequência não precisa ser contígua: basta manter a ordem original dos caracteres escolhidos.

## Exemplo

```text
Entrada: s = "character"
Saída: 5
Explicação: "carac" é subsequência de "character" e é palíndromo.
```

## Restrições

- 1 ≤ tamanho de `s` ≤ 1000
- Só letras minúsculas.

## Dica

Trabalhe com intervalos `dp[i][j]`, o melhor dentro de `s[i..j]`. Se as pontas são iguais, elas entram as duas e você olha para dentro; se não, descarte uma das pontas. Preencha dos intervalos curtos para os longos.
