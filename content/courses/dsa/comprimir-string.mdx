Comprima uma string `s` trocando cada sequência de caracteres iguais consecutivos pelo caractere seguido do tamanho da sequência. Sequências de tamanho 1 ficam só com o caractere, sem o número. Contagens com mais de um dígito são escritas por extenso (`"a12"`).

Se a versão comprimida **não ficar estritamente menor** que a original, retorne `s` sem alteração.

## Exemplo

```text
Entrada: s = "aabcccccaaa"
Saída: "a2bc5a3"

Entrada: s = "aabb"
Saída: "aabb"
Explicação: "a2b2" tem o mesmo tamanho que a original.
```

## Restrições

- `0 <= s.length <= 2000`
- `s` tem apenas letras.

## Dica

Percorra a string com dois índices: um marca o início da sequência atual e o outro avança enquanto o caractere for o mesmo. Monte o resultado numa lista e junte no final, para não concatenar strings em laço.
