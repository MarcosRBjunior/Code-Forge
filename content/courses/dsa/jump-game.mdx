Você começa no índice `0` do array `nums`. Cada valor `nums[i]` é o **tamanho máximo** do salto que dá para fazer a partir da posição `i` (você pode saltar menos). Retorne verdadeiro se for possível alcançar o último índice.

## Exemplo

```text
Entrada: nums = [3, 2, 1, 0, 4]
Saída: false
Explicação: todo caminho termina no índice 3, onde o salto máximo é 0.
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 10⁴
- 0 ≤ `nums[i]` ≤ 10⁵

## Dica

Não é preciso testar cada caminho. Ao percorrer o array, acompanhe o índice mais distante alcançável até agora.
