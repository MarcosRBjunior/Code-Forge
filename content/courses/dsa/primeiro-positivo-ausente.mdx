Dado um array de inteiros `nums`, sem ordem definida e possivelmente com negativos, zeros e repetições, encontre o **menor inteiro positivo** que não aparece nele.

O desafio está nas restrições de recurso: O(n) de tempo e O(1) de memória extra. Ordenar custa O(n log n), e um conjunto auxiliar custa O(n) de memória. Você pode modificar o próprio `nums`.

## Exemplo

```text
Entrada: nums = [3, 4, -1, 1]
Saída: 2
Explicação: 1 está presente, 2 não.
```

## Restrições

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`

## Dica

Num array de tamanho `n`, a resposta está sempre entre `1` e `n + 1`. Que tal usar as próprias posições do array como marcadores, tentando colocar cada valor `v` na posição `v - 1`?
