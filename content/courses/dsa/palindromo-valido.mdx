Uma frase é um **palíndromo** quando, depois de converter todas as letras para minúsculas e remover tudo que não for letra ou dígito, ela é lida da mesma forma nos dois sentidos. Dada a string `s`, retorne verdadeiro se ela for um palíndromo.

## Exemplo

```text
Entrada: s = "A man, a plan, a canal: Panama"
Saída: true
Explicação: depois da limpeza fica "amanaplanacanalpanama".
```

## Restrições

- 1 ≤ tamanho de `s` ≤ 2 × 10⁵
- `s` contém apenas caracteres ASCII imprimíveis.

## Dica

Dá para resolver sem criar uma string nova: dois ponteiros, um em cada ponta, pulando os caracteres que devem ser ignorados.
