Dadas duas strings `text1` e `text2`, retorne o tamanho da maior **subsequência comum** entre elas. Uma subsequência é o que sobra de uma string depois de apagar zero ou mais caracteres sem mudar a ordem dos restantes. Se não houver nada em comum, retorne `0`.

## Exemplo

```text
Entrada: text1 = "programar", text2 = "pomar"
Saída: 5
Explicação: "pomar" inteira aparece em "programar" como subsequência: p-o-m-a-r.
```

## Restrições

- 1 ≤ tamanho de cada string ≤ 1000
- Só letras minúsculas.

## Dica

Monte a tabela `dp[i][j]` para os prefixos `text1[:i]` e `text2[:j]`. Se os últimos caracteres forem iguais, eles entram juntos na resposta; se não, descarte o último de uma das strings e fique com o melhor dos dois casos.
