Imagine uma lista de temperaturas diárias. Para cada dia, quantos dias você precisa esperar até um dia mais quente? A força bruta olha para frente a partir de cada dia: O(n²). Uma **pilha monotônica** resolve em O(n), e o mesmo molde serve para uma família inteira de problemas do tipo "**próximo maior**" ou "**próximo menor**".

## O que é

É uma pilha comum com uma regra extra: os elementos dentro dela ficam sempre em ordem (crescente ou decrescente). Antes de empilhar um novo elemento, você **desempilha todos que quebrariam a ordem**. O ponto-chave é que o momento em que um elemento é desempilhado é exatamente o momento em que você descobre a resposta dele.

Para "próximo maior", mantenha a pilha **decrescente**. Quando chega um valor maior que o topo, esse valor é o próximo maior do topo. Desempilhe, registre a resposta e repita.

```python
def dias_ate_esquentar(temps):
    resposta = [0] * len(temps)
    pilha = []  # índices de dias ainda sem resposta, temperaturas decrescentes
    for i, t in enumerate(temps):
        while pilha and temps[pilha[-1]] < t:
            j = pilha.pop()
            resposta[j] = i - j
        pilha.append(i)
    return resposta

print(dias_ate_esquentar([22, 24, 21, 19, 23, 26, 20]))
# [1, 4, 2, 1, 1, 0, 0]
```

Guardar **índices** em vez de valores é quase sempre a escolha certa: com o índice você recupera o valor e ainda calcula distâncias.

## Por que é O(n)

O `while` dentro do `for` assusta, mas cada índice entra na pilha uma vez e sai no máximo uma vez. No total são no máximo 2n operações de pilha, então o tempo é **O(n) amortizado**. O espaço é O(n) no pior caso (um array estritamente decrescente nunca desempilha nada).

## As quatro variações

| Pergunta | Ordem da pilha | Desempilha quando |
| --- | --- | --- |
| Próximo maior à direita | decrescente | `atual > topo` |
| Próximo menor à direita | crescente | `atual < topo` |
| Anterior maior à esquerda | decrescente | o topo após desempilhar é a resposta |
| Anterior menor à esquerda | crescente | o topo após desempilhar é a resposta |

Para as versões "à esquerda", a resposta de um elemento é o que sobra no topo **depois** de você limpar a pilha e **antes** de empilhá-lo.

```python
def anterior_menor(nums):
    resposta = []
    pilha = []
    for x in nums:
        while pilha and pilha[-1] >= x:
            pilha.pop()
        resposta.append(pilha[-1] if pilha else -1)
        pilha.append(x)
    return resposta

print(anterior_menor([4, 2, 5, 3, 6]))  # [-1, -1, 2, 2, 3]
```

## Um uso mais avançado

No problema do **maior retângulo num histograma**, cada barra precisa saber até onde pode se estender para a esquerda e para a direita sem encontrar uma barra mais baixa. Isso é exatamente "anterior menor" e "próximo menor" ao mesmo tempo, resolvidos com uma pilha crescente em uma única passada. Quando você entender o molde, esse problema "difícil" vira uma aplicação direta.

<Callout type="tip" title="Quando reconhecer">
Frases como "próximo elemento maior", "quantos dias até", "primeiro à esquerda que é menor", "quanto cada barra se estende" ou qualquer pergunta em que cada elemento procura o primeiro vizinho que o supera ou fica abaixo dele.
</Callout>

## Armadilhas

- **Estrito ou não estrito:** `<` contra `<=` muda como valores iguais são tratados. Decida conscientemente e teste com repetidos.
- **Elementos que sobram:** ao final, quem ficou na pilha não tem resposta. Inicialize o array com o valor padrão (0 ou -1).
- **Array circular:** percorra os índices de 0 a 2n − 1 usando `i % n`, para que os elementos do fim enxerguem os do começo.
