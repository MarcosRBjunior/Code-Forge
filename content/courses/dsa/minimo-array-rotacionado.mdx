O array `nums` era crescente, com valores distintos, e foi rotacionado entre 0 e `n - 1` posições (o começo foi parar no fim). Retorne o **menor** elemento em O(log n).

## Exemplo

```text
Entrada: nums = [3, 4, 5, 1, 2]
Saída: 1
Explicação: o array original era [1, 2, 3, 4, 5], rotacionado 3 vezes.
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 5000
- Todos os valores são distintos.

## Dica

Compare o elemento do meio com o último. Se o meio for maior, o "degrau" onde está o mínimo fica à direita; caso contrário, o mínimo é o meio ou está à esquerda dele.
