Dado um array de inteiros `nums`, construa um array `answer` do mesmo tamanho em que `answer[i]` é o produto de todos os elementos de `nums` **exceto** `nums[i]`.

Resolva em O(n) e **sem usar divisão**. A divisão parece um atalho (multiplicar tudo e dividir por cada elemento), mas quebra quando há zeros no array.

## Exemplo

```text
Entrada: nums = [1, 2, 3, 4]
Saída: [24, 12, 8, 6]
Explicação: answer[1] = 1 * 3 * 4 = 12
```

## Restrições

- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- Todo produto parcial cabe num inteiro de 32 bits.

## Dica

O produto de "todos menos `i`" é o produto de tudo que está à esquerda de `i` vezes o produto de tudo que está à direita. Dá para calcular os dois numa passada de ida e outra de volta.
