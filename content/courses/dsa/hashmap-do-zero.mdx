Construa uma tabela hash **sem** usar o dicionário pronto da linguagem (`dict` em Python, `Map` ou objeto em JavaScript). A classe `MyHashMap` tem:

- `put(key, value)`: grava o par; se a chave já existe, atualiza o valor.
- `get(key)`: retorna o valor da chave, ou `-1` se ela não estiver lá.
- `remove(key)`: apaga a chave, se existir.

O objetivo é praticar a mecânica por baixo: função de hash, baldes e tratamento de colisões. Cada teste é uma sequência de chamadas, começando pelo construtor.

## Exemplo

```text
Operações: MyHashMap(), put(1, 1), put(2, 2), get(1), get(3), put(2, 1), get(2), remove(2), get(2)
Saída:     null,        null,      null,      1,      -1,     null,      1,      null,      -1
```

## Restrições

- 0 ≤ `key`, `value` ≤ 10⁶
- No máximo 10⁴ chamadas.

## Dica

Um array de tamanho fixo (de preferência primo) indexado por `key % tamanho` resolve o endereçamento. Duas chaves no mesmo índice precisam conviver: guarde uma pequena lista de pares em cada posição.
