Você recebe a raiz `root` de uma árvore de busca binária e um valor `val` que ainda não existe nela. Insira `val` na árvore e retorne a raiz (que muda apenas se a árvore estava vazia).

Existem várias formas válidas de inserir, mas aqui use a padrão: desça a partir da raiz indo para a esquerda quando `val` for menor que o nó e para a direita quando for maior, e pendure o novo nó na primeira posição vazia encontrada. Assim a resposta é única.

## Exemplo

```text
Entrada: root = [4, 2, 7, 1, 3], val = 5
        4                 4
       / \               / \
      2   7     =>      2   7
     / \               / \  /
    1   3             1  3 5
Saída: [4, 2, 7, 1, 3, 5]
```

## Restrições

- 0 ≤ número de nós ≤ 10.000
- Os valores são distintos e `val` não está na árvore.

## Dica

É uma busca na BST que, em vez de terminar em "não encontrei", termina criando um `TreeNode`. Dá para escrever de forma recursiva (devolvendo a subárvore atualizada) ou com um laço que guarda o pai.
