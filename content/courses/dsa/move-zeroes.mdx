Dado um array `nums`, mova todos os `0` para o final **mantendo a ordem relativa** dos elementos diferentes de zero.

A modificação deve ser feita **in-place**, sem criar outro array. A função não precisa retornar nada: os testes verificam o próprio `nums`.

## Exemplo

```text
Entrada: nums = [0, 1, 0, 3, 12]
Depois:  nums = [1, 3, 12, 0, 0]
```

## Dica

Use a variação de leitura e escrita: um ponteiro `escrita` indica onde colocar o próximo número diferente de zero.
