Pegue um inteiro positivo e troque-o pela soma dos quadrados dos seus dígitos. Repita o processo. Se em algum momento a sequência chegar a `1`, o número inicial é chamado de **feliz**. Caso contrário, a sequência entra num ciclo que nunca passa por `1`.

Escreva uma função que receba `n` e diga se ele é feliz.

## Exemplo

```text
Entrada: n = 19
Saída: true
Explicação:
1² + 9² = 82
8² + 2² = 68
6² + 8² = 100
1² + 0² + 0² = 1
```

## Restrições

- `1 <= n <= 2^31 - 1`

## Dica

O processo é uma sequência em que cada valor determina o próximo. Como você detectaria que ela voltou a um valor já visto? Dá para fazer com um conjunto ou com dois ponteiros, um lento e um rápido.
