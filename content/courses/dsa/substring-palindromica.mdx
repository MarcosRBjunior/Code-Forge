Dada uma string `s`, retorne a maior **substring** (trecho contíguo) que seja um palíndromo, ou seja, que se lê igual de trás para frente.

Se houver mais de uma substring com o tamanho máximo, retorne a que **começa primeiro** em `s`.

## Exemplo

```text
Entrada: s = "babad"
Saída: "bab"
Explicação: "aba" também tem tamanho 3, mas começa depois.

Entrada: s = "cbbd"
Saída: "bb"
```

## Restrições

- `1 <= s.length <= 1000`
- `s` tem apenas letras e dígitos.

## Dica

Todo palíndromo tem um centro, que pode ser um caractere (tamanho ímpar) ou o espaço entre dois caracteres (tamanho par). Expanda a partir de cada um dos `2n - 1` centros possíveis.
