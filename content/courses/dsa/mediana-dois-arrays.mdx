Você recebe dois arrays `nums1` e `nums2`, cada um em ordem crescente. Retorne a **mediana** do conjunto formado por todos os elementos dos dois: o elemento central se o total for ímpar, ou a média dos dois centrais se for par (o resultado pode ter `.5`).

O objetivo é O(log(m + n)), sem juntar os arrays.

## Exemplo

```text
Entrada: nums1 = [1, 2], nums2 = [3, 4]
Saída: 2.5
Explicação: a união ordenada é [1, 2, 3, 4]; (2 + 3) / 2 = 2.5
```

## Restrições

- 0 ≤ tamanho de `nums1`, `nums2` ≤ 1000, com pelo menos um elemento no total.
- -10⁶ ≤ valores ≤ 10⁶

## Dica

Procure um corte em cada array de modo que a metade esquerda total tenha o tamanho certo e todo elemento à esquerda seja menor ou igual a todo elemento à direita. Faça a busca binária no corte do array menor.
