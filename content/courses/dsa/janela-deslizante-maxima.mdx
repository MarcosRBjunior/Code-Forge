Uma janela de tamanho `k` desliza sobre `nums`, da esquerda para a direita, uma posição por vez. Em cada posição, ela cobre exatamente `k` elementos consecutivos. Retorne a lista com o **maior** elemento de cada janela, na ordem em que elas aparecem.

O objetivo é O(n) no total, e não O(n × k).

## Exemplo

```text
Entrada: nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
Saída: [3, 3, 5, 5, 6, 7]
Explicação: as janelas são [1 3 -1], [3 -1 -3], [-1 -3 5], [-3 5 3], [5 3 6], [3 6 7].
```

## Restrições

- 1 ≤ `k` ≤ tamanho de `nums` ≤ 10⁵
- -10⁴ ≤ `nums[i]` ≤ 10⁴

## Dica

Um elemento que tem à sua direita, dentro da janela, alguém maior nunca mais será o máximo. Guarde num deque só os índices candidatos, com valores decrescentes da frente para o fundo.
