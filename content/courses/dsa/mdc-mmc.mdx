Três ferramentas resolvem uma família inteira de problemas sobre divisibilidade: o **MDC** (máximo divisor comum), o **MMC** (mínimo múltiplo comum) e a **aritmética modular**, que mantém números gigantes sob controle.

## MDC pelo algoritmo de Euclides

A observação central: qualquer divisor de a e b também divide a − b, e portanto divide `a % b`. Então mdc(a, b) = mdc(b, a % b), e quando o segundo número chega a zero, o primeiro é a resposta.

```python
def mdc(a, b):
    while b:
        a, b = b, a % b
    return a

print(mdc(84, 36))   # 12
print(mdc(17, 5))    # 1: são coprimos
```

```text
mdc(84, 36) -> mdc(36, 12) -> mdc(12, 0) -> 12
```

Cada dois passos, o maior número cai pelo menos pela metade, então o tempo é **O(log(min(a, b)))** e o espaço O(1). Em Python, `math.gcd` já faz isso, mas saiba escrever a versão manual.

## MMC a partir do MDC

Como a · b = mdc(a, b) · mmc(a, b), o MMC sai de graça:

```python
from math import gcd

def mmc(a, b):
    return a // gcd(a, b) * b     # divide antes para evitar números grandes

def mmc_lista(nums):
    resultado = 1
    for x in nums:
        resultado = mmc(resultado, x)
    return resultado

print(mmc(4, 6), mmc_lista([2, 3, 4, 5]))   # 12 60
```

Dividir **antes** de multiplicar importa em linguagens com inteiros de tamanho fixo.

### Onde aparece

- **Reduzir frações** ou proporções: divida numerador e denominador pelo MDC. Útil para representar inclinações de retas como pares inteiros normalizados.
- **Ciclos que se sincronizam:** dois eventos com períodos 4 e 6 coincidem a cada mmc(4, 6) = 12 unidades.
- **MDC de uma lista:** aplique em sequência. Se o MDC de todos os tamanhos de grupos for maior que 1, dá para dividir tudo em grupos iguais.
- **Rotação de array** por k posições forma mdc(n, k) ciclos independentes.

## Aritmética modular

Quando o enunciado diz "devolva a resposta módulo 10^9 + 7", a resposta real é grande demais e você deve reduzir **durante** o cálculo, não só no final. As regras que valem:

| Operação | Pode aplicar módulo a cada passo? |
| --- | --- |
| Soma | Sim: (a + b) % m = ((a % m) + (b % m)) % m |
| Multiplicação | Sim: (a · b) % m = ((a % m) · (b % m)) % m |
| Subtração | Sim, mas some m antes para não ficar negativo em Java/C++ |
| Divisão | Não diretamente; use o inverso modular |

```python
MOD = 10**9 + 7

def fatorial_mod(n):
    r = 1
    for i in range(2, n + 1):
        r = r * i % MOD
    return r

def inverso(a):
    return pow(a, MOD - 2, MOD)     # vale porque MOD é primo (Fermat)

def comb_mod(n, k):
    num = fatorial_mod(n)
    den = fatorial_mod(k) * fatorial_mod(n - k) % MOD
    return num * inverso(den) % MOD

print(fatorial_mod(20), comb_mod(10, 3))   # 146326063 120
```

O `pow(a, e, m)` do Python faz exponenciação rápida modular em O(log e).

<Callout type="note" title="Por que 10^9 + 7">
É primo (o que garante inverso para todo número não divisível por ele) e cabe em 32 bits; o produto de dois valores reduzidos cabe em 64 bits. Por isso virou padrão.
</Callout>

## Quando reconhecer

- "Maior divisor", "dividir em partes iguais", "reduzir a fração", "pontos na mesma reta": MDC.
- "Quando dois ciclos se encontram de novo", "menor número divisível por todos": MMC.
- "Resposta módulo um número grande", contagens combinatórias, DP de contagem: aritmética modular.
