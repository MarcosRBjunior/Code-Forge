Você tem moedas dos valores em `coins`, em quantidade ilimitada. Retorne o **menor número de moedas** cuja soma é exatamente `amount`. Se não houver combinação possível, retorne `-1`.

## Exemplo

```text
Entrada: coins = [1, 2, 5], amount = 11
Saída: 3
Explicação: 5 + 5 + 1.
```

## Restrições

- 1 ≤ tamanho de `coins` ≤ 12
- 1 ≤ `coins[i]` ≤ 2³¹ - 1
- 0 ≤ `amount` ≤ 10⁴

## Dica

Pegar sempre a maior moeda falha em casos como `coins = [1, 3, 4]` e `amount = 6`. Calcule a resposta para cada valor de 0 até `amount`, reaproveitando os valores menores.
