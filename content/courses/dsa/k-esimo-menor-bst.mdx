Dada a raiz `root` de uma árvore de busca binária e um inteiro `k`, retorne o `k`-ésimo menor valor entre todos os nós da árvore, contando a partir de 1 (o menor de todos é o 1º).

`k` é sempre válido, ou seja, está entre 1 e o número de nós.

## Exemplo

```text
Entrada: root = [5, 3, 6, 2, 4, null, null, 1], k = 3
          5
         / \
        3   6
       / \
      2   4
     /
    1
Saída: 3
Explicação: em ordem crescente os valores são 1, 2, 3, 4, 5, 6.
```

## Restrições

- 1 ≤ `k` ≤ número de nós ≤ 10.000
- 0 ≤ `val` ≤ 10.000

## Dica

Que percurso visita os nós de uma BST em ordem crescente? Faça esse percurso e pare assim que tiver contado `k` nós, sem precisar visitar o resto da árvore.
