Um array crescente de valores **distintos** foi rotacionado em algum ponto desconhecido: um prefixo dele foi movido para o final. Por exemplo, `[0, 1, 2, 4, 5, 6, 7]` pode ter virado `[4, 5, 6, 7, 0, 1, 2]`.

Dado o array rotacionado `nums` e um valor `target`, retorne o índice de `target` ou `-1` se ele não estiver presente. A solução deve rodar em O(log n).

## Exemplo

```text
Entrada: nums = [4, 5, 6, 7, 0, 1, 2], target = 0
Saída: 4
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 5000
- Todos os valores de `nums` são distintos.

## Dica

Ao dividir no meio, pelo menos uma das metades está em ordem crescente. Descubra qual é e verifique se `target` cabe no intervalo dela.
