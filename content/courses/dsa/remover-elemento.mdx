Dado um array `nums` e um valor `val`, remova **in-place** todas as ocorrências de `val`, mantendo a ordem relativa dos demais elementos.

Depois de compactar os elementos que ficam no início do array, descarte as posições que sobraram (em Python, `del nums[k:]`; em JavaScript, `nums.length = k`). A função não precisa retornar nada: os testes verificam o próprio `nums`. Não crie um segundo array, e não use `remove` ou `splice` em laço, que custam O(n) a cada chamada.

## Exemplo

```text
Entrada: nums = [0, 1, 2, 2, 3, 0, 4, 2], val = 2
Depois:  nums = [0, 1, 3, 0, 4]
```

## Restrições

- `0 <= nums.length <= 100`
- `0 <= nums[i], val <= 100`

## Dica

Use um ponteiro de leitura que percorre tudo e um ponteiro de escrita que só avança quando o elemento lido deve ficar.
