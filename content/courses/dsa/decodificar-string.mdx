Uma string foi compactada com a regra `k[trecho]`: o `trecho` entre colchetes deve aparecer repetido `k` vezes, onde `k` é um inteiro positivo (pode ter mais de um dígito). As regras podem estar **aninhadas**, como em `3[a2[c]]`. Letras fora de colchetes ficam como estão.

Retorne a string expandida. A entrada é sempre bem formada: dígitos só aparecem como contadores, e todo colchete aberto é fechado.

## Exemplo

```text
Entrada: s = "3[a2[c]]"
Saída: "accaccacc"
Explicação: 2[c] vira "cc"; "acc" repetido 3 vezes dá "accaccacc".
```

## Restrições

- 1 ≤ tamanho de `s` ≤ 30
- `s` contém letras minúsculas, dígitos e colchetes.
- A saída tem no máximo 10⁵ caracteres.

## Dica

Ao encontrar `[`, guarde numa pilha o texto montado até ali e o contador. Ao encontrar `]`, desempilhe e combine.
