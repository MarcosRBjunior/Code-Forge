title: Notação Big-O
kind: lesson
---

A notação Big-O descreve **como o custo de um algoritmo cresce** quando a entrada cresce. Ela ignora constantes e termos menores porque, para entradas grandes, o termo dominante é o que importa.

## As classes mais comuns

| Notação | Nome | Exemplo |
| --- | --- | --- |
| O(1) | Constante | Acessar `arr[i]` |
| O(log n) | Logarítmica | Busca binária |
| O(n) | Linear | Percorrer um array |
| O(n log n) | Linearítmica | Merge sort |
| O(n²) | Quadrática | Dois laços aninhados |
| O(2ⁿ) | Exponencial | Gerar todos os subconjuntos |

## Como calcular na prática

Conte quantas vezes a operação mais interna executa em função de `n`. Laços em sequência **somam**; laços aninhados **multiplicam**.

```python
def tem_duplicado(nums):
    for i in range(len(nums)):             # n vezes
        for j in range(i + 1, len(nums)):  # até n vezes
            if nums[i] == nums[j]:
                return True
    return False
```

Os dois laços aninhados fazem cerca de n²/2 comparações, então a complexidade é **O(n²)**. Constantes como o 1/2 são descartadas.

<Callout type="note" title="Espaço também conta">
Big-O vale para memória. Uma solução que cria um conjunto auxiliar com todos os elementos usa O(n) de espaço extra, mesmo que rode em O(n) de tempo.
</Callout>

## O que dizer na entrevista

Sempre declare tempo **e** espaço ao final da solução, e explique de onde vem cada termo. Dizer que "é O(n) porque cada elemento entra e sai do conjunto uma única vez" vale mais do que só dizer que é O(n).
