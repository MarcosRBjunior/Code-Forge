Dados dois inteiros `a` e `b`, retorne a soma deles **sem usar** os operadores `+` e `-` (nem `+=`, `-=`, `sum` ou truques equivalentes). Só operações de bits estão liberadas.

Os valores podem ser negativos. Considere que os números são inteiros de 32 bits em complemento de dois.

## Exemplo

```text
Entrada: a = 2, b = 3
Saída: 5

Entrada: a = -7, b = -8
Saída: -15
```

## Restrições

- `-1000 <= a, b <= 1000`
- Em Python os inteiros não têm tamanho fixo: use uma máscara de 32 bits (`0xFFFFFFFF`) e converta o resultado de volta para negativo quando o bit 31 estiver ligado.

## Dica

Na soma bit a bit, `a ^ b` é a soma sem o "vai um", e `(a & b) << 1` é exatamente o "vai um". Repita até não sobrar nada para carregar.
