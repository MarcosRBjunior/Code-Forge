Uma **raiz** é um pedaço de palavra que pode gerar palavras maiores: a raiz `gat` gera `gato`, `gata` e `gatinho`. Você recebe a lista `dictionary` de raízes e uma frase `sentence` com palavras separadas por um espaço.

Troque cada palavra da frase pela raiz do dicionário que seja prefixo dela. Se várias raízes servirem, use a **mais curta**. Palavras sem nenhuma raiz ficam como estão. Uma palavra que é igual a uma raiz também conta (ela é prefixo de si mesma). Retorne a frase resultante.

## Exemplo

```text
Entrada: dictionary = ["gat", "rat", "mor"], sentence = "o gato roeu a rata morta"
Saída: "o gat roeu a rat mor"
```

## Restrições

- 0 ≤ tamanho de `dictionary` ≤ 1000
- 1 ≤ tamanho de `sentence` ≤ 10⁶, só letras minúsculas e espaços simples.

## Dica

Coloque as raízes numa trie. Para cada palavra da frase, ande pela trie letra a letra e pare no primeiro nó que marca o fim de uma raiz.
