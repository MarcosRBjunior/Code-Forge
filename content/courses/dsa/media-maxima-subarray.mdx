Você recebe um array de inteiros `nums` e um inteiro `k`. Entre todos os trechos **contíguos** com exatamente `k` elementos, encontre aquele cuja média aritmética é a maior possível e retorne essa média.

Para evitar problemas de precisão, devolva o valor arredondado a 5 casas decimais (em Python, `round(x, 5)`; em JavaScript, `Math.round(x * 1e5) / 1e5`).

## Exemplo

```text
Entrada: nums = [1, 12, -5, -6, 50, 3], k = 4
Saída: 12.75
Explicação: o bloco [12, -5, -6, 50] soma 51; 51 / 4 = 12.75
```

## Restrições

- 1 ≤ `k` ≤ tamanho de `nums` ≤ 10⁵
- -10⁴ ≤ `nums[i]` ≤ 10⁴

## Dica

Como todos os blocos têm o mesmo tamanho, maximizar a média é o mesmo que maximizar a soma. Ao deslizar o bloco uma posição, o que entra e o que sai da soma?
