Dado um array de inteiros `nums`, retorne-o ordenado em ordem crescente **sem usar** as funções de ordenação prontas da linguagem (`sort`, `sorted`, `Array.prototype.sort`).

A solução deve rodar em O(n log n) mesmo no pior caso, então escolha bem o algoritmo: um quick sort com pivô fixo pode degradar em entradas já ordenadas ou cheias de repetições. Você pode retornar um array novo ou o próprio `nums` ordenado.

## Exemplo

```text
Entrada: nums = [5, 1, 1, 2, 0, 0]
Saída: [0, 0, 1, 1, 2, 5]
```

## Restrições

- `1 <= nums.length <= 5 * 10^4`
- `-5 * 10^4 <= nums[i] <= 5 * 10^4`

## Dica

Merge sort garante O(n log n) em qualquer entrada. Heap sort também, e sem memória extra. Como os valores estão num intervalo pequeno, counting sort é outra saída válida.
