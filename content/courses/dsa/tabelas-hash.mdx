Procurar um valor num array desordenado exige olhar elemento por elemento: O(n) por consulta. Se você faz essa busca dentro de um laço, o algoritmo vira O(n²). Uma tabela hash guarda pares chave → valor e permite **inserir, buscar e remover em O(1) no caso médio**. É a estrutura que mais aparece em soluções de entrevista porque troca memória por velocidade.

## Como funciona

Uma função de hash transforma a chave em um número, e esse número, reduzido pelo tamanho do array interno, vira um índice. Para buscar, você recalcula o índice e vai direto à posição, sem percorrer nada.

Quando duas chaves caem no mesmo índice ocorre uma **colisão**. Há duas soluções clássicas:

- **Encadeamento:** cada posição guarda uma lista de pares; a busca percorre só essa lista curta.
- **Endereçamento aberto:** se a posição está ocupada, procura-se a próxima livre seguindo uma regra (por exemplo, a posição seguinte).

O pior caso é O(n), quando todas as chaves colidem. Para evitar isso, implementações reais usam boas funções de hash e redimensionam o array quando o **fator de carga** (elementos divididos por posições) passa de um limite. O redimensionamento é caro, mas acontece raramente, então o custo amortizado de inserir continua O(1).

## O padrão "já vi isso antes?"

Muitos problemas se resumem a perguntar, para cada elemento, se algo relacionado a ele já apareceu. Em vez de procurar no array (O(n) por consulta), guarde o que já viu em um conjunto ou mapa (O(1) por consulta).

```python
def tem_duplicado(nums):
    vistos = set()
    for x in nums:
        if x in vistos:
            return True
        vistos.add(x)
    return False
```

## Contagem e complemento

Dois usos aparecem o tempo todo. O primeiro é **contar frequências**, útil para anagramas e para achar o elemento mais comum. O segundo é guardar o **complemento**: no clássico Two Sum, para cada número você pergunta se `alvo - x` já foi visto, e guarda o índice de cada valor num dicionário.

<CodeTabs>

```python
from collections import Counter

def dois_somam(nums, alvo):
    indice = {}
    for i, x in enumerate(nums):
        if alvo - x in indice:
            return [indice[alvo - x], i]
        indice[x] = i
    return []

print(dois_somam([2, 7, 11, 15], 9))              # [0, 1]
print(Counter("banana").most_common(1))           # [('a', 3)]
```

```javascript
function doisSomam(nums, alvo) {
  const indice = new Map();
  for (let i = 0; i < nums.length; i++) {
    if (indice.has(alvo - nums[i])) {
      return [indice.get(alvo - nums[i]), i];
    }
    indice.set(nums[i], i);
  }
  return [];
}

function maisComum(texto) {
  const contagem = new Map();
  for (const c of texto) {
    contagem.set(c, (contagem.get(c) ?? 0) + 1);
  }
  const melhor = [...contagem.entries()].reduce((a, b) => (b[1] > a[1] ? b : a));
  return [melhor];
}

console.log(doisSomam([2, 7, 11, 15], 9));  // [0, 1]
console.log(maisComum("banana"));           // [["a", 3]]
```

```java
import java.util.*;

static int[] doisSomam(int[] nums, int alvo) {
    Map<Integer, Integer> indice = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        if (indice.containsKey(alvo - nums[i])) {
            return new int[]{indice.get(alvo - nums[i]), i};
        }
        indice.put(nums[i], i);
    }
    return new int[]{};
}

public static void main(String[] args) {
    System.out.println(Arrays.toString(doisSomam(new int[]{2, 7, 11, 15}, 9)));  // [0, 1]

    Map<Character, Integer> contagem = new HashMap<>();
    for (char c : "banana".toCharArray()) {
        contagem.merge(c, 1, Integer::sum);
    }
    Map.Entry<Character, Integer> melhor = Collections.max(contagem.entrySet(), Map.Entry.comparingByValue());
    System.out.println("[(" + melhor.getKey() + ", " + melhor.getValue() + ")]");  // [(a, 3)]
}
```

```cpp
#include <iostream>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

vector<int> doisSomam(const vector<int>& nums, int alvo) {
    unordered_map<int, int> indice;
    for (int i = 0; i < (int)nums.size(); i++) {
        auto it = indice.find(alvo - nums[i]);
        if (it != indice.end()) {
            return {it->second, i};
        }
        indice[nums[i]] = i;
    }
    return {};
}

int main() {
    vector<int> r = doisSomam({2, 7, 11, 15}, 9);
    cout << "[" << r[0] << ", " << r[1] << "]" << endl;  // [0, 1]

    unordered_map<char, int> contagem;
    for (char c : string("banana")) {
        contagem[c]++;
    }
    char melhor = 0;
    int maior = 0;
    for (const auto& [c, n] : contagem) {
        if (n > maior) {
            melhor = c;
            maior = n;
        }
    }
    cout << "[(" << melhor << ", " << maior << ")]" << endl;  // [(a, 3)]
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

static int[] DoisSomam(int[] nums, int alvo)
{
    var indice = new Dictionary<int, int>();
    for (int i = 0; i < nums.Length; i++)
    {
        if (indice.TryGetValue(alvo - nums[i], out int j))
        {
            return new[] { j, i };
        }
        indice[nums[i]] = i;
    }
    return new int[0];
}

static void Main()
{
    Console.WriteLine("[" + string.Join(", ", DoisSomam(new[] { 2, 7, 11, 15 }, 9)) + "]");  // [0, 1]

    var contagem = "banana".GroupBy(c => c).OrderByDescending(g => g.Count()).First();
    Console.WriteLine($"[({contagem.Key}, {contagem.Count()})]");  // [(a, 3)]
}
```

```go
import "fmt"

func doisSomam(nums []int, alvo int) []int {
	indice := map[int]int{}
	for i, x := range nums {
		if j, ok := indice[alvo-x]; ok {
			return []int{j, i}
		}
		indice[x] = i
	}
	return []int{}
}

func main() {
	fmt.Println(doisSomam([]int{2, 7, 11, 15}, 9)) // [0 1]

	contagem := map[rune]int{}
	for _, c := range "banana" {
		contagem[c]++
	}
	var melhor rune
	maior := 0
	for c, n := range contagem {
		if n > maior {
			melhor, maior = c, n
		}
	}
	fmt.Printf("[(%c, %d)]\n", melhor, maior) // [(a, 3)]
}
```

<Callout type="warning" title="O(1) não é de graça">
O custo médio depende de uma boa função de hash e de chaves imutáveis. Em Python, listas não podem ser chaves; use tuplas. Alterar um objeto depois de usá-lo como chave quebra a busca.
</Callout>

## Armadilhas e trade-offs

- **Sem ordem útil:** a tabela não devolve chaves ordenadas nem permite consulta por intervalo. Para isso use uma árvore balanceada ou ordene.
- **Memória:** guardar n itens custa O(n) de espaço, com sobra para evitar colisões. Em dados muito grandes isso pesa.
- **Hash de strings longas:** calcular o hash custa o tamanho da chave, então "O(1)" assume chaves pequenas.
- **Ataques de colisão:** em sistemas expostos, entradas escolhidas para colidir degradam para O(n). Linguagens modernas mitigam com sementes aleatórias.
