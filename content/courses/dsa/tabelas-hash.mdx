Uma tabela hash guarda pares chave → valor e permite **inserir, buscar e remover em O(1) no caso médio**. É a estrutura que mais aparece em soluções de entrevista porque troca memória por velocidade.

## Como funciona

Uma função de hash transforma a chave em um índice de um array interno. Quando duas chaves caem no mesmo índice ocorre uma **colisão**, resolvida com listas encadeadas ou com endereçamento aberto.

O pior caso é O(n), quando todas as chaves colidem, mas implementações reais redimensionam o array e usam boas funções de hash para manter o caso médio constante.

## Em cada linguagem

| Linguagem | Mapa | Conjunto |
| --- | --- | --- |
| Python | `dict` | `set` |
| JavaScript | `Map` | `Set` |
| Java | `HashMap` | `HashSet` |

## O padrão "já vi isso antes?"

Muitos problemas se resumem a perguntar, para cada elemento, se algo relacionado a ele já apareceu. Em vez de procurar no array (O(n) por consulta), guarde o que já viu em um conjunto ou mapa (O(1) por consulta).

```python
def tem_duplicado(nums):
    vistos = set()
    for x in nums:
        if x in vistos:
            return True
        vistos.add(x)
    return False
```

Compare com a versão do capítulo anterior: de O(n²) para **O(n)** de tempo, pagando O(n) de espaço.
