Dada a cabeça `head` de uma lista ligada e um inteiro `n`, retire da lista o nó que ocupa a posição `n` contando de trás para frente (o último nó é o 1º do fim) e retorne a cabeça da lista resultante.

`n` é sempre válido. Se o nó removido for a própria cabeça, a nova cabeça passa a ser o segundo nó (ou nenhum, se a lista ficar vazia).

## Exemplo

```text
Entrada: 1 -> 2 -> 3 -> 4 -> 5, n = 2
Saída:   1 -> 2 -> 3 -> 5
Explicação: o 2º nó a partir do fim é o 4.
```

## Restrições

- 1 ≤ número de nós ≤ 30
- 1 ≤ `n` ≤ número de nós
- Tente resolver com uma única passada.

## Dica

Se um ponteiro começar `n` passos à frente de outro e os dois andarem juntos, onde estará o de trás quando o da frente chegar ao fim? Um nó sentinela antes da cabeça evita o caso especial de remover o primeiro nó.
