Você recebe as cabeças `l1` e `l2` de duas listas ligadas, cada uma já em ordem não decrescente. Junte as duas em uma só lista, também ordenada, reaproveitando os nós originais, e retorne a cabeça do resultado.

Qualquer uma das listas (ou as duas) pode estar vazia.

## Exemplo

```text
Entrada: l1 = 1 -> 2 -> 4, l2 = 1 -> 3 -> 4
Saída:   1 -> 1 -> 2 -> 3 -> 4 -> 4
```

## Restrições

- 0 ≤ número de nós em cada lista ≤ 50
- -100 ≤ `val` ≤ 100
- As duas listas já estão ordenadas.

## Dica

Um nó sentinela (um nó falso posicionado antes da cabeça) elimina o caso especial de decidir quem será a primeira cabeça. Depois disso, basta comparar a frente das duas listas a cada passo.
