Projete um armazenamento chave-valor que guarda o **histórico** de cada chave. A classe `TimeMap` tem:

- `set(key, value, timestamp)`: registra que `key` passou a valer `value` no instante `timestamp`.
- `get(key, timestamp)`: retorna o valor que `key` tinha no instante `timestamp`, ou seja, o valor gravado com o **maior** carimbo menor ou igual a `timestamp`. Se não houver nenhum, retorna a string vazia `""`.

Os carimbos passados a `set` são estritamente crescentes ao longo das chamadas. Cada teste é uma sequência de chamadas, começando pelo construtor.

## Exemplo

```text
Operações: TimeMap(), set("foo", "bar", 1), get("foo", 1), get("foo", 3), set("foo", "bar2", 4), get("foo", 4), get("foo", 5)
Saída:     null,      null,                 "bar",         "bar",         null,                  "bar2",        "bar2"
```

## Restrições

- 1 ≤ `timestamp` ≤ 10⁷
- Chaves e valores com até 100 caracteres.
- No máximo 2 × 10⁵ chamadas.

## Dica

Como os carimbos chegam em ordem, a lista de cada chave já fica ordenada sem esforço. Para responder `get`, você não precisa varrer a lista inteira.
