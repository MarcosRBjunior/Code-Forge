Dados dois inteiros `x` e `n`, com `n >= 0`, calcule `x` elevado a `n`. Como o resultado cresce muito rápido, devolva-o **módulo `1_000_000_007`**, sempre como um valor entre `0` e `1_000_000_006`. Por convenção, qualquer número elevado a 0 vale 1, inclusive o próprio `0`.

O expoente pode chegar a um bilhão, então multiplicar `x` por ele mesmo `n` vezes não é uma opção. Não use a função de potência pronta da linguagem: o objetivo é implementar a exponenciação.

## Exemplo

```text
Entrada: x = 2, n = 10
Saída: 1024

Entrada: x = -2, n = 3
Saída: 999999999
Explicação: (-2)^3 = -8, e -8 módulo 1_000_000_007 é 999999999.
```

## Restrições

- `-10^9 <= x <= 10^9`
- `0 <= n <= 10^9`
- Em JavaScript, o produto de dois números próximos de `10^9` passa de `2^53`: use `BigInt` nas multiplicações.

## Dica

Repare que `x^n = (x^(n/2))^2` quando `n` é par. Olhar os bits de `n` um a um leva a um algoritmo com O(log n) multiplicações.
