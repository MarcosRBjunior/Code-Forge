Você tem um array de números e precisa responder milhares de perguntas do tipo "qual a soma entre os índices 3 e 9?" enquanto os valores também mudam. A soma de prefixos responde a consulta em O(1), mas cada atualização obriga a refazer o prefixo inteiro, em O(n). Percorrer o intervalo a cada consulta deixa a atualização em O(1) e a consulta em O(n). A **segment tree** equilibra os dois lados: **O(log n) para consultar e O(log n) para atualizar**.

## Como funciona

É uma árvore binária em que cada nó guarda o resultado de um **segmento** do array. A raiz cobre o array todo, cada filho cobre metade do pai, e as folhas são os elementos individuais.

```text
nums = [5, 2, 8, 1, 4, 7]

                 [0..5] = 27
               /             \
        [0..2] = 15        [3..5] = 12
        /       \           /       \
   [0..1]=7   [2]=8    [3..4]=5    [5]=7
    /    \              /    \
 [0]=5  [1]=2        [3]=1  [4]=4
```

Para consultar `[1..3]`, você desce a partir da raiz com três casos possíveis:

- O segmento do nó está **fora** do intervalo: devolve o elemento neutro (0 para soma).
- Está **totalmente dentro**: devolve o valor guardado, sem descer mais.
- Está **parcialmente dentro**: pergunta aos dois filhos e combina.

Em cada nível, no máximo dois nós ficam no caso parcial, então a consulta visita O(log n) nós. A atualização desce até a folha e recalcula os ancestrais no caminho de volta, também em O(log n).

## Implementação

A forma mais comum em entrevista guarda a árvore num vetor, como num heap: o nó `no` tem filhos `2*no` e `2*no+1`. Um vetor de tamanho `4n` sempre basta.

```python
class SegmentTree:
    def __init__(self, nums):
        self.n = len(nums)
        self.arvore = [0] * (4 * self.n)
        if self.n:
            self._construir(1, 0, self.n - 1, nums)

    def _construir(self, no, ini, fim, nums):
        if ini == fim:
            self.arvore[no] = nums[ini]
            return
        meio = (ini + fim) // 2
        self._construir(2 * no, ini, meio, nums)
        self._construir(2 * no + 1, meio + 1, fim, nums)
        self.arvore[no] = self.arvore[2 * no] + self.arvore[2 * no + 1]

    def atualizar(self, i, valor, no=1, ini=0, fim=None):
        if fim is None:
            fim = self.n - 1
        if ini == fim:
            self.arvore[no] = valor
            return
        meio = (ini + fim) // 2
        if i <= meio:
            self.atualizar(i, valor, 2 * no, ini, meio)
        else:
            self.atualizar(i, valor, 2 * no + 1, meio + 1, fim)
        self.arvore[no] = self.arvore[2 * no] + self.arvore[2 * no + 1]

    def consultar(self, esq, dir, no=1, ini=0, fim=None):
        if fim is None:
            fim = self.n - 1
        if dir < ini or fim < esq:          # fora do intervalo
            return 0
        if esq <= ini and fim <= dir:       # totalmente dentro
            return self.arvore[no]
        meio = (ini + fim) // 2
        return (self.consultar(esq, dir, 2 * no, ini, meio)
                + self.consultar(esq, dir, 2 * no + 1, meio + 1, fim))

st = SegmentTree([5, 2, 8, 1, 4, 7])
print(st.consultar(1, 3))   # 2 + 8 + 1 = 11
st.atualizar(2, 3)
print(st.consultar(1, 3))   # 2 + 3 + 1 = 6
print(st.consultar(0, 5))   # 22
```

class SegmentTree {
  constructor(nums) {
    this.n = nums.length;
    this.arvore = new Array(4 * this.n).fill(0);
    if (this.n > 0) {
      this._construir(1, 0, this.n - 1, nums);
    }
  }

  _construir(no, ini, fim, nums) {
    if (ini === fim) {
      this.arvore[no] = nums[ini];
      return;
    }
    const meio = Math.floor((ini + fim) / 2);
    this._construir(2 * no, ini, meio, nums);
    this._construir(2 * no + 1, meio + 1, fim, nums);
    this.arvore[no] = this.arvore[2 * no] + this.arvore[2 * no + 1];
  }

  atualizar(i, valor, no = 1, ini = 0, fim = this.n - 1) {
    if (ini === fim) {
      this.arvore[no] = valor;
      return;
    }
    const meio = Math.floor((ini + fim) / 2);
    if (i <= meio) {
      this.atualizar(i, valor, 2 * no, ini, meio);
    } else {
      this.atualizar(i, valor, 2 * no + 1, meio + 1, fim);
    }
    this.arvore[no] = this.arvore[2 * no] + this.arvore[2 * no + 1];
  }

  consultar(esq, dir, no = 1, ini = 0, fim = this.n - 1) {
    if (dir < ini || fim < esq) {          // fora do intervalo
      return 0;
    }
    if (esq <= ini && fim <= dir) {        // totalmente dentro
      return this.arvore[no];
    }
    const meio = Math.floor((ini + fim) / 2);
    return this.consultar(esq, dir, 2 * no, ini, meio)
         + this.consultar(esq, dir, 2 * no + 1, meio + 1, fim);
  }
}

        if (n > 0) {
            construir(1, 0, n - 1, nums);
        }

        if (ini == fim) {
            arvore[no] = nums[ini];
            return;

        int meio = (ini + fim) / 2;
        construir(2 * no, ini, meio, nums);
        construir(2 * no + 1, meio + 1, fim, nums);

    }

    void atualizar(int i, int valor) {
        atualizar(i, valor, 1, 0, n - 1);
    }

class SegmentTree
{
    private readonly int n;
    private readonly int[] arvore;

    public SegmentTree(int[] nums)
    {
        n = nums.Length;
        arvore = new int[4 * Math.Max(n, 1)];
        if (n > 0)
        {
            Construir(1, 0, n - 1, nums);
        }
    }

    private void Construir(int no, int ini, int fim, int[] nums)
    {
        if (ini == fim)
        {
            arvore[no] = nums[ini];
            return;
        }
        int meio = (ini + fim) / 2;
        Construir(2 * no, ini, meio, nums);
        Construir(2 * no + 1, meio + 1, fim, nums);
        arvore[no] = arvore[2 * no] + arvore[2 * no + 1];
    }

    public void Atualizar(int i, int valor)
    {
        Atualizar(i, valor, 1, 0, n - 1);
    }

    private void Atualizar(int i, int valor, int no, int ini, int fim)
    {
        if (ini == fim)
        {
            arvore[no] = valor;
            return;

        if (i <= meio)

            Atualizar(i, valor, 2 * no, ini, meio);

        else

            Atualizar(i, valor, 2 * no + 1, meio + 1, fim);
        }
        arvore[no] = arvore[2 * no] + arvore[2 * no + 1];

import "fmt"

type SegmentTree struct {
	n      int
	arvore []int
}

func novaSegmentTree(nums []int) *SegmentTree {
	st := &SegmentTree{n: len(nums), arvore: make([]int, 4*len(nums)+4)}
	if st.n > 0 {
		st.construir(1, 0, st.n-1, nums)
	}
	return st
}

func (st *SegmentTree) construir(no, ini, fim int, nums []int) {
	if ini == fim {
		st.arvore[no] = nums[ini]
		return
	}
	meio := (ini + fim) / 2
	st.construir(2*no, ini, meio, nums)
	st.construir(2*no+1, meio+1, fim, nums)
	st.arvore[no] = st.arvore[2*no] + st.arvore[2*no+1]
}

func (st *SegmentTree) atualizar(i, valor, no, ini, fim int) {
	if ini == fim {
		st.arvore[no] = valor
		return
	}
	meio := (ini + fim) / 2
	if i <= meio {
		st.atualizar(i, valor, 2*no, ini, meio)
	} else {
		st.atualizar(i, valor, 2*no+1, meio+1, fim)
	}
	st.arvore[no] = st.arvore[2*no] + st.arvore[2*no+1]
}

func (st *SegmentTree) consultar(esq, dir, no, ini, fim int) int {
	if dir < ini || fim < esq { // fora do intervalo
		return 0
	}
	if esq <= ini && fim <= dir { // totalmente dentro
		return st.arvore[no]
	}
	meio := (ini + fim) / 2
	return st.consultar(esq, dir, 2*no, ini, meio) +
		st.consultar(esq, dir, 2*no+1, meio+1, fim)
}

	st := novaSegmentTree([]int{5, 2, 8, 1, 4, 7})
	fmt.Println(st.consultar(1, 3, 1, 0, st.n-1)) // 2 + 8 + 1 = 11
	st.atualizar(2, 3, 1, 0, st.n-1)
	fmt.Println(st.consultar(1, 3, 1, 0, st.n-1)) // 2 + 3 + 1 = 6
	fmt.Println(st.consultar(0, 5, 1, 0, st.n-1)) // 22
}

**Complexidade:** construção em O(n), consulta e atualização em O(log n), espaço O(n).

## Trocando a operação

Nada no esqueleto depende de soma. Troque a combinação e o elemento neutro e a mesma árvore responde outras perguntas:

| Consulta | Combinação | Neutro |
| --- | --- | --- |
| Soma | `a + b` | `0` |
| Mínimo | `min(a, b)` | `inf` |
| Máximo | `max(a, b)` | `-inf` |
| MDC | `gcd(a, b)` | `0` |

A operação precisa ser **associativa**: o resultado não pode depender de como o intervalo foi partido.

<Callout type="note" title="Lazy propagation">
Se a atualização afeta um intervalo inteiro, como "some 5 a tudo entre 2 e 900", atualizar folha por folha custa O(n log n). A técnica de *lazy propagation* guarda a atualização pendente no nó e só a empurra para os filhos quando alguém desce por ali, mantendo O(log n). Raramente pedem o código completo em entrevista, mas vale saber explicar a ideia.
</Callout>

## Armadilhas

- Alocar só `2n` posições na versão recursiva: quando n não é potência de 2, alguns índices passam disso. Use `4n`.
- Esquecer de recalcular o pai depois de atualizar o filho.
- Usar um neutro errado, como 0 numa árvore de mínimo.

## Na entrevista

A segment tree aparece em problemas como "soma de intervalo com atualizações", "contar menores à direita" ou "mínimo em intervalo com mudanças". Antes de escrevê-la, pergunte se o array muda. Se não muda, soma de prefixos (ou *sparse table*, para mínimo) é mais simples. Se só há somas e atualizações pontuais, a Fenwick tree resolve com menos código. Use a segment tree quando a operação não tem inverso (mínimo, máximo) ou quando há atualizações em intervalo. Follow-ups comuns: "e se a atualização fosse em intervalo?" (lazy) e "qual o espaço?" (O(n), com a constante 4).
