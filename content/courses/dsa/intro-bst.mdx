Uma **árvore de busca binária** (BST, binary search tree) é uma árvore binária com uma regra de ordenação: para todo nó, **todos** os valores da subárvore esquerda são menores que ele e **todos** os da subárvore direita são maiores. Essa única propriedade transforma a árvore numa espécie de busca binária com formato flexível, que aceita inserções e remoções.

## A propriedade, com cuidado

O erro clássico é verificar só os filhos diretos. Veja:

```text
        8
       / \
      3   10
       \
        9      <- 9 é maior que 3 (ok para o pai),
                  mas está à esquerda do 8: inválido
```

A regra vale para a subárvore inteira, não só para o filho. Por isso validar uma BST exige carregar **limites** pela recursão.

```python
class No:
    def __init__(self, val, esq=None, dir=None):
        self.val, self.esq, self.dir = val, esq, dir

    if no is None:
        return True

        return False
```

## Busca e inserção

Para buscar, compare com o nó atual e desça só para um lado. Cada comparação descarta uma subárvore inteira:

<CodeTabs>

```python
class No:
    def __init__(self, val):
        self.val, self.esq, self.dir = val, None, None

def inserir(raiz, val):
    if raiz is None:
        return No(val)
    if val < raiz.val:
        raiz.esq = inserir(raiz.esq, val)
    else:
        raiz.dir = inserir(raiz.dir, val)
    return raiz

def buscar(raiz, val):
    while raiz and raiz.val != val:
        raiz = raiz.esq if val < raiz.val else raiz.dir
    return raiz is not None

def em_ordem(no, saida):
    if no:
        em_ordem(no.esq, saida)
        saida.append(no.val)
        em_ordem(no.dir, saida)
    return saida

raiz = None
for v in [50, 30, 70, 20, 40, 60]:
    raiz = inserir(raiz, v)
print(buscar(raiz, 40), buscar(raiz, 45))  # True False
print(em_ordem(raiz, []))  # [20, 30, 40, 50, 60, 70]
```

```go
type No struct {
	val      int
	esq, dir *No
}

func inserir(raiz *No, val int) *No {
	if raiz == nil {
		return &No{val: val}
	}

		raiz.dir = inserir(raiz.dir, val)

	return raiz

func buscar(raiz *No, val int) bool {

		}
```

## Altura é tudo

Busca, inserção e remoção custam **O(h)**. Se a árvore está balanceada, h = O(log n). Mas inserir valores já ordenados (1, 2, 3, 4...) cria uma "árvore" que é, na prática, uma lista ligada, com h = n.

| Operação | BST balanceada | BST degenerada |
| --- | --- | --- |
| Buscar | O(log n) | O(n) |
| Inserir | O(log n) | O(n) |
| Remover | O(log n) | O(n) |
| Percurso em ordem | O(n) | O(n) |

Árvores autobalanceadas (AVL, rubro-negra) garantem O(log n) com rotações. Em entrevista quase nunca pedem para implementá-las; basta saber que existem e que é isso que está por trás de `TreeMap` em Java ou `std::map` em C++.

<Callout type="tip" title="O superpoder: percurso em ordem">
O percurso em ordem (esquerda, nó, direita) visita os valores de uma BST em ordem crescente. Muitos problemas viram "faça um percurso em ordem e observe a sequência": k-ésimo menor, validar BST, achar dois nós trocados, converter em lista ordenada.
</Callout>

## Remoção, em resumo

Três casos: o nó é folha (só remova), tem um filho (substitua pelo filho) ou tem dois filhos (troque o valor pelo **sucessor**, o menor da subárvore direita, e remova o sucessor lá). É mais trabalhoso que difícil; vale treinar uma vez.

## Quando reconhecer

- O enunciado diz "árvore de busca binária": a ordem é uma informação que você **deve** usar; uma solução que trata a árvore como genérica geralmente não é a esperada.
- Pede k-ésimo menor, mediana, valores num intervalo, antecessor ou sucessor.
- Pede o menor ancestral comum numa BST: desça enquanto os dois valores estiverem do mesmo lado.

## Na entrevista

Pergunte se há valores duplicados e de que lado eles vão. Sempre expresse a complexidade em termos de h e depois explique a diferença entre árvore balanceada e degenerada. Se for validar, mencione a armadilha dos filhos diretos antes que o entrevistador pergunte.
