A **janela deslizante** mantém um trecho contíguo do array ou da string e o ajusta incrementalmente, em vez de recalcular tudo para cada subarray possível.

## Janela fixa e janela variável

Na **janela fixa**, o tamanho `k` é dado. Ao deslizar, você adiciona o elemento que entra e remove o que sai.

```python
def maior_soma_k(nums, k):
    soma = sum(nums[:k])
    melhor = soma
    for i in range(k, len(nums)):
        soma += nums[i] - nums[i - k]   # entra nums[i], sai nums[i - k]
        melhor = max(melhor, soma)
    return melhor
```

Na **janela variável**, o ponteiro da direita expande a janela e o da esquerda a contrai sempre que ela deixa de ser válida.

## O molde da janela variável

```python
esq = 0
for dir in range(len(s)):
    adicionar(s[dir])
    while janela_invalida():
        remover(s[esq])
        esq += 1
    atualizar_resposta(esq, dir)
```

<Callout type="note" title="Sinais no enunciado">
"Subarray contíguo", "substring", "maior ou menor janela que satisfaz uma condição". Se a pergunta fala de subsequências não contíguas, a janela deslizante não se aplica.
</Callout>

Cada elemento entra e sai da janela no máximo uma vez, então o custo total é O(n), mesmo com o `while` dentro do `for`.
