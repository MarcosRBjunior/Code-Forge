Serializar uma árvore é transformá-la em texto para salvar em arquivo ou mandar pela rede; desserializar é o caminho inverso. Neste problema o formato é fixo: os valores são escritos em **pré-ordem** (raiz, depois subárvore esquerda inteira, depois subárvore direita inteira), separados por vírgula, e cada filho ausente vira o símbolo `#`.

Implemente `deserialize(data)`, que recebe uma string nesse formato e retorna a raiz da árvore reconstruída (crie os nós com `TreeNode`). A string `"#"` representa a árvore vazia. Os testes verificam só `deserialize`, mas vale escrever também `serialize(root)`, que produz o formato a partir de uma árvore: as duas funções são uma o espelho da outra.

## Exemplo

```text
Entrada: data = "1,2,#,#,3,4,#,#,5,#,#"
Saída: [1, 2, 3, null, null, 4, 5]
      1
     / \
    2   3
       / \
      4   5
```

## Restrições

- 0 ≤ número de nós ≤ 10.000
- -1000 ≤ `val` ≤ 1000
- A string de entrada é sempre válida.

## Dica

Separe a string pelas vírgulas e consuma os pedaços um por um com um índice compartilhado (ou um iterador). Ao ler um valor, crie o nó e chame a mesma função para montar a esquerda e depois a direita; ao ler `#`, retorne vazio. Os marcadores `#` são o que tornam a pré-ordem suficiente para reconstruir a árvore sozinha.
