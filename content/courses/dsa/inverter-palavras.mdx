Dada uma string `s`, retorne uma nova string com as **palavras** em ordem inversa. Uma palavra é qualquer sequência de caracteres sem espaço.

A entrada pode ter espaços no começo, no fim e vários espaços seguidos entre as palavras. Na saída, não deve haver espaços nas pontas, e as palavras ficam separadas por exatamente um espaço. As letras dentro de cada palavra mantêm a ordem original.

## Exemplo

```text
Entrada: s = "  bom   dia  "
Saída: "dia bom"
```

## Restrições

- `1 <= s.length <= 10^4`
- `s` tem pelo menos uma palavra.

## Dica

Com `split` e `join` sai em uma linha, mas cuidado com os espaços repetidos. Para treinar, tente também percorrer a string de trás para frente, recortando cada palavra com dois índices.
