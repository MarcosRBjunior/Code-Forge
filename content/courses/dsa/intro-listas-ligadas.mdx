Uma **lista ligada** é uma cadeia de nós em que cada nó guarda um valor e uma referência para o próximo. Ao contrário do array, os nós ficam espalhados pela memória.

## Custos em comparação com arrays

| Operação | Lista ligada | Array |
| --- | --- | --- |
| Acessar o k-ésimo | O(k) | O(1) |
| Inserir ou remover com o nó em mãos | O(1) | O(n) |
| Inserir no início | O(1) | O(n) |
| Memória extra | Um ponteiro por nó | Folga de capacidade |

Em entrevistas, listas ligadas testam principalmente sua habilidade de **manipular ponteiros sem perder nós**. Como não há índice, a única forma de chegar a um nó é seguir as setas a partir da cabeça. Se você sobrescreve uma referência antes de guardá-la, o restante da lista fica inacessível. Por isso o código abaixo sempre salva o próximo nó antes de redirecionar o ponteiro atual.

<CodeTabs>

```python
class No:
    def __init__(self, val, prox=None):
        self.val = val
        self.prox = prox

def de_lista(valores):
    cabeca = None
    for v in reversed(valores):
        cabeca = No(v, cabeca)
    return cabeca

def para_lista(no):
    out = []
    while no:
        out.append(no.val)
        no = no.prox
    return out

def inverter(cabeca):
    anterior = None
    atual = cabeca
    while atual:
        proximo = atual.prox   # guarda antes de perder
        atual.prox = anterior
        anterior = atual
        atual = proximo
    return anterior

print(para_lista(inverter(de_lista([1, 2, 3, 4]))))  # [4, 3, 2, 1]
```

## Nó sentinela

Muitos bugs vêm de tratar a cabeça da lista como caso especial: remover o primeiro elemento, inserir antes dele, devolver uma lista que pode ficar vazia. Um **nó sentinela** (dummy) antes da cabeça elimina esses casos.

<CodeTabs>

```python
def remover_valor(cabeca, alvo):
    sentinela = No(0, cabeca)
    atual = sentinela
    while atual.prox:
        if atual.prox.val == alvo:
            atual.prox = atual.prox.prox
        else:
            atual = atual.prox
    return sentinela.prox
```

```javascript
function removerValor(cabeca, alvo) {
  const sentinela = new No(0, cabeca);
  let atual = sentinela;
  while (atual.prox) {
    if (atual.prox.val === alvo) {
      atual.prox = atual.prox.prox;
    } else {
      atual = atual.prox;
    }
  }
  return sentinela.prox;
}
```

</CodeTabs>

Sempre devolva `sentinela.prox`, nunca a cabeça original, porque ela pode ter sido removida. O mesmo truque simplifica a mesclagem de duas listas ordenadas: você vai pendurando nós atrás da sentinela sem se preocupar com qual será o primeiro.

## Ponteiros rápido e lento

Dois ponteiros que andam em velocidades diferentes resolvem vários problemas em O(1) de espaço:

<CodeTabs>

```python
def meio(cabeca):
    lento = rapido = cabeca
    while rapido and rapido.prox:
        lento = lento.prox
        rapido = rapido.prox.prox
    return lento

def tem_ciclo(cabeca):
    lento = rapido = cabeca
    while rapido and rapido.prox:
        lento = lento.prox
        rapido = rapido.prox.prox
        if lento is rapido:
            return True
    return False
```

```javascript

  let lento = cabeca, rapido = cabeca;

  }
  return lento;

    lento = lento.prox;
```

Quando o rápido chega ao fim, o lento está no meio. Se houver ciclo, o rápido alcança o lento por trás, como um corredor mais veloz em uma pista circular.
