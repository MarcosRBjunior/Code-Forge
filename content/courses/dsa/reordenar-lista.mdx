Você recebe a cabeça `head` de uma lista ligada cujos nós são, em ordem, `L0, L1, ..., Ln`. Reorganize os nós **in-place** para que a lista fique intercalando o começo e o fim: `L0, Ln, L1, Ln-1, L2, Ln-2, ...`.

Você não pode alterar os valores dentro dos nós, só os ponteiros. O teste lê a lista a partir da mesma cabeça que você recebeu.

## Exemplo

```text
Entrada: 1 -> 2 -> 3 -> 4 -> 5
Saída:   1 -> 5 -> 2 -> 4 -> 3
```

## Restrições

- 0 ≤ número de nós ≤ 50.000
- Tente usar memória O(1) extra.

## Dica

O resultado combina três operações que você já conhece: achar o meio da lista, inverter uma lista e intercalar duas listas.
