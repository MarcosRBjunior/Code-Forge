Dado um array de inteiros `nums`, retorne verdadeiro se **algum valor aparecer pelo menos duas vezes** e falso se todos os elementos forem distintos.

## Exemplo

```text
Entrada: nums = [1, 2, 3, 1]
Saída: true
Explicação: o valor 1 aparece nas posições 0 e 3.
```

## Restrições

- 0 ≤ tamanho de `nums` ≤ 10⁵
- -10⁹ ≤ `nums[i]` ≤ 10⁹

## Dica

Comparar todos os pares custa O(n²). Que estrutura responde "já vi este número?" em tempo constante?
