Uma **pilha** só permite mexer no topo: empilhar, desempilhar e espiar o último elemento, tudo em O(1). A regra é "o último a entrar é o primeiro a sair" (LIFO), igual a uma pilha de pratos.

## Pilhas em Python

Não existe uma classe especial: a própria `list` funciona como pilha, porque `append` e `pop` no fim são O(1).

<CodeTabs>

```python
pilha = []
pilha.append(1)      # empilha
pilha.append(2)
topo = pilha[-1]     # espia: 2
pilha.pop()          # desempilha: 2
vazia = not pilha
print(topo, pilha, vazia)
```

```javascript
const pilha = [];
pilha.push(1);                       // empilha
pilha.push(2);
const topo = pilha[pilha.length - 1]; // espia: 2
pilha.pop();                         // desempilha: 2
const vazia = pilha.length === 0;
console.log(topo, pilha, vazia);
```

```typescript
const pilha: number[] = [];
pilha.push(1);                       // empilha
pilha.push(2);

```

```java
import java.util.*;

public static void main(String[] args) {
    Deque<Integer> pilha = new ArrayDeque<>();
    pilha.push(1);                   // empilha
    pilha.push(2);
    int topo = pilha.peek();         // espia: 2
    pilha.pop();                     // desempilha: 2
    boolean vazia = pilha.isEmpty();
    System.out.println(topo + " " + pilha + " " + vazia);
}
```

## Quando pensar em pilha

Pilhas aparecem sempre que a última coisa aberta precisa ser a primeira a ser fechada. O exemplo clássico é validar parênteses:

<CodeTabs>

```python
def parenteses_validos(s):
    pares = {")": "(", "]": "[", "}": "{"}
    pilha = []
    for c in s:
        if c in "([{":
            pilha.append(c)
        elif not pilha or pilha.pop() != pares[c]:
            return False
    return not pilha

print(parenteses_validos("([]{})"))  # True
print(parenteses_validos("(]"))      # False
```

```javascript
function parentesesValidos(s) {
  const pares = { ")": "(", "]": "[", "}": "{" };
  const pilha = [];
  for (const c of s) {
    if ("([{".includes(c)) {
      pilha.push(c);
    } else if (pilha.length === 0 || pilha.pop() !== pares[c]) {
      return false;
    }
  }
  return pilha.length === 0;
}

console.log(parentesesValidos("([]{})"));  // true
console.log(parentesesValidos("(]"));      // false
```

```java
import java.util.*;

static boolean parentesesValidos(String s) {
    Map<Character, Character> pares = Map.of(')', '(', ']', '[', '}', '{');
    Deque<Character> pilha = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if ("([{".indexOf(c) >= 0) {
            pilha.push(c);
        } else if (pilha.isEmpty() || pilha.pop() != pares.get(c)) {
            return false;
        }
    }
    return pilha.isEmpty();
}

public static void main(String[] args) {
    System.out.println(parentesesValidos("([]{})"));  // true
    System.out.println(parentesesValidos("(]"));      // false
}
```

```cpp
#include <iostream>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

bool parentesesValidos(const string& s) {
    unordered_map<char, char> pares = {{')', '('}, {']', '['}, {'}', '{'}};
    vector<char> pilha;
    for (char c : s) {
        if (string("([{").find(c) != string::npos) {
            pilha.push_back(c);
        } else {
            if (pilha.empty()) return false;
            char topo = pilha.back();
            pilha.pop_back();
            if (topo != pares[c]) return false;
        }
    }
    return pilha.empty();
}

int main() {
    cout << boolalpha;
    cout << parentesesValidos("([]{})") << endl;  // true
    cout << parentesesValidos("(]") << endl;      // false
}
```

Outros sinais: desfazer operações, avaliar expressões, simular a pilha de chamadas de uma recursão e percorrer árvores em profundidade sem recursão.

Repare que a solução decide tudo olhando apenas o topo. Essa é a essência da pilha: em cada momento, só o elemento mais recente importa para a próxima decisão. Se você percebe que precisa comparar o item atual com "o último ainda pendente", provavelmente uma pilha resolve. Quando precisa do "primeiro ainda pendente", a estrutura certa é uma fila.

## Pilha monotônica

Uma **pilha monotônica** mantém seus elementos sempre em ordem crescente ou decrescente. Antes de empilhar um novo valor, você desempilha tudo que quebraria a ordem. O momento em que um elemento é desempilhado é exatamente o momento em que ele encontra a resposta que procurava.

Exemplo: para cada dia, quantos dias até uma temperatura mais alta?

<CodeTabs>

```python
def dias_ate_esquentar(temps):
    resposta = [0] * len(temps)
    pilha = []  # índices com temperaturas decrescentes
    for i, t in enumerate(temps):
        while pilha and temps[pilha[-1]] < t:
            j = pilha.pop()
            resposta[j] = i - j
        pilha.append(i)
    return resposta

print(dias_ate_esquentar([73, 74, 75, 71, 69, 72, 76, 73]))
# [1, 1, 4, 2, 1, 1, 0, 0]
```

```javascript
function diasAteEsquentar(temps) {
  const resposta = new Array(temps.length).fill(0);
  const pilha = [];  // índices com temperaturas decrescentes
  for (let i = 0; i < temps.length; i++) {
    while (pilha.length > 0 && temps[pilha[pilha.length - 1]] < temps[i]) {
      const j = pilha.pop();
      resposta[j] = i - j;
    }
    pilha.push(i);
  }
  return resposta;
}

console.log(diasAteEsquentar([73, 74, 75, 71, 69, 72, 76, 73]));
// [1, 1, 4, 2, 1, 1, 0, 0]
```


```java
import java.util.*;

static int[] diasAteEsquentar(int[] temps) {
```

```go
import "fmt"

func diasAteEsquentar(temps []int) []int {
	resposta := make([]int, len(temps))
	pilha := []int{} // índices com temperaturas decrescentes
	for i, t := range temps {
		for len(pilha) > 0 && temps[pilha[len(pilha)-1]] < t {
			j := pilha[len(pilha)-1]
			pilha = pilha[:len(pilha)-1]
			resposta[j] = i - j
		}
		pilha = append(pilha, i)
	}
	return resposta
}

func main() {
	fmt.Println(diasAteEsquentar([]int{73, 74, 75, 71, 69, 72, 76, 73}))
	// [1 1 4 2 1 1 0 0]
}
```

<Callout type="note" title="Por que é O(n)">
O `while` dentro do `for` assusta, mas cada índice entra na pilha uma vez e sai no máximo uma vez. O total de operações é proporcional a n, não a n².
</Callout>

| Pergunta | Pilha |
| --- | --- |
| Próximo maior à direita | Decrescente |
| Próximo menor à direita | Crescente |
| Maior retângulo em histograma | Crescente |

## Na entrevista

Guarde **índices** na pilha, não valores: com o índice você recupera o valor e ainda calcula distâncias. Ao explicar, descreva a invariante ("a pilha sempre está em ordem decrescente de temperatura") antes de escrever o laço. Isso deixa o raciocínio fácil de acompanhar e ajuda a justificar por que a complexidade é linear.
