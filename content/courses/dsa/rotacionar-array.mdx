Dado um array `nums` e um inteiro não negativo `k`, gire o array `k` posições para a direita: cada elemento anda `k` casas, e quem passa do fim volta pelo começo.

Faça a rotação **in-place**. A função não retorna nada: os testes verificam o próprio `nums`. Note que `k` pode ser maior que o tamanho do array.

## Exemplo

```text
Entrada: nums = [1, 2, 3, 4, 5, 6, 7], k = 3
Depois:  nums = [5, 6, 7, 1, 2, 3, 4]
```

## Restrições

- `1 <= nums.length <= 10^5`
- `0 <= k <= 10^5`

## Dica

Girar `n` posições não muda nada, então comece reduzindo `k`. Depois, pense no que acontece se você inverter o array inteiro e, em seguida, inverter separadamente as duas partes.
