Dada uma lista de strings `strs`, retorne o maior **prefixo** que todas elas têm em comum. Se não houver nenhum, retorne a string vazia `""`.

Um prefixo é um trecho inicial da string: `"pro"` é prefixo de `"programa"`, mas `"gra"` não é.

## Exemplo

```text
Entrada: strs = ["flor", "fluxo", "flanco"]
Saída: "fl"

Entrada: strs = ["carro", "bola", "casa"]
Saída: ""
```

## Restrições

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- As strings têm apenas letras minúsculas.

## Dica

O prefixo comum nunca é maior que a menor string da lista. Compare as strings coluna por coluna e pare na primeira posição em que alguma delas acaba ou diverge.
