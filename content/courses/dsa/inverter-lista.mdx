Você recebe `head`, a cabeça de uma lista simplesmente ligada. Religue os ponteiros para que a lista passe a ser percorrida na ordem contrária e retorne a nova cabeça.

Não crie nós novos: a ideia é reaproveitar os nós existentes, mudando apenas para onde cada `next` aponta. Uma lista vazia continua vazia.

## Exemplo

```text
Entrada: 1 -> 2 -> 3 -> 4 -> 5
Saída:   5 -> 4 -> 3 -> 2 -> 1
```

## Restrições

- 0 ≤ número de nós ≤ 5000
- -5000 ≤ `val` ≤ 5000

## Dica

Ao visitar um nó você precisa lembrar de três coisas: quem veio antes, quem é o atual e quem vem depois. O que se perde se você mudar `next` antes de guardar o próximo?
