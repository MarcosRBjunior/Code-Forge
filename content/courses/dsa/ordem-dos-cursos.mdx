Há `num_courses` cursos numerados de `0` a `num_courses - 1`. Cada par `[a, b]` em `prerequisites` diz que o curso `b` precisa ser feito **antes** do curso `a`. Retorne uma ordem em que dá para cursar todos eles. Se houver dependência circular, retorne uma lista vazia.

Como normalmente existem várias ordens válidas, use esta regra de desempate para que a resposta seja única: sempre que mais de um curso estiver liberado (com todos os pré-requisitos cumpridos), escolha o de **menor número**.

## Exemplo

```text
Entrada: num_courses = 4, prerequisites = [[0, 3], [1, 3], [2, 0]]
Saída: [3, 0, 1, 2]
Explicação: só o curso 3 começa liberado. Depois dele, 0 e 1 ficam livres; o 0 vem primeiro
e libera o 2. Entre 1 e 2, o 1 tem número menor.
```

## Restrições

- 1 ≤ `num_courses` ≤ 2000
- 0 ≤ tamanho de `prerequisites` ≤ `num_courses` × (`num_courses` - 1)
- Não há pares repetidos.

## Dica

Ordenação topológica pelo algoritmo de Kahn: conte quantos pré-requisitos pendentes cada curso tem e vá liberando os que chegam a zero. Para respeitar o desempate, guarde os liberados num min-heap em vez de numa fila comum.
