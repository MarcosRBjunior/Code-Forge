Java é verboso, mas tem uma das bibliotecas de coleções mais completas: heap, deque, mapa ordenado e conjunto ordenado já vêm prontos. Esta folha de consulta mostra o essencial do Collections Framework e as armadilhas que mais derrubam candidatos.

## Arrays e listas

```java
int[] a = {5, 2, 8, 1};
Arrays.sort(a);                         // O(n log n), primitivos
int[][] grade = new int[3][4];          // já inicializada com zeros
Arrays.fill(a, -1);

List<Integer> lista = new ArrayList<>();
lista.add(3);                           // O(1) amortizado
lista.get(0);                           // O(1)
lista.remove(lista.size() - 1);         // remove do fim, O(1)
Collections.sort(lista);
Collections.reverse(lista);
```

Atenção com `lista.remove(int)` contra `lista.remove(Object)`: em uma `List<Integer>`, `remove(1)` remove o **índice** 1. Para remover o valor 1, use `remove(Integer.valueOf(1))`.

## Mapas e conjuntos

```java
Map<Character, Integer> freq = new HashMap<>();
for (char c : "banana".toCharArray()) {
    freq.merge(c, 1, Integer::sum);     // contagem idiomática
}
int n = freq.getOrDefault('z', 0);

Map<String, List<String>> grupos = new HashMap<>();
grupos.computeIfAbsent("o", k -> new ArrayList<>()).add("ovo");

Set<Integer> vistos = new HashSet<>();
boolean novo = vistos.add(7);           // false se já existia
```

`HashMap` e `HashSet` têm operações O(1) em média. Quando precisar de ordem, use as versões em árvore, com O(log n):

```java
TreeMap<Integer, String> agenda = new TreeMap<>();
agenda.put(9, "reunião"); agenda.put(14, "almoço");
agenda.floorKey(12);      // 9: maior chave menor ou igual a 12
agenda.ceilingKey(12);    // 14: menor chave maior ou igual a 12
agenda.firstKey(); agenda.pollFirstEntry();

TreeSet<Integer> ts = new TreeSet<>(List.of(1, 5, 9));
ts.higher(5);             // 9
```

`TreeMap` resolve muitos problemas de intervalos e agendas que em Python exigiriam bibliotecas externas.

## Pilha, fila e heap

```java
Deque<Integer> pilha = new ArrayDeque<>();
pilha.push(1); pilha.push(2);
pilha.pop();              // 2

Deque<Integer> fila = new ArrayDeque<>();
fila.offer(1); fila.offer(2);
fila.poll();              // 1

PriorityQueue<Integer> min = new PriorityQueue<>();
PriorityQueue<Integer> max = new PriorityQueue<>(Collections.reverseOrder());
PriorityQueue<int[]> porDist = new PriorityQueue<>((x, y) -> Integer.compare(x[0], y[0]));
porDist.offer(new int[]{4, 2});
int[] topo = porDist.poll();
```

Prefira `ArrayDeque` à antiga classe `Stack`, que é sincronizada e mais lenta.

## Strings

```java
String s = "entrevista";
char c = s.charAt(0);
int idx = c - 'a';                      // índice no alfabeto
char[] cs = s.toCharArray();
Arrays.sort(cs);
String ordenada = new String(cs);

StringBuilder sb = new StringBuilder();
for (int i = 0; i < 3; i++) sb.append(i);
String r = sb.reverse().toString();     // "210"

boolean igual = s.equals("entrevista"); // nunca use == para conteúdo
```

Concatenar `String` num laço cria uma cópia a cada passo, O(n²) no total. Use `StringBuilder`.

<Callout type="warning" title="Armadilhas clássicas">
`Integer` acima de 127 comparado com `==` compara referências: use `equals` ou converta para `int`. `a + b` com `int` pode estourar silenciosamente; use `long` em somas e produtos grandes, e `lo + (hi - lo) / 2` no meio da busca binária. Em comparadores, `Integer.compare(x, y)` evita o overflow de `x - y`.
</Callout>

## Primitivos, wrappers e streams

Arrays de primitivos (`int[]`) são mais rápidos e leves que `List<Integer>`, porque não guardam objetos. Use-os para DP e contagens com alfabeto fixo, como `int[26]`. Coleções só aceitam wrappers, e o autoboxing converte sozinho, mas tem custo. Streams (`Arrays.stream(a).sum()`, `list.stream().mapToInt(Integer::intValue).toArray()`) economizam linhas em conversões, mas em laços críticos um `for` simples é mais claro e mais fácil de depurar na frente do entrevistador.

## Tabela de custos

| Operação | Custo |
| --- | --- |
| `ArrayList.add`, `get` | O(1) amortizado / O(1) |
| `ArrayList.add(0, x)`, `remove(0)`, `contains` | O(n) |
| `HashMap`/`HashSet` | O(1) médio |
| `TreeMap`/`TreeSet`: inserir, buscar, `floor`, `ceiling` | O(log n) |
| `ArrayDeque`: `push`, `pop`, `offer`, `poll` | O(1) |
| `PriorityQueue`: `offer`, `poll` | O(log n); `peek` é O(1) |
| `Arrays.sort`, `Collections.sort` | O(n log n) |

## Na entrevista

Declare tipos pela interface (`Map`, `List`, `Deque`) e instancie a implementação. Isso deixa claro que você conhece a hierarquia e facilita trocar `HashMap` por `TreeMap` se o entrevistador pedir ordem. Mencione `TreeMap` sempre que o problema envolver "o maior valor menor que X": é um diferencial do Java.
