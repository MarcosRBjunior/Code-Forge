Uma CPU precisa executar uma lista de tarefas, `tasks`, em que cada tarefa é identificada por uma letra maiúscula. Cada tarefa leva exatamente uma unidade de tempo. Em cada unidade, a CPU executa uma tarefa qualquer ou fica ociosa.

Há uma regra de resfriamento: entre duas execuções de tarefas com a **mesma letra** precisam se passar pelo menos `n` unidades de tempo. A ordem das tarefas é livre. Retorne o menor número total de unidades de tempo (contando as ociosas) para concluir todas.

## Exemplo

```text
Entrada: tasks = ["A", "A", "A", "B", "B", "B"], n = 2
Saída: 8
Uma ordem ótima: A -> B -> ocioso -> A -> B -> ocioso -> A -> B
```

## Restrições

- 1 ≤ tamanho de `tasks` ≤ 10.000
- 0 ≤ `n` ≤ 100

## Dica

As tarefas mais frequentes são as que causam espera. Uma simulação gulosa funciona bem: a cada instante, execute a tarefa disponível com mais repetições restantes (max-heap) e coloque-a numa fila de espera até ela poder voltar. Existe também uma fórmula fechada baseada na frequência máxima; tente descobri-la.
