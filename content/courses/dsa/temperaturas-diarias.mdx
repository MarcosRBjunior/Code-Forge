O array `temperatures` traz a temperatura de cada dia. Retorne um array `answer` em que `answer[i]` é **quantos dias é preciso esperar**, a partir do dia `i`, até uma temperatura estritamente maior. Se isso nunca acontecer, `answer[i]` é `0`.

## Exemplo

```text
Entrada: temperatures = [73, 74, 75, 71, 69, 72, 76, 73]
Saída: [1, 1, 4, 2, 1, 1, 0, 0]
Explicação: no dia 2 (75 graus), a próxima temperatura maior é 76, no dia 6.
```

## Restrições

- 1 ≤ tamanho de `temperatures` ≤ 10⁵
- 30 ≤ `temperatures[i]` ≤ 100

## Dica

Guarde os dias que ainda estão "esperando" por um dia mais quente. Quando chega uma temperatura alta, quais deles ela resolve, e em que ordem?
