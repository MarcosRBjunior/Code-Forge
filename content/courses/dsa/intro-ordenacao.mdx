Ordenar é muitas vezes o primeiro passo que desbloqueia um problema: depois de ordenar, duplicados ficam vizinhos, pares com soma alvo saem com dois ponteiros, intervalos podem ser mesclados numa passada. Em entrevista você quase sempre usa o sort da linguagem, mas precisa conhecer os algoritmos para discutir custo, estabilidade e variações.

## O mapa dos algoritmos

| Algoritmo | Melhor | Médio | Pior | Espaço extra | Estável |
| --- | --- | --- | --- | --- | --- |
| Bubble sort | O(n) | O(n²) | O(n²) | O(1) | Sim |
| Selection sort | O(n²) | O(n²) | O(n²) | O(1) | Não |
| Insertion sort | O(n) | O(n²) | O(n²) | O(1) | Sim |
| Merge sort | O(n log n) | O(n log n) | O(n log n) | O(n) | Sim |
| Quick sort | O(n log n) | O(n log n) | O(n²) | O(log n) | Não |
| Heap sort | O(n log n) | O(n log n) | O(n log n) | O(1) | Não |
| Counting sort | O(n + k) | O(n + k) | O(n + k) | O(k) | Sim |

Algoritmos baseados em **comparação** não conseguem ser melhores que O(n log n) no pior caso. Counting sort escapa desse limite porque não compara: usa os valores como índices.

## Insertion sort: o quadrático que vale conhecer

Ele mantém um prefixo ordenado e insere cada novo elemento no lugar certo, deslocando os maiores para a direita. Em entradas **quase ordenadas**, roda perto de O(n), e por isso é usado internamente por algoritmos híbridos em pedaços pequenos.

<CodeTabs>

```python
def insertion_sort(nums):
    for i in range(1, len(nums)):
        atual = nums[i]
        j = i - 1
        while j >= 0 and nums[j] > atual:
            nums[j + 1] = nums[j]    # empurra o maior para a direita
            j -= 1
        nums[j + 1] = atual
    return nums

print(insertion_sort([5, 2, 9, 1, 5, 6]))  # [1, 2, 5, 5, 6, 9]
```

## Estabilidade

Um sort é **estável** quando elementos com chaves iguais mantêm a ordem original. Isso importa ao ordenar por mais de um critério:

<CodeTabs>

```python
pessoas = [("ana", 30), ("bia", 25), ("caio", 30), ("davi", 25)]
por_idade = sorted(pessoas, key=lambda p: p[1])
print(por_idade)
# [('bia', 25), ('davi', 25), ('ana', 30), ('caio', 30)]
```

```javascript
const pessoas = [["ana", 30], ["bia", 25], ["caio", 30], ["davi", 25]];
const porIdade = [...pessoas].sort((a, b) => a[1] - b[1]);   // o sort do JavaScript é estável
console.log(porIdade);
// [["bia", 25], ["davi", 25], ["ana", 30], ["caio", 30]]
```

```typescript
const pessoas: [string, number][] = [["ana", 30], ["bia", 25], ["caio", 30], ["davi", 25]];

console.log(porIdade);
// [["bia", 25], ["davi", 25], ["ana", 30], ["caio", 30]]
```

```java
import java.util.*;

class Pessoa {
    String nome;
    int idade;

    Pessoa(String nome, int idade) {
        this.nome = nome;
        this.idade = idade;
    }

    @Override
    public String toString() {
        return "(" + nome + ", " + idade + ")";

}

public static void main(String[] args) {

        new Pessoa("ana", 30), new Pessoa("bia", 25), new Pessoa("caio", 30), new Pessoa("davi", 25)));
    List<Pessoa> porIdade = new ArrayList<>(pessoas);
    porIdade.sort(Comparator.comparingInt(p -> p.idade));   // List.sort é estável
    System.out.println(porIdade);
    // [(bia, 25), (davi, 25), (ana, 30), (caio, 30)]
}
```

## Usando o sort da linguagem com chaves

A maior parte do trabalho real em entrevista é escolher a **chave** certa:

<CodeTabs>

```python
palavras = ["banana", "kiwi", "uva", "abacaxi", "figo"]
# por tamanho, e alfabeticamente para desempatar
print(sorted(palavras, key=lambda w: (len(w), w)))
# ['uva', 'figo', 'kiwi', 'banana', 'abacaxi']

# decrescente por tamanho, crescente por texto
print(sorted(palavras, key=lambda w: (-len(w), w)))
# ['abacaxi', 'banana', 'figo', 'kiwi', 'uva']
```

```java
import java.util.*;

public static void main(String[] args) {
    List<String> palavras = List.of("banana", "kiwi", "uva", "abacaxi", "figo");
    // por tamanho, e alfabeticamente para desempatar
    List<String> a = new ArrayList<>(palavras);
    a.sort(Comparator.comparingInt(String::length).thenComparing(Comparator.naturalOrder()));
    System.out.println(a);
    // [uva, figo, kiwi, banana, abacaxi]

    // decrescente por tamanho, crescente por texto
    List<String> b = new ArrayList<>(palavras);
    b.sort(Comparator.comparingInt(String::length).reversed().thenComparing(Comparator.naturalOrder()));
    System.out.println(b);
    // [abacaxi, banana, figo, kiwi, uva]
}
```

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

void imprimir(const vector<string>& v) {
    cout << "[";
    for (size_t i = 0; i < v.size(); i++) cout << (i ? ", " : "") << v[i];
    cout << "]" << endl;
}

int main() {
    vector<string> palavras = {"banana", "kiwi", "uva", "abacaxi", "figo"};
    // por tamanho, e alfabeticamente para desempatar
    vector<string> a = palavras;
    sort(a.begin(), a.end(), [](const string& x, const string& y) {
        return x.size() != y.size() ? x.size() < y.size() : x < y;
    });
    imprimir(a);   // [uva, figo, kiwi, banana, abacaxi]

    // decrescente por tamanho, crescente por texto
    vector<string> b = palavras;
    sort(b.begin(), b.end(), [](const string& x, const string& y) {
        return x.size() != y.size() ? x.size() > y.size() : x < y;
    });
    imprimir(b);   // [abacaxi, banana, figo, kiwi, uva]
}
```

```csharp
    var a = palavras.OrderBy(w => w.Length).ThenBy(w => w, StringComparer.Ordinal);

    var b = palavras.OrderByDescending(w => w.Length).ThenBy(w => w, StringComparer.Ordinal);

    // [abacaxi, banana, figo, kiwi, uva]
}
```

```go
import (
	"fmt"
	"sort"
)

func main() {
	palavras := []string{"banana", "kiwi", "uva", "abacaxi", "figo"}
	// por tamanho, e alfabeticamente para desempatar
	a := append([]string{}, palavras...)
	sort.Slice(a, func(i, j int) bool {
		if len(a[i]) != len(a[j]) {
			return len(a[i]) < len(a[j])
		}
		return a[i] < a[j]
	})
	fmt.Println(a) // [uva figo kiwi banana abacaxi]

	// decrescente por tamanho, crescente por texto
	b := append([]string{}, palavras...)
	sort.Slice(b, func(i, j int) bool {
		if len(b[i]) != len(b[j]) {
			return len(b[i]) > len(b[j])
		}
		return b[i] < b[j]
	})
	fmt.Println(b) // [abacaxi banana figo kiwi uva]
}
```

Tuplas como chave comparam campo a campo, e o sinal negativo inverte a ordem de um campo numérico.

<Callout type="tip" title="Conte o custo do sort">
Se sua solução ordena e depois faz uma passada linear, a complexidade total é O(n log n), não O(n). E `list.sort()` é in-place, enquanto `sorted()` cria uma lista nova com O(n) de espaço.
</Callout>

## Quando reconhecer

Ordenar ajuda quando o enunciado fala em pares ou trincas com soma alvo, intervalos que se sobrepõem, "o k-ésimo maior", agrupar anagramas (ordenar as letras de cada palavra) ou quando você precisa de duplicados lado a lado. Desconfie quando a ordem original importa para a resposta, por exemplo quando o problema pede índices: aí você precisa guardar os índices junto com os valores.

## Na entrevista

Diga qual sort está usando e o custo: "vou usar o sort embutido, O(n log n), estável". Se perguntarem qual algoritmo escolher, raciocine por restrição: memória limitada sugere heap sort ou quick sort; necessidade de estabilidade ou dados em disco sugerem merge sort; valores inteiros num intervalo pequeno sugerem counting sort; dados quase ordenados favorecem insertion sort.
