O array `height` descreve linhas verticais: a linha `i` fica na posição `i` do eixo horizontal e tem altura `height[i]`. Escolha duas linhas que, junto com o eixo, formem um recipiente. A água que ele comporta é a distância entre as linhas multiplicada pela altura da **menor** delas. Retorne a maior quantidade possível.

## Exemplo

```text
Entrada: height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
Saída: 49
Explicação: linhas nas posições 1 (altura 8) e 8 (altura 7): 7 × 7 = 49.
```

## Restrições

- 2 ≤ tamanho de `height` ≤ 10⁵
- 0 ≤ `height[i]` ≤ 10⁴

## Dica

Comece com as duas linhas mais distantes. Ao aproximá-las, a largura sempre diminui: mover qual das duas pode, em algum momento, compensar essa perda?
