Quando um problema pede a soma de muitos intervalos diferentes do mesmo array, recalcular cada soma do zero custa O(n) por consulta. A **soma de prefixos** faz um pré-processamento de O(n) e depois responde qualquer intervalo em **O(1)**.

## A ideia

Defina `prefixo[i]` como a soma dos `i` primeiros elementos. Com um zero no início, a soma do intervalo fechado de `esq` até `dir` vira uma subtração:

`soma(esq, dir) = prefixo[dir + 1] - prefixo[esq]`

Tudo que veio antes de `esq` aparece nos dois termos e se cancela.

```python
def construir_prefixo(nums):
    prefixo = [0] * (len(nums) + 1)
    for i, x in enumerate(nums):
        prefixo[i + 1] = prefixo[i] + x
    return prefixo

def soma_intervalo(prefixo, esq, dir):
    return prefixo[dir + 1] - prefixo[esq]

nums = [3, -1, 4, 1, 5, 9]
p = construir_prefixo(nums)
print(soma_intervalo(p, 1, 3))  # -1 + 4 + 1 = 4
```

<Callout type="tip" title="Por que o zero na frente">
O prefixo com uma posição extra elimina o caso especial de intervalos que começam no índice 0. Sem ele, você precisaria de um `if` em toda consulta, e é exatamente aí que nascem os erros de índice.
</Callout>

## Prefixo combinado com tabela hash

O uso mais poderoso aparece em perguntas do tipo "quantos subarrays somam k?". Um subarray que termina em `j` soma k exatamente quando existe um prefixo anterior igual a `prefixo_atual - k`. Guardando quantas vezes cada prefixo já apareceu, a resposta sai em uma passada.

```python
from collections import defaultdict

def subarrays_com_soma(nums, k):
    contagem = defaultdict(int)
    contagem[0] = 1          # o prefixo vazio
    atual = 0
    total = 0
    for x in nums:
        atual += x
        total += contagem[atual - k]
        contagem[atual] += 1
    return total

print(subarrays_com_soma([1, 1, 1], 2))      # 2
print(subarrays_com_soma([1, 2, 3, -3], 3))  # 3
```

Essa versão funciona mesmo com números negativos, situação em que a janela deslizante falha, porque aumentar a janela já não garante aumentar a soma.

## Variações que valem conhecer

| Variação | Ideia |
| --- | --- |
| Prefixo 2D | `P[i][j]` guarda a soma do retângulo do canto até `(i, j)`; consultas por inclusão e exclusão |
| Prefixo de contagens | Prefixo de quantas vezes algo ocorreu (vogais, uns, letras) |
| Prefixo de XOR | O XOR de um intervalo também se cancela, como a soma |
| Produto exceto o próprio | Prefixo e sufixo de produtos, sem usar divisão |

## Na entrevista

Os sinais são "soma de subarray", "várias consultas de intervalo" e "quantos subarrays satisfazem". Diga explicitamente o custo: O(n) para montar, O(1) por consulta e O(n) de espaço extra. Se o array mudar entre as consultas, a soma de prefixos deixa de servir e a conversa passa para estruturas como a árvore de Fenwick, o que mostra ao entrevistador que você conhece o limite da técnica.
