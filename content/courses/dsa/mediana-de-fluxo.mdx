Implemente a classe `MedianFinder`, que recebe números inteiros um de cada vez e consegue informar, a qualquer momento, a mediana de todos os números recebidos até então. A mediana é o valor do meio da coleção ordenada; se a quantidade de números for par, é a média dos dois valores centrais.

- `MedianFinder()` cria a estrutura vazia.
- `addNum(num)` acrescenta `num` à coleção (em Python, `add_num`).
- `findMedian()` retorna a mediana atual (em Python, `find_median`). Só é chamado quando há pelo menos um número.

Cada teste é uma sequência de chamadas; a saída esperada lista o retorno de cada uma (`null` para o construtor e para `addNum`).

## Exemplo

```text
Chamadas: MedianFinder(), addNum(1), addNum(2), findMedian(), addNum(3), findMedian()
Saída:    [null, null, null, 1.5, null, 2]
Explicação: com [1, 2] a mediana é 1.5; com [1, 2, 3] é 2.
```

## Restrições

- -100.000 ≤ `num` ≤ 100.000
- Até 50.000 chamadas no total.
- `addNum` deve ser O(log n) e `findMedian` O(1).

## Dica

Divida os números em duas metades: a metade menor num max-heap e a metade maior num min-heap. Se você mantiver os tamanhos equilibrados (diferença de no máximo 1), a mediana sai direto dos topos dos heaps.
