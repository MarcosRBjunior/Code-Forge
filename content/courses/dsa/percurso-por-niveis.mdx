Dada a raiz `root` de uma árvore binária, retorne os valores dos nós agrupados por nível: primeiro uma lista só com a raiz, depois uma lista com os nós da profundidade 1, e assim por diante. Dentro de cada nível, os valores aparecem da esquerda para a direita.

Para uma árvore vazia, retorne uma lista vazia.

## Exemplo

```text
Entrada: [3, 9, 20, null, null, 15, 7]
      3
     / \
    9   20
       /  \
      15   7
Saída: [[3], [9, 20], [15, 7]]
```

## Restrições

- 0 ≤ número de nós ≤ 2000
- -1000 ≤ `val` ≤ 1000

## Dica

Uma fila percorre a árvore em largura. O truque para separar os níveis é olhar o tamanho da fila no início de cada rodada: exatamente esses nós formam o nível atual.
