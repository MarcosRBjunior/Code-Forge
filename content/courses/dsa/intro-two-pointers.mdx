A técnica de **dois ponteiros** percorre uma estrutura com dois índices ao mesmo tempo, evitando o laço aninhado que levaria a O(n²).

## Quando usar

Procure por estes sinais no enunciado:

- O array está **ordenado**, ou ordená-lo não atrapalha.
- Você precisa encontrar um **par** ou uma **subsequência** com alguma propriedade.
- A solução deve ser **in-place**, com O(1) de espaço extra.

## As duas variações

**Ponteiros opostos:** um começa no início e outro no fim, e eles se aproximam. É o caso clássico de encontrar um par com soma alvo em um array ordenado.

```python
def par_com_soma(nums, alvo):
    esq, dir = 0, len(nums) - 1
    while esq < dir:
        soma = nums[esq] + nums[dir]
        if soma == alvo:
            return [esq, dir]
        if soma < alvo:
            esq += 1   # precisamos de uma soma maior
        else:
            dir -= 1   # precisamos de uma soma menor
    return []
```

**Leitura e escrita:** os dois ponteiros andam na mesma direção. Um lê cada elemento e o outro marca onde escrever o próximo elemento válido. É a base de problemas como remover duplicados ou mover zeros.

<Callout type="tip" title="Por que funciona">
Em cada passo, um ponteiro avança e descarta uma possibilidade que comprovadamente não leva à resposta. Como cada ponteiro anda no máximo n posições, o total é O(n).
</Callout>
