Você recebe dois arrays de inteiros: `preorder`, com os valores de uma árvore binária na ordem raiz-esquerda-direita, e `inorder`, com os valores da mesma árvore na ordem esquerda-raiz-direita. Reconstrua a árvore original e retorne a sua raiz.

Todos os valores são distintos, o que garante que a árvore é única. Os arrays de entrada são listas comuns; você deve criar os nós com `TreeNode`.

## Exemplo

```text
Entrada: preorder = [3, 9, 20, 15, 7], inorder = [9, 3, 15, 20, 7]
Saída: [3, 9, 20, null, null, 15, 7]
      3
     / \
    9   20
       /  \
      15   7
```

## Restrições

- 0 ≤ tamanho ≤ 3000, e os dois arrays têm o mesmo tamanho
- Os valores são distintos.

## Dica

O primeiro elemento de `preorder` é sempre a raiz. Ao achar essa raiz em `inorder`, tudo o que está à esquerda dela forma a subárvore esquerda, e você sabe quantos elementos ela tem. Um dicionário valor → índice evita buscas lineares.
