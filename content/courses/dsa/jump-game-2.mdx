Você começa no índice 0 de `nums`. O valor `nums[i]` é o **alcance máximo** de um salto a partir de `i`: dali você pode ir para qualquer índice entre `i + 1` e `i + nums[i]`.

É garantido que o último índice é alcançável. Retorne o **menor número de saltos** para chegar até ele. Se o array tiver um único elemento, você já está no fim.

## Exemplo

```text
Entrada: nums = [2, 3, 1, 1, 4]
Saída: 2
Explicação: salte do índice 0 para o 1 e, de lá, direto para o 4.
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 10⁴
- 0 ≤ `nums[i]` ≤ 1000
- O último índice sempre é alcançável.

## Dica

Pense em "camadas", como numa BFS: todos os índices alcançáveis com `k` saltos formam um intervalo contíguo. Enquanto percorre esse intervalo, calcule até onde o próximo salto pode chegar.
