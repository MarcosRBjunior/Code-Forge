Dado um array de inteiros `nums`, sem ordem definida, retorne o tamanho da maior sequência de **valores consecutivos** (como 4, 5, 6, 7) que pode ser formada com os elementos do array. Os elementos não precisam estar lado a lado no array, e valores repetidos contam uma vez só.

O algoritmo deve rodar em O(n), então ordenar o array não vale.

## Exemplo

```text
Entrada: nums = [100, 4, 200, 1, 3, 2]
Saída: 4
Explicação: a maior sequência é 1, 2, 3, 4.
```

## Restrições

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## Dica

Coloque tudo num conjunto. Um número `x` só é o **início** de uma sequência se `x - 1` não estiver no conjunto. Conte a partir dos inícios e cada número será visitado poucas vezes.
