Todo inteiro que você usa no código é guardado como uma sequência de bits. Manipular bits é operar direto sobre essa sequência: ligar, desligar e testar posições individuais, ou combinar dois números posição a posição. É rápido, usa memória constante e aparece em entrevistas porque transforma problemas aparentemente difíceis em poucas linhas.

## Os operadores

| Operador | Nome | Regra | Exemplo |
|---|---|---|---|
| `a & b` | E | 1 só se os dois bits forem 1 | `0b1100 & 0b1010 = 0b1000` |
| `a \| b` | OU | 1 se pelo menos um bit for 1 | `0b1100 \| 0b1010 = 0b1110` |
| `a ^ b` | XOR | 1 se os bits forem diferentes | `0b1100 ^ 0b1010 = 0b0110` |
| `~a` | NÃO | inverte todos os bits | `~0 = -1` |
| `a << k` | deslocar à esquerda | multiplica por 2^k | `3 << 2 = 12` |
| `a >> k` | deslocar à direita | divide por 2^k (arredonda para baixo) | `13 >> 2 = 3` |

O XOR é o mais cobrado. Duas propriedades resolvem muitos problemas: `x ^ x = 0` e `x ^ 0 = x`. Além disso, ele é comutativo e associativo, então a ordem não importa.

## Operações sobre um bit

Para trabalhar na posição `i` (contando da direita, a partir de 0), crie uma máscara com `1 << i`.

```python
def ler_bit(n, i):
    return (n >> i) & 1

def ligar_bit(n, i):
    return n | (1 << i)

def desligar_bit(n, i):
    return n & ~(1 << i)

def alternar_bit(n, i):
    return n ^ (1 << i)
```

## Truques que valem decorar

```python
n & (n - 1)      # desliga o bit 1 mais baixo de n
n & -n           # isola o bit 1 mais baixo de n
n & 1            # 1 se n é ímpar
(n & (n - 1)) == 0 and n > 0   # n é potência de dois
```

Por que `n & (n - 1)` funciona: subtrair 1 inverte o bit 1 mais baixo e todos os zeros à direita dele. O E com o original zera exatamente essa região.

```text
n      = 1 0 1 1 0 0
n - 1  = 1 0 1 0 1 1
n&(n-1)= 1 0 1 0 0 0   ← o último 1 sumiu
```

Repetir essa operação até chegar a zero conta quantos bits 1 o número tem, em tempo proporcional a essa quantidade e não ao tamanho da palavra.

## Exemplo: o número que aparece uma vez

Num array em que todo valor aparece duas vezes, menos um, o XOR de todos os elementos devolve o valor único. Os pares se cancelam (`x ^ x = 0`) e sobra o resto.

```python
def numero_unico(nums):
    resultado = 0
    for x in nums:
        resultado ^= x
    return resultado
```

São O(n) de tempo e O(1) de memória, contra O(n) de memória de uma solução com conjunto.

## Bitmask como conjunto

Se o universo tem poucos elementos (até 20 ou 30), um inteiro representa um subconjunto: o bit `i` ligado significa "o elemento `i` está no conjunto". Enumerar todos os subconjuntos de `n` elementos vira um laço de `0` a `2^n - 1`.

```python
def todos_subconjuntos(itens):
    n = len(itens)
    for mascara in range(1 << n):
        yield [itens[i] for i in range(n) if mascara >> i & 1]
```

## Armadilhas

- **Precedência:** em Python, JavaScript e Java, `==` tem precedência maior que `&`. Escreva `(n & 1) == 0` com parênteses.
- **Números negativos:** são guardados em complemento de dois. Em Python os inteiros têm tamanho ilimitado, então `~x` é `-x - 1` e não há "overflow". Em Java e C++ a largura é fixa (32 ou 64 bits).
- **JavaScript:** os operadores de bits convertem o valor para inteiro de 32 bits com sinal. Para valores maiores, use `BigInt`.
- **Deslocamento à direita:** `>>` preserva o sinal; em JavaScript, `>>>` desloca sem sinal.

## Na entrevista

Bits aparecem quando o enunciado pede memória constante, fala em "aparece uma vez", "potência de dois", "subconjuntos" ou "sem usar operadores aritméticos". Se a solução óbvia usa um conjunto ou um dicionário, pergunte a si mesmo se XOR ou uma máscara resolvem. Follow-ups comuns: "e se houver dois números únicos?" (separe o array pelo bit em que eles diferem) e "e se cada valor aparecer três vezes?" (conte os bits por posição, módulo 3).
