A **Fenwick tree**, também chamada de *Binary Indexed Tree* (BIT), resolve o mesmo problema central da segment tree, somas de intervalo com atualizações pontuais, as duas em O(log n). A diferença é o tamanho do código: são cerca de dez linhas, num vetor simples, sem recursão. Quando a operação é soma (ou outra com inverso), ela costuma ser a escolha mais rápida de escrever.

## A ideia

Cada posição `i` do vetor interno (indexado a partir de 1) guarda a soma de um bloco de elementos que **termina em i**. O tamanho do bloco é dado pelo bit menos significativo de `i`, que você obtém com `i & -i`:

```text
i (binário)   i & -i   bloco guardado em bit[i]
 1 = 0001       1       nums[1]
 2 = 0010       2       nums[1..2]
 3 = 0011       1       nums[3]
 4 = 0100       4       nums[1..4]
 5 = 0101       1       nums[5]
 6 = 0110       2       nums[5..6]
 8 = 1000       8       nums[1..8]
```

Com isso, as duas operações viram laços sobre bits:

- **Prefixo até i:** some `bit[i]` e pule para `i - (i & -i)`, o início do bloco anterior. Cada passo apaga um bit 1, então são no máximo log n passos.
- **Atualizar a posição i:** some o delta em `bit[i]` e suba para `i + (i & -i)`, o próximo bloco que também cobre i. Cada passo empurra o bit menos significativo para cima, também em log n passos.

A soma de um intervalo `[esq, dir]` é `prefixo(dir) - prefixo(esq - 1)`.

## Implementação

<CodeTabs>

```python
class FenwickTree:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)            # índice 0 não é usado

    def somar(self, i, delta):              # nums[i] += delta (i começa em 0)
        i += 1
        while i <= self.n:
            self.bit[i] += delta
            i += i & -i                     # sobe para o próximo responsável

    def prefixo(self, i):                   # soma de nums[0..i]
        i += 1
        total = 0
        while i > 0:
            total += self.bit[i]
            i -= i & -i                     # remove o bit menos significativo
        return total

    def intervalo(self, esq, dir):
        return self.prefixo(dir) - (self.prefixo(esq - 1) if esq > 0 else 0)

nums = [5, 2, 8, 1, 4, 7]
ft = FenwickTree(len(nums))
for i, x in enumerate(nums):
    ft.somar(i, x)
print(ft.intervalo(1, 3))   # 11
ft.somar(2, -5)             # 8 vira 3
print(ft.intervalo(1, 3))   # 6
print(ft.prefixo(5))        # 17
```

```go
import "fmt"

type FenwickTree struct {
	n   int
	bit []int
}

func novaFenwick(n int) *FenwickTree {
	return &FenwickTree{n: n, bit: make([]int, n+1)} // índice 0 não é usado
}

func (f *FenwickTree) somar(i, delta int) { // nums[i] += delta (i começa em 0)
	for i++; i <= f.n; i += i & -i { // sobe para o próximo responsável
		f.bit[i] += delta
	}
}

func (f *FenwickTree) prefixo(i int) int { // soma de nums[0..i]
	total := 0
	for i++; i > 0; i -= i & -i { // remove o bit menos significativo
		total += f.bit[i]
	}
	return total
}

func (f *FenwickTree) intervalo(esq, dir int) int {
	if esq > 0 {
		return f.prefixo(dir) - f.prefixo(esq-1)
	}
	return f.prefixo(dir)
}

func main() {
	nums := []int{5, 2, 8, 1, 4, 7}
	ft := novaFenwick(len(nums))
	for i, x := range nums {
		ft.somar(i, x)
	}
	fmt.Println(ft.intervalo(1, 3)) // 11
	ft.somar(2, -5)                 // 8 vira 3
	fmt.Println(ft.intervalo(1, 3)) // 6
	fmt.Println(ft.prefixo(5))      // 17
}
```

</CodeTabs>

Repare que `somar` recebe um **delta**, não o novo valor. Para "definir nums[i] = v", guarde uma cópia do array e chame `somar(i, v - nums[i])`.

**Complexidade:** O(log n) para `somar` e `prefixo`, O(n) de espaço. Construir com n chamadas a `somar` custa O(n log n), o que basta em entrevista.

## Exemplo: contar inversões

Uma inversão é um par `i < j` com `nums[i] > nums[j]`. Percorra da direita para a esquerda e, para cada número, pergunte à Fenwick quantos menores já foram vistos. Os valores são primeiro comprimidos para postos de 0 a k-1, para o vetor não depender do tamanho dos números.

<CodeTabs>

```python
def contar_inversoes(nums):
    ordenados = sorted(set(nums))
    posto = {v: i for i, v in enumerate(ordenados)}
    ft = FenwickTree(len(ordenados))
    inversoes = 0
    for x in reversed(nums):
        p = posto[x]
        if p > 0:
            inversoes += ft.prefixo(p - 1)  # menores já vistos à direita
        ft.somar(p, 1)
    return inversoes

print(contar_inversoes([3, 1, 2, 5, 4]))   # 3
```

```javascript
function contarInversoes(nums) {
  const ordenados = [...new Set(nums)].sort((a, b) => a - b);
  const posto = new Map(ordenados.map((v, i) => [v, i]));
  const ft = new FenwickTree(ordenados.length);
  let inversoes = 0;
  for (let k = nums.length - 1; k >= 0; k--) {
    const p = posto.get(nums[k]);
    if (p > 0) {
      inversoes += ft.prefixo(p - 1);   // menores já vistos à direita
    }
    ft.somar(p, 1);
  }
  return inversoes;
}

console.log(contarInversoes([3, 1, 2, 5, 4]));   // 3
```

## Fenwick ou segment tree?

| Critério | Fenwick | Segment tree |
| --- | --- | --- |
| Código | ~10 linhas | ~30 linhas |
| Soma, XOR | Sim | Sim |
| Mínimo, máximo com atualização | Não (sem inverso) | Sim |
| Atualização em intervalo | Com truques | Lazy propagation |
| Constante de tempo | Menor | Maior |

<Callout type="warning" title="Cuidado com o índice">
A Fenwick é naturalmente indexada a partir de 1, porque `0 & -0` é 0 e o laço nunca sairia do lugar. Faça o `i += 1` na entrada das funções e trabalhe com índices de 0 no resto do código.
</Callout>
