JavaScript é uma escolha comum para quem vem de front-end, mas a biblioteca padrão é mais enxuta que a do Python: não há heap nem deque prontos. Esta folha de consulta reúne o que você precisa saber para não perder tempo com a linguagem durante a entrevista.

## Arrays

```javascript
const nums = [5, 2, 8, 1];
nums.push(3);              // O(1) amortizado
const ultimo = nums.pop(); // O(1)
nums.shift();              // O(n)! remove do início deslocando tudo
nums.sort((a, b) => a - b); // SEMPRE passe comparador para números
const grade = Array.from({ length: 3 }, () => new Array(4).fill(0));
const invertido = [...nums].reverse(); // cópia antes de inverter
console.log(nums, ultimo, grade[0], invertido);
console.log(nums.includes(8), nums.indexOf(8)); // O(n)
```

Sem comparador, `sort` converte para string: `[10, 9, 1].sort()` vira `[1, 10, 9]`. É o bug de JavaScript mais comum em entrevistas.

## Map e Set

```javascript
const freq = new Map();
for (const c of "banana") {
  freq.set(c, (freq.get(c) ?? 0) + 1);
}
console.log(freq.get("a"), freq.has("z"), freq.size); // 3 false 3

const vistos = new Set([1, 2, 3]);
vistos.add(4);
console.log(vistos.has(2), [...vistos]);

// Chaves compostas: Map compara objetos por referência, então use string
const visitado = new Set();
visitado.add(`${1},${2}`);
console.log(visitado.has("1,2")); // true
```

Prefira `Map` a objeto literal para contagens: as chaves não viram string implicitamente, não há colisão com propriedades herdadas e `size` é O(1).

## Pilha e fila

A pilha é um array com `push` e `pop`. Para fila, evite `shift` em laços grandes; use um índice de leitura:

```javascript
const fila = [1, 2, 3];
let inicio = 0;
while (inicio < fila.length) {
  const x = fila[inicio++]; // O(1) por remoção
  if (x < 3) fila.push(x + 10);
}
console.log(fila.slice(inicio), fila.length); // [] 5
```

## Heap mínimo enxuto

Quando o problema pede fila de prioridade, escreva uma. São cerca de 30 linhas e vale tê-las decoradas:

```javascript
class MinHeap {
  constructor() { this.a = []; }
  get size() { return this.a.length; }
  peek() { return this.a[0]; }
  push(x) {
    const a = this.a; a.push(x);
    let i = a.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (a[p] <= a[i]) break;
      [a[p], a[i]] = [a[i], a[p]]; i = p;
    }
  }
  pop() {
    const a = this.a, topo = a[0], fim = a.pop();
    if (a.length) {
      a[0] = fim;
      let i = 0;
      for (;;) {
        const l = 2 * i + 1, r = l + 1;
        let m = i;
        if (l < a.length && a[l] < a[m]) m = l;
        if (r < a.length && a[r] < a[m]) m = r;
        if (m === i) break;
        [a[m], a[i]] = [a[i], a[m]]; i = m;
      }
    }
    return topo;
  }
}
const h = new MinHeap();
[5, 1, 4, 2].forEach((x) => h.push(x));
console.log(h.pop(), h.pop(), h.size); // 1 2 2
```

Para ordenar por prioridade de objetos, troque as comparações `<` e `<=` por uma função comparadora recebida no construtor.

## Strings e números

```javascript
const s = "entrevista";
console.log(s[0], s.charCodeAt(0) - 97, String.fromCharCode(98));
console.log(s.split("").sort().join(""));    // ordenar caracteres
console.log(Math.floor(-7 / 2), Math.trunc(-7 / 2)); // -4 -3
console.log(Number.MAX_SAFE_INTEGER);        // 2^53 - 1
console.log(10n ** 20n);                     // BigInt para inteiros enormes
console.log(Infinity > 1e18, Math.max(...[3, 9, 2]));
```

Divisão sempre devolve ponto flutuante: use `Math.floor` ou `Math.trunc` para inteiros. Acima de 2⁵³ os inteiros perdem precisão, o que importa em problemas com módulo de 10⁹ + 7 e multiplicações; nesse caso use `BigInt` ou reduza o módulo antes de multiplicar.

<Callout type="warning" title="Cuidado com o spread em arrays grandes">
`Math.max(...arr)` passa cada elemento como argumento e pode estourar a pilha com centenas de milhares de itens. Em entradas grandes, use um laço ou `arr.reduce((m, x) => Math.max(m, x), -Infinity)`.
</Callout>

## Igualdade e cópias

Use sempre `===`, que não faz conversão de tipo. Lembre que arrays e objetos são comparados por referência: `[1, 2] === [1, 2]` é falso. Para comparar conteúdo de arrays pequenos, compare elemento a elemento ou serialize com `join`. O spread `[...a]` e `{ ...obj }` fazem cópia **rasa**: numa matriz, as linhas internas continuam compartilhadas, então copie com `grade.map((linha) => [...linha])`. Em backtracking, esse detalhe decide se a lista de respostas guarda caminhos distintos ou várias referências ao mesmo array que depois foi esvaziado.

## Tabela de custos

| Operação | Custo |
| --- | --- |
| `push`, `pop` | O(1) amortizado |
| `shift`, `unshift`, `splice` no início | O(n) |
| `includes`, `indexOf` | O(n) |
| `Map`/`Set`: `get`, `set`, `has`, `delete` | O(1) médio |
| `sort` | O(n log n) |
| `slice`, spread `[...a]` | O(n) |

## Na entrevista

Diga logo que JavaScript não tem heap nativo e pergunte se pode assumir uma implementação pronta; muitos entrevistadores aceitam. Se não aceitarem, a classe acima resolve. Use `const` e `let`, nunca `var`, e prefira `for...of` para legibilidade.
