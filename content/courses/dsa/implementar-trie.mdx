Uma **trie** (árvore de prefixos) guarda palavras caractere por caractere, compartilhando os prefixos comuns. Implemente a classe `Trie` com:

- `insert(word)`: adiciona a palavra.
- `search(word)`: retorna verdadeiro se **exatamente** essa palavra foi inserida antes.
- `startsWith(prefix)`: retorna verdadeiro se alguma palavra inserida começa com `prefix` (em Python, o método pode se chamar `starts_with`).

Cada teste é uma sequência de chamadas: a primeira cria o objeto e as seguintes são os métodos, com os retornos comparados na ordem.

## Exemplo

```text
Operações: Trie(), insert("maca"), search("maca"), search("mac"), startsWith("mac"), insert("mac"), search("mac")
Saída:     null,   null,          true,            false,          true,               null,          true
```

## Restrições

- 1 ≤ tamanho de `word` e `prefix` ≤ 2000
- Só letras minúsculas de `a` a `z`.
- No máximo 3 × 10⁴ chamadas.

## Dica

Cada nó é um mapa de caractere para filho. O que diferencia o nó do fim de "mac" quando "mac" é só prefixo de "maca" e quando também foi inserida como palavra?
