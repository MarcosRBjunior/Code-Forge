Implemente uma pilha que, além das operações de sempre, informe o menor elemento armazenado. **Todas** as operações devem rodar em O(1):

- `MinStack()`: cria a pilha vazia.
- `push(val)`: empilha `val`.
- `pop()`: remove o elemento do topo (não retorna nada).
- `top()`: retorna o elemento do topo.
- `getMin()`: retorna o menor elemento da pilha.

`pop`, `top` e `getMin` só são chamados com a pilha não vazia. Em Python, o método pode se chamar `get_min`.

## Exemplo

```text
push(-2), push(0), push(-3)
getMin() -> -3
pop()
top()    -> 0
getMin() -> -2
```

## Restrições

- -2³¹ ≤ `val` ≤ 2³¹ - 1
- Até 3 × 10⁴ operações.

## Dica

O mínimo muda quando você desempilha. Que tal guardar, junto de cada elemento, qual era o mínimo da pilha no momento em que ele entrou?
