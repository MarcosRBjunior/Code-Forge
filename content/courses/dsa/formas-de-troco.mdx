Você tem moedas dos valores em `coins`, com quantidade **ilimitada** de cada uma. Retorne de quantas maneiras diferentes é possível formar exatamente o valor `amount`.

Duas maneiras são iguais se usam as mesmas quantidades de cada moeda, não importa a ordem: `1 + 2` e `2 + 1` contam como uma só. Formar o valor `0` tem exatamente uma maneira, que é não usar moeda nenhuma.

## Exemplo

```text
Entrada: amount = 5, coins = [1, 2, 5]
Saída: 4
Explicação: 5, 2 + 2 + 1, 2 + 1 + 1 + 1 e 1 + 1 + 1 + 1 + 1.
```

## Restrições

- 0 ≤ `amount` ≤ 5000
- 1 ≤ tamanho de `coins` ≤ 300, valores distintos entre 1 e 5000.

## Dica

Use `dp[v]` = número de formas de montar `v`. Para não contar a mesma combinação em ordens diferentes, o laço **externo** deve percorrer as moedas e o interno, os valores.
