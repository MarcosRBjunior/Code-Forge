Imagine uma rede social em que amizades chegam uma de cada vez, e a qualquer momento alguém pergunta: "Ana e Bruno estão no mesmo grupo, direta ou indiretamente?". Refazer uma BFS a cada pergunta custaria O(V + E) por consulta. O **Union-Find** (também chamado de *Disjoint Set Union*, DSU) responde em tempo praticamente constante, e permite juntar grupos com a mesma eficiência.

## A ideia

Cada conjunto é uma árvore, e a raiz é o **representante** do conjunto. Duas operações:

- `find(x)`: sobe pelos pais até a raiz e devolve o representante de x.
- `union(a, b)`: encontra as raízes de a e de b e, se forem diferentes, pendura uma na outra.

Dois elementos estão no mesmo conjunto se e somente se `find` devolve a mesma raiz para ambos.

```text
Inicial:  0  1  2  3  4      (cada um é a própria raiz)
union(0,1), union(2,3), union(1,3):

      0          4
     / \
    1   2
        |
        3
find(3) → 2 → 0      find(4) → 4
```

## As duas otimizações

Sem cuidados, as árvores podem virar listas longas, e `find` passa a custar O(n). Duas técnicas resolvem isso:

1. **Compressão de caminho:** durante o `find`, faça cada nó visitado apontar direto para a raiz. As próximas consultas ficam curtas.
2. **União por tamanho (ou por posto):** ao unir, pendure a árvore menor na maior. A altura cresce devagar.

Com as duas, o custo amortizado por operação é O(α(n)), em que α é a inversa da função de Ackermann. Para qualquer n que caiba no universo, α(n) é no máximo 4, então na prática é constante.

```python
class UnionFind:
    def __init__(self, n):
        self.pai = list(range(n))
        self.tamanho = [1] * n
        self.componentes = n

    def find(self, x):
        raiz = x
        while self.pai[raiz] != raiz:
            raiz = self.pai[raiz]
        while self.pai[x] != raiz:          # compressão de caminho
            self.pai[x], x = raiz, self.pai[x]
        return raiz

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False                    # já estavam juntos
        if self.tamanho[ra] < self.tamanho[rb]:
            ra, rb = rb, ra
        self.pai[rb] = ra                   # menor embaixo do maior
        self.tamanho[ra] += self.tamanho[rb]
        self.componentes -= 1
        return True

uf = UnionFind(5)
uf.union(0, 1); uf.union(2, 3); uf.union(1, 3)
print(uf.find(3) == uf.find(0), uf.find(4) == uf.find(0))  # True False
print(uf.componentes)                                      # 2
```

class UnionFind {
  constructor(n) {
    this.pai = Array.from({ length: n }, (_, i) => i);
    this.tamanho = new Array(n).fill(1);
    this.componentes = n;
  }

  find(x) {
    let raiz = x;
    while (this.pai[raiz] !== raiz) {
      raiz = this.pai[raiz];
    }
    while (this.pai[x] !== raiz) {          // compressão de caminho
      const prox = this.pai[x];
      this.pai[x] = raiz;
      x = prox;
    }
    return raiz;
  }

  union(a, b) {
    let ra = this.find(a), rb = this.find(b);
    if (ra === rb) {
      return false;                         // já estavam juntos
    }
    if (this.tamanho[ra] < this.tamanho[rb]) {
      [ra, rb] = [rb, ra];
    }
    this.pai[rb] = ra;                      // menor embaixo do maior
    this.tamanho[ra] += this.tamanho[rb];
    this.componentes--;
    return true;
  }
}

#include <iostream>
#include <numeric>
#include <utility>
#include <vector>
using namespace std;

class UnionFind {
    vector<int> pai, tamanho;

public:
    int componentes;

    UnionFind(int n) : pai(n), tamanho(n, 1), componentes(n) {
        iota(pai.begin(), pai.end(), 0);
    }

    int find(int x) {
        int raiz = x;
        while (pai[raiz] != raiz) {
            raiz = pai[raiz];
        }
        while (pai[x] != raiz) {            // compressão de caminho
            int prox = pai[x];
            pai[x] = raiz;
            x = prox;
        }
        return raiz;
    }

    bool unir(int a, int b) {               // "union" é palavra reservada em C++
        int ra = find(a), rb = find(b);
        if (ra == rb) {
            return false;                   // já estavam juntos
        }
        if (tamanho[ra] < tamanho[rb]) {
            swap(ra, rb);
        }
        pai[rb] = ra;                       // menor embaixo do maior
        tamanho[ra] += tamanho[rb];
        componentes--;
        return true;
    }
};

int main() {
    UnionFind uf(5);
    uf.unir(0, 1); uf.unir(2, 3); uf.unir(1, 3);
    cout << boolalpha << (uf.find(3) == uf.find(0)) << " " << (uf.find(4) == uf.find(0)) << endl;  // true false
    cout << uf.componentes << endl;                                                                // 2
}

**Complexidade:** O(α(n)) amortizado por `find` ou `union`, e O(n) de espaço para os vetores `pai` e `tamanho`.

## Exemplo: aresta redundante

Num grafo que deveria ser uma árvore, uma aresta a mais criou um ciclo. Qual é ela? Processe as arestas em ordem: a primeira cujo `union` falha liga dois vértices que já estavam conectados, e portanto fecha o ciclo.

<CodeTabs>

```python
def aresta_redundante(n, arestas):
    pai = list(range(n))
    def find(x):
        while pai[x] != x:
            pai[x] = pai[pai[x]]            # compressão por "meio caminho"
            x = pai[x]
        return x
    for u, v in arestas:
        ru, rv = find(u), find(v)
        if ru == rv:
            return (u, v)
        pai[ru] = rv
    return None

print(aresta_redundante(4, [(0, 1), (1, 2), (2, 3), (3, 1)]))  # (3, 1)
```

## Quando reconhecer

- O enunciado fala em **grupos**, **componentes conectados**, **equivalência** ou "estão ligados direta ou indiretamente".
- As conexões chegam **incrementalmente** e há consultas no meio.
- É preciso detectar se uma nova aresta forma **ciclo** num grafo não dirigido.
- Problemas como juntar contas com e-mails em comum, contar províncias ou o algoritmo de Kruskal.

O Union-Find não sabe **remover** arestas nem dizer o caminho entre dois vértices. Se o problema exige isso, use BFS ou DFS.
