Você recebe as raízes `p` e `q` de duas árvores binárias. Diga se elas são iguais: precisam ter exatamente o mesmo formato e, em cada posição, nós com o mesmo valor.

Duas árvores vazias são iguais entre si.

## Exemplo

```text
Entrada: p = [1, 2], q = [1, null, 2]
    1        1
   /          \
  2            2
Saída: false
Explicação: os valores são os mesmos, mas o 2 está em lados diferentes.
```

## Restrições

- 0 ≤ número de nós em cada árvore ≤ 100
- -10.000 ≤ `val` ≤ 10.000

## Dica

Compare as raízes e, se baterem, delegue a pergunta para os pares de subárvores (esquerda com esquerda, direita com direita). Pense com cuidado nos casos em que um dos lados é vazio.
