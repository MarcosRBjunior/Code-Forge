Implemente a conversão de uma string `s` num inteiro com sinal de 32 bits, seguindo estas regras, nesta ordem:

1. Ignore os espaços em branco do início.
2. Se o próximo caractere for `+` ou `-`, ele define o sinal (sem nenhum, o número é positivo). Só um sinal é aceito.
3. Leia os dígitos seguintes até encontrar um caractere que não seja dígito ou até a string acabar. Zeros à esquerda não mudam o valor. Se nenhum dígito foi lido, o resultado é `0`.
4. Se o valor sair do intervalo de `-2^31` a `2^31 - 1`, prenda-o no limite mais próximo.

Não use as funções de conversão da linguagem (`int`, `parseInt`, `Number`) sobre a string inteira: o exercício é justamente tratar cada caso de borda.

## Exemplo

```text
Entrada: s = "   -042"
Saída: -42

Entrada: s = "1337c0d3"
Saída: 1337
Explicação: a leitura para no "c".
```

## Restrições

- `0 <= s.length <= 200`
- `s` tem letras, dígitos, espaços, `+`, `-` e `.`

## Dica

Escreva o código como uma pequena máquina de estados: espaços, depois sinal, depois dígitos. Acumule com `valor * 10 + digito` e verifique o limite a cada passo.
