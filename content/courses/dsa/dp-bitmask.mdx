Alguns problemas pedem que você escolha uma **ordem** ou uma **atribuição** entre poucos itens: visitar todas as cidades pelo menor custo, dividir tarefas entre pessoas, formar pares. Testar todas as permutações custa O(n!), o que já é inviável para n = 12. Mas, em muitos deles, o futuro só depende de **quais** itens já foram usados, e não da ordem em que foram usados. Esse "quais" é um subconjunto, e um subconjunto de até ~20 itens cabe num inteiro: a **bitmask**.

## Representando subconjuntos

O bit `i` da máscara diz se o item `i` está no conjunto. As operações de que você precisa:

- Item i está no conjunto? `mascara & (1 << i)`
- Adicionar i: `mascara | (1 << i)`
- Remover i: `mascara & ~(1 << i)`
- Conjunto com todos os n itens: `(1 << n) - 1`
- Tamanho do conjunto: `bin(mascara).count("1")`

Com n itens, existem `2^n` máscaras. Para n = 20, são cerca de um milhão de estados, o que é viável.

## Exemplo: caixeiro-viajante

Partindo da cidade 0, visite todas exatamente uma vez e volte, com custo mínimo. O estado é `(mascara, atual)`: quais cidades já foram visitadas e onde você está. A transição escolhe a próxima cidade ainda fora da máscara.

<CodeTabs>

```python
from functools import lru_cache

def menor_rota(dist):
    n = len(dist)
    TODAS = (1 << n) - 1

    @lru_cache(maxsize=None)
    def dp(mascara, atual):
        if mascara == TODAS:
            return dist[atual][0]           # fecha o ciclo
        melhor = float("inf")
        for prox in range(n):
            if not mascara & (1 << prox):   # prox ainda não visitada
                custo = dist[atual][prox] + dp(mascara | (1 << prox), prox)
                melhor = min(melhor, custo)
        return melhor

    return dp(1, 0)                          # só a cidade 0 visitada

dist = [
    [0, 10, 15, 20],
    [10, 0, 35, 25],
    [15, 35, 0, 30],
    [20, 25, 30, 0],
]
print(menor_rota(dist))   # 80
```

```javascript
function menorRota(dist) {
  const n = dist.length;
  const TODAS = (1 << n) - 1;
  const memo = new Map();

  function dp(mascara, atual) {
    if (mascara === TODAS) {
      return dist[atual][0];                 // fecha o ciclo
    }
    const chave = mascara * n + atual;
    if (memo.has(chave)) {
      return memo.get(chave);
    }
    let melhor = Infinity;
    for (let prox = 0; prox < n; prox++) {
      if (!(mascara & (1 << prox))) {        // prox ainda não visitada
        const custo = dist[atual][prox] + dp(mascara | (1 << prox), prox);
        melhor = Math.min(melhor, custo);
      }
    }
    memo.set(chave, melhor);
    return melhor;
  }

  return dp(1, 0);                           // só a cidade 0 visitada
}

const dist = [
  [0, 10, 15, 20],
  [10, 0, 35, 25],
  [15, 35, 0, 30],
  [20, 25, 30, 0],
];
console.log(menorRota(dist));   // 80
```

```java
import java.util.*;

static int n;
static int[][] dist;
static int[][] memo;   // memo[mascara][atual]; -1 = ainda não calculado

static int dp(int mascara, int atual) {
    if (mascara == (1 << n) - 1) {
        return dist[atual][0];                   // fecha o ciclo
    }
    if (memo[mascara][atual] != -1) {
        return memo[mascara][atual];
    }
    int melhor = Integer.MAX_VALUE;
    for (int prox = 0; prox < n; prox++) {
        if ((mascara & (1 << prox)) == 0) {      // prox ainda não visitada
            int custo = dist[atual][prox] + dp(mascara | (1 << prox), prox);
            melhor = Math.min(melhor, custo);
        }
    }
    return memo[mascara][atual] = melhor;
}

static int menorRota(int[][] d) {
    dist = d;
    n = d.length;
    memo = new int[1 << n][n];

    return dp(1, 0);                             // só a cidade 0 visitada
}

        {0, 10, 15, 20},
        {10, 0, 35, 25},
        {15, 35, 0, 30},
        {20, 25, 30, 0},
    };
```

```go
		memo[i] = make([]int, n)

		}

		if mascara == todas {
```

</CodeTabs>

**Complexidade:** são `2^n · n` estados, e cada um testa n próximos, ou seja, **O(2^n · n²) de tempo e O(2^n · n) de espaço**. É exponencial, mas muito melhor que O(n!): para n = 15, são cerca de 7 milhões de operações contra mais de um trilhão.

## Exemplo: atribuição bottom-up

Com n pessoas e n tarefas, `custo[p][t]` é o custo de a pessoa p fazer a tarefa t. Aqui a máscara diz quais **tarefas** já foram distribuídas, e a quantidade de bits ligados diz qual é a próxima pessoa. Então o estado é só a máscara.

<CodeTabs>

```python
def atribuir(custo):
    n = len(custo)
    dp = [float("inf")] * (1 << n)
    dp[0] = 0
    for mascara in range(1 << n):
        pessoa = bin(mascara).count("1")    # próxima pessoa a receber tarefa
        if pessoa == n or dp[mascara] == float("inf"):
            continue
        for t in range(n):
            if not mascara & (1 << t):
                nova = mascara | (1 << t)
                dp[nova] = min(dp[nova], dp[mascara] + custo[pessoa][t])
    return dp[(1 << n) - 1]

print(atribuir([[9, 2, 7], [6, 4, 3], [5, 8, 1]]))   # 2 + 6 + 1 = 9
```

```go
import (
	"fmt"
	"math"
	"math/bits"
)

func atribuir(custo [][]int) int {
	n := len(custo)
	dp := make([]int, 1<<n)
	for i := range dp {
		dp[i] = math.MaxInt64
	}
	dp[0] = 0
	for mascara := 0; mascara < (1 << n); mascara++ {
		pessoa := bits.OnesCount(uint(mascara)) // próxima pessoa a receber tarefa
		if pessoa == n || dp[mascara] == math.MaxInt64 {
			continue
		}
		for t := 0; t < n; t++ {
			if mascara&(1<<t) == 0 {
				nova := mascara | (1 << t)
				if v := dp[mascara] + custo[pessoa][t]; v < dp[nova] {
					dp[nova] = v
				}
			}
		}
	}
	return dp[(1<<n)-1]
}

func main() {
	fmt.Println(atribuir([][]int{{9, 2, 7}, {6, 4, 3}, {5, 8, 1}})) // 2 + 6 + 1 = 9
}
```

Iterar as máscaras em ordem crescente funciona porque `nova` é sempre maior que `mascara`: quando você chega a um estado, todos os que levam a ele já foram processados. Custo: O(2^n · n).

<Callout type="tip" title="O sinal mais forte">
Restrições como "n ≤ 16" ou "n ≤ 20" num problema que parece pedir permutações quase sempre indicam DP com bitmask. Com n até 10, backtracking puro talvez passe; com n na casa das centenas, a bitmask está fora de questão.
</Callout>

## Armadilhas

- **Precedência de operadores:** em várias linguagens, `mascara & 1 << i == 0` não faz o que parece. Use parênteses.
- **Estado incompleto:** no caixeiro-viajante, só a máscara não basta, porque o custo depende de onde você está. Pergunte-se: "duas situações com a mesma máscara podem ter futuros diferentes?". Se sim, falta informação no estado.
- **Memória:** `2^20 · 20` posições já passa de 20 milhões. Prefira listas ou arrays a dicionários quando o número de estados for grande.

## Na entrevista

Problemas típicos: menor caminho visitando todos os nós, dividir em k subconjuntos de soma igual, atribuir trabalhadores a bicicletas, menor superstring contendo todas as palavras. Comece pela solução de força bruta com permutações, aponte que a ordem não importa para o futuro e proponha a máscara como estado. Diga a complexidade em termos de `2^n` e justifique com o limite de n do enunciado. Follow-up comum: "dá para reconstruir o caminho?". Sim, guardando qual escolha deu o mínimo em cada estado.
