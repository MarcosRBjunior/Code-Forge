A grade `board` contém uma letra em cada célula, e `words` é uma lista de palavras distintas. Retorne todas as palavras de `words` que podem ser montadas na grade.

Uma palavra é montada partindo de uma célula e passando, a cada letra, para uma célula vizinha na horizontal ou na vertical. A mesma célula não pode ser usada duas vezes na mesma palavra. A ordem da resposta não importa, mas cada palavra encontrada aparece uma vez só.

## Exemplo

```text
Entrada:
c a s a
o r t e
m a r l
words = ["casa", "cor", "arte", "mar", "rato", "sol", "tela"]
Saída: ["casa", "cor", "arte", "mar"]
```

## Restrições

- 1 ≤ linhas, colunas ≤ 12
- 1 ≤ tamanho de `words` ≤ 3 × 10⁴, cada palavra com até 10 letras minúsculas.

## Dica

Fazer uma busca separada para cada palavra repete muito trabalho. Monte uma trie com todas as palavras e faça um único DFS a partir de cada célula, descendo na trie junto com a grade e abandonando o caminho assim que o prefixo não existir.
