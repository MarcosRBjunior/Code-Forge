Dada a raiz `root` de uma árvore binária, retorne a sua profundidade máxima: a quantidade de nós no caminho mais longo que sai da raiz e termina em uma folha (um nó sem filhos).

Uma árvore vazia tem profundidade 0, e uma árvore com um único nó tem profundidade 1.

## Exemplo

```text
Entrada: [3, 9, 20, null, null, 15, 7]
      3
     / \
    9   20
       /  \
      15   7
Saída: 3
```

## Restrições

- 0 ≤ número de nós ≤ 10.000
- -100 ≤ `val` ≤ 100

## Dica

Se você soubesse a profundidade das duas subárvores, como calcularia a da árvore inteira? Esse é o caso recursivo; o caso base é a árvore vazia.
