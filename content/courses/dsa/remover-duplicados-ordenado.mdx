Você recebe um array `nums` ordenado em ordem crescente, possivelmente com valores repetidos. Modifique-o **in-place** para que cada valor apareça uma única vez, preservando a ordem crescente.

Ao final, o array deve conter apenas os valores distintos: depois de compactá-los no início, descarte as posições que sobraram (em Python, `del nums[k:]`; em JavaScript, `nums.length = k`). A função não precisa retornar nada, pois os testes verificam o próprio `nums`. Evite criar um segundo array.

## Exemplo

```text
Entrada: nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
Depois:  nums = [0, 1, 2, 3, 4]
```

## Restrições

- `0 <= nums.length <= 3 * 10^4`
- `nums` está ordenado em ordem crescente.

## Dica

Como o array está ordenado, valores iguais estão lado a lado. Um ponteiro de escrita só precisa avançar quando o valor lido for diferente do último valor que você escreveu.
