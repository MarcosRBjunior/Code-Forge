Há `num_courses` cursos, numerados de `0` a `num_courses - 1`. Cada par `[a, b]` em `prerequisites` significa que o curso `b` precisa ser concluído **antes** do curso `a`. Retorne verdadeiro se for possível concluir todos os cursos em alguma ordem.

## Exemplo

```text
Entrada: num_courses = 2, prerequisites = [[1, 0], [0, 1]]
Saída: false
Explicação: o curso 1 exige o 0 e o curso 0 exige o 1, um ciclo.
```

## Restrições

- 1 ≤ `num_courses` ≤ 2000
- 0 ≤ tamanho de `prerequisites` ≤ 5000

## Dica

Modele os cursos como um grafo direcionado. Concluir tudo é impossível exatamente quando esse grafo tem uma propriedade específica: qual?
