O array `nums` tem `n` números **distintos**, todos no intervalo de `0` a `n`. Como o intervalo tem `n + 1` valores, exatamente um deles ficou de fora. Retorne esse valor.

Busque uma solução O(n) de tempo e O(1) de memória extra.

## Exemplo

```text
Entrada: nums = [3, 0, 1]
Saída: 2
Explicação: n = 3, o intervalo é 0..3 e falta o 2.
```

## Restrições

- `1 <= nums.length <= 10^4`
- Todos os valores de `nums` são distintos.

## Dica

`x ^ x == 0` e `x ^ 0 == x`. Se você fizer o XOR de todos os índices de `0` a `n` com todos os valores do array, quem sobra? A soma de Gauss é outro caminho.
