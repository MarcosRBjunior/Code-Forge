A **busca binária** encontra um valor em um espaço ordenado descartando metade das possibilidades a cada passo. Com um milhão de elementos, bastam cerca de 20 comparações: O(log n).

## O molde sem off-by-one

A maioria dos erros em busca binária vem de misturar convenções de intervalo. Escolha uma e use sempre a mesma. O molde abaixo procura a **primeira posição em que uma condição fica verdadeira**, assumindo que ela é falsa no começo e verdadeira no fim (monotônica).

<CodeTabs>

```python
def primeiro_verdadeiro(lo, hi, condicao):
    # procura em [lo, hi); devolve hi se nenhuma posição satisfizer
    while lo < hi:
        meio = (lo + hi) // 2
        if condicao(meio):
            hi = meio        # meio pode ser a resposta: mantém
        else:
            lo = meio + 1    # meio certamente não é: descarta
    return lo

nums = [1, 3, 3, 5, 8, 13]
# primeira posição com valor maior ou igual a 5
print(primeiro_verdadeiro(0, len(nums), lambda i: nums[i] >= 5))  # 3
```

```go
import "fmt"

func primeiroVerdadeiro(lo, hi int, condicao func(int) bool) int {
	// procura em [lo, hi); devolve hi se nenhuma posição satisfizer
	for lo < hi {
		meio := lo + (hi-lo)/2
		if condicao(meio) {
			hi = meio // meio pode ser a resposta: mantém
		} else {
			lo = meio + 1 // meio certamente não é: descarta
		}
	}
	return lo
}

func main() {
	nums := []int{1, 3, 3, 5, 8, 13}
	// primeira posição com valor maior ou igual a 5
	fmt.Println(primeiroVerdadeiro(0, len(nums), func(i int) bool { return nums[i] >= 5 })) // 3
}
```

</CodeTabs>

Três regras garantem que ele termina e acerta:

1. O intervalo é **meio aberto**: `lo` está incluído, `hi` não.
2. O laço roda enquanto `lo < hi`, então ao sair `lo == hi`.
3. Quando a condição é verdadeira, `hi = meio`; quando é falsa, `lo = meio + 1`. O intervalo sempre encolhe.

Com esse molde, "achar um valor exato" vira "achar o primeiro maior ou igual" e depois conferir se ele é igual ao alvo. "Achar o último menor ou igual" também cabe nele: é a posição anterior ao primeiro elemento estritamente maior. Reduzir todas as variações a uma única pergunta, "onde a condição passa de falsa para verdadeira?", evita decorar meia dúzia de versões ligeiramente diferentes do mesmo laço.

## Busca na resposta

A busca binária não serve só para arrays. Ela funciona em qualquer espaço em que exista uma condição monotônica: se a resposta `x` funciona, todo valor maior também funciona (ou o contrário).

Exemplo: qual a menor velocidade para comer todas as pilhas de bananas em `h` horas, comendo no máximo uma pilha por hora?

<CodeTabs>

```python
def menor_velocidade(pilhas, h):
    def consegue(v):
        horas = sum((p + v - 1) // v for p in pilhas)  # divisão com teto
        return horas <= h
    return primeiro_verdadeiro(1, max(pilhas) + 1, consegue)

print(menor_velocidade([3, 6, 7, 11], 8))  # 4
```

```javascript
function menorVelocidade(pilhas, h) {
  const consegue = (v) => {
    const horas = pilhas.reduce((total, p) => total + Math.floor((p + v - 1) / v), 0);  // divisão com teto
    return horas <= h;
  };
  return primeiroVerdadeiro(1, Math.max(...pilhas) + 1, consegue);
}

console.log(menorVelocidade([3, 6, 7, 11], 8));  // 4
```

```java
import java.util.Arrays;

static int menorVelocidade(int[] pilhas, int h) {
    int maior = Arrays.stream(pilhas).max().getAsInt();
    return primeiroVerdadeiro(1, maior + 1, v -> {
        long horas = 0;
        for (int p : pilhas) {
            horas += (p + v - 1) / v;   // divisão com teto
        }
        return horas <= h;
    });
}

public static void main(String[] args) {
    System.out.println(menorVelocidade(new int[]{3, 6, 7, 11}, 8));  // 4
}
```

```cpp
#include <algorithm>

int menorVelocidade(const vector<int>& pilhas, int h) {

        for (int p : pilhas) {
            horas += (p + v - 1) / v;   // divisão com teto

    return primeiroVerdadeiro(1, maior + 1, consegue);
}

int main() {
    cout << menorVelocidade({3, 6, 7, 11}, 8) << endl;  // 4
}
```

```go
func menorVelocidade(pilhas []int, h int) int {
	maior := 0
	for _, p := range pilhas {
		if p > maior {
			maior = p
		}
	}
	consegue := func(v int) bool {
		horas := 0
		for _, p := range pilhas {
			horas += (p + v - 1) / v // divisão com teto
		}
		return horas <= h
	}
	return primeiroVerdadeiro(1, maior+1, consegue)
}

func main() {
	fmt.Println(menorVelocidade([]int{3, 6, 7, 11}, 8)) // 4
}
```

</CodeTabs>

O array nem existe: o espaço de busca são as velocidades possíveis, e a função `consegue` é a condição monotônica.

<Callout type="tip" title="Sinais de busca na resposta">
"Menor valor que ainda funciona", "maior valor possível sem estourar", restrições grandes (até 10⁹) que impedem testar todos os candidatos. Se você consegue escrever `consegue(x)` em O(n), a solução total é O(n log M).
</Callout>

## Na entrevista

Antes de codar, diga qual é a condição monotônica e qual intervalo inicial contém a resposta com certeza. Teste mentalmente com dois elementos, que é onde os laços infinitos aparecem. Em Python não há overflow, mas em Java ou C++ calcule o meio como `lo + (hi - lo) / 2` e mencione o motivo.
