Dado um array de inteiros (com negativos), qual é a **maior soma de um subarray contíguo**? A força bruta testa todos os pares de início e fim: O(n²) com soma incremental, O(n³) sem ela. O algoritmo de Kadane resolve em **uma passada**, O(n) de tempo e O(1) de espaço.

## A ideia central

Percorra o array mantendo uma única pergunta: **qual é a melhor soma de um subarray que termina exatamente aqui?**

Ao chegar no elemento `x`, você só tem duas opções para um subarray que termina nele:

1. **Estender** o melhor subarray que terminava no elemento anterior: `melhor_aqui + x`.
2. **Recomeçar** do zero, com um subarray que contém só `x`.

Você escolhe o maior dos dois. Se a soma acumulada até o elemento anterior ficou negativa, ela só atrapalha, e recomeçar é melhor. Paralelamente, guarde o maior valor já visto de `melhor_aqui`: essa é a resposta.

```python
def maior_soma_subarray(nums):
    melhor_aqui = nums[0]
    melhor_global = nums[0]
    for x in nums[1:]:
        melhor_aqui = max(x, melhor_aqui + x)
        melhor_global = max(melhor_global, melhor_aqui)
    return melhor_global

print(maior_soma_subarray([3, -5, 4, -1, 2, 1, -6, 2]))  # 6  (4, -1, 2, 1)
print(maior_soma_subarray([-3, -1, -2]))                 # -1
```

Repare que a inicialização usa `nums[0]`, e não zero. Se você começasse com zero, um array só de negativos devolveria 0, que corresponde a um subarray vazio, normalmente não permitido.

## Rastreando o passo a passo

Para `[3, -5, 4, -1, 2, 1, -6, 2]`:

```text
x     melhor_aqui              melhor_global
3     3                        3
-5    max(-5, 3-5)  = -2       3
4     max(4, -2+4)  = 4        4    <- recomeçou
-1    max(-1, 4-1)  = 3        4
2     max(2, 3+2)   = 5        5
1     max(1, 5+1)   = 6        6
-6    max(-6, 6-6)  = 0        6
2     max(2, 0+2)   = 2        6
```

## Por que é programação dinâmica

Kadane é uma DP disfarçada. O estado é `dp[i]` = maior soma de um subarray que **termina** no índice i. A transição é `dp[i] = max(nums[i], dp[i-1] + nums[i])`, e a resposta é o máximo de todos os `dp[i]`. Como cada estado só depende do anterior, você guarda uma variável em vez da tabela inteira.

Esse truque de fixar "termina aqui" é a parte reaproveitável. Ele aparece em muitas variações.

## Variações comuns

- **Recuperar os índices** do subarray: guarde onde o `melhor_aqui` recomeçou e atualize início e fim junto com `melhor_global`.
- **Maior produto** de subarray: um negativo vezes um negativo vira positivo, então você mantém o maior **e** o menor produto que terminam em cada posição.
- **Array circular**: a resposta é o máximo entre o Kadane normal e `soma_total - menor_soma_subarray` (com cuidado quando todos são negativos).
- **Lucro de compra e venda de ação**: aplique Kadane às diferenças entre dias consecutivos.

```python
def maior_produto(nums):
    maior = menor = resposta = nums[0]
    for x in nums[1:]:
        candidatos = (x, maior * x, menor * x)
        maior, menor = max(candidatos), min(candidatos)
        resposta = max(resposta, maior)
    return resposta

print(maior_produto([2, 3, -2, 4]))    # 6
print(maior_produto([-2, 3, -4]))      # 24
```

<Callout type="tip" title="Quando reconhecer">
Procure por "subarray contíguo" junto de "maior soma", "maior lucro" ou "maior produto". Se o problema pede subsequência (não contígua), Kadane não se aplica diretamente.
</Callout>
