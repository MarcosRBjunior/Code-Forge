Você recebe `lists`, uma lista com `k` sequências de inteiros, cada uma já ordenada em ordem não decrescente. Junte todas em uma única sequência ordenada e retorne-a.

Na versão clássica, cada sequência é uma lista ligada; aqui elas chegam como arrays comuns, mas a ideia é a mesma: trate cada array como uma fila da qual você só pode olhar e retirar o elemento da frente. Algumas sequências podem estar vazias, e `lists` também pode estar vazia.

## Exemplo

```text
Entrada: lists = [[1, 4, 5], [1, 3, 4], [2, 6]]
Saída: [1, 1, 2, 3, 4, 4, 5, 6]
```

## Restrições

- 0 ≤ `k` ≤ 10.000
- 0 ≤ tamanho de cada sequência ≤ 500
- O total de elementos não passa de 10.000.

## Dica

Juntar tudo e ordenar funciona, mas ignora que cada sequência já está ordenada. O próximo elemento da resposta é sempre o menor entre as `k` frentes: um min-heap com uma entrada `(valor, qual lista, posição)` por sequência entrega isso em O(log k) a cada passo.
