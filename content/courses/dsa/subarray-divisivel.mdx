Dado um array de inteiros `nums` (que pode ter negativos) e um inteiro `k`, conte quantos trechos contíguos e não vazios de `nums` têm soma divisível por `k`. Uma soma `0` conta como divisível.

## Exemplo

```text
Entrada: nums = [4, 5, 0, -2, -3, 1], k = 5
Saída: 7
Explicação: [5], [5, 0], [0], [5, 0, -2, -3], [0, -2, -3], [-2, -3]
e [4, 5, 0, -2, -3, 1] têm soma múltipla de 5.
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 3 × 10⁴
- -10⁴ ≤ `nums[i]` ≤ 10⁴
- 2 ≤ `k` ≤ 10⁴

## Dica

A soma do trecho entre dois prefixos é divisível por `k` quando os dois prefixos deixam o mesmo resto. Cuidado: em JavaScript (e em outras linguagens), o resto de um número negativo é negativo; normalize-o.
