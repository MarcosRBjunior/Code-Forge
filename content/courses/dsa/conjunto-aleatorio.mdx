Implemente um conjunto de inteiros em que **todas** as operações rodam em tempo O(1) médio. A classe `RandomizedSet` tem:

- `insert(val)`: adiciona `val` se ele ainda não estiver presente. Retorna verdadeiro se inseriu, falso se já existia.
- `remove(val)`: remove `val` se estiver presente. Retorna verdadeiro se removeu, falso caso contrário.
- `getRandom()`: retorna um elemento sorteado, com a mesma probabilidade para todos (em Python, pode se chamar `get_random`). Sempre haverá pelo menos um elemento quando ele for chamado.

Para que os testes sejam determinísticos, `getRandom` só é chamado quando o conjunto tem exatamente um elemento. Mesmo assim, implemente o sorteio de verdade.

## Exemplo

```text
Operações: RandomizedSet(), insert(1), remove(2), insert(2), remove(1), insert(2), getRandom()
Saída:     null,            true,      false,     true,      true,      false,     2
```

## Restrições

- -2³¹ ≤ `val` ≤ 2³¹ - 1
- No máximo 2 × 10⁵ chamadas.

## Dica

Um array sorteia em O(1), mas remove do meio em O(n). Um hash remove em O(1), mas não sorteia. Combine os dois: o hash guarda o índice de cada valor no array. Para remover sem abrir buraco, o que você pode fazer com o último elemento?
