Dado um array `nums` de inteiros **distintos**, retorne todos os seus subconjuntos (o conjunto das partes), incluindo o vazio e o próprio `nums`. Não pode haver subconjuntos repetidos. A ordem dos subconjuntos e dos elementos dentro de cada um não importa.

## Exemplo

```text
Entrada: nums = [1, 2, 3]
Saída: [[], [1], [2], [3], [1, 2], [1, 3], [2, 3], [1, 2, 3]]
```

## Restrições

- 0 ≤ tamanho de `nums` ≤ 10
- Os elementos de `nums` são distintos.

## Dica

Para cada elemento há exatamente duas escolhas: ele entra ou não entra. Como transformar essas escolhas em uma recursão (ou em um laço)?
