Dado um array de inteiros `nums`, encontre todas as **triplas** de elementos, em três posições diferentes, cuja soma é `0`.

A resposta não pode ter triplas repetidas: duas triplas com os mesmos valores (em qualquer ordem) contam como uma só. A ordem das triplas e a ordem dos valores dentro de cada tripla não importam. Se não houver nenhuma, retorne uma lista vazia.

## Exemplo

```text
Entrada: nums = [-1, 0, 1, 2, -1, -4]
Saída: [[-1, -1, 2], [-1, 0, 1]]
```

## Restrições

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## Dica

Ordene o array. Fixe o primeiro elemento da tripla e resolva um Two Sum com dois ponteiros no restante. Para evitar repetições, pule valores iguais ao anterior, tanto no elemento fixo quanto nos ponteiros.
