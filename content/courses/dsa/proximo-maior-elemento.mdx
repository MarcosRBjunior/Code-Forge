Para cada posição `i` do array `nums`, encontre o **primeiro** elemento à direita de `i` que seja estritamente maior que `nums[i]`. Retorne um array do mesmo tamanho com esses valores, usando `-1` quando não houver nenhum maior à direita.

## Exemplo

```text
Entrada: nums = [2, 1, 2, 4, 3]
Saída: [4, 2, 4, -1, -1]
Explicação: depois do 1 (índice 1), o primeiro maior é o 2; depois do 4, ninguém é maior.
```

## Restrições

- 0 ≤ tamanho de `nums` ≤ 10⁴
- -10⁹ ≤ `nums[i]` ≤ 10⁹

## Dica

A força bruta é O(n²). Mantenha uma pilha com os índices que ainda esperam por um maior: quando chega um valor novo, ele "resolve" todos os do topo que forem menores.
