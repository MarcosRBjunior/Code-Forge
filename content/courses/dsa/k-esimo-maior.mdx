Dado um array de inteiros `nums` e um inteiro `k`, retorne o **k-ésimo maior** elemento na ordem decrescente. Valores repetidos contam separadamente: em `[5, 5, 4]`, o segundo maior é `5`.

## Exemplo

```text
Entrada: nums = [3, 2, 1, 5, 6, 4], k = 2
Saída: 5
```

## Restrições

- 1 ≤ `k` ≤ tamanho de `nums` ≤ 10⁵
- -10⁴ ≤ `nums[i]` ≤ 10⁴

## Dica

Ordenar tudo resolve em O(n log n). Se você mantiver só os `k` maiores vistos até agora, qual estrutura deixa o menor deles sempre à mão?
