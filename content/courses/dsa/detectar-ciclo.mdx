Você recebe a cabeça `head` de uma lista ligada. Descubra se, seguindo os ponteiros `next` a partir dela, você em algum momento volta a um nó já visitado, ou seja, se a lista tem um ciclo.

Nos testes, cada entrada aparece como um par: os valores dos nós e o índice do nó para o qual o último nó aponta (`-1` significa que o último não aponta para ninguém). Sua função recebe apenas a cabeça já montada; o índice não é passado para você.

## Exemplo

```text
Entrada: valores = [3, 2, 0, -4], o último aponta para o índice 1
         3 -> 2 -> 0 -> -4
              ^          |
              +----------+
Saída: true
```

## Restrições

- 0 ≤ número de nós ≤ 10.000
- Tente usar memória O(1).

## Dica

Um conjunto de nós visitados resolve, mas gasta memória. Pense em dois corredores numa pista, um mais rápido que o outro: se a pista for circular, o que inevitavelmente acontece?
