Cada número em `hand` é o valor de uma carta. Você quer separar **todas** as cartas em grupos de exatamente `group_size` cartas, e cada grupo precisa ter valores consecutivos, como 4, 5, 6.

Retorne verdadeiro se for possível fazer essa divisão e falso caso contrário.

## Exemplo

```text
Entrada: hand = [1, 2, 3, 3, 4, 5], group_size = 3
Saída: true
Explicação: os grupos [1, 2, 3] e [3, 4, 5].
```

## Restrições

- 1 ≤ tamanho de `hand` ≤ 10⁴
- 0 ≤ `hand[i]` ≤ 10⁹
- 1 ≤ `group_size` ≤ tamanho de `hand`

## Dica

Olhe para a menor carta que ainda sobrou: ela obrigatoriamente começa um grupo. Isso define as próximas cartas que esse grupo precisa consumir.
