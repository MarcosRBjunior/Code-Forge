Uma **subsequência** é obtida apagando zero ou mais elementos de um array sem mudar a ordem dos que sobram. Dado `nums`, retorne o tamanho da maior subsequência **estritamente** crescente.

## Exemplo

```text
Entrada: nums = [3, 1, 4, 1, 5, 9, 2, 6]
Saída: 4
Explicação: por exemplo, [3, 4, 5, 9] ou [1, 4, 5, 6].
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 2500
- -10⁴ ≤ `nums[i]` ≤ 10⁴

## Dica

Em O(n²): `dp[i]` é o tamanho da maior subsequência crescente que **termina** em `i`, calculado olhando todos os `j` anteriores com valor menor. Para O(n log n), mantenha o menor final possível de cada tamanho e use busca binária.
