Uma **escada de palavras** vai de `begin_word` até `end_word` trocando **uma letra por vez**. Toda palavra intermediária, e também a final, precisa estar em `word_list`; a palavra inicial não precisa. Todas as palavras têm o mesmo tamanho.

Retorne o número de palavras da escada mais curta, contando a inicial e a final. Se não existir escada, retorne `0`.

## Exemplo

```text
Entrada: begin_word = "pato", end_word = "gelo",
         word_list = ["gato", "galo", "gelo", "pelo", "palo"]
Saída: 4
Explicação: pato → gato → galo → gelo.
```

## Restrições

- 1 ≤ tamanho de cada palavra ≤ 10
- 1 ≤ tamanho de `word_list` ≤ 5000
- Só letras minúsculas de `a` a `z`, sem palavras repetidas na lista.

## Dica

Cada palavra é um vértice, e duas palavras são vizinhas se diferem em uma letra. O menor número de passos num grafo sem pesos sai de uma BFS. Em vez de comparar todos os pares, gere os vizinhos trocando cada posição por cada letra do alfabeto.
