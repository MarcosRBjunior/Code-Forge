Implemente a classe `NumArray`, que recebe um array de inteiros uma única vez e depois responde a muitas consultas de soma:

- `NumArray(nums)`: guarda (e pode pré-processar) o array.
- `sumRange(left, right)`: retorna a soma dos elementos de `nums` entre os índices `left` e `right`, ambos inclusive.

O array nunca é alterado depois de criado, mas pode haver milhares de consultas. Cada uma deve rodar em O(1). Em Python, o método pode se chamar `sum_range`.

## Exemplo

```text
NumArray([-2, 0, 3, -5, 2, -1])
sumRange(0, 2) -> 1    (-2 + 0 + 3)
sumRange(2, 5) -> -1   (3 - 5 + 2 - 1)
sumRange(0, 5) -> -3
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 10⁴
- 0 ≤ `left` ≤ `right` menor que o tamanho de `nums`
- Até 10⁴ chamadas de `sumRange`.

## Dica

Guarde no construtor `prefixo[i]` = soma dos `i` primeiros elementos. A soma de um intervalo vira a diferença entre dois prefixos.
