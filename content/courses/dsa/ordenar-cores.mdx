Um array `nums` representa bolinhas coloridas: `0` é vermelho, `1` é branco e `2` é azul. Reorganize o array **in-place** para que as cores fiquem agrupadas na ordem vermelho, branco, azul.

Não use a função de ordenação da biblioteca. A função não retorna nada: os testes verificam o próprio `nums`. Tente resolver em uma única passada, com memória extra constante.

## Exemplo

```text
Entrada: nums = [2, 0, 2, 1, 1, 0]
Depois:  nums = [0, 0, 1, 1, 2, 2]
```

## Restrições

- `1 <= nums.length <= 300`
- Cada `nums[i]` é `0`, `1` ou `2`.

## Dica

Contar quantos há de cada cor resolve em duas passadas. Para uma só, mantenha três regiões: a dos zeros no começo, a dos dois no fim e a dos não analisados no meio. O que fazer quando o elemento atual é `2`?
