A matriz `matrix`, de `m` linhas e `n` colunas, tem duas propriedades:

- cada linha está em ordem crescente;
- o primeiro elemento de cada linha é maior que o último da linha anterior.

Diga se `target` aparece na matriz. A solução deve rodar em O(log(m × n)).

## Exemplo

```text
Entrada: matrix = [[1, 3, 5, 7], [10, 11, 16, 20], [23, 30, 34, 60]], target = 3
Saída: true
```

## Restrições

- 1 ≤ `m`, `n` ≤ 100
- -10⁴ ≤ `matrix[i][j]`, `target` ≤ 10⁴

## Dica

Lida linha após linha, a matriz é um único array ordenado de `m × n` posições. Como converter um índice `k` desse array imaginário em linha e coluna?
