Existem `n` cidades, numeradas de `0` a `n - 1`, e a lista `flights` de voos **de ida**: cada `[de, para, preco]` é um voo direto. Retorne o menor preço total para ir de `src` até `dst` fazendo **no máximo `k` escalas** (cidades intermediárias). Se não houver rota assim, retorne `-1`.

Note que `k` escalas significa usar até `k + 1` voos.

## Exemplo

```text
Entrada: n = 4, flights = [[0, 1, 50], [1, 2, 50], [2, 3, 50], [0, 3, 400]], src = 0, dst = 3, k = 1
Saída: 400
Explicação: a rota 0 → 1 → 2 → 3 custa 150, mas tem 2 escalas. Com no máximo 1, só resta o voo direto.
```

## Restrições

- 1 ≤ `n` ≤ 100
- 0 ≤ tamanho de `flights` ≤ `n` × (`n` - 1)
- 1 ≤ `preco` ≤ 10⁴, `src` diferente de `dst`, 0 ≤ `k` menor que `n`

## Dica

O Dijkstra puro descarta caminhos baratos com escalas demais e não sabe voltar atrás. Uma alternativa é o Bellman-Ford limitado: faça `k + 1` rodadas de relaxamento, sempre a partir de uma cópia das distâncias da rodada anterior.
