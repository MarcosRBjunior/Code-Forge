Uma empresa tem a agenda do dia em `intervals`: cada par `[inicio, fim]` é uma reunião. Uma sala só comporta uma reunião por vez. Retorne o **menor número de salas** que permite realizar todas as reuniões.

A reunião ocupa a sala de `inicio` até imediatamente antes de `fim`. Assim, uma reunião que termina às 5 libera a sala para outra que começa às 5.

## Exemplo

```text
Entrada: intervals = [[0, 30], [5, 10], [15, 20]]
Saída: 2
Explicação: [0, 30] ocupa uma sala o dia todo; [5, 10] e [15, 20] revezam a segunda.
```

## Restrições

- 0 ≤ tamanho de `intervals` ≤ 10⁴
- 0 ≤ `inicio` menor que `fim` ≤ 10⁶

## Dica

Processe as reuniões em ordem de início. No momento em que uma começa, você precisa saber qual sala ocupada fica livre primeiro. Que estrutura entrega o menor horário de término rapidamente?
