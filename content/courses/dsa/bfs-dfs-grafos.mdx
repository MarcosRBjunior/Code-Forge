Quase todo problema de grafo começa com uma pergunta simples: a partir deste vértice, o que eu consigo alcançar, e em que ordem? As duas respostas clássicas são a **busca em largura** (BFS) e a **busca em profundidade** (DFS). Ambas visitam cada vértice e cada aresta uma vez; a diferença está na ordem de visita, e é ela que decide qual usar.

## Representação

Em entrevistas, o grafo quase sempre vem como lista de arestas e você o converte em **lista de adjacência**:

```java
static Map<Integer, List<Integer>> montarGrafo(int[][] arestas, boolean dirigido) {
    Map<Integer, List<Integer>> g = new TreeMap<>();
    for (int[] e : arestas) {
```

## BFS: camada por camada

A BFS usa uma **fila**. Ela visita primeiro todos os vértices a distância 1, depois os a distância 2, e assim por diante. Por isso, em grafos **sem peso**, a primeira vez que a BFS alcança um vértice é pelo caminho mais curto.

<CodeTabs>

```python
from collections import deque

def distancias(g, origem):
    dist = {origem: 0}
    fila = deque([origem])
    while fila:
        u = fila.popleft()
        for v in g[u]:
            if v not in dist:          # marque ao enfileirar, não ao retirar
                dist[v] = dist[u] + 1
                fila.append(v)
    return dist

g = {0: [1, 2], 1: [0, 3], 2: [0, 3], 3: [1, 2, 4], 4: [3]}
print(distancias(g, 0))  # {0: 0, 1: 1, 2: 1, 3: 2, 4: 3}
```

```javascript
function distancias(g, origem) {
  const dist = new Map([[origem, 0]]);
  const fila = [origem];
  for (let ini = 0; ini < fila.length; ini++) {   // índice de leitura no lugar de shift(), que é O(n)
    const u = fila[ini];
    for (const v of g[u]) {
      if (!dist.has(v)) {                         // marque ao enfileirar, não ao retirar
        dist.set(v, dist.get(u) + 1);
        fila.push(v);
      }
    }
  }
  return dist;
}
```

```java
import java.util.*;

static Map<Integer, Integer> distancias(Map<Integer, List<Integer>> g, int origem) {
    Map<Integer, Integer> dist = new TreeMap<>();
    dist.put(origem, 0);
    Deque<Integer> fila = new ArrayDeque<>();
    fila.add(origem);
    while (!fila.isEmpty()) {
        int u = fila.poll();
        for (int v : g.get(u)) {
            if (!dist.containsKey(v)) {          // marque ao enfileirar, não ao retirar
                dist.put(v, dist.get(u) + 1);
                fila.add(v);
            }
        }
    }
    return dist;
}

        0, List.of(1, 2), 1, List.of(0, 3), 2, List.of(0, 3), 3, List.of(1, 2, 4), 4, List.of(3));
```

```cpp
map<int, int> distancias(const map<int, vector<int>>& g, int origem) {
    map<int, int> dist = {{origem, 0}};
    queue<int> fila;
    fila.push(origem);
    while (!fila.empty()) {
        int u = fila.front();
        fila.pop();
        for (int v : g.at(u)) {

                dist[v] = dist[u] + 1;
                fila.push(v);
            }
        }
    }
    return dist;
}
```

```csharp
static SortedDictionary<int, int> Distancias(Dictionary<int, List<int>> g, int origem)
{
    var dist = new SortedDictionary<int, int> { [origem] = 0 };
    var fila = new Queue<int>();
    fila.Enqueue(origem);
    while (fila.Count > 0)
    {
        int u = fila.Dequeue();
        foreach (int v in g[u])
        {
            if (!dist.ContainsKey(v))            // marque ao enfileirar, não ao retirar
            {
                dist[v] = dist[u] + 1;
                fila.Enqueue(v);
            }
        }
    }
    return dist;
}
```

## DFS: até o fim e volta

A DFS usa uma **pilha**, explícita ou a de chamadas recursivas. Ela segue um caminho até não ter para onde ir e então recua. É natural para explorar componentes, detectar ciclos e fazer ordenação topológica.

<CodeTabs>

```python
def contar_componentes(n, arestas):
    g = [[] for _ in range(n)]
    for u, v in arestas:
        g[u].append(v)
        g[v].append(u)
    visto = [False] * n
    componentes = 0
    for inicio in range(n):
        if visto[inicio]:
            continue
        componentes += 1
        pilha = [inicio]
        visto[inicio] = True
        while pilha:                    # DFS iterativa: sem limite de recursão
            u = pilha.pop()
            for v in g[u]:
                if not visto[v]:
                    visto[v] = True
                    pilha.append(v)
    return componentes

print(contar_componentes(6, [(0, 1), (1, 2), (3, 4)]))  # 3: {0,1,2}, {3,4}, {5}
```

```java
import java.util.*;

static int contarComponentes(int n, int[][] arestas) {
    List<List<Integer>> g = new ArrayList<>();
    for (int i = 0; i < n; i++) g.add(new ArrayList<>());
    for (int[] e : arestas) {
        g.get(e[0]).add(e[1]);
        g.get(e[1]).add(e[0]);

    boolean[] visto = new boolean[n];
    int componentes = 0;
    for (int inicio = 0; inicio < n; inicio++) {

            for (int v : g.get(u)) {
                if (!visto[v]) {
                    visto[v] = true;
                    pilha.push(v);
                }
            }
        }
    }
    return componentes;
}
```

```csharp
static int ContarComponentes(int n, int[][] arestas)
{
    var g = new List<int>[n];
    for (int i = 0; i < n; i++) g[i] = new List<int>();
    foreach (int[] e in arestas)

        g[e[1]].Add(e[0]);
```

```go
func contarComponentes(n int, arestas [][2]int) int {
	g := make([][]int, n)
	for _, e := range arestas {
		g[e[0]] = append(g[e[0]], e[1])
		g[e[1]] = append(g[e[1]], e[0])
```

**Complexidade das duas:** O(V + E) de tempo, pois cada vértice entra na estrutura uma vez e cada lista de adjacência é percorrida uma vez. O espaço é O(V) para o conjunto de visitados e a fila ou pilha, além de O(V + E) para o grafo.

## Qual escolher

| Situação | Use |
| --- | --- |
| Menor número de passos em grafo sem peso | BFS |
| Processar por níveis (distância k, "minutos até apodrecer") | BFS, inclusive com várias origens na fila inicial |
| Contar componentes, ilhas, regiões | Qualquer uma; DFS costuma ser mais curta |
| Detectar ciclo, ordenação topológica | DFS (ou Kahn, que é BFS por grau de entrada) |
| Enumerar todos os caminhos | DFS com backtracking |

<Callout type="warning" title="Marque como visitado na hora certa">
Na BFS, marque o vértice ao colocá-lo na fila. Se marcar só ao retirar, o mesmo vértice pode entrar várias vezes, e em grades grandes isso estoura tempo e memória.
</Callout>

## Quando reconhecer

Palavras como "conectado", "alcançável", "vizinhos", "dependências", "menor número de movimentos" e qualquer grade com células que se comunicam indicam travessia de grafo. Se o enunciado fala em transformar uma palavra em outra mudando uma letra por vez, ou destravar um cadeado girando dígitos, os estados são vértices implícitos e a BFS encontra o mínimo de passos.
