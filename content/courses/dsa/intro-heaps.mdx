Um **heap** é uma estrutura que mantém o menor (ou o maior) elemento sempre acessível no topo, e permite inserir e remover em O(log n). É a implementação usual de uma **fila de prioridade**.

## Como funciona

Um heap mínimo é uma árvore binária quase completa em que todo pai é menor ou igual aos seus filhos. Ele é guardado em um array: o filho esquerdo do índice `i` fica em `2i + 1` e o direito em `2i + 2`. Inserir coloca o elemento no fim e o faz "subir" trocando com o pai; remover o topo coloca o último elemento na raiz e o faz "descer".

| Operação | Custo |
| --- | --- |
| Ver o topo | O(1) |
| Inserir | O(log n) |
| Remover o topo | O(log n) |
| Montar a partir de uma lista | O(n) |

## heapq em Python

O módulo `heapq` transforma uma `list` comum em heap mínimo:

```python
import heapq

nums = [5, 1, 8, 3, 2]
heapq.heapify(nums)          # O(n), in-place
heapq.heappush(nums, 0)
menor = heapq.heappop(nums)  # 0
print(menor, nums[0])        # 0 1
```

Não existe heap máximo pronto. O truque é inserir os valores com o sinal invertido e desinverter ao retirar. Para ordenar por uma chave, insira tuplas: `(prioridade, desempate, item)`. O desempate evita que o Python tente comparar itens que não são comparáveis.

<Callout type="tip" title="Tuplas com desempate">
Ao guardar objetos, use `(prioridade, contador, objeto)` com um contador crescente. Se duas prioridades empatarem, a comparação para no contador e nunca chega ao objeto.
</Callout>

## O padrão top-k

Para achar os k maiores elementos, não ordene tudo. Mantenha um heap **mínimo de tamanho k**: o topo é o menor dos k maiores vistos até agora, e qualquer elemento novo maior que ele entra no lugar.

```python
import heapq

def k_maiores(nums, k):
    heap = []
    for x in nums:
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif x > heap[0]:
            heapq.heapreplace(heap, x)  # remove o topo e insere x
    return sorted(heap, reverse=True)

print(k_maiores([3, 1, 5, 12, 2, 11, 9], 3))  # [12, 11, 9]
```

Isso custa O(n log k) e O(k) de espaço, melhor que O(n log n) quando k é pequeno. A mesma ideia resolve "k pontos mais próximos", "k palavras mais frequentes" e o k-ésimo maior elemento.

Outros usos clássicos: juntar k listas ordenadas (o heap guarda a cabeça de cada lista), a mediana de um fluxo (dois heaps, um máximo e um mínimo) e o algoritmo de Dijkstra.
