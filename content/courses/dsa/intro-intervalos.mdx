Reuniões numa agenda, reservas de sala, faixas de horário de funcionamento, trechos de um vídeo já assistidos. Tudo isso vira uma lista de **intervalos** `[início, fim]`, e uma família grande de problemas pergunta como eles se sobrepõem. A quase totalidade se resolve com o mesmo primeiro passo: **ordenar pelo início**.

## Quando dois intervalos se sobrepõem

Para `a = [a0, a1]` e `b = [b0, b1]`, eles se sobrepõem se cada um começa antes de o outro terminar:

<CodeTabs>

```python
def sobrepoe(a, b):
    return a[0] <= b[1] and b[0] <= a[1]

print(sobrepoe([1, 4], [3, 6]))  # True
print(sobrepoe([1, 2], [3, 4]))  # False
print(sobrepoe([1, 3], [3, 5]))  # True  (encostam em 3)
```

O caso em que eles apenas **encostam** (um termina em 3 e o outro começa em 3) é a pergunta mais importante a fazer ao entrevistador. Numa agenda, uma reunião que acaba às 10h e outra que começa às 10h **não** conflitam; numa lista de faixas fechadas, talvez devam ser unidas. A única mudança no código é `<=` contra `<`.

## Por que ordenar

Depois de ordenar pelo início, um intervalo só pode se sobrepor ao **grupo imediatamente anterior**. Você não precisa comparar cada par (O(n²)); basta uma varredura linear comparando com o último resultado.

## Molde 1: mesclar sobreposições

<CodeTabs>

```python
def mesclar(intervalos):
    intervalos = sorted(intervalos, key=lambda x: x[0])
    resultado = []
    for ini, fim in intervalos:
        if resultado and ini <= resultado[-1][1]:
            resultado[-1][1] = max(resultado[-1][1], fim)
        else:
            resultado.append([ini, fim])
    return resultado

print(mesclar([[8, 10], [1, 3], [2, 6], [15, 18], [17, 20]]))
# [[1, 6], [8, 10], [15, 20]]
```

```javascript
function mesclar(intervalos) {
  const ordenados = [...intervalos].sort((a, b) => a[0] - b[0]);
  const resultado = [];
  for (const [ini, fim] of ordenados) {
    if (resultado.length > 0 && ini <= resultado[resultado.length - 1][1]) {
      const ultimo = resultado[resultado.length - 1];
      ultimo[1] = Math.max(ultimo[1], fim);
    } else {
      resultado.push([ini, fim]);
    }
  }
  return resultado;
}
```

```java
import java.util.*;

static List<int[]> mesclar(int[][] intervalos) {
    int[][] ordenados = intervalos.clone();
    Arrays.sort(ordenados, Comparator.comparingInt(x -> x[0]));
    List<int[]> resultado = new ArrayList<>();
    for (int[] iv : ordenados) {

        if (!resultado.isEmpty() && ini <= resultado.get(resultado.size() - 1)[1]) {
            int[] ultimo = resultado.get(resultado.size() - 1);
            ultimo[1] = Math.max(ultimo[1], fim);
        } else {
            resultado.add(new int[]{ini, fim});
        }
    }
    return resultado;
}
```

```go
import (
	"fmt"
	"sort"
)

func mesclar(intervalos [][2]int) [][2]int {
	ordenados := append([][2]int{}, intervalos...)
	sort.Slice(ordenados, func(i, j int) bool { return ordenados[i][0] < ordenados[j][0] })
	resultado := [][2]int{}
	for _, iv := range ordenados {
		ini, fim := iv[0], iv[1]
		if n := len(resultado); n > 0 && ini <= resultado[n-1][1] {
			if fim > resultado[n-1][1] {
				resultado[n-1][1] = fim
			}
		} else {
			resultado = append(resultado, [2]int{ini, fim})
		}
	}
	return resultado
}

func main() {
	fmt.Println(mesclar([][2]int{{8, 10}, {1, 3}, {2, 6}, {15, 18}, {17, 20}}))
	// [[1 6] [8 10] [15 20]]
}
```

</CodeTabs>

O `max` é essencial: um intervalo pode estar inteiramente contido no anterior (`[1, 10]` e `[2, 3]`), e sem ele você encolheria o fim. Tempo O(n log n) pela ordenação, espaço O(n) para a saída.

## Molde 2: quantas salas preciso?

Dado um conjunto de reuniões, qual é o máximo de reuniões acontecendo ao mesmo tempo? Separe os eventos em inícios e fins, ordene, e varra a linha do tempo:

<CodeTabs>

```python
def salas_necessarias(reunioes):
    inicios = sorted(r[0] for r in reunioes)
    fins = sorted(r[1] for r in reunioes)
    salas = maximo = 0
    j = 0
    for ini in inicios:
        while j < len(fins) and fins[j] <= ini:   # libera salas já vazias
            salas -= 1
            j += 1
        salas += 1
        maximo = max(maximo, salas)
    return maximo

print(salas_necessarias([[9, 10], [9, 12], [10, 11], [11, 13]]))  # 2
```

```javascript
function salasNecessarias(reunioes) {
  const inicios = reunioes.map((r) => r[0]).sort((a, b) => a - b);
  const fins = reunioes.map((r) => r[1]).sort((a, b) => a - b);
  let salas = 0, maximo = 0;
  let j = 0;
  for (const ini of inicios) {
    while (j < fins.length && fins[j] <= ini) {   // libera salas já vazias
      salas--;
      j++;
    }
    salas++;
    maximo = Math.max(maximo, salas);
  }
  return maximo;
}
```

```go
import (
	"fmt"
	"sort"
)

func salasNecessarias(reunioes [][2]int) int {
	inicios, fins := []int{}, []int{}
	for _, r := range reunioes {
		inicios = append(inicios, r[0])
		fins = append(fins, r[1])
	}
	sort.Ints(inicios)
	sort.Ints(fins)
	salas, maximo, j := 0, 0, 0
	for _, ini := range inicios {
		for j < len(fins) && fins[j] <= ini { // libera salas já vazias
			salas--
			j++
		}
		salas++
		if salas > maximo {
			maximo = salas
		}
	}
	return maximo
}

func main() {
	fmt.Println(salasNecessarias([][2]int{{9, 10}, {9, 12}, {10, 11}, {11, 13}})) // 2
}
```

</CodeTabs>

Essa técnica de transformar intervalos em **eventos** (+1 ao abrir, −1 ao fechar) se chama varredura (sweep line). Tempo O(n log n), espaço O(n). Uma alternativa é usar um heap com os horários de término das salas ocupadas.

## Molde 3: remover o mínimo para não sobrepor

Para manter o maior número possível de intervalos sem conflito, ordene pelo **fim** e escolha gananciosamente o que termina mais cedo. Terminar cedo deixa mais espaço para os próximos. Esse é um dos poucos casos em que a ordenação é pelo fim, e não pelo início.

<Callout type="tip" title="Quando reconhecer">
Pares de números representando começo e fim, palavras como agenda, reunião, reserva, cobertura, faixa, sobreposição, conflito, "máximo simultâneo". Se aparecer "sem sobreposição com o mínimo de remoções", pense em guloso ordenando pelo fim.
</Callout>

## Resumo dos moldes

| Problema | Ordenar por | Ideia |
| --- | --- | --- |
| Mesclar intervalos | início | estender o último enquanto sobrepõe |
| Inserir um novo intervalo | já vem ordenado | três fases: antes, sobrepostos, depois |
| Máximo simultâneo | eventos | +1 no início, −1 no fim |
| Máximo de intervalos sem conflito | fim | guloso: menor fim primeiro |
