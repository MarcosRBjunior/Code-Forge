Numa caixa representada pela matriz `grid`, cada célula vale `0` (vazia), `1` (laranja fresca) ou `2` (laranja podre). A cada minuto, toda laranja fresca vizinha (na horizontal ou na vertical) de uma laranja podre também apodrece.

Retorne quantos minutos passam até não restar nenhuma laranja fresca. Se alguma laranja nunca for alcançada, retorne `-1`. Se já não houver laranjas frescas no início, a resposta é `0`.

## Exemplo

```text
Entrada:
2 1 0
1 1 0
0 1 1
Saída: 4
Explicação: a podridão se espalha do canto superior esquerdo e chega à última laranja,
no canto inferior direito, no quarto minuto.
```

## Restrições

- 1 ≤ linhas, colunas ≤ 10
- Cada célula é `0`, `1` ou `2`.

## Dica

Todas as laranjas podres começam a espalhar ao mesmo tempo. Uma BFS que parte de **todas** elas juntas, avançando nível por nível, mede exatamente os minutos.
