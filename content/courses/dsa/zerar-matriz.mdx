Na matriz `m × n`, sempre que uma posição vale `0`, toda a sua linha e toda a sua coluna devem virar `0`. Faça isso **in-place**. Apenas os zeros que existiam antes da chamada contam: um zero criado pela operação não espalha novos zeros.

A função não precisa retornar nada; os testes verificam `matrix`.

## Exemplo

```text
Antes:      Depois:
0 1 2 0     0 0 0 0
3 4 5 2     0 4 5 0
1 3 1 5     0 3 1 0
```

## Restrições

- 1 ≤ `m`, `n` ≤ 200
- -2³¹ ≤ `matrix[i][j]` ≤ 2³¹ - 1

## Dica

Primeiro descubra quais linhas e colunas precisam ser zeradas; só depois altere a matriz. Para usar O(1) de memória extra, a primeira linha e a primeira coluna podem servir de marcadores.
