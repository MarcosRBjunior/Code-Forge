Dada a raiz `root` de uma árvore binária, diga se ela é simétrica em relação a um eixo vertical que passa pela raiz, isto é, se a subárvore da esquerda é o reflexo exato da subárvore da direita (formato e valores).

Uma árvore vazia e uma árvore com um só nó são simétricas.

## Exemplo

```text
Entrada: [1, 2, 2, 3, 4, 4, 3]
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
Saída: true
```

## Restrições

- 0 ≤ número de nós ≤ 1000
- -100 ≤ `val` ≤ 100

## Dica

Escreva uma função auxiliar que receba **dois** nós e diga se um é o espelho do outro. Num espelho, o filho esquerdo de um corresponde ao filho direito do outro.
