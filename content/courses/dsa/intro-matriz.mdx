Muitos problemas de entrevista chegam como uma **grade**: um mapa de ilhas, um tabuleiro, uma imagem, um labirinto. Por trás, é uma lista de listas, e a dificuldade raramente está no algoritmo em si, e sim em **percorrer sem errar índices**. Esta aula reúne os moldes que você vai reutilizar o tempo todo.

## Convenções que evitam bugs

- Use `linhas = len(grade)` e `colunas = len(grade[0])`, e sempre `grade[r][c]` (linha primeiro).
- Nomeie como `r` e `c` (row, column) ou `i` e `j`, mas nunca troque no meio do código.
- Uma matriz de m linhas por n colunas tem m·n células; percorrê-la toda é O(m·n), que é linear no tamanho da entrada.

<Callout type="warning" title="A armadilha da lista repetida">
`[[0] * n] * m` cria m referências para a **mesma** linha: alterar uma altera todas. Use `[[0] * n for _ in range(m)]`.
</Callout>

## Vizinhos com vetor de direções

Em vez de quatro `if` repetidos, declare as direções uma vez e filtre os índices válidos:

<CodeTabs>

```python
DIRECOES = [(-1, 0), (1, 0), (0, -1), (0, 1)]  # cima, baixo, esquerda, direita

def vizinhos(grade, r, c):
    linhas, colunas = len(grade), len(grade[0])
    for dr, dc in DIRECOES:
        nr, nc = r + dr, c + dc
        if 0 <= nr < linhas and 0 <= nc < colunas:
            yield nr, nc

grade = [[1, 2, 3],
         [4, 5, 6]]
print(list(vizinhos(grade, 0, 0)))  # [(1, 0), (0, 1)]
```

## Exemplo: contar ilhas com DFS

Dada uma grade de `"1"` (terra) e `"0"` (água), conte as ilhas. Para cada terra ainda não visitada, some 1 e "afunde" toda a ilha conectada:

<CodeTabs>

```python
def contar_ilhas(grade):
    linhas, colunas = len(grade), len(grade[0])
    ilhas = 0

    def afundar(r, c):
        pilha = [(r, c)]
        grade[r][c] = "0"
        while pilha:
            r, c = pilha.pop()
            for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < linhas and 0 <= nc < colunas and grade[nr][nc] == "1":
                    grade[nr][nc] = "0"
                    pilha.append((nr, nc))

    for r in range(linhas):
        for c in range(colunas):
            if grade[r][c] == "1":
                ilhas += 1
                afundar(r, c)
    return ilhas

mapa = [list("11000"), list("11010"), list("00011")]
print(contar_ilhas(mapa))  # 2
```

Cada célula é visitada no máximo uma vez: tempo O(m·n). O espaço é O(m·n) no pior caso (a pilha), e a grade é alterada in-place. Usar pilha explícita em vez de recursão evita estourar a pilha de chamadas (no Python, o limite de recursão é baixo) em grades grandes.

## Exemplo: transpor e rotacionar

Rotacionar uma matriz quadrada 90° no sentido horário, in-place, é transpor e depois inverter cada linha:

<CodeTabs>

```python
def rotacionar(m):
    n = len(m)
    for i in range(n):
        for j in range(i + 1, n):
            m[i][j], m[j][i] = m[j][i], m[i][j]
    for linha in m:
        linha.reverse()
    return m

print(rotacionar([[1, 2, 3], [4, 5, 6], [7, 8, 9]]))
# [[7, 4, 1], [8, 5, 2], [9, 6, 3]]
```

```java
import java.util.*;

static int[][] rotacionar(int[][] m) {
    int n = m.length;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            int tmp = m[i][j];
            m[i][j] = m[j][i];
            m[j][i] = tmp;
        }
    }
    for (int[] linha : m) { // inverte a linha (int[] não tem reverse)
        for (int a = 0, b = linha.length - 1; a < b; a++, b--) {
            int tmp = linha[a];
            linha[a] = linha[b];
            linha[b] = tmp;
        }
    }
    return m;
}

public static void main(String[] args) {
    System.out.println(Arrays.deepToString(rotacionar(new int[][]{{1, 2, 3}, {4, 5, 6}, {7, 8, 9}})));
    // [[7, 4, 1], [8, 5, 2], [9, 6, 3]]
}
```

```go
func rotacionar(m [][]int) [][]int {

	for i := 0; i < n; i++ {
		for j := i + 1; j < n; j++ {
```

Tempo O(n²), espaço O(1). Repare que o laço interno começa em `i + 1`: se começasse em 0, cada par seria trocado duas vezes e a matriz voltaria ao original.

## Outros percursos frequentes

- **Espiral:** mantenha quatro limites (topo, base, esquerda, direita) e encolha um deles depois de cada lado percorrido.
- **Diagonais:** células da mesma diagonal têm `r - c` constante; da mesma antidiagonal, `r + c` constante.
- **Matriz ordenada por linhas e colunas:** comece no canto superior direito; se o valor é maior que o alvo, vá para a esquerda, senão desça. O(m + n).

## Quando reconhecer

Grade, tabuleiro, mapa, imagem, "células adjacentes", "regiões conectadas". Se for contar ou marcar regiões, é DFS/BFS. Se for caminho mínimo em passos, BFS. Se a resposta de uma célula depende das vizinhas de cima e da esquerda, é DP em grade.
