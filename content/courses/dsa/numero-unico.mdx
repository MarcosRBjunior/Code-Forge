No array `nums`, todo valor aparece **exatamente duas vezes**, exceto um, que aparece uma única vez. Retorne esse valor. Tente usar tempo O(n) e espaço extra O(1).

## Exemplo

```text
Entrada: nums = [4, 1, 2, 1, 2]
Saída: 4
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 3 × 10⁴
- -3 × 10⁴ ≤ `nums[i]` ≤ 3 × 10⁴

## Dica

Existe uma operação de bits em que `x` combinado com ele mesmo dá `0` e `x` combinado com `0` dá `x`.
