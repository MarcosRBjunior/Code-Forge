`prices[i]` é o preço de uma ação no dia `i`. Você pode fazer quantas operações quiser, comprando e vendendo uma unidade por vez, mas com duas regras:

- Só pode ter uma ação em mãos: precisa vender antes de comprar de novo.
- No dia seguinte a uma venda você fica em **espera** e não pode comprar.

Retorne o maior lucro possível. Se nenhuma operação compensar, a resposta é `0`.

## Exemplo

```text
Entrada: prices = [1, 2, 3, 0, 2]
Saída: 3
Explicação: compra no dia 0, vende no dia 1, espera no dia 2, compra no dia 3 e vende no dia 4.
```

## Restrições

- 1 ≤ tamanho de `prices` ≤ 5000
- 0 ≤ `prices[i]` ≤ 1000

## Dica

Descreva cada dia por estados: "com ação", "acabou de vender" e "livre, sem ação". Escreva como cada estado de hoje depende dos de ontem. A espera aparece porque só o estado "livre" pode levar a uma compra.
