Duas palavras são **anagramas** quando uma pode ser formada reorganizando as letras da outra, usando cada letra exatamente quantas vezes ela aparece. Dadas as strings `s` e `t`, retorne verdadeiro se `t` for um anagrama de `s`.

## Exemplo

```text
Entrada: s = "listen", t = "silent"
Saída: true
```

## Restrições

- 0 ≤ tamanho de `s`, `t` ≤ 5 × 10⁴
- As strings contêm apenas letras minúsculas sem acento.

## Dica

Ordenar as duas strings funciona em O(n log n). Dá para fazer em O(n) contando quantas vezes cada letra aparece?
