Dada a raiz `root` de uma árvore binária, diga se ela é uma árvore de busca binária (BST) válida. Numa BST, para **todo** nó, todos os valores da subárvore esquerda são estritamente menores que o valor do nó, e todos os da subárvore direita são estritamente maiores. Valores repetidos, portanto, invalidam a árvore.

A árvore vazia é considerada uma BST válida.

## Exemplo

```text
Entrada: [5, 4, 6, null, null, 3, 7]
      5
     / \
    4   6
       / \
      3   7
Saída: false
Explicação: 3 é filho de 6 corretamente, mas está na subárvore direita de 5 e é menor que 5.
```

## Restrições

- 0 ≤ número de nós ≤ 10.000
- Os valores cabem num inteiro de 32 bits com sinal.

## Dica

Comparar cada nó só com os filhos diretos não basta, como mostra o exemplo. Passe para baixo o intervalo de valores permitidos para cada subárvore. Outra saída: o percurso em ordem de uma BST é estritamente crescente.
