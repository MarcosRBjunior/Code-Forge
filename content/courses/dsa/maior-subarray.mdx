Dado um array de inteiros `nums`, escolha um trecho **contíguo e não vazio** cuja soma seja a maior possível e retorne essa soma. Se todos os números forem negativos, a resposta é o maior deles: você não pode escolher um trecho vazio.

## Exemplo

```text
Entrada: nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
Saída: 6
Explicação: o trecho [4, -1, 2, 1] soma 6.
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 10⁵
- -10⁴ ≤ `nums[i]` ≤ 10⁴

## Dica

Para cada posição, pergunte: vale mais a pena continuar o melhor trecho que termina na posição anterior ou começar um trecho novo aqui?
