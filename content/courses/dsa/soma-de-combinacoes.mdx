Você recebe um array `candidates` de inteiros positivos **distintos** e um inteiro `target`. Liste todas as combinações de números de `candidates` cuja soma dá exatamente `target`. Cada número pode ser usado quantas vezes você quiser.

Duas combinações são consideradas iguais se usam os mesmos números com as mesmas quantidades, independentemente da ordem; não repita combinações. A ordem das combinações e dos números dentro de cada uma não importa. Se não houver nenhuma, retorne uma lista vazia.

## Exemplo

```text
Entrada: candidates = [2, 3, 6, 7], target = 7
Saída: [[2, 2, 3], [7]]
Explicação: 2 + 2 + 3 = 7 e 7 = 7. Não há outra forma.
```

## Restrições

- 1 ≤ tamanho de `candidates` ≤ 30
- 1 ≤ `candidates[i]` ≤ 40, todos distintos
- 1 ≤ `target` ≤ 40

## Dica

Para não gerar a mesma combinação em ordens diferentes (como `[2, 3, 2]` e `[2, 2, 3]`), só permita escolher candidatos a partir do índice atual em diante. Quando a soma passa de `target`, não adianta continuar aquele ramo.
