Dado um inteiro `n`, diga se ele é uma **potência de dois**, ou seja, se existe um inteiro `x >= 0` tal que `n == 2^x`. Lembre que `1 = 2^0` conta.

Dá para resolver dividindo por 2 em laço, mas existe uma solução em O(1) com uma única operação de bits.

## Exemplo

```text
Entrada: n = 16
Saída: true

Entrada: n = 6
Saída: false
```

## Restrições

- `-2^31 <= n <= 2^31 - 1`

## Dica

Em binário, uma potência de dois tem exatamente um bit `1`. O que acontece com esse bit, e com os bits abaixo dele, quando você calcula `n - 1`? Não esqueça de tratar zero e negativos.
