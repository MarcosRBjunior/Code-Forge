Uma rede tem `n` nós, numerados de `1` a `n`. Cada item `[u, v, w]` de `times` é uma ligação **direcionada**: um sinal que sai de `u` chega a `v` depois de `w` unidades de tempo.

Um sinal é emitido a partir do nó `k`. Retorne o tempo mínimo até que **todos** os nós o tenham recebido. Se algum nó nunca receber o sinal, retorne `-1`.

## Exemplo

```text
Entrada: times = [[1, 2, 4], [1, 3, 1], [3, 2, 2]], n = 3, k = 1
Saída: 3
Explicação: o nó 3 recebe no tempo 1; o nó 2 recebe no tempo 3 pelo caminho 1 → 3 → 2,
antes do tempo 4 da ligação direta.
```

## Restrições

- 1 ≤ `n` ≤ 100
- 0 ≤ tamanho de `times` ≤ 6000
- 0 ≤ `w` ≤ 100, sem ligações repetidas.

## Dica

A resposta é a maior entre as menores distâncias de `k` até cada nó. Com pesos não negativos, Dijkstra calcula todas essas distâncias.
