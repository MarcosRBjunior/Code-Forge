Dado um array `nums` de inteiros positivos, retorne verdadeiro se for possível separar **todos** os elementos em dois grupos cujas somas sejam iguais.

## Exemplo

```text
Entrada: nums = [3, 3, 3, 4, 5]
Saída: true
Explicação: [4, 5] e [3, 3, 3] somam 9 cada.
```

## Restrições

- 1 ≤ tamanho de `nums` ≤ 200
- 1 ≤ `nums[i]` ≤ 100

## Dica

Se a soma total for ímpar, a resposta é não. Caso contrário, a pergunta vira: existe um subconjunto que soma exatamente metade do total? É uma mochila 0/1 com valores booleanos.
