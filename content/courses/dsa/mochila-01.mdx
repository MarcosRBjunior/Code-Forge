Você tem `n` itens: o item `i` pesa `weights[i]` e vale `values[i]`. A mochila aguenta no máximo `capacity` de peso. Cada item pode ser levado **inteiro uma vez** ou deixado para trás; não dá para fracionar nem repetir.

Retorne o maior valor total que cabe na mochila.

## Exemplo

```text
Entrada: weights = [1, 3, 4, 5], values = [1, 4, 5, 7], capacity = 7
Saída: 9
Explicação: os itens de peso 3 e 4 somam peso 7 e valor 9.
```

## Restrições

- 0 ≤ `n` ≤ 100, com `weights` e `values` do mesmo tamanho.
- 1 ≤ `weights[i]` ≤ `capacity` ≤ 1000
- 0 ≤ `values[i]` ≤ 1000

## Dica

`dp[c]` guarda o melhor valor com capacidade `c` usando os itens vistos até agora. Ao processar um item, percorra `c` de trás para a frente: assim cada item é contado no máximo uma vez.
