Você recebe um array `nums` ordenado em ordem estritamente crescente. Construa uma árvore de busca binária **balanceada** com esses valores, ou seja, em todo nó as alturas das duas subárvores diferem em no máximo 1, e retorne a raiz.

Várias árvores balanceadas são possíveis; para que a resposta seja única, use sempre como raiz de cada trecho `nums[lo..hi]` o elemento de índice `(lo + hi) // 2` (divisão inteira, arredondando para baixo). Crie os nós com `TreeNode`.

## Exemplo

```text
Entrada: nums = [-10, -3, 0, 5, 9]
        0
       / \
    -10   5
      \    \
      -3    9
Saída: [0, -10, 5, null, -3, null, 9]
```

## Restrições

- 0 ≤ tamanho de `nums` ≤ 10.000
- `nums` está em ordem estritamente crescente.

## Dica

Se a raiz é o elemento do meio, a metade esquerda do array forma a subárvore esquerda e a metade direita forma a direita. Isso já é a recursão inteira; trabalhe com índices em vez de fatiar o array.
