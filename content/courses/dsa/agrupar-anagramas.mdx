Dada uma lista de strings `strs`, agrupe as que são **anagramas** entre si, isto é, que usam exatamente as mesmas letras com as mesmas quantidades, em qualquer ordem.

Retorne a lista de grupos. A ordem dos grupos e a ordem das strings dentro de cada grupo não importam. Strings repetidas na entrada continuam repetidas no grupo.

## Exemplo

```text
Entrada: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
Saída: [["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]
```

## Restrições

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- As strings têm apenas letras minúsculas.

## Dica

Anagramas compartilham uma "assinatura": a própria string com as letras ordenadas, ou o vetor de contagem das 26 letras. Use essa assinatura como chave de um dicionário.
