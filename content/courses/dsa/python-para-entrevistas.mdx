Python é a linguagem mais usada em entrevistas de código porque deixa você escrever pouco e pensar mais. Esta página é uma folha de consulta: as estruturas e os idioms que resolvem 90% dos problemas, com o custo de cada operação.

## Listas, tuplas e fatiamento

```python
nums = [5, 2, 8, 1]
nums.append(3)          # O(1) amortizado
ultimo = nums.pop()     # O(1); pop(0) é O(n)!
nums.sort()             # O(n log n), in-place
copia = nums[::-1]      # fatia invertida, O(n), nova lista
grade = [[0] * 4 for _ in range(3)]   # matriz 3x4 sem referência compartilhada
par = (1, 2)            # tupla: imutável, pode ser chave de dict
print(nums, copia, grade[0], par)
```

`x in lista` é O(n). Se você vai testar pertinência muitas vezes, troque por um `set`.

## Dicionários e conjuntos

```python
from collections import defaultdict, Counter

freq = Counter("banana")             # Counter({'a': 3, 'n': 2, 'b': 1})
print(freq.most_common(1))           # [('a', 3)]

grupos = defaultdict(list)
for palavra in ["ovo", "uva", "oca"]:
    grupos[palavra[0]].append(palavra)
print(dict(grupos))                  # {'o': ['ovo', 'oca'], 'u': ['uva']}

d = {}
d["k"] = d.get("k", 0) + 1           # contagem sem KeyError
vistos = {1, 2, 3}
print(2 in vistos, vistos & {2, 9})  # True {2}
```

Inserção, remoção e busca em `dict` e `set` são O(1) em média. Desde o Python 3.7, `dict` preserva a ordem de inserção.

## Pilha, fila e heap

```python
from collections import deque
import heapq

pilha = []
pilha.append(1); pilha.append(2)
print(pilha.pop())          # 2 (LIFO)

fila = deque([1, 2])
fila.append(3)
print(fila.popleft())       # 1 (FIFO), O(1)

heap = [5, 1, 4]
heapq.heapify(heap)         # O(n)
heapq.heappush(heap, 0)     # O(log n)
print(heapq.heappop(heap))  # 0: min-heap

# max-heap: guarde o valor negado
mx = []
for x in [3, 7, 2]:
    heapq.heappush(mx, -x)
print(-mx[0])               # 7

# k maiores sem ordenar tudo
print(heapq.nlargest(2, [4, 9, 1, 7]))   # [9, 7]
```

Para heap de objetos, empurre tuplas `(prioridade, desempate, item)`; o desempate evita comparar itens que não suportam `<`.

## Ordenação com chave

```python
pessoas = [("ana", 31), ("bia", 25), ("caio", 31)]
pessoas.sort(key=lambda p: (-p[1], p[0]))   # idade desc, nome asc
print(pessoas)
intervalos = sorted([[5, 6], [1, 3], [2, 4]], key=lambda iv: iv[0])
print(intervalos)
```

A ordenação do Python é estável: elementos com mesma chave mantêm a ordem relativa.

## Busca binária pronta

```python
from bisect import bisect_left, bisect_right

a = [1, 3, 3, 3, 7]
print(bisect_left(a, 3), bisect_right(a, 3))   # 1 4: faixa de ocorrências do 3
print(bisect_left(a, 5))                        # 4: onde 5 seria inserido
```

## Idioms que economizam linhas

```python
from functools import cache
from itertools import accumulate, combinations

for i, x in enumerate(["a", "b"]):
    print(i, x)
for x, y in zip([1, 2], [3, 4]):
    print(x + y)

prefixo = list(accumulate([1, 2, 3], initial=0))   # [0, 1, 3, 6]
print(prefixo, list(combinations([1, 2, 3], 2)))

@cache
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
print(fib(50))

print(float("inf") > 10**18, divmod(17, 5), -7 // 2)   # True (3, 2) -4
print("".join(sorted("cba")), ord("a"), chr(98))
```

<Callout type="warning" title="Pegadinhas da linguagem">
`-7 // 2` é -4 (arredonda para baixo), não -3. O limite padrão de recursão é cerca de 1.000 chamadas; para DFS profunda, prefira uma pilha explícita. Strings são imutáveis: concatenar num laço é O(n²) no pior caso, então acumule em lista e use `"".join(...)`.
</Callout>

## Qual estrutura o enunciado está pedindo

Muitas vezes a escolha da estrutura já é metade da solução. Alguns atalhos de reconhecimento:

- "Já vi esse valor?" ou "quantas vezes aparece?": `set` ou `Counter`.
- "Agrupe por alguma característica" (anagramas, mesmo domínio): `defaultdict(list)` com a característica como chave, por exemplo a tupla da palavra ordenada.
- "Os k maiores", "o próximo mais urgente": `heapq`.
- "Processe na ordem de chegada" ou "camada por camada": `deque`.
- "O último aberto precisa fechar primeiro" (parênteses, desfazer): lista usada como pilha.
- "Primeira posição maior ou igual a X" num array ordenado: `bisect`.

## Tabela de custos

| Operação | Custo |
| --- | --- |
| `lista.append`, `lista.pop()` | O(1) amortizado |
| `lista.insert(0, x)`, `lista.pop(0)`, `x in lista` | O(n) |
| `dict`/`set`: inserir, buscar, remover | O(1) médio |
| `deque.appendleft`, `deque.popleft` | O(1) |
| `heappush`, `heappop` | O(log n) |
| `sorted`, `list.sort` | O(n log n) |
| fatia `a[i:j]` | O(j − i) |

## Na entrevista

Use a biblioteca padrão sem medo, mas saiba explicar o custo do que chamou. Se usar `Counter` ou `heapq`, diga a complexidade. Se o entrevistador pedir para implementar algo que a biblioteca já faz, como um heap, faça; ele quer ver o mecanismo.
