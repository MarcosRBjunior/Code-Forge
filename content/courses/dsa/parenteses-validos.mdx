A string `s` contém apenas os caracteres `(`, `)`, `[`, `]`, `{` e `}`. Ela é **válida** quando cada abertura é fechada pelo delimitador do mesmo tipo e os fechamentos acontecem na ordem certa: o último aberto é o primeiro a ser fechado. Retorne verdadeiro se `s` for válida.

## Exemplo

```text
Entrada: s = "{[]}"
Saída: true

Entrada: s = "([)]"
Saída: false
```

## Restrições

- 0 ≤ tamanho de `s` ≤ 10⁴
- `s` contém apenas os seis caracteres de parênteses, colchetes e chaves.

## Dica

"O último aberto é o primeiro a ser fechado" descreve exatamente uma estrutura de dados clássica.
