Texto aparece em metade dos problemas de entrevista: anagramas, palíndromos, janelas deslizantes, parsing. Em Java, `String` é uma classe com características que você precisa conhecer desde o começo, principalmente a imutabilidade, e o `StringBuilder` é a ferramenta para construir texto sem desperdício.

## String é imutável

Um objeto `String` não muda depois de criado. Métodos como `toUpperCase` ou `replace` devolvem uma nova string e não alteram a original. Isso é igual ao Python, mas difere de C++. Acessar um caractere custa O(1) com `charAt(i)`, mas não existe `s[i]`, nem atribuição por posição.

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        String s = "Entrevista";
        System.out.println(s.length());
        System.out.println(s.charAt(0));
        System.out.println(s.substring(2, 5));
        System.out.println(s.indexOf("vis"));
        System.out.println(s.toUpperCase());
        System.out.println(s.contains("rev"));
        System.out.println(s.replace('t', 'T'));
        System.out.println(Arrays.toString("a,b,,c".split(",")));
        System.out.println(String.join("-", "x", "y", "z"));
        System.out.println("[" + "  oi ".trim() + "]");
        System.out.println("ab".repeat(3));
        System.out.println("b".compareTo("a"));
        System.out.println("apple".compareTo("banana"));
    }
}
```

```text
5
ENTREVISTA
true

[oi]

```

`substring(inicio, fim)` inclui o início e exclui o fim, e custa O(k) por copiar k caracteres. `indexOf` devolve -1 quando não acha. `split` recebe uma expressão regular e mantém campos vazios do meio (note o espaço entre as vírgulas), mas descarta os vazios do final. `compareTo` devolve a diferença lexicográfica, negativa, zero ou positiva, e é a base da ordenação alfabética.

## Igualdade: equals, não ==

Como `String` é um objeto, `==` compara referências. Literais iguais costumam apontar para o mesmo objeto (o pool de strings), o que faz `==` parecer funcionar e esconde o bug. Com strings vindas de `new`, de leitura de entrada ou de concatenação em tempo de execução, `==` falha. Use sempre `equals`, ou `equalsIgnoreCase` quando a caixa não importa.

## StringBuilder

Concatenar com `+` dentro de um laço cria uma string nova a cada volta, copiando todo o conteúdo: com n iterações o custo total é O(n²). O `StringBuilder` mantém um buffer mutável e anexa em tempo amortizado O(1) por caractere. Ele também oferece `reverse`, `insert`, `deleteCharAt` e `setCharAt`.

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        String a = "java";
        String c = new String("java");
        System.out.println(a == c);
        System.out.println(a.equals(c));
        System.out.println(a == c.intern());

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 5; i++) {
            sb.append(i).append(',');
        }
        sb.setLength(sb.length() - 1);
        System.out.println(sb);
        sb.reverse();
        System.out.println(sb);
        sb.insert(0, "[").append("]");
        System.out.println(sb);
        sb.setCharAt(1, '9');
        System.out.println(sb);

        char[] cs = "dcba".toCharArray();
        Arrays.sort(cs);
        System.out.println(new String(cs));
        System.out.println(String.valueOf(cs).equals("abcd"));
    }
}
```

```text
Saída:
false
true
true
0,1,2,3,4
4,3,2,1,0
[4,3,2,1,0]
[9,3,2,1,0]
abcd
true
```

O truque `toCharArray` + `Arrays.sort` + `new String` gera a "forma canônica" de uma palavra, que serve de chave de mapa para agrupar anagramas. Já `sb.setLength(sb.length() - 1)` remove o último caractere, um jeito limpo de tirar a vírgula sobrando.

## Armadilhas

- `s.length()` tem parênteses; em arrays é `length` sem eles.
- `char` é numérico: `'a' + 'b'` soma códigos. Para juntar caracteres use `StringBuilder` ou `String.valueOf`.
- `split("|")` e `split(".")` não funcionam como o esperado porque o argumento é regex; escape com `"\\|"` ou use `Pattern.quote`.
- Strings aceitam `+=` em laço, mas o custo quadrático passa despercebido em testes pequenos e explode em entradas grandes.
- Em Java 17 existem blocos de texto com aspas triplas, úteis só para texto multilinha fixo.

## Na entrevista

Converta para `char[]` quando precisar alterar posições, e use `StringBuilder` ao construir a resposta. Diga a complexidade: `charAt` é O(1), `substring`, `indexOf` e `equals` são O(n). Follow-ups: "por que `String` é imutável?" (segurança, cache de hash, uso seguro como chave de mapa e compartilhamento via pool) e "qual a diferença entre `StringBuilder` e `StringBuffer`?" (o segundo é sincronizado e mais lento; use o primeiro).
