O array é a estrutura mais básica de Java: um bloco contíguo de elementos do mesmo tipo, com tamanho fixo definido na criação. Ele é o equivalente de uma lista de Python ou de um array de JavaScript, mas sem crescer e sem métodos próprios. Em compensação, é rápido, compacto e aparece em quase todo problema de entrevista.

## Criar e acessar

Há duas formas de criar: informando o tamanho (todos os elementos começam com o valor padrão, zero para números, `false` para booleanos, `null` para objetos) ou listando os valores. O tamanho está no campo `length`, sem parênteses, diferente de `size()` das listas e de `length()` das strings. Acessar fora dos limites lança `ArrayIndexOutOfBoundsException`; não há índices negativos como em Python.

```java
int[] zeros = new int[5];
int[] dados = {5, 3, 1, 4};
int primeiro = dados[0];
int ultimo = dados[dados.length - 1];
```

O acesso por índice é O(1). Como o tamanho é fixo, "adicionar" um elemento exige criar outro array e copiar tudo, que é O(n); quando precisar crescer, use `ArrayList`.

## A classe utilitária Arrays

Imprimir um array com `System.out.println(arr)` mostra algo como `[I@1b6d3586`, o endereço do objeto. Para ver o conteúdo, use `Arrays.toString` (e `Arrays.deepToString` para matrizes). A mesma classe `java.util.Arrays` traz as operações que você mais usa.

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] a = new int[5];
        Arrays.fill(a, 7);
        System.out.println(Arrays.toString(a));

        int[] b = {5, 3, 1, 4};
        Arrays.sort(b);
        System.out.println(Arrays.toString(b));
        System.out.println(Arrays.binarySearch(b, 4));

        int[] c = Arrays.copyOf(b, 6);
        System.out.println(Arrays.toString(c));
        int[] d = Arrays.copyOfRange(b, 1, 3);
        System.out.println(Arrays.toString(d));

        int[][] m = new int[2][3];
        m[1][2] = 9;
        System.out.println(Arrays.deepToString(m));
    }
}
```

```text
Saída:
[7, 7, 7, 7, 7]
[1, 3, 4, 5]
2
[1, 3, 4, 5, 0, 0]
[3, 4]
[[0, 0, 0], [0, 0, 9]]
```

`Arrays.sort` ordena no lugar em O(n log n). `binarySearch` exige o array já ordenado e devolve o índice, ou um valor negativo quando não encontra. `copyOf` cria um novo array do tamanho pedido (completando com zeros) e `copyOfRange` copia o intervalo com fim exclusivo, a mesma convenção do slice. Uma matriz `new int[2][3]` é um array de arrays: cada linha é um objeto separado, e `new int[3][]` permite linhas com tamanhos diferentes.

## Cópia, igualdade e referência

Atribuir um array a outra variável não copia nada, só duplica a referência. Para copiar use `clone()` ou `Arrays.copyOf`. E `==` compara referências; para comparar conteúdo use `Arrays.equals`. O método `equals` do próprio array também compara referência, o que surpreende quem vem de Python.

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] x = {1, 2, 3};
        int[] y = x;
        y[0] = 99;
        System.out.println(x[0]);

        int[] z = x.clone();
        z[1] = 0;
        System.out.println(Arrays.toString(x));
        System.out.println(x == z);
        System.out.println(Arrays.equals(x, new int[]{99, 2, 3}));
        System.out.println(x.equals(new int[]{99, 2, 3}));
        System.out.println(Arrays.stream(x).sum());

        int[] contagem = new int[26];
        for (char ch : "banana".toCharArray()) {
            contagem[ch - 'a']++;
        }
        System.out.println(contagem[0] + " " + contagem[1] + " " + contagem['n' - 'a']);
    }
}
```

```text
Saída:
99
[99, 2, 3]
false
true
false
104
3 1 2
```

O último trecho é o padrão de contagem por letra: um array de 26 posições indexado por `c - 'a'` substitui um `HashMap` e é mais rápido. Para o alfabeto inteiro com maiúsculas e outros símbolos, use 128 ou 256 posições indexadas diretamente pelo `char`.

## Armadilhas

- `clone()` e `copyOf` fazem cópia rasa: em matrizes, as linhas continuam compartilhadas. Copie linha a linha.
- `Arrays.asList(arr)` com `int[]` não gera uma lista de inteiros, e sim uma lista com um único elemento (o array). Use `Integer[]` ou streams.
- Para ordenar de forma decrescente é preciso `Integer[]`, não `int[]`, porque `Collections.reverseOrder()` trabalha com objetos.
- Arrays de objetos começam com `null`; usar um elemento antes de atribuir gera `NullPointerException`.

## Na entrevista

Quando o tamanho é conhecido, o array primitivo é a escolha mais eficiente em tempo e memória. Diga a complexidade: acesso O(1), busca linear O(n), busca binária O(log n) se ordenado, inserção no meio O(n). Follow-ups comuns: "como inverter um array no lugar?" (dois ponteiros trocando as pontas) e "qual a diferença entre `length`, `length()` e `size()`?".
