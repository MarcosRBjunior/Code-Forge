Em entrevista você raramente escreve um programa inteiro: recebe uma assinatura de método e preenche o corpo. Mesmo assim, entender como um programa Java é montado evita erros bobos de compilação e ajuda quando o enunciado pede um `main` completo.

## O menor programa

Todo código Java vive dentro de uma classe. A execução começa no método `main`, que a máquina virtual procura pelo nome e pela assinatura exatos.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Olá, entrevista!");
    }
}
```

```text
Saída:
Olá, entrevista!
```

Cada palavra tem um papel: `public` deixa o método visível para a JVM, `static` permite chamá-lo sem criar um objeto, `void` indica que ele não devolve nada e `String[] args` recebe os argumentos da linha de comando. O nome do arquivo precisa ser o da classe pública, por isso `Main` vira `Main.java`.

## Compilar e executar

O compilador `javac` transforma o código em bytecode (`Main.class`) e o comando `java` executa esse bytecode na JVM.

```bash
javac Main.java
java Main
```

Plataformas de entrevista fazem isso por você, mas saber o fluxo explica por que um erro de sintaxe aparece antes de qualquer saída: o programa nem chegou a rodar.

## Imprimir resultados

Você usará três formas de imprimir o tempo todo:

```java
public class Main {
    public static void main(String[] args) {
        int soma = 2 + 3;
        System.out.println("soma = " + soma);
        System.out.print("sem quebra de linha");
        System.out.println();
        System.out.printf("pi com 2 casas: %.2f%n", Math.PI);
    }
}
```

```text
Saída:
soma = 5
sem quebra de linha
pi com 2 casas: 3.14
```

`println` termina a linha, `print` não termina e `printf` formata com marcadores como `%d` (inteiro), `%s` (texto) e `%.2f` (decimal com duas casas). Use `%n` para a quebra de linha, que respeita o sistema operacional.

## Imports

Classes fora do pacote `java.lang` precisam ser importadas. As coleções que você vai usar em quase todo problema estão em `java.util`:

```java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<Integer> numeros = new ArrayList<>();
        numeros.add(10);
        numeros.add(20);
        System.out.println(numeros);
    }
}
```

```text
Saída:
[10, 20]
```

Para economizar tempo, muita gente escreve `import java.util.*;`, que traz todas as classes do pacote de uma vez. Em entrevista isso é aceito e evita parar para lembrar de cada nome.

## Comentários

Use `//` para uma linha e `/* ... */` para várias. Em entrevista, um comentário curto explicando a invariante do laço vale mais do que muitos óbvios.

## Na entrevista

Quando o enunciado dá uma classe `Solution` com um método a preencher, você não escreve `main`: o avaliador chama o seu método. Se pedirem um programa completo, lembre-se de `public static void main(String[] args)` e de que o arquivo leva o nome da classe pública. Perguntas de follow-up comuns: "para que serve o `static`?" e "o que acontece se o nome do arquivo for diferente da classe?" (erro de compilação).
