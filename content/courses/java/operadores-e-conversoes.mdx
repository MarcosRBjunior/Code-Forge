Os operadores de Java lembram os de JavaScript, mas com regras de tipo mais rígidas. O comportamento da divisão, do resto com números negativos e das conversões entre tipos é fonte frequente de respostas erradas em entrevista, justamente porque o código compila e roda, só que devolve outra coisa.

## Aritmética e divisão inteira

Quando os dois operandos são inteiros, `/` faz divisão inteira e descarta a parte fracionária (em direção ao zero). Em Python você usaria `//`, que arredonda para baixo; aqui não. O operador `%` devolve o resto com o sinal do dividendo, o que também difere do Python.

```java
public class Main {
    public static void main(String[] args) {
        int a = 7, b = 2;
        System.out.println(a / b);
        System.out.println(a % b);
        System.out.println((double) a / b);
        System.out.println(-7 / 2);
        System.out.println(-7 % 2);
        System.out.println(Math.floorMod(-7, 2));
        System.out.println(1 / 2.0);
        System.out.println(0.1 + 0.2);
    }
}
```

```text
Saída:
3
1
3.5
-3
-1
1
0.5
0.30000000000000004
```

Para obter o resto "matemático" (sempre não negativo, útil em índices circulares e hashing) use `Math.floorMod`. O cast `(double) a / b` converte `a` antes da divisão; escrever `(double) (a / b)` converteria o resultado já truncado, um erro clássico. E, como em qualquer linguagem com ponto flutuante binário, `0.1 + 0.2` não dá exatamente 0.3: compare doubles com tolerância.

## Conversões: ampliação e estreitamento

Converter para um tipo maior (de `int` para `long` ou `double`) é automático. Converter para um tipo menor exige cast explícito, porque pode perder informação. Operadores compostos como `+=` fazem o cast implícito por você, o que esconde truncamentos.

```java
public class Main {
    public static void main(String[] args) {
        int x = 10;
        x += 3.7;
        System.out.println(x);

        byte bt = (byte) 200;
        System.out.println(bt);

        long grande = 1L << 40;
        System.out.println(grande);

        int i = 5;
        int j = i++ + ++i;
        System.out.println(j + " " + i);

        char c = 'a';
        c += 1;
        System.out.println(c);
        System.out.println('a' + 1);
        System.out.println((char) ('a' + 1));

        System.out.println((5 & 3) + " " + (5 | 3) + " " + (5 ^ 3));
        System.out.println((-8 >> 1) + " " + (-8 >>> 28));
    }
}
```

```text
Saída:
13
-56
1099511627776
12 7
b
98
b
1 7 6
-4 15
```

Vamos ler esse resultado. `x += 3.7` calcula 13.7 e o cast implícito corta para 13. O cast `(byte) 200` mantém só os 8 bits baixos e vira -56. Em `1L << 40` o `L` é essencial: com `1 << 40` o deslocamento seria feito em 32 bits e daria outro valor. Na linha de `i++ + ++i`, o primeiro termo vale 5 (e `i` passa a 6), o segundo incrementa para 7 e vale 7, somando 12. Evite escrever expressões assim; elas existem aqui só para você reconhecê-las.

Com `char`, a soma `'a' + 1` vira `int` (98) e precisa de cast para voltar a caractere. Esse truque é a base de contadores por letra, como `contagem[c - 'a']++`.

## Bits e operadores lógicos

`&`, `|` e `^` operam bit a bit (AND, OR, XOR). `>>` desloca preservando o sinal e `>>>` desloca preenchendo com zeros, por isso `-8 >>> 28` dá 15. Para condições use `&&` e `||`, que fazem curto-circuito: `lista != null && lista.size() > 0` não quebra quando a lista é nula. O ternário `cond ? a : b` funciona como em JavaScript.

## Comparações e igualdade de doubles

Não use `==` com `double` esperando igualdade exata após contas. Prefira `Math.abs(x - y) < 1e-9`. Para `NaN`, nem `NaN == NaN` é verdadeiro; use `Double.isNaN`.

## Na entrevista

Sempre pergunte (ou declare) o que acontece com negativos: "o índice pode ser negativo? uso `floorMod`". Ao calcular médias de inteiros, converta para `double` antes de dividir, e ao multiplicar valores grandes promova para `long` antes da multiplicação, não depois. Follow-ups: "qual a diferença entre `>>` e `>>>`?" e "por que `int mid = (lo + hi) / 2` pode falhar?" (soma estoura; prefira `lo + (hi - lo) / 2`).
