Dicionários e conjuntos são as estruturas que mais transformam uma solução O(n²) em O(n). Contar frequências, achar complementos, detectar duplicatas e agrupar itens passam por elas. Java oferece três implementações de cada, que diferem em ordem e custo: hash, árvore e hash com ordem de inserção.

## HashMap e HashSet

`HashMap<K, V>` equivale ao `dict` do Python e ao `Map` do JavaScript. Inserir, buscar e remover custam O(1) em média, desde que o `hashCode` das chaves se distribua bem. A ordem de iteração não é garantida, então nunca dependa dela. `HashSet<E>` é um conjunto sustentado por um `HashMap`: `add` devolve `false` quando o elemento já existe, e `contains` é O(1).

Os métodos que mais ajudam a escrever menos código são `getOrDefault`, `merge` e `computeIfAbsent`:

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        String[] palavras = {"a", "b", "a", "c", "b", "a"};
        Map<String, Integer> freq = new TreeMap<>();
        for (String w : palavras) {
            freq.merge(w, 1, Integer::sum);
        }
        System.out.println(freq);

        Map<String, Integer> h = new HashMap<>();
        h.put("x", 1);
        System.out.println(h.getOrDefault("y", 0));
        System.out.println(h.containsKey("x") + " " + h.get("zzz"));

        Map<Integer, List<String>> grupos = new TreeMap<>();
        for (String w : new String[]{"oi", "ola", "ei", "hey"}) {
            grupos.computeIfAbsent(w.length(), k -> new ArrayList<>()).add(w);
        }
        System.out.println(grupos);

        for (Map.Entry<String, Integer> e : freq.entrySet()) {
            System.out.println(e.getKey() + "->" + e.getValue());
        }
    }
}
```

```text
Saída:
{a=3, b=2, c=1}
0
true null
{2=[oi, ei], 3=[ola, hey]}
a->3
b->2
c->1
```

Usei `TreeMap` nos prints para ter ordem previsível. `merge(w, 1, Integer::sum)` insere 1 quando a chave não existe e soma quando existe, o contador de frequência idiomático. `computeIfAbsent` cria o valor (aqui, uma lista) na primeira vez e devolve sempre o valor associado, evitando o clássico "se não tem, cria; depois adiciona". Note que `get` devolve `null` para chave ausente; se o valor for um `Integer` e você fizer `int n = map.get(k)` sem checar, ocorre `NullPointerException`.

## TreeMap e TreeSet

`TreeMap` e `TreeSet` mantêm as chaves ordenadas numa árvore rubro-negra. Todas as operações custam O(log n), em troca de consultas por ordem que o hash não faz: menor e maior chave, vizinho mais próximo, intervalos.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        TreeMap<Integer, String> t = new TreeMap<>();
        t.put(10, "a");
        t.put(20, "b");
        t.put(30, "c");
        System.out.println(t.floorKey(25) + " " + t.ceilingKey(25));
        System.out.println(t.firstKey() + " " + t.lastEntry().getValue());
        System.out.println(t.headMap(20) + " " + t.higherKey(30));

        Set<Integer> hs = new HashSet<>();
        System.out.println(hs.add(3) + " " + hs.add(3));

        TreeSet<Integer> ts = new TreeSet<>(List.of(5, 1, 9));
        System.out.println(ts.first() + " " + ts.floor(6));
        System.out.println(ts.pollLast());
        System.out.println(ts);

        Map<String, Integer> ordem = new LinkedHashMap<>();
        ordem.put("z", 1);
        ordem.put("a", 2);
        System.out.println(ordem);
    }
}
```

```text
Saída:
20 30
10 c
{10=a} null
true false
1 5
9
[1, 5]
{z=1, a=2}
```

`floorKey(x)` devolve a maior chave menor ou igual a x, `ceilingKey` a menor maior ou igual, e `lowerKey`/`higherKey` as versões estritas. Quando não existe, o resultado é `null`. `headMap(20)` traz as chaves estritamente menores que 20. `LinkedHashMap` preserva a ordem de inserção, útil para saída previsível e, com um construtor especial, para implementar cache LRU.

## Armadilhas

- Chaves mutáveis: se um objeto usado como chave mudar depois de inserido, o `hashCode` muda e ele "some" do mapa. Prefira chaves imutáveis (`String`, `Integer`, `record`).
- Classes próprias como chave precisam de `equals` e `hashCode` coerentes; sem isso, dois objetos "iguais" são chaves diferentes.
- Arrays como chave comparam por referência. Converta para `List` ou `String` antes.
- `HashMap` aceita uma chave `null`; `TreeMap` não.
- Remover de um mapa durante a iteração dispara `ConcurrentModificationException`; use `removeIf` em `entrySet()` ou um iterador.
