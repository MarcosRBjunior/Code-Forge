Em Python você escreve `sorted(xs, key=lambda p: p[1])` e compreensões de lista; em JavaScript, `xs.filter(...).map(...)`. Java ganhou o equivalente no Java 8: lambdas para passar comportamento como argumento e streams para encadear transformações sobre coleções. Em entrevista eles encurtam comparadores e pequenas agregações, mas também tentam você a escrever código lento ou obscuro.

## Lambdas e interfaces funcionais

Uma lambda é uma implementação curta de uma interface com um único método abstrato (interface funcional). As mais comuns estão em `java.util.function`: `Predicate` (devolve boolean), `Function` (transforma), `Consumer` (usa, sem retorno), `Supplier` (produz) e `BiFunction`. A sintaxe é `(parâmetros) -> expressão`. Uma referência de método (`String::length`, `Integer::compare`) é um atalho quando a lambda só chama um método.

```java
import java.util.*;
import java.util.function.*;

public class Main {
    public static void main(String[] args) {
        Predicate<Integer> par = n -> n % 2 == 0;
        Function<String, Integer> tamanho = String::length;
        BiFunction<Integer, Integer, Integer> soma = (a, b) -> a + b;
        Supplier<List<String>> novaLista = ArrayList::new;

        System.out.println(par.test(4) + " " + par.test(7));
        System.out.println(tamanho.apply("entrevista"));
        System.out.println(soma.apply(3, 4));

        List<String> nomes = novaLista.get();
        nomes.add("carlos");
        nomes.add("ana");
        nomes.add("bia");
        nomes.sort(Comparator.comparing(String::length).thenComparing(Comparator.naturalOrder()));
        System.out.println(nomes);

        int base = 10;
        Function<Integer, Integer> somaBase = x -> x + base;
        System.out.println(somaBase.apply(5));
    }
}
```

```text
Saída:
true false
10
7
[ana, bia, carlos]
15
```

Uma lambda só captura variáveis locais que sejam efetivamente finais: `base` não pode ser alterada depois. Se precisar acumular dentro de uma lambda, use um array de um elemento ou um `AtomicInteger`, ou melhor, uma operação de stream que agregue.

## Streams

Um stream não guarda dados: descreve um pipeline sobre uma fonte. As operações intermediárias (`filter`, `map`, `sorted`, `distinct`, `limit`) são preguiçosas e só executam quando uma operação terminal (`collect`, `sum`, `count`, `forEach`, `reduce`, `anyMatch`) é chamada. Um stream só pode ser consumido uma vez.

```java
import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> nums = List.of(5, 2, 8, 3, 8, 1);

        int somaQuadradosPares = nums.stream()
            .filter(n -> n % 2 == 0)
            .mapToInt(n -> n * n)
            .sum();
        System.out.println(somaQuadradosPares);

        List<Integer> unicosOrdenados = nums.stream()
            .distinct()
            .sorted(Comparator.reverseOrder())
            .collect(Collectors.toList());
        System.out.println(unicosOrdenados);

        List<String> palavras = List.of("kiwi", "uva", "pera", "figo", "maca", "abacaxi");
        Map<Integer, Long> porTamanho = palavras.stream()
            .collect(Collectors.groupingBy(String::length, TreeMap::new, Collectors.counting()));
        System.out.println(porTamanho);

        String juntos = palavras.stream().limit(3).collect(Collectors.joining(", "));
        System.out.println(juntos);

        int[] arr = {4, 9, 1};
        System.out.println(Arrays.stream(arr).max().getAsInt());
        System.out.println(IntStream.rangeClosed(1, 5).sum());
    }
}
```

```text
Saída:
132
[8, 5, 3, 2, 1]
{3=1, 4=4, 7=1}
kiwi, uva, pera
9
15
```

Preste atenção em `mapToInt`: ele leva a um `IntStream` de primitivos, com `sum()`, `max()` e `average()` direto, sem boxing. Já `Stream<Integer>` guarda objetos. Para listas de `int[]`, `Arrays.stream(arr)` já devolve um `IntStream`. Para obter lista de volta, `collect(Collectors.toList())` funciona em qualquer versão, e `.toList()` existe a partir do Java 16, devolvendo lista imutável.

## Trade-offs e armadilhas

Streams custam: cada estágio aloca objetos e chamadas indiretas, e em laços muito quentes um `for` simples ganha. Também são mais difíceis de depurar e não permitem `break` nem alteração de variáveis locais. Evite efeitos colaterais dentro de `map` e `filter` (como alterar uma lista externa); o resultado fica confuso, e quebra se alguém trocar para `parallelStream()`, que raramente vale a pena em entrevista.

<Callout type="warning" title="Reuso de stream">
Chamar uma segunda operação terminal no mesmo stream lança `IllegalStateException`. Recrie o stream a partir da coleção.
</Callout>

## Na entrevista

Use lambdas para comparadores (`(a, b) -> a[0] - b[0]`; cuidado com overflow, melhor `Integer.compare`) e streams para agregações curtas, como contar ou agrupar. Quando a lógica tiver estado ou índices, volte ao `for`: é mais rápido de escrever e de explicar. Follow-ups comuns: "o que é lazy evaluation num stream?" e "qual a diferença entre `map` e `flatMap`?" (`flatMap` achata um stream de streams ou listas em um só).
