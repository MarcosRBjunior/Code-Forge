<Quiz question="Você precisa contar quantas vezes cada palavra aparece em um texto de 1 milhão de palavras. Qual estrutura é a mais adequada?" options={["ArrayList com contains", "HashMap de String para Integer com merge", "int[] indexado pela palavra", "PriorityQueue"]} answer={1} explanation="HashMap dá inserção e busca O(1) em média, e merge(palavra, 1, Integer::sum) é o idioma para contar." />
<Quiz question="Um loop monta uma string de 200 mil caracteres com s += c. StringBuilder anexa em tempo amortizado constante." />
<Quiz question="Qual operação é O(n) em ArrayList mas O(1) em LinkedList?" options={["get(i)", "add(0, x)", "size()", "contains(x)"]} answer={1} explanation="Inserir no início do ArrayList desloca todos os elementos. Na LinkedList basta ligar o novo nó. get(i) é o contrário." />
<Quiz question="Qual escolha funciona como pilha eficiente em Java moderno?" options={["Stack", "ArrayDeque usando push e pop", "TreeSet", "Vector"]} answer={1} explanation="ArrayDeque é a recomendação padrão. Stack é legada e sincronizada." />
<Quiz question="Você precisa dos 10 maiores valores de um fluxo com bilhões de itens, sem guardar todos. O que usar?" options={["Ordenar tudo e pegar 10", "Min-heap de tamanho 10", "HashSet", "TreeMap com todos os valores"]} answer={1} explanation="O min-heap limitado a 10 elementos descarta o menor a cada excesso, com memória constante e O(log 10) por item." />
<Quiz question="Um mapa de int[] para contagem não encontra chaves iguais. Por quê?" options={["O mapa não aceita arrays", "Arrays usam hashCode e equals por identidade", "É preciso ordenar o mapa", "O tamanho do array difere sempre"]} answer={1} explanation="Dois arrays com o mesmo conteúdo são objetos distintos. Converta para List ou String antes de usar como chave." />
<Quiz question="Ao ordenar int[][] por início com (a, b) -> a[0] - b[0], qual risco existe?" options={["Ordem decrescente", "Overflow da subtração com valores grandes ou negativos", "Instabilidade garantida", "Erro de compilação"]} answer={1} explanation="A subtração pode estourar int e inverter o sinal. Integer.compare evita o problema." />
