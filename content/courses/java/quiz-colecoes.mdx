Teste arrays, strings, listas, mapas, filas, heaps e ordenação com situações parecidas com as de uma entrevista.

<Quiz question="Você precisa contar quantas vezes cada palavra aparece em um texto de 1 milhão de palavras. Qual estrutura é a mais adequada?" options={["ArrayList de palavras, usando contains antes de cada nova inserção feita","int[] indexado diretamente pela própria palavra lida do texto","HashMap de String para Integer, atualizado com merge a cada palavra","PriorityQueue de palavras, que agrupa automaticamente as palavras repetidas"]} answer={2} explanation="HashMap dá inserção e busca O(1) em média, e merge(palavra, 1, Integer::sum) é o idioma para contar." />
<Quiz question="Um loop monta uma string de 200 mil caracteres com s += c. Qual o problema e a correção?" options={["O laço funciona bem para esse tamanho e não há nada a corrigir no código","Estouro de int no contador do laço; trocar esse contador por long","Perda de caracteres na concatenação; usar char[] de tamanho fixo","Custo quadrático por cópias sucessivas; usar StringBuilder para anexar"]} answer={3} explanation="String é imutável e cada += copia o conteúdo. StringBuilder anexa em tempo amortizado constante." />
<Quiz question="Qual operação é O(n) em ArrayList mas O(1) em LinkedList?" options={["get(i), que acessa o elemento pela posição indicada","size(), que devolve a quantidade de elementos atual","contains(x), que procura o elemento percorrendo a coleção","add(0, x), que insere um elemento no início da lista"]} answer={3} explanation="Inserir no início do ArrayList desloca todos os elementos. Na LinkedList basta ligar o novo nó. get(i) é o contrário." />
<Quiz question="Qual escolha funciona como pilha eficiente em Java moderno?" options={["Stack, que é a recomendação atual e substitui o Deque","ArrayDeque, usando os métodos push e pop","TreeSet, que guarda os elementos na ordem de inserção","Vector, que é mais leve por não ter sincronização"]} answer={1} explanation="ArrayDeque é a recomendação padrão. Stack é legada e sincronizada." />
<Quiz question="Você precisa dos 10 maiores valores de um fluxo com bilhões de itens, sem guardar todos. O que usar?" options={["Ordenar tudo e pegar 10", "Min-heap de tamanho 10", "HashSet", "TreeMap com todos os valores"]} answer={1} explanation="O min-heap limitado a 10 elementos descarta o menor a cada excesso, com memória constante e O(log 10) por item." />
<Quiz question="Um mapa de int[] para contagem não encontra chaves iguais. Por quê?" options={["O mapa não aceita arrays e descarta a chave silenciosamente","É preciso ordenar o mapa antes de consultar as chaves repetidas","Arrays usam hashCode e equals por identidade, não por conteúdo","O tamanho dos arrays é sempre diferente entre as chaves repetidas"]} answer={2} explanation="Dois arrays com o mesmo conteúdo são objetos distintos. Converta para List ou String antes de usar como chave." />
<Quiz question="Ao ordenar int[][] por início com (a, b) -> a[0] - b[0], qual risco existe?" options={["A ordenação sai decrescente, e não crescente, por causa da subtração","Overflow da subtração quando há valores grandes ou negativos","A ordenação se torna instável por causa da subtração dos valores","Erro de compilação, pois int[] não aceita comparador"]} answer={1} explanation="A subtração pode estourar int e inverter o sinal. Integer.compare evita o problema." />
<Quiz question="Num for-each sobre uma ArrayList você chama list.remove(elemento). O que ocorre normalmente?" options={["A remoção ocorre normalmente e o laço segue sem problemas","O elemento removido é ignorado e o laço continua sem alterações","Lança ConcurrentModificationException na iteração seguinte","O laço reinicia desde o primeiro elemento após a remoção"]} answer={2} explanation="O iterador detecta modificação estrutural fora dele. Use removeIf ou Iterator.remove." />
