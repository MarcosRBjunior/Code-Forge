Pilha (último a entrar, primeiro a sair) e fila (primeiro a entrar, primeiro a sair) são a base de validação de parênteses, avaliação de expressões, busca em largura, janelas deslizantes e simulações. Em Python você usa uma lista e `collections.deque`; em JavaScript, um array com `push`/`pop`/`shift`. Java tem uma resposta única e boa: `ArrayDeque`.

## Por que ArrayDeque

Existe uma classe `Stack`, mas ela é legada: herda de `Vector`, é sincronizada (e portanto mais lenta) e expõe métodos de lista que quebram a ideia de pilha. Para filas, a interface `Queue` pode ser implementada por `LinkedList`, que gasta memória com nós. A recomendação padrão é declarar com a interface `Deque` e instanciar `ArrayDeque`, um buffer circular que faz inserção e remoção nas duas pontas em O(1) amortizado.

Como pilha, use `push`, `pop` e `peek`, que operam no início do deque. Como fila, use `offer` (insere no fim), `poll` (remove do início) e `peek` (olha o início).

```java
import java.util.*;

public class Main {
    static boolean balanceado(String s) {
        Deque<Character> pilha = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                pilha.push(c);
            } else {
                if (pilha.isEmpty()) return false;
                char abre = pilha.pop();
                if (c == ')' && abre != '(') return false;
                if (c == ']' && abre != '[') return false;
                if (c == '}' && abre != '{') return false;
            }
        }
        return pilha.isEmpty();
    }

    public static void main(String[] args) {
        Deque<Integer> st = new ArrayDeque<>();
        st.push(1);
        st.push(2);
        st.push(3);
        System.out.println(st.peek());
        System.out.println(st.pop());
        System.out.println(st);

        System.out.println(balanceado("([]{})"));
        System.out.println(balanceado("(]"));
        System.out.println(balanceado("(("));
    }
}
```

```text
Saída:
3
3
[2, 1]
true
false
false
```

Como `push` insere no início, o `toString` da pilha mostra o topo primeiro: `[2, 1]`. O algoritmo da validação é padrão: cada abertura é empilhada; cada fechamento precisa casar com o topo; no fim a pilha tem de estar vazia. Repare que `char abre = pilha.pop()` desembrulha o `Character` automaticamente.

## Filas e as duas pontas

`Queue` oferece dois pares de métodos para o mesmo efeito, com comportamento diferente quando algo dá errado: `offer`/`poll`/`peek` devolvem `false` ou `null`, enquanto `add`/`remove`/`element` lançam exceção. Em entrevista, prefira o primeiro grupo e teste o retorno. Já o `Deque` completo traz `addFirst`, `addLast`, `pollFirst`, `pollLast`, `peekFirst` e `peekLast`.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Queue<String> q = new ArrayDeque<>();
        q.offer("a");
        q.offer("b");
        System.out.println(q.peek());
        System.out.println(q.poll());
        System.out.println(q);
        q.poll();
        System.out.println(q.poll());
        try {
            q.remove();
        } catch (NoSuchElementException e) {
            System.out.println("vazia");
        }

        Deque<Integer> d = new ArrayDeque<>();
        d.addFirst(1);
        d.addLast(2);
        d.addFirst(0);
        System.out.println(d);
        System.out.println(d.pollLast() + " " + d.peekFirst());

        List<List<Integer>> adj = List.of(List.of(1, 2), List.of(3), List.of(3), List.of());
        boolean[] visto = new boolean[4];
        List<Integer> ordem = new ArrayList<>();
        Queue<Integer> fila = new ArrayDeque<>();
        fila.offer(0);
        visto[0] = true;
        while (!fila.isEmpty()) {
            int u = fila.poll();
            ordem.add(u);
            for (int v : adj.get(u)) {
                if (!visto[v]) {
                    visto[v] = true;
                    fila.offer(v);
                }
            }
        }
        System.out.println(ordem);
    }
}
```

```text
Saída:
a
a
[b]
null
vazia
[0, 1, 2]
2 0
[0, 1, 2, 3]
```

O trecho final é uma busca em largura num grafo de quatro nós: marcar como visitado ao enfileirar (e não ao desenfileirar) evita que o mesmo nó entre duas vezes na fila. Observe também que `poll` numa fila vazia devolve `null`, enquanto `remove` lança `NoSuchElementException`.

## Armadilhas

- `ArrayDeque` não aceita `null`: `push(null)` lança `NullPointerException`.
- Não use `Stack` nem `LinkedList` sem motivo; ambos aparecem em código antigo, e o entrevistador pode perguntar por que você evitou.
- Iterar um `ArrayDeque` usado como pilha começa pelo topo, o que difere da ordem de uma lista.
- `size()` e `isEmpty()` são O(1), mas `contains` é O(n).

## Na entrevista

Declare com `Deque<Integer> pilha = new ArrayDeque<>()`, mesmo para fila quando precisar das duas pontas, como em janelas deslizantes com deque monotônico. Cite que as operações são O(1) amortizado. Follow-ups: "como implementar uma fila com duas pilhas?" (pilha de entrada e de saída, transferindo só quando a de saída esvazia, o que dá O(1) amortizado) e "por que `Stack` é desaconselhada?".
