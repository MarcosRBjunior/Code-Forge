Ordenar é o passo preparatório de metade dos problemas: intervalos, duas pontas, agrupamentos, "mais próximo de". Em Python você escreve `sorted(lista, key=...)`; em JavaScript, `arr.sort((a, b) => a - b)`. Java chega ao mesmo lugar com `Arrays.sort`, `Collections.sort` e `Comparator`, só que o tipo importa: ordenar `int[]` e ordenar objetos seguem regras diferentes.

## Ordem natural

Primitivos e tipos que implementam `Comparable` (como `String`, `Integer`) ordenam sem nenhum argumento extra. `Arrays.sort(int[])` usa uma variante de quicksort (dual-pivot), em média O(n log n) e sem memória extra relevante. Para objetos, `Arrays.sort(T[])`, `Collections.sort` e `List.sort` usam o TimSort: O(n log n) garantido e estável, ou seja, elementos iguais mantêm a ordem original.

## Comparator

Um `Comparator` compara dois elementos e devolve negativo, zero ou positivo. A API moderna monta comparadores a partir de funções de extração de chave, encadeando critérios com `thenComparing` e invertendo com `reversed`.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<String> w = new ArrayList<>(List.of("pera", "uva", "banana", "kiwi", "figo"));
        w.sort(Comparator.comparingInt(String::length).thenComparing(Comparator.naturalOrder()));
        System.out.println(w);

        w.sort(Comparator.comparingInt(String::length).reversed());
        System.out.println(w.get(0));

        Integer[] nums = {3, 9, 1, 7};
        Arrays.sort(nums, Collections.reverseOrder());
        System.out.println(Arrays.toString(nums));

        int[] prim = {3, 9, 1, 7};
        Arrays.sort(prim);
        System.out.println(Arrays.toString(prim));

        Arrays.sort(prim, 1, 3);
        System.out.println(Arrays.toString(prim));
    }
}
```

```text
Saída:
[uva, figo, kiwi, pera, banana]
banana
[9, 7, 3, 1]
[1, 3, 7, 9]
[1, 3, 7, 9]
```

A primeira ordenação compara pelo tamanho e, em caso de empate, pela ordem alfabética. A segunda inverte só o critério de tamanho: como o TimSort é estável, a primeira palavra do resultado é a mais longa. Para ordenar `int[]` de forma decrescente é preciso um `Integer[]`, pois `Comparator` não funciona com primitivos; a alternativa é ordenar crescente e percorrer de trás para frente. A forma `Arrays.sort(arr, de, ate)` ordena só um intervalo (fim exclusivo).

## Ordenar pares e intervalos

Em problemas com `int[][]` (intervalos, pontos), o lambda compara linha a linha. A tentação é escrever `(a, b) -> a[0] - b[0]`, que é curto, mas pode estourar `int` quando os valores são grandes ou negativos. Prefira `Integer.compare`.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        int a = 2_000_000_000, b = -2_000_000_000;
        System.out.println(a - b);
        System.out.println(Integer.compare(a, b));

        int[][] intervalos = {{5, 8}, {1, 3}, {2, 4}};
        Arrays.sort(intervalos, (x, y) -> Integer.compare(x[0], y[0]));
        System.out.println(Arrays.deepToString(intervalos));

        int[][] pontos = {{3, 1}, {1, 2}, {3, 0}, {1, 1}};
        Arrays.sort(pontos, Comparator.comparingInt((int[] p) -> p[0]).thenComparingInt(p -> p[1]));
        System.out.println(Arrays.deepToString(pontos));

        List<int[]> merged = new ArrayList<>();
        int[][] ordenados = {{1, 3}, {2, 6}, {8, 10}};
        for (int[] iv : ordenados) {
            if (merged.isEmpty() || merged.get(merged.size() - 1)[1] < iv[0]) {
                merged.add(iv);
            } else {
                int[] ultimo = merged.get(merged.size() - 1);
                ultimo[1] = Math.max(ultimo[1], iv[1]);
            }
        }
        System.out.println(merged.size());
    }
}
```

```text
Saída:
-294967296
1
[[1, 3], [2, 4], [5, 8]]
[[1, 1], [1, 2], [3, 0], [3, 1]]
2
```

A primeira linha mostra o bug: 2 bilhões menos (-2 bilhões) dá 4 bilhões, que passa de 2,1 bilhões e volta negativo, então um comparador `a - b` diria que `a` é menor que `b`, o contrário do correto. O exemplo termina com o início do clássico "mesclar intervalos": ordene por início e, para cada intervalo, ou ele começa depois do fim do último mesclado (novo bloco) ou estende o fim.

## Comparable em classes próprias

Se uma classe tem uma ordem natural, implemente `Comparable<T>` e o método `compareTo`. Isso permite usá-la direto em `Collections.sort`, `TreeSet`, `TreeMap` e `PriorityQueue` sem comparador. Mantenha `compareTo` consistente com `equals`; do contrário, um `TreeSet` pode tratar objetos diferentes como duplicatas.

## Armadilhas

- `Arrays.sort(int[])` não aceita comparador; converta para `Integer[]` quando precisar de um.
- `Comparator` com `a - b` falha por overflow; use `Integer.compare` ou `Long.compare`.
- Comparar `double` com `==` dentro do comparador quebra a transitividade; use `Double.compare`.
- Um comparador inconsistente (que viola a transitividade) pode lançar "Comparison method violates its general contract".
- Para strings com acento ou caixa mista, a ordem natural é pela tabela Unicode, não alfabética; use `String.CASE_INSENSITIVE_ORDER` quando precisar ignorar a caixa.
