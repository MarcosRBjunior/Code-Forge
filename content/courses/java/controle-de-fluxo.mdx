Condicionais e laços em Java têm a mesma cara dos de JavaScript: chaves, ponto e vírgula e parênteses obrigatórios. As diferenças que importam estão nas condições, que precisam ser estritamente `boolean`, nos laços sobre coleções e nos recursos extras como `switch` com expressão e rótulos de `break`.

## if e condições booleanas

Em Python e JavaScript, um número ou uma lista vazia podem funcionar como "falso". Em Java isso não existe: `if (n)` com `int` é erro de compilação. Escreva `if (n != 0)` ou `if (!lista.isEmpty())`. O benefício é que o erro clássico `if (x = 5)` não compila.

```java
if (nota >= 7) {
    System.out.println("aprovado");
} else if (nota >= 5) {
    System.out.println("recuperação");
} else {
    System.out.println("reprovado");
}
```

## for, for-each e while

O `for` clássico tem inicialização, condição e passo. O for-each percorre arrays e qualquer `Iterable` sem índice, equivalente ao `for x in lista` do Python. Use o clássico quando precisar do índice ou de alterar a posição.

```java
public class Main {
    static String classificar(int n) {
        return switch (n % 3) {
            case 0 -> "zero";
            case 1 -> "um";
            default -> "dois";
        };
    }

    public static void main(String[] args) {
        int soma = 0;
        for (int i = 1; i <= 5; i++) {
            soma += i;
        }
        System.out.println(soma);

        int[] v = {4, 8, 15};
        for (int x : v) {
            System.out.println(x + ",");
        }

        for (int n = 0; n < 4; n++) {
            System.out.println(classificar(n));
        }
    }
}
```

```text
Saída:
15
4,
8,
15,
zero
um
dois
zero
```

O `switch` acima é uma expressão (disponível desde o Java 14): cada `case` com seta devolve um valor, não há fall-through e o compilador exige cobrir todos os casos, por isso o `default`. O `switch` antigo, com dois pontos, continua válido, mas cada caso precisa de `break`, senão a execução cai no seguinte. Se você vir um bug em que "todos os casos executaram", é isso.

## break, continue e rótulos

`break` sai do laço mais interno e `continue` pula para a próxima iteração. Para sair de laços aninhados de uma vez, Java oferece rótulos, algo que Python e JavaScript tratam de outro modo (em JavaScript existe, em Python não). Um rótulo vai antes do laço, e `break rotulo` encerra aquele laço específico.

```java
public class Main {
    public static void main(String[] args) {
        int[][] grid = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
        int alvo = 5;
        int linha = -1, col = -1;
        busca:
        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[i].length; j++) {
                if (grid[i][j] == alvo) {
                    linha = i;
                    col = j;
                    break busca;
                }
            }
        }
        System.out.println("achou em " + linha + "," + col);

        int n = 27, passos = 0;
        while (n != 1) {
            n = (n % 2 == 0) ? n / 2 : 3 * n + 1;
            passos++;
        }
        System.out.println(passos);

        int k = 0;
        do {
            k++;
        } while (k < 3);
        System.out.println(k);

        int impares = 0;
        for (int i = 1; i <= 9; i++) {
            if (i % 2 == 0) continue;
            impares += i;
        }
        System.out.println(impares);
    }
}
```

```text
Saída:
achou em 1,1
111
3
25
```

O segundo trecho percorre a sequência de Collatz a partir de 27, que leva 111 passos até chegar a 1. O `do-while` garante ao menos uma execução do corpo, porque testa a condição depois. E o `continue` pula os pares, somando só 1, 3, 5, 7 e 9.

## Armadilhas

- Modificar uma coleção dentro de um for-each lança `ConcurrentModificationException`; use `Iterator` ou `removeIf`.
- Em `for (int i = 0; i <= n; i++)` com array de tamanho n, o último acesso estoura o índice. Confira sempre se o limite é `<` ou `<=`.
- Variáveis declaradas no cabeçalho do `for` não existem depois dele.
- Um `;` solto depois do `if (cond);` transforma o corpo em instrução vazia e o bloco seguinte roda sempre.

(rótulo, ou extrair para um método e usar `return`) e "o que muda no `switch` com seta?" (sem fall-through, pode devolver valor).
