Arrays têm tamanho fixo, mas a maioria dos problemas pede uma sequência que cresce: coletar resultados, acumular candidatos, montar um caminho. A interface `List` resolve isso, e `ArrayList` é a implementação que você usa em 95% dos casos. Ela corresponde à `list` do Python e ao array de JavaScript.

## ArrayList: array que cresce

Por baixo, um `ArrayList` guarda um array. Quando ele enche, aloca outro com cerca de 1,5 vez o tamanho e copia. Por isso `add` no fim é O(1) amortizado, `get` e `set` por índice são O(1), mas inserir ou remover no meio é O(n), já que os elementos seguintes precisam deslizar. Os tipos são sempre wrappers: `List<Integer>`, nunca `List<int>`.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> l = new ArrayList<>();
        l.add(10);
        l.add(20);
        l.add(30);
        l.add(1, 15);
        System.out.println(l);
        System.out.println(l.get(2));
        l.set(0, 11);
        l.remove(Integer.valueOf(20));
        System.out.println(l);
        l.remove(0);
        System.out.println(l);
        System.out.println(l.contains(30) + " " + l.indexOf(15) + " " + l.size());
    }
}
```

```text
Saída:
[10, 15, 20, 30]
20
[11, 15, 30]
[15, 30]
true 0 2
```

Declare a variável com a interface (`List<Integer> l = new ArrayList<>()`) para poder trocar a implementação depois. O operador diamante `<>` deixa o compilador inferir o tipo genérico.

## A armadilha do remove

`List` tem dois métodos `remove`: um recebe `int` e remove pela posição, o outro recebe `Object` e remove pelo valor. Numa `List<Integer>`, `l.remove(20)` remove o índice 20 (e lança exceção se não existir). Para remover o valor 20, escreva `l.remove(Integer.valueOf(20))`, como no exemplo. É uma pergunta clássica de entrevista.

## LinkedList

`LinkedList` é uma lista duplamente encadeada. Inserir ou remover nas pontas é O(1), mas acessar por índice é O(n), porque é preciso caminhar pelos nós. Além de `List`, ela implementa `Deque`, então serve como fila ou pilha. Na prática, `ArrayDeque` é melhor para esses papéis, e `ArrayList` ganha na quase totalidade das tarefas por causa da localidade de memória: percorrer um array contíguo é muito mais rápido do que seguir ponteiros. A vantagem teórica de inserir no meio em O(1) só vale se você já tem o iterador na posição.

| Operação | ArrayList | LinkedList |
|----------|-----------|------------|
| `get(i)` | O(1) | O(n) |
| `add` no fim | O(1) amortizado | O(1) |
| `add(0, x)` | O(n) | O(1) |
| remover no meio por índice | O(n) | O(n) para achar |
| `contains` | O(n) | O(n) |

## Modificar enquanto percorre

Remover elementos dentro de um for-each lança `ConcurrentModificationException`, porque o iterador detecta que a lista mudou por fora. Use `removeIf`, um `Iterator` com `it.remove()` ou um laço por índice de trás para frente. Outra pegadinha: `List.of(...)` devolve uma lista imutável, e `add` ou `remove` nela lançam `UnsupportedOperationException`. Para uma lista editável, envolva em `new ArrayList<>(List.of(...))`.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> nums = new ArrayList<>(List.of(1, 2, 3, 4, 5, 6));
        nums.removeIf(n -> n % 2 == 0);
        System.out.println(nums);

        List<Integer> t = new ArrayList<>(List.of(1, 2, 3));
        try {
            for (int x : t) {
                if (x == 1) t.remove(Integer.valueOf(x));
            }
        } catch (ConcurrentModificationException e) {
            System.out.println("CME");
        }

        try {
            List.of(1, 2).add(3);
        } catch (UnsupportedOperationException e) {
            System.out.println("imutavel");
        }

        LinkedList<Integer> ll = new LinkedList<>();
        ll.addFirst(1);
        ll.addLast(2);
        ll.addFirst(0);
        System.out.println(ll);
        System.out.println(ll.removeFirst());

        List<Integer> v = new ArrayList<>(List.of(3, 1, 2));
        Collections.sort(v);
        Collections.reverse(v);
        System.out.println(v + " " + v.subList(0, 2));
    }
}
```

```text
Saída:
[1, 3, 5]
CME
imutavel
[0, 1, 2]
0
[3, 2, 1] [3, 2]
```

`subList` devolve uma visão da lista original, não uma cópia; alterá-la altera a lista base. Faça `new ArrayList<>(v.subList(0, 2))` quando precisar de uma cópia independente. `Collections.sort` e `Collections.reverse` trabalham no lugar.
