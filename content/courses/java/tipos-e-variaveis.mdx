Em Python e JavaScript uma variável aceita qualquer valor e o tipo é descoberto em tempo de execução. Java é estaticamente tipado: você declara o tipo, o compilador confere cada uso e recusa o que não bate. Isso parece burocracia no começo, mas elimina uma classe inteira de erros antes de o código rodar e deixa claro, numa entrevista, o que cada variável guarda.

## Tipos primitivos

Java tem oito tipos primitivos. Na prática você usa cinco o tempo todo:

| Tipo | Tamanho | Faixa | Uso típico |
|------|---------|-------|------------|
| `int` | 32 bits | cerca de menos 2,1 bilhões a 2,1 bilhões | contadores, índices |
| `long` | 64 bits | cerca de 9,2 vezes 10 elevado a 18 | somas grandes, timestamps |
| `double` | 64 bits | ponto flutuante | médias, razões |
| `boolean` | - | `true` ou `false` | condições |
| `char` | 16 bits | um caractere UTF-16 | caracteres de uma string |

Os outros três são `byte`, `short` e `float`, raros em problemas de entrevista. Diferente de Python, `int` tem tamanho fixo: ele estoura em silêncio em vez de crescer. Esse é o assunto de um capítulo próprio mais adiante.

```java
public class Main {
    public static void main(String[] args) {
        int idade = 30;
        long populacao = 8_000_000_000L;
        double preco = 19.99;
        boolean ativo = true;
        char letra = 'A';
        var nome = "Ana";
        System.out.println(idade + " " + populacao + " " + preco + " " + ativo + " " + letra + " " + nome);
        System.out.println(Integer.MAX_VALUE);
        System.out.println(Long.MAX_VALUE);
        System.out.println(Integer.MIN_VALUE);
    }
}
```

```text
Saída:
30 8000000000 19.99 true A Ana
2147483647
9223372036854775807
-2147483648
```

Três detalhes aparecem aí. O sufixo `L` é obrigatório em literais maiores que um `int`, senão o compilador reclama que o número é grande demais. O sublinhado em `8_000_000_000L` só ajuda a leitura. E `var` deixa o compilador inferir o tipo a partir do lado direito; continua sendo tipagem estática, apenas sem você escrever o nome do tipo.

Aspas simples criam um `char`, aspas duplas criam uma `String`. Misturar os dois é um erro comum de quem vem de JavaScript, onde tanto faz.

## Tipos de referência e wrappers

Tudo que não é primitivo é uma referência para um objeto: `String`, arrays, listas, suas próprias classes. Cada primitivo tem um wrapper: `Integer`, `Long`, `Double`, `Boolean`, `Character`. As coleções genéricas só aceitam wrappers, por isso você escreve `List<Integer>` e nunca `List<int>`. A conversão entre os dois é automática (autoboxing), mas tem custo e uma armadilha clássica.

```java
public class Main {
    public static void main(String[] args) {
        Integer a = 127, b = 127;
        Integer c = 1000, d = 1000;
        System.out.println(a == b);
        System.out.println(c == d);
        System.out.println(c.equals(d));

        String s1 = "oi";
        String s2 = new String("oi");
        System.out.println(s1 == s2);
        System.out.println(s1.equals(s2));

        int max = Integer.MAX_VALUE;
        System.out.println(max + 1);
    }
}
```

```text
Saída:
true
false
true
false
true
-2147483648
```

Para referências, `==` compara identidade (é o mesmo objeto?) e `equals` compara conteúdo. Os `Integer` entre menos 128 e 127 vêm de um cache, então `a == b` dá `true` por acaso, enquanto `c == d` dá `false`. Regra simples: com objetos, use sempre `equals`. A última linha mostra o estouro: somar 1 ao maior `int` volta ao menor valor, sem erro nem aviso.

## Valores padrão, constantes e escopo

Campos de objetos e elementos de arrays começam com valor padrão (0, `false`, `null`), mas variáveis locais não: usar uma local sem inicializar é erro de compilação. Para constantes use `final`; em um campo estático, o idioma é `static final int LIMITE = 100;`. O escopo de uma variável termina na chave que a contém, e não é permitido redeclarar o mesmo nome num escopo interno.

## Na entrevista

Declare tipos com cuidado: use `long` quando a soma ou o produto puder passar de 2 bilhões, e `int` no restante para economizar memória em arrays grandes. Prefira `equals` para comparar `String` e wrappers. Follow-ups comuns: "qual a diferença entre `int` e `Integer`?" (primitivo versus objeto, que pode ser `null` e custa mais memória) e "por que `new Integer(5)` está obsoleto?" (o cache de `valueOf` é melhor).
