Java é a linguagem de back-end de bancos, seguradoras, varejo e boa parte dos sistemas que não podem cair. As vagas são muitas e pedem quase sempre o mesmo conjunto: Java moderno, Spring Boot, banco relacional, testes, segurança e alguma noção de nuvem e microsserviços. Esta carreira põe esse conjunto em ordem, do primeiro programa até a arquitetura de sistemas distribuídos.

O alvo é a vaga de **desenvolvedor back-end Java**: alguém que constrói e mantém APIs com Spring, protege essas APIs, escreve testes que dão confiança para mudar o código e entende como o sistema roda em produção.

## Como a carreira está organizada

| Módulo | Você sai sabendo | Cursos |
|---|---|---|
| Base: fundamentos de programação | Pensamento computacional e lógica de programação | 1 |
| Nível 1: aplicações web com Java e Spring | Java e orientação a objetos, coleções, streams, JPA, primeira API, exceções, refatoração, testes, Docker | 15 |
| Nível 2: APIs seguras, microsserviços e CI/CD | Spring Boot 3, Spring Security, OAuth2, microsserviços, RabbitMQ, testes de integração, pipelines | 16 |
| Nível 3: sistemas reativos, observabilidade e arquitetura avançada | Arquitetura moderna, padrões de integração, Kafka, WebFlux, Spring Batch, IA com LangChain4j, Kubernetes, entrega contínua | 14 |

O Nível 1 leva você até a primeira API conectada a um front-end, com código limpo e testado. O Nível 2 é o que a maioria das vagas pleno pede no dia a dia: Spring Boot 3 bem configurado, segurança de verdade e o primeiro contato com microsserviços. O Nível 3 é o território do sênior: decidir arquitetura, integrar sistemas distribuídos, medir e escalar.

## Como usar

- **Siga a ordem dentro de cada nível.** Os cursos de Spring Boot 3 e de Spring Security são sequências: cada um parte do que o anterior construiu.
- **Marque cada capítulo como concluído** quando terminar. O progresso do módulo mostra quanto falta para fechar o nível.
- **Use as notas do CodeForge como diário de bordo.** Anote anotações do Spring que você esqueceu, erros de configuração que custaram uma tarde e decisões de arquitetura. Isso vira material para o README e para a entrevista.
- **Publique o que construir.** A API que atravessa a carreira pode virar um repositório público com README, testes e pipeline. Veja [Projetos para portfólio](/learn/projetos-portfolio) para transformá-la num projeto que conta no currículo.

<Callout type="tip" title="Java moderno desde o começo">
Muito material antigo ainda ensina Java 8 e Spring Boot 2. Aqui os exemplos usam Java 21 (records, `var`, pattern matching) e Spring Boot 3 (pacotes `jakarta.*`, Spring Security 6). Se um tutorial na internet usa `javax.*` ou `WebSecurityConfigurerAdapter`, ele está desatualizado.
</Callout>

## Por onde começar

Se você nunca programou, comece pelo capítulo de pensamento computacional. Se já programa em outra linguagem, vá direto para o primeiro capítulo do Nível 1 e acelere nos trechos que já conhece.
