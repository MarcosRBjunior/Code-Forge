Toda API Spring que você vai escrever nesta carreira é, no fundo, um programa Java com um método `main`, variáveis, decisões e laços. Antes de frameworks, vale montar uma aplicação pequena do zero: instalar o JDK, entender o que compila e o que roda, ler dados do usuário e organizar o código em métodos. Neste capítulo você constrói o primeiro programa da clínica que acompanha a carreira: um terminal de recepção que cadastra o atendimento e calcula o valor da consulta.

**Você vai aprender:**

- Instalar o JDK 21 e rodar Java com `javac`, `java` e o modo de arquivo único
- Tipos primitivos, `String`, `var` e text blocks
- Ler entrada com `Scanner` e decidir com `if` e `switch` moderno
- Repetir com `while` e `for` e organizar o código em métodos
- Empacotar o projeto com Maven e rodar o `.jar`

## Instalando o JDK 21

O JDK (Java Development Kit) traz o compilador `javac`, a JVM e a biblioteca padrão. Use uma distribuição LTS (suporte longo) como o Eclipse Temurin 21.

```bash
# Windows
winget install EclipseAdoptium.Temurin.21.JDK

# macOS
brew install --cask temurin@21

# Linux ou macOS, com SDKMAN (permite trocar de versão depois)
sdk list java                # mostra os identificadores disponíveis
sdk install java 21.0.5-tem  # use o identificador 21.x-tem mais recente da lista
```

Confira:

```bash
java -version
javac -version
```

As duas linhas precisam mostrar 21. Se `java` mostrar outra versão, a variável `JAVA_HOME` ou o `PATH` está apontando para um JDK antigo. Como editor, IntelliJ IDEA Community ou VS Code com o Extension Pack for Java funcionam bem.

## O primeiro programa

Crie `Recepcao.java`:

```java
public class Recepcao {
    public static void main(String[] args) {
        System.out.println("Clínica Vida: recepção aberta");
    }
}
```

O que cada parte faz:

- `public class Recepcao`: todo código Java vive dentro de uma classe. O nome da classe pública precisa ser igual ao nome do arquivo.
- `public static void main(String[] args)`: o ponto de entrada. A JVM procura exatamente essa assinatura para começar.
- `System.out.println`: escreve uma linha na saída padrão.

Há dois jeitos de rodar:

```bash
# Clássico: compila para bytecode e depois executa a classe
javac Recepcao.java
java Recepcao

# Modo arquivo único (Java 11+): compila em memória e roda
java Recepcao.java
```

O modo arquivo único é ótimo para scripts e exercícios. Para projetos reais, você usa uma ferramenta de build (Maven), que veremos no fim.

## Variáveis e tipos

Java é estaticamente tipado: o tipo de cada variável é conhecido em tempo de compilação, e o compilador recusa operações que não fazem sentido.

```java
int idade = 42;                 // inteiro de 32 bits
long cpfNumerico = 12345678901L; // inteiro de 64 bits
double valorBase = 250.0;       // ponto flutuante
boolean temConvenio = false;    // true ou false
char sexo = 'F';                // um caractere
String nome = "Ana Souza";      // texto (objeto, não primitivo)

var especialidade = "Cardiologia"; // o compilador infere String
```

`var` não torna Java dinâmico: o tipo é inferido uma vez e fica fixo. Use quando o tipo é óbvio pelo lado direito. Constantes usam `final` e nome em maiúsculas:

```java
final double VALOR_CONVENIO = 50.0;
```

### Strings e text blocks

Strings são imutáveis: todo método que "muda" uma string devolve uma nova.

```java
String nome = "  ana souza ";
String limpo = nome.trim().toUpperCase(); // "ANA SOUZA"
boolean vazio = nome.isBlank();            // false
String saudacao = "Olá, %s!".formatted(limpo);
```

Para textos de várias linhas, use text blocks (Java 15+):

```java
String recibo = """
        Paciente: %s
        Valor:    R$ %.2f
        """.formatted("Ana", 200.0);
System.out.print(recibo);
```

## Lendo dados do usuário

`Scanner` lê do teclado (`System.in`). Prefira `nextLine` e converta você mesmo: misturar `nextInt` com `nextLine` deixa uma quebra de linha pendente no buffer e pula a próxima leitura.

```java
import java.util.Scanner;

public class Recepcao {
    public static void main(String[] args) {
        var scanner = new Scanner(System.in);

        System.out.print("Nome do paciente: ");
        String nome = scanner.nextLine();

        System.out.print("Idade: ");
        int idade = Integer.parseInt(scanner.nextLine().trim());

        System.out.println("Cadastrado: " + nome + ", " + idade + " anos");
    }
}
```

Se o usuário digitar "abc" na idade, `Integer.parseInt` lança `NumberFormatException` e o programa termina com erro. Tratar isso direito é assunto de exceções; por enquanto, vamos validar num laço mais adiante.

## Decisões: if e switch

A regra de preço da clínica: convênio paga R$ 50; 60 anos ou mais tem 20% de desconto; o valor base depende da especialidade.

```java
static double valorBase(String especialidade) {
    return switch (especialidade.toLowerCase()) {
        case "clinico" -> 180.0;
        case "cardiologia", "neurologia" -> 320.0;
        case "dermatologia" -> 250.0;
        default -> throw new IllegalArgumentException("Especialidade desconhecida: " + especialidade);
    };
}

static double calcularValor(String especialidade, int idade, boolean temConvenio) {
    if (temConvenio) {
        return 50.0;
    }
    double base = valorBase(especialidade);
    if (idade >= 60) {
        return base * 0.8;
    }
    return base;
}
```

O `switch` com setas (Java 14+) é uma **expressão**: devolve um valor, não tem "queda" para o próximo caso e aceita vários rótulos separados por vírgula. Se esquecer um caso sem `default`, o compilador reclama em situações em que consegue verificar (com enums, por exemplo). Prefira essa forma ao `switch` antigo com `break`.

<Callout type="warning" title="Comparar String com == compara referência">
`if (especialidade == "clinico")` compila, mas compara se as duas variáveis apontam para o mesmo objeto na memória, não se o texto é igual. Às vezes funciona por acaso e falha com texto vindo do teclado. Use `especialidade.equals("clinico")` ou `"clinico".equalsIgnoreCase(especialidade)`. O `switch` em String já usa `equals` por baixo.
</Callout>

## Repetição

Um laço `while` serve para repetir até uma condição mudar. Aqui, pedimos a idade até vir um número válido:

```java
static int lerIdade(Scanner scanner) {
    while (true) {
        System.out.print("Idade: ");
        String linha = scanner.nextLine().trim();
        if (linha.matches("\\d{1,3}")) {
            return Integer.parseInt(linha);
        }
        System.out.println("Digite só números, por favor.");
    }
}
```

O `for` clássico é para contar; o `for` aprimorado percorre coleções e arrays:

```java
for (int hora = 8; hora <= 17; hora++) {
    System.out.print(hora + "h ");
}

String[] especialidades = {"clinico", "cardiologia", "dermatologia", "neurologia"};
for (String e : especialidades) {
    System.out.println("- " + e);
}
```

## Métodos: organizando o programa

Métodos têm nome, parâmetros com tipo e tipo de retorno (`void` quando não devolvem nada). Por enquanto, todos são `static`, ou seja, pertencem à classe e não precisam de objeto. No próximo capítulo isso muda com orientação a objetos.

Bons métodos fazem uma coisa só e têm nome de verbo: `lerIdade`, `calcularValor`, `imprimirRecibo`. O `main` vira um roteiro legível.

## A aplicação completa

Juntando tudo num menu que atende vários pacientes até o usuário sair:

```java
import java.util.Scanner;

public class Recepcao {

    static final double VALOR_CONVENIO = 50.0;

    public static void main(String[] args) {
        var scanner = new Scanner(System.in);
        int atendidos = 0;
        double totalDia = 0;

        while (true) {
            System.out.println("""

                    1) Novo atendimento
                    2) Resumo do dia
                    0) Sair""");
            System.out.print("Opção: ");
            String opcao = scanner.nextLine().trim();

            switch (opcao) {
                case "1" -> {
                    double valor = atender(scanner);
                    atendidos++;
                    totalDia += valor;
                }
                case "2" -> System.out.printf("Atendidos: %d | Total: R$ %.2f%n", atendidos, totalDia);
                case "0" -> {
                    System.out.println("Até amanhã.");
                    return;
                }
                default -> System.out.println("Opção inválida.");
            }
        }
    }

    static double atender(Scanner scanner) {
        System.out.print("Nome do paciente: ");
        String nome = scanner.nextLine().trim();
        int idade = lerIdade(scanner);
        System.out.print("Especialidade (clinico, cardiologia, dermatologia, neurologia): ");
        String especialidade = scanner.nextLine().trim();
        System.out.print("Tem convênio? (s/n): ");
        boolean convenio = scanner.nextLine().trim().equalsIgnoreCase("s");

        double valor = calcularValor(especialidade, idade, convenio);
        imprimirRecibo(nome, especialidade, valor);
        return valor;
    }

    static int lerIdade(Scanner scanner) {
        while (true) {
            System.out.print("Idade: ");
            String linha = scanner.nextLine().trim();
            if (linha.matches("\\d{1,3}")) {
                return Integer.parseInt(linha);
            }
            System.out.println("Digite só números, por favor.");
        }
    }

    static double valorBase(String especialidade) {
        return switch (especialidade.toLowerCase()) {
            case "clinico" -> 180.0;
            case "cardiologia", "neurologia" -> 320.0;
            case "dermatologia" -> 250.0;
            default -> 180.0; // na dúvida, consulta de clínico geral
        };
    }

    static double calcularValor(String especialidade, int idade, boolean temConvenio) {
        if (temConvenio) return VALOR_CONVENIO;
        double base = valorBase(especialidade);
        return idade >= 60 ? base * 0.8 : base;
    }

    static void imprimirRecibo(String nome, String especialidade, double valor) {
        System.out.print("""
                ---------- RECIBO ----------
                Paciente:      %s
                Especialidade: %s
                Valor:         R$ %.2f
                ----------------------------
                """.formatted(nome, especialidade, valor));
    }
}
```

Rode com `java Recepcao.java` e atenda dois ou três pacientes. Repare que o `main` só coordena: cada detalhe está num método com nome claro.

## Um aviso sobre dinheiro

`double` é ponto flutuante binário e não representa exatamente valores como 0.1. `0.1 + 0.2` dá `0.30000000000000004`. Para um exercício, tudo bem. Em sistema real de cobrança, use `BigDecimal` (ou guarde centavos em `long`):

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

BigDecimal base = new BigDecimal("320.00");
BigDecimal comDesconto = base.multiply(new BigDecimal("0.8")).setScale(2, RoundingMode.HALF_EVEN);
```

Note o construtor com String: `new BigDecimal(0.1)` herda a imprecisão do `double`.

## Projeto com Maven

Para algo maior que um arquivo, use Maven: ele define a estrutura de pastas, baixa dependências e gera o `.jar`. A estrutura padrão:

```text
recepcao/
  pom.xml
  src/main/java/br/com/clinica/Recepcao.java
  src/test/java/...
```

Um `pom.xml` mínimo para Java 21 com o `main` declarado no manifesto do jar:

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0">
  <modelVersion>4.0.0</modelVersion>
  <groupId>br.com.clinica</groupId>
  <artifactId>recepcao</artifactId>
  <version>1.0.0</version>

  <properties>
    <maven.compiler.release>21</maven.compiler.release>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
  </properties>

  <build>
    <plugins>
      <plugin>
        <groupId>org.apache.maven.plugins</groupId>
        <artifactId>maven-jar-plugin</artifactId>
        <version>3.4.2</version>
        <configuration>
          <archive>
            <manifest>
              <mainClass>br.com.clinica.Recepcao</mainClass>
            </manifest>
          </archive>
        </configuration>
      </plugin>
    </plugins>
  </build>
</project>
```

Adicione `package br.com.clinica;` no topo de `Recepcao.java` (o pacote espelha as pastas) e rode:

```bash
mvn package
java -jar target/recepcao-1.0.0.jar
```

Esse ciclo (código em `src/main/java`, `mvn package`, `java -jar`) é exatamente o que uma aplicação Spring Boot faz, só que com mais dependências.

## Na entrevista

- **Qual a diferença entre JDK, JRE e JVM?** A JVM executa bytecode. O JRE é a JVM com a biblioteca padrão, o necessário para rodar. O JDK inclui o JRE e as ferramentas de desenvolvimento, como `javac` e `jar`.
- **Por que `String` é imutável?** Segurança (uma string passada a outro código não muda por baixo), uso seguro entre threads e cache de strings literais no pool. Concatenação em laço deve usar `StringBuilder`.
- **O que `var` faz?** Inferência de tipo para variáveis locais. O tipo é fixado em compilação; não é tipagem dinâmica.
- **Por que não usar `double` para dinheiro?** Porque ele não representa frações decimais com exatidão. Use `BigDecimal` com escala e arredondamento definidos.

## Pratique

Evolua a `Recepcao`:

1. Troque `double` por `BigDecimal` em todo cálculo de valor.
2. Adicione a opção "3) Agenda do médico": peça a hora (8 a 17) e mostre "livre" ou "ocupado", guardando as horas ocupadas num `boolean[] agenda = new boolean[24]` que é preenchido a cada atendimento (pergunte a hora no atendimento).
3. Recuse hora fora do expediente com uma mensagem clara.
4. Transforme em projeto Maven e gere o `.jar`.

Entregue o `pom.xml`, o código e a saída de uma sessão com três atendimentos, uma consulta de agenda e o resumo do dia.
