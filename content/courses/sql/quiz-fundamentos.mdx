<Quiz question="WHERE cargo = 'Pleno' AND depto = 'Dados' OR depto = 'Vendas' devolve o quê?" options={["Plenos de Dados ou de Vendas", "Plenos de Dados mais qualquer pessoa de Vendas", "Ninguém", "Só plenos de Vendas"]} answer={1} explanation="AND tem precedência sobre OR. <Quiz question="Uma API pagina com LIMIT 20 OFFSET 200000 e ficou lenta. Qual a melhor correção?" options={["Aumentar o LIMIT", "Paginar por chave: WHERE (criado_em, id) menor que o último visto, com índice nessas colunas", "Remover o ORDER BY", "Usar SELECT DISTINCT"]} answer={1} explanation="OFFSET obriga o banco a ler e descartar todas as linhas anteriores. <Quiz question="No Postgres, ORDER BY nota DESC LIMIT 3 retorna alunos sem nota no topo. Por quê?" options={["É um bug do Postgres", "NULL é tratado como maior que tudo, então vem primeiro em DESC", "LIMIT ignora o ORDER BY", "A coluna precisa de índice"]} answer={1} explanation="Use ORDER BY nota DESC NULLS LAST. No MySQL, NULL é o menor valor e o comportamento é o inverso." />
<Quiz question="SELECT * FROM t WHERE id NOT IN (SELECT ref FROM u) devolveu zero linhas, mas você sabe que há ids sem referência. Use NOT EXISTS ou filtre ref IS NOT NULL." />
<Quiz question="Você declara FOREIGN KEY em pedidos.cliente_id no Postgres e deleções de clientes ficaram lentas.
