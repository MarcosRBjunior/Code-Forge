<Quiz question="Num relatório, a mesma consulta de soma rodada duas vezes dentro de uma transação devolve valores diferentes porque outra sessão confirmou um UPDATE no meio. Qual é a anomalia e o nível mínimo que a evita?" options={["Leitura suja; o nível mínimo para evitá-la é READ COMMITTED, o padrão do Postgres","Leitura não repetível; o nível mínimo para evitá-la é REPEATABLE READ","Deadlock entre as duas sessões; o nível mínimo para evitá-lo é SERIALIZABLE","Escrita perdida; o nível mínimo para evitá-la é READ UNCOMMITTED"]} answer={1} explanation="Ler de novo e ver dado alterado e confirmado por outra transação é leitura não repetível. <Quiz question="Qual é o nível de isolamento padrão no Postgres e no MySQL com InnoDB, respectivamente?" options={["SERIALIZABLE e READ COMMITTED", "READ COMMITTED e REPEATABLE READ", "REPEATABLE READ e READ COMMITTED", "READ UNCOMMITTED nos dois"]} answer={1} explanation="O Postgres usa READ COMMITTED por padrão; o InnoDB usa REPEATABLE READ." />
<Quiz question="Dois pedidos tentam reservar a última vaga de um curso ao mesmo tempo. Qual abordagem evita a venda dupla com uma única instrução?" options={["SELECT vagas FROM cursos WHERE id = 9 e, se houver vaga, UPDATE cursos SET vagas = vagas - 1 no código","UPDATE cursos SET vagas = vagas - 1 WHERE id = 9 AND vagas > 0, e ver as linhas afetadas","Criar um índice em cursos.vagas para a segunda consulta enxergar a vaga já ocupada","Rodar as duas reservas em READ UNCOMMITTED para que uma enxergue a escrita da outra"]} answer={1} explanation="O UPDATE condicional é atômico: a segunda transação espera o lock da linha, reavalia vagas > 0 e não altera nada." />
<Quiz question="Sua aplicação recebe 'deadlock detected' de vez em quando em transferências entre contas. O que resolve a causa?" options={["Aumentar o deadlock_timeout para o banco esperar mais antes de abortar","Atualizar as contas numa ordem fixa, como id crescente, e prever retry","Remover a chave primária da tabela de contas para o banco deixar de travar linhas","Trocar o plano por um Index Only Scan, que não precisa travar as linhas"]} answer={1} explanation="Deadlock é espera circular. <Quiz question="Existe índice em (status, criado_em). <Quiz question="O EXPLAIN de uma consulta que filtra uma tabela de 10 linhas mostra Seq Scan mesmo com índice na coluna.
