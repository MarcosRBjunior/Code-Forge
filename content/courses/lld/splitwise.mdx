O problema do Splitwise: um grupo divide despesas e o sistema mostra quem deve quanto a quem. Dois pontos pesam na avaliação: estratégias de divisão (igual, exata, percentual) e a simplificação das dívidas.

## Requisitos

- Usuários registram despesas pagas por um deles.
- Divisão igual, por valores exatos ou por percentuais.
- Consultar o saldo de cada pessoa.
- Simplificar: reduzir o número de transferências para quitar tudo.

## Entidades

| Entidade | Responsabilidade |
| --- | --- |
| `Divisao` | Strategy que gera a parte de cada participante. |
| `Despesa` | Pagador, valor e partes. |
| `Grupo` | Registra despesas e mantém saldos. |
| `simplificar` | Função que gera as transferências mínimas. |

Guardamos o saldo líquido de cada pessoa: positivo significa que tem a receber, negativo que deve. Dinheiro em centavos inteiros, para a soma das partes sempre bater.

## Implementação

```python
from collections import defaultdict
from typing import Dict, List, Tuple


class Divisao:
    def partes(self, total: int, participantes: List[str]) -> Dict[str, int]:
        raise NotImplementedError


class Igual(Divisao):
    def partes(self, total, participantes):
        base, resto = divmod(total, len(participantes))
        return {p: base + (1 if i < resto else 0) for i, p in enumerate(participantes)}


class Exata(Divisao):
    def __init__(self, valores: Dict[str, int]):
        self.valores = valores

    def partes(self, total, participantes):
        if sum(self.valores.values()) != total:
            raise ValueError("valores não somam o total")
        return dict(self.valores)


class Percentual(Divisao):
    def __init__(self, percentuais: Dict[str, int]):
        if sum(percentuais.values()) != 100:
            raise ValueError("percentuais devem somar 100")
        self.percentuais = percentuais

    def partes(self, total, participantes):
        partes = {p: total * pct // 100 for p, pct in self.percentuais.items()}
        sobra = total - sum(partes.values())
        for p in list(partes)[:sobra]:
            partes[p] += 1
        return partes


class Grupo:
    def __init__(self):
        self.saldo: Dict[str, int] = defaultdict(int)

    def despesa(self, pagador: str, total: int, participantes: List[str], divisao: Divisao):
        partes = divisao.partes(total, participantes)
        self.saldo[pagador] += total
        for pessoa, valor in partes.items():
            self.saldo[pessoa] -= valor

    def simplificar(self) -> List[Tuple[str, str, int]]:
        credores = sorted(((v, p) for p, v in self.saldo.items() if v > 0), reverse=True)
        devedores = sorted((-v, p) for p, v in self.saldo.items() if v < 0)[::-1]
        transf = []
        i = j = 0
        while i < len(devedores) and j < len(credores):
            dv, dp = devedores[i]
            cv, cp = credores[j]
            valor = min(dv, cv)
            transf.append((dp, cp, valor))
            devedores[i], credores[j] = (dv - valor, dp), (cv - valor, cp)
            if devedores[i][0] == 0:
                i += 1
            if credores[j][0] == 0:
                j += 1
        return transf


g = Grupo()
g.despesa("ana", 9000, ["ana", "bia", "caio"], Igual())                 # 30,00 cada
g.despesa("bia", 5000, ["ana", "bia"], Percentual({"ana": 60, "bia": 40}))
g.despesa("caio", 3000, ["ana", "caio"], Exata({"ana": 1000, "caio": 2000}))
print(dict(g.saldo))
print(g.simplificar())
assert sum(g.saldo.values()) == 0
```

A soma de todos os saldos é sempre zero, uma invariante ótima para testes. A simplificação é gulosa: casa o maior devedor com o maior credor repetidamente. Ela produz no máximo N-1 transferências, e encontrar o mínimo absoluto é um problema difícil (NP-difícil), o que vale mencionar na entrevista.

## Extensões

Despesas em moedas diferentes, quitação parcial (registrar um pagamento como despesa inversa), histórico auditável de despesas em vez de só saldos e grupos aninhados.

## Concorrência

Várias pessoas lançando despesas no mesmo grupo: atualizações dos saldos precisam ser atômicas (lock por grupo) ou derivadas do log de despesas, que é só anexado.

## Na entrevista

- **"Por que Strategy na divisão?"** Novas formas (por ação, por peso) entram sem alterar `Grupo`.
- **"Por que centavos?"** Ponto flutuante acumula erro e a invariante de soma zero quebraria.
