**Realização** é a relação entre um contrato (interface) e uma classe que o cumpre. Dizemos que a classe **realiza** ou **implementa** a interface. Diferente da herança, aqui não se trata de reaproveitar código: a classe promete oferecer certas operações, e quem a usa confia nessa promessa.

## Realização vs herança

| | Herança (generalização) | Realização |
| --- | --- | --- |
| Relação | "é um tipo de" | "cumpre o contrato de" |
| O que se transmite | estado e comportamento | apenas a obrigação de implementar métodos |
| UML | seta com linha cheia e triângulo vazio | seta com linha **tracejada** e triângulo vazio |
| Quantidade | geralmente uma superclasse | uma classe pode realizar várias interfaces |

```text
      «interface»
       Exportavel
           △
           ┊  (realização: linha tracejada)
   ┌───────┴────────┐
RelatorioCsv   RelatorioJson
```

## Exemplo: uma classe, vários contratos

Uma das forças da realização é que uma classe pode cumprir vários papéis independentes:

<CodeTabs>

```python
import json
from abc import ABC, abstractmethod


class Exportavel(ABC):
    @abstractmethod
    def exportar(self) -> str: ...


class Validavel(ABC):
    @abstractmethod
    def erros(self) -> list[str]: ...


class Fatura(Exportavel, Validavel):
    def __init__(self, cliente: str, itens: dict[str, float]) -> None:
        self.cliente = cliente
        self.itens = itens

    def exportar(self) -> str:
        return json.dumps({"cliente": self.cliente, "total": sum(self.itens.values())})

    def erros(self) -> list[str]:
        problemas = []
        if not self.cliente:
            problemas.append("cliente vazio")
        if any(v < 0 for v in self.itens.values()):
            problemas.append("item com valor negativo")
        return problemas


class Contato(Exportavel):
    def __init__(self, nome: str, telefone: str) -> None:
        self.nome = nome
        self.telefone = telefone

    def exportar(self) -> str:
        return f"{self.nome};{self.telefone}"


def exportar_todos(objetos: list[Exportavel]) -> list[str]:
    return [o.exportar() for o in objetos]


def validar_todos(objetos: list[Validavel]) -> dict[int, list[str]]:
    return {i: o.erros() for i, o in enumerate(objetos) if o.erros()}


fatura_ok = Fatura("Loja Sol", {"cadeira": 250.0, "mesa": 600.0})
fatura_ruim = Fatura("", {"desconto": -10.0})
print(exportar_todos([fatura_ok, Contato("Rita", "81 3333-0000")]))
print(validar_todos([fatura_ok, fatura_ruim]))
```

```javascript
// em JS não há interface formal: Exportavel e Validavel são só contratos de método
class Fatura {
  constructor(cliente, itens) {
    this.cliente = cliente;
    this.itens = itens;
  }

  exportar() {
    const total = Object.values(this.itens).reduce((a, b) => a + b, 0);
    return JSON.stringify({ cliente: this.cliente, total });
  }

  erros() {
    const problemas = [];
    if (!this.cliente) problemas.push("cliente vazio");
    if (Object.values(this.itens).some((v) => v < 0)) problemas.push("item com valor negativo");
    return problemas;
  }
}

class Contato {
  constructor(nome, telefone) {
    this.nome = nome;
    this.telefone = telefone;
  }

  exportar() {
    return `${this.nome};${this.telefone}`;
  }
}

function exportarTodos(objetos) {
  return objetos.map((o) => o.exportar());
}

function validarTodos(objetos) {
  const resultado = {};
  objetos.forEach((o, i) => {
    const e = o.erros();
    if (e.length > 0) resultado[i] = e;
  });
  return resultado;
}
```

```java
import java.util.*;

interface Exportavel {
    String exportar();
}

interface Validavel {
    List<String> erros();
}

class Fatura implements Exportavel, Validavel {
    private final String cliente;
    private final Map<String, Double> itens;

    Fatura(String cliente, Map<String, Double> itens) {
        this.cliente = cliente;
        this.itens = itens;
    }

    public String exportar() {
        double total = 0;
        for (double v : itens.values()) total += v;
        return "{\"cliente\": \"" + cliente + "\", \"total\": " + total + "}";
    }

    public List<String> erros() {
        List<String> problemas = new ArrayList<>();
        if (cliente.isEmpty()) problemas.add("cliente vazio");
        if (itens.values().stream().anyMatch(v -> v < 0)) problemas.add("item com valor negativo");
        return problemas;
    }
}

class Contato implements Exportavel {
    private final String nome;
    private final String telefone;

    Contato(String nome, String telefone) {
        this.nome = nome;
        this.telefone = telefone;
    }

    public String exportar() {
        return nome + ";" + telefone;
    }
}

static List<String> exportarTodos(List<? extends Exportavel> objetos) {
    List<String> saida = new ArrayList<>();
    for (Exportavel o : objetos) saida.add(o.exportar());
    return saida;
}

static Map<Integer, List<String>> validarTodos(List<? extends Validavel> objetos) {
    Map<Integer, List<String>> resultado = new LinkedHashMap<>();
    for (int i = 0; i < objetos.size(); i++) {
        List<String> e = objetos.get(i).erros();
        if (!e.isEmpty()) resultado.put(i, e);
    }
    return resultado;
}

public static void main(String[] args) {
    Fatura faturaOk = new Fatura("Loja Sol", Map.of("cadeira", 250.0, "mesa", 600.0));
    Fatura faturaRuim = new Fatura("", Map.of("desconto", -10.0));
    System.out.println(exportarTodos(Arrays.asList(faturaOk, new Contato("Rita", "81 3333-0000"))));
    System.out.println(validarTodos(Arrays.asList(faturaOk, faturaRuim)));
}
```

```cpp
#include <iostream>
#include <map>
#include <string>
#include <vector>
using namespace std;

struct Exportavel {
    virtual ~Exportavel() = default;
    virtual string exportar() const = 0;
};

struct Validavel {
    virtual ~Validavel() = default;
    virtual vector<string> erros() const = 0;
};

class Fatura : public Exportavel, public Validavel {
    string cliente;
    map<string, double> itens;

public:
    Fatura(string cliente, map<string, double> itens) : cliente(move(cliente)), itens(move(itens)) {}

    string exportar() const override {
        double total = 0;
        for (const auto& [nome, valor] : itens) total += valor;
        return "{\"cliente\": \"" + cliente + "\", \"total\": " + to_string(total) + "}";
    }

    vector<string> erros() const override {
        vector<string> problemas;
        if (cliente.empty()) problemas.push_back("cliente vazio");
        for (const auto& [nome, valor] : itens) {
            if (valor < 0) { problemas.push_back("item com valor negativo"); break; }
        }
        return problemas;
    }
};

class Contato : public Exportavel {
    string nome, telefone;

public:
    Contato(string nome, string telefone) : nome(move(nome)), telefone(move(telefone)) {}
    string exportar() const override { return nome + ";" + telefone; }
};

vector<string> exportarTodos(const vector<const Exportavel*>& objetos) {
    vector<string> saida;
    for (auto* o : objetos) saida.push_back(o->exportar());
    return saida;
}

map<int, vector<string>> validarTodos(const vector<const Validavel*>& objetos) {
    map<int, vector<string>> resultado;
    for (size_t i = 0; i < objetos.size(); i++) {
        auto e = objetos[i]->erros();
        if (!e.empty()) resultado[(int)i] = e;
    }
    return resultado;
}

int main() {
    Fatura faturaOk("Loja Sol", {{"cadeira", 250.0}, {"mesa", 600.0}});
    Fatura faturaRuim("", {{"desconto", -10.0}});
    Contato rita("Rita", "81 3333-0000");

    for (const auto& s : exportarTodos({&faturaOk, &rita})) cout << s << endl;
    for (const auto& [indice, problemas] : validarTodos({&faturaOk, &faturaRuim})) {
        cout << indice << ":";
        for (const auto& p : problemas) cout << " " << p << ",";
        cout << endl;
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

interface IExportavel
{
    string Exportar();
}

interface IValidavel
{
    List<string> Erros();
}

class Fatura : IExportavel, IValidavel
{
    private readonly string cliente;
    private readonly Dictionary<string, double> itens;

    public Fatura(string cliente, Dictionary<string, double> itens)
    {
        this.cliente = cliente;
        this.itens = itens;
    }

    public string Exportar()
    {
        double total = itens.Values.Sum();
        return "{\"cliente\": \"" + cliente + "\", \"total\": " + total.ToString("0.0###", System.Globalization.CultureInfo.InvariantCulture) + "}";
    }

    public List<string> Erros()
    {
        var problemas = new List<string>();
        if (cliente == "") problemas.Add("cliente vazio");
        if (itens.Values.Any(v => v < 0)) problemas.Add("item com valor negativo");
        return problemas;
    }
}

class Contato : IExportavel
{
    private readonly string nome;
    private readonly string telefone;

    public Contato(string nome, string telefone)
    {
        this.nome = nome;
        this.telefone = telefone;
    }

    public string Exportar()
    {
        return nome + ";" + telefone;
    }
}

static List<string> ExportarTodos(List<IExportavel> objetos)
{
    return objetos.Select(o => o.Exportar()).ToList();
}

static Dictionary<int, List<string>> ValidarTodos(List<IValidavel> objetos)
{
    var resultado = new Dictionary<int, List<string>>();
    for (int i = 0; i < objetos.Count; i++)
    {
        var e = objetos[i].Erros();
        if (e.Count > 0) resultado[i] = e;
    }
    return resultado;
}

static void Main()
{
    var faturaOk = new Fatura("Loja Sol", new Dictionary<string, double> { { "cadeira", 250.0 }, { "mesa", 600.0 } });
    var faturaRuim = new Fatura("", new Dictionary<string, double> { { "desconto", -10.0 } });

    foreach (var s in ExportarTodos(new List<IExportavel> { faturaOk, new Contato("Rita", "81 3333-0000") }))
        Console.WriteLine(s);
    foreach (var par in ValidarTodos(new List<IValidavel> { faturaOk, faturaRuim }))
        Console.WriteLine(par.Key + ": " + string.Join(", ", par.Value));
}
```

```go
package main

import "fmt"

type Exportavel interface {
	Exportar() string
}

type Validavel interface {
	Erros() []string
}

type Fatura struct {
	cliente string
	itens   map[string]float64
}

func (f Fatura) Exportar() string {
	total := 0.0
	for _, v := range f.itens {
		total += v
	}
	return fmt.Sprintf(`{"cliente": "%s", "total": %v}`, f.cliente, total)
}

func (f Fatura) Erros() []string {
	problemas := []string{}
	if f.cliente == "" {
		problemas = append(problemas, "cliente vazio")
	}
	for _, v := range f.itens {
		if v < 0 {
			problemas = append(problemas, "item com valor negativo")
			break
		}
	}
	return problemas
}

type Contato struct{ nome, telefone string }

func (c Contato) Exportar() string { return c.nome + ";" + c.telefone }

func exportarTodos(objetos []Exportavel) []string {
	saida := []string{}
	for _, o := range objetos {
		saida = append(saida, o.Exportar())
	}
	return saida
}

func validarTodos(objetos []Validavel) map[int][]string {
	resultado := map[int][]string{}
	for i, o := range objetos {
		if e := o.Erros(); len(e) > 0 {
			resultado[i] = e
		}
	}
	return resultado
}

func main() {
	faturaOk := Fatura{"Loja Sol", map[string]float64{"cadeira": 250.0, "mesa": 600.0}}
	faturaRuim := Fatura{"", map[string]float64{"desconto": -10.0}}
	fmt.Println(exportarTodos([]Exportavel{faturaOk, Contato{"Rita", "81 3333-0000"}}))
	fmt.Println(validarTodos([]Validavel{faturaOk, faturaRuim}))
}
```

`exportar_todos` só conhece `Exportavel`; `validar_todos` só conhece `Validavel`. `Fatura` participa dos dois porque realiza os dois contratos. `Contato` participa só do primeiro.

## Realização implícita com Protocol

Com `typing.Protocol`, a realização acontece sem declaração: basta a classe ter os métodos.

<CodeTabs>

```python
from typing import Protocol


class Medidor(Protocol):
    def ler(self) -> float: ...


class SensorTemperatura:
    def ler(self) -> float:
        return 23.5


class SensorUmidade:
    def ler(self) -> float:
        return 61.0


def media(medidores: list[Medidor]) -> float:
    return sum(m.ler() for m in medidores) / len(medidores)


print(media([SensorTemperatura(), SensorUmidade()]))  # 42.25
```

```go
package main

import "fmt"

// em Go as interfaces são estruturais, como o Protocol: basta ter o método
type Medidor interface {
	Ler() float64
}

type SensorTemperatura struct{}

func (SensorTemperatura) Ler() float64 { return 23.5 }

type SensorUmidade struct{}

func (SensorUmidade) Ler() float64 { return 61.0 }

func media(medidores []Medidor) float64 {
	soma := 0.0
	for _, m := range medidores {
		soma += m.Ler()
	}
	return soma / float64(len(medidores))
}

func main() {
	fmt.Println(media([]Medidor{SensorTemperatura{}, SensorUmidade{}})) // 42.25
}
```

Nenhum sensor herda de `Medidor`, mas um verificador de tipos aceita os dois. É útil para integrar classes de bibliotecas que você não controla.

## Por que realização importa no design

- **Troca de implementações.** O cliente depende do contrato, então dá para trocar `RelatorioCsv` por `RelatorioJson` sem mexer nele.
- **Testes.** Um dublê só precisa realizar a interface.
- **Papéis independentes.** Várias interfaces pequenas permitem que cada classe cumpra exatamente os papéis que fazem sentido.

<Callout type="note" title="Herança de interface ainda é herança em Python">
Com ABC, a sintaxe de realização é a mesma de herança (`class Fatura(Exportavel)`). A diferença é conceitual: se a base só tem métodos abstratos e nenhum estado, você está modelando realização.
</Callout>

## Armadilhas

- **Interface com métodos que nem todos podem cumprir.** Implementações começam a lançar `NotImplementedError`. Divida o contrato.
- **Contrato sem semântica.** Além da assinatura, documente o comportamento esperado (pode retornar vazio? lança erro?).
- **Misturar estado na interface.** Se a base abstrata começa a ganhar atributos e lógica, ela virou classe base, e o acoplamento aumenta.
