No LLD de um chat você modela conversas, mensagens e entrega, não a infraestrutura de WebSocket. As perguntas centrais: como representar conversas individuais e em grupo de forma uniforme, e como rastrear o estado de cada mensagem (enviada, entregue, lida).

## Requisitos

- Conversas entre dois usuários e grupos.
- Enviar mensagens; destinatários online recebem na hora, offline recebem ao conectar.
- Status por destinatário: enviada, entregue, lida.
- Histórico ordenado por conversa.

## Entidades

| Entidade | Responsabilidade |
| --- | --- |
| `Usuario` | Nome, estado online e caixa de entrada. |
| `Mensagem` | Autor, texto, instante e status por destinatário. |
| `Conversa` | Participantes e histórico. Serve para 1 a 1 e grupo. |
| `ServicoChat` | Cria conversas, envia e entrega. |

Tratar o 1 a 1 como um grupo de dois participantes elimina uma hierarquia inteira de classes. O status é por destinatário, porque num grupo cada pessoa lê em momentos diferentes.

## Implementação

```python
from enum import IntEnum
from typing import Dict, List


class Status(IntEnum):
    ENVIADA = 1
    ENTREGUE = 2
    LIDA = 3


class Usuario:
    def __init__(self, nome: str):
        self.nome = nome
        self.online = False
        self.recebidas: List["Mensagem"] = []
        self.pendentes: List["Mensagem"] = []

    def __repr__(self):
        return self.nome


class Mensagem:
    def __init__(self, autor: Usuario, texto: str, instante: int, destinatarios):
        self.autor, self.texto, self.instante = autor, texto, instante
        self.status: Dict[Usuario, Status] = {d: Status.ENVIADA for d in destinatarios}


class Conversa:
    def __init__(self, participantes: List[Usuario]):
        self.participantes = list(participantes)
        self.historico: List[Mensagem] = []


class ServicoChat:
    def __init__(self):
        self._tempo = 0

    def enviar(self, conversa: Conversa, autor: Usuario, texto: str) -> Mensagem:
        if autor not in conversa.participantes:
            raise PermissionError("autor fora da conversa")
        self._tempo += 1
        dest = [u for u in conversa.participantes if u is not autor]
        msg = Mensagem(autor, texto, self._tempo, dest)
        conversa.historico.append(msg)
        for u in dest:
            if u.online:
                self._entregar(u, msg)
            else:
                u.pendentes.append(msg)
        return msg

    def _entregar(self, usuario: Usuario, msg: Mensagem):
        usuario.recebidas.append(msg)
        msg.status[usuario] = Status.ENTREGUE

    def conectar(self, usuario: Usuario):
        usuario.online = True
        for msg in usuario.pendentes:
            self._entregar(usuario, msg)
        usuario.pendentes.clear()

    def desconectar(self, usuario: Usuario):
        usuario.online = False

    def marcar_lida(self, usuario: Usuario, msg: Mensagem):
        if msg.status.get(usuario) == Status.ENTREGUE:
            msg.status[usuario] = Status.LIDA


ana, bia, caio = Usuario("Ana"), Usuario("Bia"), Usuario("Caio")
chat = ServicoChat()
grupo = Conversa([ana, bia, caio])
chat.conectar(ana)
chat.conectar(bia)
m = chat.enviar(grupo, ana, "reunião às 10h")
print(m.status)                      # Bia entregue, Caio enviada
chat.conectar(caio)
chat.marcar_lida(bia, m)
print({u.nome: s.name for u, s in m.status.items()})
```

Mensagens para quem está offline ficam pendentes e são entregues em ordem ao conectar, preservando a sequência.

## Extensões

Observer para empurrar mensagens a quem está online (cada sessão assina a conversa), mensagens com mídia (herança ou composição com anexos), apagar para todos, edição, confirmação de leitura desativável e busca no histórico. Em grupos grandes, o status de leitura por pessoa vira um custo: muitos produtos mostram só contadores.

## Concorrência

Duas pessoas enviando ao mesmo tempo precisam de ordem consistente: um contador por conversa atribui a sequência. Em memória, um lock por conversa basta.

## Na entrevista

- **"Como garantir a ordem?"** Número de sequência por conversa, não o relógio do cliente.
- **"Como evitar mensagem duplicada em reenvio?"** Id gerado pelo cliente e deduplicação no servidor.
