## O problema

Quando um pedido é pago numa loja online, várias coisas precisam acontecer: o estoque baixa, o cliente recebe um e-mail, o financeiro emite a nota e o time de analytics registra a conversão. A tentação é colocar tudo dentro de `Pedido.pagar()`. O resultado é uma classe que conhece e-mail, estoque, nota fiscal e analytics, e que precisa ser editada toda vez que alguém quer "também ser avisado".

O Observer **inverte essa dependência**: o objeto que muda (o sujeito, ou publisher) mantém uma lista de interessados e avisa todos quando algo acontece, sem saber o que cada um faz com o aviso. Novos interessados se inscrevem sem que o sujeito mude.

## Estrutura

```text
+------------------------+        notifica       +-------------------+
|  Sujeito               |---------------------->|  Observador       |
|------------------------|  1              0..*  |  (iface)          |
| - observadores: lista  |                       |-------------------|
| + inscrever(obs)       |                       | + atualizar(evt)  |
| + cancelar(obs)        |                       +-------------------+
| + notificar(evt)       |                          ^      ^      ^
+------------------------+                          |      |      |
                                            Estoque  EmailCliente  Analytics
```

Dois estilos de entrega:

- **Push**: o sujeito envia os dados do evento junto com o aviso.
- **Pull**: o sujeito avisa "mudei" e cada observador consulta o que precisar.

Push é mais comum e evita que observadores dependam de getters do sujeito.

from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List


@dataclass(frozen=True)
class PedidoPago:
    pedido_id: str
    email: str
    itens: dict
    total: float


class Observador(ABC):
    @abstractmethod
    def atualizar(self, evento: PedidoPago) -> None: ...


class Pedido:
    def __init__(self, pedido_id: str, email: str, itens: dict, total: float):
        self.pedido_id = pedido_id
        self.email = email
        self.itens = itens
        self.total = total
        self.status = "aguardando"
        self._observadores: List[Observador] = []

    def inscrever(self, obs: Observador) -> None:
        if obs not in self._observadores:
            self._observadores.append(obs)

    def cancelar_inscricao(self, obs: Observador) -> None:
        self._observadores.remove(obs)

    def _notificar(self, evento: PedidoPago) -> None:
        for obs in list(self._observadores):  # cópia: alguém pode se desinscrever
            try:
                obs.atualizar(evento)
            except Exception as erro:  # um observador quebrado não derruba os outros
                print(f"[aviso] {type(obs).__name__} falhou: {erro}")

    def pagar(self) -> None:
        self.status = "pago"
        self._notificar(PedidoPago(self.pedido_id, self.email, self.itens, self.total))


class Estoque(Observador):
    def __init__(self, saldo: dict):
        self.saldo = saldo

    def atualizar(self, evento: PedidoPago) -> None:
        for sku, qtd in evento.itens.items():
            self.saldo[sku] -= qtd
        print("estoque:", self.saldo)


class EmailCliente(Observador):
    def atualizar(self, evento: PedidoPago) -> None:
        print(f"e-mail para {evento.email}: pedido {evento.pedido_id} confirmado")


class NotaFiscal(Observador):
    def atualizar(self, evento: PedidoPago) -> None:
        if evento.total <= 0:
            raise ValueError("total inválido para nota")
        print(f"nota emitida: R$ {evento.total:.2f}")


class Analytics(Observador):
    def __init__(self):
        self.receita = 0.0

    def atualizar(self, evento: PedidoPago) -> None:
        self.receita += evento.total
        print("receita acumulada:", self.receita)

analytics = Analytics()

import java.util.*;

class PedidoPago {
    final String pedidoId, email;
    final Map<String, Integer> itens;
    final double total;

    PedidoPago(String pedidoId, String email, Map<String, Integer> itens, double total) {
        this.pedidoId = pedidoId;
        this.email = email;
        this.itens = itens;
        this.total = total;
    }
}

interface Observador {
    void atualizar(PedidoPago evento);
}

class Pedido {
    final String pedidoId, email;
    final Map<String, Integer> itens;
    final double total;
    String status = "aguardando";
    private final List<Observador> observadores = new ArrayList<>();

    Pedido(String pedidoId, String email, Map<String, Integer> itens, double total) {
        this.pedidoId = pedidoId;
        this.email = email;
        this.itens = itens;
        this.total = total;
    }

    void inscrever(Observador obs) {
        if (!observadores.contains(obs)) {
            observadores.add(obs);
        }
    }

    void cancelarInscricao(Observador obs) {
        observadores.remove(obs);
    }

    private void notificar(PedidoPago evento) {
        for (Observador obs : new ArrayList<>(observadores)) {   // cópia: alguém pode se desinscrever
            try {
                obs.atualizar(evento);
            } catch (RuntimeException erro) {                    // um observador quebrado não derruba os outros
                System.out.println("[aviso] " + obs.getClass().getSimpleName() + " falhou: " + erro.getMessage());
            }
        }
    }

    void pagar() {
        status = "pago";
        notificar(new PedidoPago(pedidoId, email, itens, total));
    }
}

class Estoque implements Observador {
    private final Map<String, Integer> saldo;

    Estoque(Map<String, Integer> saldo) {
        this.saldo = saldo;
    }

    public void atualizar(PedidoPago evento) {
        for (Map.Entry<String, Integer> e : evento.itens.entrySet()) {
            saldo.merge(e.getKey(), -e.getValue(), Integer::sum);
        }
        System.out.println("estoque: " + saldo);
    }
}

class EmailCliente implements Observador {
    public void atualizar(PedidoPago evento) {
        System.out.println("e-mail para " + evento.email + ": pedido " + evento.pedidoId + " confirmado");
    }
}

    virtual ~Observador() = default;
    virtual void atualizar(const PedidoPago& evento) = 0;

class Pedido {
    string pedidoId, email;
    map<string, int> itens;
    double total;
    vector<shared_ptr<Observador>> observadores;

    void notificar(const PedidoPago& evento) {
        auto copia = observadores;   // cópia: alguém pode se desinscrever
        for (auto& obs : copia) {
            try {
                obs->atualizar(evento);
            } catch (const exception& erro) {   // um observador quebrado não derruba os outros
                cout << "[aviso] " << obs->nome() << " falhou: " << erro.what() << endl;
            }
        }
    }

public:
    string status = "aguardando";

    Pedido(string pedidoId, string email, map<string, int> itens, double total)
        : pedidoId(pedidoId), email(email), itens(itens), total(total) {}

    void inscrever(shared_ptr<Observador> obs) {
        if (find(observadores.begin(), observadores.end(), obs) == observadores.end()) {
            observadores.push_back(obs);
        }
    }

    void cancelarInscricao(shared_ptr<Observador> obs) {
        observadores.erase(remove(observadores.begin(), observadores.end(), obs), observadores.end());
    }

    void pagar() {
        status = "pago";
        notificar({pedidoId, email, itens, total});
    }
};

import (
	"errors"
	"fmt"
)

type PedidoPago struct {
	pedidoID string
	email    string
	itens    map[string]int
	total    float64
}

type Observador interface {
	atualizar(evento PedidoPago) error
	nome() string
}

type Pedido struct {
	pedidoID     string
	email        string
	itens        map[string]int
	total        float64
	status       string
	observadores []Observador
}

func (p *Pedido) inscrever(obs Observador) {
	for _, o := range p.observadores {
		if o == obs {
			return
		}
	}
	p.observadores = append(p.observadores, obs)
}

func (p *Pedido) cancelarInscricao(obs Observador) {
	for i, o := range p.observadores {
		if o == obs {
			p.observadores = append(p.observadores[:i], p.observadores[i+1:]...)
			return
		}
	}
}

func (p *Pedido) notificar(evento PedidoPago) {
	copia := append([]Observador{}, p.observadores...) // cópia: alguém pode se desinscrever
	for _, obs := range copia {
		if err := obs.atualizar(evento); err != nil { // um observador quebrado não derruba os outros
			fmt.Printf("[aviso] %s falhou: %v\n", obs.nome(), err)
		}
	}
}

func (p *Pedido) pagar() {
	p.status = "pago"
	p.notificar(PedidoPago{p.pedidoID, p.email, p.itens, p.total})
}

type Estoque struct {
	saldo map[string]int
}

func (e *Estoque) atualizar(evento PedidoPago) error {
	for sku, qtd := range evento.itens {
		e.saldo[sku] -= qtd
	}
	fmt.Println("estoque:", e.saldo)

from typing import Callable, DefaultDict, List

Handler = Callable[[dict], None]

    def __init__(self):
        self._assinantes: DefaultDict[str, List[Handler]] = defaultdict(list)

import java.util.function.Consumer;

class EventBus {
    private final Map<String, List<Consumer<Map<String, String>>>> assinantes = new HashMap<>();

    Runnable assinar(String topico, Consumer<Map<String, String>> handler) {
        List<Consumer<Map<String, String>>> lista = assinantes.computeIfAbsent(topico, k -> new ArrayList<>());
        lista.add(handler);

        }
    }

using Dados = map<string, string>;

class EventBus {
    map<string, vector<pair<int, Handler>>> assinantes;
    int proximoId = 0;

public:
    // devolve a função de cancelamento
    function<void()> assinar(const string& topico, Handler handler) {
        int id = proximoId++;
        assinantes[topico].push_back({id, handler});
        return [this, topico, id] {
            auto& lista = assinantes[topico];
            lista.erase(remove_if(lista.begin(), lista.end(), [id](const auto& p) { return p.first == id; }), lista.end());
        };
    }

        auto copia = assinantes[topico];
        for (auto& [id, handler] : copia) {
            handler(dados);
        }
    }
};

class EventBus
{
    private readonly Dictionary<string, List<Action<Dictionary<string, string>>>> assinantes =
        new Dictionary<string, List<Action<Dictionary<string, string>>>>();

    public Action Assinar(string topico, Action<Dictionary<string, string>> handler)
    {
        if (!assinantes.ContainsKey(topico)) assinantes[topico] = new List<Action<Dictionary<string, string>>>();
        var lista = assinantes[topico];

import "fmt"

type Dados map[string]string
type Handler func(Dados)

type assinatura struct {
	id      int
	handler Handler
}

type EventBus struct {
	assinantes map[string][]assinatura
	proximoID  int
}

func novoEventBus() *EventBus {
	return &EventBus{assinantes: map[string][]assinatura{}}
}

// devolve a função de cancelamento
func (b *EventBus) assinar(topico string, handler Handler) func() {
	id := b.proximoID
	b.proximoID++
	b.assinantes[topico] = append(b.assinantes[topico], assinatura{id, handler})
	return func() {
		lista := b.assinantes[topico]
		for i, a := range lista {
			if a.id == id {
				b.assinantes[topico] = append(lista[:i:i], lista[i+1:]...)
				return
			}
		}
	}
}

func (b *EventBus) publicar(topico string, dados Dados) {
	copia := append([]assinatura{}, b.assinantes[topico]...)
	for _, a := range copia {
		a.handler(dados)
	}
}

func main() {
	bus := novoEventBus()
	cancelarSms := bus.assinar("usuario.cadastrado", func(d Dados) { fmt.Println("SMS para", d["telefone"]) })
	bus.assinar("usuario.cadastrado", func(d Dados) { fmt.Println("boas-vindas para", d["nome"]) })

	bus.publicar("usuario.cadastrado", Dados{"nome": "Leo", "telefone": "+55 11 90000-0000"})
	cancelarSms()
	bus.publicar("usuario.cadastrado", Dados{"nome": "Bia", "telefone": "+55 21 90000-0001"})
}

Retornar uma função de cancelamento é um truque prático: evita vazamento de memória por observadores esquecidos.

## Quando usar e quando evitar

**Use quando:**

- Uma mudança num objeto precisa disparar reações em outros, e você não sabe de antemão quantos nem quais.
- Você quer desacoplar o núcleo do domínio de efeitos colaterais (notificações, métricas, auditoria).

**Evite ou tome cuidado quando:**

- A ordem de execução importa. Observer não garante ordem de forma explícita; se "baixar estoque" tem de acontecer antes de "emitir nota", modele isso como um fluxo.
- Cadeias de eventos disparando eventos ficam difíceis de depurar ("quem chamou isso?").
- Observadores lentos travam o sujeito. Em produção, considere notificação assíncrona (fila, thread).

<Callout type="warning" title="Vazamento de memória">
O sujeito guarda referências fortes para os observadores. Se ninguém cancela a inscrição, objetos que deveriam morrer continuam vivos. Ofereça sempre uma forma de cancelar e, em casos específicos, use referências fracas.
</Callout>

## Padrões parecidos

| Padrão | Diferença |
| --- | --- |
| Mediator | No Mediator, um objeto central coordena colegas e **decide** quem faz o quê. No Observer, o sujeito só transmite; não coordena nada. |
| Pub/Sub | Variação distribuída: publisher e subscriber nem se conhecem, há um broker no meio (fila, tópico). O Observer clássico é em memória e o sujeito conhece a lista de observadores. |
| Chain of Responsibility | Passa um pedido adiante até alguém tratá-lo; normalmente só um trata. No Observer, todos recebem. |
