## O problema

Sua plataforma de pagamentos integra com dois provedores, digamos **Provedor A** e **Provedor B**. Para cada um você precisa de três objetos que trabalham juntos: um cliente de cobrança, um validador de webhook (cada provedor assina as notificações de um jeito) e um conversor de status (cada um usa códigos diferentes para "pago"). Misturar peças, como validar um webhook do A com o validador do B, é um bug grave e silencioso.

O **Abstract Factory** fornece uma interface para criar **famílias de objetos relacionados** sem especificar suas classes concretas. Você escolhe a fábrica uma vez (na configuração do lojista) e todo o resto do código recebe peças garantidamente compatíveis.

## Estrutura

```text
                  +--------------------------------+
                  |  FabricaDeProvedor (abstrata)  |
                  +--------------------------------+
                  | + criar_cobranca(): Cobranca   |
                  | + criar_validador(): Validador |
                  | + criar_status(): ConversorSt. |
                  +--------------------------------+
                        ^                    ^
                        |                    |
          +-------------------+     +-------------------+
          |   FabricaProvA    |     |   FabricaProvB    |
          +-------------------+     +-------------------+
            |   |   |                 |   |   |
            v   v   v                 v   v   v
   CobrancaA ValidadorA StatusA   CobrancaB ValidadorB StatusB

  Cliente (CheckoutService) conhece só FabricaDeProvedor e as interfaces
  Cobranca, Validador e ConversorStatus.
```

Papéis: **Fábrica abstrata**, **Fábricas concretas** (uma por família), **Produtos abstratos** (um por tipo de peça) e **Produtos concretos**.

```python
import hashlib
import hmac
from abc import ABC, abstractmethod
from enum import Enum


class StatusPagamento(Enum):
    PENDENTE = "pendente"
    PAGO = "pago"
    RECUSADO = "recusado"


# ---------- Produtos abstratos ----------
class Cobranca(ABC):
    @abstractmethod
    def criar(self, pedido_id: str, centavos: int) -> dict: ...


class ValidadorWebhook(ABC):
    @abstractmethod
    def valido(self, corpo: bytes, assinatura: str) -> bool: ...


class ConversorStatus(ABC):
    @abstractmethod
    def converter(self, codigo_externo: str) -> StatusPagamento: ...


# ---------- Família do Provedor A ----------
class CobrancaA(Cobranca):
    def criar(self, pedido_id, centavos):
        return {"endpoint": "/v1/charges", "reference": pedido_id, "amount": centavos}


class ValidadorA(ValidadorWebhook):
    def __init__(self, segredo: bytes):
        self._segredo = segredo

    def valido(self, corpo, assinatura):
        esperado = hmac.new(self._segredo, corpo, hashlib.sha256).hexdigest()
        return hmac.compare_digest(esperado, assinatura)


class StatusA(ConversorStatus):
    _MAPA = {"succeeded": StatusPagamento.PAGO, "failed": StatusPagamento.RECUSADO}

    def converter(self, codigo):
        return self._MAPA.get(codigo, StatusPagamento.PENDENTE)


# ---------- Família do Provedor B ----------
class CobrancaB(Cobranca):
    def criar(self, pedido_id, centavos):
        return {"endpoint": "/api/pagamentos", "id_pedido": pedido_id, "valor": f"{centavos / 100:.2f}"}


class ValidadorB(ValidadorWebhook):
    def __init__(self, token: str):
        self._token = token

    def valido(self, corpo, assinatura):
        # B manda um token fixo + sha1 do corpo
        esperado = self._token + ":" + hashlib.sha1(corpo).hexdigest()
        return hmac.compare_digest(esperado, assinatura)


class StatusB(ConversorStatus):
    _MAPA = {"APROVADO": StatusPagamento.PAGO, "NEGADO": StatusPagamento.RECUSADO}

    def converter(self, codigo):
        return self._MAPA.get(codigo.upper(), StatusPagamento.PENDENTE)


# ---------- Fábricas ----------
class FabricaDeProvedor(ABC):
    @abstractmethod
    def criar_cobranca(self) -> Cobranca: ...

    @abstractmethod
    def criar_validador(self) -> ValidadorWebhook: ...

    @abstractmethod
    def criar_conversor(self) -> ConversorStatus: ...


class FabricaProvedorA(FabricaDeProvedor):
    def __init__(self, segredo: bytes):
        self._segredo = segredo

    def criar_cobranca(self):
        return CobrancaA()

    def criar_validador(self):
        return ValidadorA(self._segredo)

    def criar_conversor(self):
        return StatusA()


class FabricaProvedorB(FabricaDeProvedor):
    def __init__(self, token: str):
        self._token = token

    def criar_cobranca(self):
        return CobrancaB()

    def criar_validador(self):
        return ValidadorB(self._token)

    def criar_conversor(self):
        return StatusB()


# ---------- Cliente ----------
class ServicoDeCheckout:
    def __init__(self, fabrica: FabricaDeProvedor):
        self._cobranca = fabrica.criar_cobranca()
        self._validador = fabrica.criar_validador()
        self._conversor = fabrica.criar_conversor()

    def iniciar(self, pedido_id: str, centavos: int) -> dict:
        return self._cobranca.criar(pedido_id, centavos)

    def receber_webhook(self, corpo: bytes, assinatura: str, codigo: str) -> StatusPagamento:
        if not self._validador.valido(corpo, assinatura):
            raise PermissionError("assinatura de webhook inválida")
        return self._conversor.converter(codigo)


def fabrica_para(lojista: dict) -> FabricaDeProvedor:
    if lojista["provedor"] == "A":
        return FabricaProvedorA(lojista["segredo"].encode())
    if lojista["provedor"] == "B":
        return FabricaProvedorB(lojista["segredo"])
    raise ValueError("provedor desconhecido")


corpo = b'{"pedido": "P-77"}'

checkout_a = ServicoDeCheckout(fabrica_para({"provedor": "A", "segredo": "s3gr3d0"}))
print(checkout_a.iniciar("P-77", 15990))
assinatura_a = hmac.new(b"s3gr3d0", corpo, hashlib.sha256).hexdigest()
print(checkout_a.receber_webhook(corpo, assinatura_a, "succeeded"))

checkout_b = ServicoDeCheckout(fabrica_para({"provedor": "B", "segredo": "tok-123"}))
print(checkout_b.iniciar("P-78", 4500))
assinatura_b = "tok-123:" + hashlib.sha1(corpo).hexdigest()
print(checkout_b.receber_webhook(corpo, assinatura_b, "negado"))

try:
    checkout_b.receber_webhook(corpo, assinatura_a, "APROVADO")
except PermissionError as erro:
    print("bloqueado:", erro)
```

```javascript
function iguais(a, b) {
  const x = Buffer.from(a);
  const y = Buffer.from(b);
  return x.length === y.length && crypto.timingSafeEqual(x, y);
}

// ---------- Família do Provedor A ----------
class CobrancaA {
  criar(pedidoId, centavos) {
    return { endpoint: "/v1/charges", reference: pedidoId, amount: centavos };

}

class ValidadorA {
  constructor(segredo) {
    this.segredo = segredo;
  }
  valido(corpo, assinatura) {
    const esperado = crypto.createHmac("sha256", this.segredo).update(corpo).digest("hex");
    return iguais(esperado, assinatura);
  }
}

  converter(codigo) {
    const mapa = { succeeded: StatusPagamento.PAGO, failed: StatusPagamento.RECUSADO };

  }
}
```

```java
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.*;
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;

enum StatusPagamento { PENDENTE, PAGO, RECUSADO }

// ---------- Produtos abstratos ----------
interface Cobranca {
    Map<String, Object> criar(String pedidoId, int centavos);
}

interface ValidadorWebhook {
    boolean valido(byte[] corpo, String assinatura);
}

interface ConversorStatus {
    StatusPagamento converter(String codigoExterno);
}

class Cripto {
    static String hex(byte[] bytes) {
        StringBuilder sb = new StringBuilder();
        for (byte b : bytes) sb.append(String.format("%02x", b));
        return sb.toString();
    }

    static String hmacSha256(byte[] segredo, byte[] corpo) {
        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(segredo, "HmacSHA256"));
            return hex(mac.doFinal(corpo));
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }

    static String sha1(byte[] corpo) {
        try {
            return hex(MessageDigest.getInstance("SHA-1").digest(corpo));
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }

    static boolean iguais(String a, String b) {
        return MessageDigest.isEqual(a.getBytes(StandardCharsets.UTF_8), b.getBytes(StandardCharsets.UTF_8));
    }
}

// ---------- Família do Provedor A ----------
class CobrancaA implements Cobranca {
    public Map<String, Object> criar(String pedidoId, int centavos) {
        Map<String, Object> r = new LinkedHashMap<>();
        r.put("endpoint", "/v1/charges");
        r.put("reference", pedidoId);
        r.put("amount", centavos);
        return r;
    }
}

class ValidadorA implements ValidadorWebhook {
    private final byte[] segredo;
    ValidadorA(byte[] segredo) { this.segredo = segredo; }

    public boolean valido(byte[] corpo, String assinatura) {
        return Cripto.iguais(Cripto.hmacSha256(segredo, corpo), assinatura);
    }
}

class StatusA implements ConversorStatus {
    public StatusPagamento converter(String codigo) {
        if (codigo.equals("succeeded")) return StatusPagamento.PAGO;
        if (codigo.equals("failed")) return StatusPagamento.RECUSADO;
        return StatusPagamento.PENDENTE;
    }
}

// ---------- Família do Provedor B ----------
class CobrancaB implements Cobranca {
    public Map<String, Object> criar(String pedidoId, int centavos) {
        Map<String, Object> r = new LinkedHashMap<>();
        r.put("endpoint", "/api/pagamentos");
        r.put("id_pedido", pedidoId);
        r.put("valor", String.format(Locale.US, "%.2f", centavos / 100.0));
        return r;
    }
}

class ValidadorB implements ValidadorWebhook {
    private final String token;
    ValidadorB(String token) { this.token = token; }

    public boolean valido(byte[] corpo, String assinatura) {
        // B manda um token fixo + sha1 do corpo
        return Cripto.iguais(token + ":" + Cripto.sha1(corpo), assinatura);
    }
}

class StatusB implements ConversorStatus {
    public StatusPagamento converter(String codigo) {
        String c = codigo.toUpperCase();
        if (c.equals("APROVADO")) return StatusPagamento.PAGO;
        if (c.equals("NEGADO")) return StatusPagamento.RECUSADO;
        return StatusPagamento.PENDENTE;
    }
}

// ---------- Fábricas ----------
interface FabricaDeProvedor {
    Cobranca criarCobranca();
    ValidadorWebhook criarValidador();
    ConversorStatus criarConversor();
}

class FabricaProvedorA implements FabricaDeProvedor {
    private final byte[] segredo;
    FabricaProvedorA(byte[] segredo) { this.segredo = segredo; }
    public Cobranca criarCobranca() { return new CobrancaA(); }
    public ValidadorWebhook criarValidador() { return new ValidadorA(segredo); }
    public ConversorStatus criarConversor() { return new StatusA(); }
}

class FabricaProvedorB implements FabricaDeProvedor {
    private final String token;
    FabricaProvedorB(String token) { this.token = token; }
    public Cobranca criarCobranca() { return new CobrancaB(); }
    public ValidadorWebhook criarValidador() { return new ValidadorB(token); }
    public ConversorStatus criarConversor() { return new StatusB(); }
}

// ---------- Cliente ----------
class ServicoDeCheckout {
    private final Cobranca cobranca;
    private final ValidadorWebhook validador;
    private final ConversorStatus conversor;

    ServicoDeCheckout(FabricaDeProvedor fabrica) {
        this.cobranca = fabrica.criarCobranca();
        this.validador = fabrica.criarValidador();
        this.conversor = fabrica.criarConversor();
    }

    Map<String, Object> iniciar(String pedidoId, int centavos) {
        return cobranca.criar(pedidoId, centavos);
    }

    StatusPagamento receberWebhook(byte[] corpo, String assinatura, String codigo) {
        if (!validador.valido(corpo, assinatura)) {
            throw new SecurityException("assinatura de webhook inválida");
        }
        return conversor.converter(codigo);
    }
}

static FabricaDeProvedor fabricaPara(String provedor, String segredo) {
    if (provedor.equals("A")) return new FabricaProvedorA(segredo.getBytes(StandardCharsets.UTF_8));
    if (provedor.equals("B")) return new FabricaProvedorB(segredo);
    throw new IllegalArgumentException("provedor desconhecido");
}

public static void main(String[] args) {
    byte[] corpo = "{\"pedido\": \"P-77\"}".getBytes(StandardCharsets.UTF_8);

    ServicoDeCheckout checkoutA = new ServicoDeCheckout(fabricaPara("A", "s3gr3d0"));
    System.out.println(checkoutA.iniciar("P-77", 15990));
    String assinaturaA = Cripto.hmacSha256("s3gr3d0".getBytes(StandardCharsets.UTF_8), corpo);
    System.out.println("StatusPagamento." + checkoutA.receberWebhook(corpo, assinaturaA, "succeeded"));

    ServicoDeCheckout checkoutB = new ServicoDeCheckout(fabricaPara("B", "tok-123"));
    System.out.println(checkoutB.iniciar("P-78", 4500));
    String assinaturaB = "tok-123:" + Cripto.sha1(corpo);
    System.out.println("StatusPagamento." + checkoutB.receberWebhook(corpo, assinaturaB, "negado"));

    try {
        checkoutB.receberWebhook(corpo, assinaturaA, "APROVADO");
    } catch (SecurityException erro) {
        System.out.println("bloqueado: " + erro.getMessage());
    }
}
```

```cpp
static string sha1(const string& msg) {
    uint32_t h[5] = {0x67452301, 0xEFCDAB89, 0x98BADCFE, 0x10325476, 0xC3D2E1F0};
    string m = msg;
    uint64_t bits = (uint64_t)msg.size() * 8;
    m += (char)0x80;
    while (m.size() % 64 != 56) m += (char)0;
    for (int i = 7; i >= 0; i--) m += (char)(bits >> (i * 8));
    auto rotl = [](uint32_t x, int n) { return (x << n) | (x >> (32 - n)); };
    for (size_t off = 0; off < m.size(); off += 64) {
        uint32_t w[80];
        for (int i = 0; i < 16; i++) {
            w[i] = ((uint32_t)(uint8_t)m[off + 4 * i] << 24) | ((uint32_t)(uint8_t)m[off + 4 * i + 1] << 16) |
                   ((uint32_t)(uint8_t)m[off + 4 * i + 2] << 8) | (uint32_t)(uint8_t)m[off + 4 * i + 3];
        }
        for (int i = 16; i < 80; i++) w[i] = rotl(w[i - 3] ^ w[i - 8] ^ w[i - 14] ^ w[i - 16], 1);
        uint32_t a = h[0], b = h[1], c = h[2], d = h[3], e = h[4];
        for (int i = 0; i < 80; i++) {
            uint32_t f, k;
            if (i < 20)      { f = (b & c) | (~b & d);          k = 0x5A827999; }
            else if (i < 40) { f = b ^ c ^ d;                   k = 0x6ED9EBA1; }
            else if (i < 60) { f = (b & c) | (b & d) | (c & d); k = 0x8F1BBCDC; }
            else             { f = b ^ c ^ d;                   k = 0xCA62C1D6; }
            uint32_t t = rotl(a, 5) + f + e + k + w[i];
            e = d; d = c; c = rotl(b, 30); b = a; a = t;
        }
        h[0] += a; h[1] += b; h[2] += c; h[3] += d; h[4] += e;
    }
    string out;
    for (int i = 0; i < 5; i++) for (int j = 3; j >= 0; j--) out += (char)(h[i] >> (j * 8));
    return out;
}

static string hex(const string& bytes) {
    static const char* d = "0123456789abcdef";
    string r;
    for (unsigned char c : bytes) { r += d[c >> 4]; r += d[c & 15]; }
    return r;
}

static string hmacSha256(string chave, const string& msg) {
    if (chave.size() > 64) chave = sha256(chave);
    chave.resize(64, '\0');
    string ipad(64, 0), opad(64, 0);
    for (int i = 0; i < 64; i++) { ipad[i] = chave[i] ^ 0x36; opad[i] = chave[i] ^ 0x5c; }
    return sha256(opad + sha256(ipad + msg));
}

static bool iguais(const string& a, const string& b) {
    if (a.size() != b.size()) return false;
    unsigned char dif = 0;
    for (size_t i = 0; i < a.size(); i++) dif |= (unsigned char)(a[i] ^ b[i]);
    return dif == 0;
}
```

```go
	return &ServicoDeCheckout{f.CriarCobranca(), f.CriarValidador(), f.CriarConversor()}
}

func (s *ServicoDeCheckout) Iniciar(pedidoID string, centavos int) []Campo {
	return s.cobranca.Criar(pedidoID, centavos)
}

func (s *ServicoDeCheckout) ReceberWebhook(corpo []byte, assinatura, codigo string) (StatusPagamento, error) {
	if !s.validador.Valido(corpo, assinatura) {
		return Pendente, errors.New("assinatura de webhook inválida")
	}
	return s.conversor.Converter(codigo), nil
}

func fabricaPara(provedor, segredo string) FabricaDeProvedor {
	switch provedor {
	case "A":
		return FabricaProvedorA{[]byte(segredo)}
	case "B":
		return FabricaProvedorB{segredo}
	}
	panic("provedor desconhecido")
}

func main() {
	corpo := []byte(`{"pedido": "P-77"}`)

	checkoutA := NovoServico(fabricaPara("A", "s3gr3d0"))
	imprimir(checkoutA.Iniciar("P-77", 15990))
	assinaturaA := hmacSha256([]byte("s3gr3d0"), corpo)
	statusA, _ := checkoutA.ReceberWebhook(corpo, assinaturaA, "succeeded")
	fmt.Println("StatusPagamento." + string(statusA))

	checkoutB := NovoServico(fabricaPara("B", "tok-123"))
	imprimir(checkoutB.Iniciar("P-78", 4500))
	assinaturaB := "tok-123:" + sha1Hex(corpo)
	statusB, _ := checkoutB.ReceberWebhook(corpo, assinaturaB, "negado")
	fmt.Println("StatusPagamento." + string(statusB))

	if _, erro := checkoutB.ReceberWebhook(corpo, assinaturaA, "APROVADO"); erro != nil {
		fmt.Println("bloqueado:", erro)
	}
}
```

O `ServicoDeCheckout` não importa nenhuma classe concreta. Trocar de provedor é trocar a fábrica, e é impossível montar um checkout com cobrança do A e validador do B.

## Trade-offs

- **Adicionar uma família nova é fácil** (uma fábrica e seus produtos). **Adicionar um tipo de produto novo é caro**: toda fábrica precisa ganhar um método. Avalie qual eixo muda mais no seu domínio.
- Muitas classes pequenas. Para duas famílias com um produto cada, é exagero.

## Quando usar e quando evitar

| Use quando | Evite quando |
| --- | --- |
| Há famílias de objetos que precisam ser usados juntos (provedores, temas de UI, bancos de dados) | Os objetos são independentes entre si |
| A família é escolhida uma vez, por configuração | Você só cria um tipo de objeto: use Factory Method ou uma função |
| Você quer impedir misturas incompatíveis | Novos tipos de produto surgem toda semana |

## Padrões parecidos

- **Factory Method:** um método que cria **um** produto e é sobrescrito por subclasses. A Abstract Factory é um **objeto** com vários métodos fábrica, normalmente passado por composição. Muitas vezes cada método da Abstract Factory é implementado como um Factory Method.
- **Builder:** monta um objeto complexo passo a passo; a Abstract Factory devolve cada produto pronto de uma vez.
- **Singleton:** fábricas concretas costumam ter uma instância só por configuração, mas isso não precisa ser forçado pelo padrão.

<Callout type="tip" title="Pista no enunciado">
Quando o problema diz "suportar vários provedores/plataformas/temas, e cada um tem seu próprio jeito de fazer X, Y e Z", é quase sempre Abstract Factory.
</Callout>

## Na entrevista

Bons gatilhos: suporte a múltiplos provedores de pagamento, múltiplos bancos de dados (conexão, dialeto SQL e migrador), UI multiplataforma, jogos com temas. Follow-ups comuns:

- "Como você adiciona um quarto produto?" Admita o custo: todas as fábricas mudam.
- "Quem escolhe a fábrica?" A composição na inicialização (configuração do tenant), uma vez.
- "Como testar?" Uma fábrica falsa que devolve dublês para os três produtos.
