Um agendador executa tarefas em instantes futuros, uma vez ou de forma recorrente. O núcleo é uma fila de prioridade ordenada pelo horário de execução, com um laço que espera até a próxima tarefa vencer. As complicações vêm com concorrência, cancelamento e recorrência.

## Requisitos

- Agendar uma tarefa para um instante, ou com atraso.
- Tarefas periódicas (a cada N segundos).
- Cancelar tarefas pendentes.
- Executar tarefas em ordem de horário, com um pool de workers.

## Entidades

| Entidade | Responsabilidade |
| --- | --- |
| `Tarefa` | Função, horário, intervalo opcional e flag de cancelamento. |
| `Agendador` | Heap de tarefas, avanço do tempo e execução. |
| `Relogio` | Fonte de tempo injetável. |

O heap garante que a próxima tarefa a vencer está sempre no topo, com inserção e remoção em O(log n). Para ordenar de forma estável quando os horários empatam, usamos um contador de sequência como desempate.

## Implementação

Para manter o exemplo determinístico e testável, o agendador expõe `avancar_ate(instante)`, que executa tudo que venceu. Um laço real chamaria esse método a cada espera até o próximo horário.

```python
import heapq
import itertools
from typing import Callable, List


class Tarefa:
    def __init__(self, nome: str, funcao: Callable[[], None], horario: float,
                 intervalo: float = None):
        self.nome, self.funcao, self.horario, self.intervalo = nome, funcao, horario, intervalo
        self.cancelada = False

    def cancelar(self):
        self.cancelada = True


class Agendador:
    def __init__(self, inicio: float = 0.0):
        self.agora = inicio
        self._heap: List = []
        self._seq = itertools.count()

    def agendar(self, nome, funcao, atraso: float = 0, intervalo: float = None) -> Tarefa:
        t = Tarefa(nome, funcao, self.agora + atraso, intervalo)
        self._empilhar(t)
        return t

    def _empilhar(self, t: Tarefa):
        heapq.heappush(self._heap, (t.horario, next(self._seq), t))

    def proximo_horario(self):
        while self._heap and self._heap[0][2].cancelada:
            heapq.heappop(self._heap)       # descarta canceladas preguiçosamente
        return self._heap[0][0] if self._heap else None

    def avancar_ate(self, instante: float) -> int:
        executadas = 0
        while True:
            prox = self.proximo_horario()
            if prox is None or prox > instante:
                break
            _, _, t = heapq.heappop(self._heap)
            self.agora = t.horario
            t.funcao()
            executadas += 1
            if t.intervalo is not None and not t.cancelada:
                t.horario += t.intervalo      # recorrente: reagenda a partir do horário previsto
                self._empilhar(t)
        self.agora = instante
        return executadas


log = []
ag = Agendador()
ag.agendar("b", lambda: log.append(("b", ag.agora)), atraso=5)
ag.agendar("a", lambda: log.append(("a", ag.agora)), atraso=2)
rec = ag.agendar("tic", lambda: log.append(("tic", ag.agora)), atraso=1, intervalo=3)
ag.avancar_ate(8)
print(log)      # tic em 1, a em 2, tic em 4, b em 5, tic em 7
rec.cancelar()
print(ag.avancar_ate(20), ag.proximo_horario())
```

```javascript
// Heap mínimo de [horario, sequencia, tarefa], comparando horário e depois a ordem de chegada.
class HeapMinimo {
  #itens = [];

  #menor(a, b) {
    return a[0] < b[0] || (a[0] === b[0] && a[1] < b[1]);
  }

  get tamanho() {
    return this.#itens.length;
  }

  topo() {
    return this.#itens[0];
  }

  empilhar(item) {
    const v = this.#itens;
    v.push(item);
    let i = v.length - 1;
    while (i > 0) {
      const pai = (i - 1) >> 1;
      if (!this.#menor(v[i], v[pai])) break;
      [v[i], v[pai]] = [v[pai], v[i]];
      i = pai;
    }
  }

  desempilhar() {
    const v = this.#itens;
    const topo = v[0];
    const ultimo = v.pop();
    if (v.length > 0) {
      v[0] = ultimo;
      let i = 0;
      while (true) {
        let menor = i;
        const e = 2 * i + 1;
        const d = 2 * i + 2;
        if (e < v.length && this.#menor(v[e], v[menor])) menor = e;
        if (d < v.length && this.#menor(v[d], v[menor])) menor = d;
        if (menor === i) break;
        [v[i], v[menor]] = [v[menor], v[i]];
        i = menor;
      }
    }
    return topo;
  }
}

class Tarefa {
  constructor(nome, funcao, horario, intervalo = null) {
    this.nome = nome;
    this.funcao = funcao;
    this.horario = horario;
    this.intervalo = intervalo;
    this.cancelada = false;
  }

  cancelar() {
    this.cancelada = true;
  }
}

class Agendador {
  #heap = new HeapMinimo();
  #seq = 0;

  constructor(inicio = 0.0) {
    this.agora = inicio;
  }

  agendar(nome, funcao, atraso = 0, intervalo = null) {
    const t = new Tarefa(nome, funcao, this.agora + atraso, intervalo);
    this.#empilhar(t);
    return t;
  }

  #empilhar(t) {
    this.#heap.empilhar([t.horario, this.#seq++, t]);
  }

  proximoHorario() {
    while (this.#heap.tamanho > 0 && this.#heap.topo()[2].cancelada) {
      this.#heap.desempilhar(); // descarta canceladas preguiçosamente
    }
    return this.#heap.tamanho > 0 ? this.#heap.topo()[0] : null;
  }

  avancarAte(instante) {
    let executadas = 0;
    while (true) {
      const prox = this.proximoHorario();
      if (prox === null || prox > instante) {
        break;
      }
      const [, , t] = this.#heap.desempilhar();
      this.agora = t.horario;
      t.funcao();
      executadas += 1;
      if (t.intervalo !== null && !t.cancelada) {
        t.horario += t.intervalo; // recorrente: reagenda a partir do horário previsto
        this.#empilhar(t);
      }
    }
    this.agora = instante;
    return executadas;
  }
}
```

```java
import java.util.*;

class Tarefa {
    final String nome;
    final Runnable funcao;
    double horario;
    final Double intervalo; // null = não recorrente
    boolean cancelada = false;

    Tarefa(String nome, Runnable funcao, double horario, Double intervalo) {
        this.nome = nome;
        this.funcao = funcao;
        this.horario = horario;
        this.intervalo = intervalo;
    }

    void cancelar() {
        cancelada = true;
    }
}

class Agendador {
    double agora;
    private final PriorityQueue<Object[]> heap = new PriorityQueue<>((a, b) -> {
        int c = Double.compare((Double) a[0], (Double) b[0]);
        return c != 0 ? c : Long.compare((Long) a[1], (Long) b[1]);
    });
    private long seq = 0;

    Agendador(double inicio) {
        this.agora = inicio;
    }

    Tarefa agendar(String nome, Runnable funcao, double atraso, Double intervalo) {
        Tarefa t = new Tarefa(nome, funcao, agora + atraso, intervalo);
        empilhar(t);
        return t;
    }

    private void empilhar(Tarefa t) {
        heap.add(new Object[] {t.horario, seq++, t});
    }

    Double proximoHorario() {
        while (!heap.isEmpty() && ((Tarefa) heap.peek()[2]).cancelada) {
            heap.poll(); // descarta canceladas preguiçosamente
        }
        return heap.isEmpty() ? null : (Double) heap.peek()[0];
    }

    int avancarAte(double instante) {
        int executadas = 0;
        while (true) {
            Double prox = proximoHorario();
            if (prox == null || prox > instante) {
                break;
            }
            Tarefa t = (Tarefa) heap.poll()[2];
            agora = t.horario;
            t.funcao.run();
            executadas += 1;
            if (t.intervalo != null && !t.cancelada) {
                t.horario += t.intervalo; // recorrente: reagenda a partir do horário previsto
                empilhar(t);
            }
        }
        agora = instante;
        return executadas;
    }
}

public static void main(String[] args) {
    List<String> log = new ArrayList<>();
    Agendador ag = new Agendador(0.0);
    ag.agendar("b", () -> log.add("('b', " + ag.agora + ")"), 5, null);
    ag.agendar("a", () -> log.add("('a', " + ag.agora + ")"), 2, null);
    Tarefa rec = ag.agendar("tic", () -> log.add("('tic', " + ag.agora + ")"), 1, 3.0);
    ag.avancarAte(8);
    System.out.println("[" + String.join(", ", log) + "]"); // tic em 1, a em 2, tic em 4, b em 5, tic em 7
    rec.cancelar();
    int executadas = ag.avancarAte(20);
    System.out.println(executadas + " " + ag.proximoHorario());
}
```

```cpp
#include <functional>
#include <iostream>
#include <memory>
#include <optional>
#include <queue>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

struct Tarefa {
    string nome;
    function<void()> funcao;
    double horario;
    optional<double> intervalo;
    bool cancelada = false;

    void cancelar() { cancelada = true; }
};

class Agendador {
    using Item = tuple<double, long, Tarefa*>; // horário, ordem de chegada, tarefa
    priority_queue<Item, vector<Item>, greater<Item>> heap;
    vector<unique_ptr<Tarefa>> tarefas;
    long seq = 0;

    void empilhar(Tarefa* t) { heap.push({t->horario, seq++, t}); }

public:
    double agora;

    Agendador(double inicio = 0.0) : agora(inicio) {}

    Tarefa* agendar(const string& nome, function<void()> funcao, double atraso = 0, optional<double> intervalo = nullopt) {
        tarefas.push_back(make_unique<Tarefa>(Tarefa{nome, funcao, agora + atraso, intervalo}));
        Tarefa* t = tarefas.back().get();
        empilhar(t);
        return t;
    }

    optional<double> proximoHorario() {
        while (!heap.empty() && get<2>(heap.top())->cancelada) {
            heap.pop(); // descarta canceladas preguiçosamente
        }
        if (heap.empty()) return nullopt;
        return get<0>(heap.top());
    }

    int avancarAte(double instante) {
        int executadas = 0;
        while (true) {
            auto prox = proximoHorario();
            if (!prox || *prox > instante) {
                break;
            }
            Tarefa* t = get<2>(heap.top());
            heap.pop();
            agora = t->horario;
            t->funcao();
            executadas += 1;
            if (t->intervalo && !t->cancelada) {
                t->horario += *t->intervalo; // recorrente: reagenda a partir do horário previsto
                empilhar(t);
            }
        }
        agora = instante;
        return executadas;
    }
};
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Tarefa
{
    public readonly string Nome;
    public readonly Action Funcao;
    public double Horario;
    public readonly double? Intervalo;
    public bool Cancelada = false;

    public Tarefa(string nome, Action funcao, double horario, double? intervalo)
    {
        Nome = nome;
        Funcao = funcao;
        Horario = horario;
        Intervalo = intervalo;
    }

    public void Cancelar()
    {
        Cancelada = true;
    }
}

class Agendador
{
    // SortedSet ordena por horário e depois pela ordem de chegada (a sequência torna cada item único).
    private class Item
    {
        public double Horario;
        public long Seq;
        public Tarefa Tarefa;
    }

    private class Ordem : IComparer<Item>
    {
        public int Compare(Item a, Item b)
        {
            int c = a.Horario.CompareTo(b.Horario);
            return c != 0 ? c : a.Seq.CompareTo(b.Seq);
        }
    }

    private readonly SortedSet<Item> heap = new SortedSet<Item>(new Ordem());
    private long seq = 0;
    public double Agora;

    public Agendador(double inicio = 0.0)
    {
        Agora = inicio;
    }

    public Tarefa Agendar(string nome, Action funcao, double atraso = 0, double? intervalo = null)
    {
        var t = new Tarefa(nome, funcao, Agora + atraso, intervalo);
        Empilhar(t);
        return t;
    }

    private void Empilhar(Tarefa t)
    {
        heap.Add(new Item { Horario = t.Horario, Seq = seq++, Tarefa = t });
    }

    public double? ProximoHorario()
    {
        while (heap.Count > 0 && heap.Min.Tarefa.Cancelada)
        {
            heap.Remove(heap.Min); // descarta canceladas preguiçosamente
        }
        return heap.Count > 0 ? (double?)heap.Min.Horario : null;
    }

    public int AvancarAte(double instante)
    {
        int executadas = 0;
        while (true)
        {
            var prox = ProximoHorario();
            if (prox == null || prox.Value > instante)
            {
                break;
            }
            var item = heap.Min;
            heap.Remove(item);
            var t = item.Tarefa;
            Agora = t.Horario;
            t.Funcao();
            executadas += 1;
            if (t.Intervalo != null && !t.Cancelada)
            {
                t.Horario += t.Intervalo.Value; // recorrente: reagenda a partir do horário previsto
                Empilhar(t);
            }
        }
        Agora = instante;
        return executadas;
    }
}

static void Main()
{
    var log = new List<string>();
    var ag = new Agendador();
    ag.Agendar("b", () => log.Add("('b', " + ag.Agora + ")"), 5);
    ag.Agendar("a", () => log.Add("('a', " + ag.Agora + ")"), 2);
    var rec = ag.Agendar("tic", () => log.Add("('tic', " + ag.Agora + ")"), 1, 3);
    ag.AvancarAte(8);
    Console.WriteLine("[" + string.Join(", ", log) + "]"); // tic em 1, a em 2, tic em 4, b em 5, tic em 7
    rec.Cancelar();
    int executadas = ag.AvancarAte(20);
    var prox = ag.ProximoHorario();
    Console.WriteLine(executadas + " " + (prox.HasValue ? prox.Value.ToString() : "null"));
}
```

```go
import (
	"container/heap"
	"fmt"
	"strings"
)

type Tarefa struct {
	nome      string
	funcao    func()
	horario   float64
	intervalo *float64
	cancelada bool
}

func (t *Tarefa) cancelar() { t.cancelada = true }

type item struct {
	horario float64
	seq     int
	tarefa  *Tarefa
}

// fila implementa heap.Interface: ordena por horário e depois pela ordem de chegada.
type fila []item

func (f fila) Len() int { return len(f) }
func (f fila) Less(i, j int) bool {
	if f[i].horario != f[j].horario {
		return f[i].horario < f[j].horario
	}
	return f[i].seq < f[j].seq
}
func (f fila) Swap(i, j int)       { f[i], f[j] = f[j], f[i] }
func (f *fila) Push(x interface{}) { *f = append(*f, x.(item)) }
func (f *fila) Pop() interface{} {
	antigo := *f
	n := len(antigo)
	ultimo := antigo[n-1]
	*f = antigo[:n-1]
	return ultimo
}

type Agendador struct {
	agora float64
	heap  fila
	seq   int
}

func (a *Agendador) agendar(nome string, funcao func(), atraso float64, intervalo *float64) *Tarefa {
	t := &Tarefa{nome: nome, funcao: funcao, horario: a.agora + atraso, intervalo: intervalo}
	a.empilhar(t)
	return t
}

func (a *Agendador) empilhar(t *Tarefa) {
	heap.Push(&a.heap, item{t.horario, a.seq, t})
	a.seq++
}

func (a *Agendador) proximoHorario() (float64, bool) {
	for len(a.heap) > 0 && a.heap[0].tarefa.cancelada {
		heap.Pop(&a.heap) // descarta canceladas preguiçosamente
	}
	if len(a.heap) == 0 {
		return 0, false
	}
	return a.heap[0].horario, true
}

func (a *Agendador) avancarAte(instante float64) int {
	executadas := 0
	for {
		prox, existe := a.proximoHorario()
		if !existe || prox > instante {
			break
		}
		t := heap.Pop(&a.heap).(item).tarefa
		a.agora = t.horario
		t.funcao()
		executadas++
		if t.intervalo != nil && !t.cancelada {
			t.horario += *t.intervalo // recorrente: reagenda a partir do horário previsto
			a.empilhar(t)
		}
	}
	a.agora = instante
	return executadas
}

func main() {
	log := []string{}
	ag := &Agendador{}
	ag.agendar("b", func() { log = append(log, fmt.Sprintf("('b', %v)", ag.agora)) }, 5, nil)
	ag.agendar("a", func() { log = append(log, fmt.Sprintf("('a', %v)", ag.agora)) }, 2, nil)
	tres := 3.0
	rec := ag.agendar("tic", func() { log = append(log, fmt.Sprintf("('tic', %v)", ag.agora)) }, 1, &tres)
	ag.avancarAte(8)
	fmt.Println("[" + strings.Join(log, ", ") + "]") // tic em 1, a em 2, tic em 4, b em 5, tic em 7
	rec.cancelar()
	executadas := ag.avancarAte(20)
	if prox, existe := ag.proximoHorario(); existe {
		fmt.Println(executadas, prox)
	} else {
		fmt.Println(executadas, "nil")
	}
}
```

</CodeTabs>

Cancelar só marca a tarefa; ela é descartada quando chega ao topo do heap. Remover do meio de um heap seria O(n), e a remoção preguiçosa mantém o custo baixo.

## Recorrência: duas semânticas

| Modo | Próximo horário | Efeito |
| --- | --- | --- |
| Taxa fixa | Horário previsto mais intervalo | Não acumula deriva; pode empilhar execuções se atrasar |
| Atraso fixo | Fim da execução mais intervalo | Nunca sobrepõe; o período real cresce |

O exemplo usa taxa fixa. Escolha e justifique na entrevista.

## Concorrência

Em produção há uma thread de despacho que dorme até o próximo horário (com variável de condição, para acordar se entrar uma tarefa mais cedo) e um pool de workers que executa as funções. Assim uma tarefa lenta não atrasa as outras. O heap e o estado precisam de lock, e o despachador nunca executa a tarefa segurando o lock.

## Extensões

Prioridade entre tarefas no mesmo instante, tentativas com espera crescente, expressões cron, persistência para sobreviver a reinício e agendamento distribuído com eleição de líder ou trava no armazenamento para que só uma instância execute cada tarefa.

## Na entrevista

- **"Por que heap e não lista ordenada?"** Inserção O(log n) contra O(n).
- **"Como evitar espera ocupada?"** Dormir até o próximo horário com timeout e acordar por sinal quando entrar tarefa antecipada.
