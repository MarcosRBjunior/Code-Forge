Alguns objetos têm um **ciclo de vida**: um pedido é criado, pago, enviado, entregue ou cancelado; uma porta está aberta, fechada ou trancada. O comportamento depende do estado atual e nem toda ação é válida em todo estado. O diagrama de máquina de estados deixa essas regras explícitas.

## Elementos

- **Estado**: retângulo arredondado ("Pago").
- **Transição**: seta de um estado a outro, rotulada como `evento [condição] / ação`.
- **Estado inicial**: círculo preenchido. **Estado final**: círculo com borda dupla.
- **Ações de entrada e saída**: algo que roda ao entrar ou sair de um estado.

## Exemplo: ciclo de um pedido

```text
(inicio) --> CRIADO --pagar--> PAGO --enviar--> ENVIADO --entregar--> ENTREGUE --> (fim)
               |                 |
             cancelar          cancelar
               v                 v
            CANCELADO <----------+
```

Leitura: só se pode enviar um pedido pago; não se cancela um pedido já enviado. Tudo que não está desenhado é **transição proibida**, e isso é exatamente a informação valiosa.

## Do diagrama ao código

A forma mais simples é uma tabela de transições, que é a cópia direta do diagrama:

```python
from enum import Enum


class Estado(Enum):
    CRIADO = "criado"
    PAGO = "pago"
    ENVIADO = "enviado"
    ENTREGUE = "entregue"
    CANCELADO = "cancelado"


TRANSICOES = {
    (Estado.CRIADO, "pagar"): Estado.PAGO,
    (Estado.CRIADO, "cancelar"): Estado.CANCELADO,
    (Estado.PAGO, "enviar"): Estado.ENVIADO,
    (Estado.PAGO, "cancelar"): Estado.CANCELADO,
    (Estado.ENVIADO, "entregar"): Estado.ENTREGUE,
}


class Pedido:
    def __init__(self) -> None:
        self.estado = Estado.CRIADO

    def aplicar(self, evento: str) -> None:
        proximo = TRANSICOES.get((self.estado, evento))
        if proximo is None:
            raise ValueError(f"'{evento}' inválido em {self.estado.value}")
        self.estado = proximo


p = Pedido()
p.aplicar("pagar")
p.aplicar("enviar")
try:
    p.aplicar("cancelar")
except ValueError as erro:
    print(erro)
p.aplicar("entregar")
assert p.estado is Estado.ENTREGUE
```

```java
import java.util.*;

enum Estado {
    CRIADO("criado"), PAGO("pago"), ENVIADO("enviado"), ENTREGUE("entregue"), CANCELADO("cancelado");

    final String valor;

    Estado(String valor) { this.valor = valor; }
}

class Pedido {
    private static final Map<String, Estado> TRANSICOES = Map.of(
        "CRIADO|pagar", Estado.PAGO,
        "CRIADO|cancelar", Estado.CANCELADO,
        "PAGO|enviar", Estado.ENVIADO,
        "PAGO|cancelar", Estado.CANCELADO,
        "ENVIADO|entregar", Estado.ENTREGUE);

    Estado estado = Estado.CRIADO;

    void aplicar(String evento) {
        Estado proximo = TRANSICOES.get(estado.name() + "|" + evento);
        if (proximo == null) {
            throw new IllegalArgumentException("'" + evento + "' inválido em " + estado.valor);
        }
        estado = proximo;
    }
}

public static void main(String[] args) {
    Pedido p = new Pedido();
    p.aplicar("pagar");
    p.aplicar("enviar");
    try {
        p.aplicar("cancelar");
    } catch (IllegalArgumentException erro) {
        System.out.println(erro.getMessage());
    }
    p.aplicar("entregar");
    if (p.estado != Estado.ENTREGUE) throw new AssertionError();
}
```

```cpp
#include <cassert>
#include <iostream>
#include <map>
#include <stdexcept>
#include <string>
#include <utility>
using namespace std;

enum class Estado { Criado, Pago, Enviado, Entregue, Cancelado };

string nome(Estado e) {
    switch (e) {
        case Estado::Criado: return "criado";
        case Estado::Pago: return "pago";
        case Estado::Enviado: return "enviado";
        case Estado::Entregue: return "entregue";
        case Estado::Cancelado: return "cancelado";
    }
    return "?";
}

const map<pair<Estado, string>, Estado> TRANSICOES = {
    {{Estado::Criado, "pagar"}, Estado::Pago},
    {{Estado::Criado, "cancelar"}, Estado::Cancelado},
    {{Estado::Pago, "enviar"}, Estado::Enviado},
    {{Estado::Pago, "cancelar"}, Estado::Cancelado},
    {{Estado::Enviado, "entregar"}, Estado::Entregue},
};

class Pedido {
public:
    Estado estado = Estado::Criado;

    void aplicar(const string& evento) {
        auto it = TRANSICOES.find({estado, evento});
        if (it == TRANSICOES.end()) {
            throw invalid_argument("'" + evento + "' inválido em " + nome(estado));
        }
        estado = it->second;
    }
};

int main() {
    Pedido p;
    p.aplicar("pagar");
    p.aplicar("enviar");
    try {
        p.aplicar("cancelar");
    } catch (const invalid_argument& erro) {
        cout << erro.what() << endl;
    }
    p.aplicar("entregar");
    assert(p.estado == Estado::Entregue);
}
```

```csharp
using System;
using System.Collections.Generic;

enum Estado { Criado, Pago, Enviado, Entregue, Cancelado }

class Pedido
{
    private static readonly Dictionary<Tuple<Estado, string>, Estado> TRANSICOES = new Dictionary<Tuple<Estado, string>, Estado>
    {
        [Tuple.Create(Estado.Criado, "pagar")] = Estado.Pago,
        [Tuple.Create(Estado.Criado, "cancelar")] = Estado.Cancelado,
        [Tuple.Create(Estado.Pago, "enviar")] = Estado.Enviado,
        [Tuple.Create(Estado.Pago, "cancelar")] = Estado.Cancelado,
        [Tuple.Create(Estado.Enviado, "entregar")] = Estado.Entregue,
    };

    public Estado Estado = Estado.Criado;

    public void Aplicar(string evento)
    {
        Estado proximo;
        if (!TRANSICOES.TryGetValue(Tuple.Create(Estado, evento), out proximo))
        {
            throw new ArgumentException("'" + evento + "' inválido em " + Estado.ToString().ToLower());
        }
        Estado = proximo;
    }
}

static void Main()
{
    var p = new Pedido();
    p.Aplicar("pagar");
    p.Aplicar("enviar");
    try
    {
        p.Aplicar("cancelar");
    }
    catch (ArgumentException erro)
    {
        Console.WriteLine(erro.Message);
    }
    p.Aplicar("entregar");
    if (p.Estado != Estado.Entregue) throw new Exception("falhou");
}
```

```go
import (
	"fmt"
)

type Estado string

const (
	Criado    Estado = "criado"
	Pago      Estado = "pago"
	Enviado   Estado = "enviado"
	Entregue  Estado = "entregue"
	Cancelado Estado = "cancelado"
)

type chave struct {
	estado Estado
	evento string
}

var transicoes = map[chave]Estado{
	{Criado, "pagar"}:      Pago,
	{Criado, "cancelar"}:   Cancelado,
	{Pago, "enviar"}:       Enviado,
	{Pago, "cancelar"}:     Cancelado,
	{Enviado, "entregar"}:  Entregue,
}

type Pedido struct {
	estado Estado
}

func (p *Pedido) aplicar(evento string) error {
	proximo, ok := transicoes[chave{p.estado, evento}]
	if !ok {
		return fmt.Errorf("'%s' inválido em %s", evento, p.estado)
	}
	p.estado = proximo
	return nil
}

func main() {
	p := &Pedido{Criado}
	p.aplicar("pagar")
	p.aplicar("enviar")
	if erro := p.aplicar("cancelar"); erro != nil {
		fmt.Println(erro)
	}
	p.aplicar("entregar")
	if p.estado != Entregue {
		panic("falhou")
	}
}
```

## Tabela ou padrão State?

| Abordagem | Quando usar |
| --- | --- |
| Tabela de transições | Poucos estados, ação simples em cada transição |
| Padrão State (uma classe por estado) | Cada estado tem comportamento rico e diferente |
| Cadeia de if/elif | Evite: cresce mal e esconde transições ilegais |

O capítulo sobre o padrão State mostra a versão orientada a objetos; a tabela é ótima para começar e fácil de testar.

## Armadilhas

- **Estados que na verdade são flags**: se você tem `pago`, `enviado` e `cancelado` como booleanos, pode acabar em combinações impossíveis. Um único campo de estado evita isso.
- **Esquecer estados terminais**: defina quais são e proíba qualquer saída deles.
- **Transições implícitas**: se uma mudança de estado acontece por tempo (expiração), desenhe o evento de timeout.

<Callout type="note" title="Bom sinal para o padrão State">
Se você escreve o mesmo `if estado == ...` em vários métodos, é hora de pensar em State ou numa tabela de transições.
</Callout>

## Na entrevista

Máquina de estados é a base de problemas como elevador, máquina de vendas, semáforo e caixa eletrônico. Desenhe estados e eventos antes de codar. Follow-ups: "o que acontece se chegar um evento inválido?", "como você testaria todas as transições?".
