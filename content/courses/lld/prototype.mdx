## O problema

Num editor de documentos, o usuário escolhe um modelo, "Contrato de prestação de serviços", e recebe um documento novo já com cabeçalho, cláusulas, estilos e metadados. Construir esse documento do zero exige ler arquivos, aplicar estilos e montar dezenas de objetos. E quem pede o documento nem sempre sabe a classe concreta do modelo (pode ser um `Contrato`, uma `Proposta`, um `Relatorio` com seções customizadas).

O **Prototype** cria objetos novos **copiando uma instância existente** (o protótipo), em vez de chamar o construtor. A cópia já sai configurada e você só ajusta o que muda.

## Estrutura

```text
 +------------------------+         +-----------------------------+
 |  CatalogoDeModelos     |-------->|  Documento (protótipo)      |
 +------------------------+  guarda +-----------------------------+
 | + registrar(nome, doc) |         | + clonar(): Documento       |
 | + novo(nome): Documento|         | titulo, estilo, secoes,     |
 +------------------------+         | metadados                   |
         |                          +-----------------------------+
         | novo("contrato")                   ^          ^
         |   -> protótipo.clonar()            |          |
         v                            Contrato       Proposta
   documento independente             clonar()       clonar()
   (cópia profunda das seções)

 Cada classe sabe se copiar; o catálogo não conhece classes concretas.
```

Papéis: **Protótipo** (interface com `clonar`), **Protótipos concretos** e, frequentemente, um **Registro** (catálogo) que guarda protótipos por nome.

## Implementação em Python

O módulo `copy` faz a parte pesada. O ponto delicado é escolher entre **cópia rasa** (compartilha objetos internos) e **cópia profunda** (duplica tudo), e decidir o que **não** deve ser copiado, como o identificador e a data de criação.

import copy
import itertools
from dataclasses import dataclass, field
from datetime import datetime

_ids = itertools.count(1)


@dataclass(frozen=True)
class Estilo:
    """Imutável: pode ser compartilhado entre cópias sem risco."""
    fonte: str
    tamanho: int


@dataclass
class Secao:
    titulo: str
    paragrafos: list[str] = field(default_factory=list)


class Documento:
    def __init__(self, titulo: str, estilo: Estilo, secoes: list[Secao]):
        self.id = next(_ids)
        self.criado_em = datetime.now()
        self.titulo = titulo
        self.estilo = estilo
        self.secoes = secoes
        self.metadados: dict[str, str] = {}

    def clonar(self) -> "Documento":
        novo = copy.deepcopy(self)
        novo.id = next(_ids)               # identidade nunca é copiada
        novo.criado_em = datetime.now()
        return novo

    def __deepcopy__(self, memo):
        cls = type(self)
        novo = cls.__new__(cls)
        memo[id(self)] = novo
        for nome, valor in self.__dict__.items():
            if nome == "estilo":
                setattr(novo, nome, valor)                   # compartilha o imutável
            else:
                setattr(novo, nome, copy.deepcopy(valor, memo))
        return novo

    def resumo(self) -> str:
        nomes = ", ".join(s.titulo for s in self.secoes)
        return f"#{self.id} {self.titulo} [{self.estilo.fonte} {self.estilo.tamanho}] -> {nomes}"


class Contrato(Documento):
    def assinar_como(self, parte: str) -> None:
        self.metadados.setdefault("assinantes", "")
        self.metadados["assinantes"] += parte + ";"


class CatalogoDeModelos:
    def __init__(self):
        self._prototipos: dict[str, Documento] = {}

    def registrar(self, nome: str, prototipo: Documento) -> None:
        self._prototipos[nome] = prototipo

    def novo(self, nome: str) -> Documento:
        return self._prototipos[nome].clonar()


# Montar o protótipo é caro só uma vez
estilo_juridico = Estilo("Times New Roman", 12)
modelo = Contrato(
    "Contrato de prestação de serviços",
    estilo_juridico,
    [
        Secao("Partes", ["CONTRATANTE: ____", "CONTRATADA: ____"]),
        Secao("Objeto", ["Prestação de serviços de desenvolvimento de software."]),
        Secao("Pagamento", ["Valor mensal de R$ ____."]),
    ],
)

catalogo = CatalogoDeModelos()
catalogo.registrar("contrato", modelo)

doc1 = catalogo.novo("contrato")
doc1.secoes[0].paragrafos[0] = "CONTRATANTE: Padaria Pão Quente Ltda."
doc1.secoes.append(Secao("Foro", ["Fica eleito o foro de Campinas/SP."]))
doc1.assinar_como("Padaria Pão Quente")

doc2 = catalogo.novo("contrato")

print(modelo.resumo())
print(doc1.resumo())
print(doc2.resumo())
print("protótipo intacto:", modelo.secoes[0].paragrafos[0])
print("tipo preservado:", type(doc2).__name__)
print("estilo compartilhado:", doc1.estilo is modelo.estilo)
print("metadados isolados:", modelo.metadados, doc1.metadados)

import java.time.LocalDateTime;
import java.util.*;

// Imutável: pode ser compartilhado entre cópias sem risco.
class Estilo {
    final String fonte;
    final int tamanho;

    Estilo(String fonte, int tamanho) {
        this.fonte = fonte;
        this.tamanho = tamanho;
    }
}

class Secao {
    String titulo;
    List<String> paragrafos;

    Secao(String titulo, List<String> paragrafos) {
        this.titulo = titulo;
        this.paragrafos = paragrafos;
    }

    Secao copiar() {
        return new Secao(titulo, new ArrayList<>(paragrafos));
    }
}

class Documento {
    static int proximoId = 1;

    int id;
    LocalDateTime criadoEm;
    String titulo;
    Estilo estilo;
    List<Secao> secoes;
    Map<String, String> metadados = new LinkedHashMap<>();

    Documento(String titulo, Estilo estilo, List<Secao> secoes) {
        this.id = proximoId++;
        this.criadoEm = LocalDateTime.now();
        this.titulo = titulo;
        this.estilo = estilo;
        this.secoes = secoes;
    }

    protected List<Secao> copiaProfundaDasSecoes() {
        List<Secao> r = new ArrayList<>();
        for (Secao s : secoes) r.add(s.copiar());
        return r;
    }

    Documento clonar() {
        // o construtor gera id e criadoEm novos: identidade nunca é copiada
        Documento novo = new Documento(titulo, estilo, copiaProfundaDasSecoes()); // compartilha o estilo imutável
        novo.metadados.putAll(metadados);
        return novo;
    }

    String resumo() {
        List<String> nomes = new ArrayList<>();
        for (Secao s : secoes) nomes.add(s.titulo);
        return "#" + id + " " + titulo + " [" + estilo.fonte + " " + estilo.tamanho + "] -> " + String.join(", ", nomes);
    }
}

class Contrato extends Documento {
    Contrato(String titulo, Estilo estilo, List<Secao> secoes) {
        super(titulo, estilo, secoes);
    }

    @Override
    Contrato clonar() {
        Contrato novo = new Contrato(titulo, estilo, copiaProfundaDasSecoes());
        novo.metadados.putAll(metadados);
        return novo;
    }

    void assinarComo(String parte) {
        metadados.merge("assinantes", parte + ";", String::concat);
    }
}

class CatalogoDeModelos {
    private final Map<String, Documento> prototipos = new HashMap<>();

    void registrar(String nome, Documento prototipo) {
        prototipos.put(nome, prototipo);
    }

    Documento novo(String nome) {
        return prototipos.get(nome).clonar();
    }
}

static String formatar(Map<String, String> m) {
    List<String> pares = new ArrayList<>();
    for (Map.Entry<String, String> e : m.entrySet()) pares.add("'" + e.getKey() + "': '" + e.getValue() + "'");
    return "{" + String.join(", ", pares) + "}";
}

}

using System;

// Imutável: pode ser compartilhado entre cópias sem risco.
class Estilo
{
    public readonly string Fonte;
    public readonly int Tamanho;

    public Estilo(string fonte, int tamanho)
    {
        Fonte = fonte;
        Tamanho = tamanho;
    }
}

class Secao
{
    public string Titulo;
    public List<string> Paragrafos;

    public Secao(string titulo, List<string> paragrafos)
    {
        Titulo = titulo;
        Paragrafos = paragrafos;
    }

    public Secao Copiar()
    {
        return new Secao(Titulo, new List<string>(Paragrafos));
    }
}

class Documento
{
    static int proximoId = 1;

    public int Id;
    public DateTime CriadoEm;
    public string Titulo;
    public Estilo Estilo;
    public List<Secao> Secoes;
    public Dictionary<string, string> Metadados = new Dictionary<string, string>();

    public Documento(string titulo, Estilo estilo, List<Secao> secoes)
    {
        Id = proximoId++;
        CriadoEm = DateTime.Now;
        Titulo = titulo;
        Estilo = estilo;
        Secoes = secoes;
    }

    protected List<Secao> CopiaProfundaDasSecoes()
    {
        return Secoes.Select(s => s.Copiar()).ToList();
    }

    public virtual Documento Clonar()
    {
        // o construtor gera Id e CriadoEm novos: identidade nunca é copiada
        var novo = new Documento(Titulo, Estilo, CopiaProfundaDasSecoes()); // compartilha o estilo imutável
        novo.Metadados = new Dictionary<string, string>(Metadados);
        return novo;
    }

    public string Resumo()
    {
        return "#" + Id + " " + Titulo + " [" + Estilo.Fonte + " " + Estilo.Tamanho + "] -> " + string.Join(", ", Secoes.Select(s => s.Titulo));
    }
}

```go
import (
	"fmt"
	"strings"
	"time"
)

var proximoId = 1

// Imutável: pode ser compartilhado entre cópias sem risco.
type Estilo struct {
	fonte   string
	tamanho int
}

type Secao struct {
	titulo     string
	paragrafos []string
}

type Documento struct {
	id        int
	criadoEm  time.Time
	titulo    string
	estilo    *Estilo
	secoes    []*Secao
	metadados map[string]string
}

func NovoDocumento(titulo string, estilo *Estilo, secoes []*Secao) *Documento {
	d := &Documento{id: proximoId, criadoEm: time.Now(), titulo: titulo, estilo: estilo, secoes: secoes, metadados: map[string]string{}}
	proximoId++
	return d
}

// copia gera um documento novo (id e criadoEm novos) com cópia profunda das seções.
func (d *Documento) copia() *Documento {
	secoes := make([]*Secao, 0, len(d.secoes))
	for _, s := range d.secoes {
		secoes = append(secoes, &Secao{s.titulo, append([]string{}, s.paragrafos...)})
	}
	novo := NovoDocumento(d.titulo, d.estilo, secoes) // compartilha o estilo imutável
	for k, v := range d.metadados {
		novo.metadados[k] = v
	}
	return novo
}

func (d *Documento) resumo() string {
	nomes := []string{}
	for _, s := range d.secoes {
		nomes = append(nomes, s.titulo)
	}
	return fmt.Sprintf("#%d %s [%s %d] -> %s", d.id, d.titulo, d.estilo.fonte, d.estilo.tamanho, strings.Join(nomes, ", "))
}

// Prototipo é o que o catálogo precisa: clonar sem saber o tipo concreto.
type Prototipo interface {
	clonar() Prototipo
	base() *Documento
	tipo() string
}

type Contrato struct {
	*Documento
}

func (c *Contrato) clonar() Prototipo { return &Contrato{c.Documento.copia()} }
func (c *Contrato) base() *Documento  { return c.Documento }
func (c *Contrato) tipo() string      { return "Contrato" }

func (c *Contrato) assinarComo(parte string) {
	c.metadados["assinantes"] += parte + ";"
}

type CatalogoDeModelos struct {
	prototipos map[string]Prototipo
}

func (c *CatalogoDeModelos) registrar(nome string, p Prototipo) { c.prototipos[nome] = p }
func (c *CatalogoDeModelos) novo(nome string) Prototipo         { return c.prototipos[nome].clonar() }

func formatar(m map[string]string) string {
	pares := []string{}
	for k, v := range m {
		pares = append(pares, fmt.Sprintf("'%s': '%s'", k, v))
	}
	return "{" + strings.Join(pares, ", ") + "}"
}

func main() {
	// Montar o protótipo é caro só uma vez
	estiloJuridico := &Estilo{"Times New Roman", 12}
	modelo := &Contrato{NovoDocumento("Contrato de prestação de serviços", estiloJuridico, []*Secao{
		{"Partes", []string{"CONTRATANTE: ____", "CONTRATADA: ____"}},
		{"Objeto", []string{"Prestação de serviços de desenvolvimento de software."}},
		{"Pagamento", []string{"Valor mensal de R$ ____."}},
	})}

	catalogo := &CatalogoDeModelos{prototipos: map[string]Prototipo{}}
	catalogo.registrar("contrato", modelo)

	doc1 := catalogo.novo("contrato").(*Contrato)
	doc1.secoes[0].paragrafos[0] = "CONTRATANTE: Padaria Pão Quente Ltda."
	doc1.secoes = append(doc1.secoes, &Secao{"Foro", []string{"Fica eleito o foro de Campinas/SP."}})
	doc1.assinarComo("Padaria Pão Quente")

	doc2 := catalogo.novo("contrato")

	fmt.Println(modelo.resumo())
	fmt.Println(doc1.resumo())
	fmt.Println(doc2.base().resumo())
	fmt.Println("protótipo intacto:", modelo.secoes[0].paragrafos[0])
	fmt.Println("tipo preservado:", doc2.tipo())
	fmt.Println("estilo compartilhado:", doc1.estilo == modelo.estilo)
	fmt.Println("metadados isolados:", formatar(modelo.metadados), formatar(doc1.metadados))
}
```

</CodeTabs>

Observe três decisões de design:

1. **Cópia profunda** das seções: editar o `doc1` não altera o protótipo nem o `doc2`.
2. **Compartilhamento intencional** do `Estilo`, que é imutável. Copiar seria desperdício.
3. **Campos de identidade regenerados** (`id`, `criado_em`). Um clone com o mesmo id é uma fonte clássica de bugs.

<Callout type="warning" title="Cópia rasa é a armadilha número 1">
`copy.copy` copia só o objeto de fora: a lista `secoes` seria a mesma nas duas instâncias. Uma edição num documento apareceria no outro. Sempre pense no grafo de objetos antes de clonar.
</Callout>

## Quando usar e quando evitar

| Use quando | Evite quando |
| --- | --- |
| Criar do zero é caro (I/O, parsing, cálculos) e as variações são pequenas | O construtor é barato e simples |
| O cliente não conhece a classe concreta, só tem uma instância | O objeto tem referências circulares complexas ou recursos externos (sockets, arquivos abertos) |
| Você quer configurações pré-prontas (presets, modelos, inimigos de um jogo) | A cópia precisa de regras tão específicas que vira um construtor disfarçado |

## Padrões parecidos

- **Factory Method / Abstract Factory:** criam a partir de **classes**; o Prototype cria a partir de **instâncias**. Um catálogo de protótipos pode substituir uma hierarquia inteira de fábricas.
- **Memento:** também tira uma "foto" do estado, mas para **restaurar** o mesmo objeto depois (desfazer). O Prototype cria um objeto **novo e independente**.
- **Flyweight:** compartilha estado para economizar memória; o Prototype duplica estado para dar independência. No exemplo, o `Estilo` compartilhado é uma pitada de Flyweight dentro do Prototype.

## Na entrevista

Cite Prototype ao falar de modelos e presets: duplicar uma playlist, criar uma reserva a partir da anterior, gerar peças de um tabuleiro a partir de um molde, clonar configurações de um tenant. Follow-ups comuns:

- "Cópia rasa ou profunda?" Justifique campo a campo: mutáveis profundos, imutáveis compartilhados.
- "O que não deve ser copiado?" Ids, timestamps, locks, conexões.
- "Como lidar com referências cíclicas?" `deepcopy` usa o dicionário `memo` exatamente para isso.
