**Abstração** é mostrar o essencial e esconder o resto. Quando você dirige, usa volante, pedais e câmbio; não precisa saber como a injeção eletrônica calcula a mistura de combustível. Em software, abstração é desenhar objetos e interfaces que expõem **o que** fazem num nível de detalhe útil para quem usa, escondendo **como** fazem.

## Abstração vs encapsulamento

Os dois conceitos andam juntos e costumam ser confundidos:

| | Abstração | Encapsulamento |
| --- | --- | --- |
| Foco | o que o usuário do objeto enxerga | como o estado interno é protegido |
| Pergunta | qual é a visão simplificada certa? | quem pode alterar este dado e como? |
| Ferramentas | interfaces, classes abstratas, nomes de métodos bem escolhidos | atributos internos, propriedades, validação |
| Resultado | o chamador pensa em termos do domínio | o objeto não entra em estado inválido |

Uma forma de lembrar: abstração decide **qual porta existe**; encapsulamento decide **que todo mundo entra pela porta**.

## O problema: detalhes vazando para o chamador

Imagine um relatório que precisa ler dados ora de um arquivo CSV, ora de uma API:

## Criando a abstração certa

O relatório não se importa com a origem; ele quer uma sequência de **vendas**. Esse é o nível de abstração adequado:

<CodeTabs>

```python
import csv
import io
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Iterator


@dataclass(frozen=True)
class Venda:
    produto: str
    valor: float


class FonteDeVendas(ABC):
    @abstractmethod
    def vendas(self) -> Iterator[Venda]:
        """Entrega as vendas, escondendo formato e origem."""


class FonteCsv(FonteDeVendas):
    def __init__(self, conteudo: str) -> None:
        self._conteudo = conteudo

    def vendas(self) -> Iterator[Venda]:
        for linha in csv.DictReader(io.StringIO(self._conteudo)):
            yield Venda(linha["produto"], float(linha["valor"]))


class FonteApi(FonteDeVendas):
    def __init__(self, resposta: dict) -> None:
        self._resposta = resposta

    def vendas(self) -> Iterator[Venda]:
        for item in self._resposta["data"]["sales"]:
            yield Venda(item["sku"], item["amount"])


class Relatorio:
    def __init__(self, fonte: FonteDeVendas) -> None:
        self._fonte = fonte

    def total(self) -> float:
        return sum(v.valor for v in self._fonte.vendas())

    def mais_vendido(self) -> str:
        somas: dict[str, float] = {}
        for v in self._fonte.vendas():
            somas[v.produto] = somas.get(v.produto, 0) + v.valor
        return max(somas, key=somas.get)


csv_texto = "produto,valor\ncaderno,12\nlapis,3\ncaderno,12\n"
api = {"data": {"sales": [{"sku": "mochila", "amount": 90.0}]}}

for fonte in (FonteCsv(csv_texto), FonteApi(api)):
    r = Relatorio(fonte)
    print(type(fonte).__name__, r.total(), r.mais_vendido())
```

class Venda {
  constructor(produto, valor) {
    this.produto = produto;
    this.valor = valor;
    Object.freeze(this);
  }
}

class FonteDeVendas {
  *vendas() {
    throw new Error("Entrega as vendas, escondendo formato e origem.");
  }
}

class FonteCsv extends FonteDeVendas {
  #conteudo;

  constructor(conteudo) {
    super();
    this.#conteudo = conteudo;
  }

  *vendas() {
    const [, ...linhas] = this.#conteudo.trim().split("\n");
    for (const linha of linhas) {
      const [produto, valor] = linha.split(",");
      yield new Venda(produto, parseFloat(valor));
    }
  }
}

class FonteApi extends FonteDeVendas {
  #resposta;

  constructor(resposta) {
    super();
    this.#resposta = resposta;
  }

  *vendas() {
    for (const item of this.#resposta.data.sales) {
      yield new Venda(item.sku, item.amount);
    }
  }
}

class Relatorio {
  #fonte;

  constructor(fonte) {
    this.#fonte = fonte;
  }

  total() {
    let soma = 0;
    for (const v of this.#fonte.vendas()) soma += v.valor;
    return soma;
  }

  maisVendido() {
    const somas = new Map();
    for (const v of this.#fonte.vendas()) {
      somas.set(v.produto, (somas.get(v.produto) ?? 0) + v.valor);
    }
    return [...somas.entries()].reduce((a, b) => (b[1] > a[1] ? b : a))[0];
  }
}

import java.util.*;

class Venda {
    final String produto;
    final double valor;

    Venda(String produto, double valor) {
        this.produto = produto;
        this.valor = valor;
    }
}

interface FonteDeVendas {
    /** Entrega as vendas, escondendo formato e origem. */
    List<Venda> vendas();
}

class FonteCsv implements FonteDeVendas {
    private final String conteudo;

    FonteCsv(String conteudo) {
        this.conteudo = conteudo;
    }

    public List<Venda> vendas() {
        String[] linhas = conteudo.trim().split("\n");
        List<Venda> r = new ArrayList<>();
        for (int i = 1; i < linhas.length; i++) {
            String[] campos = linhas[i].split(",");
            r.add(new Venda(campos[0], Double.parseDouble(campos[1])));
        }
        return r;
    }
}

class ItemApi {
    final String sku;
    final double amount;

    ItemApi(String sku, double amount) {
        this.sku = sku;
        this.amount = amount;
    }
}

class FonteApi implements FonteDeVendas {
    private final List<ItemApi> sales; // equivale a resposta["data"]["sales"]

    FonteApi(List<ItemApi> sales) {
        this.sales = sales;
    }

    public List<Venda> vendas() {
        List<Venda> r = new ArrayList<>();
        for (ItemApi item : sales) r.add(new Venda(item.sku, item.amount));
        return r;
    }
}

class Relatorio {
    private final FonteDeVendas fonte;

    Relatorio(FonteDeVendas fonte) {
        this.fonte = fonte;
    }

    double total() {
        double soma = 0;
        for (Venda v : fonte.vendas()) soma += v.valor;
        return soma;
    }

    String maisVendido() {
        Map<String, Double> somas = new LinkedHashMap<>();
        for (Venda v : fonte.vendas()) somas.merge(v.produto, v.valor, Double::sum);
        String melhor = null;
        for (Map.Entry<String, Double> e : somas.entrySet()) {
            if (melhor == null || e.getValue() > somas.get(melhor)) melhor = e.getKey();
        }
        return melhor;
    }
}

public static void main(String[] args) {
    String csvTexto = "produto,valor\ncaderno,12\nlapis,3\ncaderno,12\n";
    List<ItemApi> api = List.of(new ItemApi("mochila", 90.0));

    for (FonteDeVendas fonte : List.of(new FonteCsv(csvTexto), new FonteApi(api))) {
        Relatorio r = new Relatorio(fonte);
        System.out.println(fonte.getClass().getSimpleName() + " " + r.total() + " " + r.maisVendido());
    }
}

#include <iostream>
#include <map>
#include <memory>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

struct Venda {
    string produto;
    double valor;
};

class FonteDeVendas {
public:
    virtual ~FonteDeVendas() = default;
    virtual string nome() const = 0;
    // Entrega as vendas, escondendo formato e origem.
    virtual vector<Venda> vendas() const = 0;
};

class FonteCsv : public FonteDeVendas {
    string conteudo;

public:
    FonteCsv(string conteudo) : conteudo(conteudo) {}

    string nome() const override { return "FonteCsv"; }

    vector<Venda> vendas() const override {
        istringstream entrada(conteudo);
        string linha;
        getline(entrada, linha); // cabeçalho
        vector<Venda> r;
        while (getline(entrada, linha)) {
            if (linha.empty()) continue;
            size_t virgula = linha.find(',');
            r.push_back({linha.substr(0, virgula), stod(linha.substr(virgula + 1))});
        }
        return r;
    }
};

struct ItemApi {
    string sku;
    double amount;
};

class FonteApi : public FonteDeVendas {
    vector<ItemApi> sales; // equivale a resposta["data"]["sales"]

public:
    FonteApi(vector<ItemApi> sales) : sales(sales) {}

    string nome() const override { return "FonteApi"; }

    vector<Venda> vendas() const override {
        vector<Venda> r;
        for (auto& item : sales) r.push_back({item.sku, item.amount});
        return r;
    }
};

class Relatorio {
    const FonteDeVendas& fonte;

public:
    Relatorio(const FonteDeVendas& fonte) : fonte(fonte) {}

    double total() const {
        double soma = 0;
        for (auto& v : fonte.vendas()) soma += v.valor;
        return soma;
    }

    string maisVendido() const {
        map<string, double> somas;
        for (auto& v : fonte.vendas()) somas[v.produto] += v.valor;
        string melhor;
        double maior = -1;
        for (auto& [produto, soma] : somas) {
            if (soma > maior) {
                maior = soma;
                melhor = produto;
            }
        }
        return melhor;
    }
};

int main() {
    string csvTexto = "produto,valor\ncaderno,12\nlapis,3\ncaderno,12\n";
    FonteCsv csv(csvTexto);
    FonteApi api({{"mochila", 90.0}});

    for (const FonteDeVendas* fonte : vector<const FonteDeVendas*>{&csv, &api}) {
        Relatorio r(*fonte);
        cout << fonte->nome() << " " << r.total() << " " << r.maisVendido() << endl;
    }
}

using System.Globalization;
using System.Linq;

class Venda
{
    public readonly string Produto;
    public readonly double Valor;

    public Venda(string produto, double valor)
    {
        Produto = produto;
        Valor = valor;
    }
}

interface IFonteDeVendas
{
    // Entrega as vendas, escondendo formato e origem.
    IEnumerable<Venda> Vendas();
}

class FonteCsv : IFonteDeVendas
{
    private readonly string conteudo;

    public FonteCsv(string conteudo)
    {
        this.conteudo = conteudo;
    }

    public IEnumerable<Venda> Vendas()
    {
        foreach (var linha in conteudo.Trim().Split('\n').Skip(1))
        {
            var campos = linha.Split(',');
            yield return new Venda(campos[0], double.Parse(campos[1], CultureInfo.InvariantCulture));
        }
    }
}

{
    public readonly string Sku;
    public readonly double Amount;

    public ItemApi(string sku, double amount)
    {
        Sku = sku;
        Amount = amount;
    }
}

class FonteApi : IFonteDeVendas
{
    private readonly List<ItemApi> sales; // equivale a resposta["data"]["sales"]

    public FonteApi(List<ItemApi> sales)
    {
        this.sales = sales;
    }

    public IEnumerable<Venda> Vendas()
    {
        foreach (var item in sales) yield return new Venda(item.Sku, item.Amount);
    }
}

class Relatorio
{
    private readonly IFonteDeVendas fonte;

    public Relatorio(IFonteDeVendas fonte)
    {
        this.fonte = fonte;
    }

    public double Total()
    {
        return fonte.Vendas().Sum(v => v.Valor);
    }

    public string MaisVendido()
    {
        var somas = new Dictionary<string, double>();
        foreach (var v in fonte.Vendas())
        {
            double atual;
            somas.TryGetValue(v.Produto, out atual);
            somas[v.Produto] = atual + v.Valor;
        }
        return somas.OrderByDescending(par => par.Value).First().Key;
    }
}

`Relatorio` agora fala a língua do domínio (`Venda`, `total`, `mais_vendido`). Os detalhes de parsing ficaram dentro de cada fonte. Uma nova fonte, como uma planilha, é só mais uma classe.

## Níveis de abstração

Um bom método opera em **um único nível** de abstração. Compare:

```text
Misturado:
  processar_pedido():
      valida estoque
      abre conexão com o banco, monta SQL, executa
      formata HTML do e-mail
      chama SMTP

Consistente:
  processar_pedido():
      reservar_estoque()
      salvar_pedido()
      notificar_cliente()
```

A versão consistente se lê como uma história. Cada passo esconde seus detalhes num método ou objeto próprio.

## Armadilhas

- **Abstração vazada (leaky abstraction).** A interface promete esconder detalhes, mas o chamador precisa saber deles mesmo assim, por exemplo tratando um erro específico do driver de banco. Traduza erros internos para erros do domínio.
- **Abstração prematura.** Criar `FonteDeVendas` quando só existe e só existirá CSV adiciona camadas sem benefício.
- **Abstração genérica demais.** Um `Processador` com método `executar(dados)` não comunica nada. Nomes devem refletir o domínio.

<Callout type="note" title="Regra prática">
Uma abstração vale a pena quando permite que alguém use o objeto sem ler a implementação. Se você sempre precisa abrir o código para entender o que acontece, a abstração está no nível errado.
</Callout>
