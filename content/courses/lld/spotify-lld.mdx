Um player de música é um bom exercício de State, Strategy e Iterator: o estado da reprodução muda o que cada botão faz, e o modo de reprodução (sequencial, aleatório, repetir) muda qual faixa vem a seguir.

## Requisitos

- Biblioteca de músicas e playlists.
- Tocar, pausar, retomar, próxima e anterior.
- Modos: sequencial, aleatório e repetir uma.
- A fila pode receber músicas extras.

## Entidades

| Entidade | Responsabilidade |
| --- | --- |
| `Musica` | Título, artista e duração. |
| `Playlist` | Lista ordenada de músicas. |
| `ModoReproducao` | Strategy: decide o próximo índice. |
| `Player` | Estado atual, fila e comandos. |

## Implementação

```python
import random
from dataclasses import dataclass
from enum import Enum
from typing import List, Optional


@dataclass(frozen=True)
class Musica:
    titulo: str
    artista: str
    duracao: int


class Modo:
    def proximo(self, atual: int, total: int) -> Optional[int]:
        raise NotImplementedError

    def anterior(self, atual: int, total: int) -> Optional[int]:
        return max(0, atual - 1)


class Sequencial(Modo):
    def proximo(self, atual, total):
        return atual + 1 if atual + 1 < total else None


class RepetirUma(Modo):
    def proximo(self, atual, total):
        return atual


class Aleatorio(Modo):
    def __init__(self, semente=None):
        self.rng = random.Random(semente)

    def proximo(self, atual, total):
        return self.rng.randrange(total)


class Estado(Enum):
    PARADO = "parado"
    TOCANDO = "tocando"
    PAUSADO = "pausado"


class Player:
    def __init__(self, fila: List[Musica], modo: Modo):
        self.fila, self.modo = list(fila), modo
        self.indice = 0
        self.estado = Estado.PARADO

    @property
    def atual(self) -> Optional[Musica]:
        return self.fila[self.indice] if self.fila else None

    def tocar(self):
        if not self.fila:
            raise ValueError("fila vazia")
        self.estado = Estado.TOCANDO

    def pausar(self):
        if self.estado is Estado.TOCANDO:
            self.estado = Estado.PAUSADO

    def retomar(self):
        if self.estado is Estado.PAUSADO:
            self.estado = Estado.TOCANDO

    def proxima(self):
        novo = self.modo.proximo(self.indice, len(self.fila))
        if novo is None:
            self.estado = Estado.PARADO
            self.indice = 0
        else:
            self.indice = novo

    def anterior(self):
        self.indice = self.modo.anterior(self.indice, len(self.fila))

    def enfileirar(self, m: Musica):
        self.fila.append(m)


ms = [Musica("A", "X", 180), Musica("B", "X", 200), Musica("C", "Y", 150)]
p = Player(ms, Sequencial())
p.tocar()
p.proxima()
p.pausar()
print(p.atual.titulo, p.estado.value)   # B pausado
p.retomar()
p.proxima()
p.proxima()                             # fim da fila
print(p.estado.value)                   # parado
p.modo = Aleatorio(semente=1)
p.tocar()
p.proxima()
print(p.atual.titulo in {"A", "B", "C"})
```

Trocar `p.modo` em tempo de execução é a vantagem do Strategy: o player não conhece as regras de ordem.

## Extensões

Embaralhar sem repetição (gerar uma permutação e percorrer, em vez de sortear sempre), histórico de reprodução para voltar à faixa realmente anterior, volume e equalizador como Decorator sobre o fluxo de áudio, e Observer para a interface atualizar a faixa atual.

## Estado explícito

O enum `Estado` evita dois booleanos que podem entrar em combinação inválida (tocando e pausado ao mesmo tempo). Se cada estado tiver comportamento rico, evolua para o padrão State com uma classe por estado.

## Na entrevista

- **"Como tocar sem repetir no aleatório?"** Embaralhe os índices e percorra; reembaralhe ao fim.
- **"Onde fica o áudio em si?"** Atrás de uma interface `Saida`; o design não depende de hardware.
