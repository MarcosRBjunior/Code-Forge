## O problema

Um sistema de orçamentos para reformas monta propostas assim: uma proposta tem **etapas** (elétrica, hidráulica, pintura); cada etapa tem **itens** (10 tomadas, 30 metros de cabo) e também pode ter **subetapas** (pintura interna, pintura externa), que por sua vez têm itens. Você precisa calcular o custo total, o prazo total e imprimir a proposta indentada.

A tentação é escrever código que pergunta o tipo a cada passo: "se for item, soma o preço; se for etapa, percorre os filhos e, se o filho for etapa, percorre de novo...". Isso espalha `isinstance` pelo código e quebra toda vez que surge um novo tipo de nó.

O **Composite** propõe tratar **folhas** (itens) e **contêineres** (etapas) pela **mesma interface**. Quem chama `custo()` não precisa saber se está falando com um item ou com uma árvore inteira.

## Como funciona

Existe um **componente** abstrato com as operações comuns. A **folha** implementa as operações diretamente. O **composto** guarda uma lista de componentes e implementa cada operação combinando o resultado dos filhos, geralmente por recursão.

```text
                 +---------------------------+
                 | <<abstrata>> NoOrcamento  |
                 | + custo()                 |
                 | + dias()                  |
                 | + imprimir(nivel)         |
                 +---------------------------+
                      ^                ^
                      |                |
          +----------------+   +-----------------------------+
          | Item  (folha)  |   | Etapa  (composto)           |
          | - preco_unit   |   | - filhos: list[NoOrcamento] |<>--+
          | - quantidade   |   | + adicionar(no)             |    |
          | - dias         |   +-----------------------------+    |
          +----------------+                ^                     |
                                            +---------------------+
                                        (filhos podem ser Item ou Etapa)
```

Uma decisão de design importante: onde declarar `adicionar`? Se ficar no componente abstrato, folha e composto têm interface idêntica (mais "transparente"), mas a folha precisa lançar erro ao receber filhos. Se ficar só no composto (como aqui), o código é mais seguro, mas quem monta a árvore precisa saber o tipo concreto. Para montagem isso costuma ser aceitável, porque montar e consumir são momentos diferentes.

```python
from abc import ABC, abstractmethod


class NoOrcamento(ABC):
    def __init__(self, nome: str):
        self.nome = nome

    @abstractmethod
    def custo(self) -> float: ...

    @abstractmethod
    def dias(self) -> int: ...

    @abstractmethod
    def imprimir(self, nivel: int = 0) -> None: ...


class Item(NoOrcamento):
    def __init__(self, nome, preco_unit, quantidade, dias=0):
        super().__init__(nome)
        self.preco_unit = preco_unit
        self.quantidade = quantidade
        self._dias = dias

    def custo(self):
        return self.preco_unit * self.quantidade

    def dias(self):
        return self._dias

    def imprimir(self, nivel=0):
        print(f"{'  ' * nivel}- {self.nome}: {self.quantidade} x R$ {self.preco_unit:.2f} = R$ {self.custo():.2f}")


class Etapa(NoOrcamento):
    def __init__(self, nome, paralela=False):
        super().__init__(nome)
        self.filhos: list[NoOrcamento] = []
        self.paralela = paralela  # subetapas paralelas: prazo é o maior, não a soma

    def adicionar(self, *nos):
        self.filhos.extend(nos)
        return self

    def custo(self):
        return sum(f.custo() for f in self.filhos)

    def dias(self):
        prazos = [f.dias() for f in self.filhos] or [0]
        return max(prazos) if self.paralela else sum(prazos)

    def imprimir(self, nivel=0):
        print(f"{'  ' * nivel}+ {self.nome} (R$ {self.custo():.2f}, {self.dias()} dias)")
        for f in self.filhos:
            f.imprimir(nivel + 1)


if __name__ == "__main__":
    eletrica = Etapa("Elétrica").adicionar(
        Item("Tomada 20A", 18.5, 10, dias=1),
        Item("Cabo 2,5mm (m)", 3.2, 30, dias=1),
    )
    pintura = Etapa("Pintura", paralela=True).adicionar(
        Etapa("Interna").adicionar(Item("Tinta acrílica (lata)", 320.0, 4, dias=3)),
        Etapa("Externa").adicionar(Item("Tinta emborrachada (lata)", 410.0, 2, dias=2)),
    )
    proposta = Etapa("Reforma apto 302").adicionar(eletrica, pintura)

    proposta.imprimir()
    print(f"Total: R$ {proposta.custo():.2f} em {proposta.dias()} dias")
    print("Só a tomada:", Item("Tomada 20A", 18.5, 1).custo())
```

```javascript
class NoOrcamento {
  constructor(nome) {
    this.nome = nome;
  }

  custo() { throw new Error("método abstrato"); }
  dias() { throw new Error("método abstrato"); }
  imprimir(nivel = 0) { throw new Error("método abstrato"); }
}

class Item extends NoOrcamento {
  constructor(nome, precoUnit, quantidade, dias = 0) {
    super(nome);
    this.precoUnit = precoUnit;
    this.quantidade = quantidade;
    this._dias = dias;
  }

  custo() { return this.precoUnit * this.quantidade; }

  dias() { return this._dias; }

  imprimir(nivel = 0) {
    console.log(`${"  ".repeat(nivel)}- ${this.nome}: ${this.quantidade} x R$ ${this.precoUnit.toFixed(2)} = R$ ${this.custo().toFixed(2)}`);
  }
}

class Etapa extends NoOrcamento {
  constructor(nome, paralela = false) {
    super(nome);
    this.filhos = [];
    this.paralela = paralela;   // subetapas paralelas: prazo é o maior, não a soma
  }

  adicionar(...nos) {
    this.filhos.push(...nos);
    return this;
  }

  custo() { return this.filhos.reduce((soma, f) => soma + f.custo(), 0); }

  dias() {
    const prazos = this.filhos.length ? this.filhos.map((f) => f.dias()) : [0];
    return this.paralela ? Math.max(...prazos) : prazos.reduce((a, b) => a + b, 0);
  }

  imprimir(nivel = 0) {
    console.log(`${"  ".repeat(nivel)}+ ${this.nome} (R$ ${this.custo().toFixed(2)}, ${this.dias()} dias)`);
    for (const f of this.filhos) {
      f.imprimir(nivel + 1);
    }
  }
}
```

```java
import java.util.*;

abstract class NoOrcamento {
    final String nome;

    NoOrcamento(String nome) {
        this.nome = nome;
    }

    abstract double custo();
    abstract int dias();
    abstract void imprimir(int nivel);

    void imprimir() { imprimir(0); }
}

class Item extends NoOrcamento {
    private final double precoUnit;
    private final int quantidade, diasItem;

    Item(String nome, double precoUnit, int quantidade, int dias) {
        super(nome);
        this.precoUnit = precoUnit;
        this.quantidade = quantidade;
        this.diasItem = dias;
    }

    double custo() { return precoUnit * quantidade; }

    int dias() { return diasItem; }

    void imprimir(int nivel) {
        System.out.println(String.format(Locale.US, "%s- %s: %d x R$ %.2f = R$ %.2f",
            "  ".repeat(nivel), nome, quantidade, precoUnit, custo()));
    }
}

class Etapa extends NoOrcamento {
    final List<NoOrcamento> filhos = new ArrayList<>();
    private final boolean paralela;   // subetapas paralelas: prazo é o maior, não a soma

    Etapa(String nome, boolean paralela) {
        super(nome);
        this.paralela = paralela;
    }

    Etapa adicionar(NoOrcamento... nos) {
        filhos.addAll(Arrays.asList(nos));
        return this;
    }

    double custo() {
        double soma = 0;
        for (NoOrcamento f : filhos) soma += f.custo();
        return soma;
    }

    int dias() {
        int maior = 0, soma = 0;
        for (NoOrcamento f : filhos) {
            maior = Math.max(maior, f.dias());
            soma += f.dias();
        }
        return paralela ? maior : soma;
    }

    void imprimir(int nivel) {
        System.out.println(String.format(Locale.US, "%s+ %s (R$ %.2f, %d dias)", "  ".repeat(nivel), nome, custo(), dias()));
        for (NoOrcamento f : filhos) {
            f.imprimir(nivel + 1);
        }
    }
}

public static void main(String[] args) {
    Etapa eletrica = new Etapa("Elétrica", false).adicionar(
        new Item("Tomada 20A", 18.5, 10, 1),
        new Item("Cabo 2,5mm (m)", 3.2, 30, 1));
    Etapa pintura = new Etapa("Pintura", true).adicionar(
        new Etapa("Interna", false).adicionar(new Item("Tinta acrílica (lata)", 320.0, 4, 3)),
        new Etapa("Externa", false).adicionar(new Item("Tinta emborrachada (lata)", 410.0, 2, 2)));
    Etapa proposta = new Etapa("Reforma apto 302", false).adicionar(eletrica, pintura);

    proposta.imprimir();
    System.out.println(String.format(Locale.US, "Total: R$ %.2f em %d dias", proposta.custo(), proposta.dias()));
    System.out.println("Só a tomada: " + new Item("Tomada 20A", 18.5, 1, 0).custo());
}
```

```cpp
class NoOrcamento {
public:
    string nome;
    NoOrcamento(string nome) : nome(nome) {}
    virtual ~NoOrcamento() = default;
    virtual double custo() const = 0;
    virtual int dias() const = 0;
    virtual void imprimir(int nivel = 0) const = 0;
};

class Item : public NoOrcamento {
    double precoUnit;
    int quantidade, diasItem;

public:
    Item(string nome, double precoUnit, int quantidade, int dias = 0)
        : NoOrcamento(nome), precoUnit(precoUnit), quantidade(quantidade), diasItem(dias) {}

    double custo() const override { return precoUnit * quantidade; }

    int dias() const override { return diasItem; }

    void imprimir(int nivel = 0) const override {
        cout << string(nivel * 2, ' ') << "- " << nome << ": " << quantidade << " x R$ " << fixed << setprecision(2)
             << precoUnit << " = R$ " << custo() << defaultfloat << setprecision(6) << endl;
    }
};

class Etapa : public NoOrcamento {
    vector<shared_ptr<NoOrcamento>> filhos;
    bool paralela;   // subetapas paralelas: prazo é o maior, não a soma

public:
    Etapa(string nome, bool paralela = false) : NoOrcamento(nome), paralela(paralela) {}

    Etapa& adicionar(initializer_list<shared_ptr<NoOrcamento>> nos) {
        filhos.insert(filhos.end(), nos.begin(), nos.end());
        return *this;
    }

    double custo() const override {
        double soma = 0;
        for (const auto& f : filhos) soma += f->custo();
        return soma;
    }

    int dias() const override {
        int maior = 0, soma = 0;
        for (const auto& f : filhos) {
            maior = max(maior, f->dias());
            soma += f->dias();
        }
        return paralela ? maior : soma;
    }

    void imprimir(int nivel = 0) const override {
        cout << string(nivel * 2, ' ') << "+ " << nome << " (R$ " << fixed << setprecision(2) << custo()
             << defaultfloat << setprecision(6) << ", " << dias() << " dias)" << endl;
        for (const auto& f : filhos) {
            f->imprimir(nivel + 1);
        }
    }
};
```

```csharp
using System;
using System.Collections.Generic;
using System.Globalization;
using System.Linq;

abstract class NoOrcamento
{
    public readonly string Nome;

    protected NoOrcamento(string nome)
    {
        Nome = nome;
    }

    public abstract double Custo();
    public abstract int Dias();
    public abstract void Imprimir(int nivel = 0);
}

class Item : NoOrcamento
{
    private readonly double precoUnit;
    private readonly int quantidade, diasItem;

    public Item(string nome, double precoUnit, int quantidade, int dias = 0) : base(nome)
    {
        this.precoUnit = precoUnit;
        this.quantidade = quantidade;
        diasItem = dias;
    }

    public override double Custo() { return precoUnit * quantidade; }

    public override int Dias() { return diasItem; }

    public override void Imprimir(int nivel = 0)
    {
        var c = CultureInfo.InvariantCulture;
        Console.WriteLine(new string(' ', nivel * 2) + "- " + Nome + ": " + quantidade + " x R$ " + precoUnit.ToString("F2", c) + " = R$ " + Custo().ToString("F2", c));
    }
}

class Etapa : NoOrcamento
{
    private readonly List<NoOrcamento> filhos = new List<NoOrcamento>();
    private readonly bool paralela;   // subetapas paralelas: prazo é o maior, não a soma

    public Etapa(string nome, bool paralela = false) : base(nome)
    {
        this.paralela = paralela;
    }

    public Etapa Adicionar(params NoOrcamento[] nos)
    {
        filhos.AddRange(nos);
        return this;
    }

    public override double Custo() { return filhos.Sum(f => f.Custo()); }

    public override int Dias()
    {
        var prazos = filhos.Select(f => f.Dias()).DefaultIfEmpty(0).ToList();
        return paralela ? prazos.Max() : prazos.Sum();
    }

    public override void Imprimir(int nivel = 0)
    {
        Console.WriteLine(new string(' ', nivel * 2) + "+ " + Nome + " (R$ " + Custo().ToString("F2", CultureInfo.InvariantCulture) + ", " + Dias() + " dias)");
        foreach (var f in filhos)
        {
            f.Imprimir(nivel + 1);
        }
    }
}
```

```go
import (
	"fmt"
	"strings"
)

type NoOrcamento interface {
	custo() float64
	dias() int
	imprimir(nivel int)
}

type Item struct {
	nome      string
	precoUnit float64
	quantidade int
	diasItem  int
}

func (i Item) custo() float64 { return i.precoUnit * float64(i.quantidade) }

func (i Item) dias() int { return i.diasItem }

func (i Item) imprimir(nivel int) {
	fmt.Printf("%s- %s: %d x R$ %.2f = R$ %.2f\n", strings.Repeat("  ", nivel), i.nome, i.quantidade, i.precoUnit, i.custo())
}

type Etapa struct {
	nome     string
	filhos   []NoOrcamento
	paralela bool // subetapas paralelas: prazo é o maior, não a soma
}

func (e *Etapa) adicionar(nos ...NoOrcamento) *Etapa {
	e.filhos = append(e.filhos, nos...)
	return e
}

func (e *Etapa) custo() float64 {
	soma := 0.0
	for _, f := range e.filhos {
		soma += f.custo()
	}
	return soma
}

func (e *Etapa) dias() int {
	maior, soma := 0, 0
	for _, f := range e.filhos {
		if f.dias() > maior {
			maior = f.dias()
		}
		soma += f.dias()
	}
	if e.paralela {
		return maior
	}
	return soma
}

func (e *Etapa) imprimir(nivel int) {
	fmt.Printf("%s+ %s (R$ %.2f, %d dias)\n", strings.Repeat("  ", nivel), e.nome, e.custo(), e.dias())
	for _, f := range e.filhos {
		f.imprimir(nivel + 1)
	}
}

func main() {
	eletrica := (&Etapa{nome: "Elétrica"}).adicionar(
		Item{"Tomada 20A", 18.5, 10, 1},
		Item{"Cabo 2,5mm (m)", 3.2, 30, 1},
	)
	pintura := (&Etapa{nome: "Pintura", paralela: true}).adicionar(
		(&Etapa{nome: "Interna"}).adicionar(Item{"Tinta acrílica (lata)", 320.0, 4, 3}),
		(&Etapa{nome: "Externa"}).adicionar(Item{"Tinta emborrachada (lata)", 410.0, 2, 2}),
	)
	proposta := (&Etapa{nome: "Reforma apto 302"}).adicionar(eletrica, pintura)

	proposta.imprimir(0)
	fmt.Printf("Total: R$ %.2f em %d dias\n", proposta.custo(), proposta.dias())
```

Note que `proposta.custo()` e `Item(...).custo()` são chamados do mesmo jeito. A regra "pintura interna e externa acontecem em paralelo" ficou encapsulada no composto, sem que o cliente saiba.

## Quando usar

- O domínio é naturalmente uma **árvore parte-todo**: menus e submenus, pastas e arquivos, organogramas, componentes de interface, cardápios com combos, kits de produtos.
- Você quer que o cliente trate um elemento e um grupo de elementos de forma uniforme.
- Operações agregadas (somar, contar, buscar, renderizar) percorrem a hierarquia.

## Quando evitar

- A estrutura não é hierárquica, ou tem só um nível. Uma lista simples resolve.
- Folhas e compostos têm operações muito diferentes. Forçar uma interface comum gera métodos vazios ou que lançam erro.
- Grafos com ciclos ou nós compartilhados: o Composite assume uma árvore. Com ciclos, a recursão não termina e você precisa de outra modelagem.

<Callout type="warning" title="Cuidado com profundidade e desempenho">
Cada `custo()` no topo recalcula a árvore inteira. Para árvores grandes consultadas com frequência, guarde o resultado em cache no composto e invalide quando um filho mudar.
</Callout>

## Padrões parecidos

- **Decorator**: também tem objeto que referencia outro da mesma interface, mas apenas **um**, e para acrescentar comportamento. O Composite tem **muitos** filhos e serve para representar estrutura.
- **Iterator**: frequentemente usado junto, para percorrer a árvore sem expor a lista interna de filhos.
- **Visitor**: quando você precisa adicionar muitas operações novas sobre a árvore (exportar PDF, calcular imposto, validar) sem mexer nas classes de nó.
- **Flyweight**: folhas idênticas e numerosas podem ser compartilhadas para economizar memória.

## Na entrevista
