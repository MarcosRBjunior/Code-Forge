O semáforo é o problema mais simples de máquina de estados, e justamente por isso é um bom aquecimento: o ciclo é pequeno e cada estado tem duração própria. O entrevistador quer ver se você modela estados com seus tempos de forma limpa, sem `sleep` espalhado, e se sabe estender para um cruzamento com vários semáforos coordenados.

## Requisitos

- **Estados**: verde, amarelo e vermelho, em ciclo.
- **Durações**: cada cor tem um tempo configurável.
- **Cruzamento**: dois eixos (norte-sul e leste-oeste) que nunca podem estar verdes ao mesmo tempo.
- **Tempo**: o sistema avança por um relógio injetável, não por `sleep`, para ser testável.
- Fora de escopo: sensores, pedestres e modo piscante (extensões).

## Modelagem do ciclo

```text
VERDE (30s) --> AMARELO (5s) --> VERMELHO (35s) --> VERDE ...
```

Cada estado sabe quanto dura e qual é o próximo. O semáforo guarda o estado atual e quanto tempo falta.

## Código: um semáforo

```python
from enum import Enum


class Cor(Enum):
    VERDE = "verde"
    AMARELO = "amarelo"
    VERMELHO = "vermelho"


PROXIMA = {Cor.VERDE: Cor.AMARELO, Cor.AMARELO: Cor.VERMELHO, Cor.VERMELHO: Cor.VERDE}


class Semaforo:
    def __init__(self, duracoes: dict[Cor, int], cor_inicial: Cor = Cor.VERMELHO) -> None:
        self.duracoes = duracoes
        self.cor = cor_inicial
        self.restante = duracoes[cor_inicial]

    def avancar(self, segundos: int) -> None:
        while segundos > 0:
            gasto = min(segundos, self.restante)
            self.restante -= gasto
            segundos -= gasto
            if self.restante == 0:
                self.cor = PROXIMA[self.cor]
                self.restante = self.duracoes[self.cor]


s = Semaforo({Cor.VERDE: 30, Cor.AMARELO: 5, Cor.VERMELHO: 35}, Cor.VERDE)
s.avancar(29)
assert s.cor is Cor.VERDE
s.avancar(1)
assert s.cor is Cor.AMARELO
s.avancar(5 + 35)
assert s.cor is Cor.VERDE
print("semáforo ok")
```

O método `avancar` consome o tempo em fatias, então pular 40 segundos de uma vez passa corretamente por vários estados.

## Código: um cruzamento seguro

O requisito de segurança é um **invariante**: os dois eixos não podem estar verdes juntos. A forma mais simples de garanti-lo é fazer um único objeto controlar os dois eixos e derivar um do outro:

```python
class Cruzamento:
    """Fases: eixo A verde, A amarelo, tudo vermelho, eixo B verde, B amarelo, tudo vermelho."""

    FASES = [
        (Cor.VERDE, Cor.VERMELHO, 30),
        (Cor.AMARELO, Cor.VERMELHO, 5),
        (Cor.VERMELHO, Cor.VERMELHO, 2),
        (Cor.VERMELHO, Cor.VERDE, 30),
        (Cor.VERMELHO, Cor.AMARELO, 5),
        (Cor.VERMELHO, Cor.VERMELHO, 2),
    ]

    def __init__(self) -> None:
        self.indice = 0
        self.restante = self.FASES[0][2]

    @property
    def cores(self) -> tuple[Cor, Cor]:
        a, b, _ = self.FASES[self.indice]
        return a, b

    def avancar(self, segundos: int) -> None:
        while segundos > 0:
            gasto = min(segundos, self.restante)
            self.restante -= gasto
            segundos -= gasto
            if self.restante == 0:
                self.indice = (self.indice + 1) % len(self.FASES)
                self.restante = self.FASES[self.indice][2]


c = Cruzamento()
for _ in range(200):
    a, b = c.cores
    assert not (a is Cor.VERDE and b is Cor.VERDE)  # invariante de segurança
    c.avancar(1)
assert Cruzamento().cores == (Cor.VERDE, Cor.VERMELHO)
print("cruzamento seguro")
```

As fases "tudo vermelho" de 2 segundos dão tempo para o cruzamento esvaziar antes de liberar o outro eixo, exatamente como em semáforos reais.

## Decisões que merecem fala

- **Relógio injetado**: `avancar(segundos)` permite testar horas de operação em milissegundos.
- **Dados em vez de código**: as durações e fases são configuração, não ifs.
- **Invariante na estrutura**: ao centralizar as fases, o estado inseguro nem pode ser representado.
- **State**: se cada cor tiver comportamento próprio (piscar o amarelo, aceitar botão de pedestre), evolua para classes de estado.

<Callout type="note" title="Quando usar State de verdade">
Para um ciclo simples, enum e tabela bastam. Introduza o padrão State quando as cores passarem a ter comportamento diferente, não apenas duração diferente.
</Callout>

## Extensões

Botão de pedestre que encurta o ciclo, sensores que prolongam o verde, horário noturno com amarelo piscante, e coordenação de vários cruzamentos em "onda verde". Em produção, o controle real roda num laço de tempo com threads ou um agendador, mas o modelo de estados permanece o mesmo.
