O sistema de elevadores combina **máquina de estados** com **escalonamento**: cada elevador tem estados e direção, e um controlador decide qual elevador atende cada chamada. É um problema excelente para o entrevistador ver se você separa o que muda (a política de despacho) do que é estável (o movimento de um elevador).

## Requisitos

- **Quantos elevadores e andares?** Configuráveis.
- **Chamadas externas**: botão no andar, com direção (subir ou descer).
- **Chamadas internas**: botão do andar de destino dentro do elevador.
- **Política de despacho**: escolher o melhor elevador para uma chamada externa.
- **Movimento**: o elevador continua na direção atual atendendo paradas pelo caminho (varredura), em vez de ir e voltar.
- Fora de escopo: capacidade de peso, portas, manutenção e prioridade (extensões).

## Entidades

| Entidade | Responsabilidade |
| --- | --- |
| `Direcao` | Enum: SUBINDO, DESCENDO, PARADO |
| `Elevador` | Andar atual, direção, conjunto de paradas pendentes; método `passo()` que avança um andar |
| `Controlador` | Recebe chamadas, escolhe elevador via estratégia, coordena os passos |
| `EstrategiaDespacho` | Interface para escolher o elevador (Strategy) |

## Código

```python
from abc import ABC, abstractmethod
from enum import Enum


class Direcao(Enum):
    SUBINDO = 1
    DESCENDO = -1
    PARADO = 0


class Elevador:
    def __init__(self, id_: int, andar: int = 0) -> None:
        self.id = id_
        self.andar = andar
        self.direcao = Direcao.PARADO
        self.paradas: set[int] = set()

    def adicionar_parada(self, andar: int) -> None:
        if andar != self.andar:
            self.paradas.add(andar)

    def _escolher_direcao(self) -> Direcao:
        if not self.paradas:
            return Direcao.PARADO
        acima = any(p > self.andar for p in self.paradas)
        abaixo = any(p < self.andar for p in self.paradas)
        if self.direcao is Direcao.SUBINDO and acima:
            return Direcao.SUBINDO
        if self.direcao is Direcao.DESCENDO and abaixo:
            return Direcao.DESCENDO
        return Direcao.SUBINDO if acima else Direcao.DESCENDO

    def passo(self) -> None:
        self.direcao = self._escolher_direcao()
        if self.direcao is Direcao.PARADO:
            return
        self.andar += self.direcao.value
        self.paradas.discard(self.andar)  # chegou: atende a parada
        if not self.paradas:
            self.direcao = Direcao.PARADO

    def custo(self, andar: int) -> int:
        """Estimativa simples: distância mais uma penalidade por parada pendente."""
        return abs(self.andar - andar) + 2 * len(self.paradas)


class EstrategiaDespacho(ABC):
    @abstractmethod
    def escolher(self, elevadores: list[Elevador], andar: int) -> Elevador: ...


class MaisProximo(EstrategiaDespacho):
    def escolher(self, elevadores, andar):
        return min(elevadores, key=lambda e: (e.custo(andar), e.id))


class Controlador:
    def __init__(self, elevadores: list[Elevador], estrategia: EstrategiaDespacho) -> None:
        self.elevadores = elevadores
        self.estrategia = estrategia

    def chamar(self, andar: int) -> int:
        elevador = self.estrategia.escolher(self.elevadores, andar)
        elevador.adicionar_parada(andar)
        return elevador.id

    def selecionar_destino(self, id_elevador: int, andar: int) -> None:
        self.elevadores[id_elevador].adicionar_parada(andar)

    def passo(self) -> None:
        for e in self.elevadores:
            e.passo()


ctrl = Controlador([Elevador(0, andar=0), Elevador(1, andar=10)], MaisProximo())
assert ctrl.chamar(8) == 1          # o elevador do 10 está mais perto
assert ctrl.chamar(1) == 0
ctrl.selecionar_destino(1, 3)
for _ in range(10):
    ctrl.passo()
assert ctrl.elevadores[0].andar == 1
assert ctrl.elevadores[1].paradas == set()
print("elevadores ok")
```

## Decisões que merecem fala

- **Varredura**: manter a direção enquanto houver paradas à frente reduz viagens; é a ideia do algoritmo SCAN de discos.
- **Strategy no despacho**: trocar por uma política que minimiza o tempo médio de espera não altera `Elevador`.
- **Conjunto de paradas**: evita duplicatas quando várias pessoas apertam o mesmo andar.
- **Controlador separado**: o elevador conhece só seu próprio movimento; quem enxerga o conjunto é o controlador.

<Callout type="tip" title="Estado e direção">
Se pedirem portas e manutenção, estenda os estados (PARADO_PORTA_ABERTA, MANUTENCAO) e use o padrão State em vez de crescer os ifs de `passo`.
</Callout>

## Extensões

Capacidade e peso, andares restritos por cartão, modo bombeiro (cancela chamadas e vai ao térreo) e prioridade. Para escala, vários prédios compartilham o mesmo controlador abstrato. Para concorrência, o controlador precisa de uma trava ou fila de eventos, já que botões chegam de várias threads.
