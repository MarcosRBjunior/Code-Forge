## O problema

Imagine montar uma requisição de envio de e-mail transacional: remetente, destinatários, cópias, assunto, corpo em texto, corpo em HTML, anexos, cabeçalhos, prioridade, data de agendamento. Quase tudo é opcional, mas existem regras: precisa de pelo menos um destinatário, assunto não pode ser vazio, anexos têm limite de tamanho.

Um construtor com doze parâmetros vira o famoso **construtor telescópico**: ninguém lembra a ordem, chamadas ficam ilegíveis e a validação se espalha. Criar o objeto vazio e ir preenchendo com setters deixa o objeto **inválido** durante um tempo e mutável para sempre.

O **Builder** separa a montagem passo a passo de um objeto complexo da sua representação final. Você configura um construtor auxiliar com chamadas nomeadas e, no fim, pede `build()`, que valida tudo e devolve um objeto pronto (de preferência imutável).

## Estrutura

```text
 Cliente
    |
    | EmailBuilder().de(...).para(...).assunto(...).build()
    v
+----------------------------+          +-------------------------+
|        EmailBuilder        |  build() |      Email (frozen)     |
+----------------------------+--------->+-------------------------+
| - _remetente               |          | remetente               |
| - _destinatarios: list     |          | destinatarios: tuple    |
| - _anexos: list            |          | assunto, texto, html    |
+----------------------------+          | anexos: tuple           |
| + de(endereco): self       |          +-------------------------+
| + para(endereco): self     |
| + anexar(nome, bytes): self|
| + build(): Email           |  (valida regras e congela)
+----------------------------+

 Opcional: Diretor (ex.: ModelosDeEmail) que conhece receitas prontas
 e chama a sequência de passos do builder.
```

from dataclasses import dataclass
from datetime import datetime


@dataclass(frozen=True)
class Anexo:
    nome: str
    conteudo: bytes


@dataclass(frozen=True)
class Email:
    remetente: str
    destinatarios: tuple
    copias: tuple
    assunto: str
    texto: str
    html: str | None
    anexos: tuple
    agendado_para: datetime | None


class EmailInvalido(ValueError):
    pass


class EmailBuilder:
    LIMITE_ANEXOS_BYTES = 10 * 1024 * 1024

    def __init__(self) -> None:
        self._remetente = "nao-responda@loja.exemplo"
        self._destinatarios: list[str] = []
        self._copias: list[str] = []
        self._assunto = ""
        self._texto = ""
        self._html: str | None = None
        self._anexos: list[Anexo] = []
        self._agendado_para: datetime | None = None

    def de(self, endereco: str) -> "EmailBuilder":
        self._remetente = endereco
        return self

    def para(self, *enderecos: str) -> "EmailBuilder":
        self._destinatarios.extend(enderecos)
        return self

    def com_copia(self, *enderecos: str) -> "EmailBuilder":
        self._copias.extend(enderecos)
        return self

    def assunto(self, texto: str) -> "EmailBuilder":
        self._assunto = texto.strip()
        return self

    def corpo(self, texto: str, html: str | None = None) -> "EmailBuilder":
        self._texto, self._html = texto, html
        return self

    def anexar(self, nome: str, conteudo: bytes) -> "EmailBuilder":
        self._anexos.append(Anexo(nome, conteudo))
        return self

    def agendar(self, quando: datetime) -> "EmailBuilder":
        self._agendado_para = quando
        return self

    def build(self) -> Email:
        if not self._destinatarios:
            raise EmailInvalido("informe ao menos um destinatário")
        if not self._assunto:
            raise EmailInvalido("assunto obrigatório")
        total = sum(len(a.conteudo) for a in self._anexos)
        if total > self.LIMITE_ANEXOS_BYTES:
            raise EmailInvalido(f"anexos somam {total} bytes, acima do limite")
        return Email(
            remetente=self._remetente,
            destinatarios=tuple(self._destinatarios),
            copias=tuple(self._copias),
            assunto=self._assunto,
            texto=self._texto,
            html=self._html,
            anexos=tuple(self._anexos),
            agendado_para=self._agendado_para,
        )


class ModelosDeEmail:
    """Diretor: conhece receitas prontas de montagem."""

    @staticmethod
    def nota_fiscal(cliente: str, numero: int, pdf: bytes) -> Email:
        return (
            EmailBuilder()
            .para(cliente)
            .assunto(f"Sua nota fiscal nº {numero}")
            .corpo("Segue em anexo a nota fiscal da sua compra.")
            .anexar(f"nf-{numero}.pdf", pdf)
            .build()
        )

    EmailBuilder()
    .de("vendas@loja.exemplo")
    .para("ana@cliente.exemplo", "bruno@cliente.exemplo")
    .com_copia("financeiro@loja.exemplo")
    .assunto("  Pedido 8841 confirmado ")
    .corpo("Seu pedido foi confirmado.", "<p>Seu pedido foi <b>confirmado</b>.</p>")
    .agendar(datetime(2026, 11, 2, 9, 0))
    .build()
)
print(email.assunto, "->", email.destinatarios, "| agendado:", email.agendado_para)

nf = ModelosDeEmail.nota_fiscal("carla@cliente.exemplo", 1203, b"%PDF-1.7 ...")
print(nf.assunto, [a.nome for a in nf.anexos])

try:
    EmailBuilder().assunto("sem destinatário").build()
except EmailInvalido as erro:
    print("erro:", erro)

class Anexo {
  constructor(nome, conteudo) {
    this.nome = nome;
    this.conteudo = conteudo;
    Object.freeze(this);
  }
}

class Email {
  constructor(campos) {
    Object.assign(this, campos);
    Object.freeze(this);
  }
}

class EmailInvalido extends Error {}

class EmailBuilder {
  static LIMITE_ANEXOS_BYTES = 10 * 1024 * 1024;

  #remetente = "nao-responda@loja.exemplo";
  #destinatarios = [];
  #copias = [];
  #assunto = "";
  #texto = "";
  #html = null;
  #anexos = [];
  #agendadoPara = null;

  de(endereco) { this.#remetente = endereco; return this; }

  para(...enderecos) { this.#destinatarios.push(...enderecos); return this; }

  comCopia(...enderecos) { this.#copias.push(...enderecos); return this; }

  assunto(texto) { this.#assunto = texto.trim(); return this; }

  corpo(texto, html = null) { this.#texto = texto; this.#html = html; return this; }

  anexar(nome, conteudo) { this.#anexos.push(new Anexo(nome, conteudo)); return this; }

  agendar(quando) { this.#agendadoPara = quando; return this; }

  build() {
    if (this.#destinatarios.length === 0) {
      throw new EmailInvalido("informe ao menos um destinatário");
    }
    if (!this.#assunto) {
      throw new EmailInvalido("assunto obrigatório");
    }
    const total = this.#anexos.reduce((soma, a) => soma + a.conteudo.length, 0);
    if (total > EmailBuilder.LIMITE_ANEXOS_BYTES) {
      throw new EmailInvalido(`anexos somam ${total} bytes, acima do limite`);
    }
    return new Email({
      remetente: this.#remetente,
      destinatarios: Object.freeze([...this.#destinatarios]),
      copias: Object.freeze([...this.#copias]),
      assunto: this.#assunto,
      texto: this.#texto,
      html: this.#html,
      anexos: Object.freeze([...this.#anexos]),
      agendadoPara: this.#agendadoPara,
    });
  }
}

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.util.*;

class Anexo {
    final String nome;
    final byte[] conteudo;

    Anexo(String nome, byte[] conteudo) {
        this.nome = nome;
        this.conteudo = conteudo;
    }
}

class Email {
    final String remetente, assunto, texto, html;
    final List<String> destinatarios, copias;
    final List<Anexo> anexos;
    final LocalDateTime agendadoPara;

    Email(String remetente, List<String> destinatarios, List<String> copias, String assunto, String texto,
          String html, List<Anexo> anexos, LocalDateTime agendadoPara) {
        this.remetente = remetente;
        this.destinatarios = destinatarios;
        this.copias = copias;
        this.assunto = assunto;
        this.texto = texto;
        this.html = html;
        this.anexos = anexos;
        this.agendadoPara = agendadoPara;
    }
}

class EmailInvalido extends RuntimeException {
    EmailInvalido(String msg) {
        super(msg);
    }
}

class EmailBuilder {
    static final int LIMITE_ANEXOS_BYTES = 10 * 1024 * 1024;

    private String remetente = "nao-responda@loja.exemplo";
    private final List<String> destinatarios = new ArrayList<>();
    private final List<String> copias = new ArrayList<>();
    private String assunto = "";
    private String texto = "";
    private String html = null;
    private final List<Anexo> anexos = new ArrayList<>();
    private LocalDateTime agendadoPara = null;

    EmailBuilder de(String endereco) { remetente = endereco; return this; }

    EmailBuilder para(String... enderecos) { destinatarios.addAll(Arrays.asList(enderecos)); return this; }

    EmailBuilder comCopia(String... enderecos) { copias.addAll(Arrays.asList(enderecos)); return this; }

    EmailBuilder assunto(String t) { assunto = t.strip(); return this; }

    EmailBuilder corpo(String t, String h) { texto = t; html = h; return this; }

    EmailBuilder corpo(String t) { return corpo(t, null); }

    EmailBuilder anexar(String nome, byte[] conteudo) { anexos.add(new Anexo(nome, conteudo)); return this; }

    EmailBuilder agendar(LocalDateTime quando) { agendadoPara = quando; return this; }

    Email build() {
        if (destinatarios.isEmpty()) {
            throw new EmailInvalido("informe ao menos um destinatário");
        }
        if (assunto.isEmpty()) {
            throw new EmailInvalido("assunto obrigatório");
        }
        long total = 0;
        for (Anexo a : anexos) total += a.conteudo.length;
        if (total > LIMITE_ANEXOS_BYTES) {
            throw new EmailInvalido("anexos somam " + total + " bytes, acima do limite");
        }
        return new Email(remetente, List.copyOf(destinatarios), List.copyOf(copias), assunto, texto, html,
                         List.copyOf(anexos), agendadoPara);
    }
}

}

#include <iostream>
#include <stdexcept>
#include <string>
#include <vector>
using namespace std;

struct Anexo {
    string nome;
    string conteudo;
};

struct Email {
    string remetente;
    vector<string> destinatarios, copias;
    string assunto, texto;
    string html;           // vazio = sem HTML
    vector<Anexo> anexos;
    string agendadoPara;   // "AAAA-MM-DD HH:MM:SS"; vazio = não agendado
};

struct EmailInvalido : invalid_argument {
    using invalid_argument::invalid_argument;
};

string aparar(const string& s) {
    size_t ini = s.find_first_not_of(" \t\n"), fim = s.find_last_not_of(" \t\n");
    return ini == string::npos ? "" : s.substr(ini, fim - ini + 1);
}

class EmailBuilder {
    static constexpr size_t LIMITE_ANEXOS_BYTES = 10 * 1024 * 1024;

    string remetente = "nao-responda@loja.exemplo";
    vector<string> destinatarios, copias;
    string assunto_, texto, html, agendadoPara;
    vector<Anexo> anexos;

public:
    EmailBuilder& de(const string& endereco) { remetente = endereco; return *this; }

    EmailBuilder& para(initializer_list<string> enderecos) { destinatarios.insert(destinatarios.end(), enderecos); return *this; }

    EmailBuilder& comCopia(initializer_list<string> enderecos) { copias.insert(copias.end(), enderecos); return *this; }

    EmailBuilder& assunto(const string& t) { assunto_ = aparar(t); return *this; }

    EmailBuilder& corpo(const string& t, const string& h = "") { texto = t; html = h; return *this; }

    EmailBuilder& anexar(const string& nome, const string& conteudo) { anexos.push_back({nome, conteudo}); return *this; }

    EmailBuilder& agendar(const string& quando) { agendadoPara = quando; return *this; }

    Email build() const {
        if (destinatarios.empty()) {
            throw EmailInvalido("informe ao menos um destinatário");
        }
        if (assunto_.empty()) {
            throw EmailInvalido("assunto obrigatório");
        }
        size_t total = 0;
        for (const auto& a : anexos) total += a.conteudo.size();
        if (total > LIMITE_ANEXOS_BYTES) {
            throw EmailInvalido("anexos somam " + to_string(total) + " bytes, acima do limite");
        }
        return {remetente, destinatarios, copias, assunto_, texto, html, anexos, agendadoPara};
    }
};

using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

class Anexo
{
    public readonly string Nome;
    public readonly byte[] Conteudo;

    public Anexo(string nome, byte[] conteudo)
    {
        Nome = nome;
        Conteudo = conteudo;
    }
}

class Email
{
    public string Remetente, Assunto, Texto, Html;
    public List<string> Destinatarios, Copias;
    public List<Anexo> Anexos;
    public DateTime? AgendadoPara;
}

class EmailInvalido : Exception
{
    public EmailInvalido(string msg) : base(msg) { }
}

class EmailBuilder
{
    const int LIMITE_ANEXOS_BYTES = 10 * 1024 * 1024;

    private string remetente = "nao-responda@loja.exemplo";
    private readonly List<string> destinatarios = new List<string>();
    private readonly List<string> copias = new List<string>();
    private string assunto = "";
    private string texto = "";
    private string html = null;
    private readonly List<Anexo> anexos = new List<Anexo>();
    private DateTime? agendadoPara = null;

    public EmailBuilder De(string endereco) { remetente = endereco; return this; }

    public EmailBuilder Para(params string[] enderecos) { destinatarios.AddRange(enderecos); return this; }

    public EmailBuilder ComCopia(params string[] enderecos) { copias.AddRange(enderecos); return this; }

    public EmailBuilder Assunto(string t) { assunto = t.Trim(); return this; }

    public EmailBuilder Corpo(string t, string h = null) { texto = t; html = h; return this; }

    public EmailBuilder Anexar(string nome, byte[] conteudo) { anexos.Add(new Anexo(nome, conteudo)); return this; }

        return new Email
        {
            Remetente = remetente,
            Destinatarios = new List<string>(destinatarios),
            Copias = new List<string>(copias),
            Assunto = assunto,
            Texto = texto,
            Html = html,
            Anexos = new List<Anexo>(anexos),

import (
	"errors"
	"fmt"
	"strings"
	"time"
)

type Anexo struct {
	nome     string
	conteudo []byte
}

type Email struct {
	remetente     string
	destinatarios []string
	copias        []string
	assunto       string
	texto         string
	html          *string
	anexos        []Anexo
	agendadoPara  *time.Time
}

var ErrEmailInvalido = errors.New("email inválido")

const limiteAnexosBytes = 10 * 1024 * 1024

type EmailBuilder struct {
	remetente     string
	destinatarios []string
	copias        []string
	assunto       string
	texto         string
	html          *string
	anexos        []Anexo
	agendadoPara  *time.Time
}

func novoEmailBuilder() *EmailBuilder {
	return &EmailBuilder{remetente: "nao-responda@loja.exemplo"}
}

func (b *EmailBuilder) de(endereco string) *EmailBuilder { b.remetente = endereco; return b }

func (b *EmailBuilder) para(enderecos ...string) *EmailBuilder {
	b.destinatarios = append(b.destinatarios, enderecos...)
	return b
}

func (b *EmailBuilder) comCopia(enderecos ...string) *EmailBuilder {
	b.copias = append(b.copias, enderecos...)
	return b
}

func (b *EmailBuilder) comAssunto(texto string) *EmailBuilder {
	b.assunto = strings.TrimSpace(texto)
	return b
}

func (b *EmailBuilder) corpo(texto string, html *string) *EmailBuilder {
	b.texto, b.html = texto, html
	return b
}

func (b *EmailBuilder) anexar(nome string, conteudo []byte) *EmailBuilder {
	b.anexos = append(b.anexos, Anexo{nome, conteudo})
	return b
}

func (b *EmailBuilder) agendar(quando time.Time) *EmailBuilder { b.agendadoPara = &quando; return b }

func (b *EmailBuilder) build() (Email, error) {
	if len(b.destinatarios) == 0 {
		return Email{}, fmt.Errorf("%w: informe ao menos um destinatário", ErrEmailInvalido)
	}
	if b.assunto == "" {
		return Email{}, fmt.Errorf("%w: assunto obrigatório", ErrEmailInvalido)
	}
	total := 0
	for _, a := range b.anexos {
		total += len(a.conteudo)
	}
	if total > limiteAnexosBytes {
		return Email{}, fmt.Errorf("%w: anexos somam %d bytes, acima do limite", ErrEmailInvalido, total)
	}
	return Email{
		remetente:     b.remetente,
		destinatarios: append([]string{}, b.destinatarios...),
		copias:        append([]string{}, b.copias...),
		assunto:       b.assunto,
		texto:         b.texto,
		html:          b.html,
		anexos:        append([]Anexo{}, b.anexos...),
		agendadoPara:  b.agendadoPara,
	}, nil
}

// Diretor: conhece receitas prontas de montagem.
func notaFiscal(cliente string, numero int, pdf []byte) Email {
	e, _ := novoEmailBuilder().
		para(cliente).
		comAssunto(fmt.Sprintf("Sua nota fiscal nº %d", numero)).
		corpo("Segue em anexo a nota fiscal da sua compra.", nil).
		anexar(fmt.Sprintf("nf-%d.pdf", numero), pdf).
		build()
	return e
}

func main() {
	html := "<p>Seu pedido foi <b>confirmado</b>.</p>"
	email, _ := novoEmailBuilder().
		de("vendas@loja.exemplo").
		para("ana@cliente.exemplo", "bruno@cliente.exemplo").
		comCopia("financeiro@loja.exemplo").
		comAssunto("  Pedido 8841 confirmado ").
		corpo("Seu pedido foi confirmado.", &html).
		agendar(time.Date(2026, 11, 2, 9, 0, 0, 0, time.UTC)).
		build()
	fmt.Println(email.assunto, "->", email.destinatarios, "| agendado:", email.agendadoPara.Format("2006-01-02 15:04:05"))

	nf := notaFiscal("carla@cliente.exemplo", 1203, []byte("%PDF-1.7 ..."))
	nomes := []string{}
	for _, a := range nf.anexos {
		nomes = append(nomes, a.nome)
	}
	fmt.Println(nf.assunto, nomes)

	if _, erro := novoEmailBuilder().comAssunto("sem destinatário").build(); erro != nil {
		fmt.Println("erro:", strings.TrimPrefix(erro.Error(), "email inválido: "))
	}
}

Pontos a notar:

- Cada método devolve `self`, o que permite a **interface fluente** (encadeamento).
- O produto `Email` é `frozen`: depois de construído, não muda. Toda a mutabilidade fica confinada ao builder.
- A validação mora em **um só lugar**, o `build()`.
- O **Diretor** (`ModelosDeEmail`) é opcional. Ele guarda sequências de passos reutilizáveis.

<Callout type="note" title="E os argumentos nomeados do Python?">
Com `dataclass` e parâmetros com valor padrão, você já evita o construtor telescópico em muitos casos. O Builder se justifica quando há montagem incremental (adicionar anexos em um laço), validação entre campos ou receitas de montagem reutilizáveis.
</Callout>

## Quando usar e quando evitar

| Use quando | Evite quando |
| --- | --- |
| O objeto tem muitos campos opcionais e regras entre eles | O objeto tem 3 ou 4 campos simples |
| A montagem acontece em etapas (laços, condicionais) | Argumentos nomeados com padrão resolvem |
| Você quer o produto imutável e sempre válido | O objeto precisa mesmo ser mutável depois |
| A mesma montagem gera representações diferentes (texto, HTML, SQL) | Só existe uma forma de criar |

## Padrões parecidos

- **Factory Method / Abstract Factory:** decidem **qual classe** instanciar e devolvem o objeto numa única chamada. O Builder foca em **como montar** um objeto complexo em vários passos.
- **Prototype:** cria copiando um objeto existente. Às vezes um builder começa a partir de um protótipo ("copie o pedido anterior e troque o endereço").
- **Composite:** builders são ótimos para montar árvores Composite (por exemplo, um construtor de menus ou de consultas SQL).

## Na entrevista

O Builder aparece naturalmente em problemas com entidades ricas: montar um `Pedido` no carrinho, uma `Pizza` com ingredientes, uma `ConsultaSQL`, uma `Notificacao` multicanal. Diga explicitamente: "vou usar um builder para garantir que o objeto nunca exista em estado inválido". Follow-ups comuns:

- "Onde fica a validação?" No `build()`, antes de criar o produto.
- "Por que não setters?" Setters permitem objeto parcialmente inicializado e mutável.
- "O builder é thread-safe?" Normalmente não precisa ser: ele é local a quem monta; o produto imutável é que pode ser compartilhado.
