## O problema

Num editor de texto, o usuário digita, apaga, aplica negrito e espera conseguir desfazer cada passo com Ctrl+Z. As mesmas ações podem vir do teclado, de um botão na barra, de um menu ou de uma macro gravada. Se cada botão chamar diretamente métodos do documento, você não tem onde registrar o que foi feito, nem como desfazer, nem como reproduzir depois.

O Command **transforma uma requisição em um objeto**. Esse objeto sabe executar a ação, carrega os parâmetros necessários e, se for o caso, sabe desfazê-la. Como é um objeto, pode ser guardado num histórico, colocado numa fila, enviado pela rede, agendado ou repetido.

## Estrutura

```text
+-------------+   aciona   +-------------------+       +-------------+
|  Invocador  |----------->|  Comando (iface)  |       |  Receptor   |
|-------------|            |-------------------|       |-------------|
| - historico |            | + executar()      |       | (faz o      |
| + rodar(c)  |            | + desfazer()      |       |  trabalho)  |
| + desfazer()|            +-------------------+       +-------------+
+-------------+                     ^                         ^
                                    |                         |
                           ComandoConcreto ---- chama -------+
                           (guarda parâmetros e
                            estado para desfazer)
```

- **Receptor**: o objeto que realmente sabe fazer o trabalho (o documento).
- **Comando concreto**: liga uma ação a um receptor, com os argumentos.
- **Invocador**: dispara comandos sem saber o que fazem (botão, atalho, fila). Aqui, também guarda o histórico.
- **Cliente**: monta o comando e entrega ao invocador.

```python
from abc import ABC, abstractmethod
from typing import List


class Documento:  # receptor
    def __init__(self):
        self.texto = ""

    def inserir(self, posicao: int, trecho: str) -> None:
        self.texto = self.texto[:posicao] + trecho + self.texto[posicao:]

    def remover(self, posicao: int, tamanho: int) -> str:
        removido = self.texto[posicao:posicao + tamanho]
        self.texto = self.texto[:posicao] + self.texto[posicao + tamanho:]
        return removido


class Comando(ABC):
    @abstractmethod
    def executar(self) -> None: ...

    @abstractmethod
    def desfazer(self) -> None: ...


class Inserir(Comando):
    def __init__(self, doc: Documento, posicao: int, trecho: str):
        self.doc, self.posicao, self.trecho = doc, posicao, trecho

    def executar(self) -> None:
        self.doc.inserir(self.posicao, self.trecho)

    def desfazer(self) -> None:
        self.doc.remover(self.posicao, len(self.trecho))


class Apagar(Comando):
    def __init__(self, doc: Documento, posicao: int, tamanho: int):
        self.doc, self.posicao, self.tamanho = doc, posicao, tamanho
        self._apagado = ""  # estado necessário para desfazer

    def executar(self) -> None:
        self._apagado = self.doc.remover(self.posicao, self.tamanho)

    def desfazer(self) -> None:
        self.doc.inserir(self.posicao, self._apagado)


class Macro(Comando):
    """Comando composto: executa vários em ordem e desfaz na ordem inversa."""

    def __init__(self, comandos: List[Comando]):
        self.comandos = comandos

    def executar(self) -> None:
        for c in self.comandos:
            c.executar()

    def desfazer(self) -> None:
        for c in reversed(self.comandos):
            c.desfazer()


class Editor:  # invocador
    def __init__(self):
        self._desfazer: List[Comando] = []
        self._refazer: List[Comando] = []

    def rodar(self, comando: Comando) -> None:
        comando.executar()
        self._desfazer.append(comando)
        self._refazer.clear()  # nova ação invalida o "refazer"

    def desfazer(self) -> None:
        if self._desfazer:
            comando = self._desfazer.pop()
            comando.desfazer()
            self._refazer.append(comando)

    def refazer(self) -> None:
        if self._refazer:
            comando = self._refazer.pop()
            comando.executar()
            self._desfazer.append(comando)


doc = Documento()
editor = Editor()

editor.rodar(Inserir(doc, 0, "Olá mundo"))
editor.rodar(Inserir(doc, 9, "!"))
editor.rodar(Apagar(doc, 0, 4))
print(repr(doc.texto))

editor.desfazer()
print(repr(doc.texto))
editor.desfazer()
print(repr(doc.texto))
editor.refazer()
print(repr(doc.texto))

assinatura = Macro([Inserir(doc, len(doc.texto), "\n--"), Inserir(doc, len(doc.texto) + 3, "\nAna")])
editor.rodar(assinatura)
print(repr(doc.texto))
editor.desfazer()
print(repr(doc.texto))
```

```java
import java.util.*;

class Documento {   // receptor
    String texto = "";

    void inserir(int posicao, String trecho) {
        texto = texto.substring(0, posicao) + trecho + texto.substring(posicao);
    }

    String remover(int posicao, int tamanho) {
        String removido = texto.substring(posicao, Math.min(posicao + tamanho, texto.length()));
        texto = texto.substring(0, posicao) + texto.substring(Math.min(posicao + tamanho, texto.length()));
        return removido;
    }
}

    void executar();
    void desfazer();

        this.comandos = comandos;
```

```cpp
#include <algorithm>

class Documento {   // receptor
public:
    string texto;

    void inserir(size_t posicao, const string& trecho) {
        texto.insert(posicao, trecho);

    string remover(size_t posicao, size_t tamanho) {

        texto.erase(posicao, tamanho);
        return removido;
    }
};

class Comando {
public:
    virtual ~Comando() = default;
    virtual void executar() = 0;
    virtual void desfazer() = 0;
};

class Inserir : public Comando {
    Documento& doc;
    size_t posicao;
    string trecho;

public:
    Inserir(Documento& doc, size_t posicao, string trecho) : doc(doc), posicao(posicao), trecho(trecho) {}

    void executar() override { doc.inserir(posicao, trecho); }

    void desfazer() override { doc.remover(posicao, trecho.size()); }
};

class Apagar : public Comando {
    Documento& doc;
    size_t posicao, tamanho;
    string apagado;   // estado necessário para desfazer

public:
    Apagar(Documento& doc, size_t posicao, size_t tamanho) : doc(doc), posicao(posicao), tamanho(tamanho) {}

    void executar() override { apagado = doc.remover(posicao, tamanho); }

    void desfazer() override { doc.inserir(posicao, apagado); }
};

// Comando composto: executa vários em ordem e desfaz na ordem inversa.
class Macro : public Comando {
    vector<shared_ptr<Comando>> comandos;

public:
    Macro(vector<shared_ptr<Comando>> comandos) : comandos(comandos) {}

    void executar() override {
        for (auto& c : comandos) c->executar();
    }

    void desfazer() override {
        for (auto it = comandos.rbegin(); it != comandos.rend(); ++it) (*it)->desfazer();
    }
};

class Editor {   // invocador
    vector<shared_ptr<Comando>> pilhaDesfazer, pilhaRefazer;

public:
    void rodar(shared_ptr<Comando> comando) {
        comando->executar();
        pilhaDesfazer.push_back(comando);
        pilhaRefazer.clear();   // nova ação invalida o "refazer"
    }

    void desfazer() {
        if (!pilhaDesfazer.empty()) {
            auto comando = pilhaDesfazer.back();
            pilhaDesfazer.pop_back();
            comando->desfazer();
            pilhaRefazer.push_back(comando);
        }
    }

    void refazer() {
        if (!pilhaRefazer.empty()) {
            auto comando = pilhaRefazer.back();
            pilhaRefazer.pop_back();
            comando->executar();
            pilhaDesfazer.push_back(comando);
        }
    }
};

    string saida = "'";
    for (char c : s) {
        if (c == '\n') saida += "\\n";
        else saida += c;
    }
    return saida + "'";
}

}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Documento   // receptor
{
    public string Texto = "";

    public void Inserir(int posicao, string trecho)
    {
        Texto = Texto.Substring(0, posicao) + trecho + Texto.Substring(posicao);
    }

    public string Remover(int posicao, int tamanho)
    {
        int fim = Math.Min(posicao + tamanho, Texto.Length);
        string removido = Texto.Substring(posicao, fim - posicao);
        Texto = Texto.Substring(0, posicao) + Texto.Substring(fim);
        return removido;
    }
}

interface IComando
{
    void Executar();
    void Desfazer();
}

class InserirCmd : IComando
{
    private readonly Documento doc;
    private readonly int posicao;
    private readonly string trecho;

    public InserirCmd(Documento doc, int posicao, string trecho)
    {
        this.doc = doc;
        this.posicao = posicao;
        this.trecho = trecho;
    }

    public void Executar() { doc.Inserir(posicao, trecho); }

    public void Desfazer() { doc.Remover(posicao, trecho.Length); }
}

class ApagarCmd : IComando
{
    private readonly Documento doc;
    private readonly int posicao, tamanho;
    private string apagado = "";   // estado necessário para desfazer

    public ApagarCmd(Documento doc, int posicao, int tamanho)
    {
        this.doc = doc;
        this.posicao = posicao;
        this.tamanho = tamanho;
    }

    public void Executar() { apagado = doc.Remover(posicao, tamanho); }

    public void Desfazer() { doc.Inserir(posicao, apagado); }
}

// Comando composto: executa vários em ordem e desfaz na ordem inversa.
class Macro : IComando
{
    private readonly List<IComando> comandos;

    public Macro(List<IComando> comandos)
    {
        this.comandos = comandos;
    }

    public void Executar()
    {
        foreach (var c in comandos) c.Executar();
    }

    public void Desfazer()
    {
        foreach (var c in Enumerable.Reverse(comandos)) c.Desfazer();
    }
}

class Editor   // invocador
{
    private readonly Stack<IComando> pilhaDesfazer = new Stack<IComando>();
    private readonly Stack<IComando> pilhaRefazer = new Stack<IComando>();

    public void Rodar(IComando comando)
    {
        comando.Executar();
        pilhaDesfazer.Push(comando);
        pilhaRefazer.Clear();   // nova ação invalida o "refazer"
    }

    public void Desfazer()
    {
        if (pilhaDesfazer.Count > 0)
        {
            var comando = pilhaDesfazer.Pop();
            comando.Desfazer();
            pilhaRefazer.Push(comando);
        }
    }

    public void Refazer()
    {
        if (pilhaRefazer.Count > 0)
        {
            var comando = pilhaRefazer.Pop();
            comando.Executar();
            pilhaDesfazer.Push(comando);
        }
    }
}
```

```go
type Documento struct { // receptor

func (d *Documento) inserir(posicao int, trecho string) {
	novo := append([]rune{}, d.texto[:posicao]...)
	novo = append(novo, []rune(trecho)...)
	d.texto = append(novo, d.texto[posicao:]...)
}

func (d *Documento) remover(posicao, tamanho int) string {
	fim := posicao + tamanho
	if fim > len(d.texto) {
		fim = len(d.texto)
	}
	removido := string(d.texto[posicao:fim])
	d.texto = append(append([]rune{}, d.texto[:posicao]...), d.texto[fim:]...)
	return removido
}

type Comando interface {
	executar()
	desfazer()
}

type Inserir struct {
	doc     *Documento
	posicao int
	trecho  string
}

func (c *Inserir) executar() { c.doc.inserir(c.posicao, c.trecho) }

func (c *Inserir) desfazer() { c.doc.remover(c.posicao, len([]rune(c.trecho))) }

type Apagar struct {
	doc     *Documento
	posicao int
	tamanho int
	apagado string // estado necessário para desfazer
}

func (c *Apagar) executar() { c.apagado = c.doc.remover(c.posicao, c.tamanho) }

func (c *Apagar) desfazer() { c.doc.inserir(c.posicao, c.apagado) }

// Comando composto: executa vários em ordem e desfaz na ordem inversa.
type Macro struct {
	comandos []Comando
}

func (m *Macro) executar() {
	for _, c := range m.comandos {
		c.executar()
	}
}

func (m *Macro) desfazer() {
	for i := len(m.comandos) - 1; i >= 0; i-- {
		m.comandos[i].desfazer()
	}
}

type Editor struct { // invocador
	pilhaDesfazer []Comando
	pilhaRefazer  []Comando
}

func (e *Editor) rodar(comando Comando) {
	comando.executar()
	e.pilhaDesfazer = append(e.pilhaDesfazer, comando)
	e.pilhaRefazer = nil // nova ação invalida o "refazer"
}

func (e *Editor) desfazer() {
	if n := len(e.pilhaDesfazer); n > 0 {
		comando := e.pilhaDesfazer[n-1]
		e.pilhaDesfazer = e.pilhaDesfazer[:n-1]
		comando.desfazer()
		e.pilhaRefazer = append(e.pilhaRefazer, comando)
	}
}

func (e *Editor) refazer() {
	if n := len(e.pilhaRefazer); n > 0 {
		comando := e.pilhaRefazer[n-1]
		e.pilhaRefazer = e.pilhaRefazer[:n-1]
		comando.executar()
		e.pilhaDesfazer = append(e.pilhaDesfazer, comando)
	}
}

func repr(s string) string { // mostra as quebras de linha como \n
	return "'" + strings.ReplaceAll(s, "\n", "\\n") + "'"
}

func main() {
	doc := &Documento{}
	editor := &Editor{}

	editor.rodar(&Inserir{doc: doc, posicao: 0, trecho: "Olá mundo"})
	editor.rodar(&Inserir{doc: doc, posicao: 9, trecho: "!"})
	editor.rodar(&Apagar{doc: doc, posicao: 0, tamanho: 4})
	fmt.Println(repr(string(doc.texto)))

	editor.desfazer()
	fmt.Println(repr(string(doc.texto)))
	editor.desfazer()
	fmt.Println(repr(string(doc.texto)))
	editor.refazer()
	fmt.Println(repr(string(doc.texto)))

	assinatura := &Macro{[]Comando{
		&Inserir{doc: doc, posicao: len(doc.texto), trecho: "\n--"},
		&Inserir{doc: doc, posicao: len(doc.texto) + 3, trecho: "\nAna"},
	}}
	editor.rodar(assinatura)
	fmt.Println(repr(string(doc.texto)))
	editor.desfazer()
	fmt.Println(repr(string(doc.texto)))
}
```

</CodeTabs>

Note que `Apagar` guarda o texto removido durante `executar`. Sem isso, desfazer seria impossível. Todo comando reversível precisa capturar o estado mínimo para voltar atrás.

## Quando usar e quando evitar

**Use quando:**

- Você precisa de desfazer/refazer, histórico ou auditoria de ações.
- Quer enfileirar, agendar, repetir ou executar remotamente operações.
- A mesma ação é disparada de vários pontos da interface (botão, atalho, menu).

**Evite quando:**

- A ação é uma chamada simples sem histórico nem fila. Uma função ou um callback resolve.
- Desfazer exigiria guardar estado enorme a cada passo. Nesse caso, combine com Memento ou snapshots periódicos.

<Callout type="tip" title="Desfazer por inversão ou por snapshot">
Há duas formas de desfazer: cada comando sabe a operação inversa (como acima) ou você guarda uma foto do estado antes de executar (Memento). Inversão economiza memória; snapshot é mais simples quando a operação inversa é difícil de calcular.
</Callout>

## Padrões parecidos

| Padrão | Diferença |
| --- | --- |
| Strategy | Strategy define **como** fazer algo e é trocada no contexto. Command representa **uma ação específica** a executar, com seus argumentos. |
| Memento | Guarda o estado de um objeto. É frequentemente usado junto com Command para implementar desfazer. |
| Chain of Responsibility | Um comando pode ser passado por uma cadeia de handlers até alguém executá-lo. |
| Composite | A `Macro` é um Composite de comandos. |

## Na entrevista

- Em editores de texto, planilhas, jogos (desfazer jogada no xadrez), sistemas bancários (operações auditáveis) ou controle remoto de casa inteligente, Command é a resposta natural para "como implementar desfazer?".
- Explique as duas pilhas e por que uma ação nova limpa o "refazer".
- Follow-ups: "como desfazer uma operação que chamou um serviço externo?" (comando de compensação, como estornar um pagamento), "como persistir o histórico?" (serializar comandos, que é a base do event sourcing).
