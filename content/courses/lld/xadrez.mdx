Xadrez é o oposto do jogo da velha: as regras são tantas que é impossível implementar tudo numa entrevista. O que o entrevistador avalia é **como você corta o escopo** e se o design deixa espaço para as regras que ficaram de fora. Um bom candidato entrega movimento de todas as peças, captura, turnos e a regra de não deixar o próprio rei em xeque, e explica onde roque, en passant e promoção se encaixariam.

## Requisitos

Perguntas que valem a pena:

- **Dois jogadores locais ou partida online?** Comece local. Online vira extensão (concorrência, relógio, reconexão).
- **Preciso validar xeque e xeque-mate?** Normalmente sim para xeque (jogada que deixa o rei atacado é ilegal). Mate pode ser dito como "nenhuma jogada legal disponível e rei em xeque".
- **Roque, en passant e promoção?** Pergunte. A resposta comum é "mencione como faria, implemente se sobrar tempo".
- **Relógio, notação PGN, desfazer?** Fora do escopo inicial.

Escopo combinado: tabuleiro 8x8, seis tipos de peça com seus movimentos, captura, alternância de turno, rejeição de jogadas que deixam o próprio rei em xeque e detecção de xeque-mate.

## Entidades e responsabilidades

| Entidade | Responsabilidade |
| --- | --- |
| `Cor` | Enum BRANCO e PRETO. |
| `Posicao` | Par imutável (linha, coluna) com conversão de notação "e2". |
| `Peca` (abstrata) | Sabe gerar seus destinos candidatos a partir do tabuleiro. Cada tipo é uma subclasse. |
| `Tabuleiro` | Mapa posição para peça, consulta de casas e verificação "esta casa é atacada pela cor X?". |
| `Jogada` | Origem, destino e peça capturada. Permite desfazer uma simulação. |
| `Partida` | Turnos, validação de legalidade (rei fora de xeque), histórico e status. |

A decisão central é **quem sabe se um movimento é válido**. Dividimos em duas camadas: a peça conhece a geometria (o cavalo pula em L, o bispo anda na diagonal até bater em algo). A partida conhece as regras globais (não pode deixar o rei em xeque, é a vez de quem). Assim, a peça nunca precisa saber de turnos, e a partida nunca precisa saber como o cavalo se move.

## Diagrama de classes

```text
+------------------+       +-------------------------+
|  Partida         |------>|  Tabuleiro              |
|------------------|       |-------------------------|
| - vez: Cor       |       | - casas: dict[Pos,Peca] |
| - historico      |       | + peca_em(pos)          |
| + mover(o, d)    |       | + atacada(pos, cor)     |
| + jogadas_legais |       | + aplicar / desfazer    |
+------------------+       +-------------------------+
                                     | 0..32
                                     v
                           +---------------------+
                           |  Peca (abstrata)    |
                           | - cor               |
                           | + destinos(tab,pos) |
                           +---------------------+
                     ^      ^      ^      ^      ^      ^
                   Rei  Dama  Torre  Bispo  Cavalo  Peao
           (Dama, Torre e Bispo herdam de Deslizante)
```

## Padrões usados e por quê

- **Polimorfismo / Strategy**: cada peça implementa `destinos`. Adicionar uma peça de variante (o "arcebispo" de Capablanca) é criar uma subclasse.
- **Template Method** em `Deslizante`: torre, bispo e dama compartilham o algoritmo "ande numa direção até sair do tabuleiro ou bater numa peça"; cada uma só informa suas direções.
- **Command** em `Jogada`: aplicar e desfazer. Isso é o que torna barata a checagem "essa jogada deixa meu rei em xeque?": aplica, testa, desfaz.
- **Factory** simples para montar a posição inicial a partir de uma string, em vez de 32 linhas de `colocar`.

```python
from enum import Enum
from typing import Dict, List, Optional, Tuple

Pos = Tuple[int, int]  # (linha 0..7, coluna 0..7); linha 0 = lado das brancas


class Cor(Enum):
    BRANCO = "branco"
    PRETO = "preto"

    def oposta(self):
        return Cor.PRETO if self is Cor.BRANCO else Cor.BRANCO


def pos(nota: str) -> Pos:
    return int(nota[1]) - 1, ord(nota[0]) - ord("a")


class JogadaIlegal(Exception):
    pass


class Peca:
    simbolo = "?"

    def __init__(self, cor: Cor):
        self.cor = cor

    def destinos(self, tab: "Tabuleiro", p: Pos) -> List[Pos]:
        raise NotImplementedError

    def __repr__(self):
        return self.simbolo.upper() if self.cor is Cor.BRANCO else self.simbolo


class Deslizante(Peca):
    direcoes: List[Pos] = []

    def destinos(self, tab, p):
        res = []
        for dl, dc in self.direcoes:
            l, c = p[0] + dl, p[1] + dc
            while tab.dentro((l, c)):
                alvo = tab.peca_em((l, c))
                if alvo is None:
                    res.append((l, c))
                else:
                    if alvo.cor is not self.cor:
                        res.append((l, c))
                    break
                l, c = l + dl, c + dc
        return res


RETAS = [(1, 0), (-1, 0), (0, 1), (0, -1)]
DIAGS = [(1, 1), (1, -1), (-1, 1), (-1, -1)]


class Torre(Deslizante):
    simbolo, direcoes = "t", RETAS


class Bispo(Deslizante):
    simbolo, direcoes = "b", DIAGS


class Dama(Deslizante):
    simbolo, direcoes = "d", RETAS + DIAGS


class Saltadora(Peca):
    saltos: List[Pos] = []

    def destinos(self, tab, p):
        res = []
        for dl, dc in self.saltos:
            q = (p[0] + dl, p[1] + dc)
            if tab.dentro(q):
                alvo = tab.peca_em(q)
                if alvo is None or alvo.cor is not self.cor:
                    res.append(q)
        return res


class Cavalo(Saltadora):
    simbolo = "c"
    saltos = [(1, 2), (2, 1), (-1, 2), (-2, 1), (1, -2), (2, -1), (-1, -2), (-2, -1)]


class Rei(Saltadora):
    simbolo, saltos = "r", RETAS + DIAGS


class Peao(Peca):
    simbolo = "p"

    def destinos(self, tab, p):
        frente = 1 if self.cor is Cor.BRANCO else -1
        inicio = 1 if self.cor is Cor.BRANCO else 6
        res = []
        um = (p[0] + frente, p[1])
        if tab.dentro(um) and tab.peca_em(um) is None:
            res.append(um)
            dois = (p[0] + 2 * frente, p[1])
            if p[0] == inicio and tab.peca_em(dois) is None:
                res.append(dois)
        for dc in (-1, 1):
            q = (p[0] + frente, p[1] + dc)
            alvo = tab.peca_em(q) if tab.dentro(q) else None
            if alvo is not None and alvo.cor is not self.cor:
                res.append(q)
        return res


class Jogada:
    def __init__(self, origem: Pos, destino: Pos, peca: Peca, capturada: Optional[Peca]):
        self.origem, self.destino = origem, destino
        self.peca, self.capturada = peca, capturada


class Tabuleiro:
    def __init__(self):
        self.casas: Dict[Pos, Peca] = {}

    @staticmethod
    def dentro(p: Pos) -> bool:
        return 0 <= p[0] < 8 and 0 <= p[1] < 8

    def peca_em(self, p: Pos) -> Optional[Peca]:
        return self.casas.get(p)

    def aplicar(self, origem: Pos, destino: Pos) -> Jogada:
        peca = self.casas.pop(origem)
        j = Jogada(origem, destino, peca, self.casas.get(destino))
        self.casas[destino] = peca
        return j

    def desfazer(self, j: Jogada) -> None:
        self.casas[j.origem] = j.peca
        if j.capturada:
            self.casas[j.destino] = j.capturada
        else:
            del self.casas[j.destino]

    def atacada(self, alvo: Pos, por: Cor) -> bool:
        return any(p.cor is por and alvo in p.destinos(self, q)
                   for q, p in list(self.casas.items()))

    def rei(self, cor: Cor) -> Pos:
        return next(q for q, p in self.casas.items() if isinstance(p, Rei) and p.cor is cor)

    @classmethod
    def inicial(cls) -> "Tabuleiro":
        t = cls()
        fila = [Torre, Cavalo, Bispo, Dama, Rei, Bispo, Cavalo, Torre]
        for c, tipo in enumerate(fila):
            t.casas[(0, c)], t.casas[(7, c)] = tipo(Cor.BRANCO), tipo(Cor.PRETO)
            t.casas[(1, c)], t.casas[(6, c)] = Peao(Cor.BRANCO), Peao(Cor.PRETO)
        return t


class Partida:
    def __init__(self):
        self.tab = Tabuleiro.inicial()
        self.vez = Cor.BRANCO
        self.historico: List[Jogada] = []

    def _deixa_rei_seguro(self, o: Pos, d: Pos, cor: Cor) -> bool:
        j = self.tab.aplicar(o, d)
        seguro = not self.tab.atacada(self.tab.rei(cor), cor.oposta())
        self.tab.desfazer(j)
        return seguro

    def jogadas_legais(self, cor: Cor) -> List[Tuple[Pos, Pos]]:
        return [(o, d) for o, p in list(self.tab.casas.items()) if p.cor is cor
                for d in p.destinos(self.tab, o) if self._deixa_rei_seguro(o, d, cor)]

    def mover(self, de: str, para: str) -> str:
        o, d = pos(de), pos(para)
        peca = self.tab.peca_em(o)
        if peca is None or peca.cor is not self.vez:
            raise JogadaIlegal(f"não há peça {self.vez.value} em {de}")
        if d not in peca.destinos(self.tab, o) or not self._deixa_rei_seguro(o, d, self.vez):
            raise JogadaIlegal(f"{de}-{para} não é legal")
        self.historico.append(self.tab.aplicar(o, d))
        self.vez = self.vez.oposta()
        return self.status()

    def status(self) -> str:
        em_xeque = self.tab.atacada(self.tab.rei(self.vez), self.vez.oposta())
        sem_saida = not self.jogadas_legais(self.vez)
        if em_xeque and sem_saida:
            return f"xeque-mate, vence {self.vez.oposta().value}"
        if sem_saida:
            return "afogamento (empate)"
        return "xeque" if em_xeque else "em andamento"


p = Partida()
try:
    p.mover("e2", "e5")
except JogadaIlegal as e:
    print("erro:", e)
# mate do louco: o xeque-mate mais curto possível
for de, para in [("f2", "f3"), ("e7", "e5"), ("g2", "g4")]:
    print(de, para, "->", p.mover(de, para))
print("d8 h4 ->", p.mover("d8", "h4"))
```

```javascript
  constructor() {
    this.casas = new Map(); // chave da posição -> peça
  }

  dentro(p) {
    return p[0] >= 0 && p[0] < 8 && p[1] >= 0 && p[1] < 8;
  }

  pecaEm(p) {
    return this.casas.get(chave(p));
  }

  aplicar(origem, destino) {
    const peca = this.casas.get(chave(origem));
    this.casas.delete(chave(origem));
    const j = new Jogada(origem, destino, peca, this.casas.get(chave(destino)));
    this.casas.set(chave(destino), peca);
    return j;
  }

  desfazer(j) {
    this.casas.set(chave(j.origem), j.peca);
    if (j.capturada) {
      this.casas.set(chave(j.destino), j.capturada);
    } else {
      this.casas.delete(chave(j.destino));
    }
  }

  atacada(alvo, por) {
    for (const [k, p] of [...this.casas]) {
      if (p.cor === por && p.destinos(this, [Math.floor(k / 8), k % 8]).some((d) => d[0] === alvo[0] && d[1] === alvo[1])) {
        return true;
      }
    }
    return false;
  }

  rei(cor) {
    for (const [k, p] of this.casas) {
      if (p instanceof Rei && p.cor === cor) return [Math.floor(k / 8), k % 8];
    }
    throw new Error("sem rei");
  }

  static inicial() {
    const t = new Tabuleiro();
    const fila = [Torre, Cavalo, Bispo, Dama, Rei, Bispo, Cavalo, Torre];
    fila.forEach((tipo, c) => {
      t.casas.set(chave([0, c]), new tipo(Cor.BRANCO));
      t.casas.set(chave([7, c]), new tipo(Cor.PRETO));
      t.casas.set(chave([1, c]), new Peao(Cor.BRANCO));
      t.casas.set(chave([6, c]), new Peao(Cor.PRETO));
    });
    return t;
  }
}

class Partida {
  constructor() {
    this.tab = Tabuleiro.inicial();
    this.vez = Cor.BRANCO;
    this.historico = [];
  }

  _deixaReiSeguro(o, d, cor) {
    const j = this.tab.aplicar(o, d);
    const seguro = !this.tab.atacada(this.tab.rei(cor), oposta(cor));
    this.tab.desfazer(j);
    return seguro;
  }

  jogadasLegais(cor) {
    const res = [];
    for (const [k, p] of [...this.tab.casas]) {
      if (p.cor !== cor) continue;
      const o = [Math.floor(k / 8), k % 8];
      for (const d of p.destinos(this.tab, o)) {
        if (this._deixaReiSeguro(o, d, cor)) res.push([o, d]);
      }
    }
    return res;
  }

  mover(de, para) {
    const o = pos(de);
    const d = pos(para);
    const peca = this.tab.pecaEm(o);
    if (peca === undefined || peca.cor !== this.vez) {
      throw new JogadaIlegal(`não há peça ${this.vez} em ${de}`);
    }
    const legal = peca.destinos(this.tab, o).some((q) => q[0] === d[0] && q[1] === d[1]);
    if (!legal || !this._deixaReiSeguro(o, d, this.vez)) {
      throw new JogadaIlegal(`${de}-${para} não é legal`);
    }
    this.historico.push(this.tab.aplicar(o, d));
    this.vez = oposta(this.vez);
    return this.status();
  }

  status() {
    const emXeque = this.tab.atacada(this.tab.rei(this.vez), oposta(this.vez));
    const semSaida = this.jogadasLegais(this.vez).length === 0;
    if (emXeque && semSaida) {
      return `xeque-mate, vence ${oposta(this.vez)}`;
    }
    if (semSaida) {
      return "afogamento (empate)";
    }
    return emXeque ? "xeque" : "em andamento";
  }
}
```

```typescript
enum Cor {
  BRANCO = "branco",
  PRETO = "preto",
}

const oposta = (cor: Cor): Cor => (cor === Cor.BRANCO ? Cor.PRETO : Cor.BRANCO);
const pos = (nota: string): Pos => [Number(nota[1]) - 1, nota.charCodeAt(0) - "a".charCodeAt(0)];

class JogadaIlegal extends Error {}

abstract class Peca {
  constructor(readonly cor: Cor) {}

  abstract destinos(tab: Tabuleiro, p: Pos): Pos[];
}

const RETAS: Pos[] = [[1, 0], [-1, 0], [0, 1], [0, -1]];
const DIAGS: Pos[] = [[1, 1], [1, -1], [-1, 1], [-1, -1]];

abstract class Deslizante extends Peca {
  abstract readonly direcoes: Pos[];

  destinos(tab: Tabuleiro, p: Pos): Pos[] {
    const res: Pos[] = [];
    for (const [dl, dc] of this.direcoes) {
      let l = p[0] + dl;
      let c = p[1] + dc;
      while (tab.dentro([l, c])) {
        const alvo = tab.pecaEm([l, c]);
        if (alvo === undefined) {
          res.push([l, c]);
        } else {
          if (alvo.cor !== this.cor) {
            res.push([l, c]);
          }
          break;
        }
        l += dl;
        c += dc;
      }
    }
    return res;
  }
}

class Bispo extends Deslizante { readonly direcoes = DIAGS; }
class Dama extends Deslizante { readonly direcoes: Pos[] = [...RETAS, ...DIAGS]; }

  casas = new Map<number, Peca>(); // chave da posição -> peça

    return p[0] >= 0 && p[0] < 8 && p[1] >= 0 && p[1] < 8;
  }

    return this.casas.get(chave(p));
  }

  aplicar(origem: Pos, destino: Pos): Jogada {
    const peca = this.casas.get(chave(origem))!;

      if (p.cor === por && p.destinos(this, dePosicao(k)).some((d) => d[0] === alvo[0] && d[1] === alvo[1])) {
        return true;
      }

    return false;
  }

  rei(cor: Cor): Pos {
    for (const [k, p] of this.casas) {
      if (p instanceof Rei && p.cor === cor) return dePosicao(k);
    }
    throw new Error("sem rei");
  }

  static inicial(): Tabuleiro {
    const t = new Tabuleiro();
    const fila: (new (cor: Cor) => Peca)[] = [Torre, Cavalo, Bispo, Dama, Rei, Bispo, Cavalo, Torre];
    fila.forEach((tipo, c) => {
      t.casas.set(chave([0, c]), new tipo(Cor.BRANCO));
      t.casas.set(chave([7, c]), new tipo(Cor.PRETO));
      t.casas.set(chave([1, c]), new Peao(Cor.BRANCO));
      t.casas.set(chave([6, c]), new Peao(Cor.PRETO));
    });
    return t;
  }
}

class Partida {
  tab = Tabuleiro.inicial();
  vez = Cor.BRANCO;
  historico: Jogada[] = [];

  private deixaReiSeguro(o: Pos, d: Pos, cor: Cor): boolean {
    const j = this.tab.aplicar(o, d);
    const seguro = !this.tab.atacada(this.tab.rei(cor), oposta(cor));
    this.tab.desfazer(j);
    return seguro;
  }

  jogadasLegais(cor: Cor): [Pos, Pos][] {
    const res: [Pos, Pos][] = [];
    for (const [k, p] of [...this.tab.casas]) {
      if (p.cor !== cor) continue;
      const o = dePosicao(k);
      for (const d of p.destinos(this.tab, o)) {
        if (this.deixaReiSeguro(o, d, cor)) res.push([o, d]);
      }
    }
    return res;
  }

  mover(de: string, para: string): string {
    const o = pos(de);
    const d = pos(para);
    const peca = this.tab.pecaEm(o);
    if (peca === undefined || peca.cor !== this.vez) {
      throw new JogadaIlegal(`não há peça ${this.vez} em ${de}`);
    }
    const legal = peca.destinos(this.tab, o).some((q) => q[0] === d[0] && q[1] === d[1]);
    if (!legal || !this.deixaReiSeguro(o, d, this.vez)) {
      throw new JogadaIlegal(`${de}-${para} não é legal`);
    }
    this.historico.push(this.tab.aplicar(o, d));
    this.vez = oposta(this.vez);
    return this.status();
  }

  status(): string {
    const emXeque = this.tab.atacada(this.tab.rei(this.vez), oposta(this.vez));
    const semSaida = this.jogadasLegais(this.vez).length === 0;
    if (emXeque && semSaida) {
      return `xeque-mate, vence ${oposta(this.vez)}`;
    }
    if (semSaida) {
      return "afogamento (empate)";
    }
    return emXeque ? "xeque" : "em andamento";
  }
}
```

```java
class Peao extends Peca {
    Peao(Cor cor) { super(cor); }

    List<int[]> destinos(Tabuleiro tab, int[] p) {
        int frente = cor == Cor.BRANCO ? 1 : -1;
        int inicio = cor == Cor.BRANCO ? 1 : 6;

        if (Tabuleiro.dentro(ul, uc) && tab.pecaEm(ul, uc) == null) {
            res.add(new int[] {ul, uc});
            int dl = p[0] + 2 * frente;
            if (p[0] == inicio && tab.pecaEm(dl, uc) == null) {
                res.add(new int[] {dl, uc});
            }

class Tabuleiro {

    static boolean dentro(int l, int c) {
        return l >= 0 && l < 8 && c >= 0 && c < 8;
    }

    Peca pecaEm(int l, int c) {
        return casas[l][c];
    }

    Jogada aplicar(int[] origem, int[] destino) {
        Peca peca = casas[origem[0]][origem[1]];
        casas[origem[0]][origem[1]] = null;
        Jogada j = new Jogada(origem, destino, peca, casas[destino[0]][destino[1]]);
        casas[destino[0]][destino[1]] = peca;
        return j;
    }

    void desfazer(Jogada j) {
        casas[j.origem[0]][j.origem[1]] = j.peca;
        casas[j.destino[0]][j.destino[1]] = j.capturada; // null se não havia captura
    }

    boolean atacada(int[] alvo, Cor por) {
        for (int l = 0; l < 8; l++) {
            for (int c = 0; c < 8; c++) {
                Peca p = casas[l][c];
                if (p != null && p.cor == por) {
                    for (int[] d : p.destinos(this, new int[] {l, c})) {
                        if (d[0] == alvo[0] && d[1] == alvo[1]) return true;
                    }
                }
            }
        }
        return false;
    }

    int[] rei(Cor cor) {
        for (int l = 0; l < 8; l++) {
            for (int c = 0; c < 8; c++) {
                if (casas[l][c] instanceof Rei && casas[l][c].cor == cor) return new int[] {l, c};
            }
        }
        throw new IllegalStateException("sem rei");
    }

    static Tabuleiro inicial() {
        Tabuleiro t = new Tabuleiro();
        for (int c = 0; c < 8; c++) {
            Peca[] brancas = {new Torre(Cor.BRANCO), new Cavalo(Cor.BRANCO), new Bispo(Cor.BRANCO), new Dama(Cor.BRANCO),
                              new Rei(Cor.BRANCO), new Bispo(Cor.BRANCO), new Cavalo(Cor.BRANCO), new Torre(Cor.BRANCO)};
            Peca[] pretas = {new Torre(Cor.PRETO), new Cavalo(Cor.PRETO), new Bispo(Cor.PRETO), new Dama(Cor.PRETO),

            t.casas[1][c] = new Peao(Cor.BRANCO);
            t.casas[6][c] = new Peao(Cor.PRETO);
        }
        return t;
    }
}

            for (int c = 0; c < 8; c++) {
                Peca p = tab.casas[l][c];
                if (p == null || p.cor != cor) continue;
                int[] o = {l, c};
                for (int[] d : p.destinos(tab, o)) {
                    if (deixaReiSeguro(o, d, cor)) res.add(new int[][] {o, d});
                }
            }
        }

        }
        if (semSaida) {
            return "afogamento (empate)";
        }
        return emXeque ? "xeque" : "em andamento";
    }
```
```csharp
}

static class Sentidos
{
    public static readonly int[][] Retas = { new[] { 1, 0 }, new[] { -1, 0 }, new[] { 0, 1 }, new[] { 0, -1 } };
    public static readonly int[][] Diags = { new[] { 1, 1 }, new[] { 1, -1 }, new[] { -1, 1 }, new[] { -1, -1 } };
}

abstract class Deslizante : Peca
{
    protected Deslizante(Cor cor) : base(cor) { }

    protected abstract int[][] Direcoes();

    public override List<int[]> Destinos(Tabuleiro tab, int[] p)
    {
        var res = new List<int[]>();
        foreach (var d in Direcoes())
        {
            int l = p[0] + d[0], c = p[1] + d[1];
            while (Tabuleiro.Dentro(l, c))
            {
                var alvo = tab.PecaEm(l, c);
                if (alvo == null)
                {
                    res.Add(new[] { l, c });
                }
                else
                {
                    if (alvo.Cor != Cor)
                    {
                        res.Add(new[] { l, c });
                    }
                    break;
                }
                l += d[0];
                c += d[1];
            }
        }
        return res;
    }
}

class Torre : Deslizante
{
    public Torre(Cor cor) : base(cor) { }
    protected override int[][] Direcoes() { return Sentidos.Retas; }
}

class Bispo : Deslizante
{
    public Bispo(Cor cor) : base(cor) { }
    protected override int[][] Direcoes() { return Sentidos.Diags; }
}

class Dama : Deslizante
{
    public Dama(Cor cor) : base(cor) { }
    protected override int[][] Direcoes() { return Sentidos.Retas.Concat(Sentidos.Diags).ToArray(); }
}

abstract class Saltadora : Peca
{
    protected Saltadora(Cor cor) : base(cor) { }

    protected abstract int[][] Saltos();

    public override List<int[]> Destinos(Tabuleiro tab, int[] p)
    {
        var res = new List<int[]>();
        foreach (var s in Saltos())
        {
            int l = p[0] + s[0], c = p[1] + s[1];
            if (Tabuleiro.Dentro(l, c))
            {
                var alvo = tab.PecaEm(l, c);
                if (alvo == null || alvo.Cor != Cor)
                {
                    res.Add(new[] { l, c });
                }
            }
        }
        return res;
    }
}

class Cavalo : Saltadora
{
    public Cavalo(Cor cor) : base(cor) { }

    protected override int[][] Saltos()
    {
        return new[] { new[] { 1, 2 }, new[] { 2, 1 }, new[] { -1, 2 }, new[] { -2, 1 }, new[] { 1, -2 }, new[] { 2, -1 }, new[] { -1, -2 }, new[] { -2, -1 } };
    }
}

class Rei : Saltadora
{
    public Rei(Cor cor) : base(cor) { }

    protected override int[][] Saltos()
    {
        return Sentidos.Retas.Concat(Sentidos.Diags).ToArray();
    }
}

class Peao : Peca
{
    public Peao(Cor cor) : base(cor) { }

    public override List<int[]> Destinos(Tabuleiro tab, int[] p)
    {
        int frente = Cor == Cor.Branco ? 1 : -1;
        int inicio = Cor == Cor.Branco ? 1 : 6;
        var res = new List<int[]>();
        int ul = p[0] + frente, uc = p[1];
        if (Tabuleiro.Dentro(ul, uc) && tab.PecaEm(ul, uc) == null)
        {
            res.Add(new[] { ul, uc });
            int dl = p[0] + 2 * frente;
            if (p[0] == inicio && tab.PecaEm(dl, uc) == null)
            {
                res.Add(new[] { dl, uc });
            }
        }
        foreach (int dc in new[] { -1, 1 })
        {
            int ql = p[0] + frente, qc = p[1] + dc;
            var alvo = Tabuleiro.Dentro(ql, qc) ? tab.PecaEm(ql, qc) : null;
            if (alvo != null && alvo.Cor != Cor)
            {
                res.Add(new[] { ql, qc });
            }
        }
        return res;
    }
}

class Jogada
{
    public readonly int[] Origem, Destino;
    public readonly Peca Peca, Capturada;

    public Jogada(int[] origem, int[] destino, Peca peca, Peca capturada)
    {
        Origem = origem;
        Destino = destino;
        Peca = peca;
        Capturada = capturada;
    }
}

class Tabuleiro
{
    public readonly Peca[,] Casas = new Peca[8, 8];

    public static bool Dentro(int l, int c)
    {
        return l >= 0 && l < 8 && c >= 0 && c < 8;
    }

    public Peca PecaEm(int l, int c)
    {
        return Casas[l, c];
    }

    public Jogada Aplicar(int[] origem, int[] destino)
    {
        var peca = Casas[origem[0], origem[1]];
        Casas[origem[0], origem[1]] = null;
        var j = new Jogada(origem, destino, peca, Casas[destino[0], destino[1]]);
        Casas[destino[0], destino[1]] = peca;
        return j;
    }

    public void Desfazer(Jogada j)
    {
        Casas[j.Origem[0], j.Origem[1]] = j.Peca;
        Casas[j.Destino[0], j.Destino[1]] = j.Capturada; // null se não havia captura
    }

    public bool Atacada(int[] alvo, Cor por)
    {
        for (int l = 0; l < 8; l++)
        {
            for (int c = 0; c < 8; c++)
            {
                var p = Casas[l, c];
                if (p != null && p.Cor == por && p.Destinos(this, new[] { l, c }).Any(d => d[0] == alvo[0] && d[1] == alvo[1])) return true;
            }
        }
        return false;
    }

    public int[] Rei(Cor cor)
    {
        for (int l = 0; l < 8; l++)
        {
            for (int c = 0; c < 8; c++)
            {
                if (Casas[l, c] is Rei && Casas[l, c].Cor == cor) return new[] { l, c };
            }
        }
        throw new InvalidOperationException("sem rei");
    }

    public static Tabuleiro Inicial()
    {
        var t = new Tabuleiro();
        for (int c = 0; c < 8; c++)
        {
            Peca[] brancas = { new Torre(Cor.Branco), new Cavalo(Cor.Branco), new Bispo(Cor.Branco), new Dama(Cor.Branco),
                               new Rei(Cor.Branco), new Bispo(Cor.Branco), new Cavalo(Cor.Branco), new Torre(Cor.Branco) };
            Peca[] pretas = { new Torre(Cor.Preto), new Cavalo(Cor.Preto), new Bispo(Cor.Preto), new Dama(Cor.Preto),
                              new Rei(Cor.Preto), new Bispo(Cor.Preto), new Cavalo(Cor.Preto), new Torre(Cor.Preto) };
            t.Casas[0, c] = brancas[c];
            t.Casas[7, c] = pretas[c];
            t.Casas[1, c] = new Peao(Cor.Branco);
            t.Casas[6, c] = new Peao(Cor.Preto);
        }
        return t;
    }
}

class Partida
{
    public readonly Tabuleiro Tab = Tabuleiro.Inicial();
    public Cor Vez = Cor.Branco;
    public readonly List<Jogada> Historico = new List<Jogada>();

    static Cor Oposta(Cor c)
    {
        return c == Cor.Branco ? Cor.Preto : Cor.Branco;
    }

    static string Nome(Cor c)
    {
        return c == Cor.Branco ? "branco" : "preto";
    }

    static int[] Pos(string nota)
    {
        return new[] { nota[1] - '1', nota[0] - 'a' };
    }

    private bool DeixaReiSeguro(int[] o, int[] d, Cor cor)
    {
        var j = Tab.Aplicar(o, d);
        bool seguro = !Tab.Atacada(Tab.Rei(cor), Oposta(cor));
        Tab.Desfazer(j);
        return seguro;
    }

    public List<int[][]> JogadasLegais(Cor cor)
    {
        var res = new List<int[][]>();
        for (int l = 0; l < 8; l++)
        {
            for (int c = 0; c < 8; c++)
            {
                var p = Tab.Casas[l, c];
                if (p == null || p.Cor != cor) continue;
                var o = new[] { l, c };
                foreach (var d in p.Destinos(Tab, o))
                {
                    if (DeixaReiSeguro(o, d, cor)) res.Add(new[] { o, d });
                }
            }
        }
        return res;
    }

    public string Mover(string de, string para)
    {
        var o = Pos(de);
        var d = Pos(para);
        var peca = Tab.PecaEm(o[0], o[1]);
        if (peca == null || peca.Cor != Vez)
        {
            throw new JogadaIlegal("não há peça " + Nome(Vez) + " em " + de);
        }
        bool legal = peca.Destinos(Tab, o).Any(q => q[0] == d[0] && q[1] == d[1]);
        if (!legal || !DeixaReiSeguro(o, d, Vez))
        {
            throw new JogadaIlegal(de + "-" + para + " não é legal");
        }
        Historico.Add(Tab.Aplicar(o, d));
        Vez = Oposta(Vez);
        return Status();
    }

    public string Status()
    {
        bool emXeque = Tab.Atacada(Tab.Rei(Vez), Oposta(Vez));
        bool semSaida = JogadasLegais(Vez).Count == 0;
        if (emXeque && semSaida)
        {
            return "xeque-mate, vence " + Nome(Oposta(Vez));
        }
        if (semSaida)
        {
            return "afogamento (empate)";
        }
        return emXeque ? "xeque" : "em andamento";
    }
}

static void Main()
{
    var p = new Partida();
    try
    {
        p.Mover("e2", "e5");
    }
    catch (JogadaIlegal e)
    {
        Console.WriteLine("erro: " + e.Message);
    }
    // mate do louco: o xeque-mate mais curto possível
    var lances = new[] { new[] { "f2", "f3" }, new[] { "e7", "e5" }, new[] { "g2", "g4" } };
    foreach (var lance in lances)
    {
        Console.WriteLine(lance[0] + " " + lance[1] + " -> " + p.Mover(lance[0], lance[1]));
    }
    Console.WriteLine("d8 h4 -> " + p.Mover("d8", "h4"));
}
```

A checagem de legalidade usa aplicar, testar e desfazer. É simples e correta, e o custo (gerar ataques do adversário para cada jogada candidata) é irrelevante para 8x8. Se o entrevistador pressionar por desempenho, mencione bitboards e geração incremental de ataques.

## Concorrência e extensões

Numa partida online, cada partida é um agregado com sua própria trava ou fila de comandos: jogadas chegam serializadas, a partida valida se o remetente é o dono da vez e incrementa uma versão. O relógio é um componente separado que observa a troca de turno (Observer) e encerra a partida por tempo.

- **Roque**: a `Jogada` ganha um tipo e um movimento secundário (a torre). O rei precisa saber se já se moveu, então `Peca` ganha `movida: bool`.
- **En passant**: depende da última jogada, que já está no `historico`. A geração de destinos do peão recebe esse contexto.
- **Promoção**: a `Jogada` carrega a peça escolhida; `aplicar` troca o peão pela nova peça e `desfazer` restaura.
- **Empate por repetição ou 50 lances**: um hash da posição contado num dicionário a cada jogada.

<Callout type="warning" title="Não tente implementar tudo">
Começar pelo roque antes de ter o cavalo funcionando é a forma mais rápida de não terminar. Implemente o núcleo, mostre que roda e só então negocie as regras especiais.
</Callout>

## Follow-ups comuns

- **"Por que a peça não valida xeque?"** Porque xeque é uma propriedade da posição inteira, não de uma peça. Manter isso na `Partida` evita que cada subclasse repita a mesma lógica.
- **"Como implementar um motor de IA?"** Um `Jogador` estratégia que usa `jogadas_legais`, aplica, avalia e desfaz (minimax com poda alfa-beta). O par aplicar e desfazer da `Jogada` é exatamente o que o motor precisa.
- **"Como gravar a partida?"** Converta o `historico` para notação algébrica. Recarregar é reaplicar as jogadas a partir da posição inicial.
- **"Por que um dicionário e não uma matriz 8x8?"** Os dois funcionam. O dicionário deixa a iteração sobre peças vivas direta (no máximo 32 entradas) e evita checar casas vazias. A matriz dá acesso indexado sem hash. Diga que escolheu pela legibilidade e que trocaria a representação sem afetar as peças, já que elas só usam `peca_em` e `dentro`.
- **"Como suportar variantes, como xadrez 960?"** Só a fábrica `inicial` muda: ela sorteia a ordem da primeira fileira respeitando as restrições da variante. Peças, partida e validação de xeque continuam iguais, o que mostra que a montagem do tabuleiro estava bem isolada.
