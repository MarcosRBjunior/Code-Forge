Uma classe quase nunca trabalha sozinha: o serviço de pedidos precisa de um repositório, de um gateway de pagamento, de um relógio. A pergunta é **quem cria** essas dependências. Se a própria classe faz `self.pagamento = PagamentoStripe()`, ela fica presa àquela implementação. **Injeção de dependência** (DI) é a prática de entregar as dependências de fora, normalmente pelo construtor. É a forma concreta de aplicar o Princípio da Inversão de Dependência.

## Sem injeção

<CodeTabs>

```python
class PagamentoCartao:
    def cobrar(self, valor: float) -> bool:
        print(f"cobrando {valor} no cartão (chamada real!)")
        return True


class ServicoPedido:
    def __init__(self) -> None:
        self.pagamento = PagamentoCartao()  # acoplado e impossível de testar

    def finalizar(self, total: float) -> str:
        return "pago" if self.pagamento.cobrar(total) else "recusado"
```

## Com injeção pelo construtor

<CodeTabs>

```python
from typing import Protocol


class Pagamento(Protocol):
    def cobrar(self, valor: float) -> bool: ...


class PagamentoCartao:
    def cobrar(self, valor: float) -> bool:
        return True


class PagamentoFalso:
    def __init__(self, aprova: bool) -> None:
        self.aprova = aprova
        self.cobrancas: list[float] = []

    def cobrar(self, valor: float) -> bool:
        self.cobrancas.append(valor)
        return self.aprova


class ServicoPedido:
    def __init__(self, pagamento: Pagamento) -> None:
        self.pagamento = pagamento

    def finalizar(self, total: float) -> str:
        return "pago" if self.pagamento.cobrar(total) else "recusado"


falso = PagamentoFalso(aprova=False)
assert ServicoPedido(falso).finalizar(80) == "recusado"
assert falso.cobrancas == [80]
assert ServicoPedido(PagamentoCartao()).finalizar(80) == "pago"
print("DI ok")
```

```javascript
// em JavaScript basta que o objeto tenha o método cobrar (tipagem estrutural, como o Protocol do Python)
class PagamentoCartao {
  cobrar(valor) { return true; }
}

class PagamentoFalso {
  cobrancas = [];

  constructor(aprova) { this.aprova = aprova; }

  cobrar(valor) {
    this.cobrancas.push(valor);
    return this.aprova;
  }
}

class ServicoPedido {
  constructor(pagamento) { this.pagamento = pagamento; }

  finalizar(total) { return this.pagamento.cobrar(total) ? "pago" : "recusado"; }
}

const falso = new PagamentoFalso(false);
console.assert(new ServicoPedido(falso).finalizar(80) === "recusado");
console.assert(JSON.stringify(falso.cobrancas) === JSON.stringify([80]));
console.assert(new ServicoPedido(new PagamentoCartao()).finalizar(80) === "pago");
console.log("DI ok");
```

class PagamentoCartao implements Pagamento {

```java
import java.util.*;

interface Pagamento {
    boolean cobrar(double valor);
}

class PagamentoCartao implements Pagamento {
    public boolean cobrar(double valor) { return true; }
}

class PagamentoFalso implements Pagamento {
    final boolean aprova;
    final List<Double> cobrancas = new ArrayList<>();

    PagamentoFalso(boolean aprova) { this.aprova = aprova; }

    public boolean cobrar(double valor) {
        cobrancas.add(valor);
        return aprova;
    }
}

class ServicoPedido {
    private final Pagamento pagamento;

    ServicoPedido(Pagamento pagamento) { this.pagamento = pagamento; }

    String finalizar(double total) { return pagamento.cobrar(total) ? "pago" : "recusado"; }
}

public static void main(String[] args) {
    PagamentoFalso falso = new PagamentoFalso(false);
    if (!new ServicoPedido(falso).finalizar(80).equals("recusado")) throw new AssertionError();
    if (!falso.cobrancas.equals(List.of(80.0))) throw new AssertionError();
    if (!new ServicoPedido(new PagamentoCartao()).finalizar(80).equals("pago")) throw new AssertionError();
    System.out.println("DI ok");
}
```

```cpp
#include <cassert>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

class Pagamento {
public:
    virtual ~Pagamento() = default;
    virtual bool cobrar(double valor) = 0;
};

class PagamentoCartao : public Pagamento {
public:
    bool cobrar(double valor) override { return true; }
};

class PagamentoFalso : public Pagamento {
    bool aprova;

public:
    vector<double> cobrancas;

    PagamentoFalso(bool aprova) : aprova(aprova) {}

    bool cobrar(double valor) override {
        cobrancas.push_back(valor);
        return aprova;
    }
};

class ServicoPedido {
    Pagamento& pagamento;

public:
    ServicoPedido(Pagamento& pagamento) : pagamento(pagamento) {}

    string finalizar(double total) { return pagamento.cobrar(total) ? "pago" : "recusado"; }
};

int main() {
    PagamentoFalso falso(false);
    assert(ServicoPedido(falso).finalizar(80) == "recusado");
    assert((falso.cobrancas == vector<double>{80}));
    PagamentoCartao cartao;
    assert(ServicoPedido(cartao).finalizar(80) == "pago");
    cout << "DI ok" << endl;
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

interface IPagamento
{
    bool Cobrar(double valor);
}

class PagamentoCartao : IPagamento
{
    public bool Cobrar(double valor) { return true; }
}

class PagamentoFalso : IPagamento
{
    private readonly bool aprova;
    public readonly List<double> Cobrancas = new List<double>();

    public PagamentoFalso(bool aprova) { this.aprova = aprova; }

    public bool Cobrar(double valor)
    {
        Cobrancas.Add(valor);
        return aprova;
    }
}

class ServicoPedido
{
    private readonly IPagamento pagamento;

    public ServicoPedido(IPagamento pagamento) { this.pagamento = pagamento; }

    public string Finalizar(double total) { return pagamento.Cobrar(total) ? "pago" : "recusado"; }
}

static void Main()
{
    var falso = new PagamentoFalso(false);
    if (new ServicoPedido(falso).Finalizar(80) != "recusado") throw new Exception("falhou");
    if (!falso.Cobrancas.SequenceEqual(new[] { 80.0 })) throw new Exception("falhou");
    if (new ServicoPedido(new PagamentoCartao()).Finalizar(80) != "pago") throw new Exception("falhou");
    Console.WriteLine("DI ok");
}
```

```go
import "fmt"

type Pagamento interface {
	cobrar(valor float64) bool
}

type PagamentoCartao struct{}

func (PagamentoCartao) cobrar(valor float64) bool { return true }

type PagamentoFalso struct {
	aprova    bool
	cobrancas []float64
}

func (p *PagamentoFalso) cobrar(valor float64) bool {
	p.cobrancas = append(p.cobrancas, valor)
	return p.aprova
}

type ServicoPedido struct {
	pagamento Pagamento
}

func (s ServicoPedido) finalizar(total float64) string {
	if s.pagamento.cobrar(total) {
		return "pago"
	}
	return "recusado"
}

func main() {
	falso := &PagamentoFalso{aprova: false}
	if (ServicoPedido{falso}).finalizar(80) != "recusado" {
		panic("falhou")
	}
	if len(falso.cobrancas) != 1 || falso.cobrancas[0] != 80 {
		panic("falhou")
	}
	if (ServicoPedido{PagamentoCartao{}}).finalizar(80) != "pago" {
		panic("falhou")
	}
	fmt.Println("DI ok")
}
```

</CodeTabs>

O serviço só conhece o contrato `Pagamento`. Nos testes entra um dublê; em produção, a implementação real.

## Formas de injetar

| Forma | Como | Quando |
| --- | --- | --- |
| Construtor | recebe no `__init__` | padrão: dependências obrigatórias |
| Setter / atributo | atribuído depois | dependência opcional (use com cautela) |
| Parâmetro de método | passado em cada chamada | dependência varia por chamada |

Prefira o construtor: o objeto nasce completo e válido, sem estado intermediário.

## Composition root

Alguém precisa montar o grafo de objetos. O ideal é fazer isso em **um único lugar**, perto do ponto de entrada (a função `main`), chamado *composition root*:

<CodeTabs>

```python
def montar_app() -> ServicoPedido:
    return ServicoPedido(PagamentoCartao())
```

```javascript
function montarApp() {
  return new ServicoPedido(new PagamentoCartao());
}
```

```typescript
function montarApp(): ServicoPedido {
  return new ServicoPedido(new PagamentoCartao());
}
```

```java
static ServicoPedido montarApp() {
    return new ServicoPedido(new PagamentoCartao());
}
```

```cpp
// a composição acontece em um único lugar, na borda da aplicação
ServicoPedido montarApp(PagamentoCartao& cartao) {
    return ServicoPedido(cartao);
}
```

```csharp
static ServicoPedido MontarApp()
{
    return new ServicoPedido(new PagamentoCartao());
}
```

```go
func montarApp() ServicoPedido {
	return ServicoPedido{PagamentoCartao{}}
}
```

</CodeTabs>

O resto do sistema não cria nada com `new`: apenas recebe. Frameworks de DI (como containers) automatizam isso, mas na entrevista a montagem manual é suficiente e mais clara.

<Callout type="note" title="DI não é o mesmo que DIP">
O DIP é o princípio (dependa de abstrações). A injeção é a técnica para entregar a abstração de fora. Também não se confunde com Service Locator, em que a classe busca suas dependências num registro global, o que esconde o que ela usa.
</Callout>

## Armadilhas

- **Construtores gigantes**: muitas dependências indicam classe com responsabilidade demais (SRP).
- **Injetar tudo**: valores simples e objetos de dados não precisam de injeção.
- **Container mágico**: se ninguém consegue dizer de onde veio uma dependência, a clareza se perdeu.

## Na entrevista

Receber colaboradores pelo construtor é um sinal forte de design maduro. Mostre o dublê de teste para provar o ganho. Follow-ups: "como testaria isso?", "o que muda para trocar a implementação?", "qual a diferença entre DI e Service Locator?".
