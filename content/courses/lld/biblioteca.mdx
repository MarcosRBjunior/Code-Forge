Um sistema de biblioteca cobre catálogo, empréstimos, devoluções, reservas e multas. A armadilha clássica é misturar o conceito de livro (obra) com o de exemplar físico. Acertar essa separação mostra maturidade de modelagem.

## Requisitos

- Catálogo de livros, cada um com vários exemplares.
- Membros pegam exemplares emprestados com limite de itens e prazo.
- Atraso gera multa por dia.
- Se todos os exemplares estão emprestados, o membro pode reservar.

## Entidades

| Entidade | Responsabilidade |
| --- | --- |
| `Livro` | Dados da obra: título, ISBN. |
| `Exemplar` | Unidade física, com estado disponível ou emprestado. |
| `Membro` | Quem empresta; guarda empréstimos ativos. |
| `Emprestimo` | Liga membro e exemplar, com data de saída e prazo. |
| `Biblioteca` | Orquestra regras: limites, multas, fila de reserva. |

## Implementação

```python
from dataclasses import dataclass
from collections import defaultdict, deque
from typing import Dict, List, Optional

DIAS_PRAZO = 14
LIMITE = 2
MULTA_DIA = 0.5


@dataclass(frozen=True)
class Livro:
    isbn: str
    titulo: str


class Exemplar:
    def __init__(self, codigo: str, livro: Livro):
        self.codigo, self.livro, self.emprestado = codigo, livro, False


@dataclass
class Emprestimo:
    membro: "Membro"
    exemplar: Exemplar
    saida: int

    @property
    def vencimento(self):
        return self.saida + DIAS_PRAZO


class Membro:
    def __init__(self, nome: str):
        self.nome = nome
        self.emprestimos: List[Emprestimo] = []


class Biblioteca:
    def __init__(self):
        self.exemplares: Dict[str, List[Exemplar]] = defaultdict(list)
        self.reservas: Dict[str, deque] = defaultdict(deque)

    def adicionar(self, ex: Exemplar):
        self.exemplares[ex.livro.isbn].append(ex)

    def emprestar(self, membro: Membro, isbn: str, hoje: int) -> Optional[Emprestimo]:
        if len(membro.emprestimos) >= LIMITE:
            raise ValueError("limite de empréstimos atingido")
        fila = self.reservas[isbn]
        if fila and fila[0] is not membro:
            self.reservar(membro, isbn)
            return None
        for ex in self.exemplares[isbn]:
            if not ex.emprestado:
                if fila and fila[0] is membro:
                    fila.popleft()
                ex.emprestado = True
                emp = Emprestimo(membro, ex, hoje)
                membro.emprestimos.append(emp)
                return emp
        self.reservar(membro, isbn)
        return None

    def reservar(self, membro: Membro, isbn: str):
        if membro not in self.reservas[isbn]:
            self.reservas[isbn].append(membro)

    def devolver(self, emp: Emprestimo, hoje: int) -> float:
        emp.exemplar.emprestado = False
        emp.membro.emprestimos.remove(emp)
        atraso = max(0, hoje - emp.vencimento)
        return atraso * MULTA_DIA


b = Biblioteca()
livro = Livro("111", "Código Limpo")
b.adicionar(Exemplar("E1", livro))
ana, rui = Membro("Ana"), Membro("Rui")
e = b.emprestar(ana, "111", hoje=0)
print(b.emprestar(rui, "111", hoje=1))   # None: ficou na fila
print(b.devolver(e, hoje=20))            # 3.0 (6 dias de atraso)
print(b.emprestar(rui, "111", hoje=21).exemplar.codigo)
```

Quem está na frente da fila tem prioridade no exemplar devolvido; os demais continuam esperando.

## Extensões

Renovação (limitada se houver reserva), tipos de membro com limites diferentes (Strategy de política), notificação ao primeiro da fila quando o exemplar volta (Observer) e itens de mídia diferentes de livros (herança leve ou composição em um `Item` base).

## Concorrência

Dois atendentes podem emprestar o último exemplar ao mesmo tempo. Proteja a verificação e a marcação como emprestado numa única seção crítica, ou use atualização condicional no banco.

## Na entrevista

- **"Onde fica a multa?"** Em uma política separada; o empréstimo só informa o atraso.
- **"Livro versus exemplar?"** Livro é a obra, exemplar é a cópia. Reservas são por livro, empréstimos por exemplar.
