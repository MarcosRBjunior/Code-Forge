Um site de perguntas e respostas no estilo Stack Overflow mistura conteúdo, votos, reputação e busca por tags. O desafio de modelagem é manter a reputação coerente com os votos sem acoplar tudo.

## Requisitos

- Usuários publicam perguntas (com tags) e respostas.
- Votos positivos e negativos em perguntas e respostas, um voto por usuário por item.
- O autor da pergunta aceita uma resposta.
- Reputação do autor muda com votos e aceitação.
- Busca de perguntas por tag.

## Entidades

| Entidade | Responsabilidade |
| --- | --- |
| `Usuario` | Nome e reputação. |
| `Postagem` | Base comum: autor, texto, votos. |
| `Pergunta` | Postagem com título, tags, respostas e resposta aceita. |
| `Resposta` | Postagem ligada a uma pergunta. |
| `Site` | Publicar, votar, aceitar, buscar por tag. |

Pergunta e resposta compartilham votos, então herdam de `Postagem`. Os votos ficam num dicionário de usuário para valor (+1 ou -1), o que garante um voto por usuário e permite trocar de opinião.

## Implementação

```python
from collections import defaultdict
from typing import Dict, List, Optional, Set

PONTOS_VOTO_POSITIVO = 10
PONTOS_VOTO_NEGATIVO = -2
PONTOS_ACEITA = 15


class Usuario:
    def __init__(self, nome: str):
        self.nome, self.reputacao = nome, 0


class Postagem:
    def __init__(self, autor: Usuario, texto: str):
        self.autor, self.texto = autor, texto
        self.votos: Dict[Usuario, int] = {}

    @property
    def pontuacao(self) -> int:
        return sum(self.votos.values())

    def votar(self, usuario: Usuario, valor: int):
        if usuario is self.autor:
            raise ValueError("não pode votar no próprio conteúdo")
        anterior = self.votos.get(usuario, 0)
        if anterior == valor:
            return
        self.autor.reputacao -= self._pontos(anterior)
        self.votos[usuario] = valor
        self.autor.reputacao += self._pontos(valor)

    @staticmethod
    def _pontos(valor: int) -> int:
        return {1: PONTOS_VOTO_POSITIVO, -1: PONTOS_VOTO_NEGATIVO, 0: 0}[valor]


class Resposta(Postagem):
    pass


class Pergunta(Postagem):
    def __init__(self, autor, titulo: str, texto: str, tags: Set[str]):
        super().__init__(autor, texto)
        self.titulo, self.tags = titulo, set(tags)
        self.respostas: List[Resposta] = []
        self.aceita: Optional[Resposta] = None


class Site:
    def __init__(self):
        self.por_tag: Dict[str, List[Pergunta]] = defaultdict(list)

    def perguntar(self, autor, titulo, texto, tags) -> Pergunta:
        p = Pergunta(autor, titulo, texto, tags)
        for t in p.tags:
            self.por_tag[t].append(p)
        return p

    def responder(self, pergunta: Pergunta, autor, texto) -> Resposta:
        r = Resposta(autor, texto)
        pergunta.respostas.append(r)
        return r

    def aceitar(self, pergunta: Pergunta, resposta: Resposta):
        if resposta not in pergunta.respostas:
            raise ValueError("resposta de outra pergunta")
        if pergunta.aceita is not None:
            pergunta.aceita.autor.reputacao -= PONTOS_ACEITA
        pergunta.aceita = resposta
        resposta.autor.reputacao += PONTOS_ACEITA

    def buscar(self, tag: str) -> List[Pergunta]:
        return sorted(self.por_tag[tag], key=lambda p: -p.pontuacao)


ana, bia, caio = Usuario("Ana"), Usuario("Bia"), Usuario("Caio")
site = Site()
p = site.perguntar(ana, "O que é um mutex?", "Explique.", {"concorrencia"})
r = site.responder(p, bia, "Trava de exclusão mútua.")
r.votar(caio, 1)
r.votar(caio, -1)          # Caio muda de ideia
site.aceitar(p, r)
print(bia.reputacao, r.pontuacao)          # 13 -1
print([q.titulo for q in site.buscar("concorrencia")])
```

Ao trocar o voto, a reputação anterior é desfeita antes de aplicar a nova, o que evita acúmulo indevido.

## Concorrência e extensões

Votos simultâneos no mesmo item exigem lock por postagem (ou contadores atômicos). Extensões: comentários (Composite leve), moderação e privilégios por reputação, histórico de edições, e busca textual com índice invertido. Reputação pode ser derivada de eventos de voto, o que facilita recalcular.

## Na entrevista

- **"Como evitar votos duplicados?"** O mapa usuário para voto garante unicidade.
- **"Onde mora a regra de reputação?"** Aqui, no voto; em escala, em um serviço que consome eventos de voto.
