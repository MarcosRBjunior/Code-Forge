Teste o que você aprendeu sobre Strategy, Iterator, Observer, Command, State, Template Method, Chain of Responsibility, Visitor, Mediator e Memento, com perguntas conceituais e de cenário.

<QuizSet>
<Quiz question="Um app de entregas calcula o frete de formas diferentes (por distância, tarifa fixa, grátis acima de R$ 150) e o lojista escolhe a regra no painel. Qual padrão encaixa melhor?" options={["State, com a regra de frete mudando sozinha conforme o objeto passa por estados internos","Strategy, com uma classe para cada regra de frete, escolhida pelo lojista no painel","Visitor, com uma operação de frete diferente para cada tipo de objeto que for visitado","Memento, com um snapshot de cada regra de frete guardado para consulta posterior"]} answer={1} explanation="Algoritmos intercambiáveis escolhidos pelo cliente, por composição, são o caso clássico do Strategy." />
<Quiz question="Um pedido muda de comportamento conforme está em 'aguardando pagamento', 'pago', 'enviado' ou 'cancelado', e cada situação decide para qual a próxima transição é válida. Qual padrão usar?" options={["Strategy", "State", "Observer", "Iterator"]} answer={1} explanation="No State, o próprio objeto troca de estado e cada estado define as transições permitidas; no Strategy, quem escolhe é o cliente." />
<Quiz question="Quando um pagamento é aprovado, o sistema precisa enviar e-mail, atualizar o estoque e registrar métricas, e novos interessados surgem a cada trimestre. Qual padrão desacopla o serviço de pagamento desses módulos?" options={["Observer", "Mediator", "Command", "Template Method"]} answer={0} explanation="O Observer permite que interessados se inscrevam no evento sem que o publicador conheça cada um." />
<Quiz question="Um editor de texto precisa de desfazer e refazer para ações como digitar, apagar e formatar. Qual combinação é mais adequada?" options={["Iterator para percorrer as ações e Visitor para aplicar a cada uma a operação de desfazer","Command, com cada ação tendo executar e desfazer, mais uma pilha de histórico das ações","Singleton para guardar o texto do documento e Facade para esconder as operações de edição","Chain of Responsibility, passando cada ação adiante até que algum handler a desfaça"]} answer={1} explanation="Encapsular cada ação como objeto com executar e desfazer é a base do undo/redo com Command." />
<Quiz question="Uma requisição HTTP passa por autenticação, limite de taxa e validação; qualquer etapa pode interromper o fluxo. Qual padrão descreve essa estrutura?" options={["Chain of Responsibility, com cada handler processando, repassando ou interrompendo a requisição","Mediator, com um coordenador central que decide qual etapa conversa com qual outra etapa do fluxo","Memento, com um snapshot da requisição guardado antes de cada etapa para poder voltar atrás","Iterator, percorrendo as etapas em sequência sem que nenhuma possa interromper o fluxo"]} answer={0} explanation="Cada handler decide se processa, repassa ao próximo ou interrompe a cadeia." />
<Quiz question="Você tem uma hierarquia estável de itens de nota fiscal (produto, serviço, frete) e precisa adicionar com frequência novas operações (cálculo de impostos, exportação XML, auditoria). Qual padrão favorece esse eixo de mudança?" options={["Visitor", "Decorator", "State", "Prototype"]} answer={0} explanation="O Visitor facilita adicionar operações sem alterar os elementos, ao custo de dificultar novos tipos de elemento." />
<Quiz question="Na tela de checkout, mudar o CEP atualiza o frete, que atualiza o total, que habilita o botão de pagar; os componentes estão todos se referenciando. Qual padrão reduz esse acoplamento muitos-para-muitos?" options={["Observer em cada componente, assinando todos os outros para receber cada mudança diretamente","Mediator, com um coordenador central que conhece as regras de interação entre os componentes","Iterator, percorrendo os componentes em ordem fixa para propagar cada mudança até o final","Template Method, com uma classe base que define a ordem de atualização dos componentes"]} answer={1} explanation="O Mediator faz cada componente falar só com o coordenador, que conhece as regras de interação." />
<Quiz question="Qual a diferença entre Template Method e Strategy?" options={["Os dois são sinônimos, pois ambos permitem trocar partes de um algoritmo em tempo de execução","Template Method varia passos por herança, e Strategy troca o algoritmo inteiro por composição","Strategy usa herança para variar passos de um esqueleto, e Template Method usa composição","Template Method serve para percorrer coleções, e Strategy serve para notificar observadores"]} answer={1} explanation="Template Method fixa o esqueleto na classe base e deixa subclasses preencherem passos; Strategy injeta um objeto com o algoritmo." />
</QuizSet>
