## O problema

Você tem um cliente HTTP interno, `ClienteHttp.get(url)`, usado por vários serviços. Agora surgem pedidos: o serviço de catálogo quer **cache**; o de pagamentos quer **retentativa** com backoff; todo mundo quer **log de latência**; o de relatórios quer cache **e** log, mas não retentativa.

Com herança, você acabaria com `ClienteComCache`, `ClienteComRetry`, `ClienteComCacheELog`, `ClienteComRetryELog`... uma explosão combinatória. E cada combinação seria fixa em tempo de compilação.

O **Decorator** resolve isso: cada comportamento extra vira um objeto que **tem a mesma interface** do cliente original e **embrulha** outro cliente. Você empilha os embrulhos que quiser, na ordem que quiser, em tempo de execução.

## Como funciona

Todos implementam a mesma interface `Cliente`. O componente concreto faz o trabalho real. Cada decorator guarda uma referência a outro `Cliente` (que pode ser o concreto ou outro decorator), faz algo antes e/ou depois e delega.

```text
          +-------------------------+
          | <<interface>> Cliente   |
          | + get(url) -> str       |
          +-------------------------+
             ^                  ^
             |                  |
  +----------------+    +---------------------------+
  | ClienteHttp    |    | ClienteDecorator          |
  | (faz a chamada)|    | - interno: Cliente  ------+---> (outro Cliente)
  +----------------+    +---------------------------+
                          ^          ^          ^
                          |          |          |
                    ComCache   ComRetentativa   ComLog

  Montagem em tempo de execução:
  ComLog( ComCache( ComRetentativa( ClienteHttp ) ) )
```

A chamada atravessa as camadas de fora para dentro e a resposta volta de dentro para fora, como numa cebola.

```python
import time
from abc import ABC, abstractmethod


class Cliente(ABC):
    @abstractmethod
    def get(self, url: str) -> str: ...


class ClienteHttp(Cliente):
    """Simula a rede: falha nas duas primeiras chamadas para /instavel."""

    def __init__(self):
        self.chamadas = 0

    def get(self, url):
        self.chamadas += 1
        if url.endswith("/instavel") and self.chamadas <= 2:
            raise ConnectionError("timeout")
        return f"conteúdo de {url}"


class ClienteDecorator(Cliente):
    def __init__(self, interno: Cliente):
        self._interno = interno

    def get(self, url):
        return self._interno.get(url)


class ComRetentativa(ClienteDecorator):
    def __init__(self, interno, tentativas=3, espera=0.01):
        super().__init__(interno)
        self._tentativas = tentativas
        self._espera = espera

    def get(self, url):
        for n in range(1, self._tentativas + 1):
            try:
                return self._interno.get(url)
            except ConnectionError:
                if n == self._tentativas:
                    raise
                time.sleep(self._espera * 2 ** (n - 1))  # backoff exponencial


class ComCache(ClienteDecorator):
    def __init__(self, interno):
        super().__init__(interno)
        self._cache = {}

    def get(self, url):
        if url not in self._cache:
            self._cache[url] = self._interno.get(url)
        return self._cache[url]


class ComLog(ClienteDecorator):
    def get(self, url):
        inicio = time.perf_counter()
        try:
            return self._interno.get(url)
        finally:
            ms = (time.perf_counter() - inicio) * 1000
            print(f"[log] GET {url} em {ms:.1f} ms")


if __name__ == "__main__":
    base = ClienteHttp()
    cliente = ComLog(ComCache(ComRetentativa(base)))
    print(cliente.get("https://api.loja/instavel"))
    print(cliente.get("https://api.loja/instavel"))  # vem do cache
    print("chamadas reais à rede:", base.chamadas)

    so_log = ComLog(ClienteHttp())
    print(so_log.get("https://api.loja/produtos"))
```

```java
import java.util.*;

interface Cliente {
    String get(String url) throws Exception;
}

// Simula a rede: falha nas duas primeiras chamadas para /instavel.
class ClienteHttp implements Cliente {
    int chamadas = 0;

    public String get(String url) throws Exception {
        chamadas += 1;
        if (url.endsWith("/instavel") && chamadas <= 2) {
            throw new Exception("timeout");
        }
        return "conteúdo de " + url;
    }
}

class ClienteDecorator implements Cliente {
    protected final Cliente interno;

    ClienteDecorator(Cliente interno) {
        this.interno = interno;
    }

    public String get(String url) throws Exception {
        return interno.get(url);
    }
}

class ComRetentativa extends ClienteDecorator {
    private final int tentativas;
    private final long espera;   // em milissegundos

    ComRetentativa(Cliente interno, int tentativas, long espera) {
        super(interno);
        this.tentativas = tentativas;
        this.espera = espera;
    }

    @Override
    public String get(String url) throws Exception {
        for (int n = 1; ; n++) {
            try {
                return interno.get(url);
            } catch (Exception e) {
                if (n == tentativas) throw e;
                Thread.sleep(espera * (1L << (n - 1)));   // backoff exponencial
            }
        }
    }
}

class ComCache extends ClienteDecorator {
    private final Map<String, String> cache = new HashMap<>();

    ComCache(Cliente interno) {
        super(interno);
    }

    @Override
    public String get(String url) throws Exception {
        if (!cache.containsKey(url)) {
            cache.put(url, interno.get(url));
        }
        return cache.get(url);
    }
}

class ComLog extends ClienteDecorator {
    ComLog(Cliente interno) {
        super(interno);
    }

    @Override
    public String get(String url) throws Exception {
        long inicio = System.nanoTime();
        try {
            return interno.get(url);
        } finally {
            double ms = (System.nanoTime() - inicio) / 1e6;
            System.out.println(String.format(Locale.US, "[log] GET %s em %.1f ms", url, ms));
        }
    }
}

public static void main(String[] args) throws Exception {
    ClienteHttp base = new ClienteHttp();
    Cliente cliente = new ComLog(new ComCache(new ComRetentativa(base, 3, 10)));
    System.out.println(cliente.get("https://api.loja/instavel"));
    System.out.println(cliente.get("https://api.loja/instavel"));  // vem do cache
    System.out.println("chamadas reais à rede: " + base.chamadas);

    Cliente soLog = new ComLog(new ClienteHttp());
    System.out.println(soLog.get("https://api.loja/produtos"));
}
```

```cpp
#include <chrono>
#include <iomanip>
#include <iostream>
#include <map>
#include <memory>
#include <stdexcept>
#include <string>
#include <thread>
using namespace std;

class Cliente {
public:
    virtual ~Cliente() = default;
    virtual string get(const string& url) = 0;
};

// Simula a rede: falha nas duas primeiras chamadas para /instavel.
class ClienteHttp : public Cliente {
public:
    int chamadas = 0;

    string get(const string& url) override {
        chamadas += 1;
        bool instavel = url.size() >= 9 && url.compare(url.size() - 9, 9, "/instavel") == 0;
        if (instavel && chamadas <= 2) {
            throw runtime_error("timeout");
        }
        return "conteúdo de " + url;
    }
};

class ClienteDecorator : public Cliente {
protected:
    Cliente& interno;

public:
    ClienteDecorator(Cliente& interno) : interno(interno) {}

    string get(const string& url) override {
        return interno.get(url);
    }
};

class ComRetentativa : public ClienteDecorator {
    int tentativas;
    int espera;   // em milissegundos

public:
    ComRetentativa(Cliente& interno, int tentativas = 3, int espera = 10)
        : ClienteDecorator(interno), tentativas(tentativas), espera(espera) {}

    string get(const string& url) override {
        for (int n = 1;; n++) {
            try {
                return interno.get(url);
            } catch (const runtime_error&) {
                if (n == tentativas) throw;
                this_thread::sleep_for(chrono::milliseconds(espera * (1 << (n - 1))));   // backoff exponencial
            }
        }
    }
};

class ComCache : public ClienteDecorator {
    map<string, string> cache;

public:
    ComCache(Cliente& interno) : ClienteDecorator(interno) {}

    string get(const string& url) override {
        if (!cache.count(url)) {
            cache[url] = interno.get(url);
        }
        return cache[url];
    }
};

class ComLog : public ClienteDecorator {
public:
    ComLog(Cliente& interno) : ClienteDecorator(interno) {}

    string get(const string& url) override {
        auto inicio = chrono::steady_clock::now();
        auto registrar = [&] {
            double ms = chrono::duration<double, milli>(chrono::steady_clock::now() - inicio).count();
            cout << "[log] GET " << url << " em " << fixed << setprecision(1) << ms << " ms" << endl;
        };
        try {
            string r = interno.get(url);
            registrar();
            return r;
        } catch (...) {
            registrar();
            throw;
        }
    }
};

int main() {
    ClienteHttp base;
    ComRetentativa comRetentativa(base);
    ComCache comCache(comRetentativa);
    ComLog cliente(comCache);
    cout << cliente.get("https://api.loja/instavel") << endl;
    cout << cliente.get("https://api.loja/instavel") << endl;  // vem do cache
    cout << "chamadas reais à rede: " << base.chamadas << endl;

    ClienteHttp outra;
    ComLog soLog(outra);
    cout << soLog.get("https://api.loja/produtos") << endl;
}
```

```go
import (
	"errors"
	"fmt"
	"strings"
	"time"
)

type Cliente interface {
	Get(url string) (string, error)
}

// Simula a rede: falha nas duas primeiras chamadas para /instavel.
type ClienteHttp struct {
	chamadas int
}

func (c *ClienteHttp) Get(url string) (string, error) {
	c.chamadas++
	if strings.HasSuffix(url, "/instavel") && c.chamadas <= 2 {
		return "", errors.New("timeout")
	}
	return "conteúdo de " + url, nil
}

// Em Go cada decorador é uma struct que embrulha outro Cliente.
type ComRetentativa struct {
	interno    Cliente
	tentativas int
	espera     time.Duration
}

func (r ComRetentativa) Get(url string) (string, error) {
	for n := 1; ; n++ {
		resposta, err := r.interno.Get(url)
		if err == nil {
			return resposta, nil
		}
		if n == r.tentativas {
			return "", err
		}
		time.Sleep(r.espera * time.Duration(1<<(n-1))) // backoff exponencial
	}
}

type ComCache struct {
	interno Cliente
	cache   map[string]string
}

func (c *ComCache) Get(url string) (string, error) {
	if _, ok := c.cache[url]; !ok {
		resposta, err := c.interno.Get(url)
		if err != nil {
			return "", err
		}
		c.cache[url] = resposta
	}
	return c.cache[url], nil
}

type ComLog struct {
	interno Cliente
}

func (l ComLog) Get(url string) (string, error) {
	inicio := time.Now()
	defer func() {
		ms := float64(time.Since(inicio).Microseconds()) / 1000
		fmt.Printf("[log] GET %s em %.1f ms\n", url, ms)
	}()
	return l.interno.Get(url)
}

func main() {
	base := &ClienteHttp{}
	var cliente Cliente = ComLog{&ComCache{ComRetentativa{base, 3, 10 * time.Millisecond}, map[string]string{}}}
	r, _ := cliente.Get("https://api.loja/instavel")
	fmt.Println(r)
	r, _ = cliente.Get("https://api.loja/instavel") // vem do cache
	fmt.Println(r)
	fmt.Println("chamadas reais à rede:", base.chamadas)

	soLog := ComLog{&ClienteHttp{}}
	r, _ = soLog.Get("https://api.loja/produtos")
	fmt.Println(r)
}
```

A ordem importa. Com `ComCache(ComRetentativa(...))`, as retentativas acontecem só quando o cache erra. Se você invertesse para `ComRetentativa(ComCache(...))`, o efeito seria o mesmo aqui, mas em outros casos (por exemplo, log dentro ou fora do retry) muda o que é medido: o log externo mede o tempo total com retentativas; o log interno mede cada tentativa.

<Callout type="note" title="E os decorators do Python?">
A sintaxe `@algo` do Python é um parente próximo: ela embrulha **funções**. O padrão Decorator do design orientado a objetos embrulha **objetos** que compartilham uma interface. A ideia é a mesma: acrescentar comportamento sem mudar o código original.
</Callout>

## Quando usar

- Adicionar responsabilidades transversais (cache, log, métricas, autorização, compressão, criptografia) sem tocar na classe original.
- Quando as combinações de comportamento variam por cliente ou por configuração.
- Quando você não pode ou não quer criar subclasses (classe final, código de terceiros).

## Quando evitar

- Se só existe uma combinação possível, uma única classe é mais simples.
- Pilhas profundas dificultam depuração: o stack trace fica cheio de camadas parecidas.
- Se o comportamento extra precisa acessar detalhes internos do objeto embrulhado, o decorator não serve, pois ele só enxerga a interface pública.
- Identidade: `isinstance(cliente, ClienteHttp)` deixa de funcionar quando o objeto está decorado. Código que depende do tipo concreto quebra.

## Padrões parecidos

- **Proxy**: mesma estrutura (embrulha algo com a mesma interface), intenção diferente. O proxy **controla o acesso** (adiar criação, checar permissão, chamar remotamente) e geralmente gerencia o ciclo de vida do objeto real. O decorator **acrescenta comportamento** e é montado pelo cliente, muitas vezes em camadas.
- **Composite**: também tem um objeto que referencia outros da mesma interface, mas com **vários** filhos e para representar hierarquias. O decorator tem exatamente **um** interno.
- **Chain of Responsibility**: cada elo pode **interromper** a cadeia e decidir não repassar. No decorator, a expectativa é sempre delegar.
- **Strategy**: troca o "miolo" do algoritmo; o decorator muda a "casca".

## Na entrevista

Decorator aparece com frequência em "projete um logger", "um rate limiter", "preço de uma pizza ou café com adicionais" e "pipeline de requisições". Mostre a interface comum, um concreto, a classe base de decorator e dois decorators. Perguntas de follow-up:

- **Por que não herança?** Explosão de subclasses e combinações fixas.
- **A ordem dos decorators importa?** Sim; dê um exemplo concreto, como log dentro ou fora do retry.
- **Como evitar montar a pilha à mão em todo lugar?** Use uma fábrica ou um builder que monta a pilha a partir da configuração.
