## O problema

Uma empresa importa extratos bancários de vários bancos. Todos seguem o mesmo roteiro: ler o arquivo, converter as linhas em transações, validar, remover duplicadas e salvar. O que muda é só o formato: um banco manda CSV com ponto e vírgula, outro manda um layout de largura fixa, outro manda JSON. Se cada importador for escrito do zero, o roteiro é copiado três vezes, e uma correção na deduplicação precisa ser feita em três lugares (e alguém sempre esquece um).

O Template Method **fixa o esqueleto de um algoritmo numa classe base** e deixa subclasses preencherem só os passos que variam. A ordem e as regras comuns ficam num único lugar; as partes específicas ficam nas subclasses.

## Estrutura

```text
+-----------------------------------+
|  ClasseBase (abstrata)            |
|-----------------------------------|
| + executar()   <- método template |   chama, em ordem:
|     passo_fixo_1()                |     - passos fixos (implementados aqui)
|     passo_variavel()   (abstrato) |     - passos abstratos (obrigatórios)
|     gancho()           (opcional) |     - ganchos (hooks) com padrão vazio
|     passo_fixo_2()                |
+-----------------------------------+
            ^                ^
            |                |
     SubclasseA          SubclasseB
  (implementa passos  (implementa passos
   variáveis)          variáveis e algum gancho)
```

Três tipos de passo:

- **Fixos**: a base implementa e as subclasses não devem mudar.
- **Abstratos**: obrigatórios, cada subclasse precisa fornecer.
- **Ganchos (hooks)**: opcionais, com implementação padrão vazia ou trivial, que a subclasse pode sobrescrever para se encaixar no fluxo.

import json
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List


@dataclass(frozen=True)
class Transacao:
    data: str
    descricao: str
    valor: float


class ImportadorExtrato(ABC):
    def importar(self, conteudo: str) -> List[Transacao]:
        """Método template: a ordem dos passos é definida aqui e só aqui."""
        conteudo = self.pre_processar(conteudo)
        brutas = self.extrair_registros(conteudo)
        transacoes = [self.converter(r) for r in brutas]
        validas = [t for t in transacoes if self._valida(t)]
        unicas = self._deduplicar(validas)
        self.apos_importar(unicas)
        return unicas

    # passos abstratos
    @abstractmethod
    def extrair_registros(self, conteudo: str) -> list: ...

    @abstractmethod
    def converter(self, registro) -> Transacao: ...

    # ganchos com comportamento padrão
    def pre_processar(self, conteudo: str) -> str:
        return conteudo.strip()

    def apos_importar(self, transacoes: List[Transacao]) -> None:
        pass

    # passos fixos
    def _valida(self, t: Transacao) -> bool:
        return t.valor != 0 and len(t.data) == 10

    def _deduplicar(self, transacoes: List[Transacao]) -> List[Transacao]:
        vistas, resultado = set(), []
        for t in transacoes:
            if t not in vistas:
                vistas.add(t)
                resultado.append(t)
        return resultado


class ImportadorCSV(ImportadorExtrato):
    def extrair_registros(self, conteudo):
        linhas = conteudo.splitlines()[1:]  # pula cabeçalho
        return [linha.split(";") for linha in linhas]

    def converter(self, registro):
        data, descricao, valor = registro
        return Transacao(data, descricao, float(valor.replace(",", ".")))

    const brutas = this.extrairRegistros(conteudo);

    return unicas;

  // passos abstratos
  protected abstract extrairRegistros(conteudo: string): R[];
  protected abstract converter(registro: R): Transacao;

  // ganchos com comportamento padrão
  protected preProcessar(conteudo: string): string {
    return conteudo.trim();
  }
  protected aposImportar(transacoes: Transacao[]): void {}

  // passos fixos
  private valida(t: Transacao): boolean {
    return t.valor !== 0 && t.data.length === 10;

  private deduplicar(transacoes: Transacao[]): Transacao[] {
    const vistas: { [chave: string]: boolean } = {};
    const resultado: Transacao[] = [];
    for (const t of transacoes) {
      if (!vistas[t.chave()]) {
        vistas[t.chave()] = true;
        resultado.push(t);
      }
    }
    return resultado;
  }
}

class Transacao {
    final String data;
    final String descricao;
    final double valor;

    Transacao(String data, String descricao, double valor) {
        this.data = data;
        this.descricao = descricao;
        this.valor = valor;
    }

    @Override public boolean equals(Object o) {
        if (!(o instanceof Transacao)) return false;
        Transacao t = (Transacao) o;
        return data.equals(t.data) && descricao.equals(t.descricao) && valor == t.valor;
    }

    @Override public int hashCode() { return Objects.hash(data, descricao, valor); }

    @Override public String toString() {
        return "Transacao(data='" + data + "', descricao='" + descricao + "', valor=" + valor + ")";
    }
}

abstract class ImportadorExtrato {
    final List<Transacao> importar(String conteudo) {

        if (fim < 0) fim = item.length();

        return bruto.startsWith("\"") ? bruto.substring(1, bruto.length() - 1) : bruto;

        return new Transacao(campo(item, "dt"), campo(item, "hist"), Double.parseDouble(campo(item, "vlr")));

struct Transacao {
    string data, descricao;
    double valor;

    bool operator<(const Transacao& o) const {
        return tie(data, descricao, valor) < tie(o.data, o.descricao, o.valor);
    }

    string str() const {
        ostringstream s;
        s << "Transacao(data='" << data << "', descricao='" << descricao << "', valor=" << valor << ")";
        return s.str();
    }
};

string aparar(const string& s) {
    size_t a = s.find_first_not_of(" \t\r\n");
    if (a == string::npos) return "";
    size_t b = s.find_last_not_of(" \t\r\n");
    return s.substr(a, b - a + 1);
}

vector<string> dividir(const string& s, char sep) {
    vector<string> partes;
    string atual;
    for (char c : s) {
        if (c == sep) { partes.push_back(atual); atual.clear(); }
        else atual += c;
    }
    partes.push_back(atual);
    return partes;
}

string fatia(const string& s, size_t de, size_t ate) {
    if (de >= s.size()) return "";
    return s.substr(de, min(ate, s.size()) - de);
}

class ImportadorExtrato {
public:
    virtual ~ImportadorExtrato() = default;

    // Método template: a ordem dos passos é definida aqui e só aqui.
    vector<Transacao> importar(string conteudo) {
        conteudo = preProcessar(conteudo);
        auto brutas = extrairRegistros(conteudo);
        vector<Transacao> validas;
        for (const auto& r : brutas) {
            Transacao t = converter(r);
            if (valida(t)) validas.push_back(t);
        }
        vector<Transacao> unicas;
        set<Transacao> vistas;
        for (const auto& t : validas) {
            if (vistas.insert(t).second) unicas.push_back(t);
        }
        aposImportar(unicas);
        return unicas;
    }

protected:
    // passos abstratos
    virtual vector<vector<string>> extrairRegistros(const string& conteudo) = 0;
    virtual Transacao converter(const vector<string>& registro) = 0;

    // ganchos com comportamento padrão
    virtual string preProcessar(const string& conteudo) { return aparar(conteudo); }
    virtual void aposImportar(const vector<Transacao>&) {}

private:
    // passos fixos
    bool valida(const Transacao& t) const { return t.valor != 0 && t.data.size() == 10; }
};

class ImportadorCSV : public ImportadorExtrato {
protected:
    vector<vector<string>> extrairRegistros(const string& conteudo) override {
        vector<vector<string>> registros;
        auto linhas = dividir(conteudo, '\n');
        for (size_t i = 1; i < linhas.size(); i++) registros.push_back(dividir(linhas[i], ';')); // pula cabeçalho
        return registros;
    }
    Transacao converter(const vector<string>& r) override {
        string valor = r[2];
        for (auto& c : valor) if (c == ',') c = '.';
        return {r[0], r[1], stod(valor)};
    }
};

class ImportadorLarguraFixa : public ImportadorExtrato {
    // colunas: data 0-9, descrição 10-29, valor 30-39
protected:

        vector<vector<string>> registros;
        for (const auto& linha : dividir(conteudo, '\n')) registros.push_back({linha});
        return registros;

// Para o exemplo, um extrator mínimo que lê campos simples de cada objeto do array.
class ImportadorJSON : public ImportadorExtrato {
public:
    string relatorio;

protected:
    string preProcessar(const string& conteudo) override {
        // este banco envia um BOM no início do arquivo
        string c = conteudo;
        while (c.compare(0, 3, "\xEF\xBB\xBF") == 0) c = c.substr(3);
        return aparar(c);
    }

    vector<vector<string>> extrairRegistros(const string& conteudo) override {
        vector<vector<string>> itens;
        size_t pos = conteudo.find('[');
        while (true) {
            size_t ini = conteudo.find('{', pos);
            if (ini == string::npos) break;
            size_t fim = conteudo.find('}', ini);
            string item = conteudo.substr(ini + 1, fim - ini - 1);
            itens.push_back({campo(item, "dt"), campo(item, "hist"), campo(item, "vlr")});
            pos = fim;
        }
        return itens;
    }

    Transacao converter(const vector<string>& r) override { return {r[0], r[1], stod(r[2])}; }

    void aposImportar(const vector<Transacao>& transacoes) override {
        relatorio = to_string(transacoes.size()) + " lançamentos importados via JSON";
    }

private:
    static string campo(const string& item, const string& chave) {
        size_t i = item.find("\"" + chave + "\"");
        size_t dois = item.find(':', i) + 1;
        size_t fim = item.find(',', dois);
        if (fim == string::npos) fim = item.size();
        string bruto = aparar(item.substr(dois, fim - dois));
        if (!bruto.empty() && bruto[0] == '"') bruto = bruto.substr(1, bruto.size() - 2);
        return bruto;
    }
};

abstract class ImportadorExtrato
{
    // Método template: a ordem dos passos é definida aqui e só aqui.
    public List<Transacao> Importar(string conteudo)
    {
        conteudo = PreProcessar(conteudo);
        var brutas = ExtrairRegistros(conteudo);
        var validas = brutas.Select(r => Converter(r)).Where(t => Valida(t)).ToList();
        var vistas = new HashSet<Transacao>();
        var unicas = new List<Transacao>();
        foreach (var t in validas)
        {
            if (vistas.Add(t)) unicas.Add(t);
        }
        AposImportar(unicas);
        return unicas;
    }

    // passos abstratos
    protected abstract List<string[]> ExtrairRegistros(string conteudo);
    protected abstract Transacao Converter(string[] registro);

    // ganchos com comportamento padrão
    protected virtual string PreProcessar(string conteudo) { return conteudo.Trim(); }
    protected virtual void AposImportar(List<Transacao> transacoes) { }

    // passos fixos
    private bool Valida(Transacao t) { return t.Valor != 0 && t.Data.Length == 10; }

    protected static string Fatia(string s, int de, int ate)
    {
        de = Math.Min(de, s.Length);
        ate = Math.Min(ate, s.Length);
        return s.Substring(de, ate - de);
    }
}

    }

    protected override Transacao Converter(string[] r)

class ImportadorJSON : ImportadorExtrato
{
    public string Relatorio = "";

    protected override string PreProcessar(string conteudo)
    {
        // este banco envia um BOM no início do arquivo
        return conteudo.TrimStart('\uFEFF').Trim();
    }

    protected override List<string[]> ExtrairRegistros(string conteudo)
    {
        var itens = new List<string[]>();
        int pos = conteudo.IndexOf('[');
        while (true)
        {
            int ini = conteudo.IndexOf('{', pos);
            if (ini < 0) break;
            int fim = conteudo.IndexOf('}', ini);
            string item = conteudo.Substring(ini + 1, fim - ini - 1);
            itens.Add(new[] { Campo(item, "dt"), Campo(item, "hist"), Campo(item, "vlr") });
            pos = fim;
        }
        return itens;
    }

    private static string Campo(string item, string chave)
    {
        int i = item.IndexOf("\"" + chave + "\"");
        int dois = item.IndexOf(':', i) + 1;
        int fim = item.IndexOf(',', dois);
        if (fim < 0) fim = item.Length;
        string bruto = item.Substring(dois, fim - dois).Trim();
        return bruto.StartsWith("\"") ? bruto.Substring(1, bruto.Length - 2) : bruto;
    }

    protected override Transacao Converter(string[] r)
    {
        return new Transacao(r[0], r[1], double.Parse(r[2], CultureInfo.InvariantCulture));
    }

    protected override void AposImportar(List<Transacao> transacoes)
    {
        Relatorio = transacoes.Count + " lançamentos importados via JSON";
    }
}

}

// Passos que cada importador precisa fornecer (Go não tem herança: o "template" é uma função)
type Passos interface {
	ExtrairRegistros(conteudo string) [][]string
	Converter(registro []string) Transacao
	PreProcessar(conteudo string) string
	AposImportar(transacoes []Transacao)
}

// Base dá o comportamento padrão dos ganchos; os importadores a embutem
type Base struct{}

func (Base) PreProcessar(conteudo string) string { return strings.TrimSpace(conteudo) }
func (Base) AposImportar([]Transacao)            {}

// Método template: a ordem dos passos é definida aqui e só aqui.
func Importar(p Passos, conteudo string) []Transacao {
	conteudo = p.PreProcessar(conteudo)
	brutas := p.ExtrairRegistros(conteudo)
	vistas := map[Transacao]bool{}
	unicas := []Transacao{}
	for _, r := range brutas {
		t := p.Converter(r)
		if t.Valor == 0 || len(t.Data) != 10 { // passo fixo: validar
			continue
		}
		if !vistas[t] { // passo fixo: deduplicar
			vistas[t] = true
			unicas = append(unicas, t)
		}
	}
	p.AposImportar(unicas)
	return unicas
}

func fatia(s string, de, ate int) string {
	if de > len(s) {
		de = len(s)
	}
	if ate > len(s) {
		ate = len(s)
	}
	return s[de:ate]
}

## Quando usar e quando evitar

**Use quando:**

- Vários algoritmos compartilham a mesma sequência de passos e diferem em detalhes.
- Você precisa garantir que certos passos sempre aconteçam, na ordem certa (validação, auditoria, liberação de recursos).
- Frameworks: o framework controla o fluxo e chama seus métodos nos pontos certos. É o "princípio de Hollywood": não nos chame, nós chamamos você.

**Evite quando:**

- As variações são muitas e combináveis (formato x destino x validação). Herança vira explosão de subclasses; prefira compor estratégias.
- A subclasse precisa mudar a ordem dos passos. Isso indica que o esqueleto não é realmente comum.

<Callout type="warning" title="Herança é acoplamento forte">
Subclasses de Template Method dependem dos detalhes da base. Uma mudança na ordem dos passos da base pode quebrar subclasses que assumiam outra ordem. Mantenha o método template estável e documente o contrato de cada passo.
</Callout>

## Padrões parecidos

| Padrão | Diferença |
| --- | --- |
| Strategy | Varia o algoritmo inteiro por **composição**, em tempo de execução. Template Method varia partes do algoritmo por **herança**, em tempo de definição da classe. Dá para converter um no outro: cada passo abstrato pode virar uma estratégia injetada. |
| Factory Method | Frequentemente é um dos passos de um Template Method: o esqueleto chama um método abstrato que cria um objeto. |
| Builder | Também tem etapas, mas o objetivo é construir um objeto, e quem decide a ordem é o cliente (ou um diretor). |

## Na entrevista

- Cite em geradores de relatórios (PDF, CSV, HTML), processadores de pagamento (validar, autorizar, capturar, notificar), pipelines de ETL e jogos de tabuleiro (inicializar, loop de turnos, verificar fim).
- Mostre que sabe a diferença entre passo abstrato e gancho; é um detalhe que impressiona.
- Follow-ups: "e se surgirem muitas combinações?" (migrar para Strategy), "como impedir que a subclasse sobrescreva o método template?" (em Java, `final`; em Python, convenção, documentação e testes).
