## O problema

Você tem um processo de exportação de relatórios financeiros: buscar os lançamentos do mês, formatar e salvar. O fluxo é sempre o mesmo, mas o **formato** muda: CSV para o contador, JSON para a integração com o ERP, texto alinhado para quem lê no terminal. Se o código do fluxo fizer `CsvFormatador()` diretamente, ele fica preso a uma classe concreta, e cada formato novo exige mexer no fluxo.

O **Factory Method** define um método responsável por criar o objeto, e deixa que **subclasses decidam qual classe concreta instanciar**. O código que usa o objeto depende só da interface do produto.

## Estrutura

```text
        +-------------------------------+           +---------------------+
        |   ExportadorDeRelatorio (abs) |  cria     |  Formatador (abs)   |
        +-------------------------------+---------->+---------------------+
        | + exportar(lancamentos): str  |           | + cabecalho(): str  |
        | # criar_formatador() (abstr.) |           | + linha(l): str     |
        +-------------------------------+           +---------------------+
             ^             ^                            ^            ^
             |             |                            |            |
 +-------------------+ +-------------------+   +-------------+ +--------------+
 | ExportadorCsv     | | ExportadorJson    |   | FormatCsv   | | FormatJson   |
 | criar_formatador()| | criar_formatador()|   +-------------+ +--------------+
 |  -> FormatCsv     | |  -> FormatJson    |
 +-------------------+ +-------------------+

 exportar() é o algoritmo fixo; criar_formatador() é o "gancho" de criação.
```

Papéis: **Produto** (`Formatador`), **Produtos concretos**, **Criador** (`ExportadorDeRelatorio`, que contém lógica de negócio e declara o método fábrica) e **Criadores concretos**.

```python
import json
from abc import ABC, abstractmethod
from dataclasses import dataclass


@dataclass(frozen=True)
class Lancamento:
    data: str
    descricao: str
    valor: float


class Formatador(ABC):
    @abstractmethod
    def formatar(self, lancamentos: list[Lancamento]) -> str: ...


class FormatadorCsv(Formatador):
    def formatar(self, lancamentos):
        linhas = ["data;descricao;valor"]
        linhas += [f"{l.data};{l.descricao};{l.valor:.2f}".replace(".", ",") for l in lancamentos]
        return "\n".join(linhas)


class FormatadorJson(Formatador):
    def formatar(self, lancamentos):
        return json.dumps([l.__dict__ for l in lancamentos], ensure_ascii=False)


class FormatadorTerminal(Formatador):
    def formatar(self, lancamentos):
        return "\n".join(f"{l.data}  {l.descricao:<20}{l.valor:>10.2f}" for l in lancamentos)


class ExportadorDeRelatorio(ABC):
    """Criador: tem a regra de negócio e delega a criação ao método fábrica."""

    @abstractmethod
    def criar_formatador(self) -> Formatador: ...

    def exportar(self, lancamentos: list[Lancamento]) -> str:
        validos = [l for l in lancamentos if l.valor != 0]
        ordenados = sorted(validos, key=lambda l: l.data)
        formatador = self.criar_formatador()        # o ponto de variação
        conteudo = formatador.formatar(ordenados)
        total = sum(l.valor for l in ordenados)
        return f"{conteudo}\n-- {len(ordenados)} lançamentos, saldo {total:.2f}"


class ExportadorContador(ExportadorDeRelatorio):
    def criar_formatador(self):
        return FormatadorCsv()


class ExportadorErp(ExportadorDeRelatorio):
    def criar_formatador(self):
        return FormatadorJson()


class ExportadorTerminal(ExportadorDeRelatorio):
    def criar_formatador(self):
        return FormatadorTerminal()


mes = [
    Lancamento("2026-10-05", "Aluguel", -3200.0),
    Lancamento("2026-10-01", "Venda #551", 1890.5),
    Lancamento("2026-10-03", "Estorno zerado", 0.0),
    Lancamento("2026-10-10", "Venda #560", 4100.0),
]

for exportador in (ExportadorContador(), ExportadorErp(), ExportadorTerminal()):
    print(f"== {type(exportador).__name__}")
    print(exportador.exportar(mes))
```

```java
import java.util.*;
import java.util.stream.*;

class Lancamento {
    final String data, descricao;
    final double valor;

    Lancamento(String data, String descricao, double valor) {
        this.data = data;
        this.descricao = descricao;
        this.valor = valor;
    }
}

interface Formatador {
    String formatar(List<Lancamento> lancamentos);
}

class FormatadorCsv implements Formatador {
    public String formatar(List<Lancamento> lancamentos) {
        List<String> linhas = new ArrayList<>();
        linhas.add("data;descricao;valor");
        for (Lancamento l : lancamentos) {
            linhas.add(String.format(Locale.US, "%s;%s;%.2f", l.data, l.descricao, l.valor).replace(".", ","));
        }
        return String.join("\n", linhas);
    }
}

class FormatadorJson implements Formatador {
    public String formatar(List<Lancamento> lancamentos) {
        return lancamentos.stream()
            .map(l -> "{\"data\": \"" + l.data + "\", \"descricao\": \"" + l.descricao + "\", \"valor\": " + l.valor + "}")
            .collect(Collectors.joining(", ", "[", "]"));
    }
}

class FormatadorTerminal implements Formatador {
    public String formatar(List<Lancamento> lancamentos) {
        return lancamentos.stream()
            .map(l -> String.format(Locale.US, "%s  %-20s%10.2f", l.data, l.descricao, l.valor))
            .collect(Collectors.joining("\n"));
    }
}

// Criador: tem a regra de negócio e delega a criação ao método fábrica.
abstract class ExportadorDeRelatorio {
    abstract Formatador criarFormatador();

    String exportar(List<Lancamento> lancamentos) {
        List<Lancamento> ordenados = lancamentos.stream()
            .filter(l -> l.valor != 0)
            .sorted(Comparator.comparing(l -> l.data))
            .collect(Collectors.toList());
        Formatador formatador = criarFormatador();   // o ponto de variação
        String conteudo = formatador.formatar(ordenados);
        double total = ordenados.stream().mapToDouble(l -> l.valor).sum();
        return String.format(Locale.US, "%s\n-- %d lançamentos, saldo %.2f", conteudo, ordenados.size(), total);
    }
}

class ExportadorContador extends ExportadorDeRelatorio {
    Formatador criarFormatador() { return new FormatadorCsv(); }
}

class ExportadorErp extends ExportadorDeRelatorio {
    Formatador criarFormatador() { return new FormatadorJson(); }
}

class ExportadorTerminal extends ExportadorDeRelatorio {
    Formatador criarFormatador() { return new FormatadorTerminal(); }
}

public static void main(String[] args) {
    List<Lancamento> mes = List.of(
        new Lancamento("2026-10-05", "Aluguel", -3200.0),
        new Lancamento("2026-10-01", "Venda #551", 1890.5),

    }
}
```

```cpp
#include <algorithm>

struct Lancamento {

    double valor;

string duasCasas(double v) {
    ostringstream s;
    s << fixed << setprecision(2) << v;
    return s.str();
}

class Formatador {
public:
    virtual ~Formatador() = default;
    virtual string formatar(const vector<Lancamento>& lancamentos) const = 0;
};

class FormatadorCsv : public Formatador {
public:
    string formatar(const vector<Lancamento>& lancamentos) const override {
        string saida = "data;descricao;valor";
        for (const auto& l : lancamentos) {
            string linha = l.data + ";" + l.descricao + ";" + duasCasas(l.valor);
            replace(linha.begin(), linha.end(), '.', ',');
            saida += "\n" + linha;
        }
        return saida;
    }
};

class FormatadorJson : public Formatador {
public:
    string formatar(const vector<Lancamento>& lancamentos) const override {
        string saida = "[";
        for (size_t i = 0; i < lancamentos.size(); i++) {
            const auto& l = lancamentos[i];
            ostringstream valor;
            valor << l.valor;
            saida += string(i ? ", " : "") + "{\"data\": \"" + l.data + "\", \"descricao\": \"" + l.descricao + "\", \"valor\": " + valor.str() + "}";
        }
        return saida + "]";
    }
};

class FormatadorTerminal : public Formatador {
public:
    string formatar(const vector<Lancamento>& lancamentos) const override {
        ostringstream saida;
        for (size_t i = 0; i < lancamentos.size(); i++) {
            const auto& l = lancamentos[i];
            saida << (i ? "\n" : "") << l.data << "  " << left << setw(20) << l.descricao << right << setw(10) << duasCasas(l.valor);
        }
        return saida.str();
    }
};

// Criador: tem a regra de negócio e delega a criação ao método fábrica.
class ExportadorDeRelatorio {
public:
    virtual ~ExportadorDeRelatorio() = default;
    virtual unique_ptr<Formatador> criarFormatador() const = 0;
    virtual string nome() const = 0;

    string exportar(const vector<Lancamento>& lancamentos) const {
        vector<Lancamento> ordenados;
        for (const auto& l : lancamentos) if (l.valor != 0) ordenados.push_back(l);
        sort(ordenados.begin(), ordenados.end(), [](const auto& a, const auto& b) { return a.data < b.data; });
        auto formatador = criarFormatador();   // o ponto de variação
        string conteudo = formatador->formatar(ordenados);
        double total = 0;
        for (const auto& l : ordenados) total += l.valor;
        return conteudo + "\n-- " + to_string(ordenados.size()) + " lançamentos, saldo " + duasCasas(total);
    }
};

class ExportadorContador : public ExportadorDeRelatorio {
public:
    unique_ptr<Formatador> criarFormatador() const override { return make_unique<FormatadorCsv>(); }
    string nome() const override { return "ExportadorContador"; }
};

class ExportadorErp : public ExportadorDeRelatorio {
public:
    unique_ptr<Formatador> criarFormatador() const override { return make_unique<FormatadorJson>(); }
    string nome() const override { return "ExportadorErp"; }
};

class ExportadorTerminal : public ExportadorDeRelatorio {
public:
    unique_ptr<Formatador> criarFormatador() const override { return make_unique<FormatadorTerminal>(); }
    string nome() const override { return "ExportadorTerminal"; }
};

int main() {
    vector<Lancamento> mes = {
        {"2026-10-05", "Aluguel", -3200.0},
        {"2026-10-01", "Venda #551", 1890.5},
        {"2026-10-03", "Estorno zerado", 0.0},
        {"2026-10-10", "Venda #560", 4100.0},
    };

    vector<unique_ptr<ExportadorDeRelatorio>> exportadores;
    exportadores.push_back(make_unique<ExportadorContador>());
    exportadores.push_back(make_unique<ExportadorErp>());
    exportadores.push_back(make_unique<ExportadorTerminal>());
    for (const auto& exportador : exportadores) {
        cout << "== " << exportador->nome() << endl;
        cout << exportador->exportar(mes) << endl;
    }
}
```

```go
import (
	"fmt"
	"sort"
	"strings"
)

type Lancamento struct {
	data      string
	descricao string
	valor     float64
}

type Formatador interface {
	formatar(lancamentos []Lancamento) string
}

type FormatadorCsv struct{}

func (FormatadorCsv) formatar(lancamentos []Lancamento) string {
	linhas := []string{"data;descricao;valor"}
	for _, l := range lancamentos {
		linhas = append(linhas, strings.ReplaceAll(fmt.Sprintf("%s;%s;%.2f", l.data, l.descricao, l.valor), ".", ","))
	}
	return strings.Join(linhas, "\n")
}

type FormatadorJson struct{}

func (FormatadorJson) formatar(lancamentos []Lancamento) string {
	itens := []string{}
	for _, l := range lancamentos {
		itens = append(itens, fmt.Sprintf(`{"data": "%s", "descricao": "%s", "valor": %v}`, l.data, l.descricao, l.valor))
	}
	return "[" + strings.Join(itens, ", ") + "]"
}

type FormatadorTerminal struct{}

func (FormatadorTerminal) formatar(lancamentos []Lancamento) string {
	linhas := []string{}
	for _, l := range lancamentos {
		linhas = append(linhas, fmt.Sprintf("%s  %-20s%10.2f", l.data, l.descricao, l.valor))
	}
	return strings.Join(linhas, "\n")
}

// Criador: tem a regra de negócio e delega a criação ao método fábrica.
// Go não tem herança: a regra recebe a "fábrica" como função.
type Exportador struct {
	nome            string
	criarFormatador func() Formatador
}

func (e Exportador) exportar(lancamentos []Lancamento) string {
	ordenados := []Lancamento{}
	for _, l := range lancamentos {
		if l.valor != 0 {
			ordenados = append(ordenados, l)
		}
	}
	sort.Slice(ordenados, func(i, j int) bool { return ordenados[i].data < ordenados[j].data })
	formatador := e.criarFormatador() // o ponto de variação
	conteudo := formatador.formatar(ordenados)
	total := 0.0
	for _, l := range ordenados {
		total += l.valor
	}
	return fmt.Sprintf("%s\n-- %d lançamentos, saldo %.2f", conteudo, len(ordenados), total)
}

func main() {
	mes := []Lancamento{
		{"2026-10-05", "Aluguel", -3200.0},
		{"2026-10-01", "Venda #551", 1890.5},
		{"2026-10-03", "Estorno zerado", 0.0},
		{"2026-10-10", "Venda #560", 4100.0},
	}

	for _, exportador := range []Exportador{
		{"ExportadorContador", func() Formatador { return FormatadorCsv{} }},
		{"ExportadorErp", func() Formatador { return FormatadorJson{} }},

	} {

	}
}
```

### A variante mais comum: fábrica simples com registro

Em Python, muitas vezes a escolha da classe depende de um valor em tempo de execução (configuração, campo de uma requisição). Nesse caso, um dicionário de classes resolve sem herança. Tecnicamente isso é uma **Simple Factory**, não o Factory Method clássico, mas é o que você mais vai usar:

<CodeTabs>

```python
class Formatador:
    def formatar(self, itens: list[str]) -> str:
        raise NotImplementedError


class Csv(Formatador):
    def formatar(self, itens):
        return ";".join(itens)


class Markdown(Formatador):
    def formatar(self, itens):
        return "\n".join(f"- {i}" for i in itens)
```

```cpp
public:
    string formatar(const vector<string>& itens) const override {

        for (size_t i = 0; i < itens.size(); i++) saida += (i ? ";" : "") + itens[i];
        return saida;
    }

public:
    string formatar(const vector<string>& itens) const override {
        string saida;
        for (size_t i = 0; i < itens.size(); i++) saida += string(i ? "\n" : "") + "- " + itens[i];
        return saida;
    }
};

map<string, function<unique_ptr<Formatador>()>>& registro() {
    static map<string, function<unique_ptr<Formatador>()>> r;
    return r;
}

void registrar(const string& nome, function<unique_ptr<Formatador>()> fabrica) {
    registro()[nome] = fabrica;
}

unique_ptr<Formatador> criarFormatador(const string& nome) {
    auto it = registro().find(nome);
    if (it == registro().end()) {
        string opcoes;
        for (const auto& [chave, f] : registro()) opcoes += (opcoes.empty() ? "" : ", ") + chave;
        throw invalid_argument("formato não suportado: " + nome + ". Opções: [" + opcoes + "]");
    }
    return it->second();
}
```

```go
import (
	"fmt"
	"sort"
	"strings"
)

type Formatador interface {
	formatar(itens []string) string
}

type Csv struct{}

func (Csv) formatar(itens []string) string { return strings.Join(itens, ";") }

type Markdown struct{}

func (Markdown) formatar(itens []string) string {
	linhas := []string{}
	for _, i := range itens {
		linhas = append(linhas, "- "+i)
	}
	return strings.Join(linhas, "\n")
}

var registro = map[string]func() Formatador{}

func registrar(nome string, fabrica func() Formatador) {
	registro[nome] = fabrica
}

func criarFormatador(nome string) (Formatador, error) {
	fabrica, ok := registro[nome]
	if !ok {
		opcoes := []string{}
		for chave := range registro {
			opcoes = append(opcoes, chave)
		}
		sort.Strings(opcoes)
		return nil, fmt.Errorf("formato não suportado: %s. Opções: [%s]", nome, strings.Join(opcoes, ", "))
	}
	return fabrica(), nil
}

func main() {
	registrar("csv", func() Formatador { return Csv{} })
	registrar("md", func() Formatador { return Markdown{} })

	itens := []string{"boleto", "pix", "cartão"}
	md, _ := criarFormatador("md")
	fmt.Println(md.formatar(itens))
	csv, _ := criarFormatador("csv")
	fmt.Println(csv.formatar(itens))
	if _, erro := criarFormatador("xlsx"); erro != nil {
		fmt.Println(erro)
	}
}
```

## Quando usar e quando evitar

| Use quando | Evite quando |
| --- | --- |
| Um algoritmo fixo precisa de um objeto cuja classe varia | Existe uma única implementação e nenhuma previsão de outra |
| Frameworks: você quer que o usuário estenda e escolha o produto | A escolha é trivial e um parâmetro de classe resolve |
| Você quer isolar `import`s e construções caras de quem usa | A hierarquia de criadores cresceria só para espelhar a de produtos sem nenhuma lógica comum |

## Padrões parecidos

- **Simple Factory:** uma função ou classe com um `if`/dicionário que decide o que criar. Não usa herança. É o primo informal.
- **Abstract Factory:** cria **famílias** de produtos relacionados (vários métodos fábrica num objeto). O Factory Method cria **um** produto e vive dentro de um criador que tem outra responsabilidade.
- **Template Method:** o Factory Method frequentemente é um passo de um Template Method, como em `exportar()`. A diferença é a intenção: Template Method varia passos de um algoritmo; Factory Method varia a criação.

## Na entrevista

Use quando o enunciado fala em "vários tipos de X" que precisam ser criados a partir de um dado (tipo de veículo no estacionamento, tipo de notificação, tipo de pagamento). Mostre a interface do produto primeiro e a fábrica depois. Follow-ups comuns:

- "Como adicionar um tipo novo sem alterar a fábrica?" Registro de classes ou subclasse de criador.
- "Qual a diferença para Abstract Factory?" Um produto versus uma família de produtos compatíveis.
- "Onde validar o tipo desconhecido?" Na fábrica, com erro claro listando as opções.
