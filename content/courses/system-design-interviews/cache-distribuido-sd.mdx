Aqui o pedido é construir o cache, não usá-lo: um armazenamento chave-valor em memória que escala horizontalmente, tolera falhas de nós e responde em menos de um milissegundo. É a base do que Redis e Memcached resolvem.

## Requisitos

### Funcionais

- `GET`, `SET` e `DELETE` por chave, com TTL opcional.
- Eviction quando a memória enche.
- Escalar adicionando nós.

### Não funcionais

- Latência abaixo de 1 ms, centenas de milhares de operações por segundo por nó.
- Alta disponibilidade; perder dados do cache é aceitável, indisponibilidade não.
- Rebalanceamento com o mínimo de chaves movidas.

## Estimativas

- 1 TB de dados quentes, nós de 64 GB utilizáveis: cerca de **16 nós**, mais réplicas.
- 1 milhão de operações por segundo / 100 mil por nó = 10 nós no mínimo; a memória costuma ser o limite.

## Arquitetura

```text
 cliente (lib com mapa do cluster) --hash(chave)--> nó A | nó B | nó C
                                                       |      |      |
                                                   réplica réplica réplica
```

**Particionamento: consistent hashing.** As chaves e os nós são mapeados num anel. Cada chave pertence ao próximo nó no sentido horário. Adicionar ou remover um nó move só uma fração (1/N) das chaves. Nós virtuais (vários pontos do anel por nó físico) equilibram a carga.

**Roteamento.** O cliente conhece a topologia (via biblioteca ou serviço de configuração) e fala direto com o nó, evitando um salto extra. Alternativa: um proxy.

**Armazenamento no nó.** Tabela hash em memória mais uma estrutura de eviction. LRU clássico usa hash mais lista duplamente ligada: acesso e atualização em tempo constante.

```python
class LRU:
    def __init__(self, capacidade):
        self.cap, self.dados = capacidade, {}  # dict preserva ordem de inserção

    def get(self, k):
        if k not in self.dados:
            return None
        v = self.dados.pop(k)
        self.dados[k] = v          # move para o fim (mais recente)
        return v

    def put(self, k, v):
        self.dados.pop(k, None)
        self.dados[k] = v
        if len(self.dados) > self.cap:
            self.dados.pop(next(iter(self.dados)))  # remove o mais antigo
```

```java
import java.util.*;

class LRU<K, V> {
    private final int cap;
    private final LinkedHashMap<K, V> dados = new LinkedHashMap<>();   // preserva a ordem de inserção

    LRU(int capacidade) {
        this.cap = capacidade;
    }

    V get(K k) {
        if (!dados.containsKey(k)) {
            return null;
        }
        V v = dados.remove(k);
        dados.put(k, v);                       // move para o fim (mais recente)
        return v;
    }

    void put(K k, V v) {
        dados.remove(k);
        dados.put(k, v);
        if (dados.size() > cap) {
            dados.remove(dados.keySet().iterator().next());   // remove o mais antigo
        }
    }
}
```

```cpp
#include <list>
#include <optional>
#include <unordered_map>
#include <utility>
using namespace std;

template <typename K, typename V>
class LRU {
    size_t cap;
    list<pair<K, V>> ordem;   // frente = mais recente, fundo = mais antigo
    unordered_map<K, typename list<pair<K, V>>::iterator> indice;

public:
    LRU(size_t capacidade) : cap(capacidade) {}

    optional<V> get(const K& k) {
        auto it = indice.find(k);
        if (it == indice.end()) {
            return nullopt;
        }
        ordem.splice(ordem.begin(), ordem, it->second);   // move para a frente (mais recente)
        return it->second->second;
    }

    void put(const K& k, const V& v) {
        auto it = indice.find(k);
        if (it != indice.end()) {
            ordem.erase(it->second);
        }
        ordem.push_front({k, v});
        indice[k] = ordem.begin();
        if (ordem.size() > cap) {
            indice.erase(ordem.back().first);             // remove o mais antigo
            ordem.pop_back();
        }
    }
};
```

```csharp
using System.Collections.Generic;

class LRU<K, V>
{
    private readonly int cap;
    private readonly LinkedList<KeyValuePair<K, V>> ordem = new LinkedList<KeyValuePair<K, V>>();   // início = mais recente
    private readonly Dictionary<K, LinkedListNode<KeyValuePair<K, V>>> indice = new Dictionary<K, LinkedListNode<KeyValuePair<K, V>>>();

    public LRU(int capacidade)
    {
        cap = capacidade;
    }

    public bool TryGet(K k, out V v)
    {
        if (!indice.TryGetValue(k, out var no))
        {
            v = default(V);
            return false;
        }
        ordem.Remove(no);
        ordem.AddFirst(no);                // move para o início (mais recente)
        v = no.Value.Value;
        return true;
    }

    public void Put(K k, V v)
    {
        if (indice.TryGetValue(k, out var existente))
        {
            ordem.Remove(existente);
            indice.Remove(k);
        }
        indice[k] = ordem.AddFirst(new KeyValuePair<K, V>(k, v));
        if (ordem.Count > cap)
        {
            var maisAntigo = ordem.Last;   // remove o mais antigo
            ordem.RemoveLast();
            indice.Remove(maisAntigo.Value.Key);
        }
    }
}
```

```go
import "container/list"

type entrada struct {
	chave string
	valor int
}

type LRU struct {
	cap    int
	ordem  *list.List // frente = mais recente, fundo = mais antigo
	indice map[string]*list.Element
}

func novoLRU(capacidade int) *LRU {
	return &LRU{cap: capacidade, ordem: list.New(), indice: map[string]*list.Element{}}
}

func (c *LRU) get(k string) (int, bool) {
	el, ok := c.indice[k]
	if !ok {
		return 0, false
	}
	c.ordem.MoveToFront(el) // move para a frente (mais recente)
	return el.Value.(entrada).valor, true
}

func (c *LRU) put(k string, v int) {
	if el, ok := c.indice[k]; ok {
		c.ordem.Remove(el)
	}
	c.indice[k] = c.ordem.PushFront(entrada{k, v})
	if c.ordem.Len() > c.cap {
		maisAntigo := c.ordem.Back() // remove o mais antigo
		c.ordem.Remove(maisAntigo)
		delete(c.indice, maisAntigo.Value.(entrada).chave)
	}
}
```

**Replicação.** Primário com réplicas assíncronas; se o primário falha, uma réplica é promovida. Aceita-se perder as últimas escritas.

**Expiração.** Lazy (checar o TTL ao ler) mais varredura periódica amostral para liberar chaves nunca lidas.

## Pontos críticos

- **Hot key:** uma chave muito lida sobrecarrega um nó. Replique leituras da chave, ou use um cache local pequeno no cliente.
- **Stampede:** quando uma chave popular expira, muitos clientes recarregam juntos. Use lock de recarga, TTL com jitter ou atualização antecipada.
- **Consistência com o banco:** o cache é secundário. Invalide ou atualize na escrita; aceite janela de inconsistência.

<Callout type="tip" title="Consistent hashing com nós virtuais">
Sem nós virtuais, remover um nó despeja toda a sua carga num único vizinho. Com eles, a carga se espalha por vários nós.
</Callout>
