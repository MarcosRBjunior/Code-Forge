Na hora de aprofundar, muitas soluções de system design se apoiam numa estrutura de dados específica. Saber qual estrutura resolve cada tipo de problema, e o que ela custa, transforma uma resposta vaga ("uso um índice") em uma resposta concreta ("uso um geohash com prefixo de 6 caracteres"). Estas são as que mais aparecem.

## Hash table e hash consistente

A base de caches, armazenamentos chave-valor e deduplicação. Leitura e escrita em tempo constante médio. Em escala distribuída, vira **hash consistente**, que decide em qual nó cada chave mora e minimiza remapeamento quando o cluster muda.

**Aparece em:** cache distribuído, chave-valor, balanceamento com afinidade.

## Árvore B e LSM-tree

Os dois motores de armazenamento mais comuns:

| | Árvore B | LSM-tree |
| --- | --- | --- |
| Escrita | Atualiza no lugar; mais lenta sob carga alta | Acumula em memória e grava em lote; muito rápida |
| Leitura | Rápida e previsível | Pode consultar vários arquivos; usa filtros para acelerar |
| Uso típico | Bancos relacionais | Bancos de escrita intensa (wide-column, chave-valor) |

Saber isso ajuda a justificar por que um banco aguenta muita escrita e outro é melhor para leituras com índices variados.

## Bloom filter

Estrutura probabilística que responde "este item **talvez** esteja no conjunto" ou "**com certeza** não está". Usa pouquíssima memória e nunca dá falso negativo, mas pode dar falso positivo.

```python
import hashlib

class BloomFilter:
    def __init__(self, size=1000, hashes=3):
        self.size = size
        self.hashes = hashes
        self.bits = [False] * size

    def _positions(self, item):
        for i in range(self.hashes):
            digest = hashlib.sha256(f"{i}:{item}".encode()).hexdigest()
            yield int(digest, 16) % self.size

    def add(self, item):
        for p in self._positions(item):
            self.bits[p] = True

    def might_contain(self, item):
        return all(self.bits[p] for p in self._positions(item))

bf = BloomFilter()
bf.add("https://exemplo.com/a")
print(bf.might_contain("https://exemplo.com/a"))  # True
print(bf.might_contain("https://exemplo.com/b"))  # quase certamente False
```

```java
import java.math.BigInteger;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.*;

static String sha256Hex(String s) {
    try {
        byte[] d = MessageDigest.getInstance("SHA-256").digest(s.getBytes(StandardCharsets.UTF_8));
        return String.format("%064x", new BigInteger(1, d));
    } catch (Exception e) {
        throw new IllegalStateException(e);
    }
}

// int(hex, 16) % m
static int modHex(String hex, int m) {
    return new BigInteger(hex, 16).mod(BigInteger.valueOf(m)).intValue();
}

class BloomFilter {
    private final int size, hashes;
    private final boolean[] bits;

    BloomFilter(int size, int hashes) {
        this.size = size;
        this.hashes = hashes;
        this.bits = new boolean[size];
    }

    BloomFilter() {
        this(1000, 3);
    }

    private List<Integer> positions(String item) {
        List<Integer> r = new ArrayList<>();
        for (int i = 0; i < hashes; i++) r.add(modHex(sha256Hex(i + ":" + item), size));
        return r;
    }

    void add(String item) {
        for (int p : positions(item)) bits[p] = true;
    }

    boolean mightContain(String item) {
        for (int p : positions(item)) if (!bits[p]) return false;
        return true;
    }
}

public static void main(String[] args) {
    BloomFilter bf = new BloomFilter();
    bf.add("https://exemplo.com/a");
    System.out.println(bf.mightContain("https://exemplo.com/a")); // true
    System.out.println(bf.mightContain("https://exemplo.com/b")); // quase certamente false
}
```

```cpp
        0x19a4c116, 0x1e376c08, 0x2748774c, 0x34b0bcb5, 0x391c0cb3, 0x4ed8aa4a, 0x5b9cca4f, 0x682e6ff3,
        0x748f82ee, 0x78a5636f, 0x84c87814, 0x8cc70208, 0x90befffa, 0xa4506ceb, 0xbef9a3f7, 0xc67178f2};
    uint32_t h[8] = {0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a, 0x510e527f, 0x9b05688c, 0x1f83d9ab, 0x5be0cd19};
    string m = msg;
    uint64_t bits = (uint64_t)msg.size() * 8;
    m += (char)0x80;
    while (m.size() % 64 != 56) m += (char)0;
    for (int i = 7; i >= 0; i--) m += (char)(bits >> (i * 8));
    auto rotr = [](uint32_t x, int n) { return (x >> n) | (x << (32 - n)); };
    for (size_t off = 0; off < m.size(); off += 64) {
        uint32_t w[64];
        for (int i = 0; i < 16; i++) {
            w[i] = ((uint32_t)(uint8_t)m[off + 4 * i] << 24) | ((uint32_t)(uint8_t)m[off + 4 * i + 1] << 16) |
                   ((uint32_t)(uint8_t)m[off + 4 * i + 2] << 8) | (uint32_t)(uint8_t)m[off + 4 * i + 3];
        }
        for (int i = 16; i < 64; i++) {
            uint32_t s0 = rotr(w[i - 15], 7) ^ rotr(w[i - 15], 18) ^ (w[i - 15] >> 3);
            uint32_t s1 = rotr(w[i - 2], 17) ^ rotr(w[i - 2], 19) ^ (w[i - 2] >> 10);
            w[i] = w[i - 16] + s0 + w[i - 7] + s1;
        }
        uint32_t a = h[0], b = h[1], c = h[2], d = h[3], e = h[4], f = h[5], g = h[6], hh = h[7];
        for (int i = 0; i < 64; i++) {
            uint32_t t1 = hh + (rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25)) + ((e & f) ^ (~e & g)) + K[i] + w[i];
            uint32_t t2 = (rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22)) + ((a & b) ^ (a & c) ^ (b & c));
            hh = g; g = f; f = e; e = d + t1; d = c; c = b; b = a; a = t1 + t2;
        }
        h[0] += a; h[1] += b; h[2] += c; h[3] += d; h[4] += e; h[5] += f; h[6] += g; h[7] += hh;
    }
    string out;
    for (int i = 0; i < 8; i++) for (int j = 3; j >= 0; j--) out += (char)(h[i] >> (j * 8));
    return out;
}

string hex(const string& bytes) {
    static const char* d = "0123456789abcdef";
    string r;
    for (unsigned char c : bytes) { r += d[c >> 4]; r += d[c & 15]; }
    return r;
}

// int(hex, 16) % m, sem precisar de inteiros enormes
unsigned long long modHex(const string& h, unsigned long long m) {
    unsigned long long r = 0;
    for (char c : h) r = (r * 16 + (c <= '9' ? c - '0' : c - 'a' + 10)) % m;
    return r;
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Security.Cryptography;
using System.Text;

static string Sha256Hex(string s)
{
    using (var sha = SHA256.Create())
    {
        return string.Concat(sha.ComputeHash(Encoding.UTF8.GetBytes(s)).Select(b => b.ToString("x2")));
    }
}

// int(hex, 16) % m, sem precisar de inteiros enormes
static int ModHex(string hex, int m)
{
    long r = 0;
    foreach (char c in hex) r = (r * 16 + Convert.ToInt32(c.ToString(), 16)) % m;
    return (int)r;
}

class BloomFilter
{
    private readonly int size, hashes;
    private readonly bool[] bits;

    public BloomFilter(int size = 1000, int hashes = 3)
    {
        this.size = size;
        this.hashes = hashes;
        bits = new bool[size];
    }

    private IEnumerable<int> Positions(string item)
    {
        for (int i = 0; i < hashes; i++)
        {
            yield return ModHex(Sha256Hex(i + ":" + item), size);
        }
    }

    public void Add(string item)
    {
        foreach (int p in Positions(item)) bits[p] = true;
    }

    public bool MightContain(string item)
    {
        return Positions(item).All(p => bits[p]);
    }
}

static void Main()
{
    var bf = new BloomFilter();
    bf.Add("https://exemplo.com/a");
    Console.WriteLine(bf.MightContain("https://exemplo.com/a").ToString().ToLower()); // true
    Console.WriteLine(bf.MightContain("https://exemplo.com/b").ToString().ToLower()); // quase certamente false
}
```

```go
import (
	"crypto/sha256"
	"encoding/hex"
	"fmt"
	"math/big"

func sha256Hex(s string) string {
	h := sha256.Sum256([]byte(s))
	return hex.EncodeToString(h[:])
}

// int(hex, 16) % m
func modHex(h string, m int) int {
	n := new(big.Int)
	n.SetString(h, 16)
	return int(n.Mod(n, big.NewInt(int64(m))).Int64())
}

type BloomFilter struct {
	size, hashes int
	bits         []bool
}

func NovoBloomFilter(size, hashes int) *BloomFilter {
	return &BloomFilter{size: size, hashes: hashes, bits: make([]bool, size)}
}

func (b *BloomFilter) positions(item string) []int {
	r := []int{}
	for i := 0; i < b.hashes; i++ {
		r = append(r, modHex(sha256Hex(fmt.Sprintf("%d:%s", i, item)), b.size))
	}
	return r
}

func (b *BloomFilter) add(item string) {
	for _, p := range b.positions(item) {
		b.bits[p] = true
	}

	for _, p := range b.positions(item) {
		if !b.bits[p] {
			return false
		}
	}
	return true
}
```

**Aparece em:** web crawler (já visitei esta URL?), LSM-trees (evitar ler arquivos que não têm a chave), verificação rápida de nomes já usados.

## Trie

Árvore de prefixos: cada nó representa um caractere, e o caminho da raiz forma a palavra. Encontrar todas as palavras com um prefixo é proporcional ao tamanho do prefixo. Para autocomplete, cada nó pode guardar os K termos mais populares abaixo dele, deixando a resposta pronta.

**Aparece em:** autocomplete, roteamento por prefixo de IP, dicionários.

## Geohash, quadtree e índices espaciais

Para "encontre motoristas a menos de 2 km", você precisa indexar duas dimensões.

- **Geohash** codifica latitude e longitude numa string; prefixos comuns indicam proximidade. Fácil de guardar em qualquer banco ou cache.
- **Quadtree** divide o mapa recursivamente em quatro quadrantes até cada um ter poucos pontos. Adapta-se à densidade (centro da cidade vira células pequenas).
- **Grades hexagonais** dividem o mundo em células de tamanho uniforme, úteis para agregações por região.

**Aparece em:** apps de corrida, busca de restaurantes, entrega.

## Skip list e sorted set

Uma lista ordenada com "atalhos" em vários níveis, com busca, inserção e consulta por posição em tempo logarítmico. É a base dos sorted sets de caches em memória, muito usados para rankings.

**Aparece em:** leaderboards, top K, filas por prioridade, janelas deslizantes de rate limiting.

## Estruturas para contagem aproximada

Quando contar exatamente custa caro demais:

- **HyperLogLog:** estima quantos itens distintos existem (usuários únicos) com alguns KB, erro em torno de 1%.
- **Count-Min Sketch:** estima a frequência de cada item num fluxo usando uma matriz pequena de contadores; superestima, nunca subestima.

**Aparece em:** analytics, top K de termos buscados, detecção de itens populares.

<Callout type="tip" title="Diga o custo junto com a estrutura">
Ao citar uma estrutura probabilística, mencione o erro aceito: "uso HyperLogLog, com cerca de 1% de erro, porque o painel não precisa de número exato e economizo gigabytes de memória".
</Callout>

## Outras que vale reconhecer

- **Heap:** manter os K maiores de um fluxo.
- **Árvore de Merkle:** comparar réplicas e achar diferenças trocando poucos hashes.
- **Log append-only:** base de filas, replicação e bancos.
- **Índice invertido:** palavra para lista de documentos; coração da busca textual.
