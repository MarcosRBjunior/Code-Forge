Em Python você escreve uma função `maior(a, b)` e ela funciona com inteiros, strings ou qualquer coisa comparável, porque o tipo só é checado em tempo de execução. C++ é estaticamente tipado: sem ajuda, você precisaria de uma versão da função para cada tipo. Templates resolvem isso: você escreve o código uma vez, com o tipo como parâmetro, e o compilador gera uma versão concreta para cada tipo usado.

## Como funciona

Um template começa com `template <typename T>`. O `T` é um parâmetro de tipo que o compilador substitui na hora do uso. Chamar `maior(3, 7)` faz o compilador deduzir `T = int` e gerar uma função para `int`; chamar `maior(2.5, 1.5)` gera outra para `double`. Isso é a instanciação, e acontece inteira em tempo de compilação: não há custo em tempo de execução, e `vector<int>` e `vector<string>` são tipos completamente diferentes e otimizados separadamente.

Um erro típico é o tipo não suportar uma operação usada no corpo: `maior` exige `operator>`. O erro aparece só na instanciação, e as mensagens de template do compilador são longas; procure a primeira linha com "required from" ou o nome da sua função.

## Funções e classes genéricas

Classes também podem ser templates, e é assim que toda a STL é feita. A partir do C++17, o compilador também deduz o parâmetro de uma classe pelo construtor (CTAD), então `Caixa c(5)` dispensa o `<int>`.

```cpp
#include <iostream>
#include <string>
using namespace std;

template <typename T>
T maior(T a, T b) {
    return a > b ? a : b;
}

template <typename T>
class Caixa {
public:
    Caixa(T x) : v(x) {}
    T get() const { return v; }

private:
    T v;
};

int main() {
    cout << maior(3, 7) << " " << maior(2.5, 1.5) << " "
         << maior<string>("abc", "abd") << "\n";
    Caixa<int> c(5);
    cout << c.get() << "\n";
    Caixa c2(string("oi"));
    cout << c2.get() << "\n";
}
```

```text
Saída:
7 2.5 abd
5
oi
```

Repare em `maior<string>("abc", "abd")`: os dois argumentos são `const char*`, e `maior("abc", "abd")` sem o tipo explícito compararia ponteiros, não texto. Informar `<string>` força a conversão. Quando a dedução dá um resultado estranho, passe o tipo explicitamente.

## Código genérico sobre contêineres

Um template pode receber qualquer contêiner que ofereça o que o corpo usa. Aqui `T{}` cria o valor neutro do tipo (0 para números, string vazia para texto):

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

template <typename T>
T somar(const vector<T>& v) {
    T r{};
    for (const T& x : v) r = r + x;
    return r;
}

template <int N>
int somaAte() {
    int s = 0;
    for (int i = 1; i <= N; i++) s += i;
    return s;
}

int main() {
    cout << somar(vector<int>{1, 2, 3}) << "\n";
    cout << somar(vector<double>{0.5, 0.25}) << "\n";
    cout << somar(vector<string>{"a", "b", "c"}) << "\n";
    cout << somaAte<10>() << "\n";
}
```

```text
Saída:
6
0.75
abc
55
```

O mesmo `somar` serve para três tipos. A última função mostra que um template também aceita parâmetros que não são tipos, como um inteiro: `std::array<int, 5>` usa exatamente isso para guardar o tamanho no tipo.

## Dicas práticas

- Defina templates inteiros em cabeçalhos ou no mesmo arquivo; o compilador precisa ver o corpo para instanciar.
- Passe `const T&` para evitar cópias de tipos grandes.
- Em C++20, `concepts` permitem declarar o que o tipo precisa oferecer (`requires`), com erros mais legíveis. Em entrevista raramente são exigidos.
- Lambdas genéricas (`auto` nos parâmetros) são templates disfarçados, assunto que reaparece no capítulo de lambdas.

## Armadilhas

- **Inchaço de código**: cada tipo gera uma cópia; é raro importar em entrevista.
- **Dedução ambígua**: `maior(1, 2.5)` falha porque `T` seria `int` e `double` ao mesmo tempo. Escreva `maior<double>(1, 2.5)`.
- **Erros tardios**: uma operação não suportada só estoura quando você instancia.
- **Especialização**: `vector<bool>` é uma especialização especial que guarda bits e não devolve referências reais; evite-o quando precisar de `&` para os elementos.

## Na entrevista

Você usa templates o tempo todo sem escrevê-los (`vector<int>`, `map<string, int>`, `sort`). Raramente pedem para escrever um do zero, mas é comum em questões de design pedir um contêiner genérico (pilha, fila, cache) com `template <typename T>`. Follow-ups: "o que acontece em tempo de compilação com um template?" (instanciação por tipo) e "por que o corpo de um template fica no cabeçalho?" (o compilador precisa dele para gerar o código de cada tipo).
