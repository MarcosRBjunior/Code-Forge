Em Python você escreve a primeira linha e o interpretador executa. Em JavaScript o motor lê o arquivo e roda. Em C++ existe uma etapa a mais: o código-fonte é traduzido por um compilador para um executável nativo, e só então roda. Isso dá a velocidade que torna C++ popular em entrevistas com limite de tempo apertado, mas também significa que um erro de sintaxe impede qualquer saída.

## O menor programa

A execução começa na função `main`, que devolve um `int`. Retornar zero significa sucesso, e se você omitir o `return` em `main` o compilador assume zero.

```cpp
#include <iostream>

int main() {
    std::cout << "Olá, entrevista!" << std::endl;
    return 0;
}
```

```text
Saída:
Olá, entrevista!
```

A linha `#include` copia para o seu arquivo as declarações de uma biblioteca antes da compilação. `std::cout` é o fluxo de saída padrão, e o operador `<<` empurra valores para ele, um depois do outro. O prefixo `std::` indica o namespace da biblioteca padrão, o equivalente a um módulo que evita colisão de nomes.

## Imprimir sem dor

Você pode encadear vários valores numa única instrução. Para quebra de linha, prefira o caractere `'\n'`: o `std::endl` também descarrega o buffer de saída, o que é mais lento quando você imprime muitas linhas.

```cpp
#include <iostream>
#include <string>

int main() {
    int soma = 2 + 3;
    std::string nome = "fila";
    std::cout << "soma = " << soma << '\n';
    std::cout << nome << " tem " << nome.size() << " letras\n";
    std::cout << 7 / 2 << " e " << 7.0 / 2 << '\n';
    return 0;
}
```

```text
Saída:
soma = 5
fila tem 4 letras
3 e 3.5
```

Repare no último exemplo: a divisão de dois inteiros trunca, como `//` em Python, e basta um operando decimal para o resultado ser decimal.

## Includes e o atalho de competição

Cada pedaço da biblioteca vive em um cabeçalho: `vector`, `string`, `map`, `algorithm` e assim por diante. Esquecer um include gera erro de compilação. Em plataformas de competição e muitas entrevistas, é aceito escrever o cabeçalho que traz tudo do GCC:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> v = {3, 1, 2};
    sort(v.begin(), v.end());
    for (int x : v) cout << x << ' ';
    cout << '\n';
}
```

```text
Saída:
1 2 3 
```

O `using namespace std;` dispensa o prefixo `std::`. Isso é conveniente em um arquivo pequeno, mas em código de produção costuma ser evitado porque pode causar conflito de nomes. Também note que `bits/stdc++.h` é específico do GCC; se o entrevistador usar outro compilador, escreva os includes que você precisa.

## Compilar e executar

Com o GCC o fluxo é um comando para compilar e outro para rodar:

```bash
g++ -std=c++17 -O2 -Wall main.cpp -o main
./main
```

A opção `-std` escolhe a versão da linguagem, `-O2` liga otimizações e `-Wall` ativa avisos úteis, como variável não usada ou possível uso sem inicializar.

## Comentários e organização

Use `//` para uma linha e `/* ... */` para blocos. Funções precisam ser declaradas antes do uso: se `main` vem primeiro, escreva antes dela o protótipo, que é só a assinatura terminada em ponto e vírgula.

## Na entrevista

Muitas vezes você recebe só a assinatura, como uma função membro de uma classe `Solution`, e não escreve `main`. Quando pedirem o programa completo, comece pelos includes, depois `using namespace std;` se o ambiente permitir, e então `main`. Follow-ups comuns: "qual a diferença entre `'\n'` e `std::endl`?" (o segundo descarrega o buffer) e "o que acontece se faltar um include?" (erro de compilação, não de execução).
