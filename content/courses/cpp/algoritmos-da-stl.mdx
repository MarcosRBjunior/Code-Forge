Em Python, `sorted`, `sum`, `max`, `min` e `list.count` funcionam direto sobre uma lista. Em C++, os algoritmos vivem fora dos contêineres, no cabeçalho `algorithm` (e `numeric`), e trabalham sobre um **intervalo** descrito por dois iteradores: o início e a posição logo depois do fim. Quase sempre você escreve `v.begin(), v.end()`. Conhecer essa biblioteca de cor economiza código e erros em entrevista.

## O intervalo semiaberto

Um intervalo `[first, last)` inclui `first` e exclui `last`. Ele é o mesmo modelo do `range(a, b)` de Python. Passar um intervalo vazio (`first == last`) é válido e não faz nada. Os algoritmos não conhecem o contêiner, só os iteradores, e por isso funcionam em `vector`, `deque`, `string` e arrays crus (com ponteiros).

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

int main() {
    std::vector<int> v = {5, 2, 9, 1, 5, 6};
    std::sort(v.begin(), v.end());
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';

    std::reverse(v.begin(), v.end());
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';

    long long soma = std::accumulate(v.begin(), v.end(), 0LL);
    std::cout << soma << " " << std::count(v.begin(), v.end(), 5) << '\n';

    auto it = std::find(v.begin(), v.end(), 9);
    std::cout << (it - v.begin()) << '\n';
    auto mx = std::max_element(v.begin(), v.end());
    auto mn = std::min_element(v.begin(), v.end());
    std::cout << *mx << " " << *mn << " " << (mn - v.begin()) << '\n';
    std::cout << std::max(3, 8) << " " << std::min(3, 8) << '\n';
    return 0;
}
```

```text
Saída:
1 2 5 5 6 9 
9 6 5 5 2 1 
28 2
0
9 1 5
8 3
```

O terceiro argumento de `accumulate` define o tipo do resultado. Escrever `0` somaria em `int` e poderia estourar; `0LL` faz a conta em `long long`. A subtração `it - v.begin()` dá o índice. Quando `find` não acha, devolve `v.end()`, e desreferenciar esse iterador é comportamento indefinido, então compare antes.

## Busca binária pronta

Em um intervalo **ordenado**, três funções fazem busca em O(log n): `binary_search` (existe ou não), `lower_bound` (primeiro elemento maior ou igual) e `upper_bound` (primeiro estritamente maior). A diferença entre as duas últimas dá a quantidade de ocorrências.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

int main() {
    std::vector<int> v = {1, 2, 5, 5, 6, 9};
    int lo = std::lower_bound(v.begin(), v.end(), 5) - v.begin();
    int hi = std::upper_bound(v.begin(), v.end(), 5) - v.begin();
    std::cout << lo << " " << hi << " " << (hi - lo) << " " << std::binary_search(v.begin(), v.end(), 6) << '\n';

    v.erase(std::unique(v.begin(), v.end()), v.end());
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';

    std::vector<int> seq(5);
    std::iota(seq.begin(), seq.end(), 1);
    std::fill(seq.begin(), seq.begin() + 2, 0);
    for (int x : seq) std::cout << x << ' ';
    std::cout << '\n';

    std::vector<int> p = {1, 2, 3};
    do {
        for (int x : p) std::cout << x;
        std::cout << ' ';
    } while (std::next_permutation(p.begin(), p.end()));
    std::cout << '\n';

    std::cout << std::any_of(seq.begin(), seq.end(), [](int x) { return x > 4; }) << " "
              << std::all_of(seq.begin(), seq.end(), [](int x) { return x >= 0; }) << '\n';
    return 0;
}
```

```text
Saída:
2 4 2 1
1 2 5 6 9 
0 0 3 4 5 
123 132 213 231 312 321 
1 1
```

Três idiomas aparecem acima. O primeiro é o "apagar-remover" com `unique`: ele só remove duplicatas **adjacentes** (por isso o vetor precisa estar ordenado) e devolve o novo fim lógico, e você corta o resto com `erase`. O segundo é `iota`, que preenche com valores crescentes, útil para criar vetores de índices. O terceiro é `next_permutation`, que gera as permutações em ordem lexicográfica e devolve falso ao chegar na última; comece de um vetor ordenado para ver todas.

## Custos

| Algoritmo | Custo |
|---|---|
| `sort` | O(n log n) |
| `find`, `count`, `accumulate`, `max_element` | O(n) |
| `binary_search`, `lower_bound`, `upper_bound` | O(log n), com intervalo ordenado e acesso aleatório |
| `unique`, `reverse`, `fill`, `iota` | O(n) |
| `next_permutation` | O(n) por chamada |

## Armadilhas

Chamar `lower_bound` num intervalo não ordenado dá resultado sem sentido, sem aviso. Chamar `v.erase(unique(...))` sem o segundo argumento apaga só um elemento. E em `set` ou `map`, use o método membro `s.lower_bound(x)`: a versão global, que recebe iteradores, funciona mas é O(n) porque iteradores de árvore não têm acesso aleatório.
