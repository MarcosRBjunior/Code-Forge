O dicionário do Python e o objeto/`Map` do JavaScript resolvem dois problemas: achar um valor por chave e testar se algo já foi visto. C++ tem duas famílias para isso, e a escolha entre elas é uma das perguntas favoritas de entrevistador. A família ordenada (`map`, `set`) mantém as chaves em ordem; a família com hash (`unordered_map`, `unordered_set`) não mantém ordem alguma, mas costuma ser mais rápida.

## map e set: ordenados

`std::map` e `std::set` são implementados como árvores de busca balanceadas (normalmente árvores rubro-negras). Por isso inserir, buscar e remover custam O(log n), e a iteração sai sempre em ordem crescente de chave. O `set` guarda só chaves e ignora duplicatas; o `map` associa a cada chave um valor.

```cpp
#include <iostream>
#include <map>
#include <set>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> palavras = {"b", "a", "c", "a", "b", "a"};
    std::map<std::string, int> freq;
    for (const auto& p : palavras) freq[p]++;
    for (const auto& [chave, qtd] : freq) std::cout << chave << "=" << qtd << ' ';
    std::cout << '\n';

    std::cout << freq.size() << " ";
    int x = freq["z"];
    std::cout << x << " " << freq.size() << " " << freq.count("w") << '\n';

    std::set<int> s = {5, 1, 3, 1, 5};
    std::cout << s.size() << " " << *s.begin() << " " << *s.rbegin() << '\n';
    std::cout << *s.lower_bound(2) << " " << *s.upper_bound(3) << '\n';
    s.erase(3);
    for (int v : s) std::cout << v << ' ';
    std::cout << '\n';
    return 0;
}
```

```text
Saída:
a=3 b=2 c=1 
3 0 4 0
3 1 5
3 5
1 5 
```

Dois pontos pedem atenção. Primeiro, o `operator[]` do `map` cria a chave com valor padrão quando ela não existe: ler `freq["z"]` aumentou o tamanho de 3 para 4. Para só consultar sem inserir, use `count` ou `find`. Segundo, `lower_bound(k)` devolve um iterador para o primeiro elemento maior ou igual a `k`, e `upper_bound(k)` para o primeiro estritamente maior; essas buscas por faixa são o motivo para escolher a versão ordenada.

## unordered_map e unordered_set: hash

Aqui a chave passa por uma função de hash que a transforma em uma posição numa tabela. Inserir, buscar e remover custam O(1) em média, mas O(n) no pior caso, quando muitas chaves colidem. Em entrevista, a conta usual é O(1) médio.

```cpp
#include <iostream>
#include <unordered_map>
#include <unordered_set>
#include <vector>

int main() {
    std::vector<int> nums = {2, 7, 11, 15};
    int alvo = 9;
    std::unordered_map<int, int> visto;
    for (int i = 0; i < (int)nums.size(); i++) {
        auto it = visto.find(alvo - nums[i]);
        if (it != visto.end()) {
            std::cout << it->second << " " << i << '\n';
            break;
        }
        visto[nums[i]] = i;
    }

    std::unordered_set<int> unicos;
    std::vector<int> dados = {4, 2, 4, 9, 2};
    bool repetido = false;
    for (int d : dados)
        if (!unicos.insert(d).second) repetido = true;
    std::cout << unicos.size() << " " << repetido << '\n';
    return 0;
}
```

```text
Saída:
0 1
3 1
```

O método `insert` devolve um par cujo `second` informa se a inserção ocorreu: é um jeito compacto de detectar duplicatas. A busca com `find` devolve `end()` quando a chave não existe, e o `it->second` é o valor.

## Qual escolher

| Necessidade | Estrutura |
|---|---|
| Só contar ou testar presença | `unordered_map` ou `unordered_set` |
| Percorrer em ordem, mínimo e máximo, `lower_bound` | `map` ou `set` |
| Chave composta como par ou vetor | `map` (hash de `pair` não vem pronto) |
| Duplicatas permitidas | `multiset` ou `multimap` |

Armadilhas: `unordered_map` com chave `pair<int,int>` não compila sem uma função de hash própria. A ordem de iteração de um `unordered_map` é imprevisível, então não dependa dela. E inserir durante a iteração pode invalidar iteradores no hash.
