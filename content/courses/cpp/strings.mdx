Em Python e JavaScript, strings são imutáveis: toda modificação cria uma nova. Em C++, `std::string` é mutável, guarda os caracteres de forma contígua (como um `vector<char>`) e você pode alterar uma posição, anexar no fim ou apagar trechos no próprio objeto. Isso muda o custo de várias operações e abre espaço para técnicas in-place que são comuns em entrevistas.

## Operações essenciais

Cada caractere é um `char`, um número pequeno. Isso é bom: `s[i]` custa O(1), e dá para fazer contas com letras. Mas significa que não existe um tipo "caractere de texto Unicode" aqui: `std::string` trata bytes, e para problemas de entrevista, que quase sempre usam ASCII, isso basta.

```cpp
#include <iostream>
#include <string>
#include <algorithm>

int main() {
    std::string s = "entrevista";
    std::cout << s.size() << " " << s[0] << " " << s.substr(2, 4) << '\n';
    std::cout << s.find("vis") << '\n';
    if (s.find("xyz") == std::string::npos) std::cout << "nao achou\n";

    s += "!";
    s.push_back('?');
    std::cout << s << '\n';

    std::string r(s.rbegin(), s.rend());
    std::cout << r << '\n';
    std::reverse(s.begin(), s.end());
    std::cout << (s == r) << " " << ("abc" < std::string("abd")) << '\n';

    std::cout << std::to_string(42) + "x" << " " << std::stoi("123") + 1 << '\n';
    return 0;
}
```

```text
Saída:
10 e trev
5
nao achou
entrevista!?
?!atsivertne
1 1
42x 124
```

`substr(pos, tam)` recebe a posição inicial e o comprimento, não o fim como o `slice` do JavaScript. `find` devolve o índice da primeira ocorrência ou o valor especial `std::string::npos` quando não encontra; esse valor é um número sem sinal gigantesco, então nunca compare com `-1` guardado em um `int` sem cuidado. Strings comparam lexicograficamente com `<`, `==` e os demais, e a conversão entre texto e número usa `to_string` e `stoi` (ou `stoll`, `stod`).

## Custos que importam

| Operação | Custo |
|---|---|
| `s[i]`, `size` | O(1) |
| `push_back`, `+=` de um caractere | O(1) amortizado |
| `substr`, cópia | O(tamanho copiado) |
| `find` de um padrão | O(n * m) no pior caso |
| `s + t` | O(tamanho de s + t) |

A armadilha clássica é concatenar com `s = s + c` dentro de um laço: cada passo cria uma string nova, o que dá O(n²). Use `s += c` ou `push_back`, que modificam no lugar. Da mesma forma, `substr` copia; em laços sobre janelas, prefira índices.

## Letras, dígitos e contagem

Como `char` é um número, a diferença `c - 'a'` dá a posição de uma letra minúscula no alfabeto, e `c - '0'` converte um dígito em valor. Com isso, um array de 26 posições faz o papel de um mapa de frequência, mais rápido que um `unordered_map`. Para dividir um texto em palavras, `istringstream` lê separando por espaço, como `split()` em Python.

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <cctype>

int main() {
    std::string t = "banana";
    int freq[26] = {0};
    for (char c : t) freq[c - 'a']++;
    std::cout << freq[0] << " " << freq[1] << " " << freq['n' - 'a'] << '\n';

    int soma = 0;
    for (char c : std::string("a1b22"))
        if (std::isdigit(c)) soma += c - '0';
    std::cout << soma << '\n';

    std::istringstream in("um dois tres");
    std::string w;
    int n = 0;
    while (in >> w) {
        n++;
        std::cout << w << ":" << w.size() << ' ';
    }
    std::cout << "| " << n << '\n';
    std::cout << (char)std::toupper('q') << '\n';
    return 0;
}
```

```text
Saída:
3 1 2
5
um:2 dois:4 tres:4 | 3
Q
```

Funções como `isdigit`, `isalpha`, `islower` e `toupper` vivem em `cctype`. Elas recebem e devolvem `int`, por isso o `(char)` antes de imprimir: sem ele apareceria o código numérico da letra.

## Armadilhas

Compare tamanhos com cuidado: `s.size() - 1` com string vazia dá um valor gigantesco, como nos vetores. Literais como `"abc"` são arrays de `char`, não `string`, então `"a" + "b"` não compila; converta um dos lados com `std::string("a")`. E lembre que `string_view` existe para olhar um trecho sem copiar, mas não é dono dos dados.

## Na entrevista

Para palíndromos e inversões, use dois ponteiros sobre a própria string, em O(1) de espaço extra. Para anagramas, compare arrays de frequência. Follow-ups: "qual o custo de concatenar em laço?" (quadrático com `+`, linear com `+=`) e "como lidar com Unicode?" (a `string` guarda bytes; seria preciso decodificar).
