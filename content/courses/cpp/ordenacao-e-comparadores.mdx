Ordenar é o primeiro passo de metade dos problemas de entrevista: intervalos, pares, "k mais frequentes", dois ponteiros. Em Python você escreve `sorted(xs, key=...)`; em JavaScript, `xs.sort((a, b) => a - b)`. Em C++ a função é `std::sort`, e o critério de ordenação vem de um **comparador**: uma função que responde "a deve vir antes de b?".

## sort e o comparador padrão

`std::sort(first, last)` ordena em ordem crescente usando `operator<` e custa O(n log n). O algoritmo é híbrido (introsort) e **não é estável**: elementos iguais podem trocar de ordem relativa. Se a estabilidade importa, use `std::stable_sort`.

Para mudar o critério, passe um terceiro argumento. O mais comum hoje é uma lambda, que escreve a regra no ponto de uso.

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <functional>

int main() {
    std::vector<int> v = {4, 1, 9, 3, 7};
    std::sort(v.begin(), v.end(), std::greater<int>());
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';

    std::vector<std::string> nomes = {"banana", "kiwi", "uva", "maca", "figo"};
    std::sort(nomes.begin(), nomes.end(), [](const std::string& a, const std::string& b) {
        if (a.size() != b.size()) return a.size() < b.size();
        return a < b;
    });
    for (const auto& s : nomes) std::cout << s << ' ';
    std::cout << '\n';

    std::vector<std::pair<int, char>> ps = {{2, 'b'}, {1, 'z'}, {2, 'a'}, {1, 'c'}};
    std::sort(ps.begin(), ps.end());
    for (auto& p : ps) std::cout << p.first << p.second << ' ';
    std::cout << '\n';
    return 0;
}
```

```text
Saída:
9 7 4 3 1 
uva figo kiwi maca banana 
1c 1z 2a 2b 
```

Aqui há três modos de comparar. O `greater` inverte a ordem numérica. A lambda ordena por tamanho e, no empate, alfabeticamente: devolve `true` quando `a` deve vir antes de `b`. E o par já vem pronto: `pair` compara o primeiro campo e depois o segundo, então `sort` simples ordena por ambos. Note que a lambda recebe `const std::string&` para não copiar as strings a cada comparação.

## Ordenar structs

Há duas maneiras de ensinar uma struct a ser ordenada: definir `operator<` dentro dela, ou passar um comparador. Para ordenar por vários critérios, `std::tie` compara tuplas campo a campo.

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <tuple>

struct Aluno {
    std::string nome;
    int nota;
    int idade;
};

int main() {
    std::vector<Aluno> as = {{"Ana", 8, 20}, {"Bia", 9, 22}, {"Caio", 8, 19}, {"Duda", 9, 21}};
    std::sort(as.begin(), as.end(), [](const Aluno& a, const Aluno& b) {
        return std::tie(b.nota, a.idade) < std::tie(a.nota, b.idade);
    });
    for (const auto& a : as) std::cout << a.nome << ' ';
    std::cout << '\n';

    std::vector<int> v = {30, 10, 20};
    std::vector<int> idx = {0, 1, 2};
    std::sort(idx.begin(), idx.end(), [&](int i, int j) { return v[i] < v[j]; });
    for (int i : idx) std::cout << i << ' ';
    std::cout << '\n';

    std::vector<std::pair<int, int>> intervalos = {{5, 8}, {1, 3}, {2, 6}};
    std::sort(intervalos.begin(), intervalos.end());
    std::cout << intervalos[0].first << " " << intervalos[2].second << '\n';
    return 0;
}
```

```text
Saída:
Duda Bia Caio Ana 
1 2 0 
1 8
```

O primeiro critério ordena por nota decrescente (daí `b.nota` à esquerda de `a.nota`) e, no empate, por idade crescente. Na terceira parte, ordenar índices por valor, o "argsort", é o jeito de manter a posição original, parecido com `sorted(range(n), key=lambda i: v[i])` de Python. A lambda captura `v` por referência com `[&]`.

## A regra de ouro: ordem fraca estrita

O comparador precisa devolver `false` para elementos iguais. Escrever `<=` em vez de `<` viola essa regra: para dois elementos iguais, o comparador diz que cada um vem antes do outro, e `sort` pode ler fora do vetor ou travar. Esse é um dos poucos casos em que um erro aparentemente inofensivo gera comportamento indefinido. O comparador também deve ser consistente, isto é, transitivo: se `a < b` e `b < c`, então `a < c`.
