Em Python você passa objetos e a linguagem decide o que acontece; em JavaScript, primitivos vão por valor e objetos por referência a um objeto compartilhado. Em C++ a escolha é sua e explícita: cada parâmetro é copiado, a menos que você peça uma referência. Entender isso é o que separa uma solução correta e rápida de uma que copia um vetor de um milhão de elementos a cada chamada.

## Declaração e retorno

Uma função declara o tipo de retorno antes do nome, e o tipo de cada parâmetro. Quem não devolve nada usa `void`. O compilador lê o arquivo de cima para baixo, então uma função precisa estar definida ou ao menos declarada (o protótipo) antes de ser chamada.

```cpp
#include <iostream>

int quadrado(int x);

int main() {
    std::cout << quadrado(7) << '\n';
    return 0;
}

int quadrado(int x) {
    return x * x;
}
```

```text
Saída:
49
```

## Valor contra referência

Por padrão o argumento é copiado. Mudar o parâmetro dentro da função não afeta a variável de quem chamou. Com `&` o parâmetro vira outro nome para a própria variável.

```cpp
#include <iostream>
#include <vector>

void trocaCopia(int a, int b) {
    int t = a; a = b; b = t;
}

void trocaRef(int& a, int& b) {
    int t = a; a = b; b = t;
}

long long soma(const std::vector<int>& v) {
    long long s = 0;
    for (int x : v) s += x;
    return s;
}

int main() {
    int x = 1, y = 2;
    trocaCopia(x, y);
    std::cout << x << " " << y << '\n';
    trocaRef(x, y);
    std::cout << x << " " << y << '\n';
    std::vector<int> v = {1, 2, 3, 4};
    std::cout << soma(v) << '\n';
    return 0;
}
```

```text
Saída:
1 2
2 1
10
```

A regra prática para entrevistas: tipos pequenos (`int`, `double`, `char`, `bool`) vão por valor; contêineres e strings grandes vão por referência constante, `const T&`, quando só serão lidos, e por referência simples, `T&`, quando a função deve alterá-los. Passar um `vector` por valor copia todos os elementos, e em uma recursão isso transforma uma solução linear em quadrática.

## Sobrecarga e argumentos padrão

C++ permite várias funções com o mesmo nome e parâmetros diferentes; o compilador escolhe pela lista de argumentos. Também permite valores padrão, que devem ficar nos últimos parâmetros.

```cpp
#include <iostream>
#include <vector>

int maior(int a, int b) { return a > b ? a : b; }
double maior(double a, double b) { return a > b ? a : b; }

long long fib(int n, std::vector<long long>& memo) {
    if (n < 2) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n - 1, memo) + fib(n - 2, memo);
}

int potencia(int base, int exp = 2) {
    int r = 1;
    for (int i = 0; i < exp; i++) r *= base;
    return r;
}

int main() {
    std::cout << maior(3, 9) << " " << maior(2.5, 1.5) << '\n';
    std::vector<long long> memo(51, -1);
    std::cout << fib(50, memo) << '\n';
    std::cout << potencia(5) << " " << potencia(2, 10) << '\n';
    return 0;
}
```

```text
Saída:
9 2.5
12586269025
25 1024
```

O `fib` com memoização é o padrão que você usará em programação dinâmica top-down: o `memo` vai por referência, para que todas as chamadas compartilhem o mesmo cache. Note também a sintaxe `return memo[n] = ...`, que atribui e devolve em uma linha.

## Recursão e a pilha

Cada chamada ocupa espaço na pilha de execução. Uma recursão com profundidade de centenas de milhares de níveis pode estourar a pilha (stack overflow), e isso encerra o programa de forma abrupta. Em C++ não há limite configurável como o `sys.setrecursionlimit` de Python: o limite é o tamanho da pilha do sistema, algo em torno de milhares a centenas de milhares de quadros. Se a profundidade pode chegar a 10^6, converta para um laço com pilha explícita.

## Armadilha: retornar referência para local

Uma função que devolve `int&` ou `const T&` de uma variável local devolve algo que deixou de existir ao fim da função. Usar esse valor é comportamento indefinido. Retorne por valor; o compilador evita a cópia na maioria dos casos.
