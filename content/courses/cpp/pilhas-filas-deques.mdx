Em Python você usa uma lista como pilha (`append` e `pop`) e `collections.deque` como fila. Em JavaScript, o array faz as duas coisas, com `shift` caro para fila. C++ dá um tipo para cada intenção: `stack` (último a entrar, primeiro a sair), `queue` (primeiro a entrar, primeiro a sair) e `deque` (acesso eficiente às duas pontas). Escolher o tipo certo já comunica ao entrevistador o que seu algoritmo faz.

## stack

A `stack` oferece `push`, `pop`, `top`, `empty` e `size`, todas em O(1). Um detalhe que surpreende: `pop` não devolve o elemento removido. Você lê com `top` e depois chama `pop`. Chamar `top` ou `pop` com a pilha vazia é comportamento indefinido, então teste `empty` antes.

```cpp
#include <iostream>
#include <stack>
#include <string>

bool balanceado(const std::string& s) {
    std::stack<char> pilha;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            pilha.push(c);
        } else {
            if (pilha.empty()) return false;
            char abre = pilha.top();
            pilha.pop();
            if ((c == ')' && abre != '(') || (c == ']' && abre != '[') || (c == '}' && abre != '{'))
                return false;
        }
    }
    return pilha.empty();
}

int main() {
    std::cout << balanceado("([]{})") << " " << balanceado("(]") << " " << balanceado("(((") << '\n';
    std::stack<int> p;
    p.push(1); p.push(2); p.push(3);
    std::cout << p.top() << " " << p.size() << '\n';
    p.pop();
    std::cout << p.top() << '\n';
    return 0;
}
```

```text
Saída:
1 0 0
3 3
2
```

Esse é o molde de qualquer problema de parênteses balanceados, e também de pilhas monotônicas e avaliação de expressões. Como `stack` não tem iteração, se precisar percorrer os elementos use um `vector` como pilha, com `push_back`, `back` e `pop_back`: é o que muita gente faz em competições.

## queue

A `queue` oferece `push` (no fim), `pop` (no início), `front`, `back`, `empty` e `size`, todos O(1). Ela é a base da busca em largura (BFS): você enfileira os vizinhos e processa na ordem de chegada. Do mesmo modo que na pilha, `pop` não devolve o valor.

## deque

O `deque` (double-ended queue) permite `push_front`, `push_back`, `pop_front` e `pop_back` em O(1), e ainda acesso por índice `d[i]` em O(1). Por baixo, ele guarda blocos de memória e um mapa deles, então não é contíguo como o `vector`. Ele é a escolha para janela deslizante com máximo (a clássica deque monotônica) e para qualquer fila que precise remover nas duas pontas.

```cpp
#include <iostream>
#include <queue>
#include <deque>
#include <vector>

int main() {
    std::queue<int> fila;
    fila.push(10); fila.push(20); fila.push(30);
    std::cout << fila.front() << " " << fila.back() << " " << fila.size() << '\n';
    fila.pop();
    std::cout << fila.front() << '\n';

    std::deque<int> d;
    d.push_back(2); d.push_back(3);
    d.push_front(1); d.push_front(0);
    d.pop_back();
    std::cout << d.front() << " " << d.back() << " " << d[1] << " " << d.size() << '\n';

    std::vector<int> a = {1, 3, -1, -3, 5, 3, 6, 7};
    int k = 3;
    std::deque<int> idx;
    for (int i = 0; i < (int)a.size(); i++) {
        while (!idx.empty() && a[idx.back()] <= a[i]) idx.pop_back();
        idx.push_back(i);
        if (idx.front() <= i - k) idx.pop_front();
        if (i >= k - 1) std::cout << a[idx.front()] << ' ';
    }
    std::cout << '\n';
    return 0;
}
```

```text
Saída:
10 30 3
20
0 2 1 3
3 3 5 5 6 7 
```

A última parte é a janela deslizante máxima: o deque guarda índices cujos valores estão em ordem decrescente, então o máximo da janela é sempre `a[idx.front()]`. Cada índice entra e sai uma vez, e o total é O(n).

## Armadilhas

Usar `vector` e `erase(begin)` como fila é O(n) por remoção. Usar `deque` quando o `vector` bastaria custa mais memória e perde a contiguidade. Esquecer de checar `empty()` antes de `top`, `front` ou `pop` causa comportamento indefinido, e é o erro mais comum aqui. E uma BFS que usa `queue` precisa marcar o nó como visitado ao enfileirar, não ao desenfileirar, para não repetir trabalho.
