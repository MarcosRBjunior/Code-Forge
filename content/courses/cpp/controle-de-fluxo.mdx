As estruturas de decisão e repetição de C++ vieram de C e serviram de modelo para JavaScript, então você já reconhece quase tudo. As diferenças que importam são o uso obrigatório de parênteses nas condições, o fato de que blocos são delimitados por chaves, não por indentação como em Python, e o comportamento do `switch`, que tem pegadinhas clássicas.

## if, else e o ternário

A condição fica entre parênteses e qualquer valor numérico vale como booleano: zero é falso, o resto é verdadeiro. Em Python você escreve `elif`; aqui é `else if`.

```cpp
#include <iostream>

int main() {
    int nota = 72;
    if (nota >= 90) {
        std::cout << "A\n";
    } else if (nota >= 70) {
        std::cout << "B\n";
    } else {
        std::cout << "C\n";
    }
    std::cout << (nota % 2 == 0 ? "par" : "impar") << '\n';
    return 0;
}
```

```text
Saída:
B
par
```

Um erro frequente é escrever `if (x = 5)` com um único sinal de igual. Isso atribui 5 a `x` e a condição fica sempre verdadeira. O GCC avisa com `-Wall`, mas na pressa vale a atenção.

## Laços: for, while, do-while e for por intervalo

O `for` clássico tem três partes: inicialização, condição e passo. O laço por intervalo, introduzido no C++11, percorre um contêiner inteiro e é o que mais aparece em soluções modernas. O `while` testa antes de executar, e o `do-while` executa pelo menos uma vez.

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {4, 8, 15, 16};
    int soma = 0;
    for (int i = 0; i < (int)v.size(); i++) soma += v[i];
    std::cout << soma << '\n';

    for (int x : v) {
        if (x == 8) continue;
        if (x == 16) break;
        std::cout << x << ' ';
    }
    std::cout << '\n';

    int n = 37, passos = 0;
    while (n != 1) {
        n = (n % 2 == 0) ? n / 2 : 3 * n + 1;
        passos++;
    }
    std::cout << passos << '\n';

    int k = 0;
    do { k++; } while (k < 0);
    std::cout << k << '\n';
    return 0;
}
```

```text
Saída:
43
4 15 
21
1
```

Em `continue`, o laço pula para a próxima iteração; em `break`, ele termina. Para percorrer sem copiar elementos pesados, como strings, use referência: `for (const auto& s : lista)`. Se você precisar alterar os elementos, use `for (auto& x : v)`. Sem o `&`, cada `x` é uma cópia e a modificação se perde.

O laço por intervalo não dá o índice. Quando precisar dele, use o `for` clássico; não há `enumerate` como em Python.

## switch

O `switch` compara um valor inteiro (ou `char`, ou enum) com constantes. Cada caso continua no seguinte até encontrar um `break`, o chamado fall-through. Esquecer o `break` é um bug comum, embora às vezes seja proposital para agrupar casos.

```cpp
#include <iostream>

int main() {
    for (char c : {'a', 'e', 'z', '7'}) {
        switch (c) {
            case 'a':
            case 'e':
                std::cout << c << ": vogal\n";
                break;
            case '7':
                std::cout << c << ": digito\n";
                break;
            default:
                std::cout << c << ": outro\n";
        }
    }
    return 0;
}
```

```text
Saída:
a: vogal
e: vogal
z: outro
7: digito
```

O `switch` não funciona com strings. Para isso use uma cadeia de `if` ou um mapa.

## Sair de laços aninhados

Não existe `break` com rótulo como em Java. As saídas aceitáveis são uma variável de controle, um `goto` raro, ou, o que é mais limpo, colocar o laço dentro de uma função e usar `return`. Essa última é a que costuma impressionar.

## Na entrevista

Prefira o laço por intervalo quando não precisa do índice, e o `for` com `int n = v.size();` quando precisa. Follow-ups comuns: "qual a diferença entre `while` e `do-while`?" e "o que acontece sem `break` em um `case`?" (a execução segue para o caso seguinte).
